## 逻辑、论证与批判性思维

| 工具 | 是什么 / 怎么用 | 出处 |
|---|---|---|
| **可证伪性划界** | 触发：有人说某主张"是科学的"，或某理论怎么都能自圆其说。动作：问"它禁止什么可观察事件发生"，逼出一个"若观察到 X 则理论错"的句子。验收：X 必须是他人可按程序观测的具体事件；若任何观察都能算支持，判为非经验主张， | 《《科学发现的逻辑》》（books/000.md） |
| **假说—演绎否证链** | 触发：要检验一个理论。动作：写成"理论 T + 辅助假说 A + 初始条件 C ⇒ 预见 P"，再取观测 ¬P，得 ¬(T∧A∧C)。验收：结论必须写成"三者至少一错"，并逐条列出可独立检验的 A，不许把失败一股脑记在  | 《《科学发现的逻辑》》（books/000.md） |
| **特设性豁免识别** | 触发：理论被否证后，支持者临时加限定。动作：检查新增假设是否带来新的可观察禁令、是否缩小了理论的经验内容。验收：若新版不禁止任何新观察，只是让旧观察重新变"符合"，判为退化性修补。 | 《《科学发现的逻辑》》（books/000.md） |
| **可检验度比较** | 触发：两个理论都还没被推翻，需要选一个。动作：分别列出各自禁止的观察集合，比较集合大小与数值精确度。验收：能明确说出哪个理论"冒更大风险、给出更多可能被证伪的机会"，优先选它。 | 《《科学发现的逻辑》》（books/000.md） |
| **基本陈述的公共化** | 触发：拿"我亲眼看见"当证据。动作：改写为"在某时某地，任何人按此程序可观察到 X"。验收：第二个人复现得了；复现不了的不算经验基础。 | 《《科学发现的逻辑》》（books/000.md） |
| **反例情境法** | 触发：拿到一段自然语言论证，先别管内容真假。动作：只保留形式，构造一个"前提全真、结论假"的情境；只要能设想出来，就判无效。验收：能把这个情境写成两句话，且不违反逻辑可能性（如"巴黎宣布独立"）。 | 《《Forallx：形式逻辑导论》》（books/001.md） |
| **可靠性的两道关** | 触发：要判断能不能接受结论。动作：第一关查形式有效（无效即停），第二关逐条核对前提在现实中是否为真。验收：两关都过才叫可靠（sound）；只过第一关只能叫有效，不能拿来当事实。 | 《《Forallx：形式逻辑导论》》（books/001.md） |
| **真值表穷举** | 触发：论证含 2–3 个命题变项。动作：列出 2ⁿ 行真值组合，算每行前提与结论；找"前提全真、结论假"的行。验收：找到即无效并指出该行；找不到即有效，行数必须齐。 | 《《Forallx：形式逻辑导论》》（books/001.md） |
| **小模型反例** | 触发：量化论证疑似无效，但说不出为什么。动作：把论域缩到 1–2 个对象，给谓词指定最小外延，逐个核对。验收：得到一个具体模型（UD + 各谓词外延），使前提真、结论假。 | 《《Forallx：形式逻辑导论》》（books/001.md） |
| **翻译先定论域** | 触发：句子里有"所有""有的""唯一""除了"。动作：先写 UD 与符号化键（每个谓词、每个常项各指什么），再逐句翻。验收：把公式回译成中文，与原文意思一致；含虚构对象的论证必须把该对象放进 UD。 | 《《Forallx：形式逻辑导论》》（books/001.md） |
| **证明逐行核验** | 触发：给出或收到一个形式证明。动作：不重推整体，只逐行核对"这一行是否由所引规则从前面的行得出"。验收：每行都合法，则整个证明合法；有任一行引错规则即整段作废。 | 《《Forallx：形式逻辑导论》》（books/001.md） |
| **演绎有效性反例法** | 触发：有人说"所以必然如此"。动作：只保留推理形式，构造一个前提全真、结论为假的情境；能设想出来即无效。验收：反例情境要具体到"谁在何时何地如何"，不能只说"也许可能"。 | 《《逻辑学：牛津通识读本》》（books/003.md） |
| **归纳强度公式** | 触发：前提只给结论部分支持。动作：比较"前提成立时结论为真"与"前提成立时结论为假"的条件概率，前者更大才算归纳上有效。验收：能说出这个比较依赖哪个总体或参照类；说不出就是空谈。 | 《《逻辑学：牛津通识读本》》（books/003.md） |
| **参照类定位** | 触发：听到"概率是 X%"。动作：追问"在什么人群/什么条件下统计的"，换一个参照类结果会不会变。验收：至少写出两个可能参照类，并说明为何选其中一个。这是全书对"概率"最实用的一刀。 | 《《逻辑学：牛津通识读本》》（books/003.md） |
| **逆概率翻转** | 触发：有人用"巧合太小，不可能是偶然"或"宇宙常数刚好合适"作论证。动作：把 P(证据|假说) 翻成 P(假说|证据)，补上先验概率与"其他假说也能产生该证据"的可能。验收：写出分子分母各是什么；若先验无法估计，明说结论 | 《《逻辑学：牛津通识读本》》（books/003.md） |
| **期望值决策** | 触发：要在风险方案间选。动作：给每个结果赋一个（可为负的）数值，乘其概率后相加，比较总和。验收：数值来源与概率来源都要写明；只比较"最好/最坏结果"不算做过决策论。 | 《《逻辑学：牛津通识读本》》（books/003.md） |
| **连锁悖论的边界追问** | 触发：遇到"去掉一粒仍是秃头，所以永远秃"这类推理。动作：找出哪一步的容忍度被无限传递，追问边界能否被任意移动。验收：指出该论证预设了"边界不存在"，而边界不存在不等于谓词无意义。 | 《《逻辑学：牛津通识读本》》（books/003.md） |
| **名实对账** | 触发：一场争论里同一个词反复出现，双方越说越远。动作：给关键词画两列，左列写它每次出现时指什么，右列写实际对象是什么；标出第一次偏移的位置。验收：能指出"第几句起'X'换所指了"，而不是笼统说"你偷换概念"。 | 《《诡辩与逻辑名篇趣谈》》（books/004.md） |
| **两可之辩拆解** | 触发：正反都能自圆其说，结论随立场翻转（邓析式"以非为是，以是为非"）。动作：不选边，先找被隐去的判准——按哪条规则、由谁裁断、可否事前公开。验收：产出一句"争的不是事实，是缺一条双方都认的判准"。 | 《《诡辩与逻辑名篇趣谈》》（books/004.md） |
| **集合/元素检查** | 触发：出现"牛马四足"这类既可分说又可合说的句子。动作：问谓语是分配给每个元素（俱一），还是描述整体（惟是）；两种读法各算一遍。验收：写出两种结论的数值或真值差异，指出原句歧义所在。 | 《《诡辩与逻辑名篇趣谈》》（books/004.md） |
| **类比限度审查** | 触发：对方用打比方代替论证。动作：列出喻体与本体的相同点、不同点，判断支撑结论的那条属性是否同类。验收：若关键属性不同类，判"类比不成立"，并要求补直接理由。 | 《《诡辩与逻辑名篇趣谈》》（books/004.md） |
| **矛盾并置** | 触发：同一方既主张 P 又主张非 P（"无不陷之矛"与"无不陷之盾"）。动作：把两句并列，找出不可同真的词项，追问是哪一句的适用范围被偷偷放大。验收：明确写出必须撤回哪一句，或加什么限定才能并存。 | 《《诡辩与逻辑名篇趣谈》》（books/004.md） |
| **利害双列** | 触发：两难取舍。动作：按《大取》"利之中取大，害之中取小"，同一方案下列利、列害，再比。验收：决策表必须两列俱全；只列好处或只列坏处都算没做完。 | 《《诡辩与逻辑名篇趣谈》》（books/004.md） |
| **真值表判定** | 触发：要判断一个复合命题形式是否有效/是否重言式。动作：列出全部命题变项，纵向排 2ⁿ 种真值组合；逐列算子公式；看结论列是否全真。验收：行数不缺、每列只按联结词规则算；全真为重言式，全假为矛盾式，有真有假为偶真式。 | 《《逻辑学是什么》》（books/005.md） |
| **推理与论证分检** | 触发：有人拿"逻辑上说得通"为结论辩护。动作：先只查形式（前提真能否保证结论真），再单独查论据是否真实。验收：能明确说出失败在形式还是论据；推理可以前提假而形式对，论证不行。 | 《《逻辑学是什么》》（books/005.md） |
| **三段论核查** | 触发：出现"所有 A 是 B，C 是 A，所以 C 是 B"式推理。动作：把三句化为 A/E/I/O 四种直言命题，标出中项、大项、小项，逐条核对周延与规则。验收：指出违反了哪条规则（如中项一次也不周延）。 | 《《逻辑学是什么》》（books/005.md） |
| **归纳支持度评估** | 触发：结论超出前提所断定的范围。动作：枚举看样本量与代表性，因果看共同因素/差异，类比看关键属性是否同类，假说演绎看能否推出可检验预言。验收：写出一句"结论比前提多断言了什么"，并指出最弱的一环。 | 《《逻辑学是什么》》（books/005.md） |
| **谬误三问** | 触发：看到百分比、平均数、排名。动作：一问基数（分母），二问绝对量（乘出来多少），三问口径（"人均"怎么算）。验收：补齐基数与绝对数后，原结论要么成立要么明显缩水。 | 《《逻辑学是什么》》（books/005.md） |
| **定义体检** | 触发：争论卡在"这算不算 X"。动作：拆成被定义项、定义项、联项，检查是否循环、过宽、过窄或用比喻代替定义。验收：给出一个可操作的判据（满足什么条件算 X），并测试边界个例。 | 《《逻辑学是什么》》（books/005.md） |
| **真值表判定** | 触发：公式只有 2–3 个变项。动作：竖列 2ⁿ 组真值组合；按生成次序横列全部子公式；逐格算到主联结词。验收：主联结词列全 1 为重言式，全 0 为矛盾式，有 1 有 0 为偶真式。 | 《《逻辑学导论（第3版）》》（books/007.md） |

| **论证四问** | 触发：评估社论、评论或题干。动作：①论题与关键概念是否清楚；②前提与隐含前提是否真实或双方可接受；③前提与结论有无语义关联（防有效却不相干）；④支持强度。验收：四问都有书面判断，只做前两问算没评完。 | 《《逻辑学导论（第3版）》》（books/007.md） |
| **强度四档** | 触发：第四问要定档。动作：前提真则结论必真＝演绎有效；支持度大于 50%、小于 100%＝归纳强；小于 50%＝归纳弱；违规则推出＝谬误。验收：贴一档，并写出结论超出证据的那一步。 | 《《逻辑学导论（第3版）》》（books/007.md） |
| **论证图解** | 触发：一段话里有多个"因为"。动作：抓结论指示词与前提指示词，分主结论、分结论、子理由，标"单独支持"与"协同支持"。验收：每个前提都能挂到结论下，能指出哪几条必须合起来才够。 | 《《逻辑学导论（第3版）》》（books/007.md） |
| **谬误定位** | 触发：觉得不对但说不出。动作：先查形式（否定前件、肯定后件、互换条件、中项不周延、量词换序）；再查非形式三类——歧义（概念混淆、构型歧义、错置重音、合举、分举）、假设（非白即黑、复杂问语、以全概偏、以偏概全、混淆因果、虚 | 《《逻辑学导论（第3版）》》（books/007.md） |

| **削弱三路** | 触发：要反驳一个论证。动作：选攻击点——削弱结论、削弱论据、削弱论证方式；手法有否定假设、反驳论据、举反例（无因有果/有因无果）、另有他因、因果倒置。验收：说明它降低了哪一环的成立概率；只表态反对不算。 | 《《逻辑学导论：推理、论证与批判性思维》》（books/008.md） |
