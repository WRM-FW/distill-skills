# 《起初》（全四卷） — 王朔
> 类型：合集 | 原文规模：约 86.8 万字 | 抽样依据（工作档案 udigest/146.md（6 段）

## 一句话
把史书里的帝王将相改写成有口音、会拌嘴的同事，用来练历史小说怎么加对话。

## R｜原文骨架
- 四卷合集，素材只给章号（10—67），未标分卷名与卷界；抽样落在三条互不相连的线。
- 汉宫线：朔儿、阿瞳、韩嫣、李敢、尹婕妤、司马迁、太后 → 写朝会、巡游、修庙、家常，把《史记》人物写成同僚。
- 上古线：黄帝、嫘母、力牧、山戬、赤溷、蚩尤 → 用现代军语写部落行军、侦察、俘获。
- 边地财政线：卜式牧羊捐产、使者问话、县令作证 → 用公文与口供的腔调写"德行"。
- 三条线共用一个方法：给古人配当代口语，让史料的空白处发出声音。

## I｜核心命题与可执行方法
- **错位的口语** —— 看哪句现代话被塞进古人口中 → 问"这句替换了史书里的哪种语气" → 会看到"你还能再可笑点吗"取代了君臣对答的庄重：亲近感来自时代错误。
- **军语授权** —— 看战争段落的术语 → 问"这套词让谁显得可信" → 会看到"番号""前导和搜索兵""职等"：官僚语言一上身，神话就有了编制。
- **史料的填空位** —— 看一段有出处的记载被扩写 → 问"哪句是史书有的，哪句是补的" → 会看到卜式献羊的理由是补的，使者与县令的追问也是补的：小说在记载的缝隙里开工。
- **天子的第一人称** —— 看"我"知道多少 → 问"这个皇帝为什么总在问傻问题" → 会看到把天子降为会被当场嘲笑的人，权力因此变得可写。
- **无权者的插科** —— 看谁在正史里没有台词 → 问"喜剧分给了谁" → 会看到尹婕妤在巡游车上嫌天子口气：笑话交给没资格进列传的人。

## A1｜书中实例
- 阿瞳自述老家"马骑顿，葩拉人"，是二百年前随堂叔西来的四万人之后；叙述者问"您今年二百几了"，被回"讨厌"。见抽样1。
- 巡游车上，尹婕妤贴着天子耳朵说"你还能再可笑点吗"，又抱怨"你昨天吃芸豆了吧"；天子回"你要别人尊重你，你也要尊重别人"。见抽样2。
- 使者问卜式为何屡次捐产，卜式说"靠他一人办不成这事，逮大家一起上，有钱的出钱，有本事的上边境拼命"；上闻之叹"这就是舜内样不教而有天德的人"。见抽样6。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写历史小说、给文言记载补对话时。
- 当用户想学北京口语的节奏与"贫"的分寸时。
- 当用户分析"戏说"与史实的边界、需要判断哪些是补白时。
- 当用户要给严肃题材配置喜剧视角时。
- 与《动物凶猛》同出王朔：那本用回忆写 1970 年代大院，这本把这套语感搬进汉代与上古；同问"人怎么用嘴对付权力"，一个对付父辈，一个对付天子。

## E｜执行步骤
1. 输入一条三十字以内的史料。动作：标出其中的空白（谁说的、为什么、当时在吃什么）。产出：三个可扩写点。
2. 动作：给每个历史人物配一种当代职业口音（科员、销售、司机），只写一句。验收：读者能听出身份，不需要头衔。
3. 动作：写一场"正事被闲话打断"的戏，闲话必须与正事有关。验收：闲话提供信息，不只是搞笑。
4. 动作：把最庄重的一句改成大白话，再读一遍。验收：意思没丢，人才活。

## B｜边界与误用
- 体量近九十万字，密度高、方言重，节选阅读容易只见油滑。
- 对史实是"借用"不是"复原"，不能当历史读物，也不宜用来考据典章。
- 四卷的分卷名与卷界素材未覆盖，跨卷人物关系需回原文核对。
- 玩笑可能盖过判断：人物说得漂亮，不等于作者同意。
