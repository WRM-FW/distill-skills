# 《看见》 — 柴静

## 一句话
一套把"人人知道不合理却无人处理"追到签字人的采访与追问流程。

## R｜原文骨架
- 第一至二章 → 入行与"非典"现场，记者的身体位置先于观点。
- 第三至六章 双城的创伤／是对峙不是对抗／沉默在尖叫 → 未成年人、同性恋、家暴。
- 第七章 山西，山西 → 环境污染与地方经济。
- 第八至十四章 → 征地、真相与涕泪、事实核查。
- 第十五至二十章 → 逻辑从泥土中剥离、无能的力量、采访方法论、陈虻。
- 组织方式：每章一案，案子后面挂一条方法。

## I｜核心命题与可执行方法
**"没人负责"的例行化拆解** —— 触发：一个明显不合理状态持续多年（人被关二十八年、污染不改）。→ 动作：列三栏：谁有权改变、改变对他有什么成本、不问会怎样。→ 验收：若答案是"没人有精力"，机制就是无人负责的例行化，不是某个坏人。

**道德眼光剥离** —— 触发：经济问题被讲成善恶问题（征地、拆迁、污染）。→ 动作：改问"买的是谁、卖的是谁、中间谁在倒手、依据哪一条法"。→ 验收：能把愤怒转成可查的条款与利益链。

**行动者内部逻辑重建** —— 触发：恶性案件。→ 动作：不评价，先重建"在他眼里什么后果不可承受"，用他的时间尺度而不是你的。→ 验收：能写出他的推理链，且这段文字不构成辩护。

**事实与结论分离** —— 触发：手上堆了大量采访材料。→ 动作：先出材料，后出结论；结论标明"这是我的解释"。→ 验收：读者能据同一批材料不同意你。

**采访即相互探问** —— 触发：面对受害者或加害者家属。→ 动作：先交出自己的一点处境，再问对方。→ 验收：对方开始反问你，而不是只作答。

## A1｜书中实例
1. 谢洪武被关二十八年，只有一张拘留证，档案里没有精神病鉴定；所长说"我说了，没有那个精力，不问那个事"，"好像他是自然而然的，好像合法一样"。
2. 土地那一段：从"不要用道德的眼光看经济问题"起，一路追到1982年宪法第十条"城市的土地属于国家所有"。
3. 药家鑫案：受访者说"你记住了车牌号，我爸妈知道了，就饶不了我，这对他是天大的事"；柴静由此进入加害者的恐惧逻辑，而不是替他开脱。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写调查报道或深度访谈，需要提问结构。
- 当面对一个"人人知道不合理却无人处理"的机构现象。
- 当需要在愤怒与理解之间找一个可核查的位置。
- 与 075 的差别：075 让你看见"理解"如何被用来开脱；166 要求理解之后仍回到事实与条款。

## E｜执行步骤
1. 输入一个个案。→ 画权力链：谁签字、谁受益、谁受损。→ 产出：责任分布图。
2. 找三个人：执行者、旁观者、家属。→ 各问同一组"为什么不"。→ 验收：三种答案之间的缝隙就是机制。
3. 把道德判断改写成条款问题。→ 查法条、查文件、查执行记录。→ 产出：可核查的事实清单。
4. 重建行动者逻辑。→ 用他的词写一段第一人称。→ 验收：不添加辩护词。
5. 输出：材料在前，结论单列，并标注不确定处。

## B｜边界与误用
- 个人回忆体，材料经过叙事重组，不能当采访实录直接引用。
- 方法散落在故事里，大量篇幅是自我省察，需要自己提炼，照搬容易学成姿态。
- 所依托的媒体环境已变，调查报道的操作空间与伦理须重新校准。
