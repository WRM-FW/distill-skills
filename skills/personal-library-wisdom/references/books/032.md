# 《美丽新世界》 — 奥尔德斯·赫胥黎
> 类型：文学 | 原文规模：约 12.1 万字 | 抽样依据（工作档案 udigest/032.md（6 段）

## 一句话
把控制写成舒适：人不是被压服的，是被提前调好、再配上止痛药。

## R｜原文骨架
- 第一章—第三章 → 培育中心、波卡诺夫斯基流程、睡眠教育；展示"制造人"的生产线。
- 第四章—第九章 → 伯纳德、莱妮娜、赫姆霍兹；个体不适与集体仪式的摩擦。
- 第十章—第十八章 → 伯纳德、赫姆霍兹与野人的冲突公开化，让"舒适"与"自由"正面碰撞。
- 《重返美丽新世界》（1958）分章：人口过剩、数量与质量、过度组织化、宣传、化学劝诱、无意识的劝诱、睡眠教育、争取自由的教育 → 把小说命题拆成可查的机制。

## I｜核心命题与可执行方法
**痛苦的去路** —— 看这个社会把不适送到哪个环节 → 问："这里的人用什么代替忍受？" → 会看到：苏摩、睡眠教育、条件设置；痛苦不是被解决，是被提前删除。

**"进步"的定义权** —— 看一句话里谁在定义好处 → 问："'进步'的受益人和成本承担者分别是谁？" → 会看到：一个卵子变九十六个人被称"惊人的进步"，论证靠"难道你真的不明白吗"顶替。

**异端经济学** —— 看罪名的受害者是谁 → 问："这条罪到底伤害了谁？" → 会看到：谋杀只杀一两个人，异端"对社会本身造成冲击"，因为人可以再造——可替换性才是控制的前提。

**强制与关怀同源** —— 看镇压现场的话术与武器 → 问："安抚的话和麻醉枪是不是同一套系统发的？" → 会看到：水枪、苏摩气体与"做个快乐的好人"的合成音同时到达。

**论文当说明书** —— 看《重返》把哪个大词降解成技术 → 问："这条预言在现实里对应哪个具体装置？" → 会看到：洗脑被拆成广告、潜意识映射、睡眠教育，可逐项对照当下。

## A1｜书中实例
- 第一章：主任演示波卡诺夫斯基流程，学生"在他们的小笔记本里划了下划线"；一个卵子最终"从八个变成了可观的九十六个胚胎"，他称之为进步。
- 抽样3：主任谈伯纳德的处置——"没有任何罪行比异端行为更加十恶不赦"，理由是"谋杀只会杀害一两个人"，而个体可以随时再造。
- 抽样4（暴动现场）：警察用水枪射倒伯纳德，音轨播放"合成反暴动演讲二号"，两分钟后那群德尔塔"含泪互相亲吻和拥抱"。

## A2｜何时调用 / 与相邻书的区分
- 当用户想分析消费社会如何让人自愿放弃某些自由时。
- 当用户写反乌托邦，需要"舒适型控制"而非"恐怖型控制"的细节时。
- 当用户想检查一项"便利"替自己挡掉了哪种不适时。
- 与《1984》同问控制如何生效：1984 答恐惧、匮乏、减字；本书答舒适、消费、造人。诊断"人怕什么"用 1984，诊断"人舍不得什么"用本书。

## E｜执行步骤
1. 取一项日常便利（推荐算法、止痛药、团建）→ 问它替代了哪种不适 → 产出"痛苦替代表"。
2. 取一段"进步"叙事 → 标出被计量的指标与被忽略的成本 → 重写一句不带褒义词的描述。
3. 读《重返》任一章 → 找一个它预言的技术 → 在今天找对应物 → 记录吻合与不吻合各一条。
4. 验收：结论要能落到具体装置，不能停在"细思极恐"。

## B｜边界与误用
- 小说（1932）与论文（1958）语气、立场不同，不要混引成一套预言。
- 书中的阶层与优生设定使用当时的种族语汇，直接套用会滑向歧视；应把它当被讽刺的对象读。
- "舒适即控制"解释不了自愿的反抗，也替代不了具体的政治分析。
- 抽样集中在生产线、暴动与论文，野人结局的细节未覆盖。
