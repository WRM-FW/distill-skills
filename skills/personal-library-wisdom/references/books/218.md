# 《名家大作超值组合套装（共 14 册）》 — 敬一丹、水均益、严歌苓等

> 类型：合集 | 原文规模：约 136.1 万字 | 抽样依据（工作档案 udigest/218.md（6 段）

## 一句话
五种文体并置，看提案、照护、怀旧、缉毒与言情各自怎么说话。

## R｜原文骨架
这是一套商业捆绑的多作者合集，总书目在素材中未展开，抽样能确认的只有五种文体，各干各的活：
- 电视人口述（敬一丹《我遇到你》）：〈"迟钝"，也许成全了我〉〈自从十岁遇到话筒〉〈放大弱者的声音〉 → 体制内如何把想做的事说成能批的事。
- 长篇小说（严歌苓《床畔》）：万红、张谷雨、吴医生 → 照护劳动如何被看见，又被结算。
- 抒情散文（写天津、年画与〈写作是什么〉的一篇）→ 怀旧如何把城市写成可消费的风景。
- 类型小说（缉毒段落：林凤冲、马海伟、东哥）→ 程序细节如何制造紧张。
- 都市言情（雷奕明、高雯）→ 欲望如何被写成可排练的剧本。
其余分册抽样未覆盖，不作评价。

## I｜核心命题与可执行方法
**提案的翻译术** —— 看一个想法怎样在十分钟内被说成"可以批"的样子（言论节目、议政色彩、话题来自代表委员、填补台里空白、对国家形象有利）→ 问"哪一句打动了审批者" → 会看到话语空间是靠"对上级有用"的论证打开的，不是靠正确。
**照护的三种计价** —— 看谁在擦身、谁在算年头（万红守了三年，吴医生把求婚当成"该是个头了"）→ 问"这份劳动被谁承认、折成什么" → 会看到同一张病床前，护理是职业、是情感、是宗教，而婚姻被当作结算方式。
**怀旧的取景** —— 看散文把哪些东西写成"岁月"（桃花、年画、绣花鞋、二流伶人的戏）→ 问"谁的生活被写成风景，谁在替她维持这份慢" → 会看到审美化的城市背后有被省略的班次与工钱。
**程序的快感** —— 看缉毒段落怎样用一瓶衡水老白干、洒在衣领上的酒、被拆开的水箱推进 → 问"读者被允许知道多少" → 会看到类型叙事的紧张来自流程细节，不来自人物内心。
**台词的导演权** —— 看高雯关灯、快进、把腿搁上沙发这一串动作 → 问"这场戏是谁写的、谁在演给谁看" → 会看到言情把欲望处理成剧本，连"意外"都是设计好的。

## A1｜书中实例
1. 敬一丹：2003 年新闻频道开播前，她没写策划案、没做专家论证，用大约十分钟向梁建增描述一档节目——"它是一个言论节目，具有议政色彩"，话题全部来自人大代表和政协委员。想法当场得到肯定，随后招兵买马。
2. 严歌苓《床畔》：吴医生从背后搂住万红，一边说"现在大城市心很高的姑娘都在打什么主意""打我这样人的主意"，一边把求婚的话混在闲谈里；万红"觉得被他拥抱竟是这样美好"，同时瞥见病床上张谷雨的右手有了变化。
3. 缉毒段落：马海伟拿起衡水老白干猛灌一口，又顺着脖领子洒了几洒，装醉去敲门；搜到卫生间，冲水把手上没有牵线，水箱里也没有毒品包裹，林凤冲一把薅起东哥撞在墙上。

## A2｜何时调用 / 与相邻书的区分
- 当用户拿到一套混杂合集，需要先判断"哪一本能回答我的问题"时。
- 当用户要做媒体、公关、体制内提案，需要看一个想法怎么被包装成可批的项目时。
- 当用户写照护、医护、长期陪护题材，需要看"付出如何被折价"时。
- 与《要有光》同写病床与家属：梁鸿追问制度接口，本套装里的《床畔》追问情感归属。
- 与《我们生活在巨大的差距里》同是随笔：余华给个人视角，敬一丹给机构视角。

## E｜执行步骤
1. 拿到合集先做文体分类：口述、长篇、类型小说、散文、言情各归一堆 → 产出"问题—文体"对照表。
2. 对口述材料，列出被省略的人（编辑、摄像、被采访对象）→ 判断这段叙述在为谁立传。
3. 对小说，找"作者替谁说话"的那一段 → 标出叙述视角的性别与阶层。
4. 把同一事件的不同文体版本并排（例如"照护"在小说里与在口述里）→ 看哪种版本给出了价格。
5. 输出一句结论：这套书里只有哪一本值得读完，其余跳过 → 验收：能说出理由，而不是"都挺好"。

## B｜边界与误用
- 商业捆绑，14 册水平与文体差异极大，任何一本的立场都不能代表整套。
- 抽样只覆盖五六种文本，总书目与其余分册未知，不能据此判断全集质量。
- 名人自述有事后合理化，成功案例的"十分钟说服"不可复制。
- 类型小说里的性别描写与警匪想象较陈旧，引用时需保持距离。
