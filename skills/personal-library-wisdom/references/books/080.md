# 《蛙》 — 莫言
> 类型：文学 | 原文规模：约 12.1 万字 | 抽样依据（工作档案 udigest/080.md（6 段）

## 一句话
用接生与引产的同一双手，算清一个国家怎样把生育变成账目。

## R｜原文骨架
- 第 1—5 章 → 剧作家蝌蚪以书信体向日本作家杉谷义人讲述姑姑万心的一生，每封信后接一章正文，信是辩解，正文是事件。
- 第一幕—第九幕 → 同名话剧，把前文讲过的场面重新演一遍，让人物当面对质。
- 第 6 章《听取蛙声一片——代后记》 → 交代素材来源与写作缘由。
- 结构要点：小说与剧本不是重复，是"讲述版"与"审判版"的并置；同一个人在两版里的说辞不同。

## I｜核心命题与可执行方法
**同一双手的正反面** —— 看姑姑的职业动作在前后期怎么变 → 问："同一套技术，谁给它换了目的，她怎么给自己记账？" → 会看到：一九五三年骑车去接生，后来带人堵门拆房逼引产；她反复念叨接生了一万个孩子，用接生数冲抵引产数——数字是她的赎罪券。

**数字的会计学** —— 看人物报数的方式 → 问："这个数怎么算出来的，谁被抹掉了？" → 会看到："与别人合作的，两个算一个"；合作接的算半个，被引产的从不入账。统计口径就是道德口径。

**命名的逃逸** —— 看人物有几个名字、谁在用哪一个 → 问："叫他这个名字的人站在什么立场？" → 会看到：万足／万小跑／蝌蚪，乳名是乡土的，笔名是文人的，"蝌蚪"又是被当作生育原料的物；名字每换一次，责任就淡一层。

**物的换算** —— 看冲突里出现什么物、赔什么 → 问："身体被折算成了什么？" → 会看到：门楼、树、罚款、鸡蛋、代孕费。王仁美把被砍的树说成"青春损失费"，是被剥夺者临时发明的一套计价法。

**双轨叙述** —— 看同一件事在小说与话剧里的差别 → 问："哪一版多出了什么？" → 会看到：剧本让人物当面互相指认（陈眉跪着叫所长"包大人"），小说里的蝌蚪却可以一直辩解。形式本身就是责任分配。

## A1｜书中实例
- 抽样第 1 段：姑姑十六岁从卫生学校毕业，一九五三年四月初四接第一个孩子，到去年春节"一共接生了一万个孩子，与别人合作的，两个算一个"；第一个接生的却是她口中的"地主的狗崽子"陈鼻。
- 抽样第 3 段：为逼王仁美引产，姑姑喊"我不下地狱，谁下地狱"，带人用钢丝绳套住肖家大门楼；王仁美从地窖爬出答应手术，随后咬住小跑手腕："你让我流血，我也让你流点血。"
- 抽样第 6 段：话剧第九幕，陈眉在派出所跪下喊"包大人"，所长敷衍"本官一定会报告给包大人知道"，并把她的乳汁说成"那是汗水吧"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要拆解"政策—执行者—受害者"三层责任时。
- 当用户想让一个人物既是加害者又是受害者时。
- 当用户要写统计数字如何塑造道德感时。
- 当用户想让小说与剧本互文、互相拆台时。
- 与《生死疲劳》同写高密东北乡与国家政策：一个用六道轮回把五十年摊开，一个用书信加话剧把一件事说两遍。
- 与《丰乳肥臀》都写生育：一个把母亲写成土地，一个把接生婆写成国家的手。

## E｜执行步骤
1. 选一个执行过强硬政策的人 → 列出"职业动作清单"与"自我辩解句" → 标出哪句是向上级说的、哪句是对当事人说的。
2. 建一张双栏账：左栏"我救过／做成过多少"，右栏"我造成过多少损失" → 检查两栏口径是否一致（是否一边用"个"、一边用"例"）。
3. 把同一事件写成两版：一版第一人称辩解，一版全由当事人对话推进 → 看哪一版更难撒谎。
4. 验收：能指出原文一处"用数字抵消罪感"的句子，并说明它省略了谁。

## B｜边界与误用
- 题材涉及计划生育，立场敏感；书中把执行者写成有血肉的人，不等于替她开脱，引用时须分清"人物的辩解"与"作者的判断"。
- 后半部代孕、牛蛙公司情节近乎闹剧，不能当社会调查读。
- 话剧部分语言高度戏曲化，直接当口语样本会失真。
- 姑姑的悔写得充分，被引产妇女的正面声音偏少，这是视角的缺口，不是事实的全部。
