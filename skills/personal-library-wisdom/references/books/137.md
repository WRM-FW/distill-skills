# 《空中小姐》 — 小米
> 类型：文学 | 原文规模：约 10.5 万字 | 抽样依据（工作档案 udigest/137.md（6 段）

## 一句话
把找书、解谜、查案写成同一件事：知识怎么变成路线，引文怎么变成证据。

## R｜原文骨架
- 三十章，加"代后记：无主题发布会"与"挑战读者"；章名多为两字（丝迷、早餐、书路、乌有、笔记、推想、酒神、巫焚、送书、命案、图纸、天干、魔术、对谈）。
- 主线是旧书圈的一桩命案与一桩旧案（"魔术师之死"），叙述者"我"与警察林莫忘搭档，边查边掉书袋。
- "天干"一章给出"四步寻书法"与天干口诀，用来在书库中定位；"挑战读者"则宣告这是本格推理，线索对读者公开。
- 抽样覆盖：早餐、酒神（夜店）、天干（书库定位）、怪谈（访客）、枪击现场、办公室闲谈。

## I｜核心命题与可执行方法
- **线索的换乘** —— 看一条线索如何变成下一条 → 问"这次靠规则、惯例还是猜测" → 会看到"包含自身"这类自定规则：解谜的合法性由解谜者自己宣布，赌错就全盘皆输。
- **引文的第二职业** —— 看书中被引的段落 → 问"它在这里是证据、解释，还是装饰" → 会看到《你一生所见的事》《鉴证百科》被用来给现实命名：读书人先找句子，再承认自己看见了什么。
- **命名的伏笔** —— 看人名（林莫忘、林莫失、莫林） → 问"这组近似是巧合还是布置" → 会看到推理小说用命名对称暗示亲属与替代关系。
- **荒诞的配速** —— 看血腥场面旁边的日常 → 问"作者用什么细节给读者换气" → 会看到焦黑排骨、自制餐锤、啃骨头的声音：喜剧稀释暴力，也拖延真相。
- **公平游戏的契约** —— 看"挑战读者" → 问"关键线索是否在揭晓前全部出现过" → 会看到本格推理的诚信边界：可以藏，不可以骗。

## A1｜书中实例
- 林莫忘早餐啃一块"通体焦黑、状似《鉴证百科》插图中烧死之人的大腿"的排骨，硬到能咬出声音；叙述者说要去拿自制的"餐锤"，典故来自科幻小说《僵硬的舌头》。（第二章）
- 依"谷雨前三戊土盛""己土三日威风盛"等四句，按顺时针、"包含自身"的规则，从"戊库"推到"庚库"倒数第二排，认定珍妮外公留下的东西在那里。（天干）
- 夜店挂着提香《酒神的狂欢》复制品，墙上是西南边陲的神谱，高处玻璃罐里据说是骨灰；叙述者想"这是个连殡仪馆都位置紧张的时代吗"。（酒神）

## A2｜何时调用 / 与相邻书的区分
- 当用户要写书业、藏书、旧书店题材时。
- 当用户设计解谜链条，需要"规则—验证—排除"的写法时。
- 当用户想给硬知识配上日常喜剧的节奏时。
- 当用户分析"引用"在叙事中的功能时。
- 与《长夜难明》同为罪案：一个靠程序与社会压力推进，一个靠文本与知识游戏推进；同问"真相怎么被证明"，一个问证据资格，一个问线索公平。

## E｜执行步骤
1. 输入一条待解线索。动作：写下三条可能规则，各推一步。验收：每条都能推出一个可检验的地点或人名。
2. 动作：为你的推理指定一条"自定惯例"，并写明它可能错在哪。产出：一句风险声明。
3. 动作：把一处硬知识（版本、典故、工艺）写成人物顺手的一句解释，不超过两句。验收：不打断对话。
4. 动作：在紧张段落之间插入一个吃饭或找东西的细节。验收：读者松一口气，线索仍在推进。

## B｜边界与误用
- 素材的书名作者（《空中小姐》、小米）与抽样内容（书业侦探小说）明显不符，版本元数据不可靠，引用需另核。
- 书中大量引书、引文多为虚构或半虚构，不能当资料源。
- 掉书袋段落会拖慢节奏，模仿时容易变成知识展示。
- 抽样未覆盖结局与凶手揭示，不能据此判断推理是否公平。
