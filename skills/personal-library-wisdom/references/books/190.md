# 《俗世奇人全本》 — 冯骥才

> 类型：合集 | 原文规模：约 8.0 万字 | 抽样依据（工作档案 udigest/190.md（6 段）

## 一句话
用五十余个天津卫奇人，示范一件事如何钉住一个人。

## R｜原文骨架
五十余篇笔记小说，一篇一人，按"靠什么在天津卫站住"分组：
- 手艺与绝活：〈苏七块〉〈刷子李〉〈泥人张〉〈张大力〉〈大回〉〈甄一口〉〈崔家炮〉 → 一门手艺如何被当众验收。
- 官场与嘴：〈死鸟〉〈好嘴杨巴〉〈陈四送礼〉〈大关丁〉 → 话怎么说才不挨罚。
- 骗与偷：〈小达子〉〈黄金指〉〈皮大嘴〉〈棒槌壶〉 → 谁的解释最后算数。
- 女性与传说：〈酒婆〉〈背头杨〉〈黄莲圣母〉〈刘道元活出殡〉 → 越界的女人如何被传成故事。
- 首尾：〈篇首歌〉〈奇人辈出〉〈自画小说插图记〉交代写法与来历。

## I｜核心命题与可执行方法
**掺假的收益账** —— 看酒馆老板几十年掺假、唯一不掺假那天出了事 → 问"这条街上诚实折算成什么" → 会看到道德判断被一次偶然推翻，因果被当成报应。
**当众验收** —— 看一门手艺在什么人面前、用什么动作完成证明（崔老大两手各攥一响、大回用铜环套住王八、甄一口的酒从脚出）→ 问"他为什么非得让人看见" → 会看到价值不在使用，在公开可复核。
**外号的可用范围** —— 看这个外号能不能当面叫 → 问"谁有权说这个词" → 会看到天津卫的等级不用头衔标，用称呼的禁区标。
**解释权** —— 看一件东西被几个人给出几种说法（倪三少的壶：高人点化、老头找乐、自己编造、"壶上那条狗"）→ 问"哪一种最后成了本地结论" → 会看到市井的真相是多版本共存，谁也结不了案。
**身体的局部开发** —— 看绝活落在身体哪一处（大回的手、甄一口的脚、孟大鼻子的鼻）→ 问"这一处被训练到什么程度，代价是什么" → 会看到"奇"是把一个人压缩成一件工具。

## A1｜书中实例
1. 酒婆：她喝酒不就菜，一饮而尽，喝完就走，从不赊账。老板忽然想到，她出事那天正是自己不往酒里掺假的头一天，"原来祸根竟在自己身上"，于是别扭起来——"到底骗人不对，还是诚实不对？"
2. 崔家炮：崔老大把两响攥在手里放，一手一响，证明炮不虚。有人用针锥把演示用的两响扎透，上下两截变成一截，当场炸烂他的手掌；不久街上就传出"这沿儿庄的两响不能买"。
3. 小达子：他在电车上偷了那人的表链，下车一摸怀中"竟然空空如也"。对方龇牙一笑，他始终琢磨不出表是怎么被取回去的，"打这天，小达子不再上电车"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写一个只靠一件事立住的人物，需要看"一人一篇"怎么下刀时。
- 当用户要处理市井、行规、手艺、传言，需要具体的动作与器物时。
- 当用户想练短篇的收尾，需要看"不解释"怎么收时。
- 与《老舍全集》同写京津市民：老舍用长句和方言铺开一个家，冯骥才用短句和一件绝活钉住一个人。
- 与《镖人》同写"江湖规矩"：镖人是武力秩序，俗世奇人是手艺秩序。

## E｜执行步骤
1. 选一个市井职业 → 写它的"验证时刻"：谁在场、做什么动作、失败会怎样 → 300 字。
2. 只写动作与器物，删掉全部心理描写 → 检查人物是否还立得住。
3. 给人物起外号，并规定谁能当面叫 → 用一次称呼冲突推进情节。
4. 结尾加一句本地传言，让事实与解释错位 → 验收：读者说不清谁对。
5. 对照〈篇首歌〉的写法，删掉最后一句总结。

## B｜边界与误用
- 笔记小说高度传奇化，不可当民俗志或史料引用。
- 女性多为奇观（酒婆、黄莲圣母），很少有自己的账本。
- "奇"的逻辑容易把穷、没出路写成命，读时要把结构性问题补回来。
- 租界、码头、清末民初的语境不能平移到当下职场。
