# 《传奇》 — 张爱玲
> 类型：文学 | 原文规模：约 17.2 万字 | 抽样依据（工作档案 udigest/135.md（6 段）

## 一句话
用嫁娶、姑妈、丫头和一只镯子，拆解都市男女如何把感情按银钱与体面结算。

## R｜原文骨架
- 序《有几句话同读者说》 → 作者自陈写作与读者的关系，可当读法提示：她要写的是"通常的人"。
- 收十一篇：鸿鸾禧、红玫瑰与白玫瑰、桂花蒸阿小悲秋、金锁记、倾城之恋、茉莉香片、沉香屑 第一炉香、第二炉香、琉璃瓦、年轻的时候、中国的日夜。
- 题材分两路：上海与香港的婚配家产（金锁记、倾城之恋、鸿鸾禧），洋场与留学生的自我想象（第二炉香、年轻的时候）。
- 抽样落在：鸿鸾禧（敦凤、米先生、老太太）、金锁记（七巧、芝寿、长安）、第一炉香（薇龙、睇睇、睨儿）、第二炉香（愫细、罗杰）、年轻的时候（汝良、沁西亚）、中国的日夜（奚太太、阿芳）。

## I｜核心命题与可执行方法
- **婚配的会计** —— 看说亲场面 → 问"谁出钱、谁出力、谁得名" → 会看到爱情被折成月钱、房子和亲戚的嘴；"反正家里总是你大"就是结算结果。
- **器物作证** —— 看一件反复出现的物件 → 问"它在谁手里、值多少、能不能分" → 会看到七巧把镯子一路推到腋下：身体瘦了，财产还在，人已被金子量完。
- **声音的等级** —— 看谁在大声说话 → 问"这个嗓门属于哪个阶层" → 会看到丫头斗嘴敢喊"君子动口，小人动手"，太太们压低声音说男人；阶级写在音量上。
- **看客的高度** —— 看叙述者站哪里 → 问"他从几楼往下看，为什么'没有能力干涉'" → 会看到冷眼是一种自保：看清而不介入，才写得出苍凉。
- **翻译的误差** —— 看留学生如何描述异国女性 → 问"他爱的是人还是'另一个世界'" → 会看到汝良把沁西亚和"像奖学金，像足球赛，像德国牌子的脚踏车"归在一起：欲望借现代性给自己镀光。

## A1｜书中实例
- 七巧晚年摸着腕上翠玉镯子，"徐徐将那镯子顺着骨瘦如柴的手臂往上推，一直推到腋下"，想起十八九岁时镯子里只塞得进一条洋绉手帕。（金锁记）
- 薇龙初上梁家，被丫头睇睇、睨儿的斗嘴挡在门外，一只木屐飞出来打中膝盖；她心里念"阎王好见，小鬼难当""在他檐下过，怎敢不低头"。（第一炉香）
- 汝良路过公馆听见绍兴戏，忽然省悟"绍兴戏听众的世界是一个稳妥的世界──不稳的是他自己"。（年轻的时候）

## A2｜何时调用 / 与相邻书的区分
- 当用户要写民国上海或香港、写婚嫁与大家族时。
- 当用户练"用物件替代心理描写"时。
- 当用户分析亲戚、佣人、看客构成的舆论场时。
- 当用户需要"冷叙述"的样本、避免抒情过度时。
- 与《四合如意》共用一本婚配账：张爱玲的货币是聘礼、金饰、亲戚面子，张怡微的货币是首付、中介费、流量；同问"婚姻怎么谈"，一个在沦陷前后，一个在平台时代。

## E｜执行步骤
1. 输入一场"见客/说亲"戏。动作：列出全部称谓、礼物、座次。验收：不看情节也能判断谁求谁。
2. 动作：标出全场唯一没说话的人。验收：能说出他/她为什么不能说话。
3. 动作：选一件道具（镯子、大衣、木屐），让它出现三次，每次改变含义。产出：一段三百字。
4. 动作：删掉所有心理动词，只留动作与对白。验收：情绪仍在，且更冷。

## B｜边界与误用
- 时代与阶级限定强：大家族、佣仆、洋场，直接移植到当代会失真。
- 叙述的冷常被读成刻薄，或被简化成"祖师奶奶"腔调；学腔容易学眼难。
- 影视改编多把苍凉改成爱情，引用时以原文为准。
- 抽样未覆盖《倾城之恋》《红玫瑰与白玫瑰》正文，涉及这两篇的判断需回原文。
