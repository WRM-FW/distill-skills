# 《窄门》 — 安德烈·纪德
> 类型：文学 | 原文规模：约 4.2 万字 | 抽样依据（工作档案 udigest/161.md（6 段）

## 一句话
把“为了更爱而放弃爱”的推理推到尽头，露出自我牺牲里的占有。

## R｜原文骨架
全书八章，无小标题，主干是杰罗姆的第一人称回忆：
- 童年段落 → 舅妈露希尔的客厅、牧师家庭的气氛，阿莉莎的自律由此显影。
- 假期段落 → 花园、泥灰岩矿场长椅，关于死亡与重聚的对话。
- 中段 → 巴黎与芬格斯玛尔的往返通信，阿莉莎不断以"更好"为由推迟。
- 末段 → 阿莉莎的日记残页，把推迟写成神学论证。
- 两种文体并置：写给对方的信与写给自己看的日记，互相拆台。

## I｜核心命题与可执行方法
**牺牲的收益** —— 看阿莉莎每次"放弃"之后得到什么 → 问：她让出的是爱人还是竞争对手 → 会看到牺牲换来道德高位，而高位是她唯一能占的位置。
**文体分层** —— 看给杰罗姆的信与给自己日记的差别 → 问：哪一版更接近她 → 会看到信是给对方看的，日记也在写给"他"看的自己。
**引文的挡箭牌** —— 看帕斯卡尔、波德莱尔被谁引用、用来回答什么 → 问：引用是在思考还是在回避 → 会看到神学词汇替代了欲望的直说，越崇高越说不出口。
**推迟的结构** —— 看每一个"以后"由谁设定 → 问：推迟本身是不是关系的形式 → 会看到不见面才是他们真正维持关系的方式。
**第三人的代价** —— 看朱莉叶特的婚事被谁安排 → 问：她的让步换来了谁的圣洁 → 会看到阿莉莎的美德以妹妹的顺从为前提。

## A1｜书中实例
阿莉莎的梦（抽样2）：她说梦见杰罗姆死了，"为了再见到你，我绞尽脑汁"，又说"死亡反而能让人靠近"。这句话后来成了她所有推迟行为的注脚。
帕斯卡尔的谈话（抽样5）：她说重读时吸引她的只有"想拯救生命的人，必会失去生命"，其余"几乎没看懂"。她用一句自己承认读不懂的话，为终身的选择背书。
日记（抽样6）：她写"你指引我们走的路，是一条窄路——窄到容不下两人并行"，又写动笔原是为了摆脱他，结果日记成了"通信的延续"。自欺在她笔下是可见的。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写克制的爱情，需要避免煽情时。
- 当用户想分析自我牺牲背后的控制欲时。
- 当用户处理信件、日记、回忆录三种文体的不可靠性时。
- 与《玩偶之家》同看婚姻与自我：那本让女主在揭穿后出走，这本让女主在信仰里越退越远；同问"她要的是什么样的爱"，不同在出走还是内耗。

## E｜执行步骤
1. 输入：把阿莉莎的每次"放弃"列成时间线，旁注她因此获得的评价。
2. 动作：在每次放弃旁标两栏——她实际失去了什么／她避免了什么。
3. 动作：对照同一时期的信与日记，圈出人称与语气的变化。
4. 产出：一段三百字的内心独白，不许出现"上帝""牺牲"两个词。
5. 验收：若独白仍能解释她的选择，说明动机不止于信仰。

## B｜边界与误用
- 冉森派与帕斯卡尔的语境对中文读者有门槛，不补背景会把她读成单纯的宗教偏执。
- 阿莉莎没有完整的正面陈述，她的形象由日记和杰罗姆的转述拼成。
- 杰罗姆的回忆带美化，不能当作客观时间线。
- 抽样未覆盖全书章节，朱莉叶特婚后部分仅见片段。
