# 《超级沟通者》 — 查尔斯·都希格
> 类型：论说 | 原文规模：约 13.1 万字 | 抽样依据（工作档案 udigest/128.md（6 段）

## 一句话
先判断对方在谈哪一种对话，再决定给方案、给共情还是给身份认同。

## R｜原文骨架
- 开篇「三种对话类型」→ 务实对话（这究竟是关于什么的）、情感对话（我们的感受如何）、社交对话（我们是谁）。
- 匹配原则（第 1 章，招募间谍）＋运用指南Ⅰ「建立有意义对话的四大原则」→ 沟通要先识别类型再对齐，错配就断线。
- 务实对话（第 2 章，勒罗伊·里德审判）＋运用指南Ⅱ「提出问题，留意线索」→ 决策类对话靠提问与协商。
- 情感对话（第 3—5 章，对冲基金经理、《生活大爆炸》、谈枪支）＋运用指南Ⅲ → 倾听、共情、在冲突中建立连接。
- 社交对话（第 6—7 章，说服反疫苗者、网飞）＋运用指南Ⅳ → 身份、刻板印象威胁、如何谈最难的对话。

## I｜核心命题与可执行方法
**先判类型再回应** —— 开口前先判：对方要的是决策、共情，还是身份被承认 → 务实对话给选项和下一步；情感对话先承认感受；社交对话谈具体经历、不贴群体标签 → 验收：对方从"你不懂"转为继续说；若对方重复同一句话，就是类型错配的信号。

**问题深入一层** —— 想建立连接 → 把"你做什么工作"换成"你为什么做这个""最难的一次是什么" → 每次对话至少问一个感受类问题 → 验收：对方给出超出事实的回答（动机、情绪、脆弱处）。

**理解循环** —— 对方说完 → ①提一个澄清问题 ②用自己的话复述 ③问"我理解得对吗" → 三步走完再表达自己 → 验收：对方说"对，就是这个意思"；若被纠正，回到第二步重做。

**全频倾听** —— 听一段叙述 → 分三层记：发生了什么、他最在乎什么、他的情绪是什么 → 把三层复述回去 → 验收：三层各写一句，且讲述者认可。

**困难对话去泛化** —— 话题涉及身份（性别、族裔、立场）→ 只讲自己的具体经历与感受，不概括对方群体，不替对方定义痛苦 → 验收：整段话没有"你们这种人"；对方开始讲自己的具体事。

**匹配脆弱** —— 对方暴露弱点 → 回以同等程度的自我暴露，不急着安慰也不急着给建议 → 验收：对话轮次继续增加而不是终止。

## A1｜书中实例
- 招募雅思明（第 1 章）：劳勒搞砸了第一次接触，她担心被杀，明说绝不可能帮忙；加钱、加承诺都无效，唯一出路是让她相信他懂她、会保护她。
- 里德案陪审团（第 2 章）：主席要求先谈感受再投票；卡尔等三人认定有罪，洛林与亨利因被告有阅读障碍而动摇，七人保留，僵局由此打开。
- 艾普利受访（第 2 章）：作者准备了一串问题，受访者却反过来连续提问，越问越深，最后作者自己讲出了家庭、兄弟的官司和写书的动机。

## A2｜何时调用 / 与相邻书的区分
- 当用户要谈一次难谈话（离职、冲突、分手、劝说不合作的人）时。
- 当对方情绪失控，用户不知道该讲道理还是该安慰时。
- 当用户说服立场对立者屡屡失败时。
- 当用户想让自己在群体里更被信任、更有影响力时。
- 与《可复制的领导力》同谈沟通：樊登给管理者输出（BIC、表扬）的模板，本书先判断对话类型；与《原则》相比，本书补上"身份被威胁时，人就事论事做不到"这一层。

## E｜执行步骤
1. 输入一段即将进行的对话 → 写一句判断：这是务实、情感还是社交对话 → 产出类型判断。
2. 按类型写开场三句：一个开放问题、一句复述、一句自我暴露 → 产出脚本。
3. 对话中执行理解循环：问—复述—确认，再表达自己的立场 → 验收：对方至少一次说"对"。
4. 结束后记三栏：他说的事实、他在乎的东西、他的情绪 → 验收：三栏都能填满。
5. 一周后再谈同一话题，比较两次的轮次与对方开放程度。

## B｜边界与误用
- 案例集中在美国语境（枪支、疫苗、种族、陪审团），移植到别处要换场景与称谓。
- 匹配不等于迎合：识别类型是为了对上频道，不是为了同意对方。
- 理解循环做成机械复读会被识破，复述必须抓到对方没说出口的重点。
- 抽样未覆盖四份运用指南正文，具体练习步骤须回查原书。
