# 《堂吉诃德》 — 塞万提斯
> 类型：文学 | 原文规模：约 40.6 万字 | 抽样依据（工作档案 udigest/141.md（6 段）

## 一句话
把“照书里的规则活”推到极限，检验现实与虚构谁先撑不住。

## R｜原文骨架
- 前言、出版说明、译者序、精印本引言 → 交代这本书是反骑士小说的阅读装置，也预告了真伪之争。
- 第一部（第1–52章）→ 受封、两次出征；风车、羊群、释放囚犯，每次理想都换来一顿打。
- 第二部 → 人物已经读过第一部，名声先于本人到达，公爵夫妇把捉弄办成节目。
- 第五十八章 → 离开公爵府，讲自由与受恩的负担。
- "前言致读者"（章节列表中位于第五十二章后）→ 作者抱怨传记被人乱写，争夺解释权。

## I｜核心命题与可执行方法
**文本层叠** —— 看人物是否读过关于自己的书 → 问：他此刻按哪一版行事 → 会看到第二部里现实被第一部的读者改写，虚构反过来规定现实。
**命名的授权** —— 看阿尔东沙被改称杜尔西内娅、客栈被称作城堡 → 问：谁有权改名，谁负责配合 → 会看到意义靠旁人默认才站得住。
**见证者的修正** —— 看桑丘每次说实话 → 问：实话为什么总被解释掉 → 会看到"现实"不是被看见的，是被维持的。
**疯的开关** —— 看堂吉诃德谈自由、美德、职业的时候 → 问：他在哪些话题上完全清醒 → 会看到疯是选择性装置，只在涉及骑士身份时启动。
**代价的承担者** —— 看每次冒险后谁在疼 → 问：理想主义的账单开给谁 → 会看到挨打的是他，付钱和挨饿的是桑丘。

## A1｜书中实例
释放囚犯（抽样2）：他把苦役犯当成受迫害的骑士，打倒押送者；事后要求被救的人去向他那位小姐报信，遭拒后引发混战。善意直接生产了更大的暴力。
桑丘的描述（抽样4）：他说看见杜尔西内娅"正在簸麦子"，灰尘把脸遮暗；堂吉诃德立刻改写成贵妇在编织金线花边的活儿。同一场景，两套词汇，谁也不让步。
公爵府（抽样5）：公爵夫人拿已出版的传记质问他是否真有心上人；他答"世界上有没有杜尔西内娅……谁知道呢"，把虚构升格为一种自愿的信仰。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析理想主义组织为何反复撞墙时。
- 当用户想写"不可靠叙述者"却不想用第一人称时。
- 当用户需要区分"信念"与"自我表演"时。
- 与《月亮与六便士》同写单一执念：那本把执念写成天才的代价，这本把执念写成喜剧；同问"他为理想付出了什么"，不同在谁付账。

## E｜执行步骤
1. 输入：选一段冒险，列出"他依据的书本规则"与"现场反馈"两栏。
2. 动作：标出每一次反馈被谁、用什么说法解释掉。
3. 动作：把场景搬到当代组织（创业、公益、学术），保留结构换掉名词。
4. 产出：一段三百字的现代版，要求读者能同时笑和不安。
5. 验收：改写后仍能指出"谁在付代价"。

## B｜边界与误用
- 版本与注释体量巨大，章节划分随译本变动，引用需注明版本。
- 它是喜剧，不是励志书；把堂吉诃德当榜样会删掉全书的自嘲。
- 女性多为被命名的对象，杜尔西内娅全程没有自己的话。
- 抽样只覆盖若干段，第二部的捉弄结构未能完整核验。
