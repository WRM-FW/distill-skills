# 《分析心理学的理论与实践》 — 卡尔·古斯塔夫·荣格
> 类型：论说｜原文规模：约 8.9 万字｜抽样依据（工作档案 udigest/018.md（6 段）

## 一句话
五讲临床现场：把自我、情结、原型、移情拆成可指认的观察线索与追问顺序。

## R｜原文骨架
- 演讲一 → 自我由身体觉察与记忆两部分构成；意识功能分外部心理（对环境的定向）与内部心理（对无意识进程的定向）。
- 演讲二 → 由一例精神分裂症幻觉与魔法书"逐字重合"，推出集体无意识。
- 演讲三 → 用高山症企业家的连续三场梦示范析梦，明确反对单梦解释。
- 演讲四 → 古代梦例（阿基劳斯、格拉菲拉）与析梦者的限度。
- 演讲五 → 移情的词源与临床处理，末段把原型接到 1918 年的历史预感。

## I｜核心命题与可执行方法
**自我情结定位** —— 触发：来访者说"我不知道自己是谁" → 动作：让他列出构成"我"的两类材料（对身体与处境的持续觉察、可回溯的记忆），再标出哪些经验"吸不进去" → 验收：能指认一个反复充当磁极的叙事（职业、家族角色）；反证：若换一个情结能同样好地组织同一批材料，则自我情结的解释不成立。

**四功能入口识别** —— 触发：有人说"我就是不会看人" → 动作：听他描述一件事时先给出什么——感官事实（感觉）、分类与因果（思维）、好坏取舍（情感）、走向与可能（直觉） → 验收：连续三件事都走同一入口；反证：若压力下稳定翻转到相反入口，那是情境策略，不是类型。

**系列梦而非单梦** —— 触发：有人拿一个梦来求解 → 动作：先要连续记录（他明确说二十到一百个才看得出夜复一夜的进程），把同一意象的变形排成序列 → 验收：能说出一条跨梦重复的场景或角色关系；反证：他自己承认单梦"可以做出任意的猜测"，一旦下一夜的梦与此前解释冲突，即撤回。

**原型识别** —— 触发：意象的强度与内容都超出个人生平 → 动作：先查神话母题与跨文化重复，再查童年读物、电影、听闻 → 反证：只要能追到个人来源，就按个人情结处理，不上调到集体层。

**移情即搬运** —— 触发：来访者对你的情绪强度与当下互动不相称 → 动作：用 Übertragung 的原义"把某物从一处带到另一处"，问他把哪段关系里的位置搬了过来（求助者、被判者、被选中者） → 验收：能同时指认被搬运的角色与原始关系；反证：若当下确有真实冒犯且强度相称，先按现实关系处理。

## A1｜书中实例
- 高山症企业家（演讲三）：眩晕、心悸、作呕与登山病症状一致；他白手起家、不断攀高，症状恰在跻身上流社会时出现。荣格不停在"这是高山症"，而是让他报梦，用梦把"你忘了自己从多低的地方上来"接上躯体。
- 阿基劳斯之梦（演讲四）：公牛冲破篱笆践踏庄稼，析梦者据此判断将有外力夺其所有；数日后罗马使节抵达，他被免职流放。荣格评这位析梦者"恰如其分"。
- 精神分裂症患者的幻觉（演讲二）：荣格起初判定"这个男人是个疯子"，读到迪特里希的书第七页发现意象逐字重现，这一震惊成了集体无意识的经验起点。

## A2｜何时调用 / 与相邻书的区分
- 当用户要为一组梦找读法，而不是解一个孤立的梦时。
- 当症状与处境明显同构（越往上爬就越眩晕）时。
- 当来访者对帮助者的情绪明显超过帮助者实际做过的事时。
- 当意象明显不属于这个人的生平材料时。
- 与《心理类型》同问"人如何定向"，差别在：本书给临床现场的判据与梦的序列，类型学那本给分类坐标。
- 与《寻求灵魂的现代人》共用高山症案例，差别在：本书保留演讲问答的现场推理，那本把它收进"现代人的处境"叙述。

## E｜执行步骤
1. 输入：一段症状描述＋最近三个梦的书面记录。
2. 先做躯体排查：症状是否符合某种已知生理模式（如高山症）；符合则并列记录，不拿心理替代。
3. 把三个梦按时间排开，只标重复场景、人物角色、身体动作；此步禁止写解释。
4. 找症状与处境的同构点（高度、速度、被看见），写成一句假设，同时写下反证条件。
5. 下次访谈只问一句验证性问题（"你最近是不是又往上走了一步"）；被否就退回材料重排。

## B｜边界与误用
- 原型一旦当作解释几乎不可反驳；单梦解释他自己都称为"任意猜测"，没有连续材料时本书给不出判据。
- 集体无意识依赖跨文化比较，"金发野兽"式的历史预感属时代言论，不宜当方法搬用。
- 五讲是口语现场，术语随讲随造，不能当体系教科书读。
