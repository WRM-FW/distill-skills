# 《荣格作品集》 — 卡尔·古斯塔夫·荣格
> 类型：合集｜原文规模：约 102.8 万字｜抽样依据（工作档案 udigest/033.md（6 段）

## 一句话
五类文本合装：自传、理论、文艺评论、临床技法、宗教对照，可各取一把尺。

## R｜原文骨架
- 自传群（童年至后期思想、通信、术语诠释）→ 用个人史示范内在意象如何被追下去。
- 理论群（分析心理学的基本假设／集体无意识的原型／集体无意识的概念）→ 给原型与无意识下定义。
- 文艺评论群（论分析心理学与诗歌的关系／心理学与文学／《尤利西斯》／毕加索／美学中的类型问题／日神与酒神）→ 用原型与类型读作品。
- 临床技法群（五讲／治疗实务原则／治疗的目的／宣泄的心理治疗价值／解析梦的实用性／梦的本质／情结理论／类型的一般描写／精神分裂）→ 给操作口径。
- 宗教与文化群（精神分析与灵魂治疗／心理学与宗教／纪念理查·威廉）→ 拿东方材料作对照。

## I｜核心命题与可执行方法
**原型识别（理论群·宗教群）** —— 触发：意象强度远超个人经历，或当事人要求"在善恶里选一边" → 动作：先看它是否让对立面同时起作用（梦里老人同时演示善恶如何运作），再查神话母题与跨文化重复 → 验收：能指出该意象在哪些文化里以同一结构出现；反证：他自己加了限定——"这只有在道德敏感性被夸大的情况下才是真实的"，若无意识立场与意识态度一致，就不能读成对立面依存。

**目的论提问（临床群·解析梦的实用性）** —— 触发：梦的内容明显不实、与当事人自述的关系不符（儿子梦见父亲醉驾撞墙，而父亲喝酒极有节制） → 动作：不问"为什么"，改问"做这个梦目的为何"，把梦当作对意识片面性的补偿 → 验收：能说出梦在平衡意识的哪一侧（此例是父亲给的安全太多）；反证：若梦只是日间残留的直译，目的论不增加信息，退回因果读法。

**否定性思维识别（文艺与思想评论）** —— 触发：一套解释"什么都说通了" → 动作：看它是否把对象化约为更普通的东西（"哗众取宠""他图什么好处"），或反过来提升为超验（"另一种层面""震动电波"）；荣格指出唯物论与通神论在此同构 → 验收：能指出它取消了对象的哪一部分；反证：若解释给出新的可检验细节，就不是否定性思维。

**伪现代人辨识（自传群）** —— 触发：有人以"我早已超越那些阶段"自居 → 动作：查他是否完成了被跳过的任务（技艺、承担、职责），因为只有超越过去的意识阶段才谈得上现代意识 → 验收：能举出一件他确实跳过的任务；反证：若有可核验的技艺与承担，不能仅凭姿态判为伪现代。

## A1｜书中实例
- 善恶相依的梦（理论群）：梦中老人演示善恶如何一同起作用；荣格引印度警句——爱上帝的人需七世才趋于完美，恨上帝的人只需三世。
- 父亲醉驾梦（临床群）：做梦者是汽车机械工，做事仔细，与父亲关系很好；荣格拒绝按"你其实恨父亲"去加重他的负担，改问梦的目的，得出"父亲给的保障太多"。
- 隐修处（自传群）：父亲与天主教神父交友，他去看克劳斯修士的圣物，心里打寒战："有谁能跟一个圣者生活在一起呢？"

## A2｜何时调用 / 与相邻书的区分
- 当用户只想找荣格某一篇的入口，而不是读整本专著时。
- 当用户要分析一件文艺作品里的反复意象时。
- 当用户被一套"什么都解释通了"的说法说服时。
- 当用户想辨别"现代"是姿态还是完成时。
- 与《心理类型》同讲类型，差别在：本书只收"一般描写"一节，系统论证仍在专书。
- 与《分析心理学的理论与实践》同讲析梦，差别在：本书多了目的论读法与文艺应用，现场问答的细节在那本。

## E｜执行步骤
1. 输入：一个反复出现的意象（梦、画、写作中反复冒出的场景），附出现时间与当时的处境。
2. 先查个人来源：童年读物、电影、真实人物、近期事件；能对上就停在此层。
3. 对不上，再查原型：这个意象在神话、宗教、炼金术里是否以同一结构出现，记下三处旁证。
4. 加问目的：它在补偿意识的哪一侧？写成一句"它要做的相反的事是……"。
5. 写反证条件并留观：下一次该意象出现时，看它是否仍承担同一功能；不承担就退回第 2 步。

## B｜边界与误用
- 合集拼装，篇目水平与体例不一，术语在不同篇里所指不完全一致。
- 原型解释几乎不可证伪，最易把任何巧合说成"集体"的。
- 文艺评论里的判词（《尤利西斯》、毕加索）带强烈个人立场，不宜当定评。
