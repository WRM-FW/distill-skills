# 《汪曾祺集》（全十册） — 汪曾祺
> 类型：合集 | 原文规模：约 85.5 万字 | 抽样依据（工作档案 udigest/070.md（6 段）

## 一句话
用手艺、吃食和闲话，把人怎么过日子写成看得见的细节。

## R｜原文骨架
- 小说卷（《大淖记事》《岁寒三友》《八千岁》《故里三陈》《桥边小说三篇》等）→ 每篇立一个靠手艺或怪脾气活着的人，情节让位给"他怎么干活、怎么说话"。
- 《晚饭花集》《菰蒲深处》两组初版本目录 → 可见作者按集子编排，匠人、尼姑、医生、旧书生反复出现，题材成系列。
- 随笔与文论（《小说笔谈》《八仙》等）→ 直接谈语言标准、现代派取舍、民间信仰，是全书最能抽出方法的部分。
- 书话（一折八扣书、扫叶山房、旧书摊）→ 记录一套廉价读书人的物质生活与趣味。
- 记人篇（《云致秋行状》《金冬心》等）→ 借"行状"一类旧体例给人立小传，评价藏在逸事里。

## I｜核心命题与可执行方法
**手艺账** —— 看人物第一次出场在干什么活 → 问："他靠哪一手换饭吃，这手艺在他身上留下什么固定动作？" → 会看到：人物不靠心理独白成立，靠旋木、开方、翻土这些动作成立；性格是手艺的副产品，不是前提。

**吃食的计量** —— 看一顿饭由谁做、给谁吃、吃完谁的态度变了 → 问："这桌菜在替谁说话？" → 会看到：仁慧的香蕈饺子不是风俗点缀，是她与二师父争夺庵堂支配权的凭据——素席办起来，香钱按月按比例分，反对声就压下去了。

**准确** —— 看他怎么判断一句话好不好 → 问："这句能不能'悬之国门，不能增减一字'？" → 会看到：他举交通安全标语"横穿马路不要低头猛跑"、卫生墙报"残菜剩饭必须回锅见开再吃"，标准不是文雅，是一看就明白、一听就记住。

**自在的算术** —— 看民间信仰里被省略掉的部分 → 问："这些神仙替信众省掉了哪笔开销？" → 会看到：八仙"度人"不讲精修顿悟，只讲看破富贵、不争酒色，所以是"很便宜的，不费劲的"生活理想；拜八仙＝用最低成本换心理稳定。

**闲笔的位置** —— 看叙事在哪一段忽然停下来写景、写吃、写路人 → 问："停了这一笔，谁的处境被悄悄交代了？" → 会看到：闲笔常承担不能明说的部分：时局、贫穷、孤独，都从旁门进来。

## A1｜书中实例
- 抽样第 2 段：尼姑仁慧募款修缮正殿、办素席，二师父骂"观音庵是清静佛地，现在成了一个素菜馆"，而"合庵尼僧都支持她"；她接着还要学只有和尚才放的焰口。
- 抽样第 4 段：《八仙》一文引浦江清《八仙考》，判断八仙被画在一起"只是为了互相搭配，好玩"，落点是"中国人为什么对八仙有那样大的兴趣呢？无非是羡慕他们的生活"。
- 抽样第 1 段：过江渡轮上一对卖唱父女，叙述者反复否认自己事先认得他们，写那支曲子"不是改变，是完成"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写一个靠手艺吃饭的普通人，又不想写成苦难展览时。
- 当用户想让风俗、吃食、器物承担情节功能而不是当背景板时。
- 当用户要练"准确"的句子，删形容词、换动词时。
- 当用户分析的文本闲笔很多、被旁人当成废话时。
- 与《骆驼祥子》都写底层劳动：老舍把劳动写成被榨取的过程，汪曾祺把劳动写成一个人最后的体面。
- 与《丰乳肥臀》都写乡土：莫言用身体和暴力记账，汪用吃食和手艺记账。

## E｜执行步骤
1. 选一个人物 → 列出他全部动作中的"专业动作"（与情节无关的那些） → 产出一张手艺清单，看哪一项能替代外貌描写。
2. 选一处吃食 → 写清食材、成本、谁做、谁吃、吃完谁的态度变了 → 验收：删掉这段情节是否受损；若不受损，它只是布景，重写。
3. 拿自己写的一句话做"增减一字"测试 → 删一个形容词、换一个动词 → 看意思是否更准。
4. 用 300 字写一段"停下来"的闲笔，要求不解释、只写动作，让读者自己读出这个人的处境。

## B｜边界与误用
- 十册合集，抽样只覆盖部分小说与随笔，散文、书信、戏剧未覆盖，不能据卡片判断全集调性。
- 汪的"淡"最容易被误学成不写冲突。他的人物多在争实利：香钱、摊位、面子，只是冲突不摆到正面。
- 名士趣味重，对旧文人、书画、骨董的欣赏带阶层偏好，写底层时偶有"可爱化"。
- 语言观偏准确、口语，不适合拿去论证抽象命题。

## 金句
- "语言的目的是使人一看就明白，一听就记住。语言的唯一标准，是准确。"
- "在克制欲望与满足可能的欲望之间，保持平衡，求得一点心理的稳定。"
