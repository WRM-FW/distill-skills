## 一句话
检查制度如何把服从写进词典、公式、玻璃和节日动作里。

## R｜原文骨架
- 四十则"记录"，每则冠以三个短语作小标题（如"夹克 墙 时刻表"、"纤毛虫 世界末日 她的房间"），另有《当晚二十二点钟》一节与附录《论文学、革命、熵与其他话题》。
- 记录一至三 → 由叙述者向"不认识的读者"解释绿墙、时刻表、恩主，解决"如何把制度说成常识"。
- 记录四至十七 → 遇见 I-330、进入古屋，解决"理性人如何被旧世界吸引"。
- 记录十八至二十九 → 全体一致日、恩主选举、公报宣言，解决"幸福如何被立法"。
- 记录三十至四十 → 想象力手术、骚乱、结局，解决"清除异端的技术流程"。

## I｜核心命题与可执行方法
**词典式陌生化** —— 看叙述者把哪些词当作需要向"野蛮人"解释的外来语：夹克、墙、时刻表、个人时间、母性规范、绿墙、恩主。问：我们今天觉得理所当然的哪些词，也值得这样注释一遍？会看到极权不靠隐瞒，靠把制度说成自然，再用一句"是最完美的"式反问完成论证。

**公式的失灵点** —— 看数学语言出现在哪里，又在哪里算不下去。他谈"无穷小的三阶函数""函数的极限"，甚至在楼梯上突然怀疑"重力不变是一个错误的想法"。问：哪一次用公式解释情感时句子断了？会看到理性话语的裂缝，正是主体崩解的位置。

**玻璃的认识论** —— 看透明墙体与"看得见"的安排。城市用玻璃建造，窗户、走廊、日程都可见。问：谁在看，谁被看，看得见是否等于自由？会看到透明不是自由的证明，而是把隐私改造成可审计项。

**幸福的神学** —— 看《众一国公报》如何定义完美：机器比人更完美，因为"机器没有想象力"；想象力被定为疾病，病灶在脑桥的某个结节，可手术切除。问：这套幸福定义把谁排除在外？会看到乌托邦的成本表被写成医学术语，排斥以治疗的名义执行。

**节日的身体编排** —— 看全体一致日、年度选举、统一新制服。问：仪式要求身体做哪些动作（排队、举手、穿同一件衣服）？会看到政治不只进入头脑，它先进入衣柜和时刻表。

## A1｜书中实例
记录三开篇：叙述者承认要解释这些词"非常滑稽而且困难"，好比二十世纪作家必须解释什么是"夹克""公寓""妻子"；随后用"人的尾巴不见后"作类比，论证定居生活最完美。

《众一国公报》宣言：先逐条比较电动机的火花、活塞的运动与人的理性，再落下判决——"机器没有想象力"，而人的微笑与夜间叹息是病症，"这种疾病的名字就是"想象力。清除方案随即公布：找到脑桥区域的结节。

记录三十七：餐厅里一切突然颤抖，叉子停在半空，人群"就像一部曾经和谐运作的宏伟的机器凌乱不堪的碎片"涌向电梯，整条大街像"显微镜下的一滴水"，里面全是乱窜的纤毛虫。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析制度语言如何伪装成常识，需要一份"被注释的词典"时。
- 当用户写反乌托邦、AI 治理、量化生活，需要具体的装置清单（玻璃、时刻表、手术）时。
- 当用户想检查自己所在组织的"幸福定义"排除了谁时。
- 与《鼠疫》同写封闭城市，差别在：加缪关心人在灾祸中如何熬，扎米亚京关心制度如何把人重新命名；一个写例外状态，一个写日常状态。

## E｜执行步骤
1. 从文本里抄出十个被解释的制度词 → 为每个词写一句"如果不解释，读者会怎么误解" → 产出"常识伪装表"。
2. 找三处数学或工程比喻 → 标出它解释的是哪种情感 → 判断哪里开始不成立。
3. 列出书中所有"可见性"装置（玻璃墙、守护卫、日程表、制服）→ 标注各自监控什么 → 对照自己生活中的同类装置。
4. 取一份组织宣言 → 用书中句式改写：先宣布"快乐吧！"，再宣告"这个障碍已经被清除了" → 验收：能否看出它删掉了哪种人。
5. 写一则三百字的"记录"，要求叙述者真心相信制度，且每段末尾都自我说服一次。

## B｜边界与误用
- 不是政治学论著；它的力量在语言实验，不能当制度分析框架引用。
- 最容易被误用为"任何管理都是极权"的万能指控；书中区分了供暖、排队等具体机制，笼统类比会失去精度。
- 女性人物（O、I-330）多作为主角自我觉醒的触发装置，性别书写有明显时代局限。
- 日记体叙述者本身不可靠，他转述的公报与对话都经过其情绪过滤，引用时须标出这一层。
