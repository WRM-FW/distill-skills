# 《荣格自传：回忆·梦·思考》 — 卡尔·古斯塔夫·荣格
> 类型：传记｜原文规模：约 18.9 万字｜抽样依据（工作档案 udigest/030.md（6 段）

## 一句话
用一个人八十年的自我记录，示范如何把梦、分裂与两难当成可追踪的材料而非答案。

## R｜原文骨架
- 一至三章（童年、中学、大学）→ "两个世界"与第一、第二人格的分裂如何形成。
- 四章 精神病治疗活动 → 临床判断、梦的预告（犹太女病人）。
- 五章 弗洛伊德 → 决裂的经过与分歧点。
- 六章 正视潜意识 → 主动想象与自我实验。
- 七章 著述 → 由《金花》进入炼丹术，接上自己十七世纪的梦。
- 八至十章 塔楼、旅行、幻象 → 把内在意象放到建筑与地理上验证。
- 十一至十二章及回顾 → 死后生活、后期思想。

## I｜核心命题与可执行方法
**两个人格分栏记录** —— 触发：当事人说"我在不同场合像两个人" → 动作：给两套各起名字，分别记兴趣、语言、价值判断、出现条件（他自己是：科学满足第一人格，宗教与历史研究供第二人格） → 验收：能说出各自的触发场景与代价；反证：若两套服务于同一目标、只是策略不同，那属角色切换，不是人格分裂。

**梦的预告式使用** —— 触发：反复梦见陌生人或陌生场景 → 动作：只记细节（年龄、衣着、说话方式、自己的动作），不解释；等现实出现对应人物再对照（他梦见不认识的姑娘患恋父情结，次日来诊者正是此人） → 反证：对照若靠事后修改记忆完成，一律作废；记录必须先于事件。

**把叙述当"我的神话"** —— 触发：写自传、复盘人生 → 动作：不追求客观标准（他说自传"没有什么标准，也没有客观的基础"），改问：哪些事件被反复讲、哪些被删、我用哪个寓言装它们 → 验收：能指出一条贯穿的母题。

**两难不求解决** —— 触发：面对责任冲突 → 动作：不逼出正确答案，让自我同时当原告与被告，把双方理由写到势均力敌（"它必须还得学会扮演被告的角色"） → 验收：决定作出后仍能复述被放弃一方的理由；反证：若一方理由明显不成立，那本来就不是冲突。

**异地作对照实验** —— 触发：想看清自己的默认设置 → 动作：换环境后记录"我在这里变成了什么"，而不是记录当地人（他明说非洲之行是"严格的个人性项目"）。

## A1｜书中实例
- 犹太女病人（四章）：他先梦见陌生姑娘患恋父情结，次日来诊者正是此人；他在她身上查不到恋父痕迹，转而问祖父，得知是虔敬派拉比，她闭眼一瞬，他据此确认关键。
- "上帝的世界"（二章）：童年他把超人之物归入另一个世界，因无人可讲而学会沉默，内心分成两个世界。
- 《金花》与炼丹术（七章）：威尔海姆 1928 年寄来文本，他起初视为"胡说八道"，搁置两年后认出炼丹术士"用象征说话"，才回头接上自己十七世纪的梦。

## A2｜何时调用 / 与相邻书的区分
- 当用户想理解自己长期"像两个人"的体验时。
- 当用户反复做同一类陌生场景的梦并想验证时。
- 当用户要写自传、口述史或做人生复盘时。
- 当用户卡在无法两全的责任冲突里时。
- 与《分析心理学的理论与实践》同讲梦，差别在：本书的梦是传主自己的，用于示范"记录先于解释"，那本用病人梦示范序列分析。
- 与《寻求灵魂的现代人》同谈现代处境，差别在：本书以个人时间线为证据，那本以时代诊断为主。

## E｜执行步骤
1. 输入：一份按年排列的十件大事清单，只写事实与日期。
2. 标出其中被反复提及的三件，以及你从未对任何人讲过的三件。
3. 为反复出现的那条线写一句母题（如"总在爬到某高度时出事"），不许用评价词。
4. 找最近一个梦或一次强烈情绪，写下细节，留空解释栏。
5. 四周后回填：哪些细节在现实中找到了对应，哪些没有；只保留对上的部分。

## B｜边界与误用
- 这是回忆性自传，不是史料；记忆重构与神话化是它自己承认的方法。
- "梦的预告"极易变成事后归因，没有事前书面记录就不能算验证。
- 神秘倾向明显（死后生活、幻象章），当材料读可以，当证据用会滑向不可反驳。
