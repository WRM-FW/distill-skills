# 《原型与集体无意识》 — 卡尔·古斯塔夫·荣格
> 类型：论说 | 原文规模：约 18.8 万字 | 抽样依据（工作档案 udigest/208.md（6 段）

## 一句话
把反复出现的意象当跨文化母题，先看正反两面，再问它在补偿什么。

## R｜原文骨架
- 全书无章节标题标记。按抽样可见论题分为：精神现象、母亲原型、原型解释原则、老人原型、个体化个案、文献注释。
- 开篇论"精神"：肯尼亚艾尔恭依部落的夜神、诺斯替灵魂赞美诗、温哥华来信人的水梦 → 精神先以气息、风、水被经验到。
- 母亲原型：伊甸园、圣城、田野、洞穴、奶牛、坟墓、巫婆并列，收束为"既可爱又可怕的母亲"。
- 原型解释原则：神话不指太阳或月亮，而是"未知的第三者"；原型是活的精神力量，赶不走。
- 老人原型：西伯利亚独腿老人、爱沙尼亚童话、墨林 → 赐生者同时是致死者的对立面。
- 个体化个案：55 岁的 X 小姐，研习心理学九年，"爸爸的女儿"，阿尼姆斯，回丹麦寻根。

## I｜核心命题与可执行方法
**母题清点** —— 触发：同一意象反复出现 → 动作：列同族形态（母亲＝伊甸园／圣城／田野／洞穴／奶牛／坟墓） → 验收：至少三种不同文本的变体，且不是同义反复。

**双面校验** —— 触发：某形象被当成纯善或纯恶 → 动作：找它的反面（母亲＝圣母／巫婆，老人＝赐生／致死，pharmakon 兼毒药与解药） → 验收：能指出缺失的那一面藏在哪。

**语境优先** —— 触发：出现"善良老人"式的帮助者 → 动作：查他在主角遇困之前做了什么 → 验收：能判断帮助本身是否就是陷阱。

**补偿假说** —— 触发：意识态度过度偏向一方 → 动作：看无意识产物是否给出相反意象 → 验收：能说出它在补哪种片面，而不是泛说"象征潜意识"。

**个体化轨迹** —— 触发：拿到一串梦或幻想 → 动作：按时间排，标自我与阴影、阿尼玛／阿尼姆斯、自性的关系变化 → 验收：指出"对抗—承认—整合"走到哪一步。

**拒绝标签** —— 触发：想直接说"这是母亲原型" → 动作：先写它在此文本中的具体动作与情绪 → 验收：解释里至少有一句只能用于这个文本。

## A1｜书中实例
- 肯尼亚艾尔恭依部落长者描述"恐惧制造者"的夜神："他要么像一阵冷风吹拂着你，使你瑟瑟发抖，要么在长草中呼啸嗷叫"，荣格称之为非洲潘神。
- 爱沙尼亚童话：丢了奶牛的受雇男孩遇到"大有帮助的老人"；荣格怀疑奶牛正是老人赶走的，所以老人也有洞穴巨人、魔鬼的一面。
- X 小姐个案：55 岁、研习心理学九年、与母亲关系不好、靠父亲情结形成阿尼姆斯，来欧洲前先回丹麦。

## A2｜何时调用 / 与相邻书的区分
- 当同一意象在梦、文本、广告、仪式里反复出现时。
- 当要判断某个象征解释是否过度时。
- 当分析品牌神话、政治图腾、集体仪式时。
- 当要区分个人情结与集体母题时。
- 与《梦的解析》：一个问个人愿望如何被伪装，一个问跨文化母题为何复现。
- 与《红书》：一个给概念分类，一个给现场记录。

## E｜执行步骤
1. 收集同一意象的五个出现场景：自己的梦、文本、新闻、广告、仪式。
2. 每场景记三项：谁在用它、它做什么、结局如何。
3. 分正负两栏，找缺失的一面。
4. 查同族形态，删掉只靠词典的对应。
5. 验收：写 150 字说明它在补偿什么，并留一句"不确定"。

## B｜边界与误用
- 原型是不可证伪的"未知第三者"，只能当解释框架，不能当因果证明。
- 民族志材料多为二手转引，且带 20 世纪初的殖民语汇，引用时需标明。
- 最容易被误用成民族性、血统论或"集体记忆"的万能背书。
- 集体无意识不能替代个人史；具体人的冲突仍要回到他的经历。
