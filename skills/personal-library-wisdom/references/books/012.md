# 《兄弟》 — 余华
> 类型：文学 | 原文规模：约 26.3 万字 | 抽样依据（工作档案 udigest/012.md（6 段，另有一份同书重复副本）

## 一句话
让一个镇子围观两场灾难，看中国人怎样把羞辱熬成热闹、把身体换成生意。

## R｜原文骨架
- 上部（章节以编号呈现，如“四”“三十四”）→ 宋凡平之死与两个孩子的童年：捞尸、送葬、挨打，李兰的偏头痛与耻辱。
- 上部中段 → 李光头追求林红：让五个孩子喊口号喊成“性交”，又到针织厂门口喊“求爱”，用“阶级敌人”“专政”给自己壮胆。
- 上部后段 → 宋钢与林红结婚，李光头落难；宋钢梦见李兰的托付，“只剩下最后一碗饭了，会让给李光头吃”。
- 下部 → 李光头成为富豪，刘新闻为他朗读“处女来信”；宋钢下岗后卖丰乳霜、戴假乳房，随小关剪刀住进民工区。
- 后记与英、法、德版评论摘要 → 作者自述与接受材料，引用时与正文分开。

## I｜核心命题与可执行方法
**围观的位置** —— 看每场灾难周围站了多少人、站得多远 → 问“他们在看戏还是在帮忙” → 捞尸时“人人脸上都是看戏的表情”；冷漠不是没有人，而是人太多。

**政治词的私用** —— 看人物在私事里借哪套词汇 → 问“这个词原本管什么，现在被用来干什么” → 追女朋友用“无产阶级革命专政”，求爱喊“天地良心”；语言与所指脱钩后变成表演道具。

**身体的两次标价** —— 看身体在上部与下部分别换成什么 → 问“这具身体在跟谁做交易” → 上部用身体挡粪水、挡拳头，下部用假乳房、处女来信换钱；两个时代记的是同一笔账，只是标价方式变了。

**承诺的钉子** —— 看谁在什么场合许下什么、谁被迫兑现 → 问“这句承诺由谁转述，听的人信不信” → 李兰临终把宋钢钉在“最后一碗饭”上；林红一句“她又不是你亲妈”点破外部视角。

**两副笔墨** —— 看上下部的句长、脏话密度、笑料位置 → 问“叙述者为什么在下部变得这么吵” → 形式本身是判断：上部还允许抒情，下部只剩狂欢。

## A1｜书中实例
- 井边（上部开头）：宋凡平把李光头父亲的尸体冲洗几遍，抱进贴着“囍”字的新床；屋外“人山人海，人人脸上都是看戏的表情”，他走过时人群“立刻为他闪出了一条道路”。
- 送葬路上（上部）：两个孩子被一个男人打，扑上去咬他的胳膊和腰；满脸血迹的拉板车人最后说“别哭了，你们哭得我鼻子都酸了”；十几个人跟到家门口，请他们帮忙抬人时“全都一声不吭”。
- 梦境（上部）：宋钢梦见李兰拉着他的手要他照顾李光头，他保证“只剩下最后一碗饭了，会让给李光头吃”，林红打哈欠打断：“她又不是你亲妈。”

## A2｜何时调用 / 与相邻书的区分
- 当用户想分析“公共羞辱如何被组织成娱乐”时。
- 当用户写跨两个时代的家族史，需要处理语言断层时。
- 当用户想诊断“兄弟情义/亲情债务”如何变成长期控制时。
- 与《许三观卖血记》同写身体换生存：许三观的血有明确单价，《兄弟》的身体已升级为品牌与噱头。与《在细雨中呼喊》同写童年创伤：那本靠记忆剪辑，这本靠两段时间对撞。

## E｜执行步骤
1. 输入一场群戏 → 标出所有在场者的动作（看/走开/递东西/说话）→ 产出围观者行为表 → 验收：能区分“帮忙的一个人”与“看着的十几个人”。
2. 输入同一人物在上部与下部的台词 → 对比用词来源（政治词/生意词/脏话）→ 产出词汇迁移表 → 验收：每个新词都能对应一种新权力。
3. 输入一处承诺（口头/临终/梦里）→ 追踪它被谁记住、谁遗忘、谁利用 → 产出债务链 → 验收：能说清这条链最后压垮了谁。
4. 写作训练：同一件事写两版，一版抒情、一版油滑，各 400 字 → 验收：两版事实完全相同，判断完全不同。

## B｜边界与误用
- 下部的大量粗口与性笑话是有意的叙述策略，不是“水平下降”；但也不必硬辩护成深刻。
- 上部把暴力与温情并置，容易让读者把灾难读成传奇；引用时须分清人物的笑与叙述者的态度。
- 女性人物（李兰、林红）多是被观看者，用这本书做性别分析要补别的材料。
- 抽样集中在上部前段、求爱事件、富豪时期与结尾附近，中间大段未覆盖。
