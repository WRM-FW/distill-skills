# 《拿破仑大帝》 — 安德鲁·罗伯茨（Andrew Roberts）

> 类型：传记 | 原文规模：约 69.6 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/204.md（6 段）

## 一句话
用书信与战报对账，分清一个人自述里哪句是事实、哪句是公关。

## R｜原文骨架
- 第一部"发奋为雄"（科西嘉—雾月）→ 他怎样获得权力：科西嘉、大革命、意大利、埃及。
- 第二部"文治武功"（执政—登峰造极）→ 权力怎样被使用：法制、财政、教育、艺术赞助，与奥斯特利茨、耶拿并列。
- 第三部"尘埃落定"（俄国—圣赫勒拿）→ 体系何时反噬：大撤退、莱比锡、滑铁卢。
- 结语与参考文献 → 三千余种史料来源。

## I｜核心命题与可执行方法
**注意力分配图** —— 触发：想判断真实优先级，而不是听事后总结 → 动作：数同一时段他给谁写信、各几封（1805年8月31日：贝尔蒂埃3封，贝西埃、康巴塞雷斯、戈丹各2封，其余各1封）→ 验收：画出"谁被反复找"的名单并解释排序。

**宣言与记录对账** —— 触发：读到胜利公报、撤退说明 → 动作：把宣言与敌方、部下的记录并排（阿克撤退时他说"阿克现在仅剩一堆石头"，作者直指是谎话）→ 验收：逐句标注"事实／宣传／自辩"。

**单点集中判据** —— 触发：评估多线作战或多项目并行 → 动作：问开战前夜是延长战线，还是把全军压到一个点（乌尔姆、耶拿、弗里德兰为正面例，阿斯佩恩-埃斯灵、莱比锡、滑铁卢为反面例）→ 验收：能说出集中的地点、时间与抽调来源。

**制度余量检验** —— 触发：判断一个强人到底留下什么 → 动作：找那些脱离本人仍在运转的机构（他创设的军成为1812至1945年欧洲军队的标准单位；巴黎消防队）→ 验收：至少列出一项"人走制度还在"的证据。

## A1｜书中实例
- 抽样2（埃及、阿克）：围城失败后他致信督政府"这个季节已经过了太久""埃及需要我"，并暗示城内每日六十人死于瘟疫；作者指出整个围城期间杰扎尔军无人死于传染病。
- 抽样2末：多年后他重读阿克宣言，自己承认"这是个小骗局！"
- 抽样3（奥斯特利茨前后）：他把部队从布洛涅东调称作"单脚尖旋转"，对部下说"至少还能去维也纳听午夜弥撒"；作者据此说明"军"这一级作战单位的诞生。

## A2｜何时调用 / 与相邻书的区分
- 当用户要判断回忆录、战报或发布会里，哪些是事实、哪些是包装。
- 当用户要分析多线并行的资源分配，需要"集中还是摊开"的判据。
- 当用户要研究权力交接与制度遗产，想知道哪些安排能活过当事人。
- 与《俄罗斯帝国史》（russia-empire-heller）：同写19世纪初欧洲，罗伯茨以一个人的决策为轴，埃莱尔以制度与农奴制为轴。
- 与《九三年》（93-hugo）：小说把革命放进伦理困境，传记把革命后的权力放进成本账。

## E｜执行步骤
1. 输入一段关键决策。动作：只读他本人书信与公报，先不评价。
2. 动作：建三栏表——他的说法／部下与敌方记录／作者判断，逐句归栏。
3. 动作：标出信息不对称处（谁知道、谁不知道、谁知道却不说），特别是人数与补给。
4. 动作：回看二十年后的自述，找矛盾。
5. 产出：一页"决策—说法—后果"表，可直接用于分析当代公关文本。

## B｜边界与误用
- 行军序列与战报密度极高，非军事读者会被淹没；抽样中有两段整段是参考文献。
- 作者对传主有明显同情，批评时仍沿用他的尺度（如把远征印度称作"浪漫想象"，却不追问代价），需另找批评者平衡。
