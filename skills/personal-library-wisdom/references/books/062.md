# 《法律的悖论》 — 罗翔
> 类型：论说 | 原文规模：约 9.1 万字 | 抽样依据（工作档案 udigest/062.md（6 段）

## 一句话
每个刑法命题都同时立着正反两面，用拆要件和双向论证把结论逼出来。

## R｜原文骨架
- 序言＋法律：法不容情，又法中有情 → 立方法：每个命题先找它的反面。
- 刑法：既惩罚犯罪人又保护犯罪人／罪犯：自我决定又被决定／犯罪：邪恶才犯罪还是犯罪才邪恶 → 刑罚根据与责任。
- 刑法：既独立又补充／因果关系：不可假设但必须假设／对向犯：同罪同罚还是异罪异罚 → 构成要件与归责。
- 生命、勒索、禁止吸毒、名誉权 → 具体罪名两面：被害人同意、自损、表达自由。
- 司法：纠正错误又容忍错误／判决：稳定性与灵活性 → 制度层面的取舍。
- 后记"在针尖上跳舞的天使" → 收在两种价值之间找平衡。

## I｜核心命题与可执行方法
**七格拆要件** —— 触发：判断某行为是否构成某罪 → 动作：拆主体、对象、行为、结果、因果、主观、违法阻却七格，逐格填有／无／不明 → 验收：一格为"无"就不得用"社会危害大"补；全满足才进价值衡量。

**入罪出罪两套原则** —— 触发：结论在两可之间 → 动作：入罪问其他部门法是否已足够（补充性），出罪问道德是否容忍或鼓励（独立性） → 验收："法益—伦理"两栏各写一句理由。

**义务来源分列** —— 触发：不作为案件 → 动作：把道德义务、法律义务、职务义务分三列 → 验收：指出义务来自法条、合同还是身份，不混用。

**对向犯查片面性** —— 触发：双方行为互为条件（行贿受贿、买卖发票、卖淫与组织卖淫） → 动作：查刑法是否只罚一方，再用"自损可否处罚""法不责众"检验 → 验收：不把另一方的可罚性当然推出。

**解释先划词义射程** —— 触发：想用"举轻以明重"把行为纳入罪名 → 动作：写日常含义＋法律定义，再看方向是否利于被告 → 验收：不利类推退回，有利类推才可通过。

**结论三问** —— 问是否违反罪刑法定、是否让国民无法预测、是否把道德争议交给刑罚 → 验收：任一为"是"即退回重写。

## A1｜书中实例
- 李四不救弟弟：老婆一句"你老爸老妈可只有一套房"，他改成"我到时给你烧玩具的"，不构成犯罪；王五不救三岁孩子，则构成不作为的故意杀人。
- 器官移植案：黄某某仅取得部分近亲属同意，条例对"未经全部近亲属同意"没规定刑责，能否定侮辱尸体罪，作者把问题留给读者。
- 真警察抢劫案：有学者用当然解释套"冒充军警人员抢劫"，作者指出这已突破语言极限。

## A2｜何时调用 / 与相邻书的区分
- 当用户问"这个行为犯不犯法"时。
- 当写法律意见要同时给入罪与出罪理由时。
- 当讨论重刑威慑、舆论与司法时。
- 当要识别"当然解释"被用来造法时。
- 与《圆圈正义》：一个讲制度两难，一个讲价值排序。
- 与《刑法罗盘》：一个给悖论框架，一个落到具体罪名与个案。

## E｜执行步骤
1. 写事实表：谁、何时、做了什么、造成什么、主观知道什么。
2. 列可能罪名，每个拆七格。
3. 控方写 300 字，辩方写 300 字，各引一条法条。
4. 用"入罪补充性／出罪独立性"复核。
5. 验收：结论后附一条最强反例，说明它为何不成立。

## B｜边界与误用
- 中国刑法语境，条文以写作时为准，引用前核对现行法。
- 案例多为教学假设（张三李四），不是判例，不能当裁判依据。
- 悖论写法易被读成"两面都对"，作者实际有明确取舍。
- 不能替代法条与司法解释检索。

## 金句
- "法益作为入罪的基础，但伦理作为出罪的依据。"
- "在入罪问题上应当注意刑法的补充性，在出罪问题则应该发挥刑法的独立性。"
