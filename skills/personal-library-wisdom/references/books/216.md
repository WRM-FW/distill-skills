# 《走过》 — 敬一丹

> 类型：文学 | 原文规模：约 11.1 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/216.md（6 段）

## 一句话
用一件旧物、一个节气、一段江岸，把"我经历过"写成别人也能查证的具体细节。

## R｜原文骨架
- 开篇三篇（我的地图、中山路记忆、假装在中年）→ 立坐标：地理来处、城市记忆、年龄自述。
- 行走与江河（长江源日记、墨脱、走川渝、运河、九公里）→ 把大地理拆成"走到哪、看见谁、花了多久"。
- 物与手艺（伞、一针一线的穿越、影的魅力、古灯、拼布）→ 用器物的用法讲日常史。
- 人与记忆（妈妈的海滩、寻找海子的痕迹、呼兰、那些校园）→ 以他人为镜写自己的来路。
- 节气与仪式（二月二赶大集、谷雨、七夕、登泰山）→ 给时间装刻度，让回忆有落点。

## I｜核心命题与可执行方法
**物作传记** —— 看什么：一把伞、一块拼布、一张航运发票 → 问：它经过谁的手，替谁解决了什么日常麻烦 → 会看到：大历史落在针脚、票价和补丁上。

**节气作刻度** —— 看什么：谷雨写水长城、写仓颉造字与"谷雨前，忙种棉" → 问：这个节气里人具体在做什么动作 → 会看到：自然时间与农事、文字绑在一起，季节变成可执行日程。

**年龄报数法** —— 看什么："我48了"之后接连写 60、69，反复问"是我一直假装在中年吗" → 问：她为什么用具体数字而不是"中年女性" → 会看到：用可核对的数字抵抗抽象的年龄焦虑。

**殿堂里的日常感** —— 看什么：拼布展第一眼是"东拼西凑" → 问：展览让人离物件更近还是更远 → 会看到：判断展陈的标准是"距离近不近"，不是级别高不高。

## A1｜书中实例
- 抽样3（凌晨三点，海边看戏）：阿那亚戏剧节，演员在观众身边穿梭，伽利略生平写在玻璃窗上，屏幕打出"你们需要的到底是真理，还是要造一个新的神"。
- 抽样5（一针一线的穿越）：她原以为拼布展第一眼是"华服""盛装"，结果主题是"东拼西凑"；由此想到母亲用绒布拼的棉背心、姑姑用碎花布拼的枕套。
- 抽样6（运河）：在中国运河博物馆看到河道管理职位表与航运发票，用"官名背后是管理制度"解释运河为何能长期运行。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写一篇关于地方或旧物的散文，缺结构与落点。
- 当用户做博物馆、展陈、城市文化文案，想找回"日常感"。
- 当用户在处理年龄、转岗、退休前后的自我叙述。
- 与《我以为这辈子完蛋了》（brosh-solutions）：敬一丹把痛感转成地点与物，布罗什把痛感画成笑话。
- 与《生命不息，折腾不止》（luo-yonghao-zheteng）：罗永浩的自述服务于说服，敬一丹的自述服务于保存。

## E｜执行步骤
1. 输入：一件家里的旧物 + 一个常去的地点。动作：写下它经手的三个人，以及每人用它做什么。
2. 动作：给它配一个时间刻度（节气、年份、某次活动），不用"小时候"这种模糊词。
3. 动作：找一个可查证的硬细节（票价、尺寸、馆名、歌词），至少一处。
4. 动作：把"我"退到第二段之后，先让物和人出场，再让自己的判断出场。
5. 产出：800 字短文；验收标准是读者能复述那件物的用法。

## B｜边界与误用
- 单篇多为栏目体与公号体，篇幅短，方法需自己提炼。
- 地名沿革、历史年代按散文处理。
- 基调温和，冲突面少；写争议性题材时这套笔法会显得回避。
- 抽样只覆盖若干单篇；未抽到的部分不宜下判断；引用馆长、解说词处注意观点归属。
