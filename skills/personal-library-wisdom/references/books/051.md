# 《老实人》 — 伏尔泰
> 类型：文学 | 原文规模：约 3.7 万字 | 抽样依据（工作档案 udigest/051.md（6 段）

## 一句话
用"每章一灾"的密度测试乐观主义：看解释怎样被灾难追上。

## R｜原文骨架
- 三十章，章名本身就是剧情摘要（"第一章 老实人在一座美丽的宫堡中怎样受教育，怎样被驱逐"）→ 先剧透，读者看的是"怎么发生"。
- 第一至第六章 → 一次驱逐、一次强征入伍、一次地震与一次功德大会；灾难以行政流程的样子出现。
- 第七至第十三章 → 居内贡与老婆子的身世插入，把个人灾难接进更大的历史账本。
- 第十四至第十八章 → 巴拉圭与黄金国：给"最好的世界"一个实物样本，再让它不可久留。
- 第十九至第二十三章 → 苏利南、海上、巴黎、英国，玛丁登场，问答体取代说教。
- 第二十四至第三十章 → 威尼斯、土耳其，众人重逢；抽样止于第二十八章前后，结局未覆盖。

## I｜核心命题与可执行方法
**灾难密度** —— 看每章死伤几人、隔多久出现一次重逢 → 问："这一章用什么理由解释刚发生的事？" → 会看到：乐观主义不是被论证驳倒的，是被频率拖垮的；解释还在，只是越来越赶不上。

**事后解释的检测** —— 看谁在灾难后提供因果链（邦葛罗斯的"充足理由"） → 问："这个解释能预测下一次吗？" → 会看到：能解释一切的解释不提供信息，只提供安慰；它越完备，越像替灾难发许可证。

**金钱流向** —— 看一笔钱在几个人手里停留、每次停留后发生什么 → 问："这笔钱在这里是通行证还是标记？" → 会看到：财富不改变命运，只改变下一次被抢的方式；钻石越多，遇到的人越坏。

**身体的计量** —— 看鞭数、伤处、美貌如何被数出来（三十棍、二十棍、十棍） → 问："谁在数？为什么数？" → 会看到：暴力被写成流程，数字递减反而成了"进步"的证据。

**问答体** —— 看老实人与玛丁的对话里谁提问、谁回避 → 问："这场对话让谁的立场移动了一寸？" → 会看到：玛丁从不给结论，只说"我不知道，除非我钻在你们肚里"；怀疑主义的功能是拆掉对方的秤，不是递上一杆新秤。

## A1｜书中实例
- 第二章：两个穿蓝衣服的人先请他吃饭、替他惠钞，随后"把老实人上了脚镣"；操练挨棍从三十减到二十再减到十，"弟兄们都认为他是天才"。
- 第九章：一夜之间他杀了以萨加和大法官，对居内贡的解释是"一个人动了爱情，起了妒性，被异教裁判所打了屁股，竟变得连自己也认不得了"。
- 第十九章：他在苏利南招募旅伴，条件是"本省遭遇最苦，最怨恨自己的行业的人"，最后选中学者玛丁，因为"世界上没有一个职业比他的更可厌"。

## A2｜何时调用 / 与相邻书的区分
- 当用户想用讽刺处理一个"一切都会好起来"的说法时。
- 当用户需要检测"能解释一切的理论"时。
- 当用户写短篇，想让节奏靠事件密度而非描写推进时。
- 当用户想分析财富如何改写人际关系时。
- 与《查第格》同为哲理小说：查第格用考验测"德行有没有用"，老实人用密度测"解释能撑多久"；前者是实验设计，后者是压力测试。
- 与《1984》都让语言参与统治：伏尔泰看漂亮话如何替暴力开脱，奥威尔看新话如何让反抗无法成形。

## E｜执行步骤
1. 选一个"一切都是最好的安排"式说法 → 配三个反例，要求来自同一周内不同领域（工作、身体、公共事件）。
2. 写一章 500 字讽刺：让主角遭一次灾，再让一位智者给出完整解释 → 删掉解释的最后一句，看是否更冷。
3. 给一笔钱做流向表：经过几个人、每站损失多少 → 用这张表替换一段心理描写。
4. 验收：读者能复述事件顺序，却说不出作者的观点。

## B｜边界与误用
- 十八世纪的"乐观主义"指莱布尼茨式的"最好世界"论，不是今天的积极心态；拿它批评"正能量"会错位。
- 书中对犹太人、耶稣会士、女性的写法带强烈时代偏见，是攻击武器而非描写，引用须标明。
- 黄金国是思想实验，不是政治方案；当乌托邦蓝图读会读反。
- 抽样未覆盖第三十章结局，常见的"种园地"式结论不能据抽样引申。
