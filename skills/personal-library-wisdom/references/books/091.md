# 《丰乳肥臀》 — 莫言
> 类型：文学 | 原文规模：约 29.3 万字 | 抽样依据（工作档案 udigest/091.md（6 段）

## 一句话
以一个母亲的身体作账本，把五十年的战争、土改与饥荒记成一本生育账。

## R｜原文骨架
- 新版自序／主要人物表 → 先给谱系：八女一子，读者须对照人物表读，否则分不清谁嫁了哪一派。
- 第 3—7 章（第一—四十五节）→ 按年代推进：抗战、日占、国共、土改、饥荒、运动。
- 第 8 章（第四十六—五十一节）→ 收束到上官金童的当代生活与母亲之死。
- 主要叙述者为上官金童：恋乳、懦弱、判断力差，部分章节转由他人承担视角。
- 结构等式：一个母亲的生育史＝一部地方政治史，页码走的是年份，不是因果。

## I｜核心命题与可执行方法
**身体的账本** —— 看每一次危机里谁的身体被拿去换东西 → 问："这一页上，谁在支付？" → 会看到：卖七妹的钱付店钱与药费；母亲的乳汁是全家唯一的流通物；女儿们分别嫁给各派势力，婚姻即结盟。

**人畜同词** —— 看写牲畜时用了哪些亲属称谓 → 问："把人话套在驴身上，说明这个家认什么作自己人？" → 会看到：樊三给驴接生，上官吕氏说"种马是你的儿，这驴就是你的儿媳妇，肚里的小骡，就是你孙子"。在这个家里，能生育的才算亲眷。

**饥饿的计量** —— 看食物以什么单位出现（碗、把、个、斤） → 问："谁分到多少，谁没分到？" → 会看到：包子、乳汁、豆饼；分配单位越细，说明短缺越狠。母亲的病中呓语把神灵与亲人混在一处，是饥饿之后的意识流。

**暴力的礼数** —— 看施暴前后有没有客套话与口号 → 问："他们用什么说法把暴力说成应该的？" → 会看到：裹脚时"紧是爱你，松是害你"；土改口号"打死一个富农，胜过打死一只野兔"；杀人之前先开大会、先喊话。

**临刑的体面** —— 看死囚在最后几小时要求什么 → 问："他争的是命，还是身份？" → 会看到：司马库只要求把刮了一半的胡子刮完，女公安说"那样你就不是司马库了"。体面是最后一笔可支配的财产。

## A1｜书中实例
- 抽样第 1 段：樊三来给难产的驴灌药，先讲价钱"两壶好酒一个肥猪头"，上官吕氏拍板"这个家，我做主"，并把种马、母驴、小骡认成"驴马亲家"。
- 抽样第 2 段：母亲在客店病倒，四姐掏出"卖俺七妹的钱"请医生；"花光了七姐换来的粉红钞票，母亲睁开了眼"，随后店主又来讨十几天的店钱饭钱。
- 抽样第 6 段：璇儿被大姑姑裹脚，"用竹片把母亲的脚夹起来"，痛得用头撞墙，大姑姑说"紧是爱你，松是害你"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写一个家族跨越数十年的兴衰，需要一条不靠年表的线索时。
- 当用户想让身体、生育承担结构功能而非装饰时。
- 当用户处理亲人之间的暴力，要写出"以爱为名"的话术时。
- 当用户要写多股势力在一个村庄里轮替、村民如何应对时。
- 与《蛙》都写生育：一个从接生婆的政策之手写，一个从母亲的肚子写。
- 与《生死疲劳》都写高密东北乡五十年：一个用六道轮回，一个用八女一子的谱系。

## E｜执行步骤
1. 画谱系图：把人物表按"嫁给谁／属于哪派／怎么死"三列填满 → 看政治站队怎样写进亲属关系。
2. 统计前一百页里"吃"与"生"的动词各出现几次 → 找出两者的替换关系。
3. 选一场暴力，删去所有口号与客套话 → 比较剩下的部分还能不能被合理化。
4. 改写练习：用"母亲的账本"重写同一段三百字，只记收支，不写心理 → 验收：每一笔能否对应到一个人。
5. 检查：你的叙述者是否比上官金童更可靠；若没有，说明你也选了一个"看不清"的位置。

## B｜边界与误用
- 书名与大量乳房、乳汁描写常被当猎奇；它承担的是短缺经济的计量功能，抽掉这一层就会读成色情。
- 叙述者恋乳、懦弱、判断差，全书的价值判断不可直接等同于作者。
- 八女一子的设置高度象征化，人物易沦为"各方势力"的标签，细读须分辨哪个女儿有独立意志。
- 暴力与性场面密集，不适合作青少年读物或公开朗读材料。
