# 《东野圭吾作品集（共69册）》 — 东野圭吾
> 类型：合集 | 原文规模：约 597.7 万字 | 抽样依据（工作档案 udigest/215.md（6 段，分属不同作品）

## 一句话
一套可拆用的推理工具箱：诡计清单、物证考古、技术伦理、记忆不可靠，各有各的用法。

## R｜原文骨架
- 伽利略系列短篇（抽样2，草薙与间宫）→ 从一处不属于现场的细节反推整段供述，供"物证优先于口供"的流程。
- 《名侦探的守则》（章节表：密室宣言／意外的凶手／不在场证明宣言……）→ 把本格诡计逐条做成"宣言—反例"的清单，供识别类型套路。
- 《从前我死去的家》（抽样4）→ 靠旧日记、门票存根、墙上字迹重建一户人家的往事，供"物证考古"。
- 《沉睡的人鱼之家》（抽样6，和昌与 BRS）→ 用医疗器械把"死亡判定"变成家庭决策，供"能做≠该做"的追问。
- 《濒死之眼》（抽样5，雨村慎介）→ 失踪与记忆错位，供"叙述者记忆可信度"的检查。
- 《平行世界爱情故事》（抽样3，Vitec 与赴美）→ 两条人生并行，供"选择的代价由谁承担"的对照。

## I｜核心命题与可执行方法
**动机的倒装** —— 看故事先给凶手还是先给动机 → 问"这个人从这起死亡里得到了什么样的日常秩序？" → 会看到动机常不是创伤，而是"维持某种生活安排"的算术。

**技术的合规缺口** —— 看一项技术被介绍时，谁问"能不能"、谁问"该不该" → 问"没有禁止，是否等于允许？" → 会看到星野答"我并没有确认这件事，但我想应该没有"，董事长随即打电话——空白被当成许可。

**细节的偏执** —— 看一个细节被摩挲几次 → 问"这个细节为什么不属于这个场景？" → 会看到草薙揪住"她没有穿和服"：和服会遮住脚，烟叶就贴不上去。

**类型自反** —— 看角色何时自己点破本格套路（密室、不在场证明、童谣杀人逐条被念出来） → 问"揭穿套路之后，故事还剩什么？" → 会看到守则系列用清单换悬念，读者从"猜凶手"转为"数招"。

**家庭的账本** —— 看亲人之间怎么算照护成本 → 问"这份爱是以谁出力、谁出钱的形式出现的？" → 会看到照护、遗产、手术同意书，都是情感的记账方式。

## A1｜书中实例
- 伽利略系列：相本美香在店里穿和服，离开前才换衣服，草薙由此判断"如果她穿的是和服，那两只脚应该是被遮住的"，脚上的烟叶只能来自挣扎时掉了鞋的现场。
- 《沉睡的人鱼之家》：和昌追问植物状态病人能否装 BRS，星野先说"我并没有确认这件事，但我想应该没有"，被追问后承认"也许也能够用于昏睡状态的病人身上"。
- 《从前我死去的家》：叙述者从佑介日记里"小美"的几条记录推出——"佑介从来没说小美是一只猫，那只是我们一厢情愿的认定而已"。

## A2｜何时调用 / 与相邻书的区分
- 要设计或检验密室、不在场证明、童谣杀人等诡计时。
- 要判断一个"技术可行但伦理存疑"的案例时。
- 要写家庭内部的照护与遗产分配时。
- 与《解忧杂货店》（同作者）都用巧合结构：那本把巧合用在安慰上，本集把巧合用在拆解上。
- 与《月亮与六便士》同写"越界者"：毛姆让他被原谅，东野让他被解释。

## E｜执行步骤
1. 选一个诡计 → 写下它依赖的三条物理事实（衣物、时刻、路径），再逐条找反证。
2. 把一个现场细节标为"不属于这里" → 倒推它何时、以什么方式进去，验收：能排除至少两个嫌疑人。
3. 给一项新技术列"能／不能／没规定"三栏 → 找出被当成"能"的那一格空白。
4. 让叙述者回忆一件事，再让物证否定它 → 验收：读者能指出他撒谎的动机，而不只是撒谎。

## B｜边界与误用
- 六十九册体量，抽样六段只覆盖四五部作品，不能代表全集（早期本格、后期社会派、幽默短篇差异极大）。
- 作品中人物跨书复用（草薙、汤川、加贺），引用时须标系列，否则会张冠李戴。
- 对女性与风俗业的描写常落回刻板印象，做文本分析时应指出而非沿用。
- 抽样1所属作品未能确认，涉及该段时不要臆断书名。
