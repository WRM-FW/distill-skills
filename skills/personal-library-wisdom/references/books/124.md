# 《夜谭十记》 — 马识途
> 类型：文学 | 原文规模：约 16.2 万字 | 抽样依据（工作档案 udigest/124.md（6 段）

## 一句话
十个县衙门小科员轮流摆龙门阵，把官、钱、亲、名四样东西的兑换率摆出来。

## R｜原文骨架
- 框架：十个穷科员结成"冷板凳会"，各取雅号（如"无是楼主""羌江钓徒"），轮流讲旧事，众人追问。
- 开篇一记：新生活视察将至，县太爷临时拉人充科长——一个只会打牌喊"碰"，一个鸦片烟鬼，靠师爷扶着"走上岗位"。
- 张牧之一记：山大王劫走官银，识破"省上钱庄开的票"，逼师爷供出买官与钱庄囤积委任状的内幕（电影《让子弹飞》所本）。
- 干亲一记：女工张小倩被总经理认作干女儿，洋货、螃蟹、甜葡萄酒，一步步走到"用不着我来描写"的那一夜。
- 羌江钓徒一记：吴永洁守寡、砸贞节牌坊未果，末了吃斋念佛；听众追问故事里"姓吴的青年"是谁，他不答。
- 第七记"无是楼主：亲仇记"讲拈阄与复仇；另有一记写佃农王子章攒钱买牛。

## I｜核心命题与可执行方法
**龙门阵框架透镜** —— 看每个故事是谁讲的、他为什么此刻讲 → 问"这故事对他有什么好处、他隐瞒了哪一段" → 会看到框架本身就是官场生态：人人借别人的事说自己。

**委任状透镜** —— 看一个职位怎样被买卖 → 问"这位置值多少钱、钱从哪来、几个月回本" → 会看到权力作为生意的现金流模型，比"腐败"二字精确得多。

**干亲透镜** —— 看一份无缘无故的好意 → 问"这好意折价多少、将来要还什么、还得起吗" → 会看到恩惠即预付款：送得越多，拒绝空间越小。

**牌坊透镜** —— 看一座道德建筑谁出钱立、立给谁看、拆时谁拦 → 问"维护成本由谁承担、收益归谁" → 会看到贞节不是观念，是有预算、有工期的工程。

**钱盒透镜** —— 看底层积累怎样被计时 → 问"他每年存多少、目标价多少、什么会让他清零" → 会看到"今年不行，还有明年"的韧性，也看到一场旱就能把积累变成欠租借约。

## A1｜书中实例
- 张牧之劫官银：师爷以为山大王"目不识丁"，谎称银票是"省上钱庄开的票"；张牧之大笑："你们就是凭这张纸到我们县里来取钱的吧？"再问"啥子人都可以去买官做吗"，会计主任答"只要你有钱"。
- 张小倩：父亲是工人，不准女儿拿礼物回家，也不准妻子去公馆，"你要去跨那家公馆的门槛，我打断你的贱腿"；中秋夜干爸干妈劝酒，两盅甜葡萄酒下肚便天旋地转。
- 王子章买牛：每天端出积蓄数，"好似钱会生儿育女"，数完叹气"还差好长一截哩"，又打气"今年不行，还有明年"；来年遇上"掐脖子旱"，收的大半是空壳。

## A2｜何时调用 / 与相邻书的区分
- 当用户要拆解"人情—利益"交换链，看清谁先付、谁后还时。
- 当用户写民国县域官场，需要具体的衙门日常与口语时。
- 当用户分析资助、提携关系里的权力不对等时。
- 与《猫城记》同写官场溃败，区别在：老舍用寓言把机制放大到灭国，马识途用账目、票据和酒席把它摁在县衙门地上。

## E｜执行步骤
1. 输入一桩你听来的"内部故事"。动作：先写清讲述者身份、讲给谁听、讲完得到什么反应。产出：不少于 100 字的框架文字。
2. 动作：把每笔钱标出来——谁给、多少、什么名义、有无凭据。验收：能算出"回本周期"或"人情余额"。
3. 动作：找出一个"好意"场景，写下接受方无法拒绝的原因（住处、工作、家人）。
4. 产出：800 字故事，由故事里的人自己讲，叙述者只在结尾问一句。

## B｜边界与误用
- 各记水准不齐，结构重复"听闻奇事—众人惊叹"；最易被误用为"民国官场黑幕"猎奇集，只记住买官和姨太太，漏掉对佃农、矿工、女工的算计。
- 女性多为被损害者或祸水，叙述视角明显男性化，引用其"道德批判"时须打折。
