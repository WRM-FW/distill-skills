# 《动物凶猛》 — 王朔
> 类型：合集 | 原文规模：约 10.8 万字 | 抽样依据（工作档案 udigest/126.md（6 段）

## 一句话
三篇北京话样本，练一双耳朵：听出谁在吹、谁在怕、谁在替自己圆场。

## R｜原文骨架
- 动物凶猛 → 部队大院少年的一个夏天：翻墙、打架、追女孩；由中年叙述者回述，记忆本身不可靠。
- 一点儿正经没有 → 写作圈酒桌上的连环侃，把"正经"当包袱抖，谁认真谁输。
- 你不是一个俗人 → "3T公司"替人吹捧的营业，把恭维做成明码标价的服务。
- 三篇共用一个装置：一群靠嘴活着的人，用语言代替行动、代替钱、代替道歉。
- 抽样后四段人物重叠（于观、马青、杨重、丁小鲁），两篇的篇界未在素材中标明。

## I｜核心命题与可执行方法
- **记忆的美化率** —— 看叙述者给自己加的光 → 问"这段是谁在讲，他要我相信什么" → 会看到"在我的回忆中她的这一形象最鲜明"式的自我授权：越强调清晰，越可能在补写。
- **圈子的准入证** —— 看谁被落下 → 问"这群人靠什么排座次" → 会看到消息、胆量、拳头和"在场"才是货币，义气只是结算方式。
- **承诺的兑现率** —— 看酒桌上的大话 → 问"这句话最后由谁付账" → 会看到完整话术：先许好处，再拖，再换话题——"光棍闯天下，空手套白狼"。
- **公文的移植** —— 看 3T 公司开会 → 问"这段官话原本属于哪个场合" → 会看到"总的来说是不错的。是有成绩的"被搬进客厅，讽刺靠腔调错位，不靠笑话。
- **观看的权力** —— 看女性如何被描述（"长着狐狸脸"、被逐楼呼喊） → 问"谁有资格看，谁只能被看" → 会看到欲望被写成集体行动，被看的人没有台词。

## A1｜书中实例
- 食堂里朋友们围打一个战士，其他人"怯懦地手拿饭勺子站在一边"；叙述者慢慢咽下最后几粒米走出去，院里大人连他一起怒视。见抽样1。
- 高晋醉酒骑车穿城，从第一幢楼开始一幢幢喊米兰的名字，"响亮、嘶哑"，整片楼区的居民被惊醒，有人一个月后还心有余悸。见抽样2。
- 于观主持"营业会议"，先表扬马青"下了班后仍然坚持捧人"，再转折点名批杨重"数你怪话多"，众人窃笑。见抽样6。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写"嘴贫"的对话、需要京味语感时。
- 当用户分析吹捧、人情、圈子如何运作时。
- 当用户处理不可靠叙述、青春回忆的美化时。
- 当用户要给荒诞场面配一副正经腔调时。
- 与《起初》同出王朔：这本让 1970 年代大院少年说话，那本把这套语感装进汉代宫廷；同问"人怎么用嘴活着"，不同在史料约束。

## E｜执行步骤
1. 输入一段三人以上对话。动作：删掉所有形容词与副词，只留动词、称呼、语气词。验收：仍能分辨谁在抢话。
2. 动作：给每人写一句"他真正想要但不会说出口的话"，不写进正文。产出：人物动机卡。
3. 动作：把其中一人的台词改成公文腔，看场面是否立刻变滑稽。验收：滑稽来自腔调，不来自内容。
4. 动作：删掉叙述者的解释句，只留动作。验收：读者仍知道这一局谁输了。

## B｜边界与误用
- 男性视角极强，女性多为欲望客体；直接模仿会连视角一起复制。
- 大院生活的时间地点很具体，脱离语境搬用只剩油滑。
- 贫嘴可学，判断难学：人物说的俏皮话常常是错的，别把台词当作者观点。
- 后两篇人物重叠，逐段归属需回原文核对；本卡只保证"这三篇共有这套话术"。
