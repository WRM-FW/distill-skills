# 《世界文学名著合辑（套装六十册）》 — 许渊冲等译
> 类型：合集 | 原文规模：约 892.2 万字 | 抽样依据（工作档案 udigest/224.md（6 段）

## 一句话
六十册合辑：把六类小说的常用叙事装置按册拆开，随取随用。

## R｜原文骨架
- 总目录 → 按书名平铺，不分国别年代；定位靠「总目录 → 书名 → 章」，部分册前附译序（如《飘》的作者小传）。
- 社会长篇（傲慢与偏见、基督山伯爵、红与黑、悲惨世界、包法利夫人等）→ 阶层、婚姻、复仇、审判的情节模型。
- 少年漫游（绿山墙的安妮、苦儿流浪记、海蒂、小飞侠、尼尔斯骑鹅旅行记）→ 儿童视角、离题对话、路程推进。
- 科学冒险（海底两万里、八十天环游地球、神秘岛）→ 用清单、里程、物资表撑住悬念。
- 传记随笔（名人传、居里夫人自传、人类的故事、培根随笔集）→ 人物小传当叙事材料。
- 俄美长篇（复活、童年·在人间·我的大学、钢铁是怎样炼成的、飘、老人与海）→ 苦难、战争与长时段。

## I｜核心命题与可执行方法
**验尸流程**（基督山伯爵）—— 看法里亚死后逐道手续：请医生、典狱长坚持依法、烧烙铁 → 问“谁在执行最后一道确认” → 复仇的时间表由官僚程序推动，死亡是流程不是场面。

**手的越界**（红与黑）—— 看于连抓手、她“略一思索”、他换燕尾服后“莽莽撞撞” → 问“这动作在对方眼里是什么” → 阶层试探先落在身体上，再由三十六法郎和衣着定价。

**离题即性格**（绿山墙的安妮）—— 看安妮从“两点”跳到野餐、再跳到“马修就是爱听我说” → 问“她被什么带走、玛丽拉用什么拉回” → 用跑题写儿童，用“你得学会抵制”写爱的制度面。

**前言即证词**（飘）—— 看译序里的米切尔小传：母亲指着种植园断壁训话、未婚夫战死、周薪二十五美元写稿 → 问“它替小说预设了什么” → “战后从头再来”被写成写作起点。

**路线的赌注**（苦儿流浪记）—— 看塞纳河与马恩河之间的取舍、五个星期、两个月前的目击 → 问“凭什么改道” → 希望不是情绪，是能被证词修正的路线。

**误会的链条**（约翰·克里斯托夫）—— 看苏兹接站失败的每一环：电报、四等车、莎乐美买菜、邻居传话 → 问“哪一环少了一句” → 冲突由信息缺口堆成，再由樱桃树与乌鸦哨音消掉。

## A1｜书中实例
- 基督山伯爵·验尸：唐代斯在墙洞后偷听，“烧红烙铁”的命令让他打了个寒战，接着是火燎皮肉的吱啦声；医生用烧脚跟证明死亡，典狱长守的是职责。
- 红与黑·入职：瑞那先生给于连第一个月三十六法郎，明令“一个子儿都不能给你父亲”，再让他换上自己的燕尾服。
- 绿山墙的安妮·野餐：安妮迟到四十五分钟，理由是“迷人的‘悠闲的原野’”，还说“马修就是爱听我说”；玛丽拉训完仍给她烤一篮子吃的。

## A2｜何时调用 / 与相邻书的区分
- 当用户要按主题挑一册读、需知道这六十册各提供什么写法时。
- 当用户比较同类情节（复仇、越界、误会）在不同国别小说里的处理时。
- 当用户拿到译序，想判断它在替正文预设什么时。
- 与《基督山伯爵》单册卡同看复仇：单册卡给完整结构，本卡只取“程序推进”这一件。

## E｜执行步骤
1. 输入一个问题（如“怎么写一次告密”）→ 在总目录挑两册不同国别的书 → 产出对照清单 → 验收：各有一条可复用装置。
2. 输入一段情节 → 标出靠什么推进（手续、路程、误会、离题）→ 产出装置标签 → 验收：换成另一册同类装置仍站得住。
3. 输入一册译序 → 划出它为正文设定的期待 → 产出预设表 → 验收：能指出哪一句在替读者定性。
4. 写作训练：用“手续”写一场死亡，不写悲伤 → 验收：读者能从流程里读出恐惧。

## B｜边界与误用
- 书名标称六十册，总目录实际列出五十四个书名（格林童话重复一次），分册与足本情况不明；译本、体例也不统一。
- 抽样第 4 段是《飘》的作者小传（译序），不是小说正文，不能当米切尔原文引用。
- 单册卡能解决的问题不必用本卡；本卡只适合跨册取材与编选判断。
- 十九世纪作品的性别与殖民视角原样保留，直接当行为指南会出事。
