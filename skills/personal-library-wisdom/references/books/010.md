# 《局外人》 — 阿尔贝·加缪
> 类型：文学 | 原文规模：约 19.6 万字 | 抽样依据（工作档案 udigest/010.md（12 段，含法语原文 4 段）

## 一句话
把“没按场合哭”当罪证来审，看社会如何用情感规范给人定罪。

## R｜原文骨架
- 第一部 → 母亲下葬、守灵、海滩、枪响；用极短句记录身体，不给心理注释。
- 第二部 → 预审、公审、监狱、与神甫冲突；把"没哭"一步步变成量刑依据。
- 金祎译本后记/导读 → 提出"双重真相"，以萨拉玛诺与老狗作反例。
- 秦三澍译本另收美国版自序、诺奖致辞、加缪年表与长导言 → 提供作者自述与接受脉络。

## I｜核心命题与可执行方法
**情绪举证** —— 看审判里哪些"事实"其实是情感解读 → 问："去掉情绪词，这条指控还剩什么行为？" → 会看到：真正被审的不是杀人，而是他有没有按规定悲伤。

**感官先行** —— 看热、光、气味、咖啡如何占满叙述 → 问："这一刻他身体在承受什么？" → 会看到：所谓冷漠常是感官过载，叙述只报身体不报意义。

**句子平权** —— 看母亲去世与喝咖啡是否用同样短的句子 → 问："作者为什么拒绝给大事加重量？" → 会看到：价值等级不在句法里，这是"荒诞"的形式证据。

**剧本检查** —— 看每个场合要求他提供哪种情绪 → 问："谁有资格规定这里该怎么反应？" → 会看到：守灵、庭审、宗教安慰都在等他念台词，他的罪是不肯念。

**当下/过去切分** —— 看人物活在哪个时态 → 问："他是在经验当下，还是在给过去补解释？" → 会看到：萨拉玛诺守着老狗的记忆而丢掉当下，默尔索最后在星空下回到当下。

## A1｜书中实例
- 守灵夜（第一部）：灯"要么全开，要么全关"，他喝牛奶咖啡、想抽烟、打了个瞌睡；母亲的朋友们进来"悄无声息"，他"听不见他们的声音"，却把每个细节看得清清楚楚。
- 预审（第二部）：法官问"您爱不爱妈妈"，他答"爱，和所有人一样"；法官举起银十字架，他只觉得太热，跟不上对方"灵魂是空的"那套推理。
- 公审（第二部）：检察官指出他在母亲下葬次日游泳、谈恋爱、看费南代尔的喜剧"开怀大笑"；玛丽当场大哭，被执达员拖出法庭。

## A2｜何时调用 / 与相邻书的区分
- 当用户想分析某场审判或舆论事件里"被告真正因什么被定罪"时。
- 当用户写第一人称小说，想用短句制造疏离感时。
- 当用户想区分"我难受"与"我知道我该难受"时。
- 与《加缪手记》同源：手记是原料与草稿（"老头和他的狗。八年的恨"），本书是压缩后的成品。分析创作过程用手记，做文本细读用本书。

## E｜执行步骤
1. 选一段庭审记录或网络声讨 → 划出所有情绪词 → 换成中性描述 → 比较剩下的行为指控。
2. 取任一场景 → 只摘感官词（光、热、气味、声音）→ 看能否还原人物状态而不引心理词。
3. 写 300 字同场景，模仿"短句＋并列"，禁用"感到""觉得" → 验收：读者说得出身体状态，说不出价值判断。
4. 分层标注：小说正文／译者后记／导言，三者的断言分开引用。

## B｜边界与误用
- 不是"冷漠人格"的辩护书；拿它当不去处理关系的挡箭牌，是典型误用。
- 法庭程序是文学装置，不等于法国刑诉实录。
- 金祎译本末尾的"双重真相"属后记/导读的阐释，不是小说原文，引用须标明。
- 秦三澍译本抽样含大量法语原文，中法对照时别把法语句法当成译文风格。
