# 《蛇结》 — 弗朗索瓦·莫里亚克
> 类型：文学 | 原文规模：约 6.2 万字 | 抽样依据（工作档案 udigest/180.md（6 段）

## 一句话
让一个满心怨恨的老律师自己开口，教你从自辩里读出他隐瞒的事。

## R｜原文骨架
- 主体是一份第一人称手稿：波尔多律师路易写给妻子伊莎的控诉书，准备死后让家人读到。
- 抽样所见章节以数字编号（10—20），中间插入书简体："于贝尔写给热娜维耶芙的信""雅妮娜写给于贝尔的信"——视角在家内换手。
- 内容按"控诉—回忆—窃听—清算"循环：出身与母亲／伊莎的坦白／玛丽奈特的出现／子女夜间算遗产／邮局取信与餐馆独白。

## I｜核心命题与可执行方法
**遗书的读者位置** —— 看叙述者假定谁在读 → 问"这段话是说给活人听，还是说给将来的人听？" → 会看到全书是一份预备被后代翻出来的自辩，读者的位置被预先写进文本，所以每句"实话"都带表演。

**财产的语法** —— 看每次提到钱、地、股权时的措辞 → 问"这一句是在记账，还是在记恨？" → 会看到两千公顷森林、卡莱斯葡萄园、苏伊士股权——爱被换算成产权，恨被换算成遗嘱条款。

**窃听的伦理** —— 看叙述者怎么获得信息 → 问"这是听见的，还是他推出来的？" → 会看到他把蜡烛放在地上、贴着门缝听子女算账，连老太太"细弱而急促"的呼吸都记录——亲密靠偷听建立。

**比喻的自证** —— 看他的比喻从哪来 → 问"这个比喻替他免掉了什么责任？" → 会看到"我们二人就像掉入陷阱的狐狸"，借伊索寓言把婚姻写成互骗的陷阱，同时把自己写成断尾的受害者。

**恨的归类癖** —— 看他把谁写进同一类 → 问"他凭什么把这些人并列？" → 会看到妻子、子女、犹太商人、啃面包的泥瓦工被编进同一条"贪婪"链——这是不可靠叙述者的证词，不是作者的判断。

## A1｜书中实例
- 回忆部分：母亲是"小公务员的遗孀"，他"二十一岁的时候，我突然坐拥了两千公顷葱郁的森林"，卡莱斯葡萄园"如今就算出价一百万，我也不会卖掉"。
- 窃听部分：孩子们在楼下压低声音算母亲的嫁妆与苏伊士股权，他躺在盥洗室地板上听；老太太上楼探他是否睡着，"她喷洒出的呼吸细弱而急促"，他担心露馅。
- 餐馆部分：他看泥瓦工啃面包，想起自己辩护的第一个案子——几个孩子不愿赡养父亲，老人"每三个月就要换地方住"。

## A2｜何时调用 / 与相邻书的区分
- 要写不可靠的第一人称、让读者自己判断时。
- 要处理遗产、分家、赡养这类家庭财产冲突中的情感语言时。
- 要练习"越自辩越暴露"的写法时。
- 与《安娜·卡列尼娜》同写婚姻牢笼：托尔斯泰给双方身体与场合，莫里亚克只给一个人的嗓子。
- 与《月亮与六便士》同用第一人称：毛姆的"我"是旁观者，这里的"我"是当事人兼原告。

## E｜执行步骤
1. 让主角写一封不打算寄出的信 → 开头先声明"我不是为了辩解"，然后列三条他受的委屈。
2. 每写一条委屈，配一条他做过的、性质相同的事 → 不评论，只并列。
3. 安排一次偷听，让他听到关于自己的评价 → 只记录他的生理反应，不记录他的反驳。
4. 结尾让他修改遗嘱 → 验收：读者能同时说出"他可怜"和"他可怕"，且都举得出证据。

## B｜边界与误用
- 叙述者充满恶意且自辩，书里没有中立裁判；照抄他的判断会把小说读成控诉书。
- 天主教外省资产阶级的背景（嫁妆、教规、名誉、德雷福斯事件）需注释，否则会误读动机。
- 对女性的写法带时代偏见：伊莎几乎只有沉默，玛丽奈特被写成半大孩子。
- 中译本正文夹大量译注，引用时须区分原文与注文。
