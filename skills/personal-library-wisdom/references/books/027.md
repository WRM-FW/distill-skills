# 《喧哗与躁动》 — 威廉·福克纳（李译本）
> 类型：文学 | 原文规模：约 14.4 万字 | 抽样依据（工作档案 udigest/027.md（6 段）

## 一句话
用四个人的记忆错位，把同一桩家事拆成四本对不上的账。

## R｜原文骨架
- 1928年4月7日（班吉）→ 以气味与声音为线索，时间随感官跳转。
- 1910年6月2日（昆丁）→ 哈佛最后一天，荣誉与乱伦执念，句子失控。
- 1928年4月6日（杰生）→ 怨恨与算计的第一人称，句子长而黏。
- 1928年4月8日（迪尔西）→ 厨房与复活节，给前三个视角一个外部支点。
- 附录《康普生家：1699—1945》→ 把散落的事实排成编年，相当于一份事后索引。

## I｜核心命题与可执行方法
**感官换轨** —— 看班吉段落里句子什么时候跳时间 → 问："是哪个气味或声音把它接上的？" → 会看到：时间按感官走，不按年代走，读者被迫用身体定位。

**名字缺失** —— 看谁只有称呼没有名字 → 问："这个叙述者能区分人和物吗？" → 会看到：身份靠重复的动作与气味辨认，"同一个人"要靠读者自己合并。

**多重账本** —— 看同一件事在四个日期里各被记成什么 → 问："谁的版本少了哪一段，为什么少？" → 会看到：真相在差额里，不在任何一个版本里。

**句式即生存策略** —— 看每个人的句长与标点 → 问："这个人的句子为什么停不下来，或断得这么碎？" → 会看到：昆丁被记忆拖着走，杰生被怨气推着走，句法就是他们的活法。

**附录反读** —— 看附录补了正文哪里没说的 → 问："哪些事实要靠附录才成立？" → 会看到：读者先感到、后确认；附录是给感受补日期。

## A1｜书中实例
- 班吉段（1928年4月7日）：凯蒂"用两只胳膊搂着我，把她那张发亮的冻脸贴在我的脸颊上。她有一股树的香味"，紧接着就切到勒斯特的抱怨——换轨靠一个气味完成。
- 昆丁段（1910年6月2日）："于是水沿着蹲在沟里的背脊一点点往上升……"整段几乎无标点，意大利小女孩与妹妹的记忆叠在同一条句子里。
- 附录：杰生三世卖地，一半为"凯丹斯在1910年四月里体体面面地举行婚礼"，一半为"昆丁能在哈佛完成一年的学业，然后，在当年的6月，结束自己的生命"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要处理"同一件事，几个当事人说法对不上"的材料时。
- 当用户写多视角小说，需要让视角差异落在句法而不只是内容上时。
- 当用户想理解"为什么家里那件事，每个人记得的都不一样"时。
- 与《麦克白》同看家族荣誉：麦克白写决定的那一夜，本书写决定之后三十年的回声。与《局外人》同是不可靠第一人称，但一个极简、一个极繁。
## E｜执行步骤
1. 取一个家庭事件，让三个人各写 200 字 → 禁止评价，只写看到、听到、闻到。
2. 三份并排，标出事实、遗漏、解释 → 产出"差额表"。
3. 选一人，改写其句长与标点以匹配其状态 → 验收：遮住内容，也能认出是谁在说。
4. 最后补一份编年附录，只写日期与事实，不写因果。

## B｜边界与误用
- 中译难以承载原文用拼写错误标记班吉智力的手法，别把译本的标点当成原文标点。
- 第一遍读不懂是设计的一部分，但"读不懂"本身不构成深刻。
- 迪尔西既是道德支点，也是"忠诚仆人"的套话，这双重性应指出而非照单全收。
- 附录是后加的，引用时与小说正文分开。
