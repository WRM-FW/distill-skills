# 《骆驼祥子》 — 老舍
> 类型：文学 | 原文规模：约 8.6 万字 | 抽样依据（工作档案 udigest/089.md（6 段）

## 一句话
用一辆车的买与丢，算清一个人的力气怎样被折算成车份儿。

## R｜原文骨架
- 全书二十四章；素材只保留了第二十一至二十四章的标题，正文抽样六段分别落在买车、虎妞夜候、茶馆老车夫、虎妞与刘四摊牌、暴雨拉车、向曹先生讲述六个场面。
- 这六个场面通常被读作一条下坠线的不同刻度：挣到车、被关系缠住、看见同行的晚年、与东家决裂、身体被天气榨干、最后只剩讲述。
- 具体章序素材未标注，引用章号须谨慎；卡片按场面的先后关系使用。
- 结构特征：第三人称全知，叙述者随时可以跳出故事下判断，这一点决定了全书的宿命感。

## I｜核心命题与可执行方法
**一辆车的会计学** —— 看每一次钱以什么名义出现（车份儿、保单、包月、借贷） → 问："这笔钱买的是物，还是他的身份？" → 会看到：九十六元买下车，他把这天当生日，"简直没什么不可以把人与车算在一块的地方"。车是他唯一能把自己记成"有产者"的凭证。

**身体的折旧率** —— 看谁在替谁预演晚年 → 问："这个人的今天，是谁的明天？" → 会看到：茶馆里五十五岁的老车夫饿晕，中年车夫说"拉包月就是凑合事，一年是一年的事，腿知道"。车夫的行业知识，就是知道自己几年后报废。

**天气即计价** —— 看恶劣天气里主客各做什么动作 → 问："这场雨对谁是风景，对谁是成本？" → 会看到：暴雨里祥子"不能抬头，不能睁眼"，坐车的"仿佛死在了车上"，一开口就是"快走！你把我扔在这儿算怎回事？"天气不是象征，是劳动条件与付钱关系的显影。

**虎妞的谈判术** —— 看底层女性怎样用亲缘词做交易 → 问："她手里有什么筹码，她把它说成了什么？" → 会看到：她当众说"咱们俩的事，一条绳拴着两蚂蚱"，转头向父亲要"你给我多少钱"；用"我已经有了"把生米煮成熟饭，用"我帮你这些年了"把劳动折成股份。

**叙述者的判决** —— 看叙述者何时跳出故事下结论 → 问："这句话，祥子自己能说出来吗？" → 会看到："希望多半落空，祥子的也非例外。"叙述者替他提供了历史感，也提前取消了他的可能性。

## A1｜书中实例
- 抽样第 1 段：祥子数钱、砍价到九十六元，铺主说"交个朋友，车算你的了"；他"几乎要哭出来"，决定把买车日当生日，"人的也是车的"。
- 抽样第 3 段：小茶馆里老车夫饿晕，祥子"飞也似又跑回来"，用白菜叶托着十个羊肉包子；老车夫摸了几回没舍得吃，孙子小马儿进门才拿起一个递过去。
- 抽样第 4 段：虎妞当着牌桌众人与刘四摊牌，"一条绳拴着两蚂蚱，谁也跑不了"；刘四回"我放把火把棚烧了，也不能给你用"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写"一个人怎样被生计一步步折算"时。
- 当用户分析底层互赠、施舍与体面的场面时。
- 当用户要写市井争吵里的试探、报价与摊牌时。
- 当用户判断一段叙事是否替人物下了结论时。
- 与《祝福》都写被吃掉的人：鲁迅写礼俗的名目，老舍写租金的算术。
- 与《生死疲劳》都写劳动者：莫言用轮回拉开距离，老舍贴着一个人的皮肉写。

## E｜执行步骤
1. 画一张现金流表：列出人物全部收入、支出、欠款、押金 → 标出哪一项决定他的身份。
2. 找三处身体描写（腿、腰、手），按故事时间排序 → 看作者怎样用同一部位写折旧。
3. 抄一场争吵，给每句话标功能（试探／威胁／报价／求和） → 数谁先报价，谁先让步。
4. 把叙述者的判断句全部划掉重读 → 验收：故事是否还成立；若成立，说明那些句子是作者加的，不是人物有的。
5. 用三百字写同一场雨，改从坐车人的角度 → 比较两版里"时间"各值多少钱。

## B｜边界与误用
- 素材只保留二十一至二十四章标题，前二十章无章节信息，场面位置靠正文推断，引用章号须谨慎。
- 叙述者会直接评价人物，这种全知口吻今天看来过于代人物发言；学它容易写成"作者替穷人总结命运"。
- 女性（虎妞、小福子）多通过男性视角与身体描写成立，分析时须标明这是"被看"的形象。
- 宿命感强，结构把一切归给环境，容易读成努力无用的决定论，忽略书中仍有具体的选择节点。
