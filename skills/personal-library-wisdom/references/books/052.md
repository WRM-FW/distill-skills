# 《只有一个人生》 — 周国平
> 类型：论说 | 原文规模：约 9.5 万字 | 抽样依据（工作档案 udigest/052.md（6 段）

## 一句话
用"距离"和"死亡"两把尺子，把日常烦恼重新量一遍大小。

## R｜原文骨架
- 八辑，每辑一个题目域：活出真性情、成为你自己、丰富的安静、都市里的外乡人、习惯于失去、活着的滋味、徘徊在人生的空地上、存在之谜。
- 第一辑 → 用袁中郎的"适世"拆"义／利"二分，给出第三种活法。
- 第二、三辑 → 自我与独处：把"孤独"和"寂寞"分开，把"安静"当能力而非状态。
- 第四、五辑 → 城市、土地、消费：用"外乡人"的位置看都市生活。
- 第六、七辑 → 死亡、失去、病：用父亲之死、生病这类具体事件承托抽象命题。
- 第八辑 → 收束到"自我之谜"，等于承认前面的答案都只是暂定。
- 文章多为两三千字的随笔：先叙事、后立论、末尾给一句能带走的判断。

## I｜核心命题与可执行方法
**距离校准** —— 看作者把一件事放在多远的位置上评 → 问："这件事在十年尺度上还剩多少重量？" → 会看到：他反复用"隔开一定距离"纠正判断；近处的小事被放大，是因为它挡住了视线，不是因为它大。

**死亡参照系** —— 看一段议论是否以死为背景 → 问："如果明天就死，这件事还重要吗？" → 会看到：这不是教人消极，而是给所有追求设一个可退的位置；退得回来，才不至于失态。

**三分法** —— 看作者怎样用第三个选项拆掉二选一（儒家的谐世、道家的玩世、佛家的出世，加上袁中郎的"适世"） → 问："这个选项是被忽略了，还是被两边共同否认了？" → 会看到：多数困境的真解法在坐标系之外，不在坐标系的另一端。

**癖作为证伪器** —— 看一个人肯为哪件事付出代价 → 问："他愿意为这个爱好损失什么？" → 会看到：判断真兴趣不看投入时间，看肯不肯吃亏；不肯吃亏的喜欢只是消遣。

**记忆的钥匙** —— 看作者用哪个感官细节打开过去（普鲁斯特的玛德莱娜小点心） → 问："这个细节可复现吗？" → 会看到：回忆不是靠意志调取的，是被一种味道、一段声音撞开的；写作能做的只是守在门口。

## A1｜书中实例
- 抽样第 1 段：他引袁中郎"余观世上语言无味面目可憎之人，皆无癖之人耳"，并称真有所癖者"将沉湎酣溺，性命死生以之"；由此把"适世"列为儒、道、佛之外的第四种人生观。
- 抽样第 3 段：巴黎艺术桥的黄昏——他和朋友靠着栏杆席地而坐，一个姑娘画素描，几个年轻人敲手鼓，有姑娘上前亲吻鼓手再平静离开；他由此说"我知道，巴黎是有颜色的"。
- 抽样第 6 段：他引肖斯塔科维奇《第十四交响乐》终曲不美化死亡，说"死是真正的终结，是一切价值的毁灭"，并承认接受它"并非因为它合理，而是因为非接受它不可"。

## A2｜何时调用 / 与相邻书的区分
- 当用户被一件近处的烦心事困住，需要重新校准它的分量时。
- 当用户想区分"独处的充实"与"寂寞的空洞"时。
- 当用户面对二选一，想找第三条路时。
- 当用户想判断自己的爱好是不是真的时。
- 与《加缪笔记》都在用短句安顿处境：加缪把句子当探针，允许它不成立；周国平把句子当结论，要求它当天能用。前者是草稿，后者是处方。
- 与《局外人》都处理死亡：加缪让死亡拆穿日常的表演，周国平让死亡给日常定出比例。

## E｜执行步骤
1. 写下一件正在困扰你的事 → 分别用"一周后""一年后""临终前"三个距离各写一句判断 → 比较哪一句最不像抱怨。
2. 列三个"我愿意为它吃亏"的爱好，写出各自已付出的代价（钱、时间、关系） → 连一个代价都写不出的，划掉。
3. 把当前的一个二选一改写成三选一 → 第三项必须是"两边都不选但仍要承担后果"的选项。
4. 用 300 字写一次"被气味或声音带回过去"的经历 → 验收：触发物具体到品牌、温度或曲名。

## B｜边界与误用
- 文章多为 1990—2000 年代的报刊随笔，例子偏知识分子生活，对体力劳动与照护处境的覆盖很少。
- "思考死亡使人豁达"是作者的结论，不是普遍规律；对刚经历丧亲或处于抑郁中的读者，这套推理可能过轻。
- 引袁中郎、奥勒留、卢克莱修多为转述与意译，做学术引用须回原文核对。
- 对西方养老方式的描述以旅行观感为据，样本有限，不宜当社会学结论。
