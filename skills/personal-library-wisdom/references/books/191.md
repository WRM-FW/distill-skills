# 《余华作品全集（套装共 13 册）》 — 余华

> 类型：合集 | 原文规模：约 93.5 万字 | 抽样依据（工作档案 udigest/191.md（6 段）

## 一句话
把中国人的悲恸写成一套可执行的动作：抱、走、挖、洗、换、拣。

## R｜原文骨架
套装按长篇、中短篇、随笔混编。抽样覆盖到的部分，各自分工如下：
- 《活着》→ 以亲人接连死亡推进，解决"丧事怎么办、话怎么跟家里说"。
- 《兄弟》→ 上下两部跨四十年，解决"身体、羞耻与商品语言如何互相翻译"。
- 《现实一种》→ 家庭内部的连环暴力，解决"暴力如何要求受害者配合"。
- 《世事如烟》→ 数字人名与宿命结构，解决"命如何替代因果"。
- 短篇《他们的儿子》《黄昏里的男孩》→ 日常小钱与羞耻，解决"一个细节如何撑起一篇"。
其余分册（随笔、文论等）抽样未覆盖，不作判断。

## I｜核心命题与可执行方法
**丧事的程序** —— 看一个人怎样处理亲人的尸体（福贵撕下袖管蒙住有庆的眼睛，把坑里的小石子一颗颗拣出来）→ 问"他为什么先想怎么跟妻子说，而不是先哭" → 会看到悲恸被办事流程接管，情绪被推迟到事情办完以后。
**公开的羞耻** —— 看谁在众人面前被剥开（李兰对两个孩子说"不要哭，不要让别人听到我们在哭"）→ 问"这个家在保护谁的面子" → 会看到苦难先被折算成"别让人听见"，然后才轮到疼。
**暴力的配合** —— 看施暴者要受害者做什么动作（山峰一遍遍说"你可以哭了""最好再来点声音"）→ 问"他要的是眼泪还是服从" → 会看到暴力不只落在身上，还要求一场情绪表演。
**钱的单位** —— 看人物用多少钱衡量一件事（出租车费、三千块、三个包子）→ 问"这笔钱在家庭里对应哪种权力" → 会看到爱常用"节约"的语言说出，说不出口的变成训斥。
**身体的夸张** —— 看《兄弟》用汽车发动机、喇叭比喻高潮 → 问"谁在叙述这具身体，读者被放在什么位置" → 会看到欲望被商品语言翻译，也看到叙述者的男性视角从未离场。

## A1｜书中实例
1. 《活着》：福贵抱着有庆往家走，走走停停，到村口田埂坐下，"一看儿子我就忍不住哭，哭了一阵又想家珍怎么办"。他先瞒着家珍，偷偷拿锄头去爹娘坟前挖坑；埋时脱下衣服，把袖管撕下来蒙住儿子的眼睛，对坟说"有庆要来了，你们待他好一点"。
2. 《兄弟》：李兰站在床前，一只只捡宋凡平尸体上的苍蝇，捡了整整一个下午；夜里一次次去井里提水，给高大的丈夫擦洗换衣。两个孩子哭，她只说"不要哭，不要让别人听到我们在哭"。
3. 《现实一种》：山峰把妻子拉起来，"你现在可以哭了"；她只是无声流泪，他于是揪住头发吼"为什么不哭得响亮一点"，随后一拳一拳打下去。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析"中国人为什么不哭"，需要看悲恸如何被程序和体面接管时。
- 当用户写家庭场景，需要知道暴力如何以"要求表态"的形式出现时。
- 当用户要练极简叙述，需要看短句如何承担高密度情绪时。
- 与《要有光》同写家庭里的病与崩溃：梁鸿给制度与价格，余华给身体与沉默。
- 与《老舍全集》同写苦难：老舍让人物说话，余华让人物做事，话越少越重。

## E｜执行步骤
1. 选一个死亡或离别场景 → 列出人物做的"办事动作"（抱、走、挖、洗、换、拣）→ 得到一张动作清单。
2. 标出情绪被推迟、被转移的句子 → 看作者把哭安排在第几步。
3. 找"别人会听见"的顾虑 → 记录这个家庭在防谁。
4. 对比同一事件在不同人物口中的版本 → 找出谁被剥夺了叙述权。
5. 仿写 200 字，不许用形容词与"悲痛""绝望" → 验收：读者能说出谁死了、谁在忍。

## B｜边界与误用
- 苦难叙事容易被当成"中国人的真相"，它其实是余华的一种叙述选择。
- 女性常作为身体与受难的载体，分析时要指出视角，不要跟着叙述走。
- 《兄弟》下部夸张到失真，讽刺与煽情混在一起，引用需分清。
- 小说不能当历史材料，书中没有提供年代、政策与统计数据。
