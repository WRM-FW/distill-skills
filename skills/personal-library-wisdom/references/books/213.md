# 《普希金文集（全十二卷）》 — 亚历山大·普希金

> 类型：合集 | 原文规模：约 70.1 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/213.md（6 段）

## 一句话
十二卷按年编次的诗文全集，用四种体裁互证同一母题：转折与不可挽回的损失。

## R｜原文骨架
- 抒情诗卷（1813 起逐年排列）：目录按「一八一三／一八一四／一八一五／一八一六」编次，单篇如《致娜塔丽亚》《皇村中的回忆》《致巴丘什科夫》《我的墓志铭》，解决"按年读一个人的声音如何变化"。
- 童话诗卷：《萨尔坦皇帝、他的儿子……和美丽的天鹅公主的故事》《母熊的故事》，解决"民间故事的口语节奏如何写进诗行"。
- 小说卷：《驿站长》（别尔金小说集）、《别墅来客》，解决"小人物叙事与未完成稿的开放结尾"。
- 戏剧卷：诗人、丛刊出版人、赌徒的小酒馆场景，解决"文学生态的自嘲"。
- 抽样只到 1816 年的抒情诗目录，后卷的具体分卷与长诗未覆盖。

## I｜核心命题与可执行方法
**跳时叙述** —— 看《驿站长》 → 问"杜妮亚的命运在哪一句被交代完" → 会看到作者不写经过，只用"她一点消息也没有，是活是死，只有上帝知道了"跨过三年。
**重复句变奏** —— 看《萨尔坦皇帝》三姐妹窗下许愿 → 问"三个愿望各换来什么" → 会看到只有"生个勇士"被选中，童话的奖惩按愿望类型分配。
**叙述者可靠性** —— 看《驿站长》的"我" → 问"他凭什么知道站长的心事" → 会看到消息源只是酒后哭诉，眼泪"由于喝了五杯潘趣酒"，抒情被自己拆台。
**体裁对照** —— 看同一母题在诗与小说中的处理 → 问"诗里用预兆，小说里用什么" → 会看到《预兆》以月亮在左在右暗示吉凶，小说用天气、账单、坟地。
**未完成稿的读法** —— 看《别墅来客》 → 问"对话在哪一句转向讽刺" → 会看到社交闲谈本身就是情节，不需要结局。
**颂与挽的切换** —— 看《皇村中的回忆》 → 问"从景物赞美到'女皇已不在'用了几行" → 会看到颂诗内部埋着时间的否定。

## A1｜书中实例
- 《皇村中的回忆》：先写"俄罗斯的雄鹰打败了狮子，正在太平和欢乐的怀抱中安眠"，随即转折"女皇已不在，一切已逝去"（抽样1）。
- 《驿站长》结尾：叙述者问站长怎么死的，酿酒师傅的妻子答"喝酒喝死的，老爷"（抽样4）。
- 《萨尔坦皇帝……的故事》开篇：三个姑娘夜纺，依次说"如果我当上皇后"要做什么（抽样3）。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析俄国文学"小人物"叙事的写法时调用。
- 当要处理诗歌中的预兆、迷信、民间母题时调用。
- 当写短篇、需要"用一句话跳过数年"的样本时调用。
- 当改编童话诗、需要口语节奏与重复结构时调用。
- 与《莎士比亚全集》卡同看"认出与错过"：莎剧靠对话当场完成相认，普希金常把关键经过留在叙述之外。

## E｜执行步骤
1. 输入：一个母题（如"预兆""离别""突然的死"）。动作：按年代在目录中取三处，分属诗、童话、小说。产出：三处文本。
2. 动作：标出每处的体裁手段（韵脚、重复句、跳时、对话）。产出：手段对照表。
3. 动作：找同一篇内语气转折的句子，标出行距。产出：转折位置图。
4. 动作：查叙述者知道什么、通过谁得知。产出：信息源清单。
5. 动作：写"同一母题的三次处理"短论，逐条注明篇名。产出：一页对照笔记。

## B｜边界与误用
- 中译是多人合译，诗行节奏与俄语格律不可复现；据译文谈"音步"会落空。
- 十二卷编次与苏联科学院版未必一致，卷序不等于创作顺序，须以目录年份为准。
- 抽样集中在 1813-1816 年抒情诗与几篇小说，长诗《叶甫盖尼·奥涅金》与戏剧代表作未取样。
- 最易误用：把《驿站长》的叙述者当成作者本人，从而把反讽读成感伤。
