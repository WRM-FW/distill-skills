# 《干校六记》 — 杨绛
> 类型：文学 | 原文规模：约 2.2 万字 | 抽样依据（工作档案 udigest/014.md（6 段，另有一份“著译七种”本）

## 一句话
用凿井种菜的力气把大词拆成日子，教人写下可核对的事实。

## R｜原文骨架
- 小引（钱锺书）→ 交代“六记”的体例与写作位置，说明只记琐事。
- 一 下放记别 → 送默存先遣下乡，“连锅端”，捆箱子，吃不下饭。
- 二 凿井记劳 → 硬地、借水泵、凿井、“有女人就不出水”的嘀咕、终于见水。
- 三 学圃记闲 → 看菜园；村里孩子与妇女来拣菜帮子、拔秫秸、拆厕所木柱。
- 四 “小趋”记情 → 一只狗在两个连队之间跑动，兼写人对它的戒备。
- 五 冒险记幸 → 雨后跳小岛过河看默存，绕道回屋，怕被领导发现。
- 六 误传记妄 → 回京“老弱病残”名单先有后无，牵出档案袋里的黑材料。

## I｜核心命题与可执行方法
**轻笔写重** —— 看灾难被译成哪种词 → 问“这里用的是家常词还是控诉词” → “头顶上着了一个焦雷”“经受折磨，就叫锻炼”；苦难在叙述里被换成生活技术问题，判断留给读者。

**可完成的小事** —— 看文本用多少字写井、渠、粪、菜 → 问“为什么记这些而不记批斗会” → 用一个能见水、能收菜的工程安放不可控的处境；有验收标准的事，是尊严的落脚点。

**物资的民间规则** —— 看东西从谁手里到谁手里 → 问“这次取用谁占理” → 孩子拣菜帮子、拔秫秸，老大娘一句“地主都让拣”；饥饿面前自有一套地方性共识。

**称呼的距离** —— 看“我们连”“班长”“领导”“老头儿”怎么用 → 问“她用谁的语言称呼自己和丈夫” → 借用体制词汇却不投入情感，反讽藏在称呼里。

**恐惧的清单** —— 看每次冒险后她结算了什么 → 问“她怕的是掉进河里还是被抓住” → “没有掉在河里，没有陷入泥里，没有滑跌，也没有被领导抓住”并列；恐惧被拆成可核对的项目。

## A1｜书中实例
- 送别（一）：默存低声说“这个月十一号，我就要走了。我是先遣队”；她像“头顶上着了一个焦雷”；沙锅鸡块“不过是鸡皮鸡骨”，“我舀些清汤泡了半碗饭，饭还是咽不下”。
- 凿井（二）：一锹下去“只筑出一道白痕”，引得小伙子们大笑；“小牛”私下说“挖井不用女人；有女人就不出水”，阿香去抗议，两人“真有点担心”。
- 名单（六）：先传“老弱病残”回京名单上有默存，她已开始打算收拾行李；公布时“没有他”。“没有误传，不会妄生希冀，就没有失望，也没有苦恼。”

## A2｜何时调用 / 与相邻书的区分
- 当用户要把一段难以直说的经历写成可读的文字时。
- 当用户分析“克制叙述”如何运作，以及它会不会变成回避时。
- 当用户判断一份回忆录哪些是事实、哪些是姿态时。
- 与《浮生六记》同用日常技术对抗困境：沈复在礼法缝隙里摆弄器物，杨绛在制度缝隙里凿井种菜。与《梁庄》式非虚构相比，本书几乎不解释，只记录。

## E｜执行步骤
1. 输入一段自己的困境经历 → 只写三件可完成的小事（工具、工序、结果）→ 产出 300 字 → 验收：不出现“苦难”“迫害”等大词，读者仍知道发生了什么。
2. 输入文中任一处轻描淡写 → 补出被省略的情绪与事实 → 产出两栏对照（写了的/没写的）→ 验收：能说出作者为什么选择不写。
3. 输入一次物资流转（菜、柴、煤、骨头）→ 画出取用者与规则 → 产出地方性规则清单 → 验收：每条规则都能找到一个说出口的人。
4. 处境诊断：把当下困境拆成“可核对的小目标”与“不可控的背景”→ 产出两列清单 → 验收：本周至少完成一个可验收项。

## B｜边界与误用
- 六记只写生活侧面，不构成对干校制度的完整叙述；当“文革史料”用会低估它的选择性。
- 克制是有意的修辞，不等于当事人不痛；用“她都不在意”解释文本是误读。
- 对当地农民的描写带着外来者的距离（“他们穿的是五颜六色的破衣裳”），做乡土分析时须指出这个视角。
- 两个版本字符数不同（后者为“著译七种”本），页码与篇目引用须注明版本。
