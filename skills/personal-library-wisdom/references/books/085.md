# 《认知觉醒》 — 周岭
> 类型：论说 | 原文规模：约 8.0 万字 | 抽样依据（工作档案 udigest/085.md（6 段）

## 一句话
先用三重大脑和元认知解释"为什么做不到"，再给舒适区边缘、深度输出、主动休息这套练法。

## R｜原文骨架
- 自序「开启自我改变的原动力」→ 作者 36 岁前后的转变，交代全书是自救笔记。
- 上篇「内观自己，摆脱焦虑」：第一章 大脑（三重大脑、焦虑的根源、耐心）／第二章 潜意识（模糊、感性）／第三章 元认知（反思能力、自控）。
- 下篇「外观世界，借力前行」：第四章 专注力（情绪专注、深度沉浸）／第五章 学习力（匹配、深度、关联、体系、打卡、反馈、休息）／第六章 行动力（清晰、傻瓜式投入、破解"道理都懂"）／第七章 情绪力（心智带宽、单一视角、游戏心态）。
- 第八章「早冥读写跑，人生五件套」→ 把前面原则落成五个日常动作。
- 结语「一流的生活不是富有，而是觉知」。

## I｜核心命题与可执行方法
**舒适区边缘选难度** —— 学习卡住或犯困时 → 判断材料处在太易、太难还是刚好：需要费力但不至于放弃、正确率大约八九成 → 把任务切到"跳一跳够得着"的档位 → 验收：一次 25 分钟内感到吃力但能完成；连续三天正确率过高就加难，低到一半以下就降档。

**消除模糊** —— 焦虑上来 → 把担心写成具体句："我担心 X 在 Y 时候发生，最坏是 Z" → 每条配一个今天能做的动作 → 验收：清单上每一"下一步"都能在 30 分钟内做完；写不出具体动作，说明还在情绪里。

**深度学习三环** —— 读完、听完一课 → ①用自己的话复述核心，不抄原句 ②找一个自己经历过的连接 ③写 300 字给外行看 → 验收：外行能复述你的结论；做不到就是还停在"知道"。

**极度专注＋主动休息** —— 开始工作 → 25 分钟只做一件事，手机移出视线；铃响即停 5 分钟，走动、不看屏；四轮后长休 → 验收：每个 25 分钟内分心不超过一次；靠拉长时长而不是提高强度加量，即为误用。

**多视角解情绪** —— 情绪上来 → 依次做四件事：写对方的版本、找一个外部人问一句、去运动 20 分钟、写 300 字复盘 → 验收：写完能说出"我原来的视角漏了什么"。

## A1｜书中实例
- 农夫与蛇（第一章）：作者用这则寓言说明蛇没有发达的情绪脑、只凭本能行事，农夫却按人有善恶之心去推断，因此丧命。
- 爱因斯坦与凯库勒（第五章讲深度学习）：爱因斯坦在去专利局路上看见伯尔尼钟楼，设想公交车以光速行驶时指针是否静止；凯库勒疲劳中梦见首尾相咬的蛇，得到苯环结构的线索。
- 张辉写生气（第七章讲反思）：开一天会吵完架，回家余怒未消，干脆坐下来写生气的细节和原因，写到一半释然，看见了自己视野的盲区。

## A2｜何时调用 / 与相邻书的区分
- 当用户说"道理都懂，就是做不到"时。
- 当用户要排一份学习计划，却总选错难度时。
- 当用户焦虑、拖延、注意力散，需要先诊断再开方时。
- 当用户想建立早起、冥想、阅读、写作、运动中的某一项时。
- 与《掌控习惯》同谈改变：克利尔给提示—渴求—反应—奖励的四步杠杆，周岭先解释理智脑为何斗不过情绪脑；与《深度工作》相比，本书覆盖学习与情绪，后者专攻工作时段的结构。

## E｜执行步骤
1. 输入一个具体卡点（学不进、拖延、易怒）→ 连记三天实际行为与发生时间 → 产出行为流水。
2. 对照三重大脑、模糊、难度错配三项，判断卡在哪一环 → 产出诊断句。
3. 选对应工具（舒适区边缘／写清担忧／25 分钟专注＋5 分钟休息）→ 连续做两周 → 产出记录表。
4. 每周写 300 字复盘：哪次分心、当时在做什么、下次改哪个条件 → 验收：第二周分心次数低于第一周。

## B｜边界与误用
- "三重大脑"是教学化简化，不是解剖学分区；别把它当脑科学结论去引用。
- 全书带较强的自助语气，"觉知"容易变成只反思不行动。
- 对时间贫困、照护负担等结构性限制谈得少，把做不到全归于认知会变成自责。
- 抽样为节选，第五章后段与第八章的具体方法未完整覆盖。
