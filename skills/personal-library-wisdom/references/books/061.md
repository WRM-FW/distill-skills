## 一句话
把婚外情拆成身体成本、通信风险与死亡修辞，检查欲望如何自我辩护。

## R｜原文骨架
- 无章节标题，靠时间与场景推进：书信往来 → 京都重逢 → 固定幽会 → 掐颈 → 夏日焰火。抽样六段正好落在这一链条的不同位置。
- 书信／邮件段 → 解决"如何在不被丈夫发现的前提下建立私密通道"。
- 床笫段（多段连续） → 解决"男性如何计算体力、年龄与快感配额"。
- 掐颈段 → 把死亡语言并入性爱，测试那句"我要死"能否成为免责依据。
- 日常抒情段（樱花、四照花、和服、焰火） → 在暴烈之后重置情绪，承担降温功能。

## I｜核心命题与可执行方法
**快感的会计学** —— 看每一次性事前后，叙述者算了哪些账：还剩几次、能撑多久、能否同时到达。问："如果现在一下攀上顶峰的话，一切就结束了"这类句子出现在哪。会看到中老年男性的欲望叙述里，快感永远附带折旧率，越是计算越显出对衰败的恐惧。

**媒介的可删除性** —— 看待通信方式如何改写越界成本。问：为什么书信阶段他"一想到倘若被冬香的丈夫看到"就不安，换成邮件就"让人放心多了"。会看到技术不是中性的：它降低的是被查获的概率，不是道德压力；胆量由删除键供给。

**死亡修辞的归属** —— 看"杀了我吧""我要死"这类话由谁说出、被谁引用、最后对谁有利。问：当冬香在痉挛中喊"我要死"，菊治是把它当请求、当兴奋证据，还是当自己施力的许可证。会看到叙述如何用她自己的喊声把施加的暴力转写成共谋。

**节气与衣物的情绪记账** —— 看抒情段落安插在哪里。问：樱花凋谢、四照花开、换上十年未穿的夏日和服，这些段落紧接在什么之后。会看到它们几乎总在激烈场景之后出现，功能是冲洗而不是推进；越美的景物描写，越像一次事后撤离。

**单向的注视** —— 看谁被描写外貌、谁被给内心。问：冬香有多少次是以"雪白的下巴"、仰起的小脸、散乱的头发出现，又有多少句是她自己的判断。会看到整本书的镜头固定在菊治一侧，女方是被解释的对象。

## A1｜书中实例
开篇通信段：菊治把书寄给冬香后主动附上手机号与邮箱，并解释邮件的好处——"万一有什么的话，也可以删除，即使保存下来，被他人看到的可能性也极低"。越界的第一步不是情欲，是风险管理。

中段床戏：他在高潮前停住，因为"如果现在一下攀上顶峰的话，一切就结束了"，并想到"自己现在的这个年龄"未必还能再战。快感被写成限量资源。

靠后一段：他掐住冬香的脖子，听到"我要死"，随后联想到古代把通奸男女叠放一刀劈开的刑法，并推演"若被施以那种刑法一刀劈下，菊治也无话可讲"。暴力想象与自我开脱在同一段完成。

## A2｜何时调用 / 与相邻书的区分
- 当用户想分析文学中的婚外情叙事、男性视角如何自我合法化时。
- 当用户要写中老年男性的欲望与身体衰败，需要一套可操作的观察点。
- 当用户讨论"同意"在叙事里如何被伪造，需要具体文本病例时。
- 与《逃离》同问"欲望与出走"，差别在：门罗让判断悬置、给出走后的账单；渡边把镜头锁在男方体内，用快感计算替代道德结算。

## E｜执行步骤
1. 输入一段亲密场景原文 → 标出所有数量词、时间词、体力词（几次、多久、还能不能）→ 产出"成本清单"。
2. 把场景中属于女方的句子单独摘出 → 统计其中描写外貌与描写判断的比例 → 得出一张注视方向表。
3. 找出场景里所有死亡相关词 → 标出说话人与引用人 → 判断谁在使用这份修辞。
4. 把紧接其后的景物段删掉再读一遍 → 比较删前删后的道德温度 → 验收：能否说出这段景物在替谁降温。
5. 用"如果当时有微信"重写开篇通信 → 检验原作的张力是否依赖通信延迟。

## B｜边界与误用
- 不提供女性欲望的第一手材料；冬香的内心基本由男方推测，不能当双视角文本用。
- 最容易被误用为"她说了要死，所以是自愿"的注脚；文本恰恰暴露了这种推导的方便，而不是证实它。
- 大量性描写会淹没分析，摘句时若只取床戏，会把它读成情色小说而非欲望研究。
- 译本对露骨段落的处理情况抽样中无法判断，引用前需核对版本。
