# 《一句顶一万句》 — 刘震云
> 类型：文学 | 原文规模：约 17.0 万字 | 抽样依据（工作档案 udigest/178.md（6 段）

## 一句话
一部关于"说得着"的小说：顺着话找事，顺着事找人，中间常拐好几道弯。

## R｜原文骨架
- 版权信息、编者荐言 → 素材里只有这两项章节标记，正文无小标题，靠分节数字推进（抽样6出现"九"）。
- 改名线 → 同一个人先后叫杨百顺、杨摩西、吴摩西；改名往往跟着换地方、换营生。
- 说话线 → 叙述只做过渡，主体是对话；一个人的位置由他"跟谁说得着"来标定。
- 物件线 → 羊、馒头铺、教堂图纸、拖拉机；东西换一次主人，人的去向就改一次。
- 抽样跨度 → 从杨百顺少年夜宿草垛，到曹青娥一代，再到曹青娥去世后牛爱香出嫁、牛爱国出场，至少两代人。

## I｜核心命题与可执行方法
**拐弯透镜** —— 看一件小事背后的真正起因 → 问这件事中间拐了几道弯、丢羊是第几环 → 会看到老裴那句"不是羊的事，中间拐着好几道弯呢"就是全书的方法论：人说的永远是最后一环。

**说得着／说不着** —— 看谁跟谁有话说、谁只剩沉默 → 问这场对话里谁在说事、谁在说人 → 会看到宋解放"嘴笨"，一天十件事九件不说；曹青娥对侯宝山只说"挺远"，剩下的不再讲。

**传话失真** —— 看一句话经过几个人、变成什么样 → 问谁转述、他改了什么 → 会看到吴摩西"假找"时愁的不是找人，是"这个谎如何编圆"。

**面子的算法** —— 看一只耳垂怎样变成一辈子的把柄 → 问这事伤的是里子还是面子、补面子要花多少 → 会看到秦曼卿把短处"说到明处"，用自曝换自由。

**物的命** —— 看谁靠什么东西谋生 → 问这件东西换过主人吗 → 会看到人的命运跟着营生走，营生跟着物件走。

## A1｜书中实例
抽样1，杨百顺丢羊挨打不敢回家，睡在打谷场草垛里，剃头匠老裴路过，带他去镇上找暖和地方。"杨百顺自生下来，头一回感到人的手是暖的。"

抽样2，秦曼卿因少一只耳垂被李家退婚，劝父亲不要置气："儿的短处说到明处，一辈子没有把柄在谁手里。"老秦叹："我跟人讲了一辈子理，最大一个理儿，原来我儿明白。"

抽样5，曹青娥夜里跟侯宝山开拖拉机耕地，"拖拉机白天是犁地，现在成了犁黑"；她只说"要跑得快，带我去个地方"，"挺远是哪里，曹青娥就不再说了"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写中国人怎么说话，需要"话里藏着另一件事"的样本时。
- 当用户想分析一件事如何被传成另一个版本时。
- 当用户要判断一段关系里"说不说得着"时。
- 与《沧浪之水》同写说话：本书写"说不着"的孤独和绕弯，沧浪写"说得着"的技术和交易。与《活着》同写底层一生：活着靠忍受，本书靠找一句话。

## E｜执行步骤
1. 选一段对话 → 列两栏：他说的表面事／真正的事 → 数中间拐了几道弯 → 产出拐弯图。
2. 标出每个人的话量与听话反应 → 判断谁说得着、谁在敷衍。
3. 找一件被反复转述的事 → 记录每次转述新增和删掉的信息 → 产出传话链。
4. 写 500 字对话，不写心理，只写谁先开口、谁没接话 → 验收：读者能说出这两个人是什么关系。

## B｜边界与误用
- 出去—回来的循环结构容易被读成宿命论，掩盖人物每一次具体的选择。
- 女性多在婚姻市场里被安排，自主空间有限；这是文本的局限，也是它写实的部分。
- 重复句式与方言对不熟悉的人是门槛，容易只读到"绕"，读不到绕里面的精确。
- 地理与年代被有意虚化，不宜当百年乡村史使用。
