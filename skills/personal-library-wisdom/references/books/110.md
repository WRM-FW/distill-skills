# 《创业在路上》 — 罗永浩
> 类型：论说 | 原文规模：约 5.7 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/110.md（6 段）

## 一句话
把一次高争议创业的取舍摊开：什么时候顶着几乎全票反对下注，什么时候必须收手聚焦。

## R｜原文骨架
- 「长谈前后」「在反对的声音中开始」→ 决定做手机时，反对意见的结构与来源。
- 「不要试图去补短板」「凡事由自己决定」→ 创始人能力边界怎么处理。
- 「做硬件的过程中，遇到的最大的坑」「什么是真相？」→ 认知盲区是怎么产生的。
- 「拿到钱比什么都重要」「让投资人青睐的商业计划书」→ 融资的执行顺序与红线。
- 「我与高管的关系」「我与员工的关系」→ 招人、留人与越级。
- 「附录 关于创业的65个极致问答」→ 把前文压成可直接查的问答。

## I｜核心命题与可执行方法
**反对票按理由去重** —— 一群人反对你时 → 先数“不同理由有几条”，同质劝法只算一票（李丰的劝法与之后几乎所有人一模一样）→ 验收：反对意见收敛到三条以内且都能被事实检验，才进入修改。约束是意见同源，放弃“人多即有理”，赌自己能识别增量。

**用平台位置筛项目** —— 现金流与长期牌桌冲突时 → 问“下一轮平台革命我还在不在选手名单里”（他放弃年约 7000 万到 1 亿的脱口秀）→ 验收：说得出这个选择卡在下一代哪一环。

**给贪婪设闸** —— 你是产品型创始人时 → 把非核心改进列成清单，超出“当周一件”就搁置（研究加湿器加水方案一星期，正事全耽误）→ 验收：每周核心任务完成率不低于约定值，清单有封存日期。

**盲区对齐** —— 团队里有资深但没做过一号位的人时 → 关键决策前逐项问“这件事你以为我知道吗”→ 验收：纪要里没有“默认共识”，每条有责任人。

**对赌红线** —— 融资条款谈判时 → 除非确认山穷水尽，不签对赌；签了就以“动作不变形”为唯一验收（他会为完成对赌放弃长期更优解）→ 验收：列出被放弃的长期选项，事后核对。

## A1｜书中实例
- 抽样 1（做手机后第一轮见人）：第一个见的是老同事李丰。李丰说“你做什么我们都可以投资至少2000万元。但是，如果你要做手机……”，随后切换成朋友身份劝退；此后半年几乎人人同调，他差点放弃。唯一说“肯定行”的是做媒体的羽良。
- 抽样 2（硬件团队组建后）：团队里已有从手机公司跳槽来的资深高管，但没人当过 CEO 或 COO，他事后判断这造成全局认知盲区，出现“你假定他们知道，他们假定你知道”的荒唐结果。
- 抽样 3（平台判断）：他算过账：做脱口秀年约 7000 万到 1 亿元，六个月工作六个月度假；仍选手机，因为要参与“下一个计算平台”。

## A2｜何时调用 / 与相邻书的区分
- 当用户面对“几乎所有人都反对”的决定时调用。
- 当用户要在现金流与长期位置间取舍时调用。
- 当用户要设计融资节奏、判断对赌条款时调用。
- 与 116《我的奋斗》同作者：116 谈人怎么长成，本书谈企业怎么活；116 多是态度宣言，本书有具体条款。与 173《乔布斯传》同问“创始人意志怎么塑造产品”，本书给失败侧清单。

## E｜执行步骤
1. 输入：一个多人反对的决定，和全部反对意见。
2. 动作：按理由合并去重，给每条标“可验证／不可验证”，只对可验证的做预案。
3. 动作：写一句“我赌什么位置”，再写“我放弃了什么”（钱、舒适、速度各一条）。
4. 动作：设两个验证点——90 天看执行，18 个月看是否还在牌桌上。
5. 产出：一页决策备忘，含反对意见表与两个验证点。

## B｜边界与误用
- 结论出自一次并不成功的创业，作者也承认“很多错误原本可以避免”；把“聚焦”“敬畏之心”当定律，是拿总结当预测。
- 附录问答是受访语境下的自我陈述，涉及失败归因处尤其要打折。
- 抽样覆盖融资、招人、产品、平台判断；供应链与量产未覆盖。
