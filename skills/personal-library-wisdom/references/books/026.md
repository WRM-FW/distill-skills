## 一句话
用"谁有权定规则、谁从中受益"解释贫富，而不是文化或地理。

## R｜原文骨架
- 第一章 "SO CLOSE AND YET SO DIFFERENT"：以相邻两地对照开场，把"同地理、同文化、结果不同"立成问题。
- 英国线：议会构成 → 内战与 1688 年光荣革命 → 政治多元主义限制王权，把定经济制度的权力挪进议会。
- 殖民地线：弗吉尼亚的约翰·史密斯、特兰斯凯的土地购买、塞拉利昂与南非的对照，展示初始制度如何分叉。
- 美国南方线：机械化削弱种植园对黑人劳动力的依赖 → 联邦与黑人的联盟 → 民权改革。
- 论证靠成对案例推进：先给一组"本该相似却不同"的地方，再拆制度。

## I｜核心命题与可执行方法
**制度双轴定位** —— 有人说"某国穷是因为文化/地理/领导人"时 → 把经济制度（产权、准入）与政治制度（集权/多元）各放一轴，标出谁定规则、谁受益 → 验收：判定是"榨取式有限增长"还是"广纳式增长"；判据是创新能否替换在位者。

**关键节点+自我强化** —— 两地同源却分叉时 → 找分叉年份的小事件，再找"谁获利、如何阻止改革"的正反馈 → 验收：能说出具体机制，而不只是"制度不同"。

**创造性破坏测试** —— 新技术、新产业被卡住时 → 问谁的收入被清零、他们能否否决 → 验收：预测阻力来自在位者而非穷人；若补贴流向在位者，即验证。

**恶性循环找断点** —— 寡头用财富买政治、再用政治护财富时 → 画出"财富→权力→规则→更多财富"的闭环 → 验收：找到断点（外部竞争、选举、联邦制、技术冲击），说明它为何失效或生效。

**小分流比较** —— 两个地理文化相近地区贫富悬殊时 → 比较殖民或建国时的初始制度，找出"小差异"被放大的时点 → 验收：能用同一组变量解释两边，而非各讲一套。

## A1｜书中实例
- 光荣革命（抽样2）：1688 年限制国王与行政权，把定经济制度的权力移到议会，并向广泛阶层开放政治。
- 塞拉利昂与南非（抽样5）：塞拉利昂的疾病环境使白人无法大规模定居，也无约翰内斯堡式矿业，因而不需要种族隔离式的榨取性劳工制度；但可可、咖啡农仍被营销局垄断抽取。
- 美国南方（抽样6）：阿拉巴马等三州近半生产机械化后，黑人不再不可或缺，精英维持旧制度的理由减少；黑人选票与联邦广纳式制度结盟，推动民权。

## A2｜何时调用 / 与相邻书的区分
- 当问"这里为什么穷"或"同样政策为何两地效果不同"时。
- 当判断一轮增长能否持续、是否只是榨取式制度下的有限繁荣时。
- 当某行业抵制新技术，需判断阻力来源时。
- 与 037《人类简史》都谈"制度是虚构秩序"：哈拉里问它如何被相信，本书问它把钱分给谁、为何难改。

## E｜执行步骤
1. 输入：一个贫富判断，写清比较对象与时间点。
2. 画双轴：经济制度的开放度、政治权力的集中度，标注规则制定者与主要受益者。
3. 找关键节点：分叉那年的小事件，以及之后的自我强化链条。
4. 反事实检验：只换文化、地理或领导人，能否解释分叉？
5. 产出"制度—激励—行为—结果"因果链，附一条可证伪观察（如创新是否被在位者买断或禁止）。

## B｜边界与误用
- 以比较叙事为主，不是计量识别，反例容易被叙事吸收。
- 易被误用成"照搬广纳式制度即可发展"，忽略国家能力与顺序。
- 对殖民遗产的处理有争议，对文化解释常一笔带过。
