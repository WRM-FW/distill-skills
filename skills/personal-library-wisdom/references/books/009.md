# 《1984》 — 乔治·奥威尔
> 类型：文学 | 原文规模：约 22.1 万字 | 抽样依据（工作档案 udigest/009.md（12 段，两个译本各 6 段）

## 一句话
把极权拆成可观察的日常技术：仇恨怎么换靶、表情怎么定罪、语言怎么减字。

## R｜原文骨架
- 第一部 → 温斯顿在真理部篡改旧报，建立"日常即罪证"的处境。
- 第二部 → 与裘莉亚的私密关系，标出监控之下亲密还能剩下多少空间。
- 第三部 → 被捕、审讯、101室，把权力写成对"最后一个人"的改造工程。
- 附录《新话的基本要义》（A/B/C 类词汇）→ 给出语言削减的技术说明书。
- 晏天译本保留"第一部/第一章"的分层与附录，董乐山、傅惟慈译本按"第1节—第10节"通排。

## I｜核心命题与可执行方法
**换靶测试** —— 看集体愤怒的宾语能否被替换 → 问："把敌人名字换掉，句子要不要重写？" → 会看到：仇恨挂在句法上，不挂在事实上，所以换靶不需要换情绪。

**脸罪审计** —— 看权力管到哪一层身体 → 问："这里有没有一条罪，罚的是表情而不是行为？" → 会看到：控制从行为推进到神经反射，抽搐、脸色、自言自语都成证据。

**减字推演** —— 看词汇表在删什么 → 问："如果这个词不存在，这个念头还能不能想完？" → 会看到：思想罪需要先完成一道语言上的前置工程。

**双重思想自检** —— 看一个人能否同时持有互斥判断而不觉得矛盾 → 问："他是在骗人，还是两套都已经真信？" → 会看到：稳定的统治不靠谎言被识破，靠谎言内化。

**私密动作盘点** —— 看监控下还剩哪些不被命名的动作 → 问："这个动作被看见会被定什么罪？" → 会看到：自由退到极小的身体尺度——不动嘴唇说话、树林、一句"黄金乡"。

## A1｜书中实例
- 两分钟仇恨（董译本抽样1）：果尔德施坦因的"羊脸"之后接欧亚国军队行军，三十秒内半屋子人爆发出怒吼——愤怒由画面剪辑供给，不由事实供给。
- 仇恨周演讲（晏天译本抽样4）：通讯员递上纸条，敌国从欧亚国改成东亚国，讲演者"连句法结构都没有发生改变"，群众两三分钟内撕掉标语、踩烂旗帜。
- 派逊斯（晏天译本抽样5）：七岁女儿从钥匙孔听到梦话去举报，他在牢里说"我为她感到骄傲。这说明我对她的教育非常正确"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析某套话语如何制造敌意、某组织如何管理表情与用词时。
- 当用户写反乌托邦设定，需要制度细节而不是口号时。
- 当用户怀疑自己"同时相信两件互斥的事"时，用双重思想自检。
- 与《美丽新世界》同问"控制如何生效"：本书答恐惧、匮乏与减字，赫胥黎答舒适、消费与造人。诊断"人怕什么"用本书，诊断"人舍不得什么"用那一本。

## E｜执行步骤
1. 输入一段宣传文本 → 标出所有敌人名与情绪词 → 逐个替换后重读 → 产出"可替换性清单"。
2. 输入一次会议或群聊记录 → 判断被禁止的是行为还是表情、语气 → 产出"脸罪条款"。
3. 输入一份术语表 → 列出被合并或删除的词 → 写一句"用旧词才说得出、用新词说不出"的话。
4. 验收：每条结论都能指回一句原文，而不是"感觉很像我见过的某件事"。

## B｜边界与误用
- 不提供反抗方案；书中的兄弟会本身是空壳，别把它当组织学教材。
- 把"老大哥"当纯隐喻，会丢掉电幕、新话、101室这些可迁移的技术细节。
- 书中把无产者写成"像牲口一样一点也没有办法"，这是党的宣传口径与温斯顿的偏见，不宜直接当作者结论。
- 两个译本人物译名不同（果尔德施坦因/戈德斯坦、奥勃良/奥布赖恩），引用须注明译本。
