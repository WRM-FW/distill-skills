# 《我们生活在巨大的差距里》 — 余华

> 类型：文学 | 原文规模：约 6.1 万字 | 抽样依据（工作档案 udigest/189.md（6 段）

## 一句话
用随笔把"差距"从统计数字还原成看与被看的位置。

## R｜原文骨架
全书无章节标题，抽样可见五束题材，各有各的活儿：
- 忆旧与梦 → 公判大会、枪决记忆，处理"写作素材从哪来"。
- 文学阅读 → 绝唱、性与死、马悦然写高本汉，处理"一个作家怎么读另一个作家"。
- 文学现场 → 1987 年《收获》先锋专号、费舍尔出版社一百二十年，处理"流派与刊物如何互相成全"。
- 行走与观看 → 南非笔记、世界杯、沈阳踢球，处理"旁观者把自己放在哪"。
- 家 → 儿子余海果的比喻与作文，处理"语言的鲜活从哪捡"。

## I｜核心命题与可执行方法
**梦的复查** —— 看反复出现的梦（公判大会、被枪决）→ 问"这个梦在替哪段白天经验记账" → 会看到暴力的想象不是凭空，是没消化完的观看。
**成像位置** —— 看同一篇里谁在黑白照片、谁在彩色照片 → 问"谁被描述，谁在描述" → 会看到差距是一种取景，不只是收入之差。
**小额支出的说法** —— 看父亲怎么谈出租车钱（"我们也不是心疼那几个钱"）→ 问"这笔钱实际在买什么" → 会看到中国家庭用"为你好"结账，绕开"舍不得"三个字。
**比喻的归属** —— 看谁的比喻被原样保留（儿子："好比是拿着遥控器，咔嚓一下把电视关了一样"）→ 问"这个比喻比大人的解释多说了什么" → 会看到孩子把伤害说成操作，成人把它说成教育。
**流派的后勤** —— 看先锋专号的招待所、公交车、编辑部旁的小餐馆 → 问"一场文学运动需要哪些具体条件" → 会看到编辑的胆量、单身汉的空闲、外地的床位，与"胡闹"的恶名一起构成现场。

## A1｜书中实例
1. 开篇忆梦：他站在县中学操场主席台前沿，身后两个持枪军人，喇叭里念罪行，最后八个字"判处死刑，立即执行"。枪响后他竟站起来，冲开枪的人喊"他妈的，还没到沙滩呢！"醒后他给自己下了一句警告："以后不能再写血腥和暴力的故事了。"
2. 费舍尔出版社百年：塞缪尔·费舍尔说"余先生，你是我见过的德语说得最好的中国人"，他回"你的中文比他们说得好"。结尾一句把两人分置在两种照片里。
3. 沈阳踢球：史铁生坐轮椅守住篮球架中间的空隙，"辽宁的学生再也不敢射门了，他们怕伤着铁生"；马原一米八五站在对方门前等头球，传球质量太烂，客场还是输了。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写"我认识的某地、某人"，需要防止写成游记或赞美诗时。
- 当用户想处理家庭里的钱与爱，需要一句不煽情的说法时。
- 当用户要回看八十年代文学现场，需要非论文的细节时。
- 与《要有光》同写"差距"：梁鸿做田野、给价格与床位；余华做随笔、给比喻与位置。
- 与《老舍全集》同写市民语言：老舍用方言分配同情，余华用短句控制距离。

## E｜执行步骤
1. 选一个反复出现的梦或画面 → 300 字内只写看到的，不写解释 → 产出"未经归因的素材"。
2. 标出画面里缺席的人：谁不在场、谁在镜头外 → 补一句他可能在的位置。
3. 找一个孩子或外行说过的比喻，原样抄下 → 用它替换你写的抽象情绪。
4. 给这段加三个坐标：地点、价格、年份 → 检查是否还像散文诗。
5. 通读，删掉所有先给结论的句子 → 验收：读者能自己走到你结尾想说的那句话。

## B｜边界与误用
- 随笔不成体系，对差距的结构性成因只给观感，不能当社会分析引用。
- 集中有应酬文（社庆、书评、序），信息密度低，别把每篇都当代表作。
- 忆旧段落含事后合理化，"因为写暴力才做噩梦"是自述，不是因果证明。
- 视野限于作家圈与城市中产，县乡只作为记忆背景出现。
