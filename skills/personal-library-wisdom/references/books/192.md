# 《生命不息，折腾不止》 — 罗永浩

> 类型：合集 | 原文规模：约 17.5 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/192.md（6 段）

## 一句话
把穷、被否、被骂这些处境拆成下一步能做的动作，而不是励志口号。

## R｜原文骨架
- 《我的奋斗》长篇自述 → 交代动机：家里没钱、谈恋爱、同龄人已打好基础。
- 高校与剧场巡回演讲 → 用创业过程当案例：预算被董事会否掉、三十七岁自学设计、海报被人整张揭走。
- Smartisan T1 发布会段落 → 把发布会当产品说明会：门票折现。
- 现场问答与微博体短答 → 处理"你凭什么""你怎么看死亡"这类当面质疑。
- 书单段（抽样3）→ 用《异类》《无价》把"定价即读心"接回自己的传播经验。

## I｜核心命题与可执行方法
**小成果换授权** —— 触发：提案被斥为"小丑"、预算批不下来 → 动作：不继续争预算，先自做一个能看见的成品（他利用加班时间自学平面设计，做海报）→ 验收：外部同行说"你可以开广告公司了"。

**揭走率测试** —— 触发：投放预算极低、海报栏被覆盖 → 动作：把钱全押在"顺眼"一项，观察海报是否被整张撕走 → 验收：校园代理反馈"整张揭走率很高"，传播物被当成收藏而非广告。

**把抱怨改成规则** —— 触发：票务规则有模糊地带、老用户可能觉得吃亏 → 动作：不做分次折现，改两年累计折现，并当众承认原说法"实际上这是骗人的" → 验收：用户"由衷地高兴"。

**定价反推** —— 触发：要给产品定价或判断促销真假 → 动作：按《无价》的路子先找对方的价格锚点，再算自己让了多少 → 验收：能说出"这个价格让谁觉得占了便宜"，而不是只报成本。

## A1｜书中实例
- 抽样2：创业半年后，他在董事会上提出二三十万预算做广告设计，被其他董事直斥为小丑，理由是"我们一线的教师也不过三十万"；他没再争，转为加班自学设计，做了一年半。
- 抽样2末：高校海报的"整张揭走率"被他当成投放效果的验收指标——宿舍墙上有霉斑，学生宁可揭一张顺眼的海报去贴。
- 抽样5：T1 发布会现场，他先承认"事先说过门票不打折"是骗人的，再宣布按票面折现、两年累计。

## A2｜何时调用 / 与相邻书的区分
- 当用户没预算、没资历，却要推动一件有具体交付物的事。
- 当用户要做低价传播，并需要可观察的效果指标。
- 当用户要处理公开质疑，把失败讲成下一步动作。
- 与《走过》（jing-yidan-zouguo）：同为公众人物第一人称，敬一丹把经历转成地方与物，罗永浩把经历转成决策与验收。
- 与《我以为这辈子完蛋了》（brosh-solutions）：都靠自嘲推进，罗永浩的自嘲服务于说服听众，布罗什的自嘲服务于接纳自己。

## E｜执行步骤
1. 输入：一件被否掉的事与否决理由。动作：把理由逐条抄下，找出唯一能用低成本证伪的一条。
2. 动作：用业余时间做一个最小成品，限定周期（他的量级是一年半），只做样品不做方案。
3. 动作：给成品设外部可观察指标（被揭走、被转发、被同行报价），别用自我感觉。
4. 动作：拿指标回到否决者面前，只报结果，不复述委屈。
5. 产出：一页"否决理由—最小动作—外部指标—复谈结果"。

## B｜边界与误用
- 这是演讲结集，方法散在段子里，商业判断多为一手经验，不能当创业教材。
- "每次取得阶段性的进步，都是妇女给我的动力"这类表述带时代与性别盲点，直接引用会冒犯听众。
- 大量段落依赖现场笑声，脱离语境读会把反讽当结论。
- 对同行、前雇主的评价是单方叙述。
