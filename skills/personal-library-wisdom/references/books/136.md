# 《告白》 — 凑佳苗
> 类型：文学 | 原文规模：约 5.5 万字 | 抽样依据（工作档案 udigest/136.md（6 段）

## 一句话
让加害者、家属与旁观者轮流自白，看同一桩命案如何长出互相拆台的版本。

## R｜原文骨架
- 第一章 告白 → 森口在结业班会上讲女儿之死，并宣布自己已经动手制裁。
- 第二章 殉教者 → 班长美月以投稿信接续，追问"制裁之后"由谁负责。
- 第三章 慈爱者 → 直树母亲的第一人称，把儿子的沉默解释成善良。
- 后续章节由其他当事人接续（抽样未显示章名），每章换一个"我"。
- 组织方式不是顺时序，而是每一章重讲一遍同一件事，只补上自己那一段。

## I｜核心命题与可执行方法
**责任起点定位** —— 看每章把因果起点放在哪一步 → 问：这一版里"我"的动作是主动还是回应 → 会看到所有人都把自己写成被逼的一方，责任被推给上一环。
**叙述顺序的权力** —— 看同一事件在不同章出现的次序 → 问：谁先说出，谁被略过 → 会看到叙事权不在事实多寡，而在谁先定义语境。
**动机的体面化** —— 看自白里的"因为" → 问：这个理由能解释行为的强度吗 → 会看到真正的驱力（被看见、被承认）被塞进从句。
**教师修辞的暴力** —— 看森口的点名、举例、反问 → 问：她在教学还是在宣判 → 会看到正确知识也能被当作羞辱工具。
**母职的评价体系** —— 看两位母亲夸孩子什么 → 问："善良"在什么情况下被拿出来用 → 会看到它是对成绩劣势的补偿话术，也是控制。

## A1｜书中实例
牛奶（抽样2）：森口把混了樱宫血的牛奶给两名学生喝，再补一句"两三个月后请一定要去验血"。惩罚被包装成一堂生理卫生课，宣判与教学用同一套语气完成。
美月的投稿（抽样2）：她抱怨老师"有点不负责任"，理由是制裁之后的事也该由老师看着。这句抱怨暴露了全班把老师当成因果链最后一环的思维。
直树的告白（抽样5）：母亲反复问"小孩醒了你还把她丢进去，是因为很害怕吧"，他在心里回答"不是那样的"。同一句话，母亲要的是可原谅的版本，儿子要的是被承认的版本。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写多视角叙事，需要设计"每个版本都自洽"的结构时。
- 当用户想分析校园事件中各方如何自我叙述时。
- 当用户处理"私刑是否有理"，需要把加害者写成人的时候。
- 与《基督山伯爵》同问制裁的正当性：那本从复仇者外部搭建工程，这本从被制裁者内部拆解后果；同问"谁有权惩罚"，不同在视角的内外。

## E｜执行步骤
1. 输入：列出全部叙述者，做一张"谁在什么时候知道什么"的表。
2. 动作：为每个叙述者标出他必须隐藏的一件事。
3. 动作：把同一场冲突按三个人的版本各写二百字，不许添加新事实。
4. 产出：一张"版本差异表"，只列差异，不判断真假。
5. 验收：读者能仅凭差异表指出每个人的利益所在。

## B｜边界与误用
- 结构依赖信息隐藏与反转，重读时张力大幅下降。
- 把 HIV 当成惩罚装置，会强化"感染即报应"的污名，引用时必须拆开处理。
- 校园与家庭语境高度日本化，迁移到别处要重设制度背景。
- 各章声音区分度不均，部分"我"更像作者的传声筒。
