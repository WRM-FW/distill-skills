# 《月亮与六便士》 — 毛姆
> 类型：文学 | 原文规模：约 8.8 万字 | 抽样依据（工作档案 udigest/155.md（6 段）

## 一句话
用一个旁观者的犹疑，拆解“天才”怎样被叙述、被定价、被原谅。

## R｜原文骨架
无章节小标题，正文以"第X章"分段：
- 开篇 → 叙述者回顾伦敦文坛，交代自己为什么要写斯特里克兰。
- 伦敦 → 结识斯特里克兰夫人，见识体面的文艺社交。
- 巴黎 → 斯特里克兰抛家弃业，叙述者被迫充当说客与见证人。
- 塔希提 → 布兰奇、蒂阿瑞与岛上居民的转述，拼出后半生。
- 尾声 → 回伦敦，斯特里克兰夫人与评论家正在生产"伟大的查理"。

## I｜核心命题与可执行方法
**转述链清点** —— 看每条关于斯特里克兰的信息由谁提供 → 问：此人有什么立场 → 会看到"天才"由二手的赞叹堆成，越远越神。
**价格时点** —— 看画价从无人要到他哥哥卖出三万法郎 → 问：评价在哪一刻转向，依据是什么 → 会看到市场先于美学，买家先于批评家。
**"不在乎"的验证** —— 看他说不在意时的行为 → 问：他是否为此付了可见的代价 → 会看到真正的不在乎表现为不辩解、不报复、不经营。
**旁观者的共谋** —— 看"我"一边厌恶一边跟着他走 → 问：叙述者为什么离不开 → 会看到好奇本身就是参与，记录即授权。
**女性功能表** —— 看布兰奇、斯特里克兰夫人、蒂阿瑞各占什么位置 → 问：她们被分配了哪种叙事功能 → 会看到她们分别是欲望的代价、体面的门面与地方色彩。

## A1｜书中实例
街头纠缠（抽样4）：叙述者明说"我不欢迎你"，斯特里克兰回答"老实说，我猜到了"，仍然跟着走，并反问"你以为我会在意你对我的看法吗"，让叙述者当场失语。这段对话本身就是全书的人物定义。
布兰奇的看护（抽样3）：她说过更讨厌他，却整夜守着病床，换床单、帮他洗漱；被问"他谢过你吗"，只答"没有"。她的沉默比台词更早预示后来的事。
画价的迟到（抽样5）：科恩先生说，当初连邮费都嫌贵，后来有绅士出三万法郎，"还没等冷静下来"就卖了。价值的诞生与判断力的缺席同时发生。

## A2｜何时调用 / 与相邻书的区分
- 当用户要判断一篇人物报道或传记的可信度时。
- 当用户写创作者题材，需要处理"作品好但人很坏"时。
- 当用户想拆解"天才叙事"如何为越界行为免责时。
- 与《堂吉诃德》同写执念：那本让执念撞上现实并付出喜剧代价，这本让执念穿过现实并被市场追认；同问"执念的代价谁付"，不同在结局是否被追认。

## E｜执行步骤
1. 输入：选一位你崇拜的创作者，列出你"知道"的关于他的五件事。
2. 动作：给每件事标注来源：本人、友人、对手、媒体、作品。
3. 动作：找出其中只由单一来源支撑、却被反复引用的一条。
4. 产出：一段二百字的"去魅版"生平，只保留可核实信息。
5. 验收：读完后仍能说出他作品的一个具体好处，而不是他的性格。

## B｜边界与误用
- 以高更为原型但大量虚构，不能当传记用。
- 女性人物多为主角的镜子或代价，直接引用会复制其性别盲区。
- "艺术家可以为所欲为"是人物逻辑，不是书的结论；毛姆用叙述者的软弱保留了反讽，容易读丢。
- 抽样跳过了巴黎中段，布兰奇事件的完整因果未核验。
