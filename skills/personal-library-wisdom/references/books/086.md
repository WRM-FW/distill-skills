# 《生死疲劳》 — 莫言
> 类型：文学 | 原文规模：约 24.5 万字 | 抽样依据（工作档案 udigest/086.md（6 段）

## 一句话
让冤魂依次投胎为驴牛猪狗，用牲畜的眼睛重算农村五十年的账。

## R｜原文骨架
- 第一章 驴折腾（第一—十一节）→ 西门闹被枪毙后转世为驴，写土改与合作社初起。
- 第二章 牛犟劲（第十二—二十节）→ 转世为牛，写单干户蓝脸与入社压力。
- 第三章 猪撒欢（第二十一—三十六节）→ 转世为猪，写大跃进、饥荒与猪场。
- 第四章 狗精神（第三十七—五十三节）→ 转世为狗，写改革后的县城、婚变与生意。
- 第五章 结局与开端 → 收束轮回，交代各人下场。
- 章回体对仗标题 → 每一节标题就是一句民间评书式的判词，把政治事件压成"折腾／犟劲／撒欢"。

## I｜核心命题与可执行方法
**畜生眼** —— 看叙述者此刻是什么动物 → 问："换成这个身体，哪件事第一次变得可见？" → 会看到：驴看得见发情与鞭子，猪看得见饲料、阉割与等级，狗看得见气味与私情。人被伦理遮住的部分，被动物的需求照亮。

**单干的理由** —— 看蓝脸拒绝入社时说的是什么话 → 问："他反对的是政策，还是某种具体的合账方式？" → 会看到：他不谈主义，只谈"亲兄弟都要分家，一群杂姓人，混在一起，一个锅里摸勺子，哪里去找好"——这是家产单位与劳动单位的冲突，不是觉悟高低。

**口号与民谚的兑换** —— 看干部说话用什么句式 → 问："这句政策话，被他换成了哪句土话？" → 会看到：洪泰岳骂人用"石头蛋子腌咸菜，油盐不进"，政策压力靠人身羞辱落地；陈大福则用"我这是工伤，公家要给我医疗费和营养费"，把身体换成票据。

**阉割的同构** —— 看动物被去势与人的失势如何并置 → 问："这一章里谁失去了什么器官或位置？" → 会看到：许宝阉猪与洪泰岳"使性失男体"同书出现，性与权力共用一套生理比喻，谁被割、谁动手，一目了然。

**作者入场** —— 看"莫言"以人物身份出现时在做什么 → 问："把他写进去，谁的可信度被削弱了？" → 会看到：这个"莫言"油嘴滑舌、蹭饭局、被众人调侃，等于作者自认在编故事，注意力被逼回"这是怎么说出来的"。

## A1｜书中实例
- 抽样第 1 段：洪泰岳上门动员蓝脸入社，迎春鞠躬打圆场，蓝脸答"我不入社！我也永远不会跪在地上求你"，洪泰岳回敬"总会有一天，你蓝脸要跪在地上求我"。
- 抽样第 2 段：西门金龙鞭打西门牛，牛"前腿一软跪在地上，就这样跪着，眼睛里的泪水，一串串地往下滴"；蓝脸扑上去护住牛头，抓碱土抹伤口，揪棉絮擦眼泪。
- 抽样第 4 段：许宝给刁小三阉割，血"像小喷泉一样往外喷涌"，金龙问要不要处理，许宝答"死掉？死掉不是正好吗？"；刁小三对猪十六说"今天的我就是明天的你"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写跨度几十年的村庄或家族史时。
- 当用户想找一个非人视角，绕开正面直述政治时。
- 当用户分析口号怎样变成日常辱骂与人身评价时。
- 当用户要处理"加害者也是受害者"的链条时。
- 与《蛙》同写高密东北乡与国家政策：一个用轮回把五十年摊开，一个用书信加话剧把一件事说两遍。
- 与《丰乳肥臀》都用身体承受历史，但这里的身体是借来的牲畜，所以能反复死、反复看。

## E｜执行步骤
1. 选一段历史（土改／合作化／包产到户） → 列出三个当事人的"单位词"（亩、工分、人头、指标） → 看谁用哪个单位说话。
2. 把同一场冲突改写成动物视角八百字，规定动物只能感知气味、饥饿、疼痛、等级，不能理解政策 → 验收：是否有一句"人话"漏了进来。
3. 收集十句干部话与十句民谚，做配对表 → 找出哪句土话承担了哪句政策的功能。
4. 通读初稿，删掉所有替读者下结论的句子，改成让当事人自辩。
5. 验收：能指出一处"动物生理细节"其实在给人类关系定性。

## B｜边界与误用
- 轮回设定使死亡失去重量，连续死亡会钝化同情，写作者慎用这套装置。
- 语言极度铺张，性、排泄、屠宰描写密集，不适合作为公文体或课堂朗读材料。
- 女性多落在身体与婚配的功能位上（迎春、秋香、合作），分析时须标明这是男性视角的分配。
- 章回体对仗是趣味也是遮蔽：复杂事件被压成四字判词，读者容易记住判词、忘掉过程。
