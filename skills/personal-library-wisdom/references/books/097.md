# 《流言》 — 张爱玲
> 类型：文学 | 原文规模：约 10.0 万字 | 抽样依据（工作档案 udigest/097.md（6 段）

## 一句话
用衣服、饭菜、看客和账目，拆解中国人怎样在被观看中学会替自己解释。

## R｜原文骨架
- 天才梦／到底是上海人／童言无忌 → 交代写作者的位置：一个被当作"天才"养大的孩子，把自嘲练成方法。
- 更衣记／穿／吃／公寓生活记趣 → 把时代变迁落到滚边、菜价、电梯和佣人身上。
- 烬余录 → 战争里的日常经济学：免考、买菜、调情、把一袋米扮成婴儿运出宿舍。
- 谈女人／论写作／自己的文章 → 给出写作主张：写日常琐事，不写英雄。
- 中国人的宗教（投胎／中国的地狱／好死与横死）→ 用民俗细节做国民性分析。
- 忘不了的画／谈音乐 → 训练感官：从一张脸、一支曲里读出阶级与处境。

## I｜核心命题与可执行方法
**无隐私透镜** —— 看门、窗纸、闹房、临终围观 → 问"这场景里有几双旁观的眼睛，他从哪一句开始解释自己" → 会看到"藉口"机制：不是虚伪，是被观看逼出的自我辩护。

**物质透镜** —— 看滚边、菜价、水电、佣人工钱 → 问"这东西多少钱、谁做的、坏了怎么修" → 会看到时代变动先落在布料和账单上，口号总是最后才到。

**乱世算术透镜** —— 看战时人怎样给自己记账 → 问"最坏的情况下他保住了什么、拿什么换的" → 会看到"饮食男女"是底线伦理，而不是堕落。

**反传奇透镜** —— 看作者怎样把一段传奇拆成若干看似无关的细节 → 问"删掉戏剧性之后还剩什么" → 会看到普通人物的苍凉：不是悲剧，是没赶上。

**面部透镜** —— 看画里一张脸的肌肉走向 → 问"这表情属于她还是属于她的位置" → 会看到阶级怎样长进人的脸上。

## A1｜书中实例
- 〈烬余录〉写港战：十二月八日正撞上大考第一天，学生"乐得欢蹦乱跳"，因为平白免考；困在港的外埠学生成天买菜、烧菜、调情，她由此得出"剩下的仿佛只有饮食男女这两项"。
- 同篇写医院院长担心"战争小孩"，看见女学生抱着长包裹溜出宿舍，以为噩梦成真，后来才知她把米扮成婴儿运出去换钱。
- 〈忘不了的画〉看赛尚夫人最后一张肖像：花园、礼拜天的衣裙、鲸鱼骨束腰，"然而背后的春天与她无关"；那张脸上的愉快"是没有内容的愉快"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析一段散文的"腔调"从哪来，需要拆句子背后的视角与人称时。
- 当用户想写城市生活与日常观察，却只会写情绪和判断时。
- 当用户要诊断"为什么中国人在公共场合总在解释自己"这类处境时。
- 与《夜谭十记》同写中国人的算计与场面，区别在：马识途写"事"，张爱玲写这些事在人身上留下的"姿势"和"口味"。

## E｜执行步骤
1. 输入一段自己的日常观察。动作：只写可见物——衣服、价格、光线、旁观人数，删去所有形容词判断。产出：一段"无观点"的白描。
2. 动作：在白描末尾补一句"在场的人怎样向别人解释这件事"。验收：这一句必须引出一句原话或一个藉口。
3. 动作：把这句解释与物质细节对照，找出"说的"和"用的"不一致处。
4. 产出：300 字分析，结论落在"他为什么必须这样解释"，而不是"他很虚伪"。

## B｜边界与误用
- 它不提供体系，只有散点；想要完整的社会分析框架会失望。
- 最易被误用成"民国小资情调"的摘句式阅读，把锋利的判断读成漂亮的比喻。
- 租界视角有盲区：对底层只有旁观式同情，对政治几乎不置一词；文中国民性判断是文学断言，引用时须降格为假设。
