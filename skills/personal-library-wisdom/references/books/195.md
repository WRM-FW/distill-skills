# 《月亮与六便士》 — 毛姆
> 类型：文学 | 原文规模：约 10.0 万字 | 抽样依据（工作档案 udigest/195.md（6 段）

## 一句话
用"传记作者"的口吻讲一个虚构天才，让你看清"天才豁免权"是谁发放的。

## R｜原文骨架
- 五十八章，第一人称：叙述者以作家身份追忆查尔斯·史特利克兰，从伦敦初识写到塔希提之死。
- 抽样覆盖：第二章自陈写作理由（"要不是战乱让我流落到了塔希提岛"）／巴黎酒馆里史特利克兰对妓女的冷漠／施特洛夫夫妇为是否接他回家养病争吵／勃朗什自杀后施特洛夫回到公寓／马赛—塔希提的街区与酒吧／库特拉斯医生看到壁画与尸体。
- 结构靠"证词"推进：叙述者不断引用别人的回忆、书信、医生转述，把虚构人物办成一桩考据。

## I｜核心命题与可执行方法
**证词的来源** —— 看每段信息怎么到叙述者手里 → 问"这是亲眼所见，还是别人说的？" → 会看到"我比大多数人都更了解他""我不记得是谁曾经说过"——考据口吻是给虚构上的保险。

**豁免权的发放** —— 看谁替越界者说话、用什么理由 → 问"这句宽容的话，代价由谁付？" → 会看到施特洛夫说"天才是世界上最值得珍惜的""我们对这样的人必须非常容忍"——最温柔的话，随后由他妻子用命来结账。

**清洗的仪式** —— 看暴力发生后留下的最后一个动作 → 问"她死前把什么收拾好了？" → 会看到勃朗什洗餐具、擦刀、挂好洗碗布、放下袖口——秩序感把自杀写成一次家务的完成。

**评估语言的失效** —— 看旁观者如何描述看不懂的作品 → 问"他用了哪些词，回避了哪些词？" → 会看到"很美，而又粗俗不雅""超越人类经验"——判断词在画前不够用，只剩敬畏与恐惧。

**欲望的地形** —— 看空间如何被分成体面与肮脏 → 问"同一个人在两处被怎样描写？" → 会看到从伦敦客厅到马赛街区，越往下走描写越具体：尘土、烟雾、喂奶的女人、托盘上的啤酒。

## A1｜书中实例
- 施特洛夫替史特利克兰辩护："天才是世界上最值得珍惜的。有天赋才华的人都是背负着沉重负担的。我们对这样的人必须非常容忍，非常有耐心。"他妻子回答："我永远也不会让他进我们的家门"。
- 勃朗什死后：施特洛夫在厨房看到餐具收好、奶酪盖上罩子、洗碗布还挂在门后的木钩上，随后她"拿起装满草酸的瓶子，走进了卧室"。
- 库特拉斯医生看画：他感到"一个人如果亲眼一睹混沌初开的景象也许会感受到的那种敬畏和欣喜"，最后说"我的上帝，这是个天才"，转头看见尸体，"他的眼睛已经瞎了"。

## A2｜何时调用 / 与相邻书的区分
- 要写艺术家/天才叙事，并检查它把成本记在谁头上时。
- 要用旁观者视角讲一个自己不在场中心的故事时。
- 要分析"宽容"话语背后的转移支付时。
- 与《大雪将至》同写不合群的男人：一个被解释过度，一个一句解释都没有。
- 与《蛇结》同写被厌恶的丈夫：那里由当事人自辩，这里由旁人代辩。

## E｜执行步骤
1. 给主角列一张"谁替他说话"的名单 → 每人格后写他付出的代价，验收：至少一人付的是钱以外的东西。
2. 把关键情节改成转述（"据某人的回忆"）→ 检查信息在哪一层开始失真。
3. 写死者最后三十分钟的家务动作，不写心理 → 验收：读者能从整洁程度读出决心。
4. 让一个专业人士面对他无法评估的对象 → 只写他找不到词的那几秒。

## B｜边界与误用
- 以高更生平为底，但人物、情节大量虚构，不能当传记引用。
- 女性角色多为功能位（被牺牲的妻子、被赠予的土著少女）；毛姆的"宽容"是叙述者的姿态，不是文本的结论。
- "月亮与六便士"的二选一被后来的读者简化成口号，原文对史特利克兰的冷酷并无辩护。
- 叙述者的俏皮话密度高，容易盖过文本的判断；引用金句时要说明是谁在说。
