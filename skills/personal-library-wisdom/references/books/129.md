# 《四合如意》 — 张怡微
> 类型：文学 | 原文规模：约 7.8 万字 | 抽样依据（工作档案 udigest/129.md（6 段）

## 一句话
十一篇都市男女的往来账，用来拆解客气话背后的钱、房、母女与平台。

## R｜原文骨架
- 全书十一篇，篇名全用曲牌：端正好、冉冉云、一春过、缕缕金、四合如意、步步娇、醉太平、锦缠道、字字双、寄生草、白观音 → 标题先提示读法：每篇是一支可独立听的小令。
- 各篇独立、人物不串；共同场景是上海与台北之间的城市女性：买房、离婚、再婚、母女、微信群。
- 抽样覆盖四路：阿梅与中介（买房、等房东离婚）、齐茜与"五人群"（艺术圈、婚姻）、茹意与盛明（异地夫妻、教育）、阿琳与母亲（房东催租、观音）。
- 叙述贴人物走，信息靠对话里的金额、平台名和停顿透出。

## I｜核心命题与可执行方法
- **账本式亲密** —— 看钱在什么时候被说出口 → 问"这笔钱谁付、记在谁账上、换什么" → 会看到感情用交易语言表述：十万服务费、十六块钱的星盘咨询、"比贞子卖得好"。
- **房子的证词** —— 看屋里的物件 → 问"谁在维护它，谁在等它解体" → 会看到五十几盆花由老太太浇、婚纱照没挂：婚姻状态写在谁浇花上。
- **群里的残骸** —— 看五个人怎么散 → 问"最后一次实质联络是什么" → 会看到"幽灵分手"：群还在、人也在，关系只剩红包与点赞。
- **母女互为编剧** —— 看母亲怎么教女儿说话 → 问"这句台词谁写的、演给谁看" → 会看到"母亲安排的剧本是，此时你多少还是要再问他要一些钱"：亲情里有导演、场记和观众。
- **求神的功用** —— 看拜观音的场面 → 问"求的是保佑还是家庭话语权" → 会看到观音断手、母亲甩耳光：信仰被编进母女债。
- **视频里的夫妻** —— 看异地婚姻的通道 → 问"消息延迟多久、经过几层平台" → 会看到"在腾讯会议室里告诉了丈夫"：亲密被降级为一次会议。

## A1｜书中实例
- 阿梅为等房东离婚，替中介搜集分居证明，还花十六块在星盘 App 上问"下半年离婚是否能顺利展开"；中介劝她"宁拆十座庙"，她回："他们离婚，最大的受益人，就是你啊小李。"（抽样1）
- 齐茜做完"一对用鱼线捆扎的乳房"，鱼线尽头是充电接口，可当床头灯；她说"听说这个作品卖得很好"，随后在腾讯会议上告诉丈夫。（抽样2）
- 茹意的学生写《旅行的意义》，结论是"还是卖玉石比较好玩"；盛明说这"比色情书要残酷多了"，因为孩子看见了"好几亿的王玉石"。（抽样3）

## A2｜何时调用 / 与相邻书的区分
- 当用户要写上海或台北的都市女性、写"体面的算计"时。
- 当用户分析婚恋市场里的房产、中介、平台抽成时。
- 当用户处理母女关系中的台词与表演时。
- 与《传奇》共用一本婚配账：张爱玲算聘礼、金饰、亲戚面子，张怡微算首付、服务费、流量；同问"婚姻怎么谈"，一个在沦陷前后，一个在平台时代。

## E｜执行步骤
1. 输入一段日常对话（母女、夫妻、中介均可）。动作：圈出所有金额、时间、平台名、地名。验收：能画出资金与信息的流向。
2. 动作：把每句客套话译成一句诉求（"我是为你好"→"你要按我说的做"）。产出：双栏对照表。
3. 动作：找出"谁在替不在场的人说话"。验收：能指认这句台词的真正作者。
4. 动作：用一件家具或一盆花替换全部心理描写，重写该段。验收：不写"她难过"，读者仍知道她难过。

## B｜边界与误用
- 城市中产经验为主，保姆、保安、快递只作背景，不能当阶层全景。
- 情节推力弱，靠细节与语气支撑；想找强故事的读者会落空。
- 冷静容易被读成刻薄；人物常自我合理化，别把她们的判断当结论。
- 平台与品牌（星盘 App、腾讯会议、湾仔码头）会过时，引用时需标年份。
