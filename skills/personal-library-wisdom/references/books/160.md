# 《玩偶之家》 — 亨利克·易卜生
> 类型：文学 | 原文规模：约 12.0 万字（中英对照） | 抽样依据（工作档案 udigest/160.md（6 段）

## 一句话
用客厅里的称呼、动作和沉默，测量一段婚姻里谁有权定义现实。

## R｜原文骨架
三幕剧，无章节标题，靠舞台指示推进：
- 第一幕 → 圣诞树、礼物、海尔茂查甜食；柯洛克斯泰上门，用借据要挟娜拉。
- 第二幕 → 娜拉周旋于丈夫、旧友林丹太太与债主之间，并说出"带坏孩子"的恐惧。
- 第三幕 → 舞会归来，信件被读，海尔茂先自保后翻脸，娜拉出走。
- 抽样覆盖上述三段，未含全剧结尾。

## I｜核心命题与可执行方法
**称呼降级** —— 看"小鸟""松鼠""甜牙小姐"出现在什么句子 → 问：称呼后面紧跟的是宠爱还是禁令 → 会看到亲昵词是管辖语法，越甜越界定权限。
**台词与动作的落差** —— 看括号里的舞台指示 → 问：身体在做什么，嘴在说什么 → 会看到谎言的证据不在台词，在动作的迟滞。
**法律与羞耻的错位** —— 看伪造签名这件事 → 问：违法与可耻是同一件事吗 → 会看到制度评价和道德评价各有一套，柯洛克斯泰被两边同时判刑。
**揭穿次序** —— 看海尔茂读完信先说什么 → 问：他第一句保护的是谁 → 会看到自私穿着"保护家庭"的外套出场。
**"奇迹"的内容** —— 看娜拉等待什么 → 问：她要的是被救还是被承认 → 会看到她的觉醒不是想走，而是发现对方不会承担。

## A1｜书中实例
查甜食（抽样1）：海尔茂用手指点着她问，甜牙小姐今天是不是在城里破了戒，娜拉连声否认。管束以调情的语气完成，拒绝的余地被事先取消。
撒谎的母亲（抽样3）：海尔茂断言"几乎每个有着不幸童年的犯罪都有一个撒谎的母亲"，又说孩子呼吸的空气里"充满了罪恶的细菌"。娜拉当场脸色发白，随后不肯见自己的孩子——审判词在她身上生效了。
奇迹（抽样6）：娜拉说她等了八年，确信丈夫会说"我是有罪的那个"；她等到的是海尔茂反问"那我岂不是要让你丢脸"。期待的落空不在事实，在这句话的先后顺序。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析一段亲密关系中的话语权力时。
- 当用户写剧本或短剧，需要"一封信推动全剧"的结构时。
- 当用户想区分"违法"与"失德"两套评价时。
- 与《菊与刀》同看规范：那本讲规范如何被内化为安全感，这本讲规范如何被一个人拿去审判另一个人；同问"人为什么服从"，不同在服从崩掉的那一秒。

## E｜执行步骤
1. 输入：挑一场两人对话，逐句标出称呼语、命令句、回避句。
2. 动作：旁注舞台指示，记录每次停顿、转身、抽手。
3. 动作：做"谁知道什么"表，标出信息差在第几句被打破。
4. 产出：把该场改成性别对调版，不改台词，只改称谓与动作。
5. 验收：对调后若多数台词仍顺畅，说明权力藏在称呼而非内容里。

## B｜边界与误用
- 1879 年的性别分工与法律背景，直接套用到今天会失真。
- 娜拉出走常被当作结论，其实只是问题的开始，剧作没有给出后续。
- 中英对照的英文经过简化，做文体分析须用完整译本。
- 海尔茂被写成观念载体，容易读成单纯的恶人，反而削弱诊断力。
