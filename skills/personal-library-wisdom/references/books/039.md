# 《拟像与拟真》 — 让·波德里亚（王睿琦 译）
> 类型：论说｜原文规模：约 7.7 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/039.md（6 段）

## 一句话
用"模型先于现实"判断一个东西还有没有原件。

## R｜原文骨架
- 拟像的旋进 → 总论：图像与指涉物脱钩后，现实如何变成模型的不在场证明。
- 拉美西斯，或玫瑰色的复活 / 超级现实和想象 / 《中国综合征》 / 《现代启示录》 → 用具体案例演示"复制先于原物"。
- 政治的咒语 / 现实的战略 / 全景视觉的终结 / 历史：一个复古的剧本 → 拟像进入政治与历史，民意与历史被预先编剧。
- 波堡效应，内爆与威慑 / 超市与超商品 / 媒体中的意义内爆 / 绝对广告 → 文化、消费与媒介的饱和。
- 克隆故事 / 全息图 / 剩余物 / 关于虚无主义 → 模型取代虚构，剩余物与价值终结。

## I｜核心命题与可执行方法
**原件追溯** —— 一个东西"像真的"却说不清出处 → 沿指涉链往回找原件：照片的原景、数据的原始记录、事件的现场 → 验收：若原件本身由模型生产，判为无参照拟像，并写出模型名称。

**超真实检验** —— 双方争论"这是不是真的"时 → 不问真假，问"哪个模型在生产它"：收视率、风险模型、卫星图、KPI → 验收：能指出模型如何反向规定现场行为，而不只是"被媒体夸大"。

**内爆诊断** —— 某领域投入越多、意义越少时（信息、展览、广告）→ 找哪组对立项塌缩（意义/媒介、公共/私人、真实/想象），找饱和点 → 验收：能解释为何加量不产生质变。

**保护即拟真** —— 看到"抢救、记录、建博物馆"时 → 问记录是否取代了对象，对象是否被要求按档案表演自己 → 验收：能指出保护行为如何参与对象的死亡。

**剩余物翻转检查** —— 边缘者、废弃物、疯子被推到舞台中心时 → 问这是结构倒置还是结构改变 → 验收：能区分"被压抑者回归"与"剩余物无处不在、不再剩余"。

## A1｜书中实例
- 塔萨代人（抽样1）：在被冷冻、绝育、保护之后，成为"对民族学之前的所有可能的印第安人进行拟真的模型"；勒克尔索的工人街区连同男人、女人和孩子被当场博物馆化。
- 波堡（抽样3）：文化被轧碎、绞扭、压缩成"最小的简单元素"，丁格利的自毁机器在博物馆里被防腐保存；建筑本身宣告"加速的循环和回收的时间性"。
- 太空与核模型（抽样2）：其目的不是登月或军事优势，而是"行星控制系统的模型向量"；让人眩晕的不是事件，而是程序与规范的完美。

## A2｜何时调用 / 与相邻书的区分
- 当用户遇到 AI 生成图、网红景点、真人秀，要判断"还有没有真的"时。
- 当危机公关、品牌叙事把事件改写成剧本时。
- 当指标、模型、档案开始替代现场，需要解释后果时。
- 与 059《消费社会》同看符号：波德里亚在此问"原件是否还存在"，在《消费社会》问"符号如何组织社会区分"。

## E｜执行步骤
1. 选一个"看起来真实"的对象，写下它声称指向什么。
2. 沿指涉链找原件：现场、原始记录、第一个版本。
3. 找生产它的模型：指标、剧本、算法、档案、展览说明。
4. 查模型是否改变现场：人是否按镜头、表格、评分表演。
5. 判定它处于哪一段拟像，并写一条反证：若原件出现，什么会改变。

## B｜边界与误用
- 1981 年的文本判断多、证据少，格言化，不能当经验研究引用。
- "大众沉默""意义内爆"等论断可证伪性低，容易变成不可反驳的预言。
- 最容易被误用为"一切皆假"的犬儒，反而放弃对具体模型与利益的追查。
- 中译术语多义（拟像/拟真/仿真），跨版本引用需核对原文。

## 金句
> 现实不能超过模型，它只是模型的不在场证明。
