# 《许三观卖血记》 — 余华
> 类型：文学 | 原文规模：约 7.9 万字 | 抽样依据（工作档案 udigest/011.md（6 段，另有一份同书重复副本）

## 一句话
把一家人的生死账折算成血量和价钱，看普通人怎样用身体结账。

## R｜原文骨架
- 中文版（再版）自序及韩、德、意版自序 → 各自说明这本书要写什么，属作者自述，与正文分开引用。
- 第一至七章 → 卖血的入门：瓜田里四叔讲“规矩”，阿方、根龙带许三观进城找李血头，卖血前喝水、憋尿。
- 第八至十九章 → 卖血换成赔偿与救命：一乐砸伤方铁匠的儿子，街上的流言把石头说成铁榔头；何小勇病危，陈家要一乐上屋顶喊魂。
- 第二十至二十九章 → 卖血变成连续作业：为二乐的前程请队长吃饭，为一乐一路卖血，途中教来喜、来顺“卖一次要歇上三个月”。
- 全书以“卖血”为节拍器，每次家庭危机对应一次抽血；抽样未覆盖小说结尾。

## I｜核心命题与可执行方法
**血量计价** —— 看每次危机里钱从哪来 → 问“这一笔是汗钱、血钱还是借来的钱” → 会看到家庭伦理被换算成可计量的身体：一次三十五块，抵地里半年。

**围观的传声** —— 看同一件事被转述几遍、每遍加了什么 → 问“消息在谁的嘴里变形” → 石头变成铁榔头、菜刀、钢针缝脑壳；暴力在流言里升值，恐惧被稀释成饭桌谈资。

**重复的差价** —— 看同一个动作第二、第三次的代价 → 问“这次卖血换来了什么，恢复期缩短了多少” → 苦难在叙述里被换成婚事、赔偿、前程；余华用重复代替抒情，让读者自己算账。

**口语谈判** —— 看人物怎样用比喻和数字讲理 → 问“他算的是钱、面子还是命” → “血跟井里的水一样”“这身上的血就是一棵摇钱树”；说服力来自算术，不来自道理。

**台面表演** —— 看人物在谁面前装派头 → 问“这顿饭吃给谁看” → 点菜敲桌子、黄酒要温一温、夫妻当面夸队长（心里清楚二乐天天骂他）；尊严靠表演维持，成本由血支付。

## A1｜书中实例
- 瓜田问答（第一章）：许三观在屋顶上问四叔，卖一次血挣三十五块，“在地里干半年的活也就挣那么多”；医院先抽一管血做检查，“这管血是白送给医院的”。他追问的第一件事是这管血给不给钱。
- 砸人之后（第八章开头）：方铁匠儿子的伤在街上被说出好几个版本——铁榔头、菜刀、钢针缝脑壳、“脑浆就像煮熟了的豆腐”；而正文写一乐用的是“一块三角的石头”。
- 做衣服那笔账（中段）：卖血得的三十元，二十一元五角做了衣服，许玉兰从剩下的八元五角里再贴两元，给许三观做中山服，说“这衣服是你卖血的钱做的”。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析“中国家庭如何用身体承担风险”时。
- 当用户写底层人物对话，需要让算账替人物说话时。
- 当用户想研究重复结构如何制造力量，而不是靠形容词时。
- 与《兄弟》同写身体换生存：本书的血还能标价（三十五元一次），《兄弟》里身体已改成商标（假乳房、处女来信）。与《在细雨中呼喊》相比，本书的苦难有账本，那本的苦难只有记忆的顺序。

## E｜执行步骤
1. 输入任选一章 → 列出本章所有金额与用途 → 产出“钱—事—人”对照表 → 验收：每笔钱都能追到出钱的人和他牺牲了什么。
2. 输入同一事件的两处叙述（砸人正文与街头流言）→ 逐句比对增删 → 产出变形清单 → 验收：能指出哪一句是转述者的加工。
3. 输入一次重复出现的动作（卖血、吃饭、送礼）→ 标出每次的差价与恢复期 → 产出代价曲线 → 验收：曲线应单调变差，否则说明选错了动作。
4. 写作训练：写 300 字，只许用对话与数字推进，不写心理 → 验收：读者能算出这家人的窘迫，却说不出作者的态度。

## B｜边界与误用
- 别把“卖血”读成奇观或国民性寓言：书里的血是特定年代缺现金时的融资手段，脱离公费医疗与农村现金短缺的背景就会读歪。
- “重复”容易被误学成啰嗦：每一次重复都必须带来差价，否则只是复读。
- 叙述者几乎不评判人物，不等于作者认同许三观的算计；把克制当冷漠是常见误读。
- 抽样覆盖第一、八章与中后段，结尾等章节未见，涉及结局的判断须另核。
