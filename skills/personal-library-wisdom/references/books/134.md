# 《圆圈正义》 — 罗翔
> 类型：论说 | 原文规模：约 9.7 万字 | 抽样依据（工作档案 udigest/134.md（6 段）

## 一句话
用「画圆」的姿态处理正义：承认画不圆，仍要一笔一笔量给人看。

## R｜原文骨架
- 代序"法律人的热点写作"＋《圆圈正义》《做一个勇敢的法律人》《在自恋中攀登仇恨的高峰》 → 提出圆圈隐喻与写作姿态。
- 《圆圈正义与安提戈涅》《从"刀把子"到"双刃剑"》《天生犯罪人》《法治的妥协》 → 法治、权力与妥协。
- 《枪支批复》的情理法／一朝犯罪是否终身受制／纪念一只越狱未遂的鹦鹉／下跪／狂人罗大拿 → 个案中的情理法。
- 道德谴责的打开方式／不要轻易向他人抡起道德的杀威棒／律师为什么喜欢为"坏人"做辩护 → 道德与辩护。
- 见死不救／路边的野草你不能采／舆论真能绑架司法吗／辱母杀人／莫某纵火与死刑／性侵犯罪与不同意 → 争议罪名。
- 致法学新人的三封信＋生命的尊严＋读书 → 职业伦理与阅读方法。

## I｜核心命题与可执行方法
**画圆法** —— 触发：有人说"现实就这样，别谈正义" → 动作：分开"圆的定义"与"画出的圆"，用应然量实然 → 验收：能同时说出判决错在哪、程序为何仍要服从。

**情理法三栏** —— 触发：案件引发众怒 → 动作：法律要件／民众情感／伦理评价各写一栏，标出冲突点 → 验收：结论能解释哪一栏被优先、为什么。

**道德杀威棒自检** —— 触发：想公开谴责某人 → 动作：先列自己的同类毛病，再问"我是在用道德替代法律吗" → 验收：谴责强度与证据强度匹配，不拿人品代替构成要件。

**辩护权反推** —— 触发：讨论"坏人该不该有律师" → 动作：把"他可恨吗"换成"取消辩护程序后，下一个被冤枉的是谁" → 验收：说清辩护权保护的是程序，不是人品。

**认识错误出罪** —— 触发：行为人确实不知道违法（采野草、摆射击摊） → 动作：问"这个错误他能否避免"，必要时由被告举证 → 验收：不能避免则不得科刑，判缓刑也不是折中。

**舆论与权力分离** —— 触发：分析舆情案件 → 动作：先找"谁有权决定"，再谈舆论 → 验收：不把"舆论干预"当终因。

## A1｜书中实例
- 聂树斌案：媒体跟进十多年，平反时作者"感到的只是悲凉"，因为关键人物未被追责；司法忌惮的不是舆论，是舆论背后的权力意志。
- 采"野草"的农夫与摆射击摊的小贩：若报道无误，都不能以犯罪论处；作者还补了一句，判缓刑也仍然是错的。
- "你能原谅这样的人渣吗"：先列迟到、虚荣、脾气、不懂装懂，最后揭出"这就是你啊"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要在具体案件里权衡情理法时。
- 当写评论容易滑向道德审判时。
- 当讨论律师伦理、舆论与司法时。
- 当法学生要找职业姿态时。
- 与《法律的悖论》：一个给价值排序，一个拆制度两难。
- 与《刑法罗盘》：一个谈姿态，一个谈罪名。

## E｜执行步骤
1. 选一个争议案件，写 100 字事实，删去形容词。
2. 三栏填：要件、情感、伦理。
3. 分别以控方、辩方、法官身份各写一段。
4. 找一条与自己结论相反的证据。
5. 验收：结论里既有法条编号，也有一句能说服非法律人的理由。

## B｜边界与误用
- 随笔体，论证不系统，引用需回原始判决。
- 道德主义倾向可能遮蔽制度与证据分析。
- 案例多为 2017 年前后热点，法条已变。
- "圆圈"是动员性隐喻，不是可操作标准。
