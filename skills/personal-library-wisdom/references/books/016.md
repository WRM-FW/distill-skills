# 《高性价比人生指南》 — 佚名
> 类型：论说 | 原文规模：约 39.7 万字 | 抽样依据（工作档案 udigest/016.md（6 段，另有一份同书 PDF 副本）

## 一句话
608 条建议逐条标价：花多少、换回什么、证据几分。

## R｜原文骨架
- 前言与「这本书想回答的问题」→ 27 个问题对应 27 节，从「不要早死」排到「人走了以后要办什么」，按性价比而非类别排序。
- 「四种资源」→ 寿命、时间与精力、金钱、人身自由；四本账各算各的，不互相折算。
- 「证据分级」→ A/B/C：有数字的 RCT、大队列或荟萃为 A，有研究但无数字为 B，经验共识为 C；608 条中 A 410、B 149、C 49。
- 「性价比档」→ 口径 × 收益量级（大/中/小）× 三项成本 → 极高 104 条、高 276 条、一般 228 条。
- 条目体例 → 成本 / 说人话 / 收益 / 证据等级 / 来源 / 备注六栏；第 6 节「反面清单」专列不该做的事。

## I｜核心命题与可执行方法
**证据定级** —— 触发：有人递来一条健康或法律建议 → 动作：问出处是 RCT、队列还是荟萃，要求给出 HR/RR 与 95% CI，再看样本口径 → 验收：能说出降了几个百分点、区间跨不跨 1；跨 1 就不算有统计学意义。

**口径隔离** —— 触发：几条建议要排先后 → 动作：先标口径（换寿命/换钱/换时间精力/换自由），同口径才放一起 → 验收：拒绝把“省 500 元”和“降 12% 死亡率”排进同一张表。

**性价比套档** —— 触发：决定这件事做不做 → 动作：写收益量级，再列三项成本（钱、时间精力、毅力），按“好处大且成本为零=极高”套 → 验收：给出档位与三项成本；记住档位本身只是 C 级判断。

**争议复核** —— 触发：某条结论看着过硬 → 动作：翻到“备注”找“争议”，核对人群与算法口径 → 验收：能复述它在什么人群、什么口径下成立，并给出一个反例。

**受益人分档** —— 触发：给别人建议或现场救人 → 动作：标好处落到①自己②直系③熟人④陌生人 → 验收：写到第④档必须同时写风险（被讹、二次伤害），且不与前三档合并计算。

**法条定位** —— 触发：涉及拘留、刑责、赔偿 → 动作：找法条编号与原文，区分“制度底线”与“结果保证” → 验收：能指出哪一步是权利、哪一步只是可能。

## A1｜书中实例
- 心梗后打流感疫苗：2571 人双盲试验，12 个月总死亡 2.9% 对 4.9%，HR 0.59（95% CI 0.39–0.89），证据 A；同一节的心血管死亡 RR 0.74、区间 0.42–1.30，作者注明“算不上有统计学意义”。
- 肠镜争议：NordICC 按“被邀请去做肠镜”的人算，结直肠癌死亡 0.28% 对 0.31%，RR 0.90（0.64–1.16）；作者据此说肠镜对死亡率的好处被高估，粪便检测的证据反而更硬。
- 自来水与瓶装水：北京第一阶梯水价 5 元一立方米，折 0.005 元一升；瓶装水按 1 元 500 毫升算是 2 元一升，差 400 倍；依据是 GB 5749-2022。

## A2｜何时调用 / 与相邻书的区分
- 当用户问“这条养生建议值不值得做、这东西要不要买”时。
- 当用户要给家人排体检、疫苗、保险的先后顺序时。
- 当用户想知道某件小事会不会把自己送进拘留所时。
- 与《自私的基因》同簇：本书管“外部证据怎么定级”，道金斯管“机制怎么反推”，一个判信不信，一个问为什么。
- 与《禅与摩托车维修艺术》：本书只算可量化的收益，禅处理不可量化的良质与注意力。

## E｜执行步骤
1. 输入一个具体困扰（如“血压高了要不要吃药”）→ 在 27 节里定位条目 → 抄下六栏 → 验收：成本、收益、证据等级齐全。
2. 输入 3 条候选建议 → 标口径 → 同口径内按量级与成本套档 → 产出排序 → 验收：没有跨口径比较。
3. 输入一条 A 级结论 → 找“争议/备注” → 写出适用人群与失效条件 → 验收：能说出一个反例。
4. 执行一条并设复盘点（三个月后量血压）→ 验收：有可测的前后数值，不是“感觉好些”。
