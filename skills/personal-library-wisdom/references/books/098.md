# 《晚熟的人》 — 莫言
> 类型：文学 | 原文规模：约 10.2 万字 | 抽样依据（工作档案 udigest/098.md（6 段）

## 一句话
把装傻、改名、汇报、调解当成乡土社会的四种谋生技术，逐一拆解。

## R｜原文骨架
- 目录十二篇：左镰／晚熟的人／斗士／贼指花／等待摩西／诗人金希普／表弟宁赛叶／地主的眼神／澡堂与红床／天下太平／红唇绿嘴／火把与口哨。
- 回乡线索（左镰、晚熟的人、斗士）→ "我"回乡后被旧识围住，被要求给面子、写文章、认人情。
- 乡场纠纷线索（天下太平、红唇绿嘴）→ 养猪场排污、上访户与村官的拉锯。
- 冒名与行骗线索（诗人金希普、表弟宁赛叶）→ 假诗人、假记者、野鸡报如何在本县运转。
- 死亡线索（火把与口哨）→ 三叔遇难后，"五七坟"前四个朋友与寡嫂幼子。
- 共同结构：叙述者始终是混出了名堂的同乡，每篇都是一次被索取、被请托的现场。

## I｜核心命题与可执行方法
**晚熟透镜** —— 看一个人在时代提速时故意慢半拍 → 问"他是真迟钝，还是把迟钝当资产" → 会看到"晚熟"是对政治节奏的套利：慢换取安全，再在市场时代一次性兑现。

**改名透镜** —— 看人物怎样给自己重新命名、挂牌 → 问"他借了哪个死人、哪段历史的光" → 会看到记忆商业化后的空壳：蒋二改成蒋天下，武功家世变成招商话术。

**汇报体透镜** —— 看对话里的"汇报—请示—表态"句式 → 问"这句话说给谁听、他要换什么" → 会看到民间话语里的权力预演：请吃饭是借口，汇报才是正事。

**调解现场透镜** —— 看基层干部怎么把是非换算成价格 → 问"最后定价多少、谁付、签了什么保证" → 会看到治理的算术：各出一千，加一句"永不上访"。

**见证人位置透镜** —— 看"我"被叫作"大哥""表叔"时答应了多少 → 问"他欠了谁、谁又欠他" → 会看到知识分子在人情网里的欠账，以及写作怎样被当作资源。

## A1｜书中实例
- 〈晚熟的人〉：蒋二在旧居前卖"我"的盗版书，被质问便指着十几个摊主说"都是他们干的"，随即请吃饭，理由是"吃饭是个借口主要是想向你汇报一下我的计划"；临走喊"今后不许再叫我蒋二我叫蒋——天——下"。
- 覃桂英与侯百利那桩纠纷：侯四被拍了一砖，开口索赔十万，村官夏顺生当场砍价，"你出一千块我出一千块"，让双方各签保证书，其中"有一条内容就是永不上访"。
- 一次采风接待：女镇长推销野生越橘饮料，被问"治秃头吗""壮阳不"，一律答"但要多喝"；同席的胡东年掏出三沓外币炫富。

## A2｜何时调用 / 与相邻书的区分
- 当用户要判断一个"成功人士"的自述里哪些是表演、哪些是实情时。
- 当用户处理基层纠纷、上访、邻里冲突，需要看懂"和稀泥"的价格结构时。
- 当用户写非虚构或乡土题材，需要"让各色人自己开口"的对话写法时。
- 与《尘埃落定》同写权力如何被继承与交易，区别在：阿来写制度坍塌的长时段，莫言写制度残余在个人身上的即时变现。

## E｜执行步骤
1. 输入一段某人向你"汇报计划"的原话。动作：标出所有称呼、许诺、请求，删去自我评价。产出：一张"他要什么"的清单。
2. 动作：追问他最近一次改名换招牌是什么时候，为什么是那时。
3. 动作：记录一场真实纠纷的收尾——谁赔多少、谁道歉、有无书面承诺。验收：写出"定价 + 担保方式"两项。
4. 产出：800 字场景写作，只允许人物说话和动作，叙述者不评论；读者应能自行判断谁在演。

## B｜边界与误用
- 十二篇水准不齐，回乡被围的框架重复；最易被误用为"乡村奇观"素材库，把活人读成段子。
- 叙述者的"我"是名人视角，只做短期回访，看不到长期生计，容易把结构问题写成个人品性。
- "晚熟"带作者自辩意味，直接当分析概念用会带褒义。
