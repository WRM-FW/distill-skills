# 《康德文集（注释版·全十册）》 — 伊曼努尔·康德（李秋零等译）

> 类型：合集 | 原文规模：约 288.3 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/145.md（6 段）

## 一句话
十册并置三大批判、实用人类学与历史评论，给出"先划认识边界、再谈应当"的操作顺序。

## R｜原文骨架
- 《纯粹理性批判》：先验感性论（空间、时间）→ 先验分析论 → 先验辩证论 → 先验方法论（训练、法规、建筑术、历史），解决"知识凭什么成立、越界在哪"。
- 《实践理性批判》：分析论（诸原理、对象、动机）→ 辩证论（至善）→ 方法论，解决"道德法则如何不被经验条件污染"。
- 《判断力批判》：审美判断力（美者、崇高者）→ 目的论判断力，解决"自然与自由之间如何搭桥"。
- 《实用人类学》：教学法分认识能力、愉快与不快的情感、欲求能力，解决"把范畴用到日常识人"。
- 历史评论与书评（抽样3 评赫尔德）：解决"个体幸福与类的发展谁优先"。
- 各卷前附科学院版编者导言与译者序，交代版本与术语，解决"先验/超验"这类词的中译分歧。

## I｜核心命题与可执行方法
**划界提问** —— 看任何"某物是什么"的断言 → 问"它是被给予的，还是仅被思维的" → 会看到显象与物自体一旦分开，越界断言立刻显形。
**形式剥离法** —— 看一个经验表象 → 问"除去感觉材料后还剩什么" → 会看到"广延和形状"这类纯直观形式，从而判明哪些知识不依赖经验。
**二律背反定位** —— 看两个都讲得通的相反命题 → 问"双方各自把哪条原则推到了经验之外" → 会看到冲突源于理性的越界，不是事实之争。
**准则普遍化检验** —— 看一条行为准则 → 问"它能否被意愿为普遍法则" → 会看到"为自己开例外"的准则在普遍化时自我取消。
**合目的性类比** —— 看一个对象 → 问"它是否显得'仿佛为某目的而安排'" → 会看到审美与目的论只是反思判断力的视角，不构成知识。
**人类学的经验校正** —— 看一条人性判断 → 问"它在哪个阶层、性别、处境下失效" → 会看到康德自己以"妇女、教士和犹太人"的清醒克制作例（抽样5），也暴露其时代偏见。

## A1｜书中实例
- 《纯粹理性批判·先验感性论》第1节：从物体表象中除去实体、力、可分性，再除去不可入性、硬、颜色，"还给我剩下了某种东西，即广延和形状"（抽样4）。
- 同书辩证论论先验客体：它"等于X"，只作为统觉统一性的相关物，不是知识对象（抽样1）。
- 评赫尔德：以塔希提岛居民为例反问"他们究竟为什么存在"，主张类的前进优先于个体幸福（抽样3）。

## A2｜何时调用 / 与相邻书的区分
- 当用户问"这个说法是不是超出了经验能支持的范围"时调用。
- 当要判断一个道德主张能否普遍化时调用。
- 当两个相反结论都言之成理、需要找出共同预设时调用。
- 当要辨析"先验/超验""显象/现象""本体/物自体"等译名时调用。
- 与《会饮篇》卡同问"什么是X"：柏拉图用对话逼出定义，康德先问"X 能否被认识"，再决定要不要谈定义。

## E｜执行步骤
1. 输入：一个断言（如"人天生自私"）。动作：判定它是分析还是综合、先天还是后天。产出：判断类型标注。
2. 动作：找出它依赖的直观形式与范畴，写明"在什么条件下才有对象"。产出：条件清单。
3. 动作：检查是否把只对显象有效的结论用到了物自体。产出：越界标记。
4. 动作：若属实践命题，改写为准则，做普遍化检验。产出：通过／自我取消的判定。
5. 动作：输出"可以说／不可说"两栏，并注明依据的批判卷次。产出：一页判据表。

## B｜边界与误用
- 术语密集且中译不统一，直接引用"先验"二字极易与原意错位，须连英文或德文并记。
- 三大批判不能当通俗读物顺读；抽样覆盖感性论、辩证论、人类学与书评，实践理性批判、判断力批判正文未取样。
- 书中的种族、性别判断属十八世纪局限，可作史料，不可作论据。
- 最易误用：把"不可知"当成"不存在"，或用"二律背反"为任何骑墙结论开脱。
