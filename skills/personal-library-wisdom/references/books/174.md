# 《刑法罗盘》 — 罗翔
> 类型：论说 | 原文规模：约 8.4 万字 | 抽样依据（工作档案 udigest/174.md（6 段）

## 一句话
拿热点案件练「要件—解释边界—权力自缚」三步，识别口袋罪与机械司法。

## R｜原文骨架
- 软暴力与黑社会（使用"软暴力"就一定是黑社会吗）→ 非法拘禁的时间标准与两份司法解释的冲突。
- 药神／假药门槛／第一百四十九条／走私初犯免责／气瓶是不是枪 → 行政标准与刑法构成要件的关系。
- 乘客与司机互殴／"不等于不"／先强奸后恋爱／聚众淫乱／房思琪／盲山／传播艾滋病 → 性犯罪与公共安全。
- 流氓罪消而不亡／寻衅滋事存废／网络发帖 → 口袋罪的谱系。
- 警察与律师／刑讯逼供追诉时效／少年司法／域外犯罪／996 → 程序与职业伦理。
- 结构：单篇评论结集，每篇一个争议点，常落到"权力也需被约束"。

## I｜核心命题与可执行方法
**标准先看前提** —— 触发：解释给出"十二小时""三次以上"这类数字 → 动作：还原它的适用前提（是否限于有组织地多次短时间拘禁），冲突时用举重以明轻 → 验收：能把数字重新绑回前提，而不是见数就套。

**行政标准≠构成要件** —— 触发：气瓶是否枪支散件、假药是否假药 → 动作：先问刑法条文保护什么，再看行政规范是补充还是替代 → 验收：说出"违反行政规范"与"符合构成要件"的差额。

**口袋罪三查** —— 触发：想用寻衅滋事、流氓罪一类兜底罪名 → 动作：查行为类型是否明确、兜底条款是否模糊、"情节恶劣"有无标准 → 验收：三项有一项含糊，就不能入罪。

**同意标准** —— 触发：性侵案件 → 动作：把"她没说不"改成"她是否给出有效同意" → 验收：能处理举证责任与认识错误，不只盯着有无反抗。

**因果分层** —— 触发：多因一果的公共安全事故 → 动作：分条件、相当因果、归责三层 → 验收：每层一句，不跳层，不把"都有错"当结论。

**权力自缚检验** —— 触发：任何扩张解释 → 动作：问"同一逻辑能否用到我身上" → 验收：能举出一个反噬案例。

## A1｜书中实例
- 公交坠江：刘某两次持手机攻击司机，冉某放开方向盘还击，互殴致车辆坠江；作者认为乘客符合以危险方法危害公共安全罪，司机不宜以故意犯罪论处。
- 马某某流氓案：组织家庭舞会，1983 年"严打"收监，陆续抓审三百多人，1984 年结案，三人死刑立即执行。
- 套路贷律师案：司机有三个选项——勇敢拒绝、开去派出所、继续开车，作者选第三项。

## A2｜何时调用 / 与相邻书的区分
- 当用户拿热点案件问"定什么罪"时。
- 当要识别口袋罪与机械司法时。
- 当写辩护意见、找构成要件缺口时。
- 当讨论性同意、少年责任年龄时。
- 与《法律的悖论》：一个给悖论框架，一个给个案操作。
- 与《圆圈正义》：一个谈罪名技术，一个谈职业姿态。

## E｜执行步骤
1. 摘事实：只留行为、结果、主观明知。
2. 列罪名，逐个拆构成要件。
3. 查解释边界：词义射程、行政标准、兜底条款。
4. 写控辩两版结论，各找一条反例。
5. 验收：指出本案最容易被滥用的那个解释，并说明反噬后果。

## B｜边界与误用
- 评论结集，事实以报道为准，不能当判决书。
- 废除寻衅滋事等是学理倡议，不是现行法。
- 写作时点约 2020 年，法条与解释已有更新。
- 修辞情绪强，引用时要剥离。
