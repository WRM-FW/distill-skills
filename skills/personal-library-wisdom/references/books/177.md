# 《解忧杂货店》 — 东野圭吾
> 类型：文学 | 原文规模：约 9.7 万字 | 抽样依据（工作档案 udigest/177.md（6 段）

## 一句话
把"给建议"拆成一套装置：看一封信如何跨两个时代，改变的是谁的时间。

## R｜原文骨架
- 五个故事由一间废弃杂货店串起：三个闯空门的小偷（敦也、翔太、幸平）在店内收到三十年前的信。
- 抽样覆盖：三人推断"咨询还在继续"／克郎回家为父亲守夜、仍要走音乐路／浪矢雄治把"遗书"交给儿子贵之、要求三十三周年忌日复活咨询窗口／浩介一家连夜潜逃、他坚持带走一整箱披头士唱片／"迷途的小狗"晴美白天上班晚上陪酒／皆月谈丸光园与浪矢雄治。
- 结构手法：两个时区靠牛奶箱与卷帘门对接，一章一个求助者，最后用丸光园把线收拢。

## I｜核心命题与可执行方法
**信的往返** —— 看一封信从写到回经过几个人、跨多少年 → 问"这封信真正改变的是谁的时间？" → 会看到建议在写信人不知情时才生效：回信者与受益者从不见面。

**建议的错位** —— 看求助者实际采纳了哪一句、忽略了哪一句 → 问"她是被说服，还是被允许？" → 会看到"迷途的小狗"要的不是职业规划，是一个可以辞职的许可；回信的功能是发许可证，不是给方案。

**知道未来的盲区** —— 看掌握信息的人在哪里判断失误 → 问"他能报出事件，能不能读准人？" → 会看到三个小偷知道泡沫与互联网，却仍用"这种蠢女人"的尺子量一个十九岁女孩。

**延迟的指令** —— 看谁在替死后做安排 → 问"这条指令为什么必须等三十三年？" → 会看到雄治要的是"当年的回信有没有帮到人"的答案，把评价权交回当事人，而不是留一句遗言。

**善意的暗线** —— 看两个看似无关的机构在哪一句被接上 → 问"这条线是谁替谁埋的？" → 会看到丸光园与浪矢杂货店的旧关系，善意被写成一条不回头、不索取的传递链。

## A1｜书中实例
- 雄治交给贵之的信："当我的三十三周年忌日快要到来时"，请他以某种方式公告"浪矢杂货店的咨询窗口将会复活"，并要对方先发誓照办。
- 浩介在潜逃前清点行李，唯一坚持的是"这个也绝对要带走"——一整箱披头士唱片；父亲问他"你对爸爸是怎么看的？"
- 晴美化名"迷途的小狗"来信，说想辞掉粉领工作专心陪酒；敦也的第一反应是"叫她别猪油蒙了心"，翔太说"要是话说得太重，反而会引起反弹"。

## A2｜何时调用 / 与相邻书的区分
- 要设计跨时空叙事、又不想写成科幻时。
- 要写"给建议"的场景，需要区分"给方案"与"给许可"时。
- 要分析善意如何被误读、又如何绕回来时。
- 与《月亮与六便士》同写抛下现有生活去追一件事：毛姆让社会审判他，东野让未来的陌生人替他辩护。
- 与《从前我死去的家》（同作者，见东野合集卡）同用物证重建过去：那本靠日记与票据，这本靠信。

## E｜执行步骤
1. 画一张双时区年表 → 每条建议标"写出年""被读年""见效年"，验收：至少有一条见效时写信人已不在场。
2. 给每个求助者写两版回信：一版给方案，一版只给许可 → 比较哪版被真正执行。
3. 让回信者掌握一条未来信息 → 再写他因此犯的一个错，错必须出在道德判断而非事实。
4. 设计一件延迟三十年才执行的指令 → 说明它要收集什么答案，验收：目的不是控制，是求证。

## B｜边界与误用
- 结构高度依赖巧合，人物心理常为接线让路；别把"每个人都恰好被接住"当现实模型。
- 对陪酒、风俗业的判断带一九八○年代日本道德预设，直接搬到今天会失真。
- 浪矢式的全知善意不可复制；小说的逻辑是叙事逻辑，不是咨询方法。
- 时间线交错，改编或引用前须先画年表，否则会把两代人的因果接错。
