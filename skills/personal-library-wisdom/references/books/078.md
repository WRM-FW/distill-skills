# 《愤怒的葡萄》 — 约翰·斯坦贝克（王一凡 译）
> 类型：文学 | 原文规模：约 21.9 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/078.md（6 段）

## 一句话
把贫困写成采购单与分餐动作，示范如何让阶级处境在物与人称里显形。

## R｜原文骨架
- 无章节标题，乔德家的迁移主线与路上临时相遇的人物（传教士凯西、独眼男人、营地流民）交替出现，每遇一人就打开一种处境。
- 凯西线 → 解决"宗教语言失去权威之后还剩什么"。
- 家庭重聚与"家庭政治大会" → 解决"迁徙中的决策由谁做"。
- 修车、打零工、宿营地 → 解决"没有地址的人如何被雇佣与驱赶"。
- 采购与分餐段 → 解决"钱不够时按什么顺序满足谁"。
- 营地舞会段 → 解决"一无所有的人如何维持体面"。

## I｜核心命题与可执行方法
**采购单里的优先级** —— 看每笔支出旁的犹豫。妈买三磅排骨、一块炖牛肉、一瓶牛奶给怀孕的罗莎夏，爸想加一罐糖浆，露西举着两盒五分钱的爆米花。问：谁的需求被排在最后，谁的被说成"浪费"。会看到贫穷不是形容词，是一串当场做出的取舍；尊严藏在"给她买牛奶"这种非必需项里。

**人称的滑动** —— 看叙述何时从"这家人"滑到"流民""人们"。问：一句话的主语从具体姓名换成集合名词，是在哪个动作之后？会看到政治化不是靠议论完成的，是靠语法：当一个家庭的饭锅前站满别家的孩子，单数就撑不住了。

**去神圣化的传教士** —— 看凯西如何拆自己的台。他把女人称作"圣器"，又把"罪孽"与"滥交"分开追问，最后承认"每一次，我还是要跟女孩子去做爱"。问：他保留了哪套词、抽走了哪种权威？会看到宗教语言被留用，神职身份被清空，剩下一个会自责的普通人。

**施舍的脸面技术** —— 看妈怎样把锅端到帐篷外。她说"我把剩下的菜分给你们"，让每个孩子去找一块木片来盛。问：施舍者做了哪个动作来避免对方像乞讨？会看到分配不只是给东西，还要给对方一个可以接受的理由和姿势。

**硬汉式去可怜化** —— 看乔德对独眼男人说的话："你就是喜欢自己可怜自己。"问：这句是救助还是羞辱？会看到它同时干两件事：逼人自救，也把结构性困境说成个人态度。

## A1｜书中实例
开篇凯西自述：他传教时心里会说"上帝为证啊，这次我不能再干那种事了"，可就在心里这么说的时候，"我就知道我还会干"。乔德则说自己从不想这些，"只要能抓到机会，我就高兴"。两种自我解释并排放着，谁也没说服谁。

营地分餐段：一群孩子站在锅边，目光跟着勺子从锅到盘子再到约翰伯伯的嘴。妈把盘子递过去，说"我不能赶他们走"，又对自家孩子喊"拿着你们的盘子，快点儿到帐篷里面去"。

公路边修车段：独眼男人反复说瞎了一只眼找不到工作；乔德回他"你还有一只眼睛睁得大大的呀"，并举一条腿的妓女和驼背为例。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写贫穷、迁徙、零工经济，需要把宏观处境落到具体账单上时。
- 当用户分析"集体"如何在小说里生成，需要看人称而非口号时。
- 当用户处理底层互助与底层互害并存的场面，需要不站队的观察点。
- 与《鼠疫》同写灾难中的普通人，差别在：加缪看行政与统计如何消化灾祸，斯坦贝克看一个家庭如何在路上被重新定义；一个写城市，一个写公路。

## E｜执行步骤
1. 摘出一段消费或分配场景 → 列出所有价格、数量、物品 → 标出谁提出、谁否决 → 产出"家庭预算优先级表"。
2. 在同一段里圈出人称代词 → 统计"我们/他们/人们"的切换点 → 判断切换发生在哪个动作之后。
3. 找一段施舍或互助 → 记录给予者说了哪句话来保全面子 → 改写成一笔不带话的转账，比较效果差异。
4. 找一段励志式劝告 → 把它拆成"事实判断"与"态度指责"两栏 → 验收：能否说出哪一栏在替结构开脱。
5. 用三百字写一个只有物、钱、动作、没有形容词的贫困场景 → 交给他人读，看能否复述出这家人的优先级。

## B｜边界与误用
- 不提供经济分析框架；书里的账单是经验材料，不能替代对租佃制、移民潮的研究。
- 最容易被误用为励志文本：乔德那套"别自怜"的话有力量，也有把结构问题个人化的危险。
- 女性角色多由妈承担道德重量，罗莎夏的转变在抽样中只见开端，不宜据此谈全书性别观。
- 一九三〇年代的加州农业背景与今日差别很大，直接套用于当代零工经济需重新校准。
