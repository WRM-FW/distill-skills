# 《时生》 — 东野圭吾
> 类型：文学 | 原文规模：约 9.8 万字 | 抽样依据（工作档案 udigest/028.md（6 段）

## 一句话
让儿子回到父亲的失败年代，把“生下你值不值”这个问题反过来问。

## R｜原文骨架
- 现在线 → 病房外，宫本与丽子守着重病的时生，"生下他，你后悔吗"被摆到桌面上。
- 过去线 → 年轻拓实在东京混日子：面试迟到、打弹子、被千鹤分手。
- 交汇线 → 时生以同龄人身份出现，催他面试、赎当、去见生母，用陪伴替代说教。
- 素材章节标题只标到"第一章"，抽样中可见节号 17 等，分章结构无法核对。

## I｜核心命题与可执行方法
**因果倒置** —— 看谁在照顾谁 → 问："如果被救的人后来才成为救人者的父亲，这笔账怎么算？" → 会看到：时生的唠叨占着父辈位置，拓实反而是被管的孩子。

**生育的追问** —— 看父母自问的那句话是对谁说的 → 问："'他幸福吗'是在问孩子，还是在替自己求赦免？" → 会看到：丽子说想问却"问不出口"，因为答案只能由无法回答的人给。

**自尊的账本** —— 看拓实每一次撒谎的场合 → 问："他骗的是千鹤，还是那个应该体面的自己？" → 会看到：面试、弹子房、藏桌下，记的是同一笔账，亏空越来越大。

**信息差的重量** —— 看读者知道而人物不知道的部分 → 问："这句普通话在读者耳里为什么变重？" → 会看到：悬念不靠案件，靠称谓与身份的双关。

**笨功夫** —— 看人物靠什么破局 → 问："他用了什么不聪明但有效的办法？" → 会看到：跑旧书店查漫画家、在当铺外数客人，胜负由耐心而非机敏决定。

## A1｜书中实例
- 病房外（抽样1）：宫本问“不后悔吗”，丽子回答“我想问问那孩子”——“有没有‘来到世上真好’的感觉？幸福吗？恨不恨我们？可我问不出口。”
- 面试（抽样2）：拓实把千鹤借给他的钱输在弹子房，迟到后被白发老者训："警卫这工作，严格遵守时间是个绝对的条件。"
- 分手（抽样6）：千鹤说自己拿面试当赌注——"只要你好好地面试，哪怕不被录用，我也会立刻和冈部一刀两断。"

## A2｜何时调用 / 与相邻书的区分
- 当用户想分析亲情叙事如何安排信息差时。
- 当用户写穿越或返乡题材，需要让设定服务于关系而不是奇观时。
- 当用户想检查自己的"失败叙事"里有没有靠撒谎维持的自尊时。
- 与《局外人》同写病床前"该不该哭"：加缪拒绝给解释，东野把解释给足——一个让人不安，一个让人释然。

## E｜执行步骤
1. 列出时生每一次"多管闲事" → 标注它替代了哪种父亲功能 → 产出"功能错位表"。
2. 找出拓实所有撒谎场景 → 记录当时说给谁听、自己损失了什么 → 看是否同一模式。
3. 抽掉一条信息差（让拓实一开始就知道时生身份）→ 重写一场戏 → 比较张力损失。
4. 验收：每条结论有具体场景，不用"感人""温暖"充当论据。

## B｜边界与误用
- 时间旅行设定不解释机制，不能当科幻文本推演。
- "绝症＋亲情"的结构会预置情绪，做分析要区分"我被感动"与"文本给了证据"。
- 素材只标出"第一章"，全书章节结构无法核对，结构描述以抽样为限。
- 对女性的写法（千鹤以婚姻为退路、淳子"腰背挺得笔直"）带类型小说套话，引用时须标明。
