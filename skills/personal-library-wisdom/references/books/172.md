# 《大雪将至》 — 罗伯特·泽塔勒
> 类型：文学 | 原文规模：约 4.0 万字 | 抽样依据（工作档案 udigest/172.md（6 段）

## 一句话
把一个人的一生交给寒冷来计时：看身体、物件与沉默怎么替他说话。

## R｜原文骨架
- 全篇无章节标题（抽样所见为连续叙述），按时间推进：山村童年与瘸腿 → 与玛丽的短暂共同生活 → 缆车工程与战争 → 被俘 → 归来做山地导游 → 独居终老。
- 每一段由一处场所定调：背椅与风雪、茅草屋与菜地、缆车营地、战俘的木箱、村口井边的招牌。
- 叙述用极短句，时间跳跃处不提醒读者，也不解释人物动机。

## I｜核心命题与可执行方法
**寒冷的计时器** —— 看时间被什么标记 → 问"这段跳过了几年，作者用什么替代了年份？" → 会看到雪化、燕子衔虫、雪下洋葱爆开：一生由物候计量，不由事件计量。

**沉默的替换** —— 看对话里谁不说话 → 问"这处沉默顶掉了哪一句本该说的话？" → 会看到艾格尔与玛丽"本来也很少交谈"，感情全由动作承担：迈一大步、把目光移走、用鞋尖在冻土上打钻。

**物件的维修史** —— 看反复出现的物件存在多久、谁在修 → 问"这件东西的寿命比人长还是短？" → 会看到茅草屋要刷漆、平底锅要用砂纸磨、手杖要用皮革缠——一生被写成一份保养记录。

**敌人的一个动作** —— 看战争段落给敌方几个镜头 → 问"作者让敌人做了什么具体的事？" → 会看到俄兵擦汗、转身、爬走、一次没回头；敌意消失后剩下的是"比之前更深的孤单"，不是胜利。

**死亡的拟人** —— 看民间说法怎么安置死亡 → 问"这个说法替人物解决了什么麻烦？" → 会看到"寒冷的女人"没有脸也没有声音，来去不解释——死亡被写成过路人，既不审判也不安慰。

## A1｜书中实例
- 羊角汉斯在背椅里讲"寒冷的女人"："她想来就来，需要什么就拿走什么；她没有脸也没有声音。"讲完他解开绳结爬出椅子，任自己站在风雪里。
- 玛丽第一次叫他的名字"安德里亚斯"，艾格尔"感觉有点奇怪"——此前她从不提他的跛脚，一个字都没有。
- 战后罗什科维奇夫妇雇他带路一星期，他在村口井边立招牌：第一行"喜欢大山的人"，第二行"找我就对了"，下面列出"确保看到日落（在山谷，山上太危险）"。

## A2｜何时调用 / 与相邻书的区分
- 要写一个人的一生，但不想用大事记串起来时。
- 要处理"创伤之后没有复原、只是继续生活"的人物时。
- 要练习"用物候和动作替代心理描写"时。
- 与《月亮与六便士》同写一个不合群的男人：毛姆不断替主人公解释，泽塔勒一句解释都不给。
- 与《蛇结》同写孤独的晚年：莫里亚克让老人滔滔控诉，这里让老人对自己的手杖说话。

## E｜执行步骤
1. 选一个你想写的人，列出他一生待过的五个场所 → 每个场所只留三件会被他反复摸到的东西。
2. 把这些东西按"谁修、修了几次、最后坏在哪"排成一条线 → 这条线就是时间轴，验收：不出现年份也能读出跨度。
3. 给他写三段独白，全部说给物件听，不许直接写情绪词 → 验收：读者能从他话题的偏移判断情绪。
4. 安排一次与"敌人"的相遇，只给对方三个动作、零句台词 → 验收：读者说不出对方是好是坏。

## B｜边界与误用
- 抽样无章节标题，无法核对全书结构与结局，卡片只覆盖六个连续片段。
- 第三人称极度克制，不等于作者赞同艾格尔的自我封闭；把沉默当美德来模仿，会写成一片空白。
- 山村、缆车工程、二战被俘有具体历史背景，不能当隐喻随手挪用。
- 短句节奏是中译本的产物，引用时不要拉长成复句。
