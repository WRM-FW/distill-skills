# 《安娜·卡列尼娜》 — 列夫·托尔斯泰
> 类型：文学 | 原文规模：约 38.4 万字 | 抽样依据（工作档案 udigest/176.md（6 段）

## 一句话
用"场合—身体—目光"三件套，读出社交场上每句话背后的价格与位置。

## R｜原文骨架
- 全书按部、章编号（抽样所见标题多为数字，仅见"死亡"等少数题名），双线并行：安娜—渥伦斯基的婚外情，列文—吉提的婚姻与农事。
- 抽样覆盖六场面：奥勃朗斯基与列文在餐厅点菜（第一部）／渥伦斯基赛马前在马厩（第二部）／列文在斯维亚日斯基家被小姨子的领口困住／安娜与戈列尼谢夫访画家米哈伊洛夫（第五部）／列文赶走瓦先卡（第六部）／米亚赫卡娅公爵夫人讲朗多（第七部）。
- 组织原则不是情节推进，而是"场合轮换"：餐厅、马厩、画室、客厅各有一套说话规则。

## I｜核心命题与可执行方法
**场合的语法** —— 看一场戏发生在哪里 → 问"这个场合允许说什么、禁止说什么？" → 会看到点菜的等级（鞑靼人的殷勤、牡蛎的产地、二十个还是三十个）先把人的社会坐标标好，后面的话才有重量。

**身体的泄密** —— 看台词与身体反应是否一致 → 问"哪一处身体动作拆穿了这句话？" → 会看到列文"无论自己往哪里看，都会看到它"；渥伦斯基用"把头发剃短些"的玩笑遮住秃顶——身体总比意识先说。

**目光的账本** —— 看谁在看谁、谁有资格看 → 问"这一节里，目光是给出去的还是收回来的？" → 会看到安娜"早就小心翼翼地同渥伦斯基交换过眼色"，社交场是一套精确的目光经济。

**琐事里的道德算术** —— 看人物怎么处理小事（点菜、粉刷、赶客） → 问"这件小事暴露了哪种公平观？" → 会看到列文赶人时喊"我丝毫没有过错，我干吗要受折磨"——嫉妒被写成对公正的索赔。

**传闻的转速** —— 看关键信息经几层转述 → 问"这句话到说话人嘴里，已经过了几个人？" → 会看到朗多的来历被公爵夫人一口气讲完，包括他如何被收作干儿子——上流社会的判断建立在传闻的流通速度上。

## A1｜书中实例
- 餐厅一场：奥勃朗斯基"手指停在菜单上，脸上露出煞有介事的犹豫神色"，问牡蛎是否新鲜，然后把计划从二十个改成三十个；列文只要"菜汤和粥"。
- 访画室一场：安娜"早就小心翼翼地同渥伦斯基交换过眼色"，知道他对画家的教育不感兴趣、只想接济他，于是打断戈列尼谢夫的长篇议论，说"我们去会会他吧"。
- 赶客一场：列文一边掰断手杖、一边用"又轻又慢"的声音请瓦先卡离开，理由是"离开这里对他来说不是很痛苦的事"。

## A2｜何时调用 / 与相邻书的区分
- 要写多人场面、需要给每个人分配"能说的话"时。
- 要分析一段对话里未说出口的部分时。
- 要判断一个人物的道德立场，而作者不给结论时。
- 与《蛇结》同写婚姻里的恨：莫里亚克只给一个人的嗓子，托尔斯泰给双方身体、场合与目击者。
- 与《月亮与六便士》同写"越界者"：毛姆让叙述者表态，托尔斯泰让宾客的闲话替社会表态。

## E｜执行步骤
1. 选一场你想写的冲突 → 先定场所，再列这个场所的三条明规则、两条潜规则。
2. 给每个在场者写一句"他真正想说的"和一句"他实际说的" → 两者之间必须差一个社会等级。
3. 加一个与台词相反的身体动作（手在抖、眼在看别处、手指停在菜单上） → 验收：删掉台词，动作仍能读出立场。
4. 把关键信息改由第三个人转述 → 验收：信息失真一处，且失真方向符合转述者的利益。

## B｜边界与误用
- 抽样集中在社交与家庭场面，安娜线后期、列文的农事与信仰线几乎未覆盖，不能据卡片判断全书结构。
- 人名译法不统一（渥伦斯基／弗龙斯基、吉提／基蒂），跨译本引用须先统一。
- 托尔斯泰的判断藏在叙述节奏与谁被给镜头里，摘句当格言会丢掉反讽。
- 19 世纪俄国贵族社会的前提（离婚、名誉、教规）不适用于今天，做类比时要显式标注。
