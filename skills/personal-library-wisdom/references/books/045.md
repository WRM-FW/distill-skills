# 《阿Q正传》 — 鲁迅
> 类型：文学 | 原文规模：约 1.6 万字 | 抽样依据（工作档案 udigest/045.md（6 段，含注释）

## 一句话
拆解一套当场生效的自我补偿算法：受辱之后，人怎样把账重新算成自己赢。

## R｜原文骨架
- 第一章 序 → 传主的姓名、籍贯、行状都无从考据，只能用“洋字”写定作阿Q；立传本身成为问题。
- 第二、三章 优胜记略（正续）→ 挨打、被骂、赌钱被抢，每一回都“得胜”；末尾去拧小尼姑的面颊。
- 第四、五章 恋爱的悲剧、生计问题 → 求爱被逐，无人雇工，跳墙偷萝卜。
- 第六、七章 从中兴到末路、革命 → 进城回来“发财”，酒后喊“造反”，赵太爷改口叫“老Q”。
- 第八、九章 不准革命、大团圆 → 假洋鬼子不准他革命；他被抓、受审，上堂就跪。
- 注释部分 → 作者自注与典故，可用于核对名物，不作为正文论据。

## I｜核心命题与可执行方法
**记账式胜利** —— 看每次受辱后他怎样改写胜负 → 问“这一回合他把自己判成什么” → 挨了哭丧棒，他立刻指着旁边的小孩说“我说他！”，把挨打改成骂错了人；屈辱当场结算成精神收益，处境却一点没变。

**转嫁链** —— 看怒气往下流给谁 → 问“他打不过谁，就去找谁” → 刚挨完哭丧棒，转身去拧小尼姑的面颊；暴力沿等级向下传递，每一层都需要一个更弱的人。

**看客合演** —— 看酒店里的人何时笑、笑多久 → 问“这笑替谁确认了地位” → 阿Q的“勋业”需要观众，“十分得意的笑”和“九分得意的笑”合起来才算一场完整的羞辱。

**命名的权力** —— 看谁有资格叫他什么（阿Q／老Q／Q哥／秃儿驴）→ 问“称呼变了，结构变了吗” → 序里连姓赵都不准，革命后赵太爷改口叫“老Q”，松动的只是称呼。

**革命的翻译** —— 看他如何理解“革命” → 问“他脑里的新词从哪里来” → “我要什么就是什么，我欢喜谁就是谁”；革命被译成旧欲望，“不准革命”暴露的其实是准入资格。

## A1｜书中实例
- 序（第一章）：他是否姓赵、名字怎么写、籍贯何处，一概考不出；作者托同乡查案卷，“案卷里并无与阿Quei的声音相近的人”，只好用了“洋字”。
- 优胜记略（第二章）：被“假洋鬼子”用黄漆棍子打过之后，他指着近旁一个孩子分辩“我说他！”；随即迎上小尼姑，摩着她的头皮说“秃儿！快回去，和尚等着你……”，酒店里的人大笑。
- 大团圆（第九章）：上堂时他“膝关节立刻自然而然的宽松，便跪了下去”；长衫人物吆喝“站着说！不要跪！”，又鄙夷一句“奴隶性！……”，“但也没有叫他起来”。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析一次受辱之后的心理自我补偿时。
- 当用户想辨认公共事件里的“看客机制”时。
- 当用户写讽刺小说，需要让叙述者装作考据家时。
- 与《兄弟》同写围观与自我合理化：阿Q的算法是个人的、精算的，刘镇的看客是集体的、起哄的；一个算得精，一个笑得响。

## E｜执行步骤
1. 输入一次具体的受辱事件 → 记录当事人原话与其后的行为 → 产出损益表（当场失去什么／当场得到什么）→ 验收：得到的部分必须由他自己说出口。
2. 输入一段群体场景 → 标出每个旁观者的动作（笑／看／走开／传话）→ 产出看客分工图 → 验收：能指出谁提供了“赏识”。
3. 输入一处称呼的变化 → 列出说话人、场合、前后称谓 → 产出称谓政治表 → 验收：能判断地位是否真的改变。
4. 写作训练：用“考据腔”写一个查无此人的小传 500 字 → 验收：越考据，越显得此人不存在。

## B｜边界与误用
- “精神胜利法”被用得太顺口，成了骂人标签；书里它是一套可拆解的操作，不是一个民族的性格结论。
- 叙述者带强烈反讽，把“我”的话当作者结论会读反。
- 未庄有具体的制度背景（科举停废、剪辫、革命党进城），抽离背景谈“国民性”会失焦。
- 抽样限于序、优胜记略、生计、革命、大团圆与注释，中间章节未覆盖。
