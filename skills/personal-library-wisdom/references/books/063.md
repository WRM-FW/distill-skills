# 《自我与本我》 — 西格蒙德·弗洛伊德
> 类型：论说｜原文规模：约 9.3 万字｜抽样依据（工作档案 udigest/063.md（6 段）

## 一句话
三篇晚期文本合成一套装置：把"我知道却做不到"拆成自我、本我、超我三个可指认的位置。

## R｜原文骨架
抽样无章节标题，按三篇定位：
- 《超越唯乐原则》→ 从常性原则推出唯乐原则，再用创伤梦与重复行为证明它不支配全部，引出死本能。
- 《集体心理学和自我的分析》→ 借勒邦描述集体心理，再以"领袖"和群居本能反驳特罗特。
- 《自我与本我》→ 抗拒来自自我本身；自我的部分是潜意识的；超我、焦虑的所在地。

## I｜核心命题与可执行方法
**"知道却做不到"定位抗拒** —— 触发：当事人承认问题、也能说出道理，就是改不了，且说不清阻力是什么 → 动作：别把阻力当成"他不肯说"，它"来自他的自我并且属于这个自我"；把冲突改写为"现实清晰的自我 vs 由自我分裂出去的部分" → 验收：他能给出阻力出现前的具体场景与身体反应；反证：若他能命名阻力并给出理由（缺钱、没时间、价值不合），那是现实顾虑，不是无意识抗拒。

**唯乐原则的边界** —— 触发：有人反复做让自己更难受的事 → 动作：先用常性原则问一句——这行为把兴奋量拉低还是拉高 → 验收：能判断它是在卸载张力还是在重复张力；反证：若张力明显升高仍反复（创伤梦、越帮越糟的"负性治疗反应"），唯乐原则失效，须换强迫性重复或死本能解释。

**集体心理三指标** —— 触发：判断一个群聊、组织或舆论场是否进入集体心理 → 动作：查三条——不渴求真理只要错觉；相反观点并存而不冲突；词语本身有魔力，口号一喊即止争 → 验收：三条同时出现；反证：若存在稳定的异议容忍与事实核查，勒邦式描述就不适用。

**孤独恐惧的对象核查** —— 触发：有人说"我一个人待不住" → 动作：问陌生人在场能否缓解。弗洛伊德指出，陌生人靠近反而加剧恐惧，恐惧真正指向母亲与熟悉的人，是"未得到满足的欲望" → 验收：能定位恐惧的具体对象；反证：若陌生人确实能安抚，群居本能说成立，"集体"解释要退让。

**三类焦虑分栏** —— 触发：说不清的害怕 → 动作：分外部世界、本我力比多、超我良心三栏，自我是"焦虑的实际的所在地"；良心恐惧的背后他放的是阉割恐惧 → 反证：若恐惧对象可明确指出且比例相称，属现实焦虑，不必下挖。

## A1｜书中实例
- 魏斯曼的躯体／种质之分（《超越唯乐原则》）：躯体必死，生殖细胞潜在永生。弗洛伊德借此说死本能与生的本能各占一半，同时承认生物学家在自然死亡问题上"意见分歧如此之大"。
- 勒邦的集体描述（《集体心理学》）：集体"从不渴求真理，它们需要的是错觉"，矛盾观点可以比肩而立而不冲突，且慑服于词语的魔力——他拿原始人的名称禁忌作旁证。
- 分析中的抗拒（《自我与本我》）：病人联想接近被压抑材料时"联想就会消失"，告诉他被抗拒控制，他"对这一事实还是一无所知"，只能从不舒服里猜到有东西在起作用。

## A2｜何时调用 / 与相邻书的区分
- 当用户说"道理我都懂，就是做不到"时。
- 当用户反复做同一件让自己更痛苦的事时。
- 当用户想判断一个群体是否已经不讲事实时。
- 当用户分不清害怕的是外部、欲望还是良心时。
- 与《弗洛伊德文集》同讲这三篇，差别在：本书是单行三篇连读，结构装置完整；文集那套是十二卷全景，含导论与术语辨析。
- 与荣格《分析心理学的理论与实践》同谈无意识，差别在：弗洛伊德把冲突放在自我内部三方之间，荣格把它放在个人情结与集体层之间。

## E｜执行步骤
1. 输入：写下三件"明知该做却没做"的事，各附当时的原话与身体反应。
2. 对每件问：阻力出现的前一秒，我在担心谁的评价（超我）、怕失去什么（外部）、还是怕某种冲动冒出来（本我）。
3. 给每件标一个主导栏；标不出的写"未定"，不许硬填。
4. 选一件做小实验：只改变外部条件（时间、地点、陪同者），看阻力是否下降。
5. 产出：一页三栏表＋一句结论（"这件事卡在良心，不在能力"），两周后复核是否仍成立。

## B｜边界与误用
- 死本能是思辨，作者自己承认生物学证据不足；拿它解释一切破坏行为会变成万能话。
- 勒邦式集体论取自十九世纪素材，对现代组织的解释力有限。
- "超我"容易被误用成道德指责的工具（"你只是超我太强"），这会取消当事人真实的伦理判断。
