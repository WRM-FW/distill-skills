# 《天下格局：文明转换关口的世界》 — 许倬云（冯俊文 整理）

## 一句话
用地理、农牧交界与道路网解释中国"大一统"为何反复重建。

## R｜原文骨架
- 导言 人类文明转换的关口 → 把"超稳定结构"立成问题：为什么分裂之后总能再统一。
- 第一讲 "天下国家"的超稳定结构：地理条件 / 游牧农耕融合 / 精耕农业与道路网 / 天人合一、安土重迁 → 四根支柱。
- 第二讲 轴心时代：两河、埃及一神信仰、罗马、波斯 → 各文明在同一个关口分叉。
- 第三讲 民族崛起与近现代世界：《威斯特伐利亚和约》、民族国家，对照"天下国家"作为文化共同体。
- 第四至七讲：自然经济到货币经济、宋代国营、明清宗室、大航海与贸易体系、战后美国霸权；第八讲与结语谈未来方向与全球化。

## I｜核心命题与可执行方法
**四支柱诊断** —— 要解释"中国为何反复统一"时 → 逐条查：连片可耕平原、农牧交界带的军事压力、水运与驿道网、安土重迁的观念 → 验收：能指出当下哪根支柱在松动，而非"文化传统"。

**通道成本法** —— 解释贸易路线与城市兴衰时 → 数转运次数与加价倍数，比较陆路与海路的载量、风险 → 验收：能说明大航海为何让内陆节点衰落、口岸城市兴起。

**网络式信仰读法** —— 用教会/教派模型套中国信仰失灵时 → 把信仰看成天地、生态、人际、身体层层套叠的网络，看个体在网中的位置义务 → 验收：能解释"修己安人"为何能代替教会组织，以及它为何难动员。

**两层皮检查** —— 用"某制度"的标签解释实际治理时 → 把制度文本与实际执行分开，找执行层的激励与人事 → 验收：能指出名义规则与实际规则在哪里分叉，谁从中获利。

**福利替代社群诊断** —— 一个社会被说成"涣散"时 → 查福利是否接管了原本由中间团体承担的功能，看工会、农会、扶轮社一类组织的存亡 → 验收：能区分"国家保障"与"人际联结"，不把前者当后者。

## A1｜书中实例
- 绸缎的加价（第五讲）：一匹绸缎运到君士坦丁堡已是原价五倍，到罗马再加三倍，到西班牙九倍，到英国十倍；蒙古驿道"换马不换人"。
- 天人合一（第一讲）：董仲舒把"天人合一"系统总结成信仰；张载"为天地立心，为生民立命"被作者称为立足天地宇宙的人间理想；德日进则说起点 α 与终点 ω 重合。
- 美国福利与社群（结语部分）：政府福利"从摇篮一直管到坟墓"，扶轮社、青商会、共济会、工会与农会都不复往日影响力；作者的儿子一代不愿讲"黑人"而要称"非裔"，彼此界限划得很远。

## A2｜何时调用 / 与相邻书的区分

## E｜执行步骤
1. 选一个"中国为什么"的问题，限定时间段，写清要解释的现象。
2. 逐条找四支柱的证据：地形、农牧关系、交通网、观念文本。
3. 找反例：分裂时期这四根支柱哪根失效，谁补上了。
4. 做长时段对照：1500 年、1840 年、当下，看哪次是结构变化、哪次只是换人。
5. 产出"结构—维持成本—观念"三列表，标出正在松动的一根。
