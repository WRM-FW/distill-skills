# 《滚动的车轮：跟着卡车司机行中国》 — 黄子懿、驳静、张从志
> 类型：论说｜原文规模：约 12.9 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/034.md（6 段）

## 一句话
跟着一条货运线走，用运费、月供和空载率读出经济与劳动的实况。

## R｜原文骨架
- 引子"我被寿光改变的人生" + 第一章 女卡车司机找货记 → 一个人如何被一条产业链改写，以及性别如何成为准入门槛。
- 第二章 山西煤运 → 运力与周期的绑定，"一根绳上的人"如何一起起落。
- 第三、四章 粤港线与青藏线 → 代际更替、贷款车与夫妻档，把"家"搬进驾驶室。
- 第五、十一章 京沪冷链与医药冷链 → 温控、记录、时效如何把司机变成系统末端。
- 第六至十二章：快递、跨境、戈壁、大件 → 平台抢单、货量下滑、规则落差与协作小队。

## I｜核心命题与可执行方法
**单线成本表** —— 要解释司机的疲劳、超载、改烧天然气时 → 列月供、油价、过路费、回程空载、罚款风险五项，算"不违规就亏"的临界点 → 验收：能指出哪种行为是成本结构的解，而非性格缺陷。

**货运景气传感器** —— 只有宏观数据、想判断某地某业冷热时 → 问三件事：运费单价、整车货量、回程是否空载；再看货主换用了什么车型 → 验收：三个一线指标与统计数字同向或背离，都能给出解释。

**性别准入成本清单** —— 某行业"女性少"时 → 分"准入"（招工、住宿、夜班、体力门槛）与"退出"（骚扰、家庭拖累）两类记账 → 验收：能区分"不适合"与"被排斥"，并指出哪一项是可被人为降低的。

**移动家庭的空间读法** —— 讨论流动劳动的家庭时 → 看两平方米驾驶室里装进了哪些再生产功能：做饭、睡觉、存粮、藏刀过安检 → 验收：能说明家庭不是缺席，而是被重新空间化。

**规则落差套利** —— 边贸城镇"因路而兴"时 → 比较两地保险理赔、路权、关卡、回程货 → 验收：能指出套利空间靠什么维持，关闭后城镇靠什么活。

## A1｜书中实例
- 宋玉兰（第一章 女卡车司机找货记，山东寿光）：2010 年从青岛装货去新疆，副手苏师傅在额济纳旗前谈条件，她当场结清 500 元赶人下车，对方威胁"我今天弄死你"；她说十个司机里得有九个会有想法。
- 刘军华夫妇（第四章 青藏线）：60 万元新车、每月还贷 1.8 万元，"连续三个月还不上贷款，就会收车"；驾驶室两平方米，冰箱装腊肉，菜刀因安检藏在最隐秘处；堵车时去泡温泉。
- 潍坊—乌鲁木齐（第九章）：3400 公里，走三天才出内蒙古；柴油从六元多涨到七元多；西瓜跌到"按车"卖 5000 元，甘肃、内蒙古车队改烧天然气。

## A2｜何时调用 / 与相邻书的区分
- 当用户问卡车司机、货运平台、县域经济或"为什么运费这么低"时。
- 当想用一线指标校验统计数字、判断行业冷热时。
- 当分析一个男性主导行业里女性的实际处境时。
- 与 026《国家为什么会失败》都问"什么决定收益"：026 看谁定规则，本书看成本如何传到最末端。

## E｜执行步骤
1. 选一条线路（产地—集散地—消费地），写清货物、里程、季节。
2. 列成本表：车价与月供、油耗或气耗、过路费、装卸等待、回程空载。
3. 跟一段路或访两三个司机，记录他们一天的时间分配与住宿方式。
4. 用货量、单价、车型变化三项交叉验证当地宏观数据。
5. 产出链条图：货主—信息部/平台—司机—收货方，标注每一环拿走多少、承担什么风险。

## B｜边界与误用
- 记者取样，个案生动但非随机，不能当行业统计。
- 运价、油价、平台规则会过期，书中数字只当方法示例。
- 对平台算法、地方治超政策着墨有限，解释不了违规行为。
- 易被误用成"司机辛苦所以值得同情"的故事，漏掉成本如何制造行为。
