# 《第二性》 — 西蒙娜·德·波伏瓦（郑克鲁 译）
> 类型：合集｜原文规模：约 40.8 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/017.md（12 段）

## 一句话
把"女人味"还原成一套制度围出来的处境，而不是天性。

## R｜原文骨架
- 第一卷·事实与神话：生物学 / 精神分析 / 历史唯物主义三种论据 → 逐一拆掉单因解释。
- 第一卷下半：历史，加蒙泰朗、劳伦斯等五个男性文本 → 看"女人"如何被写成符号。
- 第二卷·实际体验：童年到老年，按生命历程排 → 同一套约束如何换形。
- 第二卷后半：自恋 / 恋爱 / 虔信 / 独立 → 四条出路的代价。

## I｜核心命题与可执行方法
**处境还原** —— 听到"她天生爱操心、爱抱怨"时 → 把她的一天拆成空间、时间、钱、退出选项四项约束，问这个"性格"在什么条件下划算 → 验收：条件撤销后行为是否改变；不变，才轮到别的解释。

**他者化检测** —— 读到把某群体写成谜、天使或祸水的文本 → 问谁被默认为主体、谁只在关系里有位置 → 验收：找出"为……而存在"的句式，并说明这种神秘对谁有利。

**双重标准记分** —— 同一行为在两套规则下被评价时（性、野心、发怒）→ 分别记名誉成本与职业成本 → 验收：给出可比较的差额，而不是笼统说"不公平"。

**单因解释缺口检查** —— 遇到"技术或私有制自动产生性别压迫"的论证 → 追问压迫为何采取性别形式、当事人为何不反抗 → 验收：指出论证缺的那一环。

**出路成本对照** —— 评估"独立女人"方案时 → 把她与妻子、妓女、虔信者放进同一张成本表（性、经济、名誉、孤独）→ 验收：说明独立是换了一组代价。

## A1｜书中实例
- 童话与宗教（第二卷第一章 童年）：女孩从故事、报纸和大人的谈话里看到首脑、将军、探险家都是男人；《小妇人》里父亲缺席却被神圣化；圣父是"有一部浓密的白胡子的老头"。
- 性启蒙（第二卷第三章）：金西报告称阴道绝大部分内壁不受神经支配，可在其中手术而不施麻醉；波伏瓦据此指出解剖学论据含糊，快感取决于"主体所经历的处境"。
- 家庭主妇购物（第二卷第七章 社会生活）：她把买菜当赌博，比"以最少的钱获得最好的商品"，在货摊前是女王，掏空购物袋时"品尝着短暂的胜利"。

## A2｜何时调用 / 与相邻书的区分
- 当用户把某种行为归因于"女人天性"，或判断"男主外女主内很自然""某行业女性少是因为不适合"时。
- 当需要拆解一段把女性写成"神秘/天使/魔鬼"的文本时。
- 当分析外貌焦虑、母职、消费补偿时。
- 与 059《消费社会》同问消费补偿：波伏瓦答"被排除在公共行动外"，鲍德里亚答"符号区分"。

## E｜执行步骤
1. 输入：一个被说成"天生"的性别差异，记下它一天中的具体场景。
2. 列四项约束：可去的地方、可支配的时间、可用的钱、能否退出（离婚/辞职/不婚）。
3. 标出主体位置：这段描述以谁为默认读者，谁被写成例外。
4. 写两条可检验推论：换阶层、换时代、换性别是否复现；约束改变后行为是否随之改变。
5. 产出"处境—行为—代价"表，末栏写解释不了的部分。

## B｜边界与误用
- 写于 1949 年的法国，法律与就业条件已变，可迁移的是"处境"的提问方式。
- 生理与精神分析章节依赖当年数据，部分结论已被后续研究修正。
- 最容易被误读成"一切差异都是建构"，反而抹掉身体与物质约束。
- 不提供政策方案，也不处理男性处境；它诊断制度如何把一类人固定在"第二性"。
