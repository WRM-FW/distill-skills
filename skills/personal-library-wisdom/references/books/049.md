# 《加缪笔记1935—1959（精选集）》 — 阿尔贝·加缪（郭宏安 译）
> 类型：论说 | 原文规模：约 14.7 万字 | 抽样依据（工作档案 udigest/049.md（6 段）

## 一句话
二十四年思想草稿摊开：一句一个探针，用来试自己的判断在哪儿松动。

## R｜原文骨架
- 全书无章节标题，按年代编次（1935—1959），条目之间以日期与"＊＊＊"分隔。
- 早期条目 → 计划清单：一篇随笔的六个设想、小说的提纲，能看到作品尚未成形时先列意象、再找结构的做法。
- 中期条目 → 命题与警句密度最高（"心理学是行动""写作，就是对自己漠不关心"）。
- 1950 年代条目 → 旅行与城市笔记变长，罗马、希腊、提帕萨成为复位装置。
- 另有阅读摘录与转述（荷尔德林、帕韦泽），以及为《鼠疫》人物里厄写的设定笔记。
- 精选本的代价：条目被剪断，前后语境缺失，单条容易被当成格言。

## I｜核心命题与可执行方法
**翻转句** —— 看一条笔记是否把常识句翻面（"人错过了一切，甚至死亡"） → 问："它在什么条件下才成立？" → 会看到：这些命题多是半成品，需要补一个场景才能用；直接引用就变成鸡汤。

**未完成状态** —— 看这一条是计划、速写还是结论 → 问："它停在哪个阶段？" → 会看到：计划清单比成品更能暴露取舍方式——先堆意象，再定骨架，最后才决定文体。

**城市重量** —— 看城市被写成什么姿势（罗马"可感而轻"、纽约"压在肩膀上"、佛罗伦萨"欢迎旅人"） → 问："这座城市要求人怎么站？" → 会看到：地理判断其实是伦理判断，身体的吃力程度就是价值判断。

**动作速写** —— 看海牙餐厅里"黑人用他的高顶黑礼帽带走了鸽子"这类段落 → 问："这段有没有多余的解释？" → 会看到：他只记动作顺序，把判断留给读者；解释一多，速写就死。

**不接受** —— 看形而上立场如何落成制度态度（"我们不应该判处死刑，因为人们已经把我们当作死刑犯了"） → 问："这个立场要求他明天做什么？" → 会看到：拒绝是被推导出来的行动，不是情绪。

## A1｜书中实例
- 抽样第 1 段"5 月"条目：他把心理学重新定义成行动——"心理学是行动——不是关于自我的思考"，并说"完全地认识自己，唯有死"。
- 同段末尾的死刑犯速写：教士天天来看他，他"不说一句话地死去，两眼充满泪水"，拒绝躲进"我的上帝"的呼喊里换安慰。
- 抽样第 4 段：他为《鼠疫》里的里厄定位——"他与死亡搏斗"，做"上帝的敌人"甚至是职业；与帕纳卢的分歧不在胜负，在是否接受。

## A2｜何时调用 / 与相邻书的区分
- 当用户想练"一句话说清一个判断"时。
- 当用户需要把抽象立场落成具体态度时。
- 当用户写观察笔记，拿不准该记动作还是记感想时。
- 当用户想区分"格言"与"论证"时。
- 与《加缪手记》第三卷同源不同用：精选集跨二十四年，适合看命题的变形与重复；第三卷是连续三个笔记本，适合看一条素材怎样长成作品。
- 与《只有一个人生》都在用短句安顿处境：加缪把句子当探针，允许它不成立；周国平把句子当结论，要求它当天可用。

## E｜执行步骤
1. 取一条你认同的判断 → 写出它的反命题 → 各配一个能成立的场景（每段 50 字）。
2. 做一次"只记动作"的观察：在公共场所记十个动作，禁止形容词与判断 → 事后补一句解释，检查这句是否必要。
3. 用"城市重量"法写你常去的三个地方：各写"它要求你摆出什么姿势" → 不许用"美""舒服"。
4. 验收：四条里至少两条能被别人照着做，而不是只能被点头。

## B｜边界与误用
- 精选本删去大量上下文，条目间原本的日期与自我修正关系被压平，不能当完整思想传记读。
- 大量条目是小说草稿与私人备忘，不是公开主张；"我的所有作品都是反讽的"不是自我定论。
- 殖民地与阿尔及利亚相关立场在抽样中只见零散句子，不足以判断，勿据此概括。
- 中译本夹有编注与译注，不读注会把他人转述当成加缪原话。
