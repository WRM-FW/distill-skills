# 《鼠疫》 — 阿尔贝·加缪
> 类型：文学 | 原文规模：约 9.4 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/066.md（6 段）

## 一句话
把灾难拆成数字、流放感与旁观者收益，检查灾祸如何被行政语言磨平。

## R｜原文骨架
- 全书五部，与疫情的五段曲线对应：第一部封城前的征兆，第二部封城与流放感，第三部尸体处理与统计，第四部神甫之死与转折，第五部开城与余波。
- 第一部 → 死鼠从零星到六千二百三十一只再到八千只，解决"恐慌如何被数字点燃"。
- 第二部 → 分离与推算归期，解决"封城如何把等待变成刑罚"。
- 第三部 → 焚化炉、抛尸大海的预案，解决"组织能力的天花板"。
- 第四部 → 帕纳鲁病亡、柯塔尔情绪反复，解决"信仰与投机在灾难中的两种下场"。

## I｜核心命题与可执行方法
**数字的钝化曲线** —— 看统计数字出现的位置与形容词。问：同一组数字先引发恐慌、后引发松气，中间加了哪句话。会看到"微不足道"四个字如何把八千只死鼠一笔勾销；行政语言的功能不是告知，是调节情绪温度。

**流放感作为结构** —— 看人物在哪些句子里放弃推算归期。问：谁先停止计算"还要多久"，之后他的行为怎么变。会看到希望被写成消耗品：一旦承认归期不可测，人就退回到"靠回忆往昔而生活"的坐牢状态。

**立场的死亡计数** —— 看每个发言者见过多少死亡。里厄点明帕纳鲁"较少看见人死亡，所以总代表真理说话"，而乡村教士"常常听见垂死之人的呼吸"，想法就不同。问：这句话把神学争论换成了什么？换成经验密度。会看到加缪不给立场排高低，只给每个立场标注它离病床的距离。

**不壮观的灾祸** —— 看叙述者为何反复声明自己不修饰。"灾祸比任何东西都更不壮观"、"像没完没了的重重的踩踏"。问：他拒绝写哪一种场面（英雄、壮举、火焰）？会看到一种反英雄的叙事伦理：把灾难写成流程，才是对它诚实。

**旁观者的收益表** —— 看谁在封城期间过得更好。柯塔尔在公告发布前后情绪剧烈摇摆，怕开城后"谁也不会管我"。问：这场灾难为谁提供了庇护？会看到边缘人靠混乱获得身份，灾难经济学不只属于投机商，也属于所有无位置的人。

## A1｜书中实例
开篇死鼠段：情报资料局宣布单日收集焚烧六千二百三十一只，随后升至约八千只，市民焦虑达顶点；次日宣布"鼠害现象已骤然停止"，全城松了一口气。数字直接操纵群体的呼吸。

中段对话：塔鲁问里厄是否相信上帝，里厄答"不相信，但这能说明什么呢？我处在黑暗中，我很想看个清楚"，并把献身解释为"与大自然本身作斗争"。

第四部：帕纳鲁拒绝请医生，女房东认为"看病不符合他的原则"，只能给他草药汤；她两小时探视一次，记录他掀被、摸额、咳不出痰的整个过程。信仰在病床前被写成一套具体的护理动作。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析灾难报道里的数字修辞、想知道统计如何安抚人时。
- 当用户处理"封闭空间中的等待"这一母题，需要结构化的观察点。
- 当用户比较神职立场与职业立场，需要不靠辩论而靠经验的判据时。
- 与《我们》同写封闭城市，差别在：扎米亚京检查制度如何进入语言和身体，加缪检查灾难如何进入统计和日程；一个问"谁在统治"，一个问"人怎样熬"。

## E｜执行步骤
1. 输入一段灾情通报或新闻 → 圈出所有数字与形容词 → 标出数字升、降各配了什么词 → 产出"情绪调节表"。
2. 在同一文本里找"还要多久"类句子 → 记录说话人何时停止推算 → 判断其行为是否随之改变。
3. 列出文中每个立场的持有者 → 标注其与死亡现场的距离（见过几例、在场多久）→ 检验论点是否随距离移动。
4. 把一段灾难描写改写成"英雄版"（加壮举、加火焰）→ 与原段对照 → 验收：说出原段删掉了哪些戏剧性，换来了什么。
5. 找一个灾难中的获利者 → 写他的收益清单与恐惧清单 → 检查两者是否指向同一件事。

## B｜边界与误用
- 不提供防疫的技术方案；书中的行政细节是伦理布景，不能当公共卫生教材。
- 最容易被误用为"灾难也有好处"的论据；里厄的原话恰恰是"只有疯子、瞎子或懦夫才会放弃斗争"。
- 成书于一九四七年，殖民背景下的阿尔及利亚城市几乎不出场，用作后殖民批评须另找材料。
- 叙述者自称"笔者"并宣称客观，这个身份本身是可分析的构造，不宜当作者发言。
