# 《数理化通俗演义》 — 梁衡
> 类型：论说 | 原文规模：约 20.3 万字 | 抽样依据（工作档案 udigest/153.md（6 段）

## 一句话
用章回故事还原"缺哪个量、缺哪台仪器、哪一派反对"，把发现拆成可复用的判决步骤。

## R｜原文骨架
- 第 1–2 回：屈原问天、金字塔测地 → 问题意识与最早的量测。
- 第 3–7 回：测地周、阿基米德浮力与杠杆、镜子退敌 → 一个原理如何连出多种用途。
- 第 8–11 回：张衡地动仪、祖冲之割圆、一行量北斗 → 仪器与算法各自解决什么。
- 第 12–21 回：哥白尼、布鲁诺、维萨里、伽利略、马德堡半球 → 新说与旧权威的冲突成本。
- 第 22–28 回：第谷观测、开普勒椭圆、笛卡尔坐标、皇家学会、牛顿与哈雷 → 数据、数学工具、组织三者合流。
- 抽样另及法拉第、列文虎克、汤姆孙与卢瑟福、曼哈顿工程，可见全书延伸到 20 世纪中叶；列表仅列至第 28 回，后段回目未见于素材。

## I｜核心命题与可执行方法
**判决性实验：先找两派预测不同的那个数** —— 触发：两套解释都能说通现有观测。动作：找一个两派必然给出不同数值的量，设计只测这个量的装置，其余变量固定。验收：结果只能被一方容纳；两派都能解释的实验不算判决。

**误差预算决定你能不能看见** —— 触发：某异常反复出现，却一直被当噪声。动作：先算现有精度能否分辨该效应量，再决定改仪器还是改理论。验收：把误差压到小于效应量；压不下去就写"还看不见"，别急着宣布新定律。

**新仪器常常先于新理论** —— 触发：一个领域长期停在概念争论。动作：把资源投到观测与测量工具，而不是继续辩论。验收：工具到位后，争论在可预期时间内收敛。

**先算工程量级，再谈可行性** —— 触发：原理已成立，工程做不出来。动作：算分离系数、能耗、材料用量，并换成可比单位（一座城市的用电、多少吨白银、多长管道）。验收：量级能对上预算与工期，而不是只说"很难"。

**把副作用当入口** —— 触发：实验中出现了设计之外的现象。动作：先如实记录，再查是否由操作条件变化引起，最后求重复。验收：换人换时能重现；不能重现的先存疑。列文虎克喝完热咖啡再观察牙垢，小东西全没了——他撞见灭菌，当时并未意识到。

## A1｜书中实例
- 第 4 回前后：阿基米德把同重量的金块与银块分两次泡进水盆，"白银溢出的水比黄金溢出的几乎要多一倍"；再把王冠与金块分别泡入，王冠排水更多，金匠承认掺银。物理实验室里求比重的仪器至今叫"优勒加"。
- 第 22–23 回：开普勒拿到第谷二十多年的观测，试了多种曲线都不合，最后"选中火星这个典型来解剖"，而火星恰是当时所知椭圆度最大的行星，才看出轨道是椭圆。他写信告知老师马斯特林，对方置之不理，欧洲同行公开嘲笑。
- 抽样中的曼哈顿工程一节：格罗夫斯在荒野建三座地图上找不到的城市。铀-235 与铀-238 比例是 140:1，气体扩散法建了几千英里管道、耗电相当于一座纽约市；电磁法的磁铁有中等舰船大，绕线圈的铜不够，改用 1.5 万吨白银。

## A2｜何时调用 / 与相邻书的区分
- 用户要给非专业听众讲清一个发现怎么发生时，按"缺哪个量—缺哪台仪器—谁反对"三段讲。
- 用户需要历史类比来论证"仪器先行"或"精度决定可见性"时。
- 用户在设计实验、判断某个差异能否被现有手段分辨时，用误差预算。
- 用户要评估一项工程的量级是否靠谱时，用曼哈顿案例的换算法。
- 与《芯片简史》同为科技史：那本按产业与工艺约束组织，结论落在路线判断；本书按事件组织，结论落在发现方法。
- 与《编码》都讲"从简单到复杂"：那本是概念链自底向上推演，本书是历史链按时间铺开。

## E｜执行步骤
1. 输入一个待判断的主张或方案。动作：写出当时/现在能测到的量与精度。产出：可测量清单与误差量级。
2. 动作：找两派预测不同的那个量，设计只测它的最小实验。产出：判决性实验草案（含控制变量）。
3. 动作：若原理成立但做不出来，把约束换算成能耗、材料、工时三个可比量。产出：工程量级估算表。
4. 动作：翻查被忽略的副作用，列可重复的异常。产出：待验证异常清单。
5. 动作：把结论写成"若精度达到 X 则 A 成立，否则存疑"。产出：带阈值的判断句。

## B｜边界与误用
- 书中对白与心理描写是重构，不是史料；引用人物原话须回原始文献核对。
- 为可读性简化了争议：如伽利略对开普勒沉默，作者自己写"后人猜测"，这类段落不能当定论。
- 成书较早，当代技术覆盖薄；作为方法案例库好用，作为通史不全。
