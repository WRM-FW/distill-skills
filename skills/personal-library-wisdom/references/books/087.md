# 《狂人日记 鲁迅小说全集》 — 鲁迅
> 类型：合集 | 原文规模：约 13.0 万字 | 抽样依据（工作档案 udigest/087.md（6 段）

## 一句话
把"名目""从来如此""看客"拆开，用来验一段话里谁在吃人。

## R｜原文骨架
- 代序《我怎么做起小说来》 → 作者自述取材取向，交代写作立场，是理解全书态度的入口。
- 《狂人日记》《阿Q正传》《孔乙己》《药》等 → 短篇群，每篇设一个被命名的"异常者"，由旁人的嘴定义他。
- 《祝福》《离婚》《明天》一类 → 写乡镇妇女怎样在礼俗与价目里被处理掉。
- 《孤独者》《在酒楼上》《伤逝》 → 写觉醒者的失败与自我辩解，第一人称"我"多半无能为力。
- 《故事新编》（《非攻》《出关》《铸剑》等） → 把古人写成会饿会痛的人，用古代壳子装现实的钉子。
- 附录许寿裳《鲁迅先生年谱》 → 生平材料，不是小说，引用时须分清。

## I｜核心命题与可执行方法
**名目** —— 看冲突中谁先给对方一个身份词（疯子、泼皮、孝女、新派） → 问："贴上去之后，哪一步就不用解释了？" → 会看到：狂人怕的不是被吃，是"预备下一个疯子的名目罩上我"——命名是把处置变成理所当然的技术。

**从来如此** —— 找出所有以"从来""向来""本来"开头的句子 → 问："这句的主语是谁，它替代了哪一步论证？" → 会看到：礼俗不需要理由，只需要年头；要反驳它的人，得先证明自己不是疯子。

**价目表** —— 看规矩落地时出现的钱数、物件、手续 → 问："这条道德要求，折合多少钱？" → 会看到：祥林嫂捐门槛价目"大钱十二千"，换成十二元鹰洋；《离婚》里七大人以九十元了结一桩婚姻，手上还摩挲着"屁塞"——神圣与污秽同在一只手。

**看客的位置** —— 看围观者的表情与被看者的反应 → 问："谁在看，看的人付出什么代价？" → 会看到：镇上人专挑祥林嫂的伤疤问"你那时怎么竟肯了"，看她"瞪着眼睛，不说一句话"。看客不付代价，只收谈资。

**苦难的折旧** —— 看同一个故事被讲第几遍 → 问："听众的表情从哪一遍开始变？" → 会看到：阿毛的故事从催泪到"早被大家厌弃"，苦难有折旧率，重复讲述反而消耗同情。

**古人的肚子** —— 看《故事新编》里圣贤在干什么 → 问："作者给他安排了哪些生理需求？" → 会看到：墨子救宋归来"脚痛""干粮已经吃完"，进宋国界被搜检两回，城门下避雨被赶开，"淋得一身湿，从此鼻子塞了十多天"。把神坛上的人放回身体，崇高就变成差事。

## A1｜书中实例
- 抽样第 1 段：《狂人日记》里狂人劝大哥，说他们"预备下一个疯子的名目罩上我"，并把吃人者分成两种：以为从来如此应该吃的，和知道不该吃却仍然要吃的。
- 抽样第 3 段：《祝福》里祥林嫂捐了门槛后坦然去拿酒杯筷子，四婶慌忙大声说"你放着罢，祥林嫂！"，她"像是受了炮烙似的缩手，脸色同时变作灰黑"。
- 抽样第 6 段：《非攻》里墨子说服公输般后回国，一路被搜检、被募捐队要走破包袱、在城门下避雨被巡兵赶开，末了鼻子塞了十多天。

## A2｜何时调用 / 与相邻书的区分
- 当用户要判断一段话是否在给人贴标签、用身份代替事实时。
- 当用户分析"大家都这样""历来如此"式的论证时。
- 当用户要写乡镇或职场里的围观、羞辱与传话时。
- 当用户想把古代人物写成活人，而不是塑像时。
- 与《骆驼祥子》都写被吃掉的人：老舍给祥子一条经济因果链，鲁迅只给一个名目和一圈看客。
- 与《生死疲劳》都写暴力：莫言用狂欢铺开，鲁迅用一句"你放着罢"收住。

## E｜执行步骤
1. 取一段真实的争执记录 → 圈出所有身份词（"他就是个……"） → 每个词旁写：它省掉了哪条具体事实。
2. 找一句"从来如此／大家都这样" → 补出被省略的主语和受益方。
3. 列一张价目表：这件事谁付钱、付多少、付给谁、买到什么名分。
4. 把同一段苦难连写三遍，每遍换一个听众 → 观察第几遍开始变成谈资。
5. 验收：能用原文一句话证明"命名先于处置"。

## B｜边界与误用
- 这是小说全集，不是杂文集；卡片里的方法是从场面反推的，不能当鲁迅的社会评论直接引用。
- 各篇写于一九一八至一九三五年，笔法从文言小序到《故事新编》的油滑差异极大，不宜用一把尺子量。
- 女性多为被损害的形象，叙述者多为男性知识分子，分析时须指出这层视角。
- 讽刺最容易被学成刻薄：鲁迅的刀口对着"人怎么给自己找理由"，不是某类人的口音与长相。
