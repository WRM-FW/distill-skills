# 《镖人 1—11（共 11 册）》 — 许先哲

> 类型：合集 | 原文规模：约 0.4 万字（文字层） | 抽样依据（工作档案 udigest/225.md（6 段）

## 一句话
把"侠"拆成一份报价单：保护谁、讹多少、什么时候动刀。

## R｜原文骨架
漫画分三章推进，抽样只能读到文字层（回目、引文、前情提要、作者后记），画面未进入素材：
- 第一章 游侠（第一回 刀马与小七、第二回 悬赏令、第五回 狂沙曲）→ 立人物：镖客接活、报价、动手。
- 第二章 大漠（第二十回 不存在的人、第二十三回 家族的崛起、第四十九回 复仇、第五十回 家园）→ 把私人护送卷进家族与汗国的争夺。
- 第三章 江湖（第五十七回 帝国、第五十八回 左骁骑卫、第九十七回 裴世矩、第一百回 观风）→ 把江湖接到朝廷改制与对外征伐。
- 附录（作者后记、特别附录、各册前情提要）→ 交代创作方法与连载的记忆装置。

## I｜核心命题与可执行方法
**报价的伦理** —— 看刀马怎样在同一句话里既接下保护、又讹出三倍赏金 → 问"这笔钱买的是安全，还是沉默" → 会看到镖师的义气是谈成的价格，不是先验的德性。
**"以武犯禁"的边界** —— 看谁被允许动刀（官府、镖人、家族、复仇者）→ 问"同样杀人，哪一种被叫作罪" → 会看到秩序外的人靠秩序的定义活着，犯禁与执法只隔一道任命。
**前情提要的删减** —— 看每册开头三百字重述保留了谁、删掉了谁 → 问"它要求读者记住的是因果还是关系" → 会看到连载叙事的记忆管理：人物关系必须清楚，动机可以模糊。
**引文的合法性** —— 看《史记》《隋书》的句子被放在回目前（"窃钩者诛，窃国者侯"）→ 问"这句古文替这一回收拾了什么" → 会看到引文既给暴力镀上历史感，也给读者一个"这是史实"的错觉。

## A1｜书中实例
1. 后记：许先哲写 2010 年他二十六岁，"一事无成，也没有正规学过美术，没有写剧本的经验，对漫画业界更是一无所知"，但"我决心成为一个漫画家"。侠客的造型参照梁家辉，斗笠对应西部牛仔的帽子。
2. 序言（日方评论）："第一话就要抓住读者的心"是漫画的铁则；第一话里几个画面就把刀马是什么人、要做什么交代完，随后是一场暴风骤雨般的打戏，并称这是"举世罕见的话痨型动作戏主人公"。
3. 前情提要：刀马受游商老莫所托护送知世郎去长安，途中遇到押送燕子娘的刀客竖；到驿站歇息时，与阿育娅有婚约的和伊玄出现，"并带来老莫的首级"。此后阿育娅只身重返沙暴复仇。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析"侠"这个符号如何被现代漫画重写，需要看作者自述与引文策略时。
- 当用户写类型故事的开头，需要看"三页交代人物与任务"的做法时。
- 当用户处理连载结构，需要看前情提要如何替读者管理记忆时。
- 与《俗世奇人》同写"规矩外的人"：冯骥才写手艺人的行规，许先哲写武力者的报价。
- 与《老舍全集》同写乱世：老舍写沦陷区的日常，本作写乱世里的职业化暴力。

## E｜执行步骤
1. 先读各册前情提要，列人物关系表 → 标出每册被删掉的动机 → 得到叙事的"记忆骨架"。
2. 把回目前的史料引文与正文对照 → 判断引文是反讽、装饰还是背书 → 记录判断依据。
3. 统计刀马每回"说话"与"动手"的次序 → 看是否总是先报价后出手（需原书图像，素材不足时标明）。
4. 用"侠以武犯禁"检验每次冲突：谁先破坏了谁的秩序 → 写出一句谁在执法、谁在犯法的判定。
5. 写作训练：写一个"先谈价、再救人"的 500 字场景，不许写心理活动。

## B｜边界与误用
- 素材仅 7105 字，是图片书的文字层，画面、分镜、动作设计均未覆盖，不能评价画工与节奏。
- 十一册只抽到零星回目，不能据此判断全书结构与人物弧线。
- 书中的史料引文服务叙事，不是考据，不能当隋史材料引用。
- "信念越强，力量越强"是宣传语，不是作品论点，别拿它当分析方法。
