# 《诸子百家系列套装（全二十册）》 — 孟子、荀子、老子、墨子、韩非子等（中华书局全本全注全译）

## 一句话
二十部先秦两汉子书按"原文—注释—译文"三行并置，可直接抽取各家治国的诊断、处方与判据。

## R｜原文骨架
- 儒家《孟子》：十四篇按「梁惠王上—尽心下」编次，每篇标"凡 N 章"，以君问臣答逼出施政责任。
- 儒家《荀子》：以《非十二子》判别人家，以《王制》"王者之等赋"给出赋税、关市、山林、贡道的制度清单，解决"王道如何落成税制"。
- 道家《老子》：目录连续列出"十一章……五十三章"，以反命题压缩治理格言。
- 墨家《墨子》：《尚同》按「里长—乡长—国君—天子」逐级同义，解决"意见如何一级级统一"。
- 法家与杂家：《韩非子》释"术"为循名责实、操杀生之柄；《淮南子·天文训》以斗柄指向配十二律排历法。
- 其余：《公孙龙子》《列子》《庄子》《鬼谷子》《管子》《孙子兵法》《吴子》《司马法》等，书名在素材中被截断，正文仅《鬼谷子·分威》《管子》记事被抽样命中。

## I｜核心命题与可执行方法
**同义递推检验** —— 看《墨子·尚同》的层级链 → 问"每一级的'是'由谁判定、判错如何纠" → 会看到它把"统一"当治理前提，纠错口子只留给上一级，因此只能向上收敛，不能向下反馈。
**反命题格言** —— 看《老子》"后其身而身先"与《荀子》"贱身而贵有道，故身贵而令行" → 问"这句反话在什么条件下成立" → 会看到交换条件是"人多争位"，无争则反话失效。
**制度清单化** —— 看《王制》"王者之等赋" → 问"税种、税率、征收时点、流通环节各是什么" → 得到一张可对照的财政表，而不是"仁政"口号。
**术的可见性** —— 看《韩非子》对"术"的定义 → 问"谁掌握、能否公开、如何验收" → 会看到术靠"不可见"生效，与公开考核天然冲突。
**记事反证** —— 看《管子》桓公屡不听管仲而伐鲁 → 问"谏言与结果之间是否只差一次失败" → 会看到作者用连续失败把"不勤兵、不忌辱、不辅过"压成判据。
**历法即政令** —— 看《天文训》斗柄与十二律的配列 → 问"这套对应靠什么维持秩序" → 会看到天人相应是一张排表，用来给政令定时。

## A1｜书中实例
- 《荀子·王制》"王者之等赋"段：田野什一、关市"几而不征"、山林泽梁"以时禁发而不税"，一路排到"四海之内若一家"（抽样1）。
- 《墨子·尚同》：里长率民"尚同乎乡长"，乡长再"尚同乎国君"，两段句式几乎逐字复写，只换称谓（抽样2）。
- 《鬼谷子·分威》："挠其一指，观其余次"，陶弘景注解为触动局部以知全部（抽样3）。

## A2｜何时调用 / 与相邻书的区分
- 当用户问"这句话出自哪家、原意是什么、注家怎么解"时调用。
- 当要把"仁政/无为/尚同/法术"落成可核对的制度条目时调用。
- 当比较诸子对同一问题（用兵、赋税、意见统一）的不同答案时调用。
- 当需要一句可引的判断句支撑论证、且必须注明出处时调用。
- 与《会饮篇》卡同问"如何用对话推进主张"：诸子多以君—臣—民的位置差推进，柏拉图以提问—让步—反例推进。

## E｜执行步骤
1. 输入：一个制度问题（如"赋税怎么定"）。动作：在总目录定位各家相关篇目。产出：候选篇目清单。
2. 动作：抄原文一句、译文一句、注一条，三行并列。产出：可复核的引文卡。
3. 动作：做四列对照表——问题／诊断／处方／隐含条件。产出：各家方案并置表。
4. 动作：为每条处方补一个"失效条件"。产出：带边界的判断，而非格言。
5. 动作：写一段结论，指明哪家在何种条件下成立。产出：300 字以内的比较判断。

## B｜边界与误用
- 译文与注释是今人所作；只引译文等于引注者，不能当先秦原意。
- 二十册非同一学派，"尚同"与"无为"彼此冲突，拼成"传统智慧"会抹掉分歧。
- 抽样仅 6 段，集中在荀子、墨子、鬼谷子、管子、淮南子；《庄子》《列子》《孙子兵法》正文未覆盖。
- 书中多"原缺，据文义补"，读到的句子可能出自整理者（抽样6 可见连续补字）。
