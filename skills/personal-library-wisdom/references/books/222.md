# 《老舍全集》 — 老舍

> 类型：合集 | 原文规模：约 464.6 万字 | 抽样依据（工作档案 udigest/222.md（6 段）

## 一句话
用客气话、口音和幽默，标出北平人在乱世里的道德位置。

## R｜原文骨架
全集按小说、话剧、散文、文论分卷。抽样覆盖到的部分，分工如下：
- 早期长篇《二马》→ 马威在伦敦的公园与河边：中国人在外国怎么走路、怎么看自己。
- 《四世同堂》→ 戏园枪击与第二天的报纸：沦陷区的日子怎么继续。
- 抗战题材长篇（复仇者一段）→ 一个普通人怎样把自己说服成杀手。
- 话剧《秦氏三兄弟》→ 一院之内的主仆、兄弟与新旧之争，解决"一场戏如何交代时代"。
- 散文〈梅兰芳同志千古〉→ 一个人的职业习惯如何被写成品格。
- 英文论说（谈中国人的信仰、命与婚姻）→ 如何向外国读者解释自己人。
未抽样到的卷次不作判断。

## I｜核心命题与可执行方法
**客气话的语法** —— 看人物怎么请安、怎么寒暄、怎么"闹别扭" → 问"这句话的表面意思与真实要求差多少" → 会看到北平人的礼数是个压缩包，一个"您"里同时装着等级、拒绝与求人。
**亡国的日常账** —— 看沦陷后谁还算房租、谁还唱戏、谁劝自己"这跟我没关系" → 问"日子靠什么继续" → 会看到汉奸不是天生的，是把生活一块块切出去换安稳。
**复仇的算术** —— 看老冯磨刀前的自我说服（"杀一个够本，杀两个就有了赚头，很简单"）→ 问"他靠什么把恐惧换算成账" → 会看到正义感与算计可以同时成立，勇气是算完之后的副产品。
**口音的道德位置** —— 看谁说话带土音、谁说话文绉绉（铁子："我把城里的人、洋人，一个个的都捶扁了"）→ 问"作者把哪种语言分给哪种人" → 会看到老舍用口音分配同情，也用口音分配可笑。
**幽默的止痛位置** —— 看叙述者何时开玩笑（马威看河："野鸭太懒，白鸥太浮躁，只有小黑鸭老含着希望"）→ 问"这个比喻替谁遮住了什么" → 会看到幽默总出现在人物最无力的时候，是叙述者递过去的一只手。

## A1｜书中实例
1. 复仇段落：老冯摸到菜刀，用小毛巾包好出门，路上"心中好似也清楚了些"；他觉得"刀是天下最硬棒的东西"，自己"好似只是一口正气，刀是正气的唇舌"。敲门，刀抹在开门人的气嗓上，"血溅出老远，一声没出"；进屋只叫了声"大利，爸来了！"
2. 《四世同堂》：戏园里枪响，若霞倒在台上，人群"乱滚，乱爬，乱碰，乱打"；小文抄起椅子砸向行凶的醉鬼，回头对妻子说"霞！死吧，没关系！"；桐芳趴下，用手用膝往前爬，去护若霞。第二天小报写的是"女伶之死"，说夫妇"勾通奸党，暗藏武器"。
3. 《秦氏三兄弟》：秦叔礼跟乡下长工铁子比武，一伸手就被摔倒，捂着头进来告状："一个种地的乡下脑壳，敢在这儿发威？不行，我告诉妈妈去！"秦伯仁只回一句："他是耪大地的，你就行啦？"

## A2｜何时调用 / 与相邻书的区分
- 当用户要写北平/北京的人情与礼数，需要看称呼如何承担冲突时。
- 当用户处理沦陷、占领、集体沉默这类题材，需要看"日常如何与暴行并存"时。
- 当用户要写一个人的职业习惯（如名伶、手艺人），需要看如何用细节代替评价时。
- 与《俗世奇人》同写天津卫与手艺：冯骥才写绝活，老舍写绝活背后的人情与国运。
- 与《余华作品全集》同写苦难：余华让人物少说话，老舍让人物多说，靠废话暴露处境。

## E｜执行步骤
1. 选一段对话 → 删掉全部称呼与敬语 → 看还剩下什么冲突，缺的部分就是礼数承担的功能。
2. 标出方言词与文雅词，记录作者把它们分给了谁 → 画一张"语言—阶层"表。
3. 找幽默句，标出它前后各发生了什么 → 判断笑是缓解还是遮盖。
4. 用同一事件写两个版本：报纸版与当事人版（《四世同堂》那段就是范本）→ 比较删改。
5. 检查：有没有把汉奸、看客写成天生的坏人 → 若没有过程，重写。

## B｜边界与误用
- 全集含大量应景文、通俗唱词、未完成稿，质量与文体极不齐，不能篇篇当代表作。
- 1949 年后的散文受时代话语约束，抒情常让位于表态。
- 英文论说面向外国读者，有简化与自我说明的成分，不等于他的全部看法。
- 不能把某个人物的嘴当成老舍的立场，他习惯让可笑的人说出正确的话。
