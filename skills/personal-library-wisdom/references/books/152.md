# 《全球真实故事集》 — 吴琦 编
> 类型：合集 | 原文规模：约 10.8 万字 | 抽样依据（工作档案 udigest/152.md（6 段）

## 一句话
一组非虚构样本，教你把"处境"拆成身份、证据、物资三本账。

## R｜原文骨架
- 《真东西》（The Real Thing）→ 列于卷首，抽样未覆盖，仅存篇名。
- 《五兄弟》→ 洪都拉斯五兄弟偷渡美国后分散五地；同一个人被经济、法律、政治三套语言分别命名。
- 《四楼的囚徒》→ 抽样未覆盖，仅存篇名，不作判断。
- 《采矿业中的女性》→ 刚果（金）手工采矿，以伊薇特·姆万扎的口述谈合作社、正规化与机械化之争。
- 《失踪者》→ 马马杜·赛杜渡海失联，家人用替代证据判断生死。
- 《古巴的比，古巴的波普》→ 哈瓦那制琴师罗德里格兹·佩纳，物资短缺下的手艺标准。
- 《英国民间观察》→ 圈地、份地、公地观念，接奥斯特罗姆的"公共"定义。
- 《冲绳漫步》《触碰》→ 抽样6为《触碰》开头，驻华记者写自己如何被采访对象改变。

## I｜核心命题与可执行方法
**三套命名** —— 看同一个人在经济、法律、政治语言里的三种称呼 → 问谁在用哪套词、哪套词让他被同情、哪套词让他被驱逐 → 会看到"难民／非法移民／廉价劳动力"不是描述，是三种处置方式。

**替代证据** —— 看没有尸体、没有文件时人用什么确认事实 → 问这条判断链上有几个"别人家的儿子"、谁有资格去核实 → 会看到弱者的真相只能靠类比与传闻成立。

**物资的证词** —— 看具体数字与物件（6.5 美元时薪、8000 美元蛇头费、一把改制的雷昆托）→ 问这个数字对谁是大数目 → 会看到一个数字在两套生活里重量不同，这个差就是结构。

**公地的消失** —— 看一块资源从"大家的"变成"谁的"的过程 → 问圈走它的人给了什么补偿、补偿够不够活 → 会看到"份地"既是补偿方案，也是把权利降级为恩惠。

**稀缺中的精度** —— 看一个人在没有零件、没有店铺时怎么维持标准 → 问他替谁修、修的是乐器还是记忆 → 会看到短缺社会的技术不是落后，是另一种精度。

## A1｜书中实例
《五兄弟》抽样1：到美国四周后五兄弟决定分开住，怕被突击检查、怕集体被抓；米格尔去新泽西投奔叔叔，小亚历克斯在达拉斯理发，奥斯卡在郊区卖玉米，路易斯去佛罗里达打零工，安吉尔去休斯敦。

《失踪者》抽样3：家人凭"巴黎人"从法国24台看到的沉船新闻，推断马马杜·赛杜已死。父亲的说法是："如果'巴黎人'确信自己的儿子死了，那我们就得接受我们的儿子也肯定是死了……那可以算作一种证据。"

《采矿业中的女性》抽样2：姆万扎主张矿工组建文件齐全的合作社、推动机械化，同时反驳"机械化会导致没有文化的妇女失业"这一说法。

## A2｜何时调用 / 与相邻书的区分
- 当用户要把一个社会处境写成非虚构，而不是写成评论时。
- 当用户需要拆解"非法／合法""素质低"这类标签时。
- 当用户手上只有二手证词，要判断它够不够支撑结论时。
- 与《第七天》同写底层死亡：本书给证据链和制度语言，《第七天》给寓言和申诉。与《活着》同写苦难：本书追问谁该负责，《活着》记录怎么熬。

## E｜执行步骤
1. 选一个当事人 → 列出他在三套语言里的名字（经济／法律／道德）→ 产出一张命名对照表。
2. 收集可核验的物证：钱数、时间、地点、物件 → 每个数字旁注明"对谁而言是大数"。
3. 画信息链：谁亲眼看见、谁转述、谁有权确认 → 标出断点，断点就是报道的入口。
4. 写 300 字，只允许一个形容词，其余用动词和数字 → 验收：删掉形容词后事实仍成立。

## B｜边界与误用
- 各篇作者立场与材料厚度不一，不能当作对"全球底层"的整体判断。
- 多为外部记者视角，当事人很少自己执笔，转述损耗不可避免。
- 抽样仅 6 段，《四楼的囚徒》等篇目未进入抽样，不足以判断全书写法。
- 个别篇目理论引用密集（如《英国民间观察》），离开注释难以独立阅读。
