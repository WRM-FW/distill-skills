# 《科学发现的逻辑》 — 卡尔·波普尔（Karl Popper）
> 类型：论说 | 原文规模：约 69.6 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/000.md（6 段）

## 一句话
用能否被观察否证给科学划界，并给出假说—演绎—反证的完整检验流程。

## R｜原文骨架
- 第一部分「科学逻辑导论」：归纳问题 → 划界问题 → 可证伪性作为划界标准 → 经验基础与科学客观性，解决"什么算科学"。
- 第二部分「科学方法理论」：方法论规则为何是约定，解决"规则从哪来、能否改"。
- 第三部分「理论」：因果性、解释与预见的演绎；严格全称与存在陈述；普遍性层次与否定后件式（modus tollens），解决"理论如何推出预见"。
- 第四部分「可证伪性」：对约定主义反驳的回应、可证伪性的逻辑研究、否证与一致性，解决"否证如何可能"。
- 第五部分「经验基础」：记录语句、基本陈述、经验基础的客观性，解决"用什么事实去否证"。
- 第六、七部分「可检验度」「简单性」：潜在否证者类的比较、精确度、简单性与可证伪度的关系，解决"两个都没被推翻时选哪个"。

## I｜核心命题与可执行方法
**可证伪性划界** —— 触发：有人说某主张"是科学的"，或某理论怎么都能自圆其说。动作：问"它禁止什么可观察事件发生"，逼出一个"若观察到 X 则理论错"的句子。验收：X 必须是他人可按程序观测的具体事件；若任何观察都能算支持，判为非经验主张，而不是判为假。

**假说—演绎否证链** —— 触发：要检验一个理论。动作：写成"理论 T + 辅助假说 A + 初始条件 C ⇒ 预见 P"，再取观测 ¬P，得 ¬(T∧A∧C)。验收：结论必须写成"三者至少一错"，并逐条列出可独立检验的 A，不许把失败一股脑记在 T 头上。

**特设性豁免识别** —— 触发：理论被否证后，支持者临时加限定。动作：检查新增假设是否带来新的可观察禁令、是否缩小了理论的经验内容。验收：若新版不禁止任何新观察，只是让旧观察重新变"符合"，判为退化性修补。

**可检验度比较** —— 触发：两个理论都还没被推翻，需要选一个。动作：分别列出各自禁止的观察集合，比较集合大小与数值精确度。验收：能明确说出哪个理论"冒更大风险、给出更多可能被证伪的机会"，优先选它。

**基本陈述的公共化** —— 触发：拿"我亲眼看见"当证据。动作：改写为"在某时某地，任何人按此程序可观察到 X"。验收：第二个人复现得了；复现不了的不算经验基础。

## A1｜书中实例
- 第一部分论划界处：波普尔指出实证主义者每次想说清"有意义"，结果只是把划界标准换个说法；"无意义"一词本身带着贬斥意图，真正目标是"消灭形而上学"（抽样1）。这说明"意义"不能替代"划界"。
- 论随机性"解释"处：只要假定世界序列足够长，总会出现一段"所有观察都符合引力定律"的宇宙期，尽管"实际上"只有随机散射（抽样3）。这种解释可套到任何规律上，因此不构成经验解释——正是不可证伪的样板。
- 论假说概率处：不能说假说序列里有"真频率"，因为我们永远无法知道一个假说是否为真；若改用"未被否证/已被否证"之比，任何无限参照序列中每个假说的概率都相等（抽样4）。

## A2｜何时调用 / 与相邻书的区分
- 当用户问"这套说法算科学吗""为什么占星术不是科学"时调用。
- 当实验结果与理论不符、团队争论"是不是理论错了"时，用否证链拆开理论与辅助假说。
- 当某人不断给失败预测打补丁时，用特设性豁免识别判断修补是否退化。
- 与《逻辑学是什么》同问"论证是否成立"，但陈波给的是形式判定（真值表、三段论）；波普尔给的是经验科学的检验结构，关注"预言被观测顶翻"这一环。

## E｜执行步骤
1. 输入：一个主张或理论。动作：写出它禁止的可观察事件清单。产出：至少一条"若 X 则错"。
2. 动作：列出该理论依赖的辅助假说与初始条件，画成 T+A+C ⇒ P 的链条。产出：一张可检查的推演图。
3. 动作：在观测前写死判据（什么结果算不符、误差多大）。产出：预先登记的否证条件。
4. 动作：观测不符时，先逐条排查 A 与 C，再判定 T 是否被否证。产出：责任归属清单。
5. 动作：若理论被修补，比较新旧版本的经验内容。产出：判定"进步"还是"退化"的一句话结论。

## B｜边界与误用
- 不教假说从哪来：发现的心理学被明确排除，卡片不能当创意方法用。
- 现实科学极少"一票否决"：统计检验、测量误差、复杂模型都让否证变成程度问题，直接套"一次反例即推翻"会误伤正常研究。
- 最容易被误用成"你不可证伪所以你是错的"：不可证伪只说明它不是经验科学，不说明其内容为假。
- 对归纳的否定立场较强，且抽样多为脚注与概率技术章节，关于后期修正的部分未覆盖。
