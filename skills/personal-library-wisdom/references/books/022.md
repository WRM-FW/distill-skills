# 《麦克白》 — 威廉·莎士比亚（朱生豪 译）
> 类型：文学 | 原文规模：约 2.5 万字 | 抽样依据（工作档案 udigest/022.md（6 段）

## 一句话
把野心写成可复述的句式：预言只给称号，人自己补上手段。

## R｜原文骨架
- 第一幕 → 军曹报捷、女巫三重预言、邓肯封赏；把"预言"与"奖赏"并置在同一场。
- 第二幕 → 夫人定计、刺杀邓肯、涂血嫁祸侍卫；行动完成，语言开始不够用。
- 第三幕 → 班柯被杀、宴会见鬼；权力从"取得"转入"防守"。
- 第四幕 → 再访女巫、麦克德夫家被屠、马尔康试探麦克德夫；暴政的复制机制。
- 第五幕 → 夫人病、勃南森林移动、麦克白披甲；预言按字面兑现。

## I｜核心命题与可执行方法
**预言的缺口** —— 看预言给了什么、没给什么 → 问："从'你将成为王'到'你去杀王'，这一步是谁补的？" → 会看到：女巫只给称号，手段由听者自己填；预言是触发器，不是原因。

**身份质询** —— 看说服场景攻击的是判断还是资格 → 问："这句话在讨论风险，还是在问'你算不算男人'？" → 会看到：夫人绕开成败计算，直接重定义男子气概与爱情，谋杀于是从"对不对"移到"敢不敢"。

**委婉语追踪** —— 看角色用什么词替代"杀" → 问："这段独白绕开了哪个词？" → 会看到：先说"这件事"，行动才跟上；语言的退让先于道德的退让。

**恐惧的对象** —— 看掌权后他依次杀谁 → 问："他杀的是威胁，还是可能性？" → 会看到：从邓肯到班柯到麦克德夫的家眷，防的是"将来"，所以越防越多。

**病理化政治** —— 看医生与病症被放在什么位置 → 问："谁的病治不好，为什么？" → 会看到：夫人的病"要仗病人自己设法"，国家的病却被要求"验一验小便"；政治被写成无法外治的身体。

## A1｜书中实例
- 第一幕第七场：麦克白说"我们还是不要进行这一件事情吧"，夫人以"我曾经哺乳过婴孩……把它的脑袋砸碎"作答——用极端假设当论据，把犹豫直接定性为怯懦。
- 第三幕第一场：班柯独白承认"你得到这种富贵的手段恐怕不大正当"，紧接着又想女巫关于自己子孙的预言——同一套话在不同人身上生出不同动机。
- 第五幕第三场：麦克白要医生"从记忆中拔去一桩根深蒂固的忧郁"，医生答"那还是要仗病人自己设法的"；同场他下令，谁嘴里提起一句害怕的话就把他吊死。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析"一个决定是怎么被说出口的话一步步推着走完的"时。
- 当用户写权力或野心题材，需要给人物一套自欺的措辞时。
- 当用户想识别身边的说服术：对方在谈事实，还是在谈你的资格。
- 与《喧哗与骚动》同看"家族荣誉如何毁人"：本书给的是决定发生的那一夜，福克纳给的是决定之后三十年的回声。

## E｜执行步骤
1. 取任意说服场景的对话 → 标出"事实句"与"身份句" → 统计比例；身份句占比越高，越接近操纵。
2. 列出全剧所有替代"杀"的说法 → 按出现顺序排列 → 看委婉语如何逐步缩短、直白化。
3. 把一条预言改写成"只有条件、没有手段"的句子 → 让另一角色补手段 → 观察补法暴露的性格。
4. 验收：每条判断落到某场某句台词，不用"人物性格如此"作论据。

## B｜边界与误用
- 朱生豪译文文白夹杂，做语言分析先承认译者在场，别把译文节奏当成莎士比亚的原文节奏。
- 女巫是超自然力量还是人物心理投射，两种读法都能自洽，不要当定论。
- 剧本为演出而写，读台词要补上停顿、旁白与身体动作，否则容易误判人物意图。
- 不提供"野心值不值得"的伦理结论，它只演示代价怎么结算。
