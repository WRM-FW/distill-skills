# 《巴金作品全集：共20册》 — 巴金
> 类型：合集 | 原文规模：约 144.7 万字 | 抽样依据（工作档案 udigest/114.md（6 段）

## 一句话
用账单、病床和矿灯，量出旧家庭与旧制度怎样把人分摊到不同位置。

## R｜原文骨架
抽样落在六部作品上：
- 高家一线（《家》《春》《秋》）→ 用请安、装烟、购物单和遗嘱把几代人绑在一起。
- 《家》的鸣凤线 → 婢女的"顺受"与琴、淑华一辈的"反抗"并置，两种命运同一屋檐。
- 《春》的周家线 → 觉新替舅父采买、领三封银圆，写亲戚间的金钱与体面。

- 《秋》的克明病中 → 卖不卖公馆的争执，把家族解体写成一次财产表决。
- 《第四病室》→ 后方医院十二张病床，姓名退为床号。
- 《砂丁》→ 锡矿里的铁镣、矿灯与涨水，写被卖进去的劳工。
- 《火》→ 上海抗战中的刘波与护士素贞，写私人感情如何被公共责任征用。

## I｜核心命题与可执行方法
**账本透镜** —— 看购物单、银圆封数、谁给谁请安 → 问"钱谁出、这人为什么不能上桌、东西买给谁看" → 会看到家族制度靠礼仪和账目维持，暴力只是它失效后的补丁。

**两张脸透镜** —— 看同一处境下"顺受的"与"反抗的"两张脸 → 问"她们各自有没有退路：钱、学历、娘家、外面的人" → 会看到反抗不是性格，是资源；把勇敢当品质会看漏前提。

**床号透镜** —— 看公共机构里人怎样被编号 → 问"谁在记录、记录给谁看、缺了什么" → 会看到冷漠不是恶意，是流程；十二张床各有故事，只有病情进表格。

**矿灯透镜** —— 看灾难发生时人们先抢什么 → 问"逃生的顺序由什么决定、谁被留在后面" → 会看到排序即阶级：戴镣铐的人爬得最慢，喊"灯要紧"的先丢了锄头。

**情话换算透镜** —— 看恋人怎样把私情翻译成公共理由 → 问"他用了哪个大词、这词替谁做了决定" → 会看到大叙事进入亲密关系的方式，常是替对方安排牺牲。

## A1｜书中实例
- 《家》：鸣凤被太太喊去装烟，淑华当面责骂她"你又不是哑巴"，觉慧躲在黑暗里听着，"这些话一字一字地送进了觉慧的耳里"；他想辩护，"然而有什么东西在后面拉住他"，终于不作声。
- 《春》：周伯涛俯在案上开列应购物品单子，两位舅母在旁贡献意见，枚少爷"怯生生地站在另一边旁观"，不敢动一下；陈氏搬出三封银圆，每封一百枚，交给觉新代买。
- 《砂丁》：矿井涨水，众人戴铁镣爬，老张的灯落水熄了；后面的人喊"当心灯，灯要紧"，同时"除了两三个人外大家都早把锄丢了"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析中国式家庭的权力结构，需要从礼数和账目入手，而不是从"封建"这个词入手时。
- 当用户处理机构中的去人格化（医院、工厂、宿舍），想找可写细节时。
- 当用户写群像，需要学用一次采购、一顿饭、一张病床交代一批人时。
- 与《流言》同写都市日常，区别在：张爱玲停在一张脸和一个藉口上，巴金把细节推到家产分配与制度更替。

## E｜执行步骤
1. 输入一个家庭或团队。动作：找一张真实账单，标出付款人、经手人、受益人。产出：三方关系图。
2. 动作：找出同一处境下的两个人，写下她们可动用的资源（钱、学历、亲戚）。验收：能解释为什么一个忍、一个走。
3. 动作：写一个公共空间（病房、车间、宿舍）的 400 字，只允许写编号、流程和对话，不许写心理。
4. 动作：把一段私人争执改写成两个人各自引用"大局"的对话。验收：读者能看出谁在用大词换对方的让步。

## B｜边界与误用
- 二十册差异极大，早期小说与晚年随笔的可信度不同，不能混着引用。
- 最易被误用为"反封建"口号文本，把人物当立场标签，忽略对软弱者的体谅。
- 部分作品（如《火》）宣传色彩重，人物近乎理念的传声筒，分析时须指出。
- 女性价值多由婚姻与牺牲衡量，沿用会带回原书的性别盲区。
