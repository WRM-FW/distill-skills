# 《我与地坛》 — 史铁生
> 类型：文学 | 原文规模：约 8.3 万字 | 抽样依据（工作档案 udigest/143.md（6 段）

## 一句话
把残疾、丧亲、被困写成有地点、有路线、有旁人的日常，用来练不煽情的自述。

## R｜原文骨架
- 我与地坛 → 十五年反复进入同一座园子，写母亲、老人夫妇、唱歌青年、长跑者。
- 我二十一岁那年 / 合欢树 / 秋天的怀念 → 写病、写母亲、写"子欲养"的具体物证。
- 墙下短记 → 由实墙推到"秘密""意义""命运"的墙。
- 黄土地情歌 / 我的梦想 / 好运设计 → 写插队、写愿望、写"如果一切顺利"的反向推演。
- 记忆与印象1、2 → 童年院落群像：奶奶、珊珊、庄子、雪儿。
- 想念地坛 / 扶轮问路（代跋） → 回望园子与写作本身。

## I｜核心命题与可执行方法
- **路线即思想** —— 看一个人每天怎么走 → 问"他为什么总在同一段路停" → 会看到思考有坐标：东北角的树林、祭坛东侧的小路，都是问题被想通或想不通的位置。
- **墙的双层读法** —— 看实墙如何转成"秘密" → 问"这道墙防谁、护谁" → 会看到"肚皮和眼皮都是墙，假笑和伪哭都是墙"：限制不是要被拆除的东西，它是趣味与意义的来源。
- **用别人的时间量自己** —— 看那些陌生人（老人夫妇从中年走到老年、唱歌青年忽然不见） → 问"为什么记住他们" → 会看到停滞的人靠他人的变化确认时间还在走。
- **母亲的沉默** —— 看母亲做了什么而没说什么 → 问"她为什么站在门外不进来" → 会看到爱以不打扰的形式出现，也因此更难写。
- **声音先于意义** —— 看庙里的诵经、钟鼓 → 问"这段经验为什么说不清却记得" → 会看到感官记忆的存档方式："很多事可以不懂但能够知道"。
- **好运设计的代价** —— 看"如果一切顺利"的推演 → 问"他把苦难安排在了哪一格" → 会看到自我安慰的技术：先设计完美，再证明完美无法承受。

## A1｜书中实例
- 那对老人夫妇十五年逆时针绕园子，男人肩宽腿长、上身挺直不动，"女人像是贴在高大的丈夫身上跟着漂移"；彼此从未说过话，叙述者看着他们从中年情侣变成两个老人。（我与地坛 四）
- 邻居女孩珊珊被继母打，跑了；众人议论她是不是"找她亲妈去了"，叙述者说"要是我，我就去找我亲妈"，被奶奶喝止。（记忆与印象）
- 十九岁的庄子死于一场群殴，"混战中不知是谁，一刀恰中庄子心脏"；最流传的说法是为一个女孩，鲶鱼说"绝对没那么回事"。（记忆与印象）

## A2｜何时调用 / 与相邻书的区分
- 当用户要写疾病、丧亲、长期困境中的自述时。
- 当用户想把"想不通"写成可读的思辨而不是金句时。
- 当用户练地点写作：用一个反复去的地方承载多年变化。
- 当用户需要克制抒情、避开"感动"腔调时。
- 与《四合如意》都靠日常细节：张怡微用细节算账，史铁生用细节存时间；一个向外看人情，一个向内看念头。

## E｜执行步骤
1. 输入一个你反复去的地点。动作：写下路线、固定时段、你会停的那一处。产出：三百字，不写心情。
2. 动作：记录三个常年出现在那里的陌生人，只写外形与动作的变化。验收：时间感由他们承担，不由形容词承担。
3. 动作：选一件与逝者有关的实物，写它现在的位置和状态。验收：不出现"怀念"二字。
4. 动作：把一段"想不通"写成一次具体推演（如果A，则B），允许没有结论。验收：读者能跟着走完，而不是被劝服。

## B｜边界与误用
- 散文而非方法，不能当残障议题或心理建议使用。
- 命运、上帝、意义的解释属个人信念，引用时需标明这是书中人的答案。
- "好运设计"易被读成鸡汤，其真正内容是反证，不是励志。
- 写作年代在上世纪八九十年代，北京院落、插队、票证等背景需注释。
