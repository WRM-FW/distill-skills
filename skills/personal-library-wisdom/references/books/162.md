# 《沧浪之水》 — 阎真
> 类型：文学 | 原文规模：约 23.7 万字 | 抽样依据（工作档案 udigest/162.md（6 段）

## 一句话
把单位里的每句话拆成三层：字面、关系、交易，看中国人怎么把话说圆。

## R｜原文骨架
- 开篇（抽样1）→ 池大为报到，刘主任、马厅长、申科长轮流出场；分房一事把"看重"立为全书的通用货币。
- 中段（抽样2、3）→ 为妻子调动奔走、胡一兵劝其下海，"只有骗子是真的"与"清高和善良是怯懦的另一种说法"两种判词对撞。
- 后段（抽样4、5）→ 沈姨家的连环奉承、医院里的报信，池大为从被动挨打转为主动出手。
- 尾声（抽样6）→ 与孟晓敏重逢，被问"你害了我"，代价问题被翻出来。
- 体例 → 无章节标题，第一人称内心独白推进，场景几乎全在机关、家庭、饭桌三处。

## I｜核心命题与可执行方法
**称谓透镜** —— 看谁在什么时刻改口（小池／大为／池处长）→ 问改称呼前后发生了什么、谁先改 → 会看到称呼是位置的体温计；孟晓敏叫他"池大为"时，他"心中似乎转了个弯才想明白"。

**三层解码** —— 看一句奉承话的三层 → 问字面夸谁、关系上踩谁、交易上想让谁听见 → 会看到"有些人你给他个面子，他还要顺着竿子爬个没完"一句里同时办了夸马厅长、踩同类、自证不贪三件事。

**信息定价** —— 看谁知道得早、谁去告诉谁 → 问这条消息值多少、为什么必须当面说 → 会看到信息不是知识，是关键时刻可以兑换的筹码。

**人情复式账** —— 看小恩小惠的往来（分房、搭车、照看孩子）→ 问这笔记在谁头上、什么时候要还 → 会看到人情不是感情，是一份没有合同的债务。

**清高的成本** —— 看拒绝一次交易之后代价落在谁身上 → 问谁在挤公交、谁在陪笑脸 → 会看到道德选择的账单常由家人支付。

## A1｜书中实例
抽样1，申科长带池大为看房，一路介绍厅里情况，末了自述："八年！八路军一场抗战都打完了，我还坐在这里。"一句话把资历、怨气和对新人的示好全装进去。

抽样2，耿院长说"只有骗子是真的"。池大为回办公室关起门，抓着头发把自己往上拔，一边跳一边"呱！呱！呱！"——屈辱最后只能落在身体上。

抽样4，沈姨家里，池大为与董柳一唱一和，把马厅长夸到"要是马厅长管的范围再大一些，就是全省人民的福气了"，沈姨"望着我很神秘地笑了一笑"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要判断单位里一句客气话到底什么意思时。
- 当用户要写职场、官场小说，需要"话里有话"的对话样本时。
- 当用户想分析一个人如何在体制内逐步改变说话方式时。
- 与《一句顶一万句》同写说话：本书研究"说得着"的技术，《一句顶一万句》研究"说不着"的孤独。与《活着》同写忍耐：福贵忍的是命，池大为忍的是位置。

## E｜执行步骤
1. 截取一段三人以上对话 → 每句话填三栏：字面义／关系义／交易义 → 产出解码表。
2. 标出称呼变化与在场者名单 → 追问谁被排除在这句话之外。
3. 找出全段唯一没有说出口的请求 → 把它补写出来 → 看是否会破坏场面。
4. 同一件事写两份汇报，一份给上级、一份给配偶 → 对比删了什么 → 验收：两份都成立，但事实不同。

## B｜边界与误用
- 把官场规则写成普遍人性，容易滑向"人人如此"的宿命论，抹掉人物的选择空间。
- 女性多为欲望或助力角色（董柳的调动、孟晓敏的旧情），缺少独立动机。
- 视野限于省级机关，基层与体制外几乎不出现。
- 后期池大为的自省停在道德自责，没有制度层面的出口，读的时候要自己补上这一层。
