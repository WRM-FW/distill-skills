# 《浮生六记》 — 沈复
> 类型：经典 | 原文规模：约 10.5 万字（周公度译注本，含注） | 抽样依据（工作档案 udigest/013.md（6 段，另含张佳玮译本）

## 一句话
把风雅拆成开销、把夫妻写成同谋，看礼法怎样用一句闲话把人逐出家门。

## R｜原文骨架
- 卷一 闺房记乐 → 初见、吃粥、洞房、别后重逢、沧浪亭消夏论诗；立起两人世界的日常尺度。
- 卷二 闲情记趣 → 插花、盆景、园林章法、雇馄饨担子去南园对花热饮；把雅趣拆成可操作的手艺。
- 卷三 坎坷记愁 → 失欢于翁姑、被小叔诬陷、为友作保被累、芸病、父亲去世后奔丧被追债。
- 卷四 浪游记快 → 寒山登高访隐居地、潼关、潼川“不系之舟”；以游历安放无处安身的处境。
- 卷五 中山记历、卷六 养生记道 → 张佳玮译本标为“[佚]”（学界多视为后人伪托），宜作史料读，不作沈复亲笔读。
- 各版序跋、王韬跋、沈复年谱 → 出版与接受材料，与正文分层引用。

## I｜核心命题与可执行方法
**雅趣的成本** —— 看每件雅事前后出现的银钱、典当、借贷 → 问“这一场风雅花了多少，钱从哪里来” → 梅花盒、馄饨担、插花都不免费；审美生活有一本明细账。

**共谋式夫妻** —— 看两人如何绕过礼法（托词、雇担子、私下出行）→ 问“主意是谁出的，风险谁担” → 芸是策划者，沈复是记录者；亲密关系的实质是共同作案。

**礼法的解释权** —— 看每次获罪的触发点 → 问“谁有资格解释规矩” → 不是有人作恶，而是父、姑、弟垄断了“规矩”的解释权；一封信、一句谗言就足以把人逐出家门。

**物件的证词** —— 看反复出现的物件（粥、茉莉、佛手、兰影、梅花盒）→ 问“这物件在谁手里、被谁记住” → 情感靠物证存活，“藏粥”既是定情也是日后的把柄。

**雅言的遮掩** —— 看叙述者把什么写得轻、把什么写得重 → 问“这段为什么用这么雅的词” → 越是窘迫处笔调越含蓄；文体本身就是一种自我保护。

## A1｜书中实例
- 沧浪亭消夏（卷一）：六月酷热，请示母亲后带芸住进临水的“我取”轩；芸不善饮，“勉强着可以喝三杯”；论诗时她说“与其学杜甫的森严，不如学李白的活泼”。
- 南园看花（卷二，张佳玮译本）：众人苦于对花冷饮，芸说“我自担炉火来”，实际是花一百钱雇鲍姓馄饨担子，用砂罐架在行灶上煎茶。
- 奔丧被追债（卷三）：父亲骨肉未寒，讨债的登门；他对弟弟启堂说“大丈夫贵在自立，我既然一个人来，仍将一个人回去”，随后住进朋友安排的禅寺大悲阁。

## A2｜何时调用 / 与相邻书的区分
- 当用户想把“雅事”还原成开销与人力，写日常生活的物质基础时。
- 当用户分析中国传统家庭里“规矩”由哪些具体的人执行时。
- 当用户写第一人称回忆，想学克制的抒情时。
- 与《干校六记》同写困境中的日常技术：沈复在礼法缝隙里摆弄器物，杨绛在制度缝隙里凿井种菜；一个为审美，一个为生存。

## E｜执行步骤
1. 输入任一卷 → 标出所有钱、物、人情的往来 → 产出收支与亏欠表 → 验收：能指出哪一笔享受挪用了哪一笔必需。
2. 输入一次获罪事件 → 还原“谁说了什么—谁信了—谁执行” → 产出归责链 → 验收：链条末端必须落到具体的解释者，而不是“封建礼教”。
3. 输入一件反复出现的物件 → 追踪它在三个场景里的用途 → 产出物件传记 → 验收：同一物件在不同场景承担不同功能。
4. 写作训练：写 300 字一次出游，只写准备与收拾，不写风景 → 验收：读者能从准备工作看出这家的经济状况与关系。

## B｜边界与误用
- 卷五、卷六的归属有争议，张佳玮译本已标“[佚]”；引用养生、琉球部分不要当作沈复亲历。
- 沈复的自述有自我美化，“多情”与“无能”常被混为一谈；芸的形象经他的笔写成，不能直接当女性自述。
- 纳妾、狎妓等情节是当时士人生活实录，读时须放回语境，不宜当浪漫范本。
- 两个译本差异明显（周公度本注细，张佳玮本口语化），引文须注明版本。
