# 《我的奋斗（给剽悍的人生一个解释）》 — 罗永浩
> 类型：传记 | 原文规模：约 2.5 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/116.md（6 段）

## 一句话
用一个人的偏科成长史，给出一套检查"自己是否还在独立思考"的粗筛办法。

## R｜原文骨架
- 「1972～1990，从出生到长大成人」→ 家庭、阅读、校园暴力的早期样本，交代性格的来处。
- 童年读物（《七把叉》、县委机关图书室）→ 读书的复合动机：喜欢，加上能换来敬佩。
- 小学与中学的教师、同学群像 → 教育如何提前把人分类并放弃。
- 旅游鞋与青春期 → 地方观念的时间差、面子如何支配判断。
- 读者问答（选修课、独立思考、在乎什么、二十年变化）→ 把态度压成可回答的问题。
- 演讲段落 → 对"成熟"的正面反驳。

## I｜核心命题与可执行方法
**动机双账** —— 做一件"看起来正确"的事时 → 同时写下崇高动机与现实收益（他承认读书能换来"你懂得可真多"的目光）→ 验收：两栏都写得出来，且不因第二栏羞耻；写不出第二栏的，多半在自我美化。

**独立思考粗筛** —— 怀疑自己被话术包围时 → 拿三份不同立场的主流文本对读（他的做法是《人民日报》《新闻联播》，再找一个立场鲜明的博客）→ 验收：能指出哪一句"不像人话"，并说出它在替谁说话。

**早介入原则** —— 要改变一个系统时 → 优先选最小年龄段（问他进哪一级学校，他选小学，理由是"脑子被弄坏了的人长大了之后能改造回来的不是很多"）→ 验收：干预点落在习惯成型之前，而不是补救阶段。

**情绪当信号** —— 你对某类事持续愤怒时 → 反查它对应哪一种被侵犯的价值（"对假、恶、丑的愤怒都是因为对真、善、美的热爱"）→ 验收：能把愤怒翻译成一条有对象、有动作的主张。

**成熟度证伪** —— 有人说"你以后就懂了"时 → 问他把什么换成了什么（他回敬老同学的是"你已经把世界变得恶心了"）→ 验收：对方说得出交换的具体代价，否则那只是投降的修辞。

## A1｜书中实例
- 抽样 1（1972 年，吉林和龙县龙门公社）：父母下放期间生下他，说是"失手怀上"，因为乡下医务所条件差才没堕胎。他小时候反复被告知这件事，一度为此"出过许多身冷汗"。
- 抽样 2（童年阅读）：他把家里旧书看完，去父亲单位的县委机关图书室借书；看书早，让他在学校获得"女同学敬佩的目光"，他明说这是动力之一。
- 抽样 5（读者问答）：被问"如何知道自己是否有独立思考的能力"，他答"希望他们学会思考，这比知识重要得多"，并给出对读三份文本、看是否"句句都不像人话"的粗筛法。

## A2｜何时调用 / 与相邻书的区分
- 当用户想检查自己是否被环境驯化时调用。
- 当用户想给"成熟""现实一点"这类劝告祛魅时调用。
- 当用户要设计一个最小可行的教育或培训干预时调用。
- 当用户想理解一代人的校园经验与阅读史时调用。
- 与 110《创业在路上》同作者：116 谈人怎么长成，110 谈企业怎么活；116 多是态度宣言，缺可验证流程，需要 110 补条款。与 117《三重门》同写少年成长，116 是当事人自述并直接下判断。

## E｜执行步骤
1. 输入：一句你最近常说的"没办法，大家都这样"。
2. 动作：写下这句话替你省掉了哪次冲突、哪笔收益、哪个具体的人。
3. 动作：用三文本对读法，找一份与你立场相反的材料，只标"替谁说话"的句子。
4. 动作：挑一条你最近的愤怒，翻译成主张：对象、要求、时限各一项。
5. 产出：一段两百字的自我说明，要求能被别人当场反驳。

## B｜边界与误用
- 演讲体，笑点和情绪密度高，论断常以反问收尾，不能当证据使用。
- 对教育的判断（"脑子被弄坏了"）粗放，几乎不给反例，照此推论会低估成年后的改变可能。
- 抽样覆盖童年到青春期与读者问答；成年后的职业选择、英语培训经历抽样未覆盖。
