# 《活着》 — 余华
> 类型：文学 | 原文规模：约 5.6 万字 | 抽样依据（工作档案 udigest/148.md（6 段）

## 一句话
把一个人的一生折成一本收支账：力气、粮食、名字，怎么算才算得下去。

## R｜原文骨架
- 作者简介 → 只给最低限度的作者信息，不介入正文。
- 第一至十章（无小标题）→ 福贵第一人称顺序讲述，章与章之间不做时间标记，读者靠"谁又没了"来定位年份。
- 采风者框架（抽样1）→ "我"坐在树下听，苦难先过一层耳朵，全书是转述而非自述。
- 牛与田（抽样1、2）→ 反复出现的计量单位是亩、季、口、顿；进度条是粮食，不是年份。
- 丧事序列（抽样3—6）→ 每次死人后面都跟一次分配：送人、分糖、分粥、留屋。死亡被写成家务。

## I｜核心命题与可执行方法
**算账透镜** —— 看每段对话里的数量词（五亩、三堆、四只手、一个季节）→ 问谁在算、算给谁听、哪一笔被漏掉 → 会看到苦难不是被感受的，是被折算成可承受的单位，而漏掉的那一笔通常是人。

**骗的伦理** —— 看谁对谁说了不真的话，以及这句话的用途 → 问这个谎让谁继续干活、被骗的人有没有获益 → 会看到善意谎言是一种维持秩序的技术，不是道德例外。

**身体的替话** —— 看该说话的地方出现了什么动作（低头、睁圆眼睛、用烂泥堵伤口、嘴巴一动一动）→ 问哪句话被身体替掉了、谁没有发言位置 → 会看到沉默不是没有内容，是被分配了别的载体。

**归因的分工** —— 看灾祸之后人物把原因归给谁（天、国家、命、自己不够勤快）→ 问哪些归天、哪些归己 → 会看到"笨鸟多飞"把结构问题翻译成个人勤勉，人因此还能起床。

**转述的损耗** —— 看"我"站在什么位置 → 问这个故事经过几张嘴、讲述者为什么挑这个时候讲 → 会看到回忆本身是一次整理，把不能忍受的部分修剪掉了。

## A1｜书中实例
抽样1，老人对牛喊出好几个名字："我怕牠知道只有自己在耕田，就多叫出几个名字去骗牠。"这是全书方法的缩影：用一个谎维持一天的力气。

抽样3，送凤霞给人。福贵把镰刀篮子扔到角落，说"我下地了……别来见我"，到了田里"总觉得劲使不到点子上"。丧女之痛被写成使不上劲。

抽样4，有庆分糖，分成三堆，从另两堆各拿两颗给自己，再放回去，最后"还是只有三堆"，其中没有父亲的。分配动作暴露了他在家里的位置。

## A2｜何时调用 / 与相邻书的区分
- 当用户想分析"中国式忍受"的具体机制，而不是笼统谈苦难时。
- 当用户要写不控诉的丧亲叙事，需要"把情绪换成动作"的样本时。
- 当用户判断一段苦难叙事是否在消费苦难，用"谁在算账、谁被算掉"这把尺。
- 与《第七天》同写死亡：本书问活着的人怎么把日子算下去，《第七天》问死者怎么排队、谁先火化。与《现实一种》同写余华的暴力：本书的暴力由时代和贫穷执行，后者由家人之间的日常动作执行。

## E｜执行步骤
1. 取一段含分配的对话（分糖、租田、送人）→ 抄出所有数量词与亲属称谓 → 产出一张"谁得到多少"的表。
2. 在表上标出"谁没有被分到" → 追问这个人为什么不出声 → 产出一句被省略的台词。
3. 找出这段里被身体替代的情绪 → 改写成一句直接抒情 → 比较哪个更假。
4. 用"只写动作和数目、不写感受"的规则重写自己的一段经历，300 字 → 验收：全文不出现"难过""痛苦"。

## B｜边界与误用
- 不提供饥荒与运动的结构分析，历史只作为背景音，不能当史料。
- 把福贵的忍受读成"中国人的美德"是最常见的误用；文本展示的是忍受的技术，不是忍受的正当性。
- 叙述经过几十年回忆的修剪，福贵的美化与省略本身是文本效果，不宜当事实证词。
- 家珍、凤霞的苦多作为福贵的经验出现，女性视角在结构上是缺失的。
