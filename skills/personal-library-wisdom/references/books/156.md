# 《第七天》 — 余华
> 类型：文学 | 原文规模：约 6.1 万字 | 抽样依据（工作档案 udigest/156.md（6 段）

## 一句话
把死后世界写成一座办事大厅：看中国人怎么排队、怎么被叫号、怎么互相收尸。

## R｜原文骨架
- 第一天 → 殡仪馆候烧区，塑料椅与沙发分区，进口炉与国产炉分工；死后第一件事是排队。
- 第二天 → 与前妻李青重逢，靠睡衣上的名字和一张错位的脸相认。
- 第三天 → 回到生父母家，旁观一场关于房子、离婚、跳楼的争吵。
- 第四天 → 进入"死无葬身之地"，骨骼下棋、婴儿唱歌，一个无户籍的共同体成形。
- 第五、六天 → 李月珍与二十七个孩子；鼠妹净身，众人排队端水送行。
- 第七天 → 鼠妹去墓地安息，叙述转向寻找父亲。

## I｜核心命题与可执行方法
**排队透镜** —— 看空间分区与叫号规则（塑料椅／沙发、进口炉／国产炉）→ 问谁定的队、被问的人为什么总说"这个我不知道" → 会看到等级不靠暴力维持，靠一套没人负责的流程。

**修补透镜** —— 看身体错位与修复（眼珠、鼻子、下巴被一一放回）→ 问谁有资格替别人修、生前为什么修不了 → 会看到死亡提供了生前没有的体面，这既是反讽也是补偿。

**借词透镜** —— 看从生前借来的词（贵宾、叫号、回头率、婚纱）→ 问它原本属于哪个系统、挪到死后还成不成立 → 会看到消费与行政语言已经殖民了人对死亡的理解。

**无血缘的家** —— 看谁在照顾谁（二十七个孩子、众人给鼠妹净身）→ 问没有户口、没有亲属，凭什么组成家 → 会看到共同体靠重复的照料动作成立，不靠制度承认。

**不肯讲的故事** —— 看骨骼说"那边的故事里我们的最出名"，然后不讲了 → 问谁被允许讲述、为什么最出名的反而沉默 → 会看到记忆也有排队顺序。

## A1｜书中实例
抽样1，候烧区里有人追问"为什么非要等到市长烧了，才烧我们"，穿蓝衣服的人一律答"这个我不知道"；进口炉留给贵宾，国产炉给他们。规则执行得很熟练，责任却无人认领。

抽样3，生父母家的争吵从"同学的父母有权有势"升级到离婚协议、跳楼、下跪、自己打嘴巴；生父生母关门睡觉，"他们已经习惯这样的争吵"。

抽样6，众人簇拥鼠妹走向安息之地，反复说她的殓衣"看上去像婚纱"，她答"可是我不是去出嫁"。安慰的话越说越顺，悲伤就越难出口。

## A2｜何时调用 / 与相邻书的区分
- 当用户想分析"制度如何通过流程分配尊严"时。
- 当用户要写用死者视角讲现实的故事，需要处理视角合法性时。
- 当用户需要辨认"安慰性叙事"何时变成遮蔽时。
- 与《活着》同一作者：活着是幸存者的账本，本书是死者的行政流程。与《现实一种》相比，本书的暴力由流程执行，一滴血也不用流。

## E｜执行步骤
1. 选一个你熟悉的排队场景（医院、办事大厅、殡仪馆）→ 画出空间分区与准入规则 → 产出一张"谁能进哪里"的图。
2. 抄下现场所有官方话术 → 逐句标注它回答了什麼、回避了什麼 → 产出一份话术清单。
3. 找出三个从生前借来的词 → 还原它原本的系统 → 判断它在此处是否失效。
4. 用死者视角重写这个场景 400 字 → 验收：不出现"批判""讽刺"等评论词，只写流程。

## B｜边界与误用
- 讽刺直露，人物常承担控诉功能，性格单薄，容易被当成新闻评论读。
- 对现实事件的影射依赖读者已知的新闻背景，时过境迁后效力下降。
- "死无葬身之地"的温情段落容易把结构问题转成情感安慰，读者哭完就结束了。
- 不宜当作具体事件的事实记述，它是有意寓言化的。
