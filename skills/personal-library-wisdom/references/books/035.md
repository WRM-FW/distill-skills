# 《古兰经》 — 马坚 译，谢赫穆罕默德·安萨里 导读

> 类型：经典 | 原文规模：约 49.7 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/035.md（6 段）

## 一句话
一百一十四章按苏勒编排、每章先导读后译文，可据"同一先知故事的复述差异"做主题串经。

## R｜原文骨架
- 编排层：章名＋章序（开端、黄牛、仪姆兰的家属、妇女、筵席……大事），章节标题只列出前五十六章，解决"章名作为记忆钩子与检索入口"。
- 导读层（安萨里）：逐章给历史背景与当代议题，如黄牛章用十六处经文讲以色列后裔的教训（抽样1）。
- 译文层（马坚）：分节编号，如 17:1-16、28:62-77、71:13-28，解决"经文的精确定位"。
- 叙事章（高处、呼德、优素福、努哈）：同一先知事迹分散在多章，努哈在 71 章与 11:25-49 各有一版，导读明说前者"不再重复"洪水过程（抽样6）。
- 律例与论辩章（妇女、筵席、协商）：以"他们说……你说……"的诘问句式推进。

## I｜核心命题与可执行方法
**复述差异比对** —— 看同一先知故事在两章 → 问"这章省略什么、补什么、把重点移到哪" → 会看到 71 章略去洪水过程，改述"真理与邪恶的对抗"，取材服务于论点而非纪事。
**章名索题** —— 看章名（黄牛、蜘蛛、协商、队伍） → 问"章名取自哪一节、那一节在章中什么位置" → 会看到章名多取自一个突兀意象，是记忆钩子，不是内容提要。
**导读与经文分层** —— 看导读的断言 → 问"它引了哪几节支撑、哪些是导读自己的推论" → 会看到导读属于解释传统，引用时必须与译文分栏标注，否则把注家当经文。
**审判场景的问答结构** —— 看 28:62-75 的"在那日，真主将召唤他们说" → 问"被问者如何回答、答不上来意味着什么" → 会看到场景靠"提问—失语—定罪"推进，论证力来自对方的沉默。
**此世与后世的对照句** —— 看 17:11-15 → 问"今世的急躁如何对应后世的账簿" → 会看到"行为附着在脖子上""你读你的本子"把伦理写成可结算的账。
**称谓与立场标记** —— 看"信道者／不信道者／曾受经典者"的分布 → 问"这一段在对谁说话" → 会看到同一教训因听众不同而改变语气与举证方式。

## A1｜书中实例
- 黄牛章导读：引 2:49 讲以色列人在法老治下被屠杀儿子、留存女子，说明该章十六处经文针对犹太人的历史教训（抽样1）。
- 夜行章 17:13-15："我使每个人的行为附着在他的脖子上"，复活日"你读你的本子吧"（抽样3）。
- 努哈章导读：明说该章不重复"呼德章"陈述过的洪水故事，而阐述真理与邪恶的对抗（抽样6）。

## A2｜何时调用 / 与相邻书的区分
- 当用户问某节经文出处、需要章:节定位时调用。
- 当要比较同一先知故事在不同苏勒的写法时调用。
- 当需要区分"译文"与"导读观点"、避免把注家当经文时调用。
- 当分析经文的论辩句式（诘问、反问、对偶）时调用。
- 与《圣经》卡同做经文查考：圣经卡靠跨书卷平行叙事与双语校读，本书卡靠同章异苏勒的复述差异。

## E｜执行步骤
1. 输入：一个主题（如"赦宥""忏悔""施舍"）。动作：用章名与节号索引找出全部节点。产出：主题—节号清单。
2. 动作：每处抄下本节及前后各一节。产出：带上下文的摘录。
3. 动作：标注该章属于麦加时期还是麦地那时期，比较语气差异。产出：语境标注表。
4. 动作：把导读的句子与译文分栏，标出哪句无经文支撑。产出：双层笔记。
5. 动作：输出"主题—节号—语境—导读说法"四列表。产出：一页专题查考。

## B｜边界与误用
- 译文是马坚个人译本，导读是当代学者之作，二者都不是"经文本身"；导读观点不能当教义定论。
- 抽样 6 段、章节表仅到 56 章，麦地那后期章节与律例细节覆盖不足。
- 本书不处理教法裁决与阿拉伯语词源，遇到具体教法问题须另查注疏。
- 最易误用：把导读的慷慨陈词当作经文原话引用，或把单节从苏勒整体中切出。
