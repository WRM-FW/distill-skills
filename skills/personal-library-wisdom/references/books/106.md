# 《尘埃落定》 — 阿来
> 类型：文学 | 原文规模：约 15.5 万字 | 抽样依据（工作档案 udigest/106.md（6 段）

## 一句话
用一个被公认的"傻子"当观测点，拆解权力场里谁在算账、谁在演戏、谁在看戏。

## R｜原文骨架
- 全书不分卷，以麦其土司家二少爷（"傻子"）的第一人称回忆推进，章节以事件命名。
- 少年部分：喇嘛治病、母亲与奶娘、官寨三层的空间秩序，先立起土司家的等级与日常。
- 外来者部分：查尔斯传教士带自鸣钟进官寨，军政府大员、黄师爷、照相机依次到来。
- 经济部分：种罂粟还是种粮食的决策、边界市场、饥民施粥，把权力写成粮价。
- 战争部分：茸贡女土司与拉雪巴土司相争，麦其家供粮供枪，胜负被第三方定价。
- 终局部分：官寨碉楼在地动中崩塌一角，土司们沉溺妓院与梅毒，黄师爷说"他们来了"。

## I｜核心命题与可执行方法
**傻子位置透镜** —— 看一个人人都不防备的角色怎样被允许在场 → 问"他哪句是装傻、哪句是真不知道" → 会看到无威胁的位置最接近全景，聪明人因要维持聪明而看不见。

**下种博弈透镜** —— 看一次种植或投资前的等待 → 问"他在等谁的消息、误了农时的代价多大、对手也在等谁" → 会看到经济决策本质是信息战，不是道德选择。

**边界定价透镜** —— 看第三方怎样在别人的战争里收钱 → 问"他卖给谁、卖什么、什么时候停" → 会看到"中立"不是不参与，而是掌握定价权的另一种说法。

**器物顺序透镜** —— 看自鸣钟、机枪、梅毒进入领地的先后 → 问"这件新东西进来后，谁的地位变了、谁的解释失效了" → 会看到现代性按物件排队抵达，每件都重排一次等级。

**倒计时透镜** —— 看哪个细节在预告旧秩序到期 → 问"这征兆当时被谁注意到、谁故意没注意" → 会看到历史转折被写成一次地动：先塌一角，再等下一次。

## A1｜书中实例
- 种粮决策：父亲把询问的目光转向"我"，哥哥与侍女塔娜都说种罂粟，"我"偏说"粮食，全部种粮食"，父亲答"我也是这样想的"，哥哥冲出房去。
- 边界一战：父亲留下"该怎么干就怎么干"，"我"便用粮食把茸贡家人马喂饱，暗中对付饿着肚子的拉雪巴人马，又给女土司派机枪手和投弹手，"一场土司间的战争刚刚开始，胜负就要由我来决定了"。
- 查尔斯进官寨：他献上一座镶珐琅的自鸣钟；土司问"你给我们带来什么好处"，又问他的上帝是不是佛陀，觉得"两者间区别过于微妙"，便说"来了就是我们的客人"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析一个组织里"谁是真傻、谁是装傻"，或想找不被设防的观察位时。
- 当用户面对一次重大下注（种植、投资、转型），需要拆出各方的信息依赖时。
- 当用户写多民族、边疆、制度转型题材，需要处理"外来器物"的落地节奏时。
- 与《晚熟的人》同写权力与变现，区别在：莫言看旧结构今天的残值，阿来看它被粮价、枪械和疾病掏空。

## E｜执行步骤
1. 输入一个权力场（公司、家族、项目组）。动作：画出三层空间，标出谁住哪层、谁能进哪扇门。产出：一张等级地图。
2. 动作：找出场内最不被防备的人，逐条记下他听到的话。验收：至少三条是别人不设防才说的。
3. 动作：复盘一次集体决策，列出各方在等谁的消息。产出：一张"信息依赖表"，标出谁先动、谁只能跟。
4. 动作：写 600 字该场景，全用傻子视角，只陈述见闻，不解释动机。

## B｜边界与误用
- 傻子视角是高度人为的设计，不能当成"边缘人天然客观"的证据。
- 最易被误用为藏族风情读物，把土司制度读成奇观，忽略真正主题是权力如何计算。
- 女性人物多为功能位，身体描写带明显男性视角，分析时需指出。
- 对制度崩溃后的"新秩序"几乎没展开，止于"他们来了"，不能回答替代方案。
