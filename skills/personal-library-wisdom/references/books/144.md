# 《深度工作》 — 卡尔·纽波特
> 类型：论说 | 原文规模：约 10.4 万字 | 抽样依据（工作档案 udigest/144.md（6 段）

## 一句话
把无干扰的高强度认知当成稀缺产能来排程，用日程、仪式和收工线把它守住。

## R｜原文骨架
- 第一部分「理论」：第 1 章 深度工作是有价值的 → 快速学难技能、精英级产出、三类赢家（高级技术工人、超级明星、所有者）。
- 第 2 章 深度工作是少见的 → 度量黑洞、最小阻力原则、忙碌代表生产能力、对互联网的顶礼膜拜。
- 第 3 章 深度工作是有意义的 → 从神经学、心理学、哲学三条路论证。
- 第二部分「准则」：准则 1 工作要深入（选定深度哲学、习惯化、大手笔、不要独自工作、像经商一样执行、图安逸）。
- 准则 2 拥抱无聊／准则 3 远离社交媒体（关键少数法则、手艺人方法）／准则 4 摒弃浮浅（逐分钟计划、浮浅预算、五点半收工、变得不容易联系到）。

## I｜核心命题与可执行方法
**选一种深度哲学** —— 先算每周能被保护的整块时间 → 四选一：禁欲主义（长期断联）、双峰（按周或月切块）、节奏（每天固定时段，链条法）、新闻记者（有空档就切入）→ 验收：连续两周，选定时段的实际发生率不低于八成。

**给时段写四要素** —— 进时段前 → 写清在哪、多久、做什么、成功标准（如"写完 1200 字"），材料备齐、网络断开 → 验收：时段结束能对着标准打勾；中途查手机记一次失败。

**像经商一样执行** —— 定季度目标 → 只留一到两个最重要目标，各配一个可量化的领先指标，做一块每周更新的记分板 → 验收：记分板每周有数字，且能看出投入与产出的关系。

**手艺人方法选工具** —— 想装一个新工具或平台 → 先写下职业与生活里决定成功和幸福的核心因素，再问它对核心因素的益处是否大于害处 → 只是"有点用"就不装 → 验收：每个拒绝都能说出它损害了哪个核心因素。

**流程导向邮件** —— 收到要来回多轮的邮件 → 花一两分钟想"从现状到目标，最少需要几步"，然后一封写全：确认项目、我做什么、何时给、你做什么、无需回复 → 验收：该线程邮件总数不超过两封。

**硬性收工** —— 设一个下线时间（如 17:30）→ 下线前十分钟清空清单、写下明天第一件事 → 验收：下线后不再查看工作消息；做不到就把下线时间再提前半小时。

## A1｜书中实例
- 荣格与杰森·本（第 1 章）：作者把两人并置——一个要超越弗洛伊德，一个要在创业公司里保住位置，处境不同，但都必须产出能力范围内最好的东西。
- 20 号楼与贝尔实验室（准则 1「不要独自工作」）：两处都证明有效深度工作不必与世隔绝，协作式深度反而更能出创新，关键是中枢辐射型结构。
- 邮件范本（准则 4）：作者示范先确认项目，再想信息量最少的流程，最后写清双方动作与时间，使一个咖啡邀约不必来回六七封。

## A2｜何时调用 / 与相邻书的区分
- 当用户的一天被会议和消息切碎，想找回整块时间时。
- 当用户要产出长文、代码、研究等高质量成果时。
- 当用户评估某个 App 或平台是否值得装时。
- 当用户想设定下班边界却总失败时。
- 与《掌控习惯》同谈行为：克利尔用四定律建立自动动作，本书专攻高认知强度区块的排程与守护；与《认知觉醒》相比，番茄加主动休息是入门版，本书给的是日程哲学、浮浅预算和收工线。

## E｜执行步骤
1. 连续一周记录时间去向，按半小时一格，标出被打断的次数 → 产出时间账。
2. 从四种深度哲学里选一种，把时段写进日历并通知相关人 → 产出周计划。
3. 每个时段前写四要素，结束后只按标准打勾或打叉 → 产出成功率。
4. 设浮浅预算（每天多少分钟回消息）与硬性收工时间 → 验收：连续两周，深度时段不被打断的天数过半。
5. 四周后复盘：删掉一个低价值工具，增加一个时段 → 验收：产出量或质量有可指认的变化。

## B｜边界与误用
- 立场偏知识工作者，对必须随时响应的一线岗位、照护责任人并不适用。
- "深度工作"常被误读成拒绝一切协作，书中恰恰留了协作与安逸两章。
- 社交媒体一章带 2016 年前后的语境，具体平台判断需更新。
- 抽样未覆盖准则 2、3 的操作细节，冥想、记牌等训练只见标题。

## 金句
- "想要成功，你就必须产出自己能力范围内最好的产品，而这项任务需要深度。"
- "只有一种工具对这些因素的实际益处大于实际害处时才选择这种工具。"
