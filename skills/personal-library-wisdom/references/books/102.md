# 《猫城记》 — 老舍
> 类型：文学 | 原文规模：约 5.6 万字 | 抽样依据（工作档案 udigest/102.md（6 段）

## 一句话
借一个火星猫国的衰亡，给"糊涂、哄、迷叶"三样东西建一套可复用的诊断模型。

## R｜原文骨架
- 全书二十七章，用第一人称"我"坠机火星后的行踪串起：被捕—迷林—进城—看教育—看军队—逃离。
- 前九章：被捕与获救、大蝎的迷林、迷叶的经济地位、公使太太与八个"小妖精"，先立起猫国面貌。
- 第十至十七章：参观学校、博物馆、图书馆，看学生解剖校长、古物被卖，回答教育为何空转。
- 第十八章整章交给小蝎独白，讲"哄"的分类与经费来源，是全书的机制说明。
- 第十九至二十七章：红绳军、"夫司基"、敌军压境与灭国，把机制推演到结局。
- 结构特点：观察者始终看不懂，读者看得懂——落差就是论证。

## I｜核心命题与可执行方法
**外来者眼睛透镜** —— 看叙述者哪一句说看不懂 → 问"他不懂的是规矩，还是规矩背后的利益" → 会看到双层距离：猫人习以为常的荒诞，被一个外星人当成谜题说出来。

**迷叶透镜** —— 看一种外来作物怎样同时成为食品、药品、货币和命脉 → 问"谁控制种苗、谁定价、谁先吃、断供会怎样" → 会看到"成瘾品—财政—主权"的三段链条，可替换成任何单一资源。

**哄透镜** —— 看一个组织怎样靠名号与月薪自我维持 → 问"钱从哪来、发给谁、名目是什么" → 会看到政治成为职业：不哄便没有饭吃，于是哄的目的一开始就不是成事。

**解剖室透镜** —— 看制度里的人如何互相指认 → 问"此刻谁是人质、谁在表演、谁说真话会死" → 会看到信任崩掉之后，"疑心"成为最理性的生存策略。

**糊涂透镜** —— 看人物用摹仿冒充懂行 → 问"他是不知道，还是知道了不肯承认" → 会看到"糊涂"不是智力问题，是一种集体默契。

## A1｜书中实例
- 第十八章小蝎讲"哄"：皇上把参政哄的重要人物封了官，这些人便专心作官；后又起"民政哄"要赶皇上，皇上索性自组一哄，哄员每月领一千国魂，对方投诚只给一百，最后加到一百零三个国魂才没破裂。
- 同一段给出分层：平民"没受过教育，没知识，没脑子"，有钱人"不敢"动，只有"到过外国的，学校读书的，流氓，地痞，识几个字的军人"能靠哄吃饭，故"革命在敝国成了一种职业"。
- "我"从土里救出校长和教员，松绑后问"哪位是校长"，两人"彼此互相指了一指"，随即像蜻蜓一样分头跑掉——都怕被指认成校长而被杀。

## A2｜何时调用 / 与相邻书的区分
- 当用户要诊断一个组织为何只剩形式、人人自保而无人负责时。
- 当用户分析一种资源（作物、补贴、流量）如何养出一个寄生阶层时。
- 当用户需要写政治寓言、讽刺小说，想知道"设定"如何承担论证时。
- 与《夜谭十记》同写官场荒诞，区别在：马识途用县衙门和买官账目，老舍用虚构把机制放大到灭国尺度。

## E｜执行步骤
1. 输入你熟悉的组织。动作：列出它的三种"哄"：名目、经费来源、实际产出。产出：三列表。
2. 动作：找出该组织里"不敢动"的人和"不动就饿"的人，各写一个具体人。验收：差异能用钱解释，而非性格。
3. 动作：写一个外来者视角的 500 字片段，只允许他记录看不懂的动作，不许他下判断。
4. 产出：让读者从这些动作里自己推出机制；若读者推不出，说明细节不够，不是讽刺不够。

## B｜边界与误用
- 讽刺先行，人物多为类型符号，不能当人物塑造范本。
- 最易被误用为"国民性批判"的现成骂词，把制度问题推给"糊涂"这种气质，反而放过机制。
- 书成于一九三〇年代初，对革命、群众、女性的部分判断带时代偏见，引用须标注。
- 结尾灭国写得急促，机制推演到"外敌"这一步就停了，没有回答如何重建。

- "糊涂是我们的要命伤。"
