# 《我胆小如鼠》 — 余华
> 类型：合集 | 原文规模：约 6.3 万字 | 抽样依据（工作档案 udigest/112.md（6 段）

## 一句话
把"胆小"当作一种被分配的位置，看它怎样换走工作、换走话语权，也换走活命机会。

## R｜原文骨架
- 开篇六节（杨高）→ 从小学课堂被老师当作"胆小如鼠"的活标本讲起，到进机械厂当清洁工，与吕前进对调岗位。
- 杨高与父亲 → 反复追问"你敢不敢闭上眼睛开车"，父亲答"不能"，这是全篇的伦理底线。
- 续接篇章（第二十一、二十二节）→ 并存三条互不相干的线：钟其民吹箫、镇上因地震传言抢购毛竹、男孩星星失踪；另有商店门口被监视的幻觉。
- 同两节内另有王香火被日军挑作向导、雇工孙喜赶回家却被一座座拆掉的桥拦住。
- 末尾三篇《我为何写作》《文学中的现实》《余华新版访谈录》→ 作者自述取材与语言观，可当全书的方法说明读。

## I｜核心命题与可执行方法
**恐惧定价透镜** —— 看一个人的怕被谁在什么场合公开命名 → 问"这标签给他换来什么、省了谁的麻烦" → 会看到"胆小"不是心理事实，是社会位置的分配结果：老师需要标本，同学需要垫底的。

**岗位交换透镜** —— 看两个岗位对调时双方给出的理由 → 问"谁用'技术''油腻''体面'这类词把位置换走" → 会看到体力劳动被贬低不靠工资，靠话语；吕前进的指甲一直是黑的，却始终占着"技术活"的名分。

**带路者透镜** —— 看暴力现场怎样随机挑人 → 问"他被挑中是因为什么特征、做了什么动作" → 会看到王香火只是鞠了一躬、被鞭柄敲了敲肩，就成了向导；"汉奸"叙事在这类随机性面前会失效。

**拆桥透镜** —— 看一个人赶路时脚下的规则怎样持续变化 → 问"他每跑一步，路径是否已被别人改掉" → 会看到结构性变动追赶个体的荒诞：桥是他家少爷下令拆的，他却在向拆桥的人求渡。

**声音透镜** —— 看灾难中谁在发声、谁只听 → 问"这些声音有共同目标吗" → 会看到嘈杂各有目的，而个体的箫声反而是唯一的秩序。

## A1｜书中实例
- 开篇写老师要举例说明什么叫胆小如鼠，先举一串同学的名字，最后点到他这个连鹅都害怕的学生，当众宣布胆小如鼠说的就是他。
- 杨高坐在门槛上等到天黑，只为问父亲"你敢不敢闭上眼睛开车"；父亲笑着说"不能"，理由是"我会被撞死的"。
- 雇工孙喜要回安昌门，被告知洪家桥"拆掉啦"，改走百元，桥刚拆；追上船求渡，船上人说"你还是往前跑吧，前面不远有一座桥，我们正要去拆"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析"老实人为什么总吃亏"，需要跳出性格解释、找到位置与话语机制时。
- 当用户写基层劳动者与工厂，需要具体的动作与口语而非同情时。
- 当用户处理"被时代推着跑"的处境，想找可讲的寓言结构时。
- 与本批《十八岁出门远行》同一作者：那本问"暴力怎样被叙述"，这本问"恐惧怎样被安排"。

## E｜执行步骤
1. 输入一段你被贴标签的经历。动作：写下标签第一次被公开说出的场合、说话人、在场人数。产出：一个"命名现场"。
2. 动作：列出这个标签给你的三项实际后果（谁替你做了决定、你少做了什么、谁得了便利）。验收：三项都能指到具体的人。
3. 动作：找"换岗位"的案例，抄下双方解释用的形容词。产出：一张"话语—利益"对照表。
4. 动作：写 500 字，只写一个人赶路而路不断被改，不写心理。验收：读者感到荒谬，但说不出作者态度。

## B｜边界与误用
- 合集内部水准不一，后附创作谈有自我重复，不宜当论文引用。
- 最易被误用为"老实人励志"或"性格决定命运"，恰恰反了：书里说的是位置决定表演。
- 王香火一节涉日军暴行，笔调游戏化，用于历史教育须谨慎。
