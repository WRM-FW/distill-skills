# 《人为什么活着》 — 稻盛和夫
> 类型：论说 | 原文规模：约 4.5 万字 | 抽样依据（工作档案 udigest/074.md（6 段）

## 一句话
把经营目标换算成"要爬多高的山"，再用利他与知足给扩张设上限。

## R｜原文骨架
- 开篇是与王石的对谈 → 登山比喻、赠股、利润是否为唯一目的、按需采购，先把经营问题摆出来。
- 第一章「人类存在于生存的价值」至第五章「欲望」→ 从宇宙万物皆有存在理由，推到人该如何安置欲望。
- 第六章「意识与灵魂」至第九章「自由」→ 意识体、轮回、科学与宗教的边界、人的本性。
- 第十章「青少年犯罪」至第十二章「命运与因果报应」→ 教育、人生目的、命运与因果，收在"一心向善可改命"。
- 抽样跨章跳跃，只保留了论证的两端：第一章的存在论与第十二章的因果论。

## I｜核心命题与可执行方法
**先报山高，再配装备** —— 接一个新目标或新岗位 → 先写下"这座山多高"：目标量级、周期、最坏结果 → 按高度反推时间、资金、人手、训练四项配置 → 验收：装备清单每一项都能对应一个具体高度要求；用登丘的装备去登高山，就是不合格。

**三方皆好检验** —— 谈一笔交易、定一个价 → 分别写出买方、卖方、第三方（员工、社区、环境）各得到什么 → 有一方净损失就改结构，不改话术 → 验收：三方都能用一句话说出自己得到了什么。

**按需采购** —— 备货、囤课、囤资料 → 只买这次能用完的数量，把仓储、过期、注意力占用算进单价 → 验收：月底盘点未使用库存金额下降；出现"因为便宜所以多买"即为违规。

**四德日课** —— 每晚固定时间 → 各写一行：今天为别人做了什么（布施）、克制了什么（持戒）、忍住了什么（忍辱）、全力做了什么（精进）→ 每行必须是具体事，不许写形容词 → 验收：连续 30 天，至少 20 天四行都有具体内容。

**知足配额** —— 给产能、接单量、开采量定上限 → 像轮作一样留恢复期，超过上限的单不接 → 验收：一年后核心资源（健康、团队、土地）的产出能力没有下降。

## A1｜书中实例
- 登山问答（开篇对谈）：王石问攀登"企业"这座山要注意什么，稻盛先反问山有多高，说险峻高山要用相应装备与训练，用散步的心情去登必然遭遇困难。
- 西乡隆盛与西南战争（第十二章前）：书中反复追问，这位一向善用智慧的人物，为何此役不任指挥官、只跟在年轻人后面，最后归因于他"情感重于理智"。
- 非洲部落火耕（末章）：酋长只种够族人吃一年的粮食，来客多吃就挨饿也不扩种，理由是"部落里的神明不允许"；他们把森林分十块、十年轮烧一块，为曾孙辈留地力。

## A2｜何时调用 / 与相邻书的区分
- 当用户问"这个事业目标该定多大、要配多少资源"时。
- 当用户要在利润与员工、社区之间做取舍时。
- 当用户想给扩张设一个自我约束的上限时。
- 当用户需要一个每晚可写的自省模板时。
- 与《原则》同谈决策：达利欧用可信度加权处理组织分歧，稻盛先用"动机是否利他"做前置筛选；与《掌控习惯》相比，本书不管行为自动化，只管"为什么值得做"的价值排序。

## E｜执行步骤
1. 输入一个在谈的目标或项目 → 写一句"这座山多高"（量级＋周期＋最坏结果）→ 产出高度判断。
2. 按高度列资源四项：时间、钱、人、训练 → 缺哪项就标红 → 产出装备差距表。
3. 画三方得失表，找出净损失方 → 改交易结构 → 验收：三方各得其所，且没有靠隐瞒达成。
4. 设产能上限与恢复期，写进日历 → 验收：上限被触碰时能拒绝一单。
5. 连续 30 天做四德日课，月底只数有具体内容的天数。

## B｜边界与误用
- 意识体、轮回、造物主等章节属信仰陈述，不可当作可验证事实引用。
- "付出不亚于任何人的努力"最容易被拿去美化过劳，书中并未给出劳动时长的边界。
- 案例多来自日本经营语境（终身雇佣、伙伴式经营），直接搬到股权与劳动关系不同的地方会走样。
- 抽样跳章，第十二章的因果论证与第十章的教育论述基本未覆盖。

## 金句

- "但是“求利有道”，必须通过正当的市场竞争、用正当的方法获取利润。"
