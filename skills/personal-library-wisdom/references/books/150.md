# 《云边有个小卖部》 — 张嘉佳
> 类型：文学 | 原文规模：约 7.4 万字 | 抽样依据（工作档案 udigest/150.md（6 段）

## 一句话
用一间小卖部和一张嘴，看中国人怎样把爱说成玩笑、把日子过成账。

## R｜原文骨架
- Chapter1 山野，桃树，王莺莺 → 先把"家"写成一块具体的地，人物挂在田埂、桃树、小卖部上。
- Chapter2—4 喂，打劫／我在做梦吗／不死的少女 → 程霜入场，把"随时会死"处理成可以开玩笑的日常。
- Chapter5—6 城市多少盏灯／一千零一份保单 → 城市的失败被量化成业绩指标，数字代替了尊严。
- Chapter7—12 → 场景从街道折回灶台与田埂，寻找与送别交替。
- Chapter13—16 婚礼／外婆的拖拉机／除夕／我爱你 → 用三场仪式收束：办酒、开车接人、年夜饭。章名本身就是动作。

## I｜核心命题与可执行方法
**围观透镜** —— 看私事发生时有多少旁观者（宿舍五层窗户全开，二楼喊"音量大一点"）→ 问谁在看、观看怎样把当事人逼成演员 → 会看到小地方的公共性不是共同体，是一张节目单。

**嘴上的错位** —— 看玩笑与真话的比例 → 问这句玩笑在替哪句正经话挡枪 → 会看到程霜用"再找一个啊"说"我喜欢你"，刘十三只剩"我可不可以继续等你"。

**照料的账本** —— 看食物、煤球、录音笔、火腿肠 → 问这笔投入花了多少时间多少钱、想换什么 → 会看到王莺莺的爱全部以物资形式出现，"一点都不浪费"就是她的语法。

**强的女人与空的母亲** —— 看谁在解决问题，谁只被提起 → 问母亲为什么只以"她有她的难处"出现 → 会看到缺席被一句体谅封口，叙事不再为它负责。

**返乡的价目** —— 看城市与小镇之间的换算（保单、时薪、油钱）→ 问回来是逃还是被接住 → 会看到返乡不解决失败，只提供一张床和一顿热饭。

## A1｜书中实例
抽样1，麻将桌上罗老师、牛大田、毛婷婷、王莺莺为"幺鸡能不能收回"打成一团，刘十三趁机小跑溜走。一场牌局把四个人的关系和小镇的吵闹一次写完。

抽样6，七十岁的王莺莺开拖拉机进城找外孙，先塞火腿肠给交警："对，我就是在贿赂你。"大路走不了就走小路，最后抱着醉倒的刘十三说"不哭不哭，外婆来了"。

抽样4，王莺莺摊蛋皮：换下旺煤球、垫旧煤球控火，铜勺转一圈，蛋饺冻起来让外孙带回学校——"这时候才想起，外孙已经不上学了。"一个动作落空，写出全部心酸。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写"不靠台词说爱"的亲情场面时。
- 当用户想分析小镇、县城的舆论如何把私事变成公共节目时。
- 当用户判断一段治愈叙事是不是只靠死亡煽情时。
- 与《活着》同问"怎么活下去"：活着靠忍和记账，本书靠嘴皮子和一顿热饭。与《一句顶一万句》同写"说不着"，本书的人还能用玩笑把话兜住。

## E｜执行步骤
1. 取一场三人以上的对话 → 给每句话标功能（抢话／打岔／试探／收场）→ 产出一张话轮表。
2. 找出其中唯一一句真心话 → 改写成玩笑 → 看信息还能不能传到 → 产出两个版本，比较哪个更像这个人。
3. 把一个"我爱你"换成一件具体的事（做饭、修东西、开车来接）→ 写 200 字，不许出现"爱"字。
4. 给场景加一个旁观者 → 重写 → 检查私事是否变成了表演。

## B｜边界与误用
- 情绪推进依赖死亡（外婆、程霜的病），悲喜由事件直接给出，而非人物行动累积。
- 城市与职场部分高度功能化，只用来证明"失败"，不能当城市经验读。
- 口语幽默密度过高，配角常被写成段子，人物让位于抖机灵。
- 对乡镇的描写带着返乡者的滤镜，不宜当社会志使用。
