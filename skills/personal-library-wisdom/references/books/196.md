# 《莎士比亚全集》 — 威廉·莎士比亚（朱生豪 译）

> 类型：合集 | 原文规模：约 130.4 万字（按正文字符数/1.6 估算，保留一位小数） | 抽样依据（工作档案 udigest/196.md（6 段）

## 一句话
三十九部剧分喜剧、历史、悲剧三序，用两套骨架拆解人物的决策与误判。

## R｜原文骨架
- 卷一至卷二（喜剧起手）：《维洛那二绅士》《爱的徒劳》《罗密欧与朱丽叶》《驯悍记》《错误的喜剧》《仲夏夜之梦》《威尼斯商人》，解决"誓言与欲望冲突"的喜剧模型。
- 卷三至卷四（历史剧与问题喜剧）：《亨利四世》上下篇、《温莎的风流娘儿们》《无事生非》《终成眷属》《亨利五世》《皆大欢喜》《泰尔亲王配力克里斯》，解决"王位合法性与民间秩序"。
- 卷五至卷六：《第十二夜》《亨利六世》三部、《雅典的泰门》《理查三世》《一报还一报》《亨利八世》，解决"循环复仇与僭主"。
- 卷七至卷八：《辛白林》《李尔王》《科利奥兰纳斯》《暴风雨》《冬天的故事》《特洛伊罗斯与克瑞西达》《麦克白》，解决"分国、篡位、迟来的认出"。
- 卷九至卷十：《裘力斯·凯撒》《哈姆莱特》《安东尼与克莉奥佩特拉》《泰特斯》《奥瑟罗》等，解决"共和与君主、犹豫、嫉妒"。
- 卷十一：《维纳斯与阿都尼》等叙事诗，解决"抒情诗如何进入戏剧语言"。

## I｜核心命题与可执行方法
**誓—破誓—诡辩三段** —— 看《爱的徒劳》四人立誓苦修禁欲 → 问"破誓后他们用什么话把违约说成进步" → 会看到俾隆把黑说成"美的极致"，誓言的代价被修辞抹掉。
**帏幕试探** —— 看《亨利四世》亲王把福斯塔夫藏在帏幕后、支走郡吏 → 问"谁在考谁、考出了什么" → 会看到账单比台词诚实：半便士面包配两加仑酒。
**身份验证链** —— 看《配力克里斯》父女相认 → 问"靠什么证据确认身份" → 会看到出生地、经历、母亲名字三重核对，"真理不厌反复证明"。
**恐惧的先见** —— 看《特洛伊罗斯与克瑞西达》克瑞西达的独白 → 问"恐惧是遮蔽还是预警" → 会看到她宁要"有理智领导的恐惧"，不要盲目理智的横冲。
**伪证链** —— 看《奥瑟罗》手帕与伊阿古的挑拨 → 问"哪一步是事实、哪一步是解释" → 会看到苔丝狄蒙娜每句实话都被读成谎，悲剧由证据链的空缺造成。
**程序性暴力** —— 看《亨利八世》勃金汉被控叛国 → 问"指控的证据在台上出现了吗" → 会看到权力靠"网子撒到我身上"完成，不需要真相。

## A1｜书中实例
- 《爱的徒劳》：国王说"黑色是地狱的象征"，俾隆反称"她那点漆的瞳人，泼墨的脸色，才是美的极致"（抽样1）。
- 《亨利四世》上篇：亲王搜福斯塔夫口袋，读出"付面包 半便士""付白葡萄酒二加仑 五先令八便士"（抽样2）。
- 《奥瑟罗》：奥瑟罗当面称苔丝狄蒙娜为娼妇，她答"我没有丈夫"，又说"我应该受到这样的待遇"（抽样6）。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析某一场的权力关系、谁掌握信息时调用。
- 当判断一个虚构人物的决定是否可信、动机是否铺垫足够时调用。
- 当要写台词、独白、辩论，需要"用一句话翻转立场"的样本时调用。
- 当改编莎剧、需要确认某条情节线的功能时调用。
- 与《麦克白》单行卡同问"野心如何变成行动"：本卡给跨剧的结构骨架（誓—破誓、试探—误信），单行卡给一剧的细读。

## E｜执行步骤
1. 输入：一个场景。动作：列出"谁想要什么、谁掌握哪条信息、谁知道谁知道"。产出：信息矩阵。
2. 动作：找出立场翻转的那一句台词，标出它替换了什么词。产出：转折句摘录。
3. 动作：把该句换成一句直话，看结构是否塌。产出：结构承重判断。
4. 动作：回到全剧，找同一手法出现的第二处。产出：手法复现证据。
5. 动作：写 200 字判断：这场戏靠什么成立、删掉哪句就散。产出：可复核的短评。

## B｜边界与误用
- 朱生豪译本大量使用四字格与归化表达，不能当原文韵律或双关的依据。
- 全集按译者编次，不按创作年代；早期与晚期作品混排，不能据卷序判断风格演变。
- 抽样只覆盖六场，十四行诗与大部分历史剧未取样。
- 剧本是演出底本，舞台提示简略；把台词当人物心理实录会过度解读。
