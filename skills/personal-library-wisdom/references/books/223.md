# 《你不可错过的32部欧美文学不朽名作》 — 莎士比亚 等
> 类型：合集 | 原文规模：约 629.2 万字 | 抽样依据（工作档案 udigest/223.md（6 段，分属不同作品）

## 一句话
三十二部经典的合订样本库：同一组问题在不同文体里各有各的解法。

## R｜原文骨架
- 目录列三十二部，抽样覆盖七部左右（莎剧九种、《堂吉诃德》《红与黑》《白鲸》《卡拉马佐夫兄弟》《夜色温柔》，另有一页博学型注释）；本卡只对其中六个场面给出工具。
- 莎士比亚四大悲剧（孙大雨译，素体韵文）→ 独白与行动的时间差：决定说得越清楚，执行越迟。
- 莎士比亚喜剧五种 → 错认与配对：谁因为什么认错人，观众比角色多知道什么。
- 《堂吉诃德》→ 章题本身即评判："骇人风车之险""匪夷所思的堂吉诃德第一次离家出游"。
- 《红与黑》→ 于连在主教面前的临场应答，表演即晋升；《白鲸》→ 斯塔布逼厨司对鲨鱼"讲道"，命令被包装成布道。
- 《卡拉马佐夫兄弟》→ 帕伊西神父与米乌索夫争论"教会应当蜕变为国家"；《夜色温柔》→ 一顿午餐里三个人的注意力分配。

## I｜核心命题与可执行方法
**延迟的复仇** —— 看"决定"与"执行"之间隔了几场戏 → 问"这段独白是推动行动，还是替代行动？" → 会看到独白越长，行动越被消耗；戏靠拖延运转。

**错认的机制** —— 看谁因为什么认错人 → 问"这个错认要求观众比角色多知道多少？" → 会看到喜剧的快感来自信息差，不来自巧合本身。

**章题的预判** —— 看标题如何先于正文下判断 → 问"如果章名改成中性词，这段还剩下多少讽刺？" → 会看到"勇武的""匪夷所思的"把叙述者的立场提前塞给读者。

**表演性晋升** —— 看人物在权力面前背诵什么 → 问"他答不出时，诚实是弱点还是技术？" → 会看到于连答塔西陀"在神学院的图书馆里找不到"，主教反而更满意——坦白成了晋升手段。

**布道与贪欲** —— 看命令如何被说成道德 → 问"这段训话的真正目的是什么？" → 会看到斯塔布一边逼厨司"文文雅雅地说话"，一边要鲨鱼别抢邻居的鲸脂——修辞为分配服务。

**注意力的分配** —— 看同一场面里每个人各自注意到什么 → 问"谁被写成了背景？" → 会看到妮珂只注意丈夫对谁下功夫，狄克只注意自己，露丝玛利只注意自己的不方便。

## A1｜书中实例
- 《红与黑》：主教考问于连，发现他连塔西陀的名字都不知道，于连"坦率地回答说，这个作者的作品在神学院的图书馆里找不到"；主教"感到很高兴"，送他八卷本，并许他"最好的堂区"。
- 《白鲸》：斯塔布要厨司弗里斯对鲨鱼"讲道"，厨司先说"你们这些贪心的同胞呀"，斯塔布喝止"我不要听你那凶巴巴的咒骂。跟它们文文雅雅地说话"。
- 《夜色温柔》：露丝玛利托狄克转告科利斯·克莱"我不能等他了"，妮珂冷冷回一句"你最好把口信托伙计转达"。

## A2｜何时调用 / 与相邻书的区分
- 要做跨文体比较（同一主题在悲剧、小说、讽刺里怎么处理）时。
- 要给写作训练找高密度样本、逐句拆句子时。
- 要判断一段"经典段落"为什么有效、能不能迁移时。
- 与《安娜·卡列尼娜》（本书目亦收录，另有单行卡）并用：那张卡拆社交场，这张卡拆文体差异。
- 与《月亮与六便士》相邻：都写"越界者"，一个在19世纪俄国与法国，一个在20世纪英法。

## E｜执行步骤
1. 选一个母题（复仇／错认／布道／旁观） → 在本书目里找三种文体的段落各一。
2. 用同一张表记录：谁在说、对谁说、说给谁听（在场者／读者／上帝） → 验收：三种文体的"第二听众"不同。
3. 把一段独白改写成动作，把一段动作改写成独白 → 比较哪一种更假。
4. 给一段讽刺换一个中性章名 → 验收：讽刺强度下降多少，说明判断有多少来自标题。

## B｜边界与误用
- 这是选本/合订，篇目与译本依版本而异；抽样只覆盖七部左右，不能代表三十二部。
- 莎士比亚为素体韵文译本，散文化转述会丢掉节奏，引用须标幕场。
- 部分译本语言较早（"老爷""您哪"），直接当现代汉语范本会带出腔调。
- "不朽名作"是出版方的定位，不是分析结论；不要用它替代对具体文本的判断。
