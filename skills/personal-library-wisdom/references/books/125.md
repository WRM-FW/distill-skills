# 《长夜难明》 — 紫金陈
> 类型：文学 | 原文规模：约 9.3 万字 | 抽样依据（工作档案 udigest/125.md（6 段）

## 一句话
把一桩"证据链齐全"的铁案拆回每个人算过的账，看正义如何在人事里拐弯。

## R｜原文骨架
- 楔子 → 地铁抛尸、当众被捕：先把"铁案"摆足，再让读者等它裂开。
- 第三章 一审开庭 → 写媒体怎样把命案做成连续话题，为后文舆论反噬埋线。
- 第三十七章 妙高乡夜访 → 用一次越界侦查（借社会车辆、带枪、只吓唬）把"合法与违法"的界线变成具体动作。
- 第五十三章 停职之后 → 让同僚互助与家人被威胁同时发生：一边喝茅台，一边孩子被接走。
- 第六十六章 四人改稿 → 法医、警察、检察官、律师各交一份稿子，把翻案做成有分工的项目。
- 素材无章节标题标记，正文以"第X章"推进；结局段不在抽样内。

## I｜核心命题与可执行方法
- **吻合度检查** —— 看证据链 → 问"这份口供为什么顺得像写好的" → 会看到"一切口供都与调查完全吻合"本身就是疑点：太顺，说明有人替所有人写好了说法。
- **劝退的报价单** —— 看每一次放弃 → 问"他给的理由是哪一个：前途、立足、人情，还是证据不足" → 会看到正义被换算成编制、年底考核与地方关系。
- **威胁的家庭化** —— 看施压手段 → 问"恐惧是从哪件生活小事进来的" → 会看到不是刀，是接孩子、拍照、举报、送烟酒。
- **专业分工的杠杆** —— 看四人的行业 → 问"哪一环只有这个专业能撬" → 会看到翻案不是勇气问题，是证据资格问题。
- **不追问的合谋** —— 看旁观者 → 问"谁在哪个节点选择了不追问" → 会看到系统靠沉默运转，不靠作恶。

## A1｜书中实例
- 张超隔着铁窗受访，被问是否悔恨，他停了一下说"也没什么好后悔的"；新闻照常播出，"没人觉得有什么不妥"。这是全书第一个反扣，在第三章之前。
- 江阳被副局长与大队长劝退：对方道歉、讲年底命案考核的压力、临走送上烟酒；他"东西没拿"，也没有一口回绝。见抽样3。
- 胡一浪把江阳的儿子接去吃饭、送玩具，孩子回家时"拿着玩具飞机高兴笑着"；江阳动手后，旁边立刻响起相机声和"我要举报"。见第五十三章前。

## A2｜何时调用 / 与相邻书的区分
- 当用户想分析"一个人为什么在体制内被劝退"时。
- 当用户要写悬疑，但希望案子承担社会信息而不只是谜题时。
- 当用户讨论翻案、申诉、举报的成本结构时。
- 当用户需要"多方合谋却无人作恶"的叙事样本时。
- 与《咸的玩笑》同写县域人情压力：刘震云让人用玩笑把名声洗白，紫金陈让人用程序把证据磨平；一个查"话怎么说圆"，一个查"案怎么办成"。

## E｜执行步骤
1. 输入一段"劝说放弃"的对话。动作：逐句标出说话人此刻要保的东西（职位、考核、面子、家庭）。产出：一张利益表。
2. 动作：把对话改写成不含情绪词的会谈记录，只留条件、时间、物件（烟酒、信封、电话）。验收：读者仍能判断谁在施压。
3. 动作：为每个施压者补一句他自认正当的理由。验收：没有一个人物是"纯恶"。
4. 动作：从结局倒推——要让案子翻，必须先补哪一环证据、由哪个专业补。验收：路径可执行，不靠巧合。

## B｜边界与误用
- 类型小说，人物功能化明显：江阳的坚持、张超的牺牲都服务结构，不宜当真实司法个案引用。
- 对基层公安、检察程序的描写为剧情服务，不能当程序教材。
- 女性角色多停在"被保护者/被威胁者"位置，做性别分析时材料很薄。
- 最易误用：把"迟到的正义"读成热血，忽略书里真正在算的是每个人的职业寿命。
