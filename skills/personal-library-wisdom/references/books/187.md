# 《要有光》 — 梁鸿

> 类型：文学 | 原文规模：约 14.5 万字 | 抽样依据（工作档案 udigest/187.md（6 段）

## 一句话
把"孩子出问题了"还原成一张由学校、医院、家庭和钱共同签字的账单。

## R｜原文骨架
四部按地点推进，每部解决一类场景：
- 第一部 滨海市 → 一个"问题学生"如何被识别：〈和光中学〉〈表演"正常"〉〈驱逐1〉〈爱是什么〉。
- 第二部 京城 → 中产家庭的资源竞赛：〈怎么样都行〉〈大梦初醒〉〈我们看不起他〉〈刻舟求剑〉。
- 第三部 丹县 → 县域的医疗与教育接口：〈我不要住院〉〈游戏皮肤〉〈上学有什么意义〉〈权中的一天〉。
- 第四部 时间…… → 用〈雅雅日记〉与回访，把前面的判断重新过一遍。
两条线交替：阿叔的补习班式临时收容，和县乡卫生院精神科的建设。

## I｜核心命题与可执行方法
**"正常"的表演成本** —— 看谁在替谁圆场（老师勉强的笑、母亲小心翼翼的跟进、孩子每隔几分钟的出声）→ 问"这个场合要求每个人演出什么" → 会看到症状之外还有一整套表情劳动，而它不被计入任何账单。
**支付的账本** —— 看每一次转学、住院、报班的价格与付款人 → 问"这笔钱买的是治疗、看管，还是家长的安心" → 会看到三千块一个月的病房、攒班学费、补习班住宿被放进同一个天平。
**制度的下一站** —— 看心理老师配比、卫生院科室、教体局指标 → 问"识别出来之后，人能被送到哪里" → 会看到 1000∶1 的配备如何落成表格，表格下面却没有承接机构。
**原话层** —— 只抄当事人说的话，不抄诊断 → 问"这句话在向谁要什么" → 会看到"你根本不知道我在说什么"是请求，"上学有什么意义"是谈判。
**替谁生病** —— 看家里谁的症状最响 → 问"这个症状替谁挡住了矛盾" → 会看到父亲的"再要一个"、母亲的否认与孩子的崩溃排在同一条因果链上。

## A1｜书中实例
1. 和光中学办公室：王老师将近六十岁、退休返聘、带了这个孩子三年；夸他"善良，爱帮助同学"时，"给人的感觉是小正的优点是她绞尽脑汁才想到的"。母亲一路跟着，"也是勉强的笑容"。一场谈话把三方位置摆完：老师要体面，母亲要不被指责，孩子在被谈论时不停弄出声音。
2. 小夏：在滨海市精神卫生中心四人间住过，一个月三千块；父亲说"不就三千块钱一个月吗，把你送到精神病院，我养你一辈子"。后来她在补习班住了将近一年，2018 年冬开始正常上课，2019 年考上普通高中，2021 年读大专，2024 年做了店长。
3. 丹县娟娟：母亲拒绝买游戏皮肤，她吞下三十多片药，咬住母亲的手指不放。杜梅在吴庄镇卫生院遇到王振医生，"他愿意花时间听她倾诉"。作者紧接着写"时间是最好的遗忘剂"，暑假一过，母亲又"抱新的希望"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要把一个"厌学、自伤、被劝退"的案例拆成场景问题，而不是找一个责任人时。
- 当用户在做县域教育、精神卫生、社工方案，需要知道基层的实际接口长什么样时。
- 当用户想写多地点、多家庭、长时段的非虚构，需要看结构怎么搭时。
- 与余华《我们生活在巨大的差距里》同写"差距"：余华给观感与比喻，本书给可核对的场景与价格。
- 与张爱玲同写家庭内部的算计：张爱玲用器物与礼数，本书用床位与报名费。

## E｜执行步骤
1. 输入一个孩子的"问题行为"记录 → 改写成场景表：时间、地点、在场者、触发句、谁收拾残局 → 产出一张不含诊断词的现场清单。
2. 在表右侧加"支付"栏：钱、谁的时间、谁的职业前途 → 标出最大的一笔。
3. 画"下一站"：学校之后能去哪，医院之后能回哪；画不出的地方就是断点。
4. 只留三段原话（孩子、家长、老师各一），删掉全部转述 → 检查三方是否在说同一件事。
5. 输出一句"可改的一处"，必须落在一个具体动作上，例如"办公室谈话先问孩子想不想在场"。

## B｜边界与误用
- 不是诊疗手册，不能据以判断某个孩子该不该住院、该不该用药。
- 样本偏城市中产与县域两头，农村留守只在末尾带过，不能当全国剖面。
- 作者同情明显偏向孩子，家长的恐惧与无能容易被写成加害，引用时要补回家长的位置。
- "阿叔"式个人承担不可复制，把它当方法只会得出"缺一个好人"这种无效结论。
