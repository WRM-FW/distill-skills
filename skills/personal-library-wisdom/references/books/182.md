# 《现实一种》 — 余华
> 类型：文学 | 原文规模：约 5.1 万字 | 抽样依据（工作档案 udigest/182.md（6 段）

## 一句话
拆解暴力的一台机床：看它怎样藏在倒水、搬凳子、哄孩子这些动作里。

## R｜原文骨架
- 自序 → 作者的写作自述，抽样未覆盖正文。
- 《现实一种》→ 兄弟两家，一个孩子摔死另一个孩子，复仇按家务流程一步步推进。
- 《河边的错误》→ 河边命案、疯子、目击的孩子、查案的马哲；程序反复卡住。
- 第一章、第二章、第三章 → 素材中的分章标记，与前后篇目的归属在抽样里无法确认。
- 《一九八六年》→ 一个满身血污的疯子走进春天的小镇，幻觉中的刑罚与人群的旁观并行。

## I｜核心命题与可执行方法
**日常动作透镜** —— 看暴力前后的琐事（找水、搬凳子、看麻雀、摸额头）→ 问作者删掉了哪个情绪词 → 会看到暴力不被写成事件，而被写成一连串家务，读者在琐事里失去警觉。

**观看者透镜** —— 看现场有几个在看的人、他们做了什么 → 问谁本可以介入、他的替代动作是什么 → 会看到孩子说"所有的大人都不相信我"，人群看疯子时"谁也没有注意他"：看而不介入，是第二个现场。

**物化透镜** —— 看人被比喻成什么 → 问比喻的方向是从人到大块肉、塑料凳，还是反过来 → 会看到先物化，才下得去手；"他感到自己是抱着一大块肉"。

**程序卡点** —— 看证据、口供、定罪在哪一步失效 → 问谁在替程序补洞 → 会看到脚印破坏现场、疯子不能负责、许亮主动认罪：程序最后需要一个人来顶。

**春天反讽** —— 看景物描写的温度与随后发生的事 → 问这段阳光在为谁做准备 → 会看到春雪融化、少女嘴唇、自行车铃声之后，走进来一个脚上裂满口子的疯子。

## A1｜书中实例
抽样1，皮皮把堂弟从摇篮里抱出来，"像抱那只塑料小凳一样"，越抱越沉，就松了手；随后他搬凳子去够杯子喝水，回来才看见堂弟躺在地上，血"像一朵花似的在慢吞吞开放着"。

抽样2，山岗用麻绳把发高烧的山峰绑在树上，山峰问"你在干什么"，他答"给你按摩"；山峰还提醒他"你应该在太阳穴上按摩"。

抽样3，目击的孩子对马哲说："所有的大人都不相信我。因此我只能告诉和我差不多大的孩子了，他们相信我。"

## A2｜何时调用 / 与相邻书的区分
- 当用户要写暴力而不渲染血腥，需要"动作替代情绪"的样本时。
- 当用户想分析旁观者如何成为共谋时。
- 当用户判断一段犯罪叙事是否只靠猎奇时。
- 与《活着》《第七天》同属余华：活着写忍受，第七天写申诉，本书写暴力的机械结构——不追问为什么，只展示怎么进行。

## E｜执行步骤
1. 选一个暴力场景 → 删去所有形容词与情绪词，只留动作和物件 → 看剩下的东西是否仍然可怕。
2. 标出所有观看者及其动作 → 问谁本可以介入、他做了什么替代动作。
3. 找出把人写成物的比喻 → 改回人称 → 比较两种写法各失去什么。
4. 用"最明亮的景物加最冷的事"写 300 字 → 验收：不出现"残忍""恐怖"。

## B｜边界与误用
- 先锋小说的人物是功能性的，不宜做心理分析或道德审判。
- 暴力描写密集，容易被当猎奇消费，文本的反讽会被读掉。
- 对制度只有寓言式指涉，不能当司法或精神病学的材料。
- 《河边的错误》里"疯子"的设定依赖当时的法律常识，今天读要补背景。
