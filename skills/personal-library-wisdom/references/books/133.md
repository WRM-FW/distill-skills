# 《咸的玩笑》 — 刘震云
> 类型：文学 | 原文规模：约 15.9 万字 | 抽样依据（工作档案 udigest/133.md（6 段）

## 一句话
用一桩县城"咸猪手"风波，拆解笑话怎么变成债、舆论怎么进货、人怎么给自己结案。

## R｜原文骨架
- 正文三十三章，写延津人杜太白：五十出头，主持红白喜事，与唱二夹弦的田锦绣谈婚论嫁，随后卷入"咸猪手"事件，被网文讨伐、被派出所抓，又被儿子的事牵扯。
- 每几章后插"附录"，与正文互为注脚：宋徽宗的一首词、李香君柳如是、第欧根尼、陈琳《讨曹操檄》、花蕊夫人、寿王李琩、白居易、赤脚大仙告粉丝书、贝多芬、阿基米德、李贽、忍死待君。
- 附录不是装饰：正文人物引了什么，附录就补什么，把一桩县城丑闻接进两千年的典故链。
- 抽样覆盖：婚前财务谈判、按摩店的"绿色"、申时行的私事、小林写檄文、泰山与春芽、派出所所长讲"获嘉"。

## I｜核心命题与可执行方法
- **玩笑的记账法** —— 看一个玩笑在哪一步变成债 → 问"谁先笑、谁最后付、付多少" → 会看到"咸"是笑完之后嘴里剩下的味道：话说得越圆，账越难赖。
- **附录作反证** —— 看正文引典与附录的对应 → 问"这个典故替谁开脱" → 会看到小林说"箭在弦上，不得不发"，而这话本是陈琳骂完曹操后用来脱身的；典故一到位，恶行就有了台阶。
- **舆论的进货价** —— 看谁从道德事件里挣钱 → 问"他涨了多少粉、卖了多少货" → 会看到"能带不少脚气水和防臭鞋垫呢"：正义是流量入口，货在后面。
- **钱的方言** —— 看婚姻谈判 → 问"这场谈判用什么单位计价" → 会看到"每个月，给你一千块钱零花钱"：感情用月供表述，自由按百分比缩水。
- **自我说服的修辞** —— 看人怎么给欲望改名 → 问"他把什么说成'纯洁'" → 会看到"绿色""干净""想念也属于纯洁"：先造词，再行动。
- **父子的替代解释** —— 看一个人如何替另一个人结案 → 问"这套心理学解释是谁提供的" → 会看到"是想重新找一个爸"与"巴黎想找一个妈"：用故事把难堪收进抽屉。

## A1｜书中实例
- 田锦绣提出婚后"你把你挣的钱，每个月都交到家里；家里，每个月，给你一千块钱零花钱"，杜太白当场说"没问题"，事后算账：每月万把块，"突然缩水百分之九十"。（抽样1）
- 鞋匠小林写檄文骂杜太白，先否认有人指使，最后承认"发了这篇文章，粉丝，一下涨了两万多"，"能带不少脚气水和防臭鞋垫呢"。（抽样4）
- 派出所所长把"获嘉"得名（汉武帝获吕嘉人头）的典故挪去给"桃花发廊"改名"获太白发廊"；伦敦抗议"连李白也抓不好吧"。（抽样6）

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析网络暴力、热搜、地方舆论的生成时。
- 当用户要写"一本正经说歪理"的对话时。
- 当用户诊断中年男性的自我辩解、羞耻与翻身叙事时。
- 与《长夜难明》同写县域权力：一个用案子把权力摊开，一个用笑话把权力绕过去；同问"人怎么在人情里活"，一个求证据，一个求说法。

## E｜执行步骤
1. 输入一起本地风波（一句话即可）。动作：列出所有从中获益的人及其获益方式。验收：至少找出一个"卖货的"。
2. 动作：为主角找一条古事（诗、檄、典故），写成一段附录。验收：附录能反过来解释正文里某人的辩解。
3. 动作：把关键对话改写成"钱＋时间"的条款，删掉形容。验收：读者能算出谁亏。
4. 动作：给每个角色配一个自造词（如"绿色""纯洁"），看谁用得最顺。产出：一张话术表。

## B｜边界与误用
- 语言极密，方言、絮叨、重复句多，读不惯会觉得吵；模仿容易只学到绕。
- 对女性身体的写法常停在年龄与外形，做性别分析需另找材料。
- 附录知识量大，容易读成掉书袋；它的功能是互文，不是考据。
- 结局与后半部不在抽样内，人物走向不宜据抽样推断。
