# 《收获文学榜中短篇小说2019-2021合辑》 — 《收获》文学杂志社 编
> 类型：合集 | 原文规模：约 101.5 万字 | 抽样依据（工作档案 udigest/164.md（6 段）

## 一句话
六篇当代中短篇作横向样本，练一件事：把时代装置写进人的动作里。

## R｜原文骨架
- 体例 → 按年度分册，每册收中篇与短篇，篇末标注原刊出处（如"选自《天涯》2019年第6期"），可回溯。
- 抽样1（原载《天涯》2019年第6期）→ 矿井、严打、流氓罪，一个人如何被指标吞掉。
- 《天台上的父亲》邵丽 → 丧父之后的城市生活，怒气落在陌生人身上。
- 抽样3 → 在理发店遇上旧日师兄，用手艺和照片保存过去。
- 抽样4 → 监狱工场，监视器下的同情，以及来"体验生活"的编剧。
- 抽样5 → 疫情期古城的搭讪，半张脸与"约吗"广告牌。
- 抽样6 → 机关新人古玉在雍城排队、吃网红店、接汇报电话。

## I｜核心命题与可执行方法
**指标透镜** —— 看罪名、名额、任务如何落到个人头上 → 问这个人的倒霉是他做的，还是指标需要 → 会看到"保卫科正愁名额不满"：惩罚先有配额，再有对象。

**情绪转移** —— 看悲伤之后对陌生人发的火 → 问这股气原本该向谁发、为什么落在服务员或抱狗女孩身上 → 会看到丧亲之痛无处安放时，会找最近的可指责者。

**手艺即记忆** —— 看重复的动作（洗头、推子、拍照）→ 问他用什么动作记住过去 → 会看到"我过去这些年，都花在这些照片上了"：手艺是记忆的容器。

**观看的伦理** —— 看谁在看监视器、谁在体验生活 → 问观看者从别人的苦难里拿走了什么 → 会看到同情也可以被采集为素材。

**时代装置** —— 看口罩、广告牌、汇报材料、排队叫号 → 问这个装置怎样改写人和人之间的基本动作（搭讪、排队、汇报）→ 会看到宏大变化落在最小的动作上。

## A1｜书中实例
抽样1，"我"因看穿碎花裙的姑娘被举报，"鉴于我确实没有具体的肢体触摸，但毕竟用目光对女性进行了一番猥亵"，判了三年；同监杨晓武只是拎着擀面杖站在表哥打架现场观望，就被赶来的公安逮捕。

抽样4，陈和平指着监视器里的俞佩华和黄童童说："她们看上去像一对母女。你瞧见了吧，这就是母爱。"他还带演员来"体验一下，深入生活对演出有帮助"。

抽样6，古玉陪冯诗柔排了十一桌等网红泰国菜，心里想的是"更想找个地方吃一颗白水煮羊头"；饭没吃完，马处长电话来了，李部长的日程提前到周二上午。

## A2｜何时调用 / 与相邻书的区分
- 当用户要一组当代题材短篇样本，找"社会新闻如何变成小说"时。
- 当用户练"把制度写进动作"的写法时。
- 当用户判断一篇现实题材小说是否观念先行时。
- 与其他单本不同：这里提供横向对照，六篇各有各的时代装置，适合比较而不适合概括。

## E｜执行步骤
1. 选一篇 → 列出文中所有"时代装置"（指标、监视器、口罩、材料）→ 产出装置清单。
2. 找一个人物把制度语言说成家常话的瞬间 → 抄下原句 → 分析他改了哪个词。
3. 比较两篇里"看"的位置：谁在看谁、观看者有没有代价 → 写 200 字判断。
4. 仿写 800 字：只写一个动作链（排队—点单—接电话），把时代信息藏进物件 → 验收：不出现年份与政策名。

## B｜边界与误用
- 抽样只覆盖六篇，占全合辑极小比例，不能代表榜单全貌。
- 榜单体例带有刊物审美偏好，入选不等于定评。
- 部分篇目观念先行，人物为议题服务。
- 五册体量大、风格差异明显，不宜整体概括。
