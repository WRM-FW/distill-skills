# 《加缪手记》第一卷 — 阿尔贝·加缪（黄馨惠 译）
> 类型：文学 | 原文规模：约 6.2 万字 | 抽样依据（工作档案 udigest/025.md（6 段）

## 一句话
看一部作品的原料如何被记下、搁置、再改写成成品。

## R｜原文骨架
- 编辑说明＋导读 → 交代手记性质：本不打算公开，只与自己对话，"不要多话"。
- 1934—1940 分年编排 → 读书、旅行、剧场、小说草稿混在同一条时间轴上。
- 1935—1942 年间作品一览＋剧场剧目表 → 把手记与已刊作品对照。
- 书末大量译注与原编注 → 逐条标出哪一段后来进了哪部作品。

## I｜核心命题与可执行方法
**变形追踪** —— 看同一条笔记反复出现、被改写 → 问："这条从见闻变成了哪部作品的哪一段？" → 会看到：创作是反刍，不是灵感；一条三行的观察可以养出一整章。

**格言当假设** —— 看短句的口气是结论还是试探 → 问："这句后来在哪部作品里被展开或推翻？" → 会看到：手记里的断言都是待验证的，不是可直接引用的教条。

**清单式观察** —— 看旅行笔记只留名词与形容词 → 问："他为什么省掉心理描写？" → 会看到：这是在积累可调用的感官库存，写作时再来取。

**反向命题** —— 看他把常识翻面的习惯 → 问："这句反过来还成立吗？" → 会看到：真理感常来自对称，不来自论证，读者要自己补中间那段。

**三段分期** —— 看导读给出的"荒谬→反抗→爱与节制" → 问："这是作者自述，还是编者的归纳？" → 会看到：用它定位可以，当引文不行。

## A1｜书中实例
- 中欧行记（抽样2）：布拉格一段只写"饿。没有钱。死亡。泡醋的黄瓜。独臂人把他的手风琴压在屁股下。"——用清单代替叙述，情绪靠物价和身体位置透出来。
- 抽样5："老头和他的狗。八年的恨。"编者注说明这一段后来成为《局外人》里萨拉玛诺的故事——一句判断长成一个次要人物。
- 抽样3 小说草稿中 M 的话："幸福是就是，不是就不是。重要的是幸福的意愿……一张等着我们把花色绣上去的底布。"

## A2｜何时调用 / 与相邻书的区分
- 当用户想研究"一个念头如何长成一部作品"时。
- 当用户写日记或素材本，想知道怎么记才便于日后调用时。
- 当用户读到一句漂亮的断言，想判断它是不是被断章取义时。
- 与《局外人》配对：手记给原料与草稿，小说给压缩后的成品。分析创作过程用手记，分析文本效果用小说。

## E｜执行步骤
1. 连续两周，每天只记三条：一个场景、一句听来的话、一个反常识判断 → 不写感想。
2. 周末把三条并置，找重复出现的意象 → 标为"待展开"。
3. 选一条改写成 300 字场景 → 保留原来的名词，删掉所有解释性句子。
4. 验收：改写后仍能指回原笔记的具体词，而不是只剩一个主题。

## B｜边界与误用
- 手记不是体系，不能当哲学结论引用；许多条目只有半句，"M""Z"指代不明，脱离上下文就会读歪。
- 中译本夹有大量译注与原编注，读者容易把编者按语当成加缪原话；抽样4 整段都是注释。
- 只覆盖 1934—1940，不能代表加缪全部思想。
- 当成"金句库"来摘抄，正好违背作者"不要多话"的写法。
