# 《平凡的世界》 — 路遥
> 类型：文学 | 原文规模：约 50.7 万字 | 抽样依据（工作档案 udigest/015.md（6 段，另有一份同书重复副本）

## 一句话
把阶层上升写成一张价目表：多少钱、多少人情、多少次丢脸，换一步路。

## R｜原文骨架
- 全书三部、正文五十五章（抽样所见为连续编号，未标部次）→ 以双水村孙家两代人为轴，从1975年前后写到改革初期。
- 孙玉厚一线 → 送弟孙玉亭去柳林镇读书、1960 年玉亭跑回、张罗娶亲；先交代“读书改换门风”这笔旧账。
- 孙少安一线 → 辍学务农、与润叶分手、娶贺秀莲、进城拉砖、在菜市场捡菜帮子。
- 孙少平一线 → 外出揽工、下煤矿、与田晓霞相恋；晓霞死后转回惠英嫂与明明身边。
- 田福军等干部线 → 下乡调查、改革争论、给少安写条子放人。
- 孙兰香一线 → 考上北方工业大学、与吴仲平恋爱、在校园里辩论四维空间。

## I｜核心命题与可执行方法
**换算率** —— 看每一次身份跃迁的票价（二毛五理发、八块五报名费、每月十块、五十块）→ 问“这一步花了多少钱，谁出的” → 阶层流动被写成明细账；尊严有单价。

**体面的技术** —— 看人物在公共场合如何遮掩窘迫（趁无人捡菜、进理发店“开一回洋荤”、请客点菜）→ 问“他怕谁看见” → 贫穷的核心不是缺钱，是被人看见缺钱。

**信的枢纽** —— 看信件、纸条、口信如何启动情节（润叶的恋爱信、兰香写“我去”、田福军的手书）→ 问“这封信替谁办了制度办不成的事” → 人情链条是乡土社会的执行系统。

**叙述者的代言** —— 看“我们记得”“我们也不会忘记”这类句子 → 问“谁在替人物总结意义” → 全知叙述者兼做道德见证人；人物的苦常由叙述者当场兑现成意义。

**苦难的报偿** —— 看每次受苦之后是否紧跟奖励 → 问“这份苦在叙事里被换成了什么” → 苦难被折算成道德资本与上升资格；报偿一旦缺席，叙述就沉默。

## A1｜书中实例
- 石圪节理发（少安婚前）：他犹豫之后“决定破费进一次理发店，开一回洋荤”，花二毛五分；出门时头皮发麻，“心里热腾腾的”，走过小桥却“一颗热腾腾的心突然冰凉了下来”——他想起春天在这里捏着润叶的恋爱信。
- 县城菜市场（少安拉砖）：他等市场“空无一人”才去捡菜帮子菜叶，“心在狂跳，脸烧得像燃烧的炭块……小偷行窃一般紧张”。
- 校园辩论（兰香）：她与吴仲平争论四维空间与相对论，叙述者插一句“学术方面的辩论，也是他们谈恋爱的一个内容”。

## A2｜何时调用 / 与相邻书的区分
- 当用户要写底层青年的上升故事，需要具体价格与手续时。
- 当用户分析全知叙述者的抒情如何替人物表态时。
- 当用户判断一段“苦难叙事”是否可信、报偿是不是硬塞的时。
- 与《许三观卖血记》同写匮乏中的父辈：许三观用血换钱，孙玉厚用人情换弟弟的前途；一个交易身体，一个交易关系。

## E｜执行步骤
1. 输入任一人物的上升线 → 列出每一步的花费与担保人 → 产出上升成本表 → 验收：每个节点都有具体金额或具体的人。
2. 输入一段叙述者插话 → 删去议论只留场景 → 产出两版对照 → 验收：能说出删掉后人物是变强还是变弱。
3. 输入一次“体面”场景 → 标出遮掩动作与所怕的对象 → 产出羞耻坐标 → 验收：能指出他怕的是哪一类人。
4. 写作训练：写 400 字一次进城，只写价钱、路程和手续 → 验收：不写“自卑”二字，读者能感到落差。

## B｜边界与误用
- 叙述者频繁替人物总结意义，容易把复杂处境压成励志；引用时区分“人物想的”与“叙述者说的”。
- 女性人物（秀莲、润叶、晓霞）多承担情感功能，做性别分析会失望。
- 全书对改革前景持乐观基调，用它分析当下的城乡问题须打折扣。
- 抽样覆盖孙家早年、少安婚前与拉砖、润生遇郝红梅、晓霞、兰香数段，中间大量章节未覆盖。
