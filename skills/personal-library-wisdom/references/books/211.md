# 《张爱玲经典作品集》 — 张爱玲

> 类型：合集 | 原文规模：约 92.3 万字 | 抽样依据（工作档案 udigest/211.md（6 段）

## 一句话
把婚嫁、体面与亲戚网络，折算成衣料、敬语和月光的价钱。

## R｜原文骨架
集子按写作年代与文体混编，抽样覆盖到四条线：
- 早期短篇：〈第一炉香〉〈第二炉香〉〈茉莉香片〉〈心经〉〈封锁〉〈倾城之恋〉〈金锁记〉 → 一个女人怎样用婚姻换生存。
- 中期：〈红玫瑰与白玫瑰〉〈留情〉〈桂花蒸 阿小悲秋〉〈等〉〈创世纪〉 → 体面家庭的日常账。
- 晚期：〈色，戒〉〈相见欢〉〈浮花浪蕊〉〈同学少年都不贱〉〈怨女〉〈小艾〉 → 回望时的删改与自辩。
- 散文：〈更衣记〉〈烬余录〉〈谈女人〉〈论写作〉〈中国人的宗教〉 → 她自己的解释系统。
- 另有一路旧小说译注（〈海上花〉），把吴语对白改成普通话。

## I｜核心命题与可执行方法
**婚嫁的换算** —— 看每次婚嫁、同居、分手时的数目与付款人 → 问"这段关系按什么计价" → 会看到敦凤从婆家到米先生"中间是有无数的波折"，婚姻是一次资产重组，情义是账面上的装饰。
**衣料的证词** —— 看人物穿什么、衣服怎么保养（艾军在英国定做的西装"永远看上去半新不旧"，肘弯打麂皮补钉，从不连穿两天，诀窍在挂）→ 问"这件衣服替他申报了什么身份" → 会看到体面靠维护成本维持，脏是看不见的。
**客气话的刀口** —— 看敬语出现的位置（米先生对敦凤"有时候要说'对不起'，有时候要说'谢谢你'，也只是'谢谢你，对不起'而已"）→ 问"这句话省掉了什么" → 会看到亲密关系里的客气就是距离的刻度。
**月光的计时** —— 看景物如何被换算成年龄（三十岁生日，水泥阑干"浴在晚唐的蓝色的月光中"，"墓碑一样沉重的压在心上"）→ 问"这个意象在替谁计时" → 会看到女性被年龄定价的自觉，写景即算命。
**帘下的视线** —— 看叙述者把镜头放在哪里（莲生砸玻璃时，"来安暨两个轿班只在帘下偷窥，并不进见"）→ 问"谁被允许看，谁只能听" → 会看到情欲与暴力的场面由下人转述，权力藏在视线的高度里。

## A1｜书中实例
1. 〈第二炉香〉结尾：罗杰安白登把煤气关小，看火苗缩成一圈"齐整的小蓝牙齿"，最后一扑、一炸、化为乌有。他关门上闩，重新开煤气，却"这一次他没有擦火柴点上火"。收束只有一句："沉香屑烧完了。火熄了，灰冷了。"
2. 〈留情〉：敦凤与米先生挨着肩膀走在街上，她觉得"很平安"；对面阳台上的鹦哥让她想起从前那个婆家，本想指给米先生看，因为刚闹了别扭，就没叫他看。
3. 〈浮花浪蕊〉：洛贞夸钮先生讲究穿，姐姐笑着说"你不知道他衣裳多脏"——呢子耐脏，干洗多了伤料子；又说范妮"就羡慕人家用男人的钱"。

## A2｜何时调用 / 与相邻书的区分
- 当用户要分析一段关系里的钱、面子与亲戚网络，需要看怎么用一顿饭、一件衣服写清时。
- 当用户写都市情感，需要避免把欲望写成宣言时。
- 当用户要练"以物写人"，需要看器物如何承担性格与阶级时。
- 与《老舍全集》同写市民社会：老舍写院子与街，张爱玲写公寓、阳台与帘子。
- 与《俗世奇人》同写手艺：冯骥才写绝活，张爱玲写维持体面的手艺。

## E｜执行步骤
1. 选一场戏 → 做"物品账"：钱、衣料、家具、吃食各列一栏 → 看哪一栏最先出现。
2. 标出所有称呼与敬语的变化 → 画出两人距离的升降。
3. 找叙述者站的位置（门、窗、帘、楼梯口）→ 判断谁在看、谁被看。
4. 把一处景物改写成时间：这段月光等于多少岁 → 核对是否与人物处境对上。
5. 仿写 300 字：用一件家务动作写一次诀别，不出现"爱""恨""悲" → 验收：读者能说出关系断在哪一步。

## B｜边界与误用
- 世界限于沪港中上层与遗老家庭，工人、农民基本不在场，不能当社会全貌。
- 苍凉美学容易被误读成"看破"，其实人物大多在算计，并未超脱。
- 集中版本复杂，同一篇有初刊、改定、自译之别，引用要注明出自哪一版。
- 散文中的性别观有时代局限，直接当观点引用会失真。
