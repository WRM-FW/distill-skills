# 《老人与海》 — 海明威（鲁羊 译）
> 类型：文学 | 原文规模：约 3.1 万字 | 抽样依据（工作档案 udigest/056.md（6 段）

## 一句话
用一本消耗账写尊严：看人如何在资源见底时仍按自己的规则做事。

## R｜原文骨架
- 无章节标题，单一中篇，按出海进程分四段：出海前、与大鱼僵持、鲨鱼夜袭、归港。
- 开篇露台一段 → 用男孩与啤酒交代八十四天无鱼，以及两人"师徒兼父子"的替代关系。
- 海上第一天 → 用飞鱼、僧帽水母、海龟建立一套海上伦理词典。
- 僵持段 → 手抽筋、吃生鱼、算睡眠，身体成为唯一的仪表盘。
- 鲨鱼段 → 武器逐件损失（鱼叉、刀、短棍、舵柄），抵抗降级为"有什么用什么"。
- 抽样止于归港之前，老人回屋与游客误认的结尾未覆盖。

## I｜核心命题与可执行方法
**重复句计时** —— 看同一句话出现几次、每次前后差什么（"要是男孩在这儿就好了"） → 问："这一次重复是新信息，还是纯消耗？" → 会看到：重复是疲劳的刻度，不是抒情；语句不变而处境变坏，压力就出来了。

**对手的尊严化** —— 看叙述给鱼分配了什么称呼（兄弟） → 问："如果对手是同类，胜利还剩下什么？" → 会看到："是那鱼正带着我回家，还是我带着它回家"——胜负被悄悄换成了同行。

**身体的叛变** —— 看左手抽筋被怎么称呼（"这算哪门子的手啊"） → 问："谁在指挥谁？" → 会看到：意志的边界不在决心，在手抽筋的那一秒；尊严是在部件不听话时仍按程序操作。

**消耗账本** —— 看每次补给的数量（半口水、几只虾、一条金枪鱼） → 问："这笔账还能撑几个小时？" → 会看到：硬汉不是姿态，是卡路里与睡眠的管理；吃饭被写成任务，不写成享受。

**道德标签** —— 看叙述给哪些生物贴了贬义词（僧帽水母"海洋中最虚伪的家伙"） → 问："这个标签服务的是生态，还是人的需要？" → 会看到：海被抓进人的道德词典，是为了让杀戮有秩序；连海龟吃水母都被写成"乐意看到"。

## A1｜书中实例
- 抽样第 1 段：露台上男孩问他第一次带自己出海是几岁，他说"五岁"，并提起那次"过早地把鱼拖进了船舱，它几乎把小船撕成了碎片"；男孩答"从我们一起出海到现在，所有事情我都能记得"。
- 抽样第 3 段：鱼线割破他的手，他把手泡进海水看血迹散开，随后说"这算哪门子的手啊"；又劝自己吃掉金枪鱼，"它会让你的手恢复力量的"。
- 抽样第 6 段：鲨鱼成群夜袭，他先挥短棍，"感觉到棍子被什么抓住了，接着就被拉走了"，最后抽出舵柄又砸又砍，舵柄断裂后用断口去扎。

## A2｜何时调用 / 与相邻书的区分
- 当用户要把"坚持"写得不喊口号时。
- 当用户需要分析重复句的节奏功能时。
- 当用户在处理一场注定失败的消耗，想找不自我美化的写法时。
- 当用户想写"人与对手"而不是"人与敌人"时。
- 与《赌徒》都写输：陀思妥耶夫斯基让主角在输后解释自己，海明威让主角在输后闭嘴干活；一个向内挖，一个向外省。
- 与《重新派遣》都写极限状态下的独白：海明威的独白有节奏和体面，克莱的独白是算术和玩笑，用来挡住情绪。

## E｜执行步骤
1. 找出一段你反复说的话（"再撑一下""没事"） → 记录一周内出现的次数与每次的处境 → 判断它是补充还是消耗。
2. 写一场消耗：只写补给（吃了什么、睡了多久、还剩多少） → 不许写"累""痛" → 300 字。
3. 给你的对手（一个人、一个项目、一种病）写"兄弟"式描述：只写它的动作与耐力，不写你对它的评价。
4. 验收：读者能从数字推出现在是第几阶段，而不需要你说明。

## B｜边界与误用
- 抽样未含结尾，"人可以被毁灭，但不能被打败"是版本宣传语，不在抽样原文里，引用须分开。
- 硬汉伦理容易被读成"受苦即高贵"；书中独白同时也在自我说服，别只取励志面。
- 译本无注，古巴渔村的经济背景（鱼价、鲨鱼工厂）需外部资料才能读透。
- 全书几乎没有女性视角，男孩的敬爱是唯一的柔软来源，不足以代表完整的人际世界。
