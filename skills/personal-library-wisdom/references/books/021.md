# 《心理类型》 — 荣格（吴康 译）
> 类型：论说｜原文规模：约 25.1 万字｜抽样依据（工作档案 udigest/021.md（6 段）

## 一句话
把人分成两种态度、四种功能，并给出一套在争吵与自我误解中定位偏差的坐标。

## R｜原文骨架
抽样无章节标题，按内容定位：
- 德尔图良段 → 用教父的激情思维示范内倾思维如何以"内在现实"对抗知识。
- 席勒章 → 以"事物与形式""被动性与主动性"讲两种机制在个体内只能主次并存。
- 印度材料（《迦托普梵书》般茶帕底）→ 用"牺牲"讲对立面的均衡，而非转化。
- 詹姆斯章 → 柔性/刚性与内倾/外倾的对应，并声明尚待检验。
- 内倾理性型概述 → 类型偏差落在前提里，不在结论里。
- 象征章 → 对立双方势均力敌才生象征，一方被降伏则成症状。

## I｜核心命题与可执行方法
**态度定向判定** —— 触发：要给某人"固执/冷淡/爱表现"下判断 → 动作：看他在客体里找到自己还是丧失自己（原文：外倾型"通过客体真正找到他自己，而内倾型则在那里丧失了自己"），并比较社交前后的能量变化 → 验收：判断依据稳定来自外部材料或内部标准；反证：若两种场合都同一方式且不随客体变，那是习惯，不是类型。

**查前提而非驳结论** —— 触发：一场争论谁也说服不了谁 → 动作：不去证明对方结论荒谬，去挖未说出的前提，因为"主观因素的决定性地位，它先于一切结论和判断" → 验收：能写出一句"他把什么当成了不必论证的东西"；反证：若分歧其实在事实、数据或定义层，就不是类型冲突。

**劣势功能反读** —— 触发：某人异常激烈地贬低某类活动 → 动作：把贬低的强度当指标，内倾者轻视外倾，外倾者对内倾"投以同样的厌恶、恐惧和无言的蔑视"；越激烈越靠近自己的劣势端 → 反证：若他能举出具体例子说明该活动的缺陷，属判断而非投射。

**象征与症状的分判** —— 触发：一个意象、作品或行为反复出现 → 动作：看它是否同时容纳对立双方（"一旦出现对立双方处于势均力敌的状况"） → 验收：能读出正反两面的诉求；反证：若它只表达一方，并持续暗示被压下去的另一方，那是症状不是象征。

**以人物当类型标本** —— 触发：想验证一个类型判断 → 动作：取一个极端人物，看他在"与自己功能相反的证据"面前怎么办（德尔图良："上帝之子死了；这之所以可信，是因为它是荒唐的"） → 验收：能说出他牺牲了哪一半现实。

## A1｜书中实例
- 德尔图良（前段）：以内在现实对抗哲学与诺斯替知识。荣格把"因为荒唐所以相信"读成内倾思维的极端形态，而不是单纯的信仰告白。
- 詹姆斯的两栏对照（中段）：柔性＝理性主义、唯心、乐观、自由意志、一元、教条；刚性＝经验主义、唯物、悲观、宿命、多元、怀疑。荣格据此把柔性对应内倾、刚性对应外倾，并自认仍需检验。
- 席勒（前段）：把"事物与形式""被动性与主动性"的对立说成"距离是无限的"，荣格用它说明两种机制在同一人身上只能排主次。

## A2｜何时调用 / 与相邻书的区分
- 当用户想解释"为什么我和某人根本说不到一块"时。
- 当用户想给自己或同事做一次非量表式的类型判断时。
- 当用户把某人的持续贬低当作客观评价时。
- 当用户分不清一个反复出现的意象是创造力还是病灶时。
- 与《分析心理学的理论与实践》同用类型，差别在：本书给坐标与历史证据，那本给临床问法与梦的序列。
- 与《寻求灵魂的现代人》同讲四功能，差别在：那本把它压成一节通俗说明，本书给出发生学与哲学史论证。

## E｜执行步骤
1. 输入：一次具体的争吵记录（双方原话，不少于十轮）。
2. 分别标出双方判断所依据的材料：外部事实、内部标准、关系好坏、未来走向。
3. 写出各自未论证的前提各一句，判断是否只是态度定向不同。
4. 找出双方各自贬低对方的那句话，标注强度，推测各自的劣势功能。
5. 产出：一份"分歧类型诊断"，含一条可验证预测（换到对方擅长的场景，谁会更吃力），下次同类争执时核对。

## B｜边界与误用
- 类型是理想模型，不是量表；拿来给人贴标签、择偶配对，会把它变成星座。
- 抽样为片段且无章节标题，不能据此复述全书论证顺序。
- 把历史人物读成心理标本有以论代史之嫌，德尔图良那句话他自己也指出与史实不符。
