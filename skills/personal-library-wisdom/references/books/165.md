# 《基督山伯爵》 — 大仲马
> 类型：文学 | 原文规模：约 57.5 万字（三册） | 抽样依据（工作档案 udigest/165.md（6 段）

## 一句话
把复仇拆成情报、身份、债务与时间四项工程，看正义如何被私人接管。

## R｜原文骨架
套装三册，章节以"第X章"命名：
- 第一册 马赛 → 返航、订婚、阴谋、审讯、伊夫堡；第14–20章写牢中岁月与越狱。
- 第二册 罗马与巴黎 → 以基督山身份登场，设局、认亲、下毒、金融战。
- 第三册 收网 → 清算与出逃；抽样见唐格拉尔提款、烧信、准备离境。
- 抽样覆盖第一册前段（返航至伊夫堡）与后段（罗马、巴黎、唐格拉尔出逃），中段布局未完整核验。

## I｜核心命题与可执行方法
**信息分配表** —— 看每一场各自知道什么 → 问：读者比人物多知道哪一条 → 会看到悬念不靠事件，靠信息落差的位置。
**恩债分类** —— 看莫雷尔与唐格拉尔 → 问：同样的债务为何结算方式相反 → 会看到复仇者按"是否曾施恩"而不是按"是否有罪"排序。
**父子链** —— 看假父子、真父子、养父子 → 问：这份关系继承了什么 → 会看到身份是可以由文件、金钱和沉默拼装的。
**代理距离** —— 看基督山几乎不亲手杀人 → 问：执行被放在几层之外 → 会看到道德责任被外包给下属、舆论与法律。
**时间的复利** —— 看十四年牢狱与多年布局 → 问：等待换来了什么 → 会看到复仇的前提是先成为另一个人，而那个人也回不去了。

## A1｜书中实例
订婚宴（抽样1）：维尔福说政治犯"更坏"，因为国王是一国之父；侯爵夫人随即用一句"可以让人忘掉他父亲做过些什么"把话题转回前程。审判者的位置从一开始就和家族利益绑在一起。
认父（抽样4）：安德烈亚对卡德鲁斯说"我找到了我爸爸"，紧接着"管它呢！只要他给钱让我花"。假父子的交易性被这一句话说完，也让后面所有体面都变成租来的。
审问（抽样5）：基督山以布索尼神甫身份对卡德鲁斯说"每个罪犯都这么说"，然后逐条摆出他杀珠宝商的细节。赦免的前提是全供，怜悯在这里是一种审问技术。

## A2｜何时调用 / 与相邻书的区分
- 当用户要设计长篇的复仇或布局结构时。
- 当用户想分析"信息差如何制造悬念"时。
- 当用户处理组织中的代理执行与责任转移时。
- 与《告白》同问制裁的正当性：那本从被制裁者内部写后果，这本从制裁者外部写工程；同问"谁有权惩罚"，不同在有没有把代价算进去。

## E｜执行步骤
1. 输入：选一个复仇目标，列出他必须被摧毁的三样东西（名声、家庭、钱）。
2. 动作：为每样指定一个代理人，写明此人为何愿意执行。
3. 动作：画信息表，标出哪一步读者知道而目标不知道。
4. 产出：一页布局图，含时间、地点、见证人、意外。
5. 验收：任取一步，能说出目标若提前知道，计划会从哪断。

## B｜边界与误用
- 连载通俗剧的巧合密度极高，照搬到写实题材会失真。
- 复仇的伦理在书中被"天意"包装，实际未受审判；引用时须把这一层揭开。
- 女性角色多为被保护、被利用或被牺牲的位置。
- 三册篇幅巨大，抽样只覆盖首尾，中层布局的因果未核验。
