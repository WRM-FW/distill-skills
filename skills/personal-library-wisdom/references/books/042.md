# 《查第格》 — 伏尔泰
> 类型：合集 | 原文规模：约 4.0 万字 | 抽样依据（工作档案 udigest/042.md（6 段，含三篇作品）

## 一句话
用三则哲理故事做思想实验：换尺度、换命运、换证据，看判断怎么翻面。

## R｜原文骨架
- 《查第格》十九章（"独眼人""鼻子""狗与马"……"猜谜"）→ 让一个好人连续遭遇制度与偶然，检验"德行有没有用"。
- 《小大人》七章（天狼星居民游历土星，到"与人类的谈话"）→ 用尺度差拆掉"规则/混乱"的常识。
- 《巴蒲克》→ 派外来者考察一座城，最后用一件样品代替判决（抽样所见为连续叙述，无分章标题）。
- 三篇共用一种写法：短段、快转、结尾一句反转。

## I｜核心命题与可执行方法
**《查第格》：考验的设计** —— 看每一次试探是谁设的局 → 问："这个局测的是人的忠诚，还是条件的可能性？" → 会看到：假死试妻的结论不是"女人善变"，而是"忠贞需要不可能的前提"。

**《查第格》：偶然的账本** —— 看人物如何解释厄运 → 问："谁在事后替偶然写说明书？" → 会看到：天使说"天下没有一桩出于偶然的事"，渔夫的长篇倒霉史被排成"考验、惩罚、奖赏、预防"——解释越完整，越像替不公开脱。

**《小大人》：尺度翻转** —— 看观察者被放大或缩小后哪条常识失效 → 问："换个尺度，这个判断还成立吗？" → 会看到：钻石项链当显微镜才看见鲸鱼与人；土星人说地球"一切都是混沌"，小大人答"说不定住在这儿的就不是明理的人"。

**《巴蒲克》：样品代替判决** —— 看谁有资格审一座城 → 问："只能带一件证据回去，带什么？" → 会看到：金银土石混铸的人像让审判者说"即使不是一切皆善，一切都还过得去"——用配比取代纯度。

**反转句法** —— 看每段末句如何改写前文 → 问："这句是推翻上文，还是把读者请出场？" → 会看到：论证常由类比完成，不由推理完成。

## A1｜书中实例
- 《查第格》"鼻子"：查第格假死，加陶按剧本向阿曹拉索要"上一天新死的人的鼻子"治病；她持剃刀到坟前，查第格坐起来说"割我鼻子的主意，和把溪水改道的主意还不是半斤八两"。
- 《查第格》"渔夫"：乳酪商人依次失去主顾、妻子、屋子、鱼；每一段都以一次收费的"讲道理"收尾——讼师二两、检察官二两、首席法官的书记二两。
- 《小大人》：土星人捡起项链上散落的钻石当显微镜，用"直径一百六十尺"的镜片，才看见水里的鲸鱼。

## A2｜何时调用 / 与相邻书的区分
- 当用户想用一则短故事检验某个伦理命题时。
- 当用户需要"换尺度"的思维工具（把问题放大到宇宙，或缩小到日常）时。
- 当用户听到一套过于完整的解释，想查它在替谁免责时。
- 与《加缪手记》都用短句推进，但伏尔泰的短句是当众使用的论证武器，加缪的是私下待发酵的种子。

## E｜执行步骤
1. 选一个道德判断（如"忠诚"）→ 设计一个只有极端条件才能通过的测试 → 写出它测出的到底是人还是条件。
2. 把同一事件分别用"偶然""考验""惩罚"三种框架解释 → 比较三种解释各自让谁免责。
3. 把观察尺度改三次（个人／城市／星系）→ 记录判断在哪一层翻转。
4. 收尾写一句反转，要求它同时承认反方一半的道理 → 验收：读者无法用一句话站队。

## B｜边界与误用
- 巴比伦、波斯是法国现实的化名，别当东方社会史料。
- "试妻"故事带 18 世纪性别偏见，且文本对其是反讽还是认同并不明确，引用时须标注。
- 三篇文体不同（哲理小说、宇宙讽刺、道德寓言），不要合并成一套"伏尔泰思想"。
- 中译本夹有大量原注（影射包税员、扬山尼派等），不读注会漏掉一半讽刺。
