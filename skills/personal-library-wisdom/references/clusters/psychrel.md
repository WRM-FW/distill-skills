# 心理学、亲密关系与疗愈｜跨书综合

## 这一簇在解决什么

六本书面对同一句求助的不同说法："我们总吵同一件事""我不知道自己怎么了""他是不是有病""该不该走"。人一开口就用形容词和名词回答自己：他冷漠、我讨好型、原生家庭。形容词不可核对，名词更像已经做完诊断。这一簇的共同动作是把回答往后推：先换成可观察的行为，再决定要不要命名，最后才谈干预。

切口四路：米勒两版把关系拆成可计量的量（奖赏与代价、CL 与 CLalt、冲突走到第几步、拒绝是机会成本还是内在成本）；《蛤蟆先生》把内部换成可当场指认的口吻与坐标；《变态心理学》把"算不算病"换成四维连续谱与三道门槛；《社会心理学精品译丛》用实验程序与效应量替换"我觉得"。勒庞最旧也最不可靠，却提供别处没有的视角：两人的事被搬进群里，匿名与领袖会放大情绪。底线三句：描述先于命名，命名先于干预，干预有边界。

## 可执行流程（核心）

六个流程共用一道前置闸门：出现自伤、伤人、成瘾或精神病性症状，跳过后面所有步骤，直接走"停手线"。顺序不能颠倒——先安全，再模式，最后解释。

### 流程1：用可观察行为给关系做体检

- 适用：只有一堆形容词，或要判断偶发还是模式。
- 步骤：1) 抄最近三次同类情境的原话与动作，不写评价（《蛤蟆先生去看心理医生》执行步骤），少于三次不下结论。2) 用同书的**三种自我状态辨认**逐句标父母、儿童、成人口吻，看分布。3) 用《社会心理学精品译丛》的**非言语通道读取**看真假笑的时间进程与注视时长。4) 用《亲密关系（第8版）》的**奖赏—代价记账**各列五条并标可否替代，再用**CL 与 CLalt 双比较**写现状、期望、最佳替代。5) 用**归因纠偏**把"他就是这种人"改成情境归因，强制写一条反例。
- 产出：四列表（情境／原话动作／状态／可替代性），加一句"不满意还是不依赖"。
- 卡在哪：只取最伤人的一次；三次须跨家务、钱、亲友、性，否则只是吵架画像。

### 流程2：判断冲突会不会走到伤害

- 适用：争吵变密，出现威胁、摔物、查行踪。
- 步骤：1) 用《亲密关系（十周年纪念版）》的**冲突路径判读**标节点（避免→谈判→升级→打斗），记转折句。2) 用同书卡纳里清单数直接手段（批评与负面归因、敌意命令、对抗性提问、嘲讽贬抑）与间接手段（故作高贵、烦躁哀号、换话题、推脱）。3) 只用《变态心理学》**4D 连续谱评估**的"危险"维打分：推搡、掐颈、器物、跟踪、限制人身或经济自由、以自伤相威胁。4) 中度以上即停止双人练习，转人身安全机构、危机干预或警方；《社会心理学精品译丛》的**整合式解决方案**只用于危险维为轻、双方能安全退出时。
- 产出：转折句、手段计数、危险维评级、一个去向。
- 卡在哪：把"沟通不好"当结论。暴力特征是控制与恐惧；用沟通技巧处理控制，风险不动。

### 流程3：做"走还是留"的决定

- 适用：反复分手又回头，或"没吵架没出轨，就是不满意"。
- 步骤：1) 用《亲密关系（第8版）》的**CL 与 CLalt 双比较**：低于 CL 是不满意，高于 CLalt 是不依赖，二者可同时不成立。2) 用《亲密关系（十周年纪念版）》的**CL 漂移检测**写三年前与现在的"应得待遇"清单；再用**享乐适应校准**查曲线，婚恋幸福几年后回落。3) 用**代价性质判断**分清拒绝是机会成本（可做大蛋糕）还是内在成本（只能换方案）。4) 用《社会心理学精品译丛》的**整合式解决方案**问"怎样做双方都能成功"，再选做大蛋糕、补偿、降代价或桥接。5) 按维持／修复／退出各写一条动作与验收标准。
- 产出：满意度—依赖度四象限、期望漂移表、可做大蛋糕／只能换方案、三条动作。
- 卡在哪：把 CLalt 写成"有没有更好的人"。替代还包括独身、搬走、拆共同财务；只算新伴侣，等于把决定交给运气。

### 流程4：命名重复模式，不把人变成类型

- 适用：同一类人反复出现，同一场争吵反复上演。
- 步骤：1) 用《蛤蟆先生》的**心理游戏命名**写"触发句—应对句—固定结局"，名字用动词短语。2) 用**人生坐标定位**问反复进入哪一格、该格下最常做的两个决定；再用**愤怒的出口盘点**看气指向谁。3) 用《变态心理学》的**案例去标签化**把自述拆成可数的行为与时长。4) 用**4D 连续谱评估**四维各打轻／中／重并写证据。5) 用**责任与责怪分离**把"该怪谁"改成"本周能改哪一件小事"。
- 产出：模式卡——三段行为链、坐标、四维分、一条可证伪观察、一件本周动作。
- 卡在哪：把工具当判决。"他在玩 PLOM""她是讨好型"正是獾的挑剔型父母口吻；标签一宣布，模式就藏起来。

### 流程5：判断"要不要就医"

- 适用：量表自测后恐慌；亲友持续低落、失眠、疑心、暴食。
- 步骤：1) 用《变态心理学》的**4D 连续谱评估**打分，不用是／否。2) 用**诊断标准逐条核对**过三道门槛：病程（躁狂至少 1 周、几乎每天大部分时间）、附加症状数（3 项，心境仅易激惹则 4 项）、功能损害；缺一条不下结论。3) 用**鉴别与共病排查**排除物质、躯体疾病与其他障碍，写一句"为什么不是另一个"。4) 用**取向对照**从生物学、认知、家庭系统各写一段解释。5) 给出自助／门诊／急诊三档。
- 产出：4D 简表、门槛核对、排除清单、一个去处。
- 卡在哪：拿教材自查当诊断。标准需受训者结合访谈；该书抽样只覆盖第 2、7、12 章，其余章仅见标题，条目需回原书核对。

### 流程6：判断冲突被搬进群里之后

- 适用：家族群审判、同事群站队、网络曝光伴侣。
- 步骤：1) 用《乌合之众》的**匿名—责任稀释**标人数、身份可见度、有无署名，问"若由一人署名，他还会这么做吗"。2) 用**情绪极端化读数**按断言、重复、夸张、论证计数。3) 用**领袖—威望机制**问"抽走他，行动会不会停"。4) 用**信念宗教化检测**看反例者被当同行还是敌人。5) 用《社会心理学精品译丛》的**说服变量分栏**拆来源、信息、受众；圈内连续离婚时用《亲密关系（第8版）》的**离婚传染识别**数一度、二度网络（75%、33%，三度无效）。
- 产出：责任归属表、发言计数、一条降极化改动（署名或分层选项）。
- 卡在哪：拿"乌合之众"贴标签。勒庞只能当假设源。

### 停手线：出现即中止分析

任一项成立，停止关系归因、沟通练习与"理解他"式解释：自伤或自杀的计划与准备；施暴或明确威胁，含掐颈、器物、跟踪、限制人身与经济自由；成瘾（酒精、药物、赌博、网络）已妨碍日常义务或出现戒断；精神病性症状（幻觉、妄想、思维紊乱）。去向：即刻危险→急诊、报警或危机热线；无即刻危险但符合门槛→精神科门诊；只是关系困扰→个体或伴侣咨询。读书只能做到"认出该找谁"，真实咨询含评估、风险筛查与药物议题，不能替代治疗。

**标签化三条禁令**：不给自己下诊断名词当身份，只描述这一次的行为链；不向对方宣布他的类型；不拿坐标预测对方动机。

## 分歧地图

**一、变量在关系里还是人心里。**《亲密关系》两版认为去留可由 CL、CLalt 与代价性质算出；《蛤蟆先生》认为人带坐标进场，换人仍重演同一游戏。具体去留用前者，反复模式用后者；只用交换模型，会把模式误判成"这次对象不行"。

**二、命名还是去标签。**《变态心理学》要求**案例去标签化**，把自述拆成症状清单再对标准；《蛤蟆先生》的三状态与坐标本身就是命名工具。前者为分流与治疗决策，后者为让人看见模式。要就医用前者，要开口谈用后者且标签可撤回；后书自己批判贴标签，只能靠"用于自检、不用于宣告对方"化解。

**三、改期望还是改关系。**《亲密关系（十周年纪念版）》的 **CL 漂移检测**说满意度下降可能只来自期望上升，**享乐适应校准**说幸福必回落；第 8 版更强调结果与替代。前者易读成"降低期待就好"，后者易读成"不满意就该走"。期望确有升高证据时先校准；结果长期低于 CL 且低于 CLalt 时谈退出。

**四、群体可救还是不可救。**《乌合之众》断言群体只产生确信、只需要主人；《社会心理学精品译丛》用从众、说服与冲突实验给出可改变量。勒庞适合识别修辞，不适合预测；要干预只能用实验册。他"制度是性格的表达"又把制度降为性格的投影，宿命论更重。

**五、爱情是量还是脚本。**《亲密关系》用爱情量表分开测量激情之爱与相伴之爱，并用追踪数据说明婚姻的快乐会回落；《蛤蟆先生》把亲密关系写成童年坐标的重演。前者给可比较的数字，后者解释"明知数据不利仍重复"。

## 组合用法

**安全先行：198 + 202 + 090。** 先用危险维与鉴别排除器质性与成瘾，再用冲突路径标升级点，最后才用三状态开对话。顺序颠倒，就是把控制谈成沟通。

**去留决策：199 + 202 + 219。** 双比较算依赖，CL 漂移解释"没变坏也不满意"，整合式方案验"还能不能做大蛋糕"。

**模式复盘：090 + 198 + 199。** 坐标命名模式，标准防止升级为诊断，交换模型算出实际代价。

**群体压力：084 + 219 + 199。** 勒庞给极化读数，实验册给可改变量，离婚传染识别把"身边都在离"还原成网络效应。

## 选读路径

**只有 30 分钟**：198 第 1 章的 4D → 090 第十三章坐标 → 199 第 6 章 CL/CLalt。先拿"什么算严重"，再拿"我反复在哪一格"，最后拿"我为什么不走"。

**正在做去留决定**：199 第 6 章 → 202 第 6、11 章 → 219 的《社会冲突》册。先算依赖，再看漂移与冲突路径，最后学方案。

**想弄懂自己为何总这样**：090 全书 → 198 评估与诊断章 → 202 第 1 章工具性—表达性双维自评。先用叙事进门，再用标准校正，最后把"性格"换成可训练的两种技能。

**要写科普**：198 的标准与证据等级 → 219 的实验程序与效应量 → 084 当反面修辞样本。先用判据压住断言。

## 薄弱与空白

**材料不足**：198 抽样六段中三段是参考文献或术语表，正文只覆盖第 2、7、12 章；199 只覆盖第 1、3、6、8、10、13 章，沟通、性爱、暴力、修复仅见标题；202 三段为参考文献，正文只覆盖第 1、6、11 章；219 是七册合装，抽样只落在《亲密关系》非言语段与判断、冲突片段。引用未抽样章节需回原书核对。

**证据要打折**：084 是 1895 年的断言加例证，无抽样、无对照、无数据，性别与种族类比属时代偏见，只能生成假设；202 数据止于 2000 年代，社交媒体几乎未涉及；199 与 202 以美国异性恋样本为主，外推需谨慎。

**整簇空白**：没有一本讲中国本土转介路径：哪类机构接伴侣暴力、热线怎么用、如何判断咨询师合格、药物由谁开。亲密关系暴力章在目录里但抽样未覆盖，恰是"停手线"最缺的细节。

**只能算推断**：用"离婚传染"解释中国家族群压力，是把美国社区网络数据外推；用 TA 坐标解释依恋类型，是两套体系混用，书中并未对接。
