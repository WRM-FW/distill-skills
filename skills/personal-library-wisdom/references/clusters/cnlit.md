# 中国现当代文学｜跨书综合

## 这一簇在解决什么

四十九本书处理的不是文学评价，而是判断问题：在资源稀缺、权力不对等、面子必须维持的环境里，谁在付账、谁在忍、谁在演。证据大多是可核对的物——血量、车份儿、工分、聘礼、床位、罚款。人物的性格常是这些数字的余数。

第二个问题是"话"：说给谁听、绕几道弯、哪句是汇报或辩解。老舍、刘震云、阎真、王朔各有一套听法，合起来是解码器。

第三个是写作者位置：门外、帘下、傻子位、死后的队伍，决定看见什么。

## 可执行流程（核心）

### 流程1：判断一个处境里谁在忍、谁在付账
- 适用：家里或单位出了事，所有人都说"没事"。
- 步骤：1) 用《许三观卖血记》的"血量计价"列出三种通货的单价——现金、身体、人情；2) 用《活着》的"算账透镜"抄出全部数量词与亲属称谓，做"谁得到多少"表，标出"谁没有被分到"，那人通常就是忍的人；3) 用《余华作品全集》的"丧事的程序"看情绪排在第几步：先办事、先瞒人、后哭，说明这家在防"被听见"；4) 用《平凡的世界》的"体面的技术"问"他怕谁看见"，穷的核心是被人看见缺钱；5) 用《沧浪之水》的"清高的成本"结算，谁拒绝交易、代价落在谁身上。
- 产出：三列成本表（现金／身体与人情／面子），每行写支付人、金额或等价物，末句"付款人是___"。
- 卡在哪：把"忍"写成性格。每笔都指不到人，说明还在做道德评价。

### 流程2：写一段家里的事，不煽情
- 适用：写父母、丧事、旧屋、一次决裂，一落笔就滑向抒情。
- 步骤：1) 用《我与地坛》的"路线即思想"定地点与路线：他每天从哪走到哪、在哪停；2) 用《汪曾祺集》的"手艺账"找三个与情节无关的专业动作（旋木、开方、摊蛋皮），替代外貌与心理；3) 用《张爱玲经典作品集》的"衣料的证词"做物品账（钱、衣料、家具、吃食），让一件道具出现三次、每次改一次含义；4) 用《干校六记》的"可完成的小事"处理最重的部分，只写三件有验收标准的事，不出现"苦难"；5) 用《云边有个小卖部》的"嘴上的错位"把唯一的真心话改成玩笑。
- 产出：800—1200字，含物品账、路线、三个专业动作。验收：不出现"难过""怀念"，读者能说出谁死了、谁在忍、关系断在哪。
- 卡在哪：第4步的"小事"会被写成象征。必须有可验收的结果（水出来了、菜收了）。

### 流程3：听懂一段话里的三层意思
- 适用：饭桌、汇报、亲戚盘问、调解现场。
- 步骤：1) 用《沧浪之水》的"三层解码"给每句填字面义／关系义／交易义，用"称谓透镜"标出谁在何时改口；2) 用《一句顶一万句》的"拐弯透镜"数拐了几道弯，看他说的第几环，用"传话失真"记录转述者的增删；3) 用《晚熟的人》的"汇报体透镜"抓"汇报—请示—表态"句式：请吃饭是借口，汇报才是正事；4) 用《老舍全集》的"客气话的语法"删掉称呼与敬语，剩下的冲突就是礼数承担的功能；5) 用《咸的玩笑》的"钱的方言"把对话改写成"钱＋时间"条款，算谁亏。
- 产出：解码表（原话／三层义／他要保的东西），加"他没说出口的请求是___"。
- 卡在哪：全读成交易会漏掉真的"说不着"。刘震云那一栏填不出，就别硬套。

### 流程4：写一段不能直说的创伤
- 适用：家里有过不能提的事，单位有过不能写的年份。
- 步骤：1) 用《在细雨中呼喊》的"记忆的排序"按刺痛程度而非时间排章节，相邻两章要有情绪落差；2) 用《十八岁出门远行》的"日期刑罚透镜"——不写事件，写时间本身受刑，再用"出门口吻"删掉因果连接词；3) 用《干校六记》的"恐惧的清单"把怕拆成可核对的项目，并列而不递进；4) 用《活着》的"身体的替话"保留被动作替掉的那句话的位置，删掉解释；5) 用《我不想缺席人世间的任何一场悲喜剧》的"位置自省"写200字，交代你与当事人的关系、你无法确认的三件事。
- 产出：1500字以内的叙事，加"写了／没写"对照，逐条说明理由。
- 卡在哪：克制与回避只差一步。若说不出为什么省略，那不是克制，是没想清楚。

### 流程5：判断一场公共羞辱里谁在合谋
- 适用：热搜、单位通报、村里传话、群里围攻。
- 步骤：1) 用《阿Q正传》的"看客合演"标出旁观者的动作（笑／看／走开／传话），谁提供了"赏识"，用"转嫁链"看怒气往下流给了谁；2) 用《狂人日记 鲁迅小说全集》的"名目"圈出所有身份词，每个词旁写它省掉了哪条事实，用"从来如此"补出受益方；3) 用《兄弟》的"围观的位置"区分"帮忙的一个人"与"看着的十几个人"；4) 用《晚熟的人》的"调解现场透镜"找收尾定价，谁赔多少、有没有"永不上访"式承诺；5) 用《咸的玩笑》的"舆论的进货价"列出获益者，找出一个卖货的。
- 产出：围观分工图＋定价单＋一句判断：谁组织的，谁只是被卷进来。
- 卡在哪：止于"国民性"三个字。写不出具体受益方，就还是骂人。

## 分歧地图

**一、苦难该不该当场结算。**《活着》《许三观卖血记》只给账、不给报偿，叙述者不替人物总结；《平凡的世界》用"苦难的报偿"把苦折成道德资本与上升资格，叙述者兼做代言。差别在叙述者能否替人物兑现意义。写"人怎么熬"用余华；写"人为什么值得熬"用路遥，但要接受励志折价。

**二、日常之美是不是逃避。**《汪曾祺集》认为冲突都在实利里（香钱、摊位、面子），只是不摆到正面；《狂人日记 鲁迅小说全集》认为不指认就是合谋；《传奇》的"看客的高度"两者都不选——看清而不介入，判断降为自保，只剩苍凉。写家常取汪，写公共事件取鲁迅，写"看清了也无可奈何"取张。

**三、克制是伦理还是遮蔽。**《干校六记》用"轻笔写重"，判断留给读者；《我不想缺席……》主张"准确性作为伦理"加"位置自省"，认为省略必须交代理由。当事人已逝、年代不可证实，用杨绛；当事人还在世，用梁鸿。

**四、人情是执行系统还是债务。**《平凡的世界》的"信的枢纽"视人情为乡土办事的执行系统，是资源；《沧浪之水》的"人情复式账"视人情为没有合同的债务，早晚要还且常由家人支付。前提不同：前者资源靠关系调配，后者靠位置分配。

**五、装傻是位置、策略，还是标签。**《尘埃落定》的"傻子位置透镜"说不被设防的位置最接近全景；《晚熟的人》的"晚熟透镜"说装傻是对政治节奏的套利；《我胆小如鼠》的"恐惧定价"说胆小是被命名后分配到的地方。混用会把被欺负的人说成聪明人。

**六、记忆能不能作证。**《动物凶猛》的"记忆的美化率"承认叙述者给自己加光；《在细雨中呼喊》的"双声时间"让童年的不懂与成年的解释并存；《悠悠岁月》用"无人称的我们"和滑向"她"的代词分配责任。三人都在处理不可靠，办法相反。

## 组合用法

1. **三种通货的账本**：《许三观卖血记》给身体单价，《活着》给粮食与分配，《平凡的世界》给人情与手续。合起来能算一个家庭三十年的总账。
2. **白描双镜**：《汪曾祺集》管手艺与"准确"，《张爱玲经典作品集》管器物与看客的高度。汪把句子写准，张把镜头放低到帘下、阳台。
3. **围观三件套**：《阿Q正传》给个人的自我补偿算法，《兄弟》给集体的起哄现场，《狂人日记》给命名的前置程序。只用阿Q会读成性格。
4. **非虚构三道闸**：《我不想缺席……》管位置与准确性，《干校六记》管省略的分寸，《全球真实故事集》管证据链与"三套命名"。

## 选读路径

- **只有30分钟**：《阿Q正传》第二、三章 →《活着》分糖一段。先学"受辱后怎么结账"，再学"谁被算掉了"。
- **要判断一个具体处境**：《沧浪之水》→《一句顶一万句》→《许三观卖血记》。先有解码器，账才看得懂。
- **要写家里的事**：《我与地坛》→《汪曾祺集》→《干校六记》。地点、手艺、省略，各治一个。
- **想系统读懂这一簇**：《狂人日记 鲁迅小说全集》→《传奇》→《生死疲劳》→《我不想缺席……》。

## 薄弱与空白

- **顾准与沈从文不在本簇书卡中**（cnlit.json 无对应 uid）。"制度中的个人良知"与"抒情—乡土"只能靠《干校六记》《汪曾祺集》间接替代。
- **大型合集抽样不足，判断须回原书**：114 巴金、191 余华全集、211 张爱玲、222 老舍、164 收获榜、218 组合套装均只抽数段。225《镖人》仅7105字文字层。
- **版本与元数据**：137《空中小姐》书名作者与内容不符，只用其"引文的第二职业"方法；013《浮生六记》卷五、六多被视为伪托；089《骆驼祥子》前二十章无章节信息；227《汝州一高》单校单届、自愿填写且有"控评"，沉默者不在场。
- **视角缺口**：女性形象多由男性叙述，张爱玲是冷眼而非女性自述；非虚构与理论样本偏少，"制度如何运作"只能给文学证据。
