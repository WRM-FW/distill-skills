# 逻辑、论证与批判性思维｜跨书综合

## 这一簇在解决什么

这一簇只答一个问题：一句话给出理由之后，凭什么接受它的结论。十本书的分歧不在答案，在从哪一层动手。层次选错，算得再准也救不回。

第一层是句子：《Forallx》与陈波两本教材拆符号、排真值表、造小模型，判"前提真能否保证结论真"；普里斯特把有效性延伸到概率与决策。共同前提是有效性只看形式。第二层是话语：周建武先辨"这是不是论证"再补隐含前提，陈波第 3 版给论证图解与论证四问，《逻辑学是什么》给定义体检与谬误三问，孙中原则用先秦案例做古汉语版本。第三层是经验：《科学发现的逻辑》问理论能否被观察顶翻，把失败归到理论、辅助假说还是初始条件。第四层是互动：两本博弈论管别人也按理由行动时该怎么选，《世界的逻辑》则站得更远，问这张支付表是谁定的。

十本书拼起来是一条流水线：分诊、还原、清洗、判定、定档、找错、反打。

## 可执行流程（核心）

### 流程1：判一段话能不能信

- 适用：社论、举报信、项目汇报，要给"接受／削弱／存疑"。
- 步骤：1) 用周建武的**论证辨识**排除说明、举例、解释、警告，再用陈波第 3 版的**论证图解**分主结论、分结论、子理由；2) 用周建武的**重构三步**补隐含前提，**否定代入法**验：否定后垮掉才算假设；3) 用陈波的**定义体检**、孙中原的**名实对账**清洗关键词；4) 按陈波第 3 版分层判：命题层真值表或成假赋值，词项层查周延，量化层造小模型；5) 无效写反例，有效用周建武的**可靠／可信双公式**查前提真假；6) 用陈波第 3 版的**谬误定位**报名字，说清违反论证四问的哪一问。
- 产出：结构图、隐含前提一句、判定依据、可靠／可信结论、谬误名。
- 卡在：第 2 步。补前提易把对方补成钢人；守"似真性"不守"最善"。

### 流程2：把一段自然语言形式化

- 适用：论证绕、句子长、要写能逐行复核的记录。
- 步骤：1) 用《Forallx》的**翻译先定论域**，写清 UD 与符号化键，虚构对象、未来事件都放进 UD；2) 逐句翻，"所有／有的／唯一／除了"按量词规则，不合并、不省括号；3) 变项 4 个以上改用陈波第 3 版的**成假赋值**逆推；量化句用**小模型反例**，论域缩到 1–2 个对象；4) **回译**比对，不一致回第 1 步。
- 产出：UD ＋ 符号化键 ＋ 公式 ＋ 判定（有效／无效及反例）＋ 回译对照。
- 卡在：回译最常跳过。《Forallx》明说翻译错了后面算得再对也没用。

### 流程3：在信息不完整时评估归纳强度

- 适用："增长 80%""人均 3200""概率只有百万分之一"。
- 步骤：1) 用陈波的**谬误三问**拆数字：基数、绝对量、口径；2) 用普里斯特的**参照类定位**追问"在什么人群、什么条件下统计"，至少列两个参照类；3) 用**归纳强度公式**比较两个条件概率——前提真时结论为真 vs 为假，前者更大才算归纳上有效；说不出参照类即判"没有确定内容"；4) 遇"巧合太小不可能是偶然"，用**逆概率翻转**：把 P(证据|假说) 翻成 P(假说|证据)，补先验，列出其他假说也能产生该证据；先验估不出就说结论不成立；5) 用陈波第 3 版的**强度四档**定档，写一句"结论比前提多断言了什么"。
- 产出：数字核查表（基数、绝对量、口径、参照类）＋ 强度档位 ＋ 最弱一环。
- 卡在：概率方向写反，两个数是不同的；先验最易被悄悄设成 50%。普里斯特只给思路，真做贝叶斯得另找材料。

### 流程4：检验一个理论或强主张

- 适用："是不是这套方法错了""预测失败要不要放弃理论""对方总能自圆其说"。
- 步骤：1) 用《科学发现的逻辑》的**可证伪性划界**逼出"若观察到 X 则此说错"，X 须是他人按程序可观测的事件；逼不出的判非经验主张，不判为假；2) 写**假说—演绎否证链** T＋A＋C⇒P，观测前写死判据，把每条辅助假说单列；3) 不符时先逐条排查 A 与 C，产出责任归属清单；4) 对方打补丁时用**特设性豁免识别**比新旧经验内容，新版不禁止任何新观察即判退化；5) 两说都未被推翻时用**可检验度比较**，选禁止观察集合更大的；6) 主动攻击转周建武的**削弱三路**：打结论、论据或论证方式。
- 产出：T＋A＋C⇒P 图、责任归属清单、"进步还是退化"判定、一条否证条件。
- 卡在：第 3 步。辅助假说互相牵连，逐个排查没完；波普尔也承认统计检验与误差让否证变成程度问题，须按领域惯例设门槛。

### 流程5：把想法写成能被反驳的结构

- 适用：写论文、方案、驳论，或提交待评审的判断。
- 步骤：1) 用周建武的**图尔敏六要素**填主张、根据、保证、支撑、反驳、限定，"反驳"格不许空；2) 用陈波第 3 版的**论证图解**自查每条前提能否挂到结论下；3) 用《科学发现的逻辑》的**基本陈述的公共化**改写证据，并预写否证条件——什么结果出现就撤回；4) 用**削弱三路**自打一遍，每条攻击写回应，打不动的降为"限定"；5) 涉及取舍时用孙中原的**利害双列**，按"利之中取大，害之中取小"比较。
- 产出：六格齐全的论证稿 ＋ 自打记录（攻击点／回应／降级）＋ 一句撤回条件。
- 卡在：第 4 步容易造软靶。先问"什么数据会让我难堪"，再决定写不写进去。

### 流程6：判断该不该跟进、该不该信狠话

- 适用：价格战、谈判先后手、抽查与罚款、招聘门槛、要不要先让一步。
- 步骤：1) 用王则柯的**三要素建模**列参与人、穷举策略、每格写两个支付；2) 用王则柯的**严格优势剔除**删被支配策略，再用**划线法**逐列、逐行找最大支付，双线同格即均衡；3) 用《妙趣横生博弈论》的**先判囚徒困境**查对角线：一次性→背叛，有终点→倒推，无终点且认得出对手→以牙还牙；4) 有先后时用**倒推筛威胁**，末端不划算的划掉；要自己可信，用**让承诺可信**改支付或改规则；5) 多均衡用**风险优势判定**初筛（须写明"50/50 是参考性假设"），或按**共同信号协调**设信号；6) 类型看不见时用**用门槛甄别**；7) 落地前用《世界的逻辑》的**三循环定位**与**企业主义判据**补一刀：支付表由谁定，成本落在谁头上。
- 产出：支付矩阵 ＋ 均衡格 ＋ 结构标签 ＋ 候选策略 ＋ 可信性检验 ＋ 一句"支付表由谁定"。
- 卡在：支付数字。工具再对，数字估错就是精确的错误；支付表是输入不是结论，事后比对实际支付，差在哪格改表。

## 分歧地图

**一、终审在形式还是在经验。**《Forallx》与陈波第 3 版认为有效性是纯形式的，前提全假也可有效，"有效"不等于"成立"；《科学发现的逻辑》认为形式有效只说明推理没毛病，决定主张命运的是能否被观察顶翻。区别在对象：一段已写好的话 vs 一个还在跑的理论。混用会出现"有效所以成立"的跳跃。

**二、谬误名是诊断还是修辞。**孙中原整本书以命名为方法：名实对账、两可之辩、集合／元素检查、类比限度审查；陈波两本都警告贴标签不等于反驳，报出名字还得说明前提为何不成立。根源在文本对象：先秦名辩的毛病确实在词项漂移，命名即定位；现代议论文的毛病多在隐含前提，命名反而遮住缺口。

**三、支付表是给定还是待查。**《妙趣横生博弈论》把支付当输入，只管在给定支付下算最优；《世界的逻辑》认为支付表由资本积累、地方财政与产权安排生产，不问"谁定的"，算出的最优只是在一个被设定的局里最优。一次谈判用前者，一个产业十年、一座城市为何只能卖地用后者。用前者解释后者，会把结构问题写成当事人算错。

**四、反例是一票否决还是程度问题。**《科学发现的逻辑》语气接近一票否决；陈波第 3 版的**强度四档**与普里斯特的**归纳强度公式**把支持度当连续量，过 50% 即"强"。划界问"算不算经验科学"，评估问"这条证据值多少信任"，同一份数据两个答案。

## 组合用法

**《Forallx》＋ 陈波第 3 版：把直觉变成可复核的记录。** 前者用**反例情境法**让人三十秒内感到"这里跳了"，后者用**成假赋值**与**论证图解**把感觉写成一行具体赋值。只有前者，反例停在"我能想象"，对方可以不认。

**周建武 ＋ 孙中原：补前提时不被话术带走。** 重构三步把缺口补成可被否定的陈述，名实对账在补之前确认关键词没换所指。中文争论常输在"公平""效率"到第 3 句已换了意思，此时补出的前提必然补错。

**《科学发现的逻辑》＋ 周建武：把"反驳"升级成"定位"。** 削弱三路说往哪打，否证链说打完落在谁头上。只用前者，容易把一次实验失败说成理论被推翻；加了责任归属清单，才会先问仪器是否标错。

## 选读路径

**只有 30 分钟。**《逻辑学是什么》第七章（谬误三问、定义体检）→ 陈波第 3 版**论证四问**与**强度四档**→《Forallx》第一章的巴黎反例。先拿尺子，再拿框架，最后钉死"有效不等于为真"。

**要判一段具体的话、写一篇驳论。** 周建武（论证辨识→重构三步→削弱三路）→ 陈波第 3 版（论证图解→谬误定位）→《Forallx》（反例情境法、小模型）。先会拆主张与理由，再会画图找缺口，最后把缺口写成反例。

**要检验理论、写开题。**《科学发现的逻辑》（划界→否证链→特设性豁免）→ 普里斯特（归纳强度、参照类、逆概率）→《Forallx》（量化与小模型）。先定"什么算被推翻"，再算"证据有多少分量"，最后补工具。

**要处理谈判、竞标、制度设计。**《博弈论平话》（三要素→划线法→倒推）→《妙趣横生博弈论》（囚徒困境→承诺→门槛）→《世界的逻辑》（三循环、企业主义）。先会看均衡，再会改局，最后会问局是谁设的。

## 薄弱与空白

**两本材料本身不足。**《诡辩与逻辑名篇趣谈》PDF 无文字层，章节、页码、案例全部来自 OCR 补录；《逻辑学：牛津通识读本》抽样正文字符数为 0，结构由 OCR 重建。引用这两本的具体措辞与页码须回原书核对。

**《世界的逻辑》与本簇其余九本不同学科。** 它讲资本积累与空间生产的运行逻辑，不是论证的形式逻辑。纳入靠"归因框架"这一共同点：两者都问表面现象背后是什么结构在推。这是编辑归类，别指望它给判定程序。

**概率与因果有缺口。** 普里斯特的贝叶斯只给思路，无先验选择与建模；周建武的因果停在穆勒五法，不处理回归与混杂；陈波第 3 版的归纳章只讨论"归纳能否被证明"。本簇能识别"这个统计说法有问题"，给不出"该用哪个模型修正"。

**缺论证的语用与写作。** 图尔敏六要素服务应试题型而非长文谋篇，孙中原给的是古汉语案例不能直接迁移。如何组织三千字驳论、如何安排让步段，本簇未覆盖。
