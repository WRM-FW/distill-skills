# 科学哲学、知识论与世界观｜跨书综合

## 这一簇在解决什么

这一簇处理一个动作的三个面：判断一句话该不该信、信到什么程度、什么时候放手。

《高性价比人生指南》从结果端进：608 条建议逐条标价，用 RCT／队列／荟萃分 A/B/C，用 HR、RR 与 95% 区间判断"这点差别是不是还在误差里"。它回答"有没有被数据撑住"。

《自私的基因》从机制端进：把"为了种群好"改写成"对哪个基因的拷贝数有利"，用 ESS 扰动判断一个策略是自我修正还是自我加强，用性比、亲子冲突、囚徒困境把解释压成可算的数量关系。它回答"这个解释有没有真干活"。

《禅与摩托车维修艺术》从判断端进：良质不是物体而是事件，写不成判据，却在"就是它了"的瞬间真实发生。它回答"算不出来的部分，怎么才不被'凭感觉'吞掉"。

三本合起来能拼出一条链：这句话什么意思 → 什么算把它推翻 → 推翻之后怎么办。但这一簇没有科学哲学专著；可证伪性、特设性这些词是从操作反推的框架，不是原著立场，引用要分清转述与原文。

## 可执行流程（核心）

### 流程1：把一句主张改写成可检验的句子
- 适用：听到"这样更健康""这是进化来的""这个方法更好"，却说不清怎么算对、怎么算错。
- 步骤：1) 用《高性价比人生指南》的**口径隔离**标这句话在换什么——寿命、金钱、时间精力、自由，四本账不许混算，"降 12% 死亡率"与"省 500 元"不能进同一句；2) 用**证据定级**补三件套：人群、指标（HR/RR）、对照与时间窗，并要求 95% CI，把"有效"写成"对谁、多久内、把什么从多少降到多少"；3) 若还剩"更好""有质量"，用《禅》的**理性扩容**插一个中间量：先假定"三个月内静息心率降几次"这类可测层，再算它在具体场景的值；4) 用《自私的基因》的**基因视角换算**查主语：说"这是为了……"必须指得出对谁的什么收益，指不出就退回；5) 写下反驳条件：什么观测会让你放弃它。
- 产出：一张"可检验句"卡片——人群／指标与单位／对照／时间窗／预期区间／反驳条件。
- 卡在哪：第 3 步最容易滑回"跟着感觉走"；中间量只是脚手架，当成本体就成了新教条。

### 流程2：判定一次失败算不算反驳
- 适用：数据不利、实验没做出效果、有人举了一个反例。
- 步骤：1) 用《高性价比人生指南》的**证据定级**看区间分噪声与信号：流感疫苗那节总死亡 HR 0.59（0.39–0.89）站得住，心血管死亡 RR 0.74（0.42–1.30）跨 1，作者自判"算不上有统计学意义"——不显著只说明数据没说清；2) 用同书的**证据定级**查分母与人群口径：NordICC 按"被邀请去做肠镜"的人算，RR 0.90（0.64–1.16），改成"实际做了的人"结论就变；3) 若主张是机制模型，用《自私的基因》的**ESS 扰动检验**：把该策略比例轻微推高，收益变差＝自我修正（峡谷），单个反例不致命，变好＝自我加强（刀锋），小扰动就能掀翻；4) 用《禅》的**价值僵化停机**处理"这个反例不重要"的直觉：放慢，列三个被判为不重要的细节逐个看，很多反驳不是被驳倒的，是被扔掉的。
- 产出：一页判定——噪声／口径错位／真反驳／待定，各附理由与下一步观测。
- 卡在哪：把噪声当反驳会频繁改主意，把反驳当噪声就是不肯认错；区分只能靠事先写下的条件。

### 流程3：识别特设性修补
- 适用：一个理论每次被反驳后都"还能用"，或一条建议对谁无效都能解释。
- 步骤：1) 用《高性价比人生指南》的**争议复核**翻备注，看结论在什么人群、什么口径下成立，作者有没有主动给过反例，给不出反例的"过硬结论"先降级；2) 查修补有没有新增可检验的预测：只改适用范围、不改预测的（"对年轻人无效，对中年人有效；对中年人也无效？那是压力大的"）就是特设性修补；3) 拿《自私的基因》的**读尾注的元检验**作正面样板：作者算错后保留原文、在注释里逐段讲，读者能核对改了什么——修正与自欺的区别不在"改不改口"，而在有没有留下可查记录；4) 用同书的**觅母复制检验**解释它为什么传得开：看它靠什么被模仿、寄宿在谁的注意力上，传播优势与真假是两件事；5) 用《禅》的**古典／浪漫互译**逼对方说结构：只许讲谁、在什么条件下、改变了什么量，只剩"你不懂"的多半是修补。
- 产出：一张修补清单——每次反驳后新增了什么条款、是否带来新预测、哪一条能被证伪。
- 卡在哪：修补常常真诚、听着也合理；判据不是"像不像狡辩"，而是"有没有新增可检验内容"。

### 流程4：给证据排座次
- 适用：一堆互相冲突的材料，要决定信哪个、先读哪个。
- 步骤：1) 用《高性价比人生指南》的**证据定级**套档：有数字的 RCT、大队列、荟萃为 A，有研究无数字为 B，经验共识为 C（608 条中 A 410、B 149、C 49，近一成只有共识级）；2) 同级内再看区间与样本口径，同一节里两个指标可以一个算数一个不算；3) 用同书的**口径隔离**分表，四本账各算各的；4) 用《禅》的**侦察阅读**筛材料：只留能回答当前问题的段落，并写下跳过了什么、为什么可以跳；5) 用《自私的基因》的**读尾注的元检验**给每条 A 级结论加"修订状态"——原版怎么说、后来更正什么、争议在哪。
- 产出：一张证据表——结论／等级／区间／人群口径／适用时点／修订状态／失效条件。
- 卡在哪：等级只说明设计强度，不说明对你适用；该书自己的**性价比套档**也只是 C 级判断。

### 流程5：判断一个解释是不是"什么都能解释"
- 适用：听到"这是人性""这是进化的结果""动物这样做是为了种群"。
- 步骤：1) 用《高性价比人生指南》的**受益人分档**问好处落到谁——自己、直系、熟人、陌生人，写到第四档必须同时写风险；2) 用《自私的基因》的**基因视角换算**把"为了物种"改成"对哪个基因的拷贝数有利"，指不出收益方的解释退回；3) 用**性比投资核算**反推：若解释成立，应推出什么数量关系（如费希尔 50∶50），推不出数字的只是叙事；4) 用**囚徒困境记分**检查合作类解释，善良、宽容、不嫉妒能否各自对应到可观测行为；5) 设边界栏——物种、环境、时间尺度，并单列"不能从生物学推出什么"。
- 产出：一张"解释体检表"——解释对象／收益方／可推出的数量关系／反例／边界／不能推出的规范结论。
- 卡在哪：基因中心是建模视角，"基因想要"不是观测。

### 流程6：把检验结果翻成一句建议
- 适用：检验做完了，要给人一句话结论。
- 步骤：1) 用《高性价比人生指南》的**性价比套档**：写收益量级，列三项成本（钱、时间精力、毅力）套档，并标明档位是 C 级判断；2) 用同书的**受益人分档**写清建议给谁、风险谁承担；3) 涉及法律，用同书的**法条定位**区分"制度底线"与"结果保证"，别把"你有权"写成"你一定会赢"；4) 对算不出来的那栏，用《禅》的**良质事件定位**，要求指出一次"就是它了"的瞬间；5) 用**进取心切片**分辨缺的是工具、时间还是意愿；意愿问题加证据也没用。
- 产出：一条建议加三行附注——证据等级、成本、不可检验的价值选择。
- 卡在哪：把 C 级判断说成 A 级结论；或用"无法量化"逃掉全部检验。

**边界**：这套流程只处理"世界是不是这样"的经验命题。价值问题——该不该、值不值得、谁的利益优先——它给不出答案，只能把事实清干净，把选择留给当事人（《自私的基因》那句"不能从达尔文主义推出价值观"就是这条线）。它也不替代领域知识：肠镜该不该做，得有人懂肠道；流程只告诉你该要哪个数字、哪个区间。

## 分歧地图

**一、可检验性是不是可信的门槛。**《自私的基因》与《高性价比人生指南》默认：给不出反驳条件的说法不承载信息；《禅》却主张良质是事件、写不成判据，仍真实可辨。差别在对象：前者管经验命题，后者管评价判断。用可检验性判"这首诗好不好"会漏，用良质判"疫苗有没有效"会滑向"你不懂"。

**二、一个反例够不够。**《自私的基因》的 ESS 是确定性模型，一次扰动就分出刀锋与峡谷，单点即可定性；《高性价比人生指南》面对有抽样误差的人群数据，单个不利结果常落在区间内。差别在有没有噪声：机制层认单反例，效果层先看区间与口径。

**三、解释"为什么"与证明"有没有用"是两件事。**《自私的基因》能给利他一个基因解释，却推不出"人应该自私"；《高性价比人生指南》能给肠镜的效果区间，却不解释机制。机制通顺补不了数据缺口——疫苗那节心血管死亡就是例子。

**四、修正与自欺长得很像。**《自私的基因》保留原文加注，是公开可查的修正；《禅》里的价值僵化，是把异常判为不重要。两者都不推翻原结论，区别在有没有留下别人能核对的记录、有没有新增预测。

## 组合用法

**《高性价比人生指南》＋《自私的基因》：可信度与机制。** 前者判"这条说法站不站得住"，后者判"这个解释有没有干活"，合起来把"听起来有道理"与"有证据"拆成两栏，专治机制通顺就信。

**《高性价比人生指南》＋《禅》：可量化与不可量化。** 能算的用 A/B/C 算清，算不出的用良质事件接住，同时防止把 C 级判断包装成 A 级结论。

**《自私的基因》＋《禅》：两个停机键。** ESS 扰动查模型稳不稳，价值僵化停机查自己漏看了什么；一个对外，一个对内。反复修不好时，先停机看细节，再回来做扰动。

**三本＋一张单：** 流程 1 的卡片、流程 4 的表、流程 3 的修补清单钉在一起，就是一次完整的主张审查，从表述到证据到修补记录，全程留痕。

## 选读路径

**只有 30 分钟：**《高性价比人生指南》的「证据定级」＋「争议复核」→《自私的基因》的「基因视角换算」＋「读尾注的元检验」。先拿区间与收益方两把尺。

**要做一次重要决定（体检、保险、要不要停药）：** 该书「口径隔离」→「性价比套档」→「受益人分档」→《禅》的「良质事件定位」。先分账再排序，最后处理算不出来的部分。（该书素材为节选，具体条目需回原书核对）

**要写论文或做文献综述：**《自私的基因》「读尾注」→《高性价比人生指南》「争议复核」→《禅》「侦察阅读」→《自私的基因》「ESS 扰动检验」。先学怎么标自己的错，再学怎么读别人的争议，最后才是筛选与建模。

**纯粹想读懂这类问题：**《禅》前半（古典／浪漫、良质）→《自私的基因》（复制因子到性比）→《高性价比人生指南》（证据分级）。抽象度递减：什么是好 → 什么是机制 → 什么算证据。

## 薄弱与空白

1. **没有一本是科学哲学原著。** 可证伪性、特设性这些框架是从操作反推的，不能当作波普尔、拉卡托斯、库恩的立场引用；写论文须回原书。
2. **《高性价比人生指南》素材为抽样**，只见前言、目录与条目片段，608 条未逐条核；价格、政策、法条有时点，引用前须核当年文件。流程 4 的 A/B/C 比例来自该书自述，未经复核。
3. **《禅》未覆盖父子线结局与部分注疏，《自私的基因》未覆盖亲属选择、亲子冲突的完整论证。** 流程 2、5 涉及 ESS 与性比的参数设定，需回原书核对。
4. **缺社会科学因果推断（DAG、工具变量、自然实验）与贝叶斯证据更新，也缺伪科学的具体案例**（占星、顺势疗法、替代医学）。本簇只给"怎么问"，给不了"某个领域里答案是什么"。
