# 书库总览

## 这是什么

用户个人资料库（Library 文件夹）中全部 **246 个书籍文件**的蒸馏产物：**228 个工作单元**（同名不同版本/译本已合并），每单元一张书卡，外加 16 份跨书主题综合。

- **原文规模**：抽取正文约 1.5 亿字符（约 9300 万汉字），另有 3 本扫描件经 OCR 补录（约 75 万字符）。
- **蒸馏方法**：每本书做「OPF 章节结构还原 + 6 段跨位置连续抽样（不改写）」，由独立蒸馏员据此写成 R/I/A1/A2/E/B 六段书卡；每簇再由综合员读完全部成员书卡写成跨书流程、分歧地图与组合配方。
- **可溯源**：书卡中的实例与金句均取自抽样原文；材料不足处（节选、样章、扫描件）在各卡与簇文档的"薄弱与空白"中如实标注。

## 怎么用这个 skill

1. 带着任务来，先在 SKILL.md 路由表里找到簇，读簇文档里的"可执行流程"。
2. 流程指向具体书目时，再开对应书卡看细节、实例与边界。
3. 只想速查结论：cheatsheet；按方法名查：glossary；查书：books-index。

## 已知边界

- 书卡基于抽样而非全文精读；涉及精确引用（写论文、出庭、出版）须回原书核对。
- 部分文件本身是节选/样章/扫描件（如《黄仁勋：英伟达之芯》仅有样章、三本逻辑学教材靠 OCR），已在对应卡片标注。
- 文学类书卡提供的是分析透镜，不是文学史定论。
