- **Evidence-Based Ergogenic Supplements (`Chapter 9`)**:
  - **Creatine Monohydrate**: Increases muscle phosphocreatine by 10-40%, lean body mass, and high-intensity repetitive power. Loading: `20-25 g/day` (or `0.3 g/kg/day`) for 5 days, followed by maintenance of `2-5 g/day` (`0.03 g/kg/day`).
  - **Caffeine**: `3-9 mg/kg` 60 min prior to aerobic endurance events spares glycogen and reduces RPE.

### Module B: Injury Rehabilitation and Reconditioning (`Chapter 20`, `Tables 20.1-20.2`)

1. **Three Tissue Healing Phases & Exercise Rules**:
   - **Phase 1 - Inflammation Phase** (typically 2-3 days, up to 1+ wk): Pain, swelling, redness, decreased collagen synthesis. **Rule**: **Zero active loading of the injured tissue**; protect new clot/fibrin matrix; maintain cardiorespiratory fitness and strength/power of uninjured adjacent limbs.
   - **Phase 2 - Repair Phase** (starts ~2 days post-injury, lasts up to 2 months): Collagen fiber production (Type III, unaligned/weak), decreased organization. **Rule**: Consult sports medicine team; begin **submaximal isometric** strengthening at pain-free angles -> progress to **isokinetic** and **low-load isotonic (`<50% 1RM`)** + proprioceptive/neuromuscular control drills (`2-3x15-20` for endurance athletes; `3-4x8-10` for strength/power athletes).
   - **Phase 3 - Remodeling Phase** (lasts months to >1 year): Collagen alignment along stress lines (Type I), increased tissue strength. **Rule**: Progress to **sport-specific velocities, Closed & Open Kinetic Chain (CKC/OKC) functional movements**, and higher intensities (`50-75%+ 1RM`).
2. **Rehabilitation Resistance Loading Protocols (`Table 20.2`)**:
   - **DeLorme Protocol** (Ascending Pyramid, 3 sets x 10 reps): Set 1 = `10 reps @ 50% 10RM` -> Set 2 = `10 reps @ 75% 10RM` -> Set 3 = `10 reps @ 100% 10RM`.
   - **Oxford Protocol** (Descending Pyramid, 3 sets x 10 reps, accommodates fatigue): Set 1 = `10 reps @ 100% 10RM` -> Set 2 = `10 reps @ 75% 10RM` -> Set 3 = `10 reps @ 50% 10RM`.
   - **Knight's DAPRE Protocol** (4 sets, autoregulated by Set 3 performance):
     - **Set 1**: `10 reps @ 50% estimated working 1RM`
     - **Set 2**: `6 reps @ 75% estimated working 1RM`
     - **Set 3**: **Maximum repetitions possible @ 100% working weight**
     - **Set 4 & Next Session Adjustment (`Table 20.2`)**:
       - `0-2 reps in Set 3`: Decrease Set 4 by **5-10 lb (2.3-4.5 kg)** | Decrease Next Session Set 3 by **5-10 lb (2.3-4.5 kg)**
       - `3-4 reps in Set 3`: Decrease Set 4 by **0-5 lb (0-2.3 kg)** | Keep Next Session Set 3 the **Same**
       - `5-6 reps in Set 3`: Keep Set 4 the **Same** | Increase Next Session Set 3 by **+5-10 lb (+2.3-4.5 kg)**
       - `7-10 reps in Set 3`: Increase Set 4 by **+5-10 lb (+2.3-4.5 kg)** | Increase Next Session Set 3 by **+5-15 lb (+2.3-6.8 kg)**
       - `>=11 reps in Set 3`: Increase Set 4 by **+10-15 lb (+4.5-6.8 kg)** | Increase Next Session Set 3 by **+10-20 lb (+4.5-9.0 kg)**

### Module C: Facility Design, Spacing, and Risk Management (`Chapters 21-22`, `Table 21.1`)

- **Four Facility Design Phases (2-Year Timeline)**: Predesign (25%, needs/feasibility/master plan) -> Design (10%, blueprints/specs) -> Construction (50%, ~12 months) -> Preoperation (15%, ~3-4 months, staffing/SOPs).
- **Space & Structural Specifications (`Table 21.1`)**:
  - **General Space**: **40 to 50 sq ft (3.7-4.6 m2) per athlete**; Stretching/warm-up: **49 sq ft (4.6 m2) per athlete**.
  - **Prone/Supine Bench**: `(Bench length [6-8 ft] + 3 ft safety) x (User width [7 ft] + 3 ft safety) = 90 sq ft (9 m2)` for a 6-ft bench.
  - **Standing Barbell (Curl/Row)**: `(Bar length [4-7 ft] + 6 ft double safety) x 4 ft width = 40 sq ft (3 m2)` for a 4-ft bar.
  - **Standing in a Power Rack (Squat/Press)**: `(Bar length [7 ft] + 6 ft double safety) x (8-10 ft width) = 130 sq ft (12 m2)`.
  - **Olympic Lifting Platform**: `(Platform [8 ft] + 4 ft walkway) x (8 ft + 4 ft walkway) = 144 sq ft (12.25 m2)`.
  - **Clearances & Walkways**: Minimum **36 inches (91 cm)** between bar ends, between lifting equipment and weight trees, and for doors/walkways; **60 inches (152 cm)** for main circulation hallways; **>=6 inches (15 cm)** from mirrors; mirrors mounted **>=20 inches (51 cm)** above floor (above 18-in weight plates).
  - **Ceiling, Floor, and Environment**: Ceiling **12-14 ft (3.7-4.3 m)** clearance; non-ground floor load capacity **>=100 lb/sq ft (488 kg/m2)**; Ramp slope **12:1 (1 ft run per 1 inch rise)** for thresholds >0.5 in; Lighting **75-100 foot-candles (807-1,076 lux)**; Temperature **68-78 F (20-26 C)** (ideal **72-78 F [22-26 C]**); Humidity **<=60%**; Air exchange **8-12/hr** (optimal **12-15/hr**); Sound **<=90 dB**.
- **Supervision Ratios & Legal Risk Management (`Chapters 21-22`)**:
  - **Staff-to-Athlete Ratios**: Middle school / Junior high **<= 1:10**; High school / Secondary **<= 1:15**; College / Adult **<= 1:20** (absolute facility ceiling **<= 1:50**).
  - **Four Elements of Negligence**: (1) Duty, (2) Breach of duty, (3) Proximate cause, (4) Damages (~80% of athletic injury lawsuits involve supervision failures).
  - **Product Liability Protection**: Never modify equipment from manufacturer specifications, use equipment only for its intended purpose, inspect regularly, and immediately tag/remove defective equipment.

## A1 - Book Applications (Past Application)

### Case 1: Patellofemoral Injury Reconditioning (`Chapter 20`, Marathon Runner vs. Olympic Lifter)

- **Inflammation Phase**: Zero quadriceps loading for both; marathoner maintains hip/ankle endurance and upper-body/non-impact cardio; Olympic lifter maintains upper-body strength/power and hip/hamstring strength.
- **Repair Phase**: Both start pain-free isometric quad extensions -> progress to submaximal (`<50% 1RM`) isotonic extensions (`2-3x15-20` for marathoner; `3-4x8-10` for Olympic lifter).
- **Remodeling Phase**: Add CKC squat and lunge (`50-75% 1RM, 2-3x15-20` + return to running for marathoner; `>75% 1RM, 4-5x3-8` + RDL and competition velocities for Olympic lifter).

1. **For Nutrition/Hydration**: Compute daily kcal (`Table 10.7`), protein (`1.5-2.0 g/kg`), carbohydrate (`8-10` vs. `5-6 g/kg`), fat (`>=20%`), and fluid replacement (`>=0.5 L per lb lost`).
2. **For Injury Reconditioning**: Identify tissue healing phase (`Inflammation / Repair / Remodeling`), select CKC/OKC exercises cleared by sports medicine, and apply the 4-set `DAPRE` adjustment table (`Table 20.2`).
3. **For Facility Planning**: Calculate station square footage (`Table 21.1`), verify 36-in/60-in clearances and environmental targets, and enforce `1:10 / 1:15 / 1:20` supervision ratios.

## B - Boundary and Failure Modes (Boundary)

- **Failure Mode (Loading Tissue During the Inflammatory Phase)**: Active stressing of newly injured tissue disrupts fibrin clot formation and prolongs inflammation.
- **Failure Mode (Modifying Equipment or Leaving Broken Machines Untapped)**: Alters manufacturer liability and creates direct negligence exposure (`Duty + Breach + Proximate Cause + Damages`).
