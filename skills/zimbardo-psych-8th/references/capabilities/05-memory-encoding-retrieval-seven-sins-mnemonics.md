# Capability 05: Constructive Memory, Three-Stage Processing, Seven Sins Diagnosis, and Study Mnemonics

## R - Source Anchor (Reading)

- **Source Location**: Chapter 5 (Memory, `Core Concepts 5.1-5.4`, `Sections 5.1-5.8`, `Chapter Problem: Evaluating Recovered Recovered Memories`, `Critical Thinking Applied: The Recovered Memory Controversy`).
- **Core Mechanism**:
  - **Constructive & Reconstructive Memory (`5.1`)**: Memory is **not** a video camera; it encodes fragments and reconstructs them at retrieval using existing **schemas**, expectations, and current context (`Loftus`). Every memory task requires `Encoding -> Storage -> Retrieval`.
  - **Three-Stage Information Processing (`Atkinson-Shiffrin + Baddeley`, `5.2-5.4`)**: Information flows from fleeting **Sensory Memory** (`Iconic/Echoic`) through capacity-limited **Working Memory (`7 +/- 2 chunks`)** into vast **Long-Term Memory (`Explicit [Semantic/Episodic]` vs. `Implicit [Procedural/Priming]`)**, consolidated via **Long-Term Potentiation (`LTP`)** in the hippocampus (`explicit`) and cerebellum/basal ganglia (`implicit`) and modulated by the amygdala (`emotional/flashbulb/PTSD`).
  - **Schacter's Seven Sins of Memory (`5.6-5.7`)**: Memory failures divide into **3 Sins of Omission (Forgetting)** and **4 Sins of Commission (Distortion/Intrusion)**-all adaptive evolutionary trade-offs that prevent cognitive overload and update old information.

## I - Methodology Skeleton (Interpretation)

### 1. Three-Stage Memory Architecture & Brain Substrates (`Ch 5.2-5.5`)

| Memory Stage | Subsystems / Components | Capacity | Duration | Encoding & Neural Substrate |
| :--- | :--- | :--- | :--- | :--- |
| **1. Sensory Memory** (`5.2`) | **Iconic** (visual, `Sperling`) & **Echoic** (auditory) | Large (`12+` visual items raw) | Iconic: **`~0.25-0.5 s`**<br>Echoic: **`~3-4 s`** | Pre-attentive sensory cortices; selects changing/relevant input for working memory. |
| **2. ### 2. Schacter's 7 Sins of Memory Diagnostic & Remediation Matrix (`Ch 5.6-5.7`)

| Category | Sin of Memory | Underlying Mechanism & Classic Evidence | Adaptive Value (`5.7.5`) | Actionable Countermeasure / Prevention |
| :--- | :--- | :--- | :--- | :--- |
| **Omission 1** | **Transience** (`5.6.1`) | **Ebbinghaus Forgetting Curve** (rapid initial drop then plateau), **Proactive Interference** (`old blocks new`), **Retroactive Interference** (`new blocks old`), and retrieval-induced synaptic pruning. | Clears obsolete clutter (old parking spots, old passwords). | Use **Spaced / Distributed Practice**, overlearning, and sleep between study blocks to minimize retroactive interference. |
| **Omission 2** | **Absent-Mindedness** (`5.6.2`) | Divided attention / **Default Mode Network (`DMN`)** daydreaming during encoding, or **Prospective Memory failure** (`accounts for ~50% of all everyday memory loss`: forgetting to execute a future intention). | Allows automatic habits to run without exhausting conscious focus. | Eliminate multitasking during encoding; for **Prospective Memory**, place **unignorable external focal cues** directly in the physical execution path (e.g., medicine bottle on car keys). |
| **Omission 3** | **Blocking** (`5.6.3`) | Temporary retrieval bottleneck (**Tip-of-the-Tongue `TOT` state**), heightened by stress or aging (`proper names`). | Prevents competing similar memories from firing simultaneously. | Stop forcing the blocked word; shift to associative **context, semantic, or phonetic cues** and relax sympathetic arousal. |
| **Commission 1** | **Misattribution** (`5.7.1`) | Confusing the **source** of a memory (remembering the fact but attributing it to the wrong person, dream, or imagination). | Prioritizes gist meaning over costly source metadata. | Explicitly tag source metadata at encoding; beware of familiarity without source recall (`cryptomnesia` / eyewitness transference). |
| **Commission 2** | **Suggestibility** (`5.7.2`) | **Loftus Misinformation Effect**: Post-event leading questions (*"How fast were the cars going when they smashed into vs. hit each other?"*) overwrite the original memory trace during reconsolidation. | Allows social updating of shared narratives. | Use **neutral, non-leading open questions** in interviews/investigations; separate witnesses immediately. |
| **Commission 3** | **Bias** (`5.7.3`) | **Consistency / Egocentric / Expectancy Bias**: Rewriting past memories to match current beliefs, attitudes, or self-image. | Maintains psychological coherence and self-esteem. | Keep contemporaneous written logs (`timestamps`) before outcomes are known. |
| **Commission 4** | **Persistence** (`5.7.4`) | Intrusive, unwanted recall of traumatic events or humiliating failures driven by hyperactive **amygdala + norepinephrine** release (**PTSD**). | Ensures survival-critical threats are never forgotten. | Apply **Cognitive-Behavioral Exposure**, **Time Perspective Therapy (`TPT`, Ch 14)**, or researched reconsolidation blockers (`propranolol debate, Ch 13`). |

### 3. Encoding Specificity & Study Mnemonics Protocol (`Ch 5.5, 5.8 & Using Psychology to Learn Psychology`)

- **Encoding Specificity Principle (`Tulving`)**: Retrieval succeeds best when retrieval conditions match encoding conditions across:
  1. **Context-Dependent Memory** (`Godden & Baddeley scuba-diver study`: study in quiet, exam-like environments).
  2. **State-Dependent & Mood-Congruent Memory** (match physiological/arousal state and avoid studying exclusively on stimulants or extreme fatigue).
- **Serial Position Effect (`5.6.1`)**: Recall is highest for the beginning (**Primacy Effect** -> transferred to LTM) and end (**Recency Effect** -> still in Working Memory), and lowest for the **Middle** of a list -> *Study-plan rule*: Break long study sessions into short `25-45 min` blocks (creating more beginnings and endings) and give extra review to middle chapters.
- **3 High-Efficacy Mnemonic Systems (`5.8`)**:
  1. **Chunking into Core Concepts (`To the Student`)**: Group isolated details (`IBMUFOFBILOL`) under hierarchical **Core Concept** schemas (`4 chunks` instead of `12 letters`).
  2. **Method of Loci (`5.8.1`)**: Mentally walk a familiar spatial route (rooms in your home) and anchor vivid visual images of items at each locus.
  3. **Natural Language Mediators & Self-Reference (`5.8.2-5.8.3`)**: Create acronyms, rhymes, vivid interactive mental imagery, and personal self-examples.

## A1 - Book Applications (Past Application)

### Case 1: Evaluating "Recovered Memories" vs. False Memory Construction (`Ch 5 Opening Problem & Critical Thinking Applied`)

- **Problem**: Clients in suggestive therapy (using hypnosis, dream interpretation, or guided imagery) suddenly "recover" vivid memories of childhood abuse or alien abduction decades later.
- **Method**: Applied **Loftus's "Lost in the Mall" and Misinformation paradigms** plus neuroscience of trauma memory.
- **Conclusion & Result**: While genuine trauma can sometimes be forgotten (`dissociative amnesia`) or remembered all too vividly (**Persistence / PTSD**), human memory does **not** store a pristine video awaiting playback; suggestive questioning, hypnosis, and guided imagery easily implant rich, high-confidence **false memories** via **Misattribution and Suggestibility**.

## E - Executable Steps (Execution)

1. **Diagnose the Memory Stage & Sin**: Pinpoint whether the failure occurs at **Encoding** (`Absent-mindedness / shallow maintenance rehearsal / chunk overload > 7+/-2`), **Storage/Consolidation** (`Transience / sleep deprivation / retroactive interference`), or **Retrieval/Distortion** (`Blocking, Misattribution, Suggestibility, Bias, Persistence`).
2. **Restructure Encoding for Deep Semantic Storage**: Chunk material into `5-9` hierarchical Core Concepts, generate personal examples (**Elaborative Rehearsal**), pair verbal text with visual diagrams (**Dual Coding**), and space study across multiple sleep cycles (**Distributed Practice**).
3. **Engineer Retrieval & Prospective Cues**: Use active self-testing (`retrieval practice`), match study context to test context (**Encoding Specificity**), and anchor future intentions (**Prospective Memory**) to physical trigger objects in the environment.

## B - Boundary and Failure Modes (Boundary)

- **Failure Mode (Equating "Flashbulb Memory" Confidence with Accuracy, `Ch 5 Psychology Matters`)**: People feel 100% certain of their **Flashbulb Memories** (e.g., where they were on 9/11 or Challenger disaster), but longitudinal tracking (`Neisser & Harsch; Talarico & Rubin`) proves flashbulb details decay and distort over time just like ordinary episodic memories-only *subjective confidence* remains inflated.
- **Failure Mode (Wishing for "Photographic / Eidetic" Total Recall, `Ch 5.1 Psychology Matters`)**: As Luria's patient `S.` (*The Mind of a Mnemonist*) and hyperthymesia cases show, inability to forget (**lack of adaptive transience**) floods working memory with irrelevant sensory trivia and cripples abstract concept formation.
