## R - Reading (原文锚点与核心机制)

1. **定义理论与五条定义规则 (陈波《逻辑学导论》第6章第1节；周建武《逻辑学导论》)**：
   - 定义由**被定义项 (`Ds`) + 定义联项 + 定义项 (`Dp`)** 构成，最常用方法为**“属加种差定义法 (`Genus + Differentia`)”**。
   - **定义的五条铁律**：①定义项与被定义项外延必须全同(防**定义过宽**或**定义过窄**)；②定义项不得直接或间接包含被定义项(防**同语反复 / 循环定义**)；③定义项不得含混晦涩或用比喻代定义(防**比喻定义**，如“建筑是凝固的音乐”)；④定义一般不应采用否定形式(防**否定定义**，除非被定义项本身是负概念如“无期徒刑”)；⑤定义必须保持价值中立(警惕把主观好恶塞进定义的**说服性定义 Persuasive Definition**)。
2. **论证识别、结构图解与图尔敏 (Toulmin) 六要素模型 (周建武《逻辑学导论》；陈波第6章第2节)**：
   - **四种基本论证结构图 (Argument Diagrams)**：
     - **序列结构 (Serial / 链式)**：`P1 -> P2 -> C` (环环相扣，任一环断裂则整体崩溃)。
     - **收敛结构 (Convergent / 独立支持)**：`P1 -> C` 且 `P2 -> C` (多路独立证据，一路被驳倒其余仍可支撑结论)。
     - **联结结构 (Linked / 结合支持)**：`P1 + P2 -> C` (大小前提必须共同发力，缺一不可，拆掉隐含前提即瓦解)。
     - **发散结构 (Divergent)**：同一前提 `P` 同时推导出两个结论 `C1` 与 `C2`。
   - **斯蒂芬·图尔敏 (Stephen Toulmin) 实质论证六要素模型 (周建武/武宏志)**：
     1. **主张 (Claim, `C`)**：论证者试图确立的结论。
     2. **数据 / 理由 (Data / Grounds, `D`)**：支撑主张的具体事实或证据。
     3. **保证 / 推理通行证 (Warrant, `W`)**：连接 `D` 与 `C` 的普遍原则、规则或桥接假设(通常为隐含前提)。
     4. **支撑 (Backing, `B`)**：证实保证 `W` 本身合法可靠的法条、科学理论或统计基底。
     5. **模态限定词 (Qualifier, `Q`)**：限定主张成立强度的副词(如“大概、通常、除极少数情况外”)。
     6. **反驳 / 例外条件 (Rebuttal, `R`)**：明确指出在何种特殊情形下(`Unless...`)保证 `W` 失效、主张不成立。
3. **非形式逻辑谬误四大谱系与批判性思维五算子 (周建武《逻辑学导论》；陈波第6章第3节)**：
   - 涵盖**相关谬误 (Fallacies of Relevance)**、**歧义谬误 (Fallacies of Ambiguity)**、**预设谬误 (Fallacies of Presumption)** 与**弱归纳谬误 (Fallacies of Weak Induction)**，以及论证有效性分析的五大标准操作：**削弱 (Weaken)、加强 (Strengthen)、假设 (Assumption)、解释 (Explain)、评价 (Evaluate)**。

## I - Interpretation (方法论骨架、定量参数表与决策规则)

### 1. 非形式逻辑 20 大高频谬误分类、形式特征与反制话术全表

| 谬误大类 | 具体谬误名称 | 逻辑变形结构 / 核心诡计 | 一句话精准破拆与反制话术 |
| :--- | :--- | :--- | :--- |
| **一、相关谬误** (前提与结论在心理上相关、逻辑上无关) | **1. 诉诸人身 (`Ad Hominem`)** (虐待型/处境型/你也一样 `Tu Quoque`) | 攻击提出者的品格、动机、身份或“你自己也没做到”，以此否定其论证本身 | “发言者的个人品行/处境与其论证的逻辑有效性和证据真伪完全独立，请直接回应证据本身。” |
| **一、相关谬误** | **2. 稻草人谬误 (`Straw Man`)** | 将对方温和、带限定的主张扭曲夸大为极端荒谬的靶子加以痛批 | “你反驳的是被你夸大变形后的极端观点，我原本的主张带有明确限定条件 `X`。” |
| **一、相关谬误** | **3. 诉诸无知 (`Appeal to Ignorance`)** | “因为尚未证明 `P` 为假，所以 `P` 必为真”(或反之) | “缺乏反面证据不等于拥有正面证据；根据谁主张谁举证原则(`Onus Probandi`)，举证责任在你。” |
| **一、相关谬误** | **4. 诉诸不当权威 (`Ad Verecundiam`)** | 引用非本专业领域名人、存在利益冲突的专家或模糊“有关专家”背书 | “该人士并非本领域同行评议权威，且存在利益关联，请出示原始实证数据。” |
| **一、相关谬误** | **5. 诉诸众人/怜悯/恐惧 (`Ad Populum / Misericordiam / Baculum`)** | 用多数人相信、煽情卖惨或威胁恐吓替代逻辑理由 | “流行度、同情心或利害威胁属于动机根(`ratio agendi`)，不能充当命题为真的认识根据(`ratio cognoscendi`)。” |
| **一、相关谬误** | **6. 转移论题 / 红鲱鱼 (`Red Herring`)** | 在己方理亏时抛出一个极具情绪煽动性的次要话题引开注意力 | “这个次要话题我们稍后单聊，现在请回到最初的核心论题 `T` 上。” |
| **二、预设谬误** (前提暗藏未证结论或不当预设) | **7. 乞题 / 循环论证 (`Begging the Question / Petitio Principii`)** | 用同义改写的结论充当前提，或 `A → B → A` 兜圈子 | “你的前提要想成立，必须先预设结论已经为真；请提供独立于结论之外的外部证据。” |
| **二、预设谬误** | **8. 复杂问语 (`Complex Question`)** | 在一个问题中捆绑未经证实的恶意预设(如“你为什么总是抄袭？”) | **拆分先行法**：“你的问题预设了 `P`，但 `P` 完全不符合事实，因此该问题不成立。” |
| **二、预设谬误** | **9. 虚假二难 / 非黑即白 (`False Dilemma`)** | 将具有中间光谱或可兼容的反对选项伪装成唯一穷尽的矛盾选项 | “这两个极端选项并非矛盾关系，至少还存在第三种可行方案 `C` 以及兼顾方案 `D`。” |
| **二、预设谬误** | **10. 合成与分割 (`Composition & Division`)** | 把局部个体的属性强加给系统整体(合成)，或把整体属性强加给每个个体(分割) | “个体最优不等于系统整体最优(反之亦然)，零部件轻不等于整架飞机轻。” |
| **三、歧义谬误** (语词或语法双关滑移) | **11. 偷换概念 (`Equivocation`)** | 同一语词在上下文中悄然切换内涵或外延 | “你在前提中用的‘X’是指定义1，在结论中却滑向了定义2，犯了四词项谬误。” |
| **三、歧义谬误** | **12. 断章取义 / 重音 (`Accent / Quoting out of Context`)** | 剥离原文前置限定条件或改变重音扭曲原意 | “请还原原文完整的上下文限定语，脱离语境的半句话不能代表原命题。” |
| **四、弱归纳谬误** (经验或因果推断越界) | **13. 轻率概括 / 以偏概全 (`Hasty Generalization`)** | 凭极小样本、个案故事或无代表性样本直接断言全称规律 | “个案轶事不具备统计显著性，样本量 `n` 过小且存在抽样偏差。” |
| **四、弱归纳谬误** | **14. 事后归因 (`Post Hoc Ergo Propter Hoc`)** | “`A` 发生在 `B` 之前，所以 `A` 是 `B` 的原因” | “时间先后只是因果关系的必要条件而非充分条件，公鸡打鸣不是太阳升起的原因。” |
| **四、弱归纳谬误** | **15. 相关当因果 / 共同原因忽视 (`Cum Hoc`)** | 看到 `A` 与 `B` 统计正相关就断定 `A` 导致 `B` | “相关不等于因果：既可能是因果倒置(`B → A`)，也可能是共同第三因(`Z → A, B`)。” |
| **四、弱归纳谬误** | **16. 滑坡谬误 (`Slippery Slope`)** | 无证据断言迈出第一步 `A` 必然引发一连串失控连锁反应直达灾难 `Z` | “从 `A` 到 `Z` 之间包含多个低概率条件跳跃，且中间存在明确的制度/技术熔断机制。” |
| **四、弱归纳谬误** | **17. 赌徒谬误 (`Gambler's Fallacy`)** | 误以为独立随机事件具有自我纠偏记忆(“连开10次红，下次必开黑”) | “独立重复试验无记忆性，每一次的概率分布完全独立于历史结果。” |
| **四、弱归纳谬误** | **18. 幸存者偏差 (`Survivorship Bias`)** | 只统计留存下来的成功样本，忽略沉默的失败分母 | “你只看到了活下来的分子 `a`，必须补齐已淘汰样本构成的完整 `2×2` 四格表(`a,b,c,d`)。” |

### 2. 批判性思维五大核心算子操作手册 (周建武《逻辑学导论》)

| 批判性算子 | 攻击/加强的图尔敏靶点 | 标准操作动作 (强度由高到低排序) |
| :--- | :--- | :--- |
| **1. 削弱 (Weaken)** | 拆毁保证 `W` > 给出反驳例外 `R` > 否定数据 `D` | **最强削弱**：①证明**因果倒置**(`C → D`)或**另有他因**(`Z → C`)；②**拆桥**(证伪连接 `D` 与 `C` 的隐含假设 `W`)；③给出 `D` 成立但 `C` 不成立的直接反例(`D ∧ ¬C`) |
| **2. 加强 (Strengthen)** | 补齐保证 `W` + 提供支撑 `B` + 排除他因 `¬Z` | **最强加强**：①**搭桥**(显式建立 `D → C` 的必然联系)；②**排除他因**(用求异法证明“无 `D` 则必无 `C`”)；③补充独立收敛证据 |
| **3. 寻找隐含假设 (Assumption)** | 挖掘联结结构中缺失的必要前提 `W` | **否定代入检验法 (Negation Test)**：将候选假设 `W` 取否定(`¬W`)代入原论证，若原论证瞬间崩塌无法推出 `C`，则 `W` 必为原论证不可或缺的隐含假设！ |
| **4. 解释表面矛盾 (Explain)** | 调和两个看似冲突的经验事实 `F1` 与 `F2` | 必须同时承认 `F1` 与 `F2` 皆为真，寻找一个**差异化第三变量 `V`**(如基数变化、结构比例变化、统计口径差异)使 `F1 ∧ F2` 自然共存 |
| **5. 评价论证 (Evaluate)** | 识别决定论证成败的**关键决定性问题** | 正确的评价问题必须满足**“双刃剑测试 (Yes/No Bifurcation Test)”**：回答“是”则有力加强原论证，回答“否”则有力削弱原论证 |

## A1 - Past Application (书中经典案例闭环还原)

- **案例 1：利用“2×2 四格对照表”破除单样本因果幻觉 (周建武《逻辑学导论》因果论证评估)**
  - **问题 (Problem)**：某养生保健品广告宣称：“本市百岁老人调查显示，`85%` 的百岁老人每天都喝本店的富氢水 (`D`)，可见喝富氢水是长寿的秘诀 (`C`)！”如何从逻辑上彻底击穿该论证？
  - **方法 (Method)**：调用批判性思维**完整四格表 (`2×2 Contingency Table`) 缺失基数审计**与**因果倒置/第三因削弱算子**。
  - **结论 (Conclusion)**：
    1. **分母与对照组缺失**：广告只给出了“长寿且喝水 (`a = 85%`)”这一格，完全隐瞒了“未活到百岁但也每天喝该水 (`c`)”的人数比例！如果全市所有老人无论长寿与否都有 `85%` 喝该水(比如当地自来水厂冠名)，则相关度为 `0`。
    2. **共同第三因 (`Z`)**：能常年购买昂贵保健水的老人往往经济条件优渥、医疗保障完善(`Z`)，真正驱动长寿的是高收入医疗条件 `Z`，而非富氢水。
  - **结果 (Outcome)**：建立“凡见单一百分比归因，必画四格表追问对照组基数与混淆变量”的条件反射。

- **案例 2：“论证有效性分析”标准拆解：从商业报告中揪出连环谬误 (周建武《逻辑学导论》)**
  - **问题 (Problem)**：某企业战略报告写道：“去年我司在南方市场削减了20%广告费，但南方销量反而增长了10%，可见广告对销量毫无作用，今年应在全国全面停投广告。”
  - **方法 (Method)**：调用图尔敏模型与谬误排雷表逐层解剖。
  - **结论 (Conclusion)**：①**混淆相关与因果/忽视他因**：“削减广告后销量增长”可能是因为去年南方经济复苏、竞争对手暴雷或降价促销，若不削减广告销量可能增长30%(违反反事实比较基准)；②**以偏概全/轻率概括**：南方局部市场的短期表现不能简单外推至全国所有区域市场；③**滑坡/极化谬误**：“削减20%未跌”绝不能线性外推为“削减100%(全面停投)也不会跌”。
  - **结果 (Outcome)**：生成结构严谨、直击要害的商业论证有效性批判报告。

## E - Execution (分步可执行指令与完成标准)

### Step 1: 论证骨架剥离与图尔敏六要素映射 (Argument Reconstruction)

1. 圈出文本中的**前提指示词**(因为、鉴于、由于、数据显示)与**结论指示词**(因此、可见、说明、应当)，剥离纯修辞背景与情绪宣泄句。
2. 将核心论证填入图尔敏六要素槽位：
   - `[D 数据/事实]` -> `[W 隐含保证(用否定测试揪出)]` + `[B 支撑]` -> `[Q 模态限定]` + `[C 核心主张]` (附 `[R 反驳例外条件]`)。
3. 判定论证的宏观拓扑结构属于**序列链式**、**收敛独立式**还是**联结结合式**。

### Step 2: 三层批判性审计扫描 (Three-Tier Critical Audit)

按 **ARG 标准 (Acceptability 可接受性 / Relevance 相关性 / Groundedness 充足性)** 逐层扫描：

1. **概念与预设层 (`A`)**：核心概念定义是否过宽/过窄/偷换？前提是否包含虚假预设或复杂问语？数据是否真实无幸存者偏差？
2. **相关性与保证层 (`R`)**：数据 `D` 与主张 `C` 之间是否存在隐含跳跃？是否犯了诉诸人身/权威/无知/众人或稻草人谬误？
3. **充分性与反例层 (`G`)**：样本是否以偏概全？因果归因是否忽略了**因果倒置、共同第三因、时间滞后或反事实基准**？是否存在未声明的例外边界 `R`？

### Step 3: 生成结构化批判或强化方案 (Critique or Fortification Output)

- **若为破论 (攻击/审查模式)**：按【原论证桥接链条 -> 谬误定性名称 -> 致命反例/他因拆解 -> 反制话术】四段式输出。
- **若为立论 (构建/润色模式)**：主动为用户的论点补齐【硬核数据 `D` + 显式保证 `W` + 权威支撑 `B` + 严谨限定词 `Q` + 预先回应反方最强质疑的让步反驳段 `R`】。

## B - Boundary (适用边界、反例失败模式与盲点)

1. **反例失败模式 1：谬误谬误 (The Fallacy Fallacy / Argument from Fallacy)**
   - 陈波与周建武均明确警告：**证明一个人的论证过程犯了逻辑谬误(或推理无效)，绝不等于证明他的结论本身在事实上是假的！**(例如某人用拙劣的阴谋论论证“吸烟有害健康”，其论证虽充满谬误，但结论“吸烟有害健康”依然为真)。反驳时应明确说“你的理由推不出该结论”，切勿直接断言“所以你的结论一定为假”。
2. **反例失败模式 2：违反善意原则 (Principle of Charity) 的吹毛求疵**
   - 在重构他人自然语言论证时，应遵循**善意原则**：在不违背原文明确词义的前提下，尽量将对方的省略论证补充为最合理、最强的版本再加以评估，避免自己先把对方的话曲解成稻草人再批判。
