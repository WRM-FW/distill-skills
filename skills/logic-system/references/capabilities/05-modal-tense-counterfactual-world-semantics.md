## R - Reading (原文锚点与核心机制)

1. **实质蕴涵怪论与可能世界关系语义学 (Priest《Non-Classical Logic》第1-3章)**：
   - 经典实质蕴涵 `A ⊃ B` 仅取决于当前世界的真值，导致两大怪论：`¬A ⊨ A ⊃ B` (只要前件假，任何条件句皆真) 与 `B ⊨ A ⊃ B` (只要后件真，任何条件句皆真)。
   - **克里普克可能世界框架 (Kripke Frame `⟨W, R, v⟩`)**：引入非空可能世界集合 `W`、世界间的二元可达关系 `R ⊆ W × W` 与赋值函数 `v`：
     - **必然性 (`□A`) 在世界 `w` 为真**：当且仅当对于所有满足 `w R w'` 的可达可能世界 `w'`，`A` 在 `w'` 皆为真。
     - **可能性 (`⋄A`) 在世界 `w` 为真**：当且仅当存在至少一个满足 `w R w'` 的可达可能世界 `w'`，使得 `A` 在 `w'` 为真(`⋄A ≡ ¬□¬A`)。
2. **正规模态系统谱系 (`K, D, T, B, S4, S5`) 与时态逻辑 `Kt` (Priest 第3章)**：
   - 最基础正规模态逻辑 `K` 不对可达关系 `R` 施加任何限制，满足分配公理 `□(A ⊃ B) ⊃ (□A ⊃ □B)` 与必然化规则 (`⊢ A ⇒ ⊢ □A`)。通过对 `R` 施加自反、持续、对称、传递、欧几里得条件，精准刻画**物理必然性、认识论必然性(`知道`)、道义规范必然性(`应当/允许`)与形而上学必然性(`S5`)**。
   - **普赖尔时态逻辑 (`Kt`, Priest 第3.6a-b节)**：将可能世界 `W` 解释为时间点，可达关系 `R` 解释为时间先后 `<`，引入四个时态算子：`FA` (未来某时真)、`PA` (过去某时真)、`GA` (`≡ ¬F¬A`, 未来恒真)、`HA` (`≡ ¬P¬A`, 过去恒真)，拆解亚里士多德“明日海战”宿命论谬误。
3. **反事实条件句逻辑与刘易斯相似球语义学 (`C, C+, C1, C2`, Priest 第5, 19章)**：
   - 自然语言中的反事实条件句 `A > B`(“假若当初 `A`，就会 `B`”)在经典实质蕴涵 `⊃` 和严格蕴涵 `□(A ⊃ B)` 下都会失效 - 因为经典的**前件加强律 (Antecedent Strengthening: `A → B ⊢ (A ∧ C) → B`)**、**假言三段论传递律 (`A → B, B → C ⊢ A → C`)** 与**换质位律 (`A → B ⊢ ¬B → ¬A`)** 在含背景默认条件 (`ceteris paribus`) 的反事实推理中**全部不成立**！
   - **选择函数与相似球语义学 (Stalnaker / David Lewis `C1, C2`)**：每个世界 `w` 周围围绕着一族按相似度嵌套的同心球 `S_w`。评估 `A > B` 在现实世界 `w` 是否为真，不看所有可能世界，也不只看现实世界，而是**在与现实世界 `w` 最相似且使前件 `A` 为真的那一层最近可能世界集合 `f(w, [A])` 中，检验后件 `B` 是否全部为真**！
4. **量化模态逻辑：从言 (`de dicto`) vs 从事 (`de re`) 与严格指示词 (Priest 第14-17章)**：
   - 区分 `□∃x Fx` (从言模态：在每个可能世界里都有某个个体是 `F`，不同世界可以是不同的人) 与 `∃x□Fx` (从事模态：现实中存在某一个特定个体 `x`，他在所有可能世界里都是 `F`)。
   - 区分克里普克**严格指示词 (Rigid Designator, 如专名“水”、“启明星”：在所有可能世界指称同一对象，满足必然同一性 `a = b ⊢ □(a = b)`)** 与**非严格指示词 (Non-rigid Designator, 如摹状词“行星数目的数字 ‘8’”：随可能世界变化而改变指称，不满足必然替换)**。

### 1. 正规模态逻辑系统公理、可达关系性质与应用场景映射表 (Priest 第3章)

| 系统名称 | 新增特征公理图式 | 可达关系 `R` 的数学约束条件 | 语义分析树 (Tableau) 规则 | 典型应用领域与算子解读 |
| :--- | :--- | :--- | :--- | :--- |
| **`K`** | `□(A ⊃ B) ⊃ (□A ⊃ □B)` | 无任何约束 (任意有向图) | `□A, i` 且 `i r j` ⇒ `A, j`；`⋄A, i` ⇒ 新建 `i r j` 且 `A, j` | 基础模态框架 |
| **`D`** (道义逻辑) | **`□A ⊃ ⋄A`** (应当蕴涵允许/无规范冲突) | **持续性 / 串行性 (Serial: `∀w∃u(wRu)`)** | 对每个出现的世界 `i`，至少存在一个可达世界 `i r j` | **法律与伦理规范 (`□ = 应当 Obligatory`, `⋄ = 允许 Permitted`)** (注：道义逻辑绝不满足 `□A ⊃ A`，因为人会违法！) |
| **`T`** (`M`) | **`□A ⊃ A`** (或 `A ⊃ ⋄A`) | **自反性 (Reflexive: `∀w(wRw)`)** | 自动添加 `i r i` (故 `□A, i` 直接得 `A, i`) | 客观必然性与知识逻辑 (`若必然真/真知道，则在现实世界必真`) |
| **`B`** | `A ⊃ □⋄A` (或 `⋄□A ⊃ A`) | 自反 + **对称性 (Symmetric: `wRu ⇒ uRw`)** | `i r j` 自动补 `j r i` | 布劳威尔模态系统 |
| **`S4`** | **`□A ⊃ □□A`** (正内省公理) | 自反 + **传递性 (Transitive: `wRu ∧ uRv ⇒ wRv`)** | `i r j` 且 `j r k` 自动补 `i r k` | 认识论可证性/正内省 (`知道 A 则知道自己知道 A`) |
| **`S5`** | **`⋄A ⊃ □⋄A`** (负内省公理) | **等价关系 (自反+对称+传递 / 或完全互通 यूनिवर्सल)** | 无需画可达箭头 `r`：所有世界两两互通 (`□A, i` 得任意 `j` 上的 `A, j`) | **形而上学绝对必然性 / 完全信息知识逻辑** |

### 2. 反事实条件句 `A > B` 禁用经典推演规则警示表 (Priest 第5章)

在评估“如果当初 `A`，就会 `B`”或带默认前提的日常条件句时，**严禁机械套用以下三条在经典实质蕴涵中有效的规则**：

| 经典逻辑规则 | 经典公式 (`⊃`) | 在反事实逻辑 (`>`) 中是否有效 | 书中经典反例说明 (Priest 第5.2节) | 失效的相似球语义学机制 |
| :--- | :--- | :---: | :--- | :--- |
| **前件加强律 (Antecedent Strengthening)** | `A ⊃ B ⊨ (A ∧ C) ⊃ B` | **无效 (`⊭`)** | “如果你划这根火柴(`A`)，它会燃(`B`)”为真；但不能推出“如果你划这根火柴(`A`)且它湿透了(`C`)，它会燃(`B`)” | 最接近现实的 `A` 世界球层 `f(w,[A])` 中火柴是干的；但 `A ∧ C` 迫使我们跳到更远的球层 `f(w,[A∧C])`，在那里 `B` 为假！ |
| **传递律 / 假言三段论 (Transitivity)** | `A ⊃ B, B ⊃ C ⊨ A ⊃ C` | **无效 (`⊭`)** | “如果胡佛生在苏联(`A`)，他会是共产党员(`B`)”真；“如果胡佛是共产党员(`B`)，他会是卖国贼(`C`)”真；但不能推出“如果胡佛生在苏联(`A`)，他会是卖国贼(`C`)” | 最接近现实的 `A` 世界(生在苏联)远比最接近现实的 `B` 世界(生在美国却入共党)离现实更远，球层发生错位！ |
| **换质位律 (Contraposition)** | `A ⊃ B ⊨ ¬B ⊃ ¬A` | **无效 (`⊭`)** | “如果雨下但没下大(`A`)，地面会湿(`B`)”真；不能推出“如果地面没湿(`¬B`)，那么或者没下雨或者下了大雨(`¬A`)” | 地面没湿的最近可能世界是“根本没下雨”，而非“下了瓢泼大雨” |

### 3. 从言模态 (`de dicto`) vs 从事模态 (`de re`) 范围歧义拆解表

| 歧义句式实例 | 从言解读 (`de dicto`：模态词在外层，管辖整个命题) | 从事解读 (`de re`：模态词在内层，修饰特定个体的本质属性) | 经典谬误诊断 (模态范围谬误 Modal Scope Fallacy) |
| :--- | :--- | :--- | :--- |
| “单身汉必然未婚” | **`□∀x(Bx → ¬Mx)`** (真：按概念定义，在任何可能世界里，凡被称为单身汉的个体在该世界未婚) | `∀x(Bx → □¬Mx)` (假：现实中某个单身汉张三，在其他可能世界里完全可能结婚！) | 宿命论诡辩常把真的 `□(A → B)` 或 `□(A ∨ ¬A)` 偷换为假的 `A → □B` 或 `□A ∨ □¬A` |
| “在场必有一人是冠军” | **`□∃x Cx`** (真：比赛规则决定每个可能世界都会产生一名冠军) | `∃x□Cx` (假：并不存在某一个天选之子在所有可能世界里都包揽冠军) | 混淆“规则必然产生某角色”与“某具体个体必然垄断该角色” |
| “行星的数目必然大于7” (Priest 第16章) | 若将“行星的数目”作非严格摹状词：`□∃x(Px ∧ x > 7)` (假：太阳系完全可能只有6颗行星) | 若先在现实世界锁定指称 `x = 8`：`∃x(Px ∧ □(x > 7))` (真：数字 `8` 在所有可能世界都大于 `7`) | 奎因“8 > 7 必然，行星数=8，故行星数必然>7”悖论：源于将非严格摹状词混同于严格指示词 |

## A1 - Past Application (书中经典案例闭环还原)

- **案例 1：亚里士多德“明日海战”与宿命论诡辩破拆 (Priest《Logic: VSI》第7章；《Non-Classical Logic》第3.6a节)**
  - **问题 (Problem)**：宿命论者论证：“(1) 明天要么发生海战，要么不发生海战，这是必然的 (`□(S ∨ ¬S)`)；(2) 如果明天发生海战，那么它必然发生；如果明天不发生海战，那么它必然不发生；(3) 所以明天是否发生海战早在今天就已经命中注定 (`□S ∨ □¬S`)，人的自由选择毫无意义。”这一推理错在哪里？
  - **方法 (Method)**：调用模态逻辑 `K/T` 的语义分析树(Tableau)与**模态范围歧义 (Modal Scope Fallacy)** 检验。
  - **结论 (Conclusion)**：
    - 宿命论者在前提(1)中说的是 `□(S ∨ ¬S)`(从言必然性：在每个未来可能分支世界里，排中律 `S ∨ ¬S` 都成立)；但在前提(2)中，他把 `□(S → S)`(必然地：若发生则发生)非法偷换成了 `S → □S`(从事/后件必然：一旦实际上发生，它在所有可能世界里都必然发生)！
    - 在模态逻辑中，**`□(A ∨ B) ⊭ □A ∨ □B`**(必然析取绝不蕴涵析取必然)，且 **`□(A → B) ⊭ A → □B`**。构造两个可达世界 `w1 (S=1)` 与 `w2 (S=0)`，立即验证 `□(S ∨ ¬S)` 为真而 `□S ∨ □¬S` 为假。
  - **结果 (Outcome)**：不牺牲二值排中律即可彻底粉碎宿命论(“事后必真”绝不等于“事前必然”)。

- **案例 2：克里普克“启明星就是长庚星 (`a = b`)”为何既是必然真理又是后验经验发现 (Priest《Non-Classical Logic》第16.4节)**
  - **问题 (Problem)**：古人最初不知道清晨的“启明星 (`Hesperus, a`)”与傍晚的“长庚星 (`Phosphorus, b`)”都是金星，后来通过天文观测才发现 `a = b`。既然这是经验后验才发现的，为什么克里普克与模态逻辑却证明 `a = b ⊨ □(a = b)`(它是必然真理)？
  - **方法 (Method)**：调用第16章**严格指示词 (Rigid Designator)** 与可能世界同一性语义学。
  - **结论 (Conclusion)**：专名“启明星”与“长庚星”都是**严格指示词**，它们在所有可能世界中都固定指称金星这颗天体(`v(a) = v(b) = 金星`)；而在任何可能世界中，金星都必然等于它自己(`□(x = x)`)，由莱布尼茨不可分辨者同一律得 `□(a = b)`。之所以需要经验发现，是因为我们最初是通过两个**非严格摹状词**(“清晨升起的亮星” vs “傍晚出现的亮星”)去定位它们的。
  - **结果 (Outcome)**：厘清“认识论上的先验/后验 (`a priori / a posteriori`)”与“形而上学模态上的必然/偶然 (`necessary / contingent`)”两个正交维度。

## E - Execution (分步可执行指令与完成标准)

### Step 1: 模态/条件算子定性与系统选型 (Modal System Selection)

1. 识别论证中的核心算子属于哪一类模态系统(对照 `I.1` 表)：
   - 逻辑/形而上学必然性 -> 选 **`S5`** (所有可能世界等价互通)。
   - 物理规律/知识必然性 -> 选 **`T` 或 `S4`** (自反 `□A ⊃ A`，不可假设违背物理定律的现实状态)。
   - 法律/伦理规范(“应当/允许”) -> 选 **`D`** (严禁使用 `□A ⊃ A`，只可用 `□A ⊃ ⋄A` 即“应当做的事必然是被允许的”)。
   - 反事实假设(“假若 `A` 则会 `B`”) -> 选 **刘易斯条件句逻辑 `C1/C2`** (`A > B`)。

### Step 2: 模态范围 (`de dicto` vs `de re`) 消歧与符号化

1. 凡遇到“如果 `A`，那么必然 `B`”或“某物必然是 `F`”，强制写出两种辖域公式：
   - **从言宽辖域 (`de dicto`)**：`□(A → B)` 或 `□∃x Fx`。
   - **从事窄辖域 (`de re`)**：`A → □B` 或 `∃x□Fx`。
2. 核查推理是否把真的 `□(A → B)` 非法当作 `A → □B` 与 `A` 进行 `MP` 推演从而得出伪必然结论 `□B`。

### Step 3: 可能世界语义分析树 (World Tableau) 或相似球检验

1. **可能世界 Tableau 检验 (Priest 第2-3章)**：
   - 根结点写 `前提, 0` 与 `¬结论, 0` (世界 `0` 为现实世界)。
   - 遇到 `⋄A, i` 或 `¬□A, i`：必须引入一个**全新的可能世界 `j`**，记下可达边 `i r j` 及 `A, j`(或 `¬A, j`)。
   - 遇到 `□A, i` 或 `¬⋄A, i`：对所有已存在的满足 `i r j` 的世界 `j`，派生 `A, j`(或 `¬A, j`)。
   - 根据所选系统(`T/D/B/S4/S5`)补齐可达边 `r`；若所有分支皆在同一世界内闭合(`P, i` 与 `¬P, i`)则有效，否则从未闭合分支读出可能世界反例模型。
2. **反事实相似球检验 (`A > B`)**：
   - 固定现实世界 `w0` 的全部背景事实，只做**最小程度的外科手术修改(Minimal Mutilation)**使前件 `A` 变为真，构成最近可能世界层 `S_1 = f(w0, [A])`；检查在 `S_1` 中 `B` 是否必然成立，并排查是否误用了前件加强、传递律或换质位律。

## B - Boundary (适用边界、反例失败模式与盲点)

1. **反例失败模式 1：逻辑全知问题 (Logical Omniscience Problem, Priest 第4章)**
   - 在所有正规模态逻辑(`K` 及以上)中，由于存在必然化规则(`⊢ A ⇒ ⊢ □A`)与分配律，任何逻辑重言式在所有可能世界皆为真。若将 `□` 解释为真实人类的“知道 (`Knows`)”或“相信 (`Believes`)”，会导出“只要一个人知道公理，他就自动知道所有数学定理”的荒谬结论。处理有限理性主体的信念时，必须启用 Priest 第4章的**非正规可能世界 (Non-normal Worlds `W - N` / 不可能世界 Impossible Worlds)**。
2. **反例失败模式 2：在道义逻辑 (`D`) 中误用自反公理 `□A ⊃ A`**
   - 在法律与伦理推理中，“人人应当遵守交通规则 (`□A`)”为真，绝不蕴涵“人人都实际上遵守了交通规则 (`A`)”。将 `T` 系统公理误用于规范命题会抹杀“应然 (`Ought`)”与“实然 (`Is`)”的界限。
