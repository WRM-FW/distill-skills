   - **惠施“历物十事”与“合同异” (第一编第2章)**：“至大无外谓之大一，至小无内谓之小一”、“天与地卑，山与泽平”、“日方中方睨，物方生方死”、“大同而与小同异，此之谓小同异；万物毕同毕异，此之谓大同异”、“卵有毛”、“飞鸟之景未尝动也”。本质是夸大概念的相对性与连续性，抹杀事物定性差别的界限。

   - **公孙龙“白马非马”与“离坚白” (第一编第4章；《公孙龙子》)**：
     - **《白马论》**：“马者，所以命形也；白者，所以命色也；命色者非命形也，故曰白马非马。”其诡辩核心在于**割裂词项的内涵与外延**，将“白马不等于马(内涵不等同 `White Horse ≠ Horse`)”偷换为“白马不属于马类(外延不蕴涵 `¬∀x(Wx ∧ Hx → Hx)`)”，混淆了汉语系词“是/非”的**等同义 (`=`)** 与**类属包含义 (`⊆`)**！

| **1. 或 (Huo)** | “或也者，不尽也。” | **相容选言推理 (`p ∨ q`)** | 选言肢未穷尽全部外延，肯定一肢绝不能否定另一肢 |
| **2. 假 (Jia)** | “假也者，今不然也。” | **假言/反事实推理 (`p → q`)** | 对当前尚未发生或反事实情况设定条件关系，分清小故(必要)与大故(充要) |

| **4. 辟 (Pi)** | “辟也者，举他物而以明之也。” | **比喻与说明性类比** | 借对方熟悉的具体事物阐明抽象道理，但须严守“异类不比”，不可越界当严格证明 |
| **5. 侔 (Mou)** | “侔也者，比辞而俱行也。” | **主谓项同加修饰词的附性推理 (`S 是 P ⊢ MS 是 MP`)** | **极高危区**：必须通过下方“侔式四界”核验深层语义关系，严禁看字面句式相同就盲目顺推！ |
| **6. 援 (Yuan)** | “援也者，曰‘子然，我奚独不可以然也？’” | **援引对方先例的同行类推 / 反唇相讥** | 当对方承认命题 `A` 时，援引与 `A` 同类的己方命题 `B` 反问对方，迫使其保持逻辑一致 |
| **7. 推 (Tui)** | “推也者，以其所不取之同于其所取者，予之也。” | **归谬式类推 (`Reductio by Analogy`)** | 指出对方所拒绝的命题与其所接受的命题在逻辑结构与类属上完全相同，从而驳倒对方的双标 |

### 2. 荀子《正名》“三惑”诡辩破拆诊断矩阵 (孙中原第二编第2章)

荀子将先秦一切名家与纵横家诡辩精准归结为三类“乱名/乱实”机制，并给出对应的一句话裁决准则：

| 荀子三惑分类 | 原典定义与成因机制 | 书中典型诡辩病案 | 荀子“正名”裁决处方 |
| :--- | :--- | :--- | :--- |
| **第一惑：惑于用名以乱名** (用概念搞乱概念) | 不懂“共名(属)”与“别名(种)”的层级包含，拿词语字面差异否定上下位类属 | **“杀盗非杀人也”**、**“白马非马”**、**“见侮不辱”**(宋钘改定义把被人欺侮定义为不耻辱) | **“验之所以为有名”**：核查设立名称的初衷与共名-别名层级树，“人”是共名，“盗”是人中之别名，盗必含于人 |
| **第二惑：惑于用实以乱名** (用个别事实搞乱普遍概念) | 抓住具体事物在极端、局部或相对视角下的个别感官现象，去否定约定俗成的普遍概念分类 | **“山渊平”**(高山深渊在宇宙尺度下差不多高)、**“情欲寡”**、**“刍豢不加甘，大钟不加乐”** | **“验之所缘以同异”**：回到人类共同感官器官(`天官`)在正常标准尺度下的常规分辨基准，不拿极端尺度偷换日常尺度 |
| **第三惑：惑于用名以乱实** (用语词组合的歧义歪曲客观事实) | 利用复合词组或量词的语法歧义，凭空捏造违背物理事实的荒诞结论 | **“有牛马非马”**(复合名“牛马”既非纯牛亦非纯马，遂诡称其中的马不是马)、**“飞鸟之景未尝动”** | **“稽实定数”**：直接用客观经验事实(`实`)与数量核查(`数`)戳穿文字游戏，“名定而实辨” |

## A1 - Past Application (书中经典案例闭环还原)

- **案例 1：公孙龙“白马非马”与墨家、荀子正名联合破拆 (孙中原第一编第4章、第二编第1-2章)**
  - **问题 (Problem)**：公孙龙过关，关吏曰：“马不准过。”公孙龙骑白马过，诡辩曰：“白马非马！因为求马，黄、黑马皆可致；求白马，黄、黑马不可致。故白马非马。”关吏明知被骗却无言以对。如何用名辩逻辑当场破拆？
  - **方法 (Method)**：调用荀子《正名》**共名-别名层级律**与《墨经》**以名举实/类包含律**。
  - **结论 (Conclusion)**：
    1. 按荀子《正名》：“马”是**共名**(上位属概念，外延为 `{白马, 黄马, 黑马...}` 的并集)，“白马”是**别名**(下位种概念，外延为共名之真子集)。
    2. 公孙龙在“求马黄黑马皆可致，求白马黄黑马不可致”中证明的只是**“白马的外延真包含于马的外延 (`白马 ⊂ 马`，故 `白马 ≠ 马`)”**；但他却利用古汉语“非”既可表“不等于 (`≠`)”又可表“不属于 (`⊄`)”的歧义，把“白马不等于马整体”偷换成了“白马不属于马类”，犯了荀子第一惑“惑于用名以乱名”。
  - **结果 (Outcome)**：关吏只需回答：“关令禁的是‘共名之马(`∀x(Mx → ¬Pass(x))`)’，你的白马虽是‘别名’，其实体仍属‘马类(`Wx → Mx`)’，故依墨家‘效’法，必在禁行之列！”

- **案例 2：《吕氏春秋·察传》“丁氏穿井得一人”与王充《论衡》效验核查 (孙中原第二编第4、7章)**
  - **问题 (Problem)**：宋国丁氏家里没井，常派一人在外打水；后来家里打了井，丁氏感慨说：“吾穿井得一人(我打井省下了一个人工劳动力)！”传话者听后四处宣扬：“丁氏挖井从土里挖出了一个活人！”轰动全国。如何防范此类谣言与逻辑失真？
  - **方法 (Method)**：调用《吕氏春秋·察传》**“辞多类非而是，多类是而非；闻言必熟论，必验之以理”**与韩非**参验法**。
  - **结论 (Conclusion)**：丁氏原话中的“得一人”是省略了动作谓词的语用缩略(“多获得一个人的可用工时”)，传话者犯了**语词歧义与字面机械坐实谬误**。按吕不韦与王充“效验/定于有证”原则：凡听闻反常传言，第一步先做**常理可行性核查(`验之以理`：地下无空气水源，不可能埋着活人)**，第二步做**源头交叉参验(`询诸丁氏`)**，谣言不攻自破。
  - **结果 (Outcome)**：为舆情核查、情报审计与历史考据提供中国本土“名实参验”标准工作流。

## E - Execution (分步可执行指令与完成标准)

### Step 1: 墨辩“故、理、类”三物立论/审论核查 (Mohist Three-Element Audit)

对任何立论或辩词，按《墨经·大取》“三物必具”逐一拷问：

1. **查“故” (根据)**：该主张的立论依据是什么？它是**“小故” (必要条件：无之必不然，但有之不必然)** 还是**“大故” (充要条件：有之必然)**？严禁拿一个“小故”单条件直接断言结果必然发生！
2. **查“理” (规律)**：从“故”到“辞”的推演是否遵循客观常理(`中效`)？
3. **查“类” (范畴)**：类比或归谬外推时，两个对象是否属于**同一本质类属 (`以类行`)**？若拿不同质的对象强行类比(如“义可以利人，难道拿义当饭吃吗”)，立即判定为《墨经》所说的**“狂举 / 异类不比”**！

### Step 2: 荀子“三惑”与墨家“侔式四界”破诡辩协议

当对方玩弄文字诡辩或平行句式类推(`你既然承认 A，就必须承认 B`)时：

1. **先用荀子“三惑”定性**：
   - 是用别名否定共名 (`用名乱名`)？-> 画出共名-别名包含树。
   - 是用极端微观/宏观现象否定日常尺度概念 (`用实乱名`)？-> 锁定常规检验尺度。
   - 是利用复合词/缩略语歧义歪曲事实 (`用名乱实`)？-> 执行“稽实定数”还原事实。
2. **再用墨家“侔式四界”拆解平行类推**：
   - 检查两句话中的核心动词或量词是否属于**“是而不然”**或**“一周而一不周”**(如前一句隐含全称 `∀x`，后一句隐含特称 `∃x`)，当场指出其深层量词结构并不对称，阻断对方的恶意“推/援”。

### Step 3: 韩非“矛盾之说”与“参验法”闭环实证

1. **以子之矛攻子之盾**：将对方在不同场合或同一文本中的两条极端承诺放在同一假想交互场景中碰撞(如“当你的全能之矛刺向你的全能之盾时”)，逼出其不可同真的逻辑破产点。
2. **参验落地**：“听其言必责其用，观其行必求其功” - 将口头承诺转化为可观测、可计量的客观“效验”指标进行事后核验。

## B - Boundary (适用边界、反例失败模式与盲点)

1. **反例失败模式 1：将惠施、公孙龙、庄子的全部命题简单斥为“纯胡搅蛮缠”**
   - 孙中原在《诡辩与逻辑名篇趣谈》前言与各章评析中指出，名家与道家的诡辩虽然违反了常规形式逻辑，但往往触及了**概念内涵与外延的对立统一、无限可分性、感官综合以及语言表达思想的张力**。在破拆其逻辑漏洞的同时，应客观识别其启发思维辩证边界的认识论价值。
2. **反例失败模式 2：滥用“约定俗成”压制科学概念革新**
   - 荀子“约定俗成谓之宜”适用于日常语言规范与社会契约正名；但在自然科学与技术前沿中，当旧有日常概念分类(如把鲸鱼叫“鱼”)与客观生物演化事实冲突时，必须以《墨经》“以名举实”的客观实在为准进行科学重定义，不可死守旧俗。
