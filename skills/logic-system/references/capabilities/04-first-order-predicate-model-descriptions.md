## R - Reading (原文锚点与核心机制)

1. **量化逻辑 QL 的语法构件与亚里士多德四命题现代符号化 (Magnus《forall x》第4章；陈波第4章第1节)**：
   - 一阶量化逻辑 (`QL`) 引入**论域 (Universe of Discourse, `UD`)**、**个体常元 (`a, b, c...`)**、**个体变元 (`x, y, z...`)**、**`n` 元谓词 (`Fx, Rxy...`)**、**全称量词 (`∀`)**、**存在量词 (`∃`)** 与**等词 (`=`)**。
   - **直言命题符号化铁律 (Magnus 第4.5节)**：
     - 全称命题 (`All Fs are Gs / No Fs are Gs`) **必须搭配实质蕴涵 `→`**：`∀x(Fx → Gx)` 与 `∀x(Fx → ¬Gx)`。**绝不可将“所有 `F` 都是 `G`”写成 `∀x(Fx & Gx)`**(那意味着论域里万事万物既是 `F` 又是 `G`！)。
     - 特称命题 (`Some Fs are Gs / Some Fs are not Gs`) **必须搭配合取 `&`**：`∃x(Fx & Gx)` 与 `∃x(Fx & ¬Gx)`。**绝不可将“有些 `F` 是 `G`”写成 `∃x(Fx → Gx)`**(只要论域里有一个非 `F` 的物体，`∃x(Fx → Gx)` 就自动空洞为真！)。
2. **多重关系谓词、量词重叠与二元关系性质 (陈波第4章第2节；Magnus 第4.5-4.7节)**：
   - 同类量词可交换顺序 (`∀x∀y Rxy ⇔ ∀y∀x Rxy`；`∃x∃y Rxy ⇔ ∃y∃x Rxy`)；但**异类量词交换顺序会彻底改变语义**：
     - **`∃x∀y Lxy` (特指强命题)** vs **`∀y∃x Lxy` (泛指弱命题)**：由 **`∃x∀y Rxy` 可以必然推出 `∀y∃x Rxy`**，但反之 **`∀y∃x Rxy ⊭ ∃x∀y Rxy`**(如“每个人都有一位母亲 `∀y∃x Mxy`”真，不能推出“有一位共同的母亲生了所有人 `∃x∀y Mxy`” - 犯此错即**量词移位谬误 Quantifier Shift Fallacy**)。
   - **等词 (`=`) 表达精确数量与“除...之外” (Magnus 第4.7节 & Quick Reference)**：
     - 若要表达“张三认识除了他自己以外的所有人”，不能写 `∀x Kzx`(含自己)，必须加入等词排除：`∀x(x ≠ z → Kzx)`。
3. **形式模型语义学与有限模型反例构造 (Magnus 第5章；陈波第4章第3-4节)**：
   - `QL` 中的一个**模型 (Model / Interpretation)** 由三要素定义：`⟨UD, extension(P), referent(c)⟩`。要证明一个量化推理无效 (`Γ ⊭ A`)，只需构造一个仅含 `1-3` 个元素的微型有限论域 `UD = {d1, d2}`，显式指定各谓词的外延集合，使前提全真而结论为假。
4. **罗素确定摹状词理论 (Bertrand Russell's Theory of Definite Descriptions, 陈波第4章第6节；Priest《Logic: VSI》第4章)**：
   - 针对“当今法国国王是秃头 (`The present King of France is bald`)”这类含**空摹状词 (`the F / 那个唯一的F`)**的句子，罗素揭示其表层语法虽是主谓结构，深层逻辑实为三个命题的合取：**①存在性 (`∃x Fx`) + ②唯一性 (`∀y(Fy → y = x)`) + ③谓述性 (`Bx`)**，合写为：
     `∃x(Fx ∧ ∀y(Fy → y = x) ∧ Bx)`。

## I - Interpretation (方法论骨架、定量参数表与决策规则)

### 1. 量词重叠与等词数量符号化标准公式表 (Magnus 第4章 Quick Reference)

| 自然语言量化/数量表达 | 标准一阶逻辑 (`QL` + `=`) 符号化公式 | 语义精确解读与防错要点 |
| :--- | :--- | :--- |
| 所有 `F` 都是 `G` / 没有 `F` 是 `G` | `∀x(Fx → Gx)` / `∀x(Fx → ¬Gx)` | `∀` 配 `→`；当不存在 `F` 时空洞为真 |
| 有些 `F` 是 `G` / 有些 `F` 不是 `G` | `∃x(Fx ∧ Gx)` / `∃x(Fx ∧ ¬Gx)` | `∃` 配 `∧`；承诺至少存在 1 个 `F` |
| **只有 `F` 才是 `G`** (`Only Fs are Gs`) | **`∀x(Gx → Fx)`** | 等价于“所有 `G` 都是 `F`”，注意方向与“所有 `F` 是 `G`”相反 |
| **至少有 1 个 `F`** (`At least 1 F`) | `∃x Fx` | 存在量词基础含义 |
| **至少有 2 个不同的 `F`** (`At least 2 Fs`) | `∃x∃y(Fx ∧ Fy ∧ x ≠ y)` | 必须加 **`x ≠ y`**，否则不同变元 `x, y` 可指派给同一个体！ |
| **至多有 1 个 `F`** (`At most 1 F`) | `∀x∀y((Fx ∧ Fy) → x = y)` (或 `¬∃x∃y(Fx ∧ Fy ∧ x ≠ y)`) | 若任意两个个体都是 `F`，则它们必是同一个体(允许有 0 个或 1 个 `F`) |
| **恰好有 1 个 `F`** (`Exactly 1 F`) | **`∃x(Fx ∧ ∀y(Fy → x = y))`** | 即“至少有 1 个 `F`”与“至多有 1 个 `F`”的合取 |
| **那个唯一的 `F` 是 `G`** (罗素摹状词 `The F is G`) | **`∃x(Fx ∧ ∀y(Fy → y = x) ∧ Gx)`** | 隐含存在性+唯一性；若不存在 `F` 或有多个 `F`，该肯定句直接为**假 (`0`)** |

### 2. 二元关系 `Rxy` 的逻辑性质与排序有效推理核查表 (陈波第4章第2节)

在进行比较、排序、亲属、因果或等价关系推理时，必须先核定关系谓词 `R` 的两项结构属性：

| 维度 | 性质名称 | 一阶逻辑定义公式 | 典型关系实例 | 支持的直接推理 / 禁忌 |
| :--- | :--- | :--- | :--- | :--- |
| **自反维度** | **自反性 (Reflexive)** | `∀x Rxx` | 等于、与...同岁、包含于 | 由个体存在可直接得 `Raa` |
| **自反维度** | **反自反性 (Irreflexive)** | `∀x ¬Rxx` | 大于、比...高、在...之北、是...之父 | 任何 `Raa` 皆为逻辑假 |
| **对称维度** | **对称性 (Symmetric)** | `∀x∀y(Rxy → Ryx)` | 是...的同学/配偶、相邻、不等于 | 由 `Rab` 可直接换位得 `Rba` |
| **对称维度** | **反对称性 (Antisymmetric)** | `∀x∀y((Rxy ∧ Ryx) → x = y)` | 小于等于 `≤`、集合子集 `⊆` | 若 `Rab ∧ Rba` 则 `a = b` |
| **对称维度** | **非对称/强反对称 (Asymmetric)** | `∀x∀y(Rxy → ¬Ryx)` | 大于 `>`、比...年长、是...的上级 | 由 `Rab` 必推得 **`¬Rba`** (严禁逆转) |
| **传递维度** | **传递性 (Transitive)** | `∀x∀y∀z((Rxy ∧ Ryz) → Rxz)` | 大于、早于、在...以北、是...的祖先 | 支撑链式排序传递推理 `Rab, Rbc ⊢ Rac` |
| **传递维度** | **反传递性 (Intransitive)** | `∀x∀y∀z((Rxy ∧ Ryz) → ¬Rxz)` | 是...的生父、比...大两岁、垂直于(平面内) | **严禁跨代传递** (`a` 是 `b` 之父，`b` 是 `c` 之父，则 `a` 必**不是** `c` 之父) |
| **传递维度** | **非传递性 (Non-transitive)** | 既不恒传递也不恒反传递 | **认识、喜欢、朋友、半决赛击败** | **高频谬误**：误将“朋友的朋友”、“喜欢的人喜欢的人”或球队循环克制当成传递关系！ |

### 3. 自然演绎量词四规则约束红线表 (Magnus 第6.5节)

| 规则缩写与名称 | 推理图式 | **核心合法性红线 (违反即导致证明无效)** |
| :--- | :--- | :--- |
| **`∀E` (全称消去)** | `∀x Ax ⊢ Ac` | 可将受 `∀x` 约束的**全部** `x` 替换为任意常元 `c`(不能只替换一部分 `x`) |
| **`∃I` (存在引入)** | `Ac ⊢ ∃x Ax` | 可将常元 `c` 的**全部或部分**出现替换为 `x`(前提是 `x` 未被内层量词捕获) |
| **`∀I` (全称引入)** | `Ac ⊢ ∀x Ax` | **常元 `c` 必须是完全任意的代表**：① `c` 不得出现在任何未卸载的前提或子证明假设中；② `c` 不得保留在结论 `∀x Ax` 中 |
| **`∃E` (存在消去)** | `∃x Ax`, 子证明 `[Ac ... B] ⊢ B` | **实例化常元 `c` 必须是全新临时假名**：① `c` 不得出现在子证明之外的任何前提中；② `c` 不得出现在 `∃x Ax` 中；③ **`c` 绝不得泄漏到子证明结论 `B` 中** |

## A1 - Past Application (书中经典案例闭环还原)

- **案例 1：“当今法国国王不是秃头”的宽辖域 vs 窄辖域歧义消解 (陈波《逻辑学导论》第4章第6节；Priest《Logic: VSI》第4章)**
  - **问题 (Problem)**：现实中当今法国没有国王(`F = ∅`)。那么命题(1)“当今法国国王是秃头”与命题(2)“当今法国国王不是秃头”似乎都是假的，这岂不是违反了排中律 `A ∨ ¬A`？
  - **方法 (Method)**：调用罗素摹状词理论，区分否定词 `¬` 相对于存在量词 `∃x` 的**窄辖域 (Narrow Scope / 内部否定)**与**宽辖域 (Wide Scope / 外部否定)**。
  - **结论 (Conclusion)**：
    - 命题(1)符号化为：`∃x(Fx ∧ ∀y(Fy → y = x) ∧ Bx)` -> 因 `∃x Fx` 为假，故命题(1)为**假 (`0`)**。
    - 命题(2)在自然语言中有两种解读：
      - **窄辖域解读 (内部否定)**：`∃x(Fx ∧ ∀y(Fy → y = x) ∧ ¬Bx)`(“存在一位当今法国国王，而且他长着浓密头发”) -> 这与命题(1)只是**反对关系**，因为 `∃x Fx` 为假，窄辖域解读同样为**假 (`0`)**！
      - **宽辖域解读 (外部否定)**：`¬∃x(Fx ∧ ∀y(Fy → y = x) ∧ Bx)`(“并非存在一位身为秃头的当今法国国王”) -> 这才是命题(1)真正的逻辑矛盾命题，在法国无国王时为**真 (`1`)**！
  - **结果 (Outcome)**：在不放弃经典二值排中律的前提下，彻底消解了困惑哲学界千年的“空摹状词否定悖论”与“预设陷阱”。

- **案例 2：用 2 元素微型模型 (`Model`) 秒破量词移位与量化无效论证 (Magnus《forall x》第5.5-5.6节)**
  - **问题 (Problem)**：检验论证：“有些 `A` 是 `B` (`∃x(Ax ∧ Bx)`)，有些 `A` 是 `C` (`∃x(Ax ∧ Cx)`)，所以有些 `B` 是 `C` (`∃x(Bx ∧ Cx)`)”是否有效？以及“每个人都有所爱之人 (`∀x∃y Lxy`)，所以有一个人被所有人爱 (`∃y∀x Lxy`)”是否有效？
  - **方法 (Method)**：调用 Magnus 第5章有限模型反例构造法 (`UD = {a, b}`)。
  - **结论 (Conclusion)**：
    - 对第一个论证，构造模型：`UD = {d1, d2}`，`extension(A) = {d1, d2}`，`extension(B) = {d1}`，`extension(C) = {d2}`。此时 `d1` 满足 `Ax ∧ Bx`，`d2` 满足 `Ax ∧ Cx`，两前提皆真；但 `B ∩ C = ∅`，结论为假！(若误对两个存在前提使用同一个常元 `c` 实例化就会犯错，恰印证了 `∃E` 必须引入全新常元的铁律)。
    - 对第二个论证，构造模型：`UD = {d1, d2}`，`extension(L) = {⟨d1, d1⟩, ⟨d2, d2⟩}`(每个人只爱自己)。此时 `∀x∃y Lxy` 为真，但不存在任何人同时被 `d1` 和 `d2` 所爱，`∃y∀x Lxy` 为假！
  - **结果 (Outcome)**：用极其直观的 2 元素集合模型，瞬间证伪一切复杂的量化无效推理。

## A2 - Future Trigger (未来触发场景与邻近能力边界区分)

- **典型触发场景与用户语言信号**：
  - 涉及**多重全称/存在量词交织**(“每一个...都存在一个...” vs “存在一个...使得每一个...”)、**多元比较/排序/亲属/位置关系推理**、或含**“唯一一个 / 至少两个 / 除了...之外”**的精确数量逻辑分析。
  - 涉及含隐含存在预设的提问或陈述(如“你什么时候停止打你老婆的？”、“这个世界上最完美的阴谋是什么？”)，需要用**罗素摹状词宽窄辖域拆解法**破除预设圈套。
  - 需要对一阶谓词逻辑公式构造**有限模型反例 (`UD, extension`)**或执行带量词规则(`∀I, ∀E, ∃I, ∃E`)的 **Fitch 自然演绎证明**。
- **与邻近能力的边界区分**：
  - **组合 (`composes-with`)**：内嵌命题联结词推演时与 `03` 协同；简单单主谓词项推理可退化为 `02` 的三段论快速检验。
  - **对比 (`contrasts-with`)**：经典 `QL` 默认**论域 `UD` 非空**(`⊢ ∃x(x = x)`)且**所有常元 `c` 在论域中皆有指称 (`⊢ ∃x(x = c)`)**。若用户不想把专名(如“孙悟空”、“夏洛克·福尔摩斯”)改写为罗素摹状词，而是希望直接在带空专名或空论域的形式系统中推理，应切换至 `06` 中的**自由逻辑 (Free Logic, Priest 第13章)**。

## E - Execution (分步可执行指令与完成标准)

### Step 1: 论域设定、谓词提取与量词辖域对齐 (UD & Quantifier Scope Alignment)

1. 显式声明**论域 `UD`**(如“所有人类”或“不受限全集”)，定义一元/多元谓词 (`Fx, Rxy`) 与常元 (`a, b`)。
2. 翻译全称句时强制检查 `∀x(... → ...)`，翻译特称句时强制检查 `∃x(... ∧ ...)`。
3. 遇到多层量词(`∀x∃y` vs `∃y∀x`)或否定词加摹状词(`The F is not G`)时，必须分别写出其**特指/泛指**或**宽辖域/窄辖域**的精确一阶公式，严禁模糊混写。

### Step 2: 关系性质核查或双元素有限模型反例测试 (Relation Check / Finite Model Test)

1. **若为关系推理**：对照 `I.2` 表核查关系谓词 `R` 的自反性、对称性与传递性，严禁对非传递关系(如“朋友、喜欢、相交、击败”)做链式传递，严禁对非对称关系做换位。
2. **若怀疑量化推理无效**：构造最小反例模型 `M`：
   - 设 `UD = {0, 1}` (若涉及传递性或至少 3 个对象则设 `UD = {0, 1, 2}`)。
   - 在有限论域上将 `∀x φ(x)` 展开为合取 `φ(0) ∧ φ(1)`，将 `∃x φ(x)` 展开为析取 `φ(0) ∨ φ(1)`。
   - 寻找使前提全真、结论为假的谓词外延集合 `extension(P)` 并输出验证。

### Step 3: 量词自然演绎实例化顺序控制 (Quantifier Proof Ordering)

- 在构造同时含有 `∃x` 前提与 `∀x` 前提的形式证明时，**铁律：必须先做存在消去 (`∃E` 引入新常元 `c`)，再做全称消去 (`∀E` 将 `∀x` 实例化到同一个 `c` 上)**！若先做 `∀E` 用掉了常元 `c`，后续 `∃E` 就违反了“常元 `c` 不得在前面出现过”的合法性红线。

## B - Boundary (适用边界、反例失败模式与盲点)

1. **反例失败模式 1：违反 `∀I` / `∃E` 常元新鲜性约束导致伪证明**
   - 例如由 `∃x Fx` 和 `∃x Gx`，若错误地先后实例化为同一个常元 `Fa` 和 `Ga`，就会证出荒谬的 `∃x(Fx ∧ Gx)`(比如“有人是男人，有人是女人，所以有人既是男人又是女人”)。每消去一个独立的 `∃x`，必须启用一个**全新的独立常元**。
2. **反例失败模式 2：不可判定性极限 (Undecidability of Full First-Order Logic)**
   - 虽然一阶单主谓词逻辑(Monadic QL)和语句逻辑 `SL` 都是算法可判定的，但包含二元及以上关系谓词的完全一阶逻辑是**不可判定的 (丘奇定理 Church's Theorem)**：当某无效公式只在无限论域上才有反例时，有限模型搜索不会自动停机。
