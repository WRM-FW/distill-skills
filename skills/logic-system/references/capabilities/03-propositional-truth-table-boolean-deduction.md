## R - Reading (原文锚点与核心机制)

1. **语句逻辑 SL 符号化与自然语言精细转译 (Magnus《forall x》第2章；陈波《逻辑学导论》第2章第1-2节)**：
   - 语句逻辑 (`SL`) 将简单陈述句抽象为原子命题字母 (`A, B, C...`)，通过 5 个真值函数联结词 (`¬, &, ∨, →, ↔`) 构造复合公式 (wff)。
   - **充分条件与必要条件黄金映射规则**：
     - **充分条件** (“如果 `A` 那么 `B`”、“只要 `A` 就 `B`”、“一旦 `A` 则 `B`”、“`A only if B`”) -> **前件为 `A`，后件为 `B` (`A → B`)**。
     - **必要条件** (“只有 `B` 才 `A`”、“除非 `B` 否则不 `A`”) -> **后件为必要条件 `B` (`A → B` 或 `¬B → ¬A`)**。
     - **“除非 (`Unless`)”铁律 (Magnus 第2.4节)**：“`A unless B` (除非 `B`，否则 `A`)”严格符号化为 `¬B → A`，在经典二值逻辑中等值于相容析取 `A ∨ B`。
     - **“既不...也不... (`Neither A nor B`)”**：符号化为 `¬(A ∨ B)` 或 `¬A & ¬B`。
2. **完全真值表、单行部分真值表 (归谬赋值法) 与重言蕴涵 (Magnus 第3章；陈波第2章第3-4节)**：
   - 含 `n` 个原子命题的复合公式共有 `2^n` 行真值指派。主联结词列全为 `1` 为**重言式 (Tautology)**，全为 `0` 为**矛盾式 (Contradiction)**，有 `1` 有 `0` 为**偶真式 / 可满足非重言式 (Contingent)**。
   - **单行部分真值表 / 归谬赋值法 (Partial Truth Table, Magnus 第3.5节)**：为检验论证 `A1, ..., Ak ⊨ B` 是否有效，无需列出 `2^n` 行全表，只需假设**所有前提为 `1` 且结论 `B` 为 `0`**，逆向推导各原子命题真值；若导出某原子命题既为 `1` 又为 `0` 的冲突，则证得该论证**有效 (Valid)**；若能无冲突赋出一组真值，则该单行赋值即为**反例模型 (Counterexample)**，证得论证**无效 (Invalid)**。
3. **Fitch 风格自然演绎系统与逆向证明策略 (Magnus 第6章；陈波第2章第5节)**：
   - 每个联结词配对一条**引入规则 (`I`)**与一条**消去规则 (`E`)**，配合衍生规则(`MP, MT, HS, DIL`)与等值置换规则(`Comm, DN, DeM, MC, ↔ex`)。
4. **布尔代数、逻辑门与卡诺图硬件极小化 (Petzold《编码》；康华光/阎石《数字电子技术基础》)**：
   - 香农(Claude Shannon)将命题逻辑同构映射为开关电路：串联为合取(`AND`)，并联为析取(`OR`)，反相器为否定(`NOT`)。利用最小项 (`Minterm, m_i`) 与卡诺图 (`Karnaugh Map`) 相邻格合并(`2^k` 个 1 圈消去 `k` 个互补变量)，可将任意复杂条件决策表化简为最简“积之和 (`SOP / 析取范式`)”规则。

## I - Interpretation (方法论骨架、定量参数表与决策规则)

### 1. 自然语言条件与选言句式符号化防错速查表

| 自然语言句式结构 | 标准 SL 符号化 | 等值真值函数转换 | 极易踩坑的常见误译 (禁忌) |
| :--- | :--- | :--- | :--- |
| 如果 `A` 那么 `B` / 只要 `A` 就 `B` | `A → B` | `¬A ∨ B` | 严禁顺手逆转为 `B → A` |
| **只有 `B`，才 `A`** (`A only if B`) | **`A → B`** (或 `¬B → ¬A`) | `¬A ∨ B` | **头号高频错误**：误译为 `B → A` (把必要条件当成了充分条件) |
| **除非 `B`，否则 `A`** (`A unless B`) | **`¬B → A`** (或 `¬A → B`) | **`A ∨ B`** | 误译为 `B → ¬A` (除非是“除非 `B` **才**不 `A`”，否则 `unless` 只承诺 `¬B → A`) |
| **除非 `B`，否则不 `A`** | **`¬B → ¬A`** (即 **`A → B`**) | `¬A ∨ B` | 搞反否定号位置 |
| 要么 `A` 要么 `B` (二者必居其一，不可兼) | `¬(A ↔ B)` 或 `A ⊻ B` | `(A ∨ B) ∧ ¬(A ∧ B)` | 漏掉“不可同真 (`¬(A ∧ B)`)”约束，误用相容析取 `A ∨ B` |
| 并非“如果 `A` 那么 `B`” | `¬(A → B)` | **`A ∧ ¬B`** | **极高频错误**：误以为“如果 `A` 则 `B`”的否定是“`A → ¬B`”！实为 **`A` 真且 `B` 假 (`A ∧ ¬B`)** |

### 2. 命题推理四大有效形式 vs 两大经典形式谬误对比表

| 推理名称 | 前提 1 | 前提 2 | 结论 | 有效性定性 | 逻辑状态说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **肯定前件式 (Modus Ponens, MP)** | `A → B` | `A` | `B` | **有效 (`Valid`)** | 充分条件假言推理标准正推 |
| **否定后件式 (Modus Tollens, MT)** | `A → B` | `¬B` | `¬A` | **有效 (`Valid`)** | 证伪与排除法的核心引擎 |
| **选言三段论 (Disjunctive Syllogism, DS)** | `A ∨ B` | `¬A` | `B` | **有效 (`Valid`)** | 否定肯定式(相容与不相容析取皆适用) |
| **相容选言肯定否定式** | `A ∨ B` | `A` | `¬B` | **无效 (`Invalid`)** | **肯定一肢谬误** (相容析取允许 `A, B` 同真；仅不相容析取 `A ⊻ B` 可由 `A` 推 `¬B`) |
| **肯定后件谬误 (Affirming the Consequent)** | `A → B` | `B` | `A` | **无效 (`Invalid`)** | 混淆充分条件与必要条件 (`A=0, B=1` 即为反例) |
| **否定前件谬误 (Denying the Antecedent)** | `A → B` | `¬A` | `¬B` | **无效 (`Invalid`)** | 忽略 `B` 可由其他原因触发 (`A=0, B=1` 即为反例) |

### 3. Fitch 自然演绎“目标导向逆向策略表” (Magnus 第6.7节)

当需要从前提集 `Γ` 形式证明目标公式 `G` 时，先看目标 `G` 或现有前提的**主联结词 (Main Connective)**：

| 当前目标 `G` 的主联结词 | 优先采用的逆向拆解策略 (Backward Strategy) | 现有前提的主联结词 | 优先采用的正向榨取策略 (Forward Strategy) |
| :--- | :--- | :--- | :--- |
| **`A → B` (条件句)** | 立即开设子证明：第 `i` 行假设 `A`，将子目标设为 `B`；证出 `B` 后用 **`→I`** 收口 | **`A & B` (合取)** | 立即用 **`&E`** 拆出单行 `A` 和单行 `B` 备用 |
| **`¬A` (否定句)** | 立即开设归谬子证明：假设 `A`，寻找任意矛盾对 `C` 与 `¬C`，用 **`¬I`** 收口 | **`A → B` (条件句)** | 寻找或先证出 `A` (用 `→E/MP`)，或寻找 `¬B` (用 `MT`)，或用 `MC` 置换为 `¬A ∨ B` |
| **`A & B` (合取句)** | 拆成两个独立子目标：先证 `A`，再证 `B`，最后用 **`&I`** 合并 | **`A ∨ B` (析取句)** | 寻找 `¬A` 或 `¬B` 走选言三段论，或对 `A` 和 `B` 分别开设子证明走 **`∨E` / 二难推理 `DIL`** |
| **`A ↔ B` (双条件句)** | 开设两个子证明：先由假设 `A` 证 `B`，再由假设 `B` 证 `A`，用 **`↔I`** 收口 | **`¬(A ∨ B)` 或 `¬(A & B)`** | 立即用**德摩根定律 (`DeM`)** 转化为 `¬A & ¬B` 或 `¬A ∨ ¬B` |
| **原子命题 `P`** (无主联结词) | 若正向规则推不出，立即开设反证子证明：假设 `¬P`，导出矛盾后用 **`¬E`** 收口 | **`¬(A → B)` (负假言)** | 立即用 **`MC` + `DeM`** 等值转化为 **`A & ¬B`**，瞬间拆出两个确定信息 `A` 和 `¬B`！ |

## A1 - Past Application (书中经典案例闭环还原)

- **案例 1：半费之讼 (普罗泰戈拉 vs 欧提勒士) 二难推理与破斥 (陈波《逻辑学导论》第2章第7节 / 《逻辑学是什么》第3部分)**
  - **问题 (Problem)**：古希腊智者普罗泰戈拉收欧提勒士学辩术，约定“毕业后打赢第一场官司才交另一半学费”。欧提勒士毕业后一直不接官司，老师起诉他并构造二难推理：`(1) 如果欧胜诉，按合同约定应交半费 (W → P)；(2) 如果欧败诉，按法庭判决应交半费 (¬W → P)；(3) 欧要么胜诉要么败诉 (W ∨ ¬W)；所以欧必交半费 (P)`。欧提勒士如何反击？
  - **方法 (Method)**：调用复杂构成式二难推理 (`(A → C) ∧ (B → D) ∧ (A ∨ B) ⊢ C ∨ D`) 的三大破斥法则：①攻击选言前提未穷尽；②攻击假言前提不成立；③构造**反向二难推理 (反戈一击)**。
  - **结论 (Conclusion)**：欧提勒士指出老师混淆了两个不同标准(合同约定 vs 法庭判决)，遂构造反向二难：`(1) 若我胜诉，按法庭判决我不交半费 (W → ¬P)；(2) 若我败诉，按合同约定我不交半费 (¬W → ¬P)；(3) W ∨ ¬W；所以我绝不交半费 (¬P)`。其底层根源在于合同条款与本次诉讼形成了跨层自指冲突。
  - **结果 (Outcome)**：展示二难推理在商业博弈、法庭辩论与逻辑攻防中的对称破拆技巧。

- **案例 2：多条件复杂业务规则的布尔代数与卡诺图化简 (Petzold《编码》/ 康华光《数字电子技术基础》)**
  - **问题 (Problem)**：某信贷审批系统规定：“当申请人有房产(`A`)且有稳定流水(`B`)，或者虽无房产(`¬A`)但有稳定流水(`B`)且有担保人(`C`)，或者有房产(`A`)但无稳定流水(`¬B`)且有担保人(`C`)时，予以放款(`Y=1`)。”如何将该冗长规则化简为最简判断逻辑？
  - **方法 (Method)**：写出最小项之和表达式 `Y = A·B + A'·B·C + A·B'·C`，填入 3 变量卡诺图或应用布尔吸收律 `X + X'·Y = X + Y`。
  - **结论 (Conclusion)**：`Y = B·(A + A'·C) + A·B'·C = A·B + B·C + A·C` (即三项条件 `A, B, C` 中**任意满足至少两项**即可放款，对应多数表决器 Majority Gate！)。
  - **结果 (Outcome)**：将 3 条复杂的复合分支规则瞬间压缩为 1 句清晰无冗余的“三选二”规则，彻底消除业务代码与合同条款中的死分支与重叠漏洞。

## E - Execution (分步可执行指令与完成标准)

### Step 1: 原子命题词典定义与公式精确转译 (Symbolization Key & WFF Translation)

1. 显式列出**符号化词典 (Symbolization Key)**：每个大写字母 (`A, B, C...`) 必须对应一个肯定陈述句(将“不/没有”提取为外部联结词 `¬`)。
2. 严格按照 `I.1` 表转译条件句与选言句，特别核查：
   - 遇到“只有 `B` 才 `A`” -> 必写 `A → B`。
   - 遇到“并非(如果 `A` 则 `B`)” -> 必写 `¬(A → B)` 并立即等值展开为 **`A ∧ ¬B`**。
   - 多层联结词必须加齐括号，消除结合歧义(如 `(A ∧ B) ∨ C` vs `A ∧ (B ∨ C)`)。

### Step 2: 归谬赋值法 (单行部分真值表) 快速有效性裁决

1. 设所有前提公式 `P1 = 1, P2 = 1, ..., Pk = 1`，且目标结论 `Q = 0`。
2. 优先从**唯一确定真值**的公式入手逆向传播：
   - 若某前提为 `A ∧ B = 1` -> 立即固定 `A = 1, B = 1`。
   - 若结论或某式为 `A ∨ B = 0` -> 立即固定 `A = 0, B = 0`。
   - 若某式为 `A → B = 0` -> 立即固定 **`A = 1, B = 0`**。
3. 将已固定的原子真值代入其余假言/选言前提，使用 `MP / MT / DS` 链式传导：
   - **判停标准 A (有效)**：若在所有分支中均被迫赋予某原子字母矛盾值 (`X = 1` 且 `X = 0`)，证明不存在反例，推理**形式有效 (`⊨`)**。
   - **判停标准 B (无效)**：若找到至少一组无矛盾的原子真值指派使所有前提为 `1` 且结论为 `0`，直接输出该组指派作为**铁证反例 (`⊭`)**。

### Step 3: 自然演绎构造或布尔卡诺图化简 (Proof Construction or K-Map Minimization)

- **若任务要求形式证明 (`⊢`)**：按 `I.3` 逆向策略表规划子证明缩进层级，每一行严格标注【公式 + 规则缩写 + 引用行号】，并确认所有子证明假设(`Assumption`)在末行前均已合法卸载(`Discharged`)。
- **若任务要求业务规则体检/化简**：列出 `2^n` 真值表，检查是否存在：①**未定义空洞**(某行输入组合未映射任何输出动作)；②**规则冲突**(同一行输入同时触发互斥动作)；③用布尔代数/卡诺图合并相邻项，输出最简判定表达式。

## B - Boundary (适用边界、反例失败模式与盲点)

1. **反例失败模式 1：实质蕴涵怪论 (Paradoxes of Material Implication) 误用**
   - 在经典 `SL` 中，`¬A ⊨ A → B` 与 `B ⊨ A → B` 皆为重言蕴涵(例如因为“2+2=5”为假，所以“如果2+2=5，那么雪是黑的”在真值表上为真)。切勿在日常或商业争论中拿“因为前件假所以假言命题为真”当成实质论证理由(Priest《Non-Classical Logic》第1章)。
2. **反例失败模式 2：丢失自然语言连词的时间、因果或转折语用信息**
   - 在 `SL` 中，“她服了毒药并且去世了 (`A & B`)”与“她去世了并且服了毒药 (`B & A`)”真值完全等值 (`Comm`)；“虽然很贵但是很好用”与“既贵又好用”也共享同一个 `&`。当推理高度依赖**时间先后顺序**时，必须保留时序约束或路由至 `05` (时态逻辑 `Kt`)。
