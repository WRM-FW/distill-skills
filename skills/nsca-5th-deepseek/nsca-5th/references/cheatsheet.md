# 决策规则速查 — Essentials of Strength Training and Conditioning, 5th Edition

| 能力 | 一句话规则 |
|---|---|
| 需求分析（Step 1：运动特征评估 + 运动员评估） | 设计任何抗阻计划前，先做两阶段需求分析（先评估运动、后评估运动员），产出运动需求画像+训练状态+主目标。 |
| 训练状态分类（beginner / intermediate / advanced） | 用 Table 18.1 的六维（当前训练/训练年龄/周频率/训练应激/技术/背景）判定 beginner|intermediate|advanced，跨档取保守档。 |
| 确定主要训练目标（单目标聚焦 + emphasis/de-emphasis + 赛季优先级） | 每训练块只设一个主目标（据测试+运动分析+赛季优先级），其余素质用 emphasis/de-emphasis 维持；团队成员项目只并行兼容素质。 |
| 动作选择（Step 2） | 在"类型学×专项性×技术经验×器材×时间"五约束下求交选动作，输出带 core/assistance、structural/power 标签的清单。 |
| 训练频率（Step 3：状态×赛季双查表 + 恢复日间距 + split 时机） | 频率＝状态表(T18.4)∩赛季表(T18.7)，同肌群间隔 1–3 天，split 仅中高级+off-season 适用。 |
| 动作顺序（Step 4） | 单次课默认 power→其他 core（最难优先）→assistance；时间紧/新手可上下肢交替或 push–pull 交替。 |
| 确定与估算 1RM / xRM（Step 5 之测试与估算） | 三条路径选一（直接测 1RM / 由 xRM 估 / 按目标次数做 xRM）；辅助 ≤8RM、power xRM ≤5 次、低 1RM 者用相对增量。 |
| 按训练目标分配负荷与重复（Step 5 核心） | 目标定 %1RM×次数（strength ≥85%/≤6；power 75–85%/3–5；hypertrophy 67–80%/8–12；endurance ≤67%/≥12），乘 1RM 得重量、取整到 5 lb。 |
| Power 训练负荷赋值特例 | Power 动作不用常规 %1RM–次数关系：可重载动作 75–90%、抓接派生 60–80%、单次用力项 1–2 次@80–90%、多次用力项 3–5 次@75–85%。 |
| 替代/自调负荷法（RPE / RIR / SRB） | 先用 %1RM 定基础、再用 RPE/RIR 区间自调（新手限制自主）；或用 SRB 5% 区间逐周递进。 |
| 负荷进阶（何时加：2-for-2；加多少：增幅/重轻日变异） | 何时加＝2-for-2（连续两次末组各超目标 ≥2 次）；加多少＝查 Table 18.12（较弱上肢 2.5–5 lb…较强下肢 10–15+ lb）或相对 2.5%–10%。 |
| 训练量分配（Step 6 + volume-load 计算） | 量＝组数×次数×负荷（移动自重者用 system mass 加体重）；组次按 Table 18.13 依目标与状态取值。 |
| 组间休息时长（Step 7） | 按目标查 Table 18.15（力量/爆发 2–5 min；肥大 多关节 2–3 min、单关节 60–90 s；耐力 ≤30 s），再逐动作按实际负荷与肌群量微调。 |
| 完整 7 步抗阻训练计划设计（端到端 SOP） | 按需求分析→动作→频率→顺序→负荷→量→休息七步组装出一份含组数×次数×负荷×休息的可执行计划。 |
| 抗阻训练计划设计（七步 SOP · 晋级入口） | 用户要"给这个运动员排一份抗阻训练计划"时，用本入口按七步出完整周计划（组数×次数×负荷×休息）。 |
| 周期化的三级建立流程（周期化 → 规划 → 编程） | 先搭宏观框架（一级）→ 再选训练模型（二级）→ 最后落地负荷结构（三级）；上层缺输入不往下推。 |
| 周期化模型的选择框架（parallel / sequential / emphasis） | 新手/青训→parallel；中高级需更大刺激→sequential；中高级且赛程密集→emphasis（每两周轮换重点）。 |
| 周期层级结构与时长口径（Table 22.2） | mesocycle 取 2–6 周（默认 4）、microcycle 取 1 周；单赛季项目年度 = 1 个 macrocycle。 |
| 运动季节 ↔ 周期化时期映射与传统四期演变 | off-season→preparatory、preseason→first transition、in-season→competitive、postseason→second transition；preseason 不是建基础期。 |
| 年度训练计划（macrocycle）的编排流程 | 1 annual plan = 1 macrocycle → 切四赛季 → 细分 2–4 周 mesocycle（标相位/microcycle 数）→ 钉测试节点 → 放卸载周。 |
| 用变量填充一个中周期（Table 22.3 档位落地） | 按相位查 Table 22.3 取强度/量/组次 → 用 RM 落到 kg（周五=周一×0.90、热身另计）→ 赛内改 %RM 区间不力竭。 |
| 周期化三大机制理论（GAS / 刺激—疲劳—恢复 / 体能—疲劳） | 用 GAS 判是否滑向衰竭、SFR 解释负荷-恢复、体能—疲劳说明"减量抬高备战状态"，据此安排卸载。 |
| 峰值 vs 维持的决策框架（peaking / maintenance） | 短窗关键赛→peaking（~1–2 周、50%–≥93% 1RM、1–3×1–3）；长赛季团队项目→maintenance（85%–93% 1RM、~2–5×3–6、microcycle 级调制）。 |
| 密集赛程 / 长赛季的赛内负荷编排与卸载周 | 长赛季用 3–4 周中周期块、末个 microcycle 卸载；赛内不力竭、用 %RM 区间，非关键课 -10%，比赛与抗阻/plyo 间留 2–3 天。 |
| 波动的辨识：undulating vs 传统"伪线性"周期化 | 周内同时波动负荷+量+焦点→DUP；仅变负荷、组次不变→传统模型（实为非线性，勿称 linear）；两者优劣原文无定论。 |
| 周期化与年度计划编排（总纲） | 分层→选模型→定周期层级→映射赛季→排年度并钉测试/卸载→用 Table 22.3 填块落值→按体能—疲劳动调卸载→竞赛期分派峰值或维持。 |
| 有效测试的证据本位选择框架（效度/信度双门槛） | 先过信度门（能力未变时重复测是否一致）→ 再过效度门（是否测的是它声称的属性）；稳 ≠ 准；两门都过才采用，若均有效取更简单经济者。 |
| 专项特异性与测试电池构建（含年龄/性别/训练状态边界） | 按专项供能系统 + 力学动作模式选测，用四维（动作模式/肌群/供能系统/技能复杂度）查覆盖，再按经验/训练状态/年龄/性别过滤适用性。 |
| 测试顺序编排与休息安排 | 非疲劳 → 敏捷 → 最大力量/爆发 → 冲刺 → 局部肌耐力 → 无氧能力 → 有氧；试次间非极限 ≥2 min、接近最大 ≥3 min、电池内 ≥5 min；磷酸原 3–5 min、糖酵解 ≥1 h 恢复。 |
| 测试员选拔、培训与施测分工 | 同一测试尽量同一人施测以消除评分者间误差；新手须先做与资深者的一致性校验；每人同时只负责一项，需判断的测试交最熟练者。 |
| 运动员测试准备、记录与测试日标准化 | 提前公布日期/目的、T-3 天熟悉课、统一讲解与热身、固定同一时段并尽量室内；记录表须含全部成绩 + 环境 + 设备设置 + 备注。 |
| 测试信度受损来源排查（前后测一致性） | 四来源排查——受试者内变异 / 评分者间不一致 / 评分者内变异 / 测试本身不一致；对策为明确评分系统 + 前后测同一评分者 + 标准化校准 + 增加练习。 |
| 环境因素对测试的调整（温度/湿度/海拔） | 海拔 >579 m 调常模、≤2743 m 内每 914 m 约 −5% VO2max、到高海拔后 ≥10 天再测（不影响力量/功率）；避免极端热湿、留 ≥3 °C 裕度、热习服 ≥1 周、测前 24 h 补水。 |
| 测试安全红线：健康风险识别与转诊（含低钠血症） | 持续红旗（胸痛/意识模糊/眩晕/皮肤深红湿冷/脉搏不规则等）→ 转诊，单次严重（如丧失意识）→ 立即就医；低钠血症（极清亮尿+皮肤胀+意识改变、体温不升）→ 绝不补液、立即交医师。 |
| 测试监控体系三层设计与运动科技引入决策 | 上：protocol（测什么、多久）→ 中：procedure（逐步细则）→ 下：equipment（过效度/信度、实用、相关）；引入新工具用四问闸门，先做与金标准的一致性验证再采用。 |
| 最大力量测试协议族（1RM / IMTP / 北欧腘绳肌） | 1RM 首试 ≈50% 估测 1RM、热身后 3–5 次内定位到真值数个百分点内；IMTP 取 3–5 s 峰值力、峰值力波动 >15% 加测并按四条信号剔除无效试次；相对力量 = 力量 ÷ 体重。 |
| 负荷-速度剖面（VBT）建立与 1RM 预测禁用 | 取 20–90% 1RM 各负荷点记录杠速拟合 L-V 线性关系，用于评价与处方强度；明确禁止由剖面估 1RM（会系统性高估，1RM 须直接测）。 |
| 跳跃与下肢爆发力测试协议族 | 纵跳取三次最佳（0.5 in/1 cm）、蹲跳膝角约 110° 保持 2–3 s、手固定于髋；落地跳看跳高/触地时间/RSI；不同测法（力台/摸高/Vertec）成绩不可互换比较。 |
| 速度与变向/敏捷测试协议族 | 优先电子计时（手计时最多快 0.24 s）；短距测加速、40 yd 测最大速度、试次间 ≥2 min；变向族判罚明确——T-test 未触锥/交叉步/未面向前该次无效，5-10-5 取 0.01 s。 |
| 无氧能力测试协议族（Wingate / 300-yd / 90-s 箱跳 / Margaria 冲刺） | 无氧能力取 30–90 s；Wingate 30 s、阻力≈体重 7.5%、出每 5 s 区间功率与疲劳指数；300-yd 两次取平均（0.1 s）；90 s 箱跳双脚离地双脚触箱顶才计、踩箱不计。 |
| 局部肌肉耐力测试协议族（partial curl-up / push-up / AFT HRP / YMCA 卧推） | partial curl-up 节拍 40 拍/分（20 次/分）、胶带距 <45 岁 12 cm / ≥45 岁 8 cm、上限 75 次；YMCA 卧推男 80 lb/女 35 lb、60 拍/分（30 次/分）；未达底面/跟不动节拍不计，AFT 静止 >5 s 终止。 |
| 有氧能力测试协议族（1.5-mile / 12-min / Yo-Yo IRT / MAS / 30-15 IFT） | 1.5-mile/12-min run（12-min 距离 = 圈数 × 400 m）、Yo-Yo IRT（2×20 m、10 s 恢复、两次未达线终止）、MAS（每 2 min +1 km/h、保持 ≥2 min 的速度为 MAS）、30-15 IFT（30 s 跑+15 s 走）；1.5-mile 的 VO2max 只能查表 14.22–14.25。 |
| 动作筛查与柔韧性测试（AMSC / FMS / TJA + 坐位体前屈 / 过顶深蹲） | 筛查先立评分者信度、可录像回看、FMS/RTSB 取最佳而 TJA 求和；坐位体前屈器材前后一致、三次取最佳（0.25 in/1 cm）、<15 in 够不到；过顶深蹲 pass/fail（髋褶低于膝顶）；任何柔韧测试禁弹震。 |
| 平衡测试协议族（BESS / SEBT） | BESS = 3 站姿 × 硬/软地共六条件、闭眼手放髋各 20 s、7 类错误、六条件错误求和为单总分；SEBT = 八方向 120 cm/45°、每条件 3 次取平均、前伸间 15 s、≥4 次练习、可只测 AM/M/PM。 |
| 人体测量与体成分测量协议（身高/体重/围度/皮褶/BIA） | 身高脱鞋 0.25 in/0.5 cm、体重用认证天平清晨排空进食前、皮褶干皮运动前且卡尺松柄后 1–2 s 读 0.5 mm（两次 ≤10% 取平均否则加测）、BIA 条件一致；体成分优选受训者皮褶（r=0.99）。 |
| Margaria-Kalamen 台阶冲刺功率计算（含单位口径裁断） | P = (w × h) / t；w = 体重（lb × 4.448 或 kg × 9.81）牛、h = 台阶高（in × 0.0254 或 6 级落差）米、t 秒；本簇统一取 kg × 9.81、lb × 4.448。 |
| 体成分估算计算（皮褶→体密度→体脂% + SEE 区间） | 两步法——① 按人群/位点选方程由皮褶算体密度 Db；② 用 %BF = (a/Db − b) × 100；报告须带 SEE 区间（±3%–5%，如 24% → 21%–27%）。 |
| 最大有氧速度（MAS）与 VO2max 估算 | MAS 取保持 ≥2 min 的最后速度；VO2max = 3.5 × MAS（km/h）；哨声间隔 = 锥距 ÷ 速度；1.5-mile 无公式只能查表。 |
| 描述统计、数据标准化与运动员画像 | 算 x̄ 与 SD = √(Σ(x−x̄)²/(n−1))、z = (x−x̄)/SD 并治理方向，再用六步法合成运动员画像定位弱项。 |
| 幅度统计（SWC / 效应量 / 差异分解读） | SWC = 0.2 × 组间 SD；ES = (后测均值 − 前测均值) ÷ 前测 SD，锚点 0.2/0.6/1.2/2.0；警惕收益递减与故意低报。 |
| 常模数据的查找与解读口径（表 14.1–14.37） | 按项目/年龄/性别选表 14.1–14.37，定位百分位并赋描述词（90/70/50/30/10），强制标注"描述性 vs 规范"并核对年代人群。 |
| 反应力量指数（RSI）与离心利用率（EUR）计算 | RSI = 跳跃高度 ÷ 触地时间（m/s）；10-5 取最佳 5 次 RSI 平均；EUR = CMJ 高度 ÷ 蹲跳高度。 |
| NSCA 测试、评估与数据解释（完整流程） | 先定要回答的问题 → 过效度/信度门槛选测并配专项电池 → 排顺序休息与分工准备 → 算 z/SWC/ES 查常模画画像 → 红旗即转诊。 |
| Plyometric 计划设计总纲：需求分析 + 五步 SOP + 六变量框架 | Design any plyometric program by the fixed five-step SOP over six variables, teaching technique before assigning variables. |
| Plyometric 强度与量：Table 19.5 多因素强度 + Table 19.6 触点档位 | Judge intensity with the seven Table 19.5 factors, then read volume from Table 19.6 (experience × intensity); as intensity rises, volume falls. |
| Plyometric 频率与恢复：以恢复窗反推周次数（含组间/次间） | Fix frequency by the recovery window (48–72 h between sessions → usually 2–3/week), never train a body area at moderate-high volume on successive days, and treat plyo as power not aerobic training. |
| Plyometric 进阶：渐进过载、强度↑量↓、计划时长 | Progress plyometrics by overload: switch to harder drills and, as intensity rises, cut volume — do not simply add reps. |
| Plyometric 训练前评估与准入：技术 / 力量 / 平衡 / 身体特征 | Before any plyometric drill, verify technique, the back-squat-equivalent strength tier, and a 30-second balance test — then pick the drill tier accordingly. |
| 年龄人群 plyo 处方裁剪：青少年 / 儿童 / 大师 | Adjust plyometrics by age: prepubescent children and masters with knee surgery/joint degeneration must avoid depth jumps and high-intensity single-leg drills. |
| Plyometric 专项热身（RAMP：激活—动员—增强） | Begin every plyometric session with a low-to-high dynamic warm-up chain (marching → ground contact → footwork → neuromuscular accel/decel), not with high-intensity jumps. |
| Plyometric 安全与常见错误排障：技术/落地/ACL + 深跳高度/体重 + 场地器材 | On any plyometric red flag, attribute it to the six correctable causes and fix it: no knee valgus (ACL risk), depth-jump box 16–42 in (≤18 in if >100 kg), cushioned surface, mats <6 in. |
| Plyometric 与抗阻/有氧的整合与排序（含 complex training 三型） | Pair lower-body lifting with upper-body plyos (and vice versa), avoid heavy lifting + plyometrics on the same day (or use complex training), and do plyometrics before aerobic work. |
| Plyometric 训练计划设计（晋级伞形卡：从需求分析到安全的一体化流程） | One integrated flow for plyometric design: needs analysis → pretraining screen → teach technique → assign the six variables (intensity/volume via Tables 19.5–19.6, frequency/recovery via 48–72 h) → progress → integrate & sequence → safety check. |
| 速度 / 变向 / 敏捷三分定义与能力判定 | Classify a movement problem as Speed, COD, or Agility by whether it is pre-planned and whether it includes a reactive stimulus; agility = COD + perceptual-cognitive. |
| 速度 / 变向 / 敏捷的力学指标口径与计算（RFD / impulse / momentum / power / COD deficit） | Use force/RFD/impulse as direct metrics (power is derived), and isolate change-of-direction ability with COD deficit = COD test time − linear sprint time. |
| 敏捷/变向需求分析与分期处方（5 步流程 + 3 block 模板） | Program agility/COD by the five-step needs-analysis chain and the three-block prescription (linear deceleration → lateral deceleration/transition → deceleration + re-acceleration + reaction). |
| 速度发展的 short-to-long 分期处方（Table 20.7） | Periodize sprint speed short-to-long across four blocks — acceleration → longer acceleration → introduce max velocity → reinforce max velocity (Table 20.7). |
| 冲刺技术错误排障（症状 → 原因 → 纠正） | Diagnose sprint errors by symptom → cause → correction (Table 20.1), fixing force application and gait rather than just the surface cue. |
| 速度手段选择与进阶（三级分类 + 进阶/退阶/变式 + 负荷规则） | Choose speed methods by tier (primary max-velocity sprint, secondary resisted/assisted, tertiary lifting/jumping) and set load by sport — overspeed ≤10%, resistance 10–12% (track) or 20–30% body weight (field). |
| 敏捷 drill 可操纵因素与知觉—认知进阶（含过渡移动） | Tune any agility drill by mechanical constraints (spacing, entry/exit velocity, action/angle, start posture), then add perceptual-cognitive load (opponents, time, rules, sport-specific stimuli) to move from closed to reactive agility. |
| 变向训练取向决策（角度/入速 → 快慢 SSC + GCT 基准） | Decide the training orientation from cutting angle and ground contact time: shallow (<75°) cuts with GCT <250 ms train like speed; aggressive (≥75°) cuts >250 ms need eccentric/max strength and propulsion. |
| 变向/敏捷技术诊断要点（视觉—躯干—腿—臂） | Diagnose COD technique on four dimensions — visual focus, trunk control, leg braking via co-triple flexion, and arm action — replacing stiff-legged braking. |
| 速度/敏捷监控指标选择与解读 | Track speed with Table 20.8 and COD/agility with Table 20.12, and cross-read changes (GCT↓ + time↓ = RFD↑; unchanged COD deficit = linear-speed effect) rather than judging by completion time alone. |
| 速度 / COD / 敏捷计划设计变量清单与 volume-load | Fill the shared design variables (angle, approach velocity, order, frequency, intensity, recovery, sets/reps, work-to-rest) and quantify load with volume-load (e.g., 3×5×100 kg = 1,500 kg). |
| 敏捷发展多元方法框架（力量谱 + 闭技能技术 + 知觉认知） | Develop agility along three lines — physical qualities (strength spectrum, action capacity), closed-skill COD technique, and perceptual-cognitive ability — with fitness preceding technique. |
| 速度 / SSC 训练目标与两判据 | Improve sprint SSC by brief ground support and enhanced impulse; accept an SSC drill only if it uses skillful multijoint movements through the kinetic chain and is structured in short bouts with frequent rest. |
