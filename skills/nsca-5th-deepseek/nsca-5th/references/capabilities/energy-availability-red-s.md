# 能量可用性（EA）与 RED-S 识别

## R — 原文 (Reading)

> "LEA is quantified by energy availability (EA), calculated as energy intake minus exercise energy expenditure, relative to fat-free mass (FFM). Optimal EA for healthy function is around 45 kilocalories per kilogram FFM per day, while severe perturbations can occur below 30 kilocalories per kilogram FFM per day."

— Chapter 11 · Nutrition Strategies for Maximizing Performance（`ch11.txt:1497-1500`）

## I — 自述 (Interpretation)

把「训练量过大 / 吃得不够」量化为一个可算指标，并用硬阈值触发警觉与转诊。骨架：

- **计算口径**：`EA = (能量摄入 − 运动能量消耗) ÷ FFM`，单位 **kcal/kg FFM/天**。
- **阈值**：健康功能最优约 **45**；**<30** 可出现严重紊乱。
- **中间区（30–45）**：原文未命名——本卡按「亚临床 / 需警惕」表述，**不补造临床分级**。
- **含义**：低能量可用性（LEA）是 **RED-S（相对能量不足）** 的成因；RED-S 累及代谢率、月经功能、骨健康（骨密度↓、骨应力伤↑）、免疫、蛋白合成与心血管健康；女性常见闭经（经下丘脑-垂体-性腺轴）；LEA 可能是运动员受伤风险最强的指标之一。
- **角色定位**：这是**安全红旗**——教练须能识别并**升级到转诊多学科团队**，而非当作减重/纪律问题自行处理。

## A1 — 案例 / 演练 (Application)

**原书未给 EA 的数值算例**；只给公式与阈值。以下为**明确标记的合成演练**，按原文公式复算。

**合成演练（标记：合成；可复算）**
- 输入：女运动员 60 kg、FFM 48 kg；能量摄入 2200 kcal/天、运动净消耗 700 kcal/天。另一例：摄入 1800、消耗 900。
- 执行：
  - 例 1：EA = (2200 − 700)/48 = 1500/48 = **31.25 kcal/kg FFM/天**（>30 但 <45 → 亚临床 / 需警惕，非健康最优）；
  - 例 2：EA = (1800 − 900)/48 = 900/48 = **18.75**（<30 → 严重 LEA，红旗，**须转诊多学科团队**）。
- 容差：±0.5。
- 原书未说明该合成输入的「实际结果」，此处为按公式复算。

## A2 — 未来触发 (Trigger)

**用户情境（3–5 条）**
1. 运动员训练量大、吃得不够，出现月经失调/停经、反复骨应力伤、体重骤降。
2. 要判断「吃得够不够」有没有量化依据。
3. 女运动员闭经或男运动员性功能/情绪异常，怀疑能量不足。
4. 需要把「过度训练/表现下降」与能量不足区分开。
5. 想知道什么时候必须停下来转诊。

**语言信号（中英双写）**：能量可用性 / 相对能量不足 / 能量摄入不够 / 闭经 / 月经失调 / 骨应力伤 / 吃得不够 / energy availability / EA / RED-S / low energy availability / LEA / 45 kcal / below 30 / amenorrhea / 转诊。

**与相邻能力的区分（初稿）**

- 与 **body-composition-intervention**：减脂干预归那张卡；本卡是「别减过头」的安全底线。

## E — 执行 (Execution)

**输入契约（必需字段）**
- 能量摄入（kcal/天）；运动净能量消耗（kcal/天）；去脂体重 FFM（kg）。
- **缺失须先询问，不得静默猜值**：若 FFM 未知 → 须体成分测量；若运动消耗未知 → **须用可直接测量的运动净消耗输入**（如代谢当量/测热），不得凭感觉估。
- 适用条件：运动员，尤其体重级别/瘦身导向项目；**有红旗症状时优先转诊**，计算不替代临床评估。

**步骤（每步有完成标准）**
1. **收集三项输入**——摄入、运动净消耗、FFM。完成标准：三项齐备并标注单位。
2. **算 EA**——公式 `EA = (摄入 − 运动消耗) ÷ FFM`；单位 kcal/kg FFM/天。完成标准：输出 EA 数值。
3. **对阈值判定**——`约 45` 为健康最优；`<30` 为严重 LEA（红旗）；`30–45` 表述为「亚临床 / 需警惕」。完成标准：输出判定类别。
4. **触发转诊判停**——若 EA `<30` 或出现红旗（闭经、反复骨应力伤、体重骤降）→ **停止自行干预，转诊多学科团队**（运动医学医师 + 注册营养师 + 心理/营养专业）。完成标准：输出转诊动作与对象。

**输出契约**
- 字段：`{EA(kcal/kg FFM/天), 判定(亚临床/严重), 是否转诊, 转诊对象}`。
- 单位：kcal/kg FFM/天。
- 容差：EA ±0.5。
- **约束（原文只给方向未给数值，不得静默补值）**：原文**未给**运动能量消耗的测算方法、**未给 30–45 过渡区的命名**、未给 `severe perturbations below 30` 的精确临床界值。本卡只做「45 / <30」阈值判定 + 「亚临床」表述，**不补造临床分级**。

## B — 边界 (Boundary)

- **不要**把 LEA/RED-S 当减重或纪律问题自行处理——须识别并升级转诊（`ce11-04`）。
- **不要**在缺少可靠运动消耗输入时凑数——原文未给测算方法，凭感觉估会把红旗算成正常。
- **不要**把 30–45 区间命名为临床诊断——原文未命名，本卡只作「需警惕」。
- **不要**只算 EA 就排除问题——异常进食模式或闭经单独出现不等于确诊，须由合格专业人员评估（见 eating-disorder-rwl-referral）。
- **作者盲点（3.1/3.3）**：EA 阈值（45/30）为共识值；原文承认 LEA 对运动表现的直接证据有限；常模/阈值有年代与人群前提。
- **专业边界（2.2-14）**：教练职责是识别、记录、通知团队并**转介**有资质的医疗/营养/心理团队；不诊断、不治疗。
- **相邻易混**：与 **eating-disorder-rwl-referral** 分工——本卡量化 LEA，那张卡处置进食障碍/RWL。
