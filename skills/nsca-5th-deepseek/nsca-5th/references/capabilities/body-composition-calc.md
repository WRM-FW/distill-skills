# 体成分估算计算（皮褶→体密度→体脂% + SEE 区间）

## R — 原文 (Reading)

> "the minimum SEE for population-specific skinfold equations is ±3% to ±5%. Therefore, if a 25-year-old male athlete's body fat is measured at 24%, there is a minimum of a 6% range (21%-27%)."

— Chapter 14 · Body Composition（`ch14.txt:1505-1507`）

## I — 自述 (Interpretation)

体脂估算走**两步法**，再按 SEE 报区间：

1. **由皮褶算体密度 Db**：按被测人群从**表 14.35** 选方程，用各位点皮褶和 ΣSKF（mm）与年龄代入，得 Db(g/cc)。Jackson-Pollock 型形式：`Db = 常数 − k₁·ΣSKF + k₂·ΣSKF² − k₃·age`。
   - 例（男性 18–61 岁，Σ3SKF = 胸+腹+大腿）：`Db = 1.109380 − 0.0008267·Σ + 0.0000016·Σ² − 0.0002574·age`。
2. **由 Db 算体脂率 %BF**：按人群从**表 14.36** 选两分模型公式：`%BF = (a/Db) − b`，**再 ×100** 得百分比。
   - 例（白人 18–59 岁男性）：`%BF = (4.95/Db) − 4.50`。
3. **报区间（强制）**：**无普遍接受的体成分常模**；须计入估计标准误 SEE，**报告一个区间**。人群特异皮褶方程的最小 SEE 为 **±3%–±5%**，故测得 24% 时至少报 6% 宽的区间（21%–27%）。

## A1 — 案例 / 演练 (Application)

**原书案例（worked-example，`c14-04`/`c14-05`）**：
- `c14-04`：25 岁男性测得体脂 24% → 最小 SEE ±3% → 报告 **21%–27%**。
- `c14-05`：给出两步流程（表 14.35 算 Db → 表 14.36 算 %BF）与一组男性运动员方程，**原书未代入算出最终 %BF**。

**合成演练（明确标记，可复算）**：25 岁男性，Σ3SKF（胸+腹+大腿）= 40 mm，用白人男 18–59 岁方程。
- Db = 1.109380 − 0.0008267(40) + 0.0000016(40²) − 0.0002574(25) = **1.0724 g/cc**
  （独立核算 1.109380 − 0.033068 + 0.00256 − 0.006435 = 1.072437）。
- %BF = (4.95/1.0724 − 4.50) × 100 = **11.6%**（独立核算 4.6158 − 4.50 = 0.1158 → 11.58%）。
- 报告区间 ±3% → **8.6%–14.6%**。

**用户情境**：

4. 想把测得体脂 24% 换算成报告口径。

## E — 执行 (Execution)

**输入契约（必需字段）**：各位点皮褶（mm，已按 0.5 mm 平均）+ 年龄 + 性别 + 人群/种族（选方程）+ 所选运动专项（若用运动员方程）。**缺人群/性别/年龄须先问**，不得默认。

**步骤与完成标准**：
1. **求 ΣSKF**：按所选方程要求的位点求皮褶之和（mm）。完成标准：输出 Σ 与所用位点。
2. **选方程（表 14.35，按人群）**：输出 Db。完成标准：给出方程形式与系数，算出 Db(g/cc)。
3. **选公式（表 14.36，按人群）**：`%BF = (a/Db) − b`，**×100**。完成标准：输出 %BF（%）。
4. **报区间**：`区间 = %BF ± SEE`（SEE 至少 ±3%–5%）。完成标准：输出区间，宽度 ≥6%。
5. **输出**。

**输出契约**：`{ΣSKF(mm), 所选方程(表号), Db(g/cc), %BF(%), 区间(≥6%宽), SEE来源}`。

**舍入/容差**：Db 保留 4 位小数（g/cc）；%BF 保留 1 位小数；独立复算容差 ±0.2 个百分点。

**判停点/分支**：
- 未指定人群 → 不计算，先问（不同方程结果差异大）。
- 想直接报单点 %BF → 拒绝，强制带 SEE 区间。

**约定**：完整方程集须回查原表 14.35/14.36（`p14-33`/`p14-34`/`p14-35` gap，本卡按表号登记，不逐一抄录系数）；SEE"最小 ±3–5%"为一般口径，未逐一对应各方程。**不得由本卡补造方程**。

## B — 边界 (Boundary)

- **不要**把体脂当精确单点值报告——必须带 SEE 区间（`ce14-05`）。
- **不要**跨人群套用方程（如用白人男性方程算女性/其他族群）。
- **不要**在运动后/潮湿皮肤取的皮褶上直接套本卡（数源不可靠，见 `anthropometry-bodycomp-measure`）。
- **作者盲点（3.1/3.3）**：体脂无普遍常模；方程系数与 SEE 来自特定人群/年代。
- **专业边界（2.2-14）**：体成分异常的医学/营养解读须转诊，本卡只做计算与区间报告。
- **相邻易混**：与 `anthropometry-bodycomp-measure`（测量取数）分工——本卡只算数与报区间。
