# 过度训练恢复策略选择与恢复时长预期

## R — 原文 (Reading)

> "Once overtraining occurs and overtraining syndrome has developed, the first thing that must be done is a careful revision of the training program. A rapid decrease in the training volume, intensity, or both is typically warranted. … Regardless, decreasing or eliminating the training stress is mandatory when overtraining has occurred."

— Chapter 24 · Recovery Methods and Strategies（`ch24.txt` 第 931–947 行）

## I — 自述 (Interpretation)

恢复不是"选一个辅助手段",而是一条**有硬约束的优先级链**：

1. **第一位、且强制**：**修改训练计划**——迅速下调训练量、强度或两者；必要时停训。"降低或消除训练应力"是**强制项**（mandatory），不可绕过。
2. **训练性手段**：训练减量/taper（与"改计划"相关，"Strong"）。
3. **恢复模式**：按证据强度分层——优质睡眠（**Strong**）、正念类干预（Promising）、冷水浸泡（Promising）；床旁休息"有利损伤、不利体能"；按摩 Inconclusive；泡沫轴/加压/补水/针灸/红光（Possible）。
4. **饮食与补剂**：碳水化合物（Promising）、蛋白质/支链氨基酸/硝酸盐/L-谷氨酰胺/维生素/口服 ATP（Possible）。
5. **冷冻疗法**：冷水浸泡（Promising）、其他冷冻手段（Inconclusive）。
6. **恢复时长预期**（依程度）：功能性超量停药可达 **约 1 周**回原水平；重度过训练后，**高强度抗阻可达约 4 周**、**大容量长跑可达数月至一年**。

核心态度：**先把训练改对，再谈辅助**；辅助手段证据强度参差，不能替代"降低训练应力"。

## A1 — 案例 / 演练 (Application)

**原书素材（tabular-example · c24-1 / Table 24.4，`ch24.txt` 第 949–1022 行；worked-example · c24-2，第 934–947 行）**：Table 24.4 给出四类策略与有效性分级（Most strong/Strong/Promising/Possible/Inconclusive）；c24-2 给出恢复时间量级。**原书未给某个具体运动员的完整恢复过程**。

**合成演练（明确标记，按原书规则）**：一名抗阻训练者出现 NFOR：1RM 下降约 8%，减量 1 周未见超量恢复。
- 第一步：**修订训练计划**（降量/降强度，必要时停训）——强制项。
- 叠加：训练减量 taper → 优质睡眠（Strong）/正念（Promising）/冷水浸泡（Promising）等。
- 恢复时长预期：**可达约 4 周量级**（高强度抗阻重度过训练口径）。
- 若撤量 1 周即超量恢复 → 应属 FOR（见 U1），而非 NFOR/OTS。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 已确认/怀疑过度训练，问"**怎么恢复**、要不要减量、停多久"。
2. 问"**各种恢复手段（冷疗/按摩/睡眠/补剂）哪个有用**"。
3. 问"恢复**要多久**才能回到成绩"。
4. 训练者/家长想加"恢复产品",需要按证据强度取舍。

**语言信号（中英双写）**：怎么恢复 / 恢复策略 / 恢复手段 / 要减量吗 / 停训多久 / 恢复要多久 / 冷水浸泡 / 按摩 / 睡眠 / 恢复补剂 / recovery strategy / recovery methods / how to recover from overtraining / deload / taper / cold-water immersion / how long to recover。

**与相邻能力的区分（初稿）**：本卡管"**已发生 OT/OR 后的恢复处置**"。**命名分档**（是不是 OT、哪一档）→ `cap.nsca.overtraining-continuum-classification`；**归因排查**（到底是不是练过头）→ `cap.nsca.underperformance-attribution-triage`；**事前预防/整合恢复进训练** → `cap.nsca.overtraining-prevention-integration`。**与"周期化"不同**：那是计划编排（含计划性减量周），本卡是**异常状态下的纠偏处置**；**与"测试与评估"不同**：那是测量，本卡是处置。

## E — 执行 (Execution)

**输入契约（必需）**：已判定的档位（FOR/NFOR/OTS，来自 U1）；训练类型（抗阻/耐力/混合）；当前量/强度轨迹；可接受停训程度。**可选**：睡眠/营养状况、共病。

**步骤与完成标准**：
1. **强制第一步：修订训练计划**——迅速降低或消除训练量、强度或两者，必要时停训。完成标准：写出具体的量/强度下调方案；**未做此步不得进入下一步**。
2. **加训练性减量（taper）**。完成标准：写出 taper 结构（与第 1 步衔接）。
3. **按证据强度叠恢复模式**：优先 Strong（优质睡眠），再 Promising（正念、冷水浸泡），Possible/Inconclusive 项在资源允许时可选、须如实标注证据弱。完成标准：恢复手段分类列出，每项标有效性等级。
4. **饮食与补剂**：优先碳水（Promising），其余标 Possible。完成标准：逐项标等级，不夸大。
5. **给恢复时长预期**：据档位与训练类型给量级（超量约 1 周；重度过训练抗阻约 4 周、大容量长跑数月至一年）。完成标准：写出量级 + 依据。
6. **输出恢复方案**。

**输出契约**：`{训练计划修订(强制), taper 方案, 恢复模式清单+证据等级, 饮食补剂清单+等级, 恢复时长预期, 复查节点}`。
**约定**：恢复时长量级取自 `ch24.txt` 第 936–939 行（1 周 / 4 周 / 数月至一年），**为分程度量级而非精确值**；本卡不细化到天，不虚构个体精确恢复期。

**判停点/分支**：
- 无法修改训练（如赛季中不容许停训）→ 至少**降低**量/强度，并注明"未满足强制停产、风险自担"。
- 仅靠辅助手段、不动训练计划 → **驳回**（违反强制项）。
- 疑似 RED-S / 抑郁 / 医疗问题 → 转诊（`cap.nsca.rehab-scope-and-referral`）。
- 恢复后需防复发 → 交 `cap.nsca.overtraining-prevention-integration`。

## B — 边界 (Boundary)

- **不要**把恢复寄托在证据弱的辅助手段上——首位且强制的是"改训练"。
- **不要**在未修订训练计划时声称"在恢复"。
- **原文自认的证据强度弱（B 段主依据）**：`ch24.txt` 第 1024–1030 行直言"there are few data supporting these methods for this purpose"；Table 24.4 多为 Possible/Inconclusive——辅助手段**证据弱、非处方级**。
- **时长口径依赖训练类型**：1 周/4 周/数月至一年分别对应超量/高强抗阻/大容量耐力，**不可跨类型照搬**。
- **共识≠实证**：Table 24.4 的等级是文献汇总判断，非同质 RCT 结论。
- **专业边界**：疑似疾病/心理共病（RED-S、抑郁）须转诊，恢复方案不替代医疗。
- **相邻易混**：U1（分档）、`cap.nsca.overtraining-prevention-integration`（预防/整合）。
