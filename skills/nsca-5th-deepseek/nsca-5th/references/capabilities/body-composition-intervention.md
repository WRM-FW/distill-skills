# 体成分改变（增重 / 减脂）干预

## R — 原文 (Reading)

> "consume approximately 500 additional calories per day in order to gain weight ... 1.8 to 2.7 grams protein per kilogram body weight per day ... in addition to maintaining a moderate energy deficit of approximately 500 calories per day."

— Chapter 11 · Nutrition Strategies for Maximizing Performance（`ch11.txt:1263, 1337-1339`）

## I — 自述 (Interpretation)

把体成分干预统一到「先估能量需求 → 再按目标调能量平衡 ± 蛋白档」的框架：

- **第一步估需求**：Cunningham 方程（含 FFM）× 活动系数，或稳定体重期 3 天饮食记录法（见 macronutrient-energy-needs）。
- **增重路径**：约 **+500 kcal/天**（须依个体调整）；加大份量/餐次、选能量密度高食物；蛋白 **1.6–2.2 g/kg/天**（正常/高蛋白过量摄食者约 45% 多余热量存为瘦体重，低蛋白 5% 者 95% 存为体脂）；可辅**一水肌酸**（安全有效增瘦体重）。
- **减脂路径**：无「万能饮食」，**总热量与依从性是关键**（低碳/低脂只要热量低于维持需求即可减重，降幅无显著差异）；蛋白 **1.8–2.7 g/kg/天**（或约 2.3–3.1 g/kg FFM/天）以保肌；**中度热量缺口约 500 kcal/天**。
- **超重/肥胖初始目标**：**6 个月内减初始体重的 10%**；须筛查并存病（糖尿病、骨科、心脏、心理障碍如暴食障碍/抑郁）与改变意愿。
- **通用约束**：个体化、易依从、考虑生活方式与病史；用体成分（非仅 BMI）核对目标；`目标体重 = FFM ÷ (1 − 期望体脂%)`。

## A1 — 案例 / 演练 (Application)

**原书未给增重/减脂的数值算例**；`ce11-02` 提示「饮食记录会改变真实进食」（估算陷阱）。以下为**明确标记的合成演练**，按原文规则复算。

**合成演练（标记：合成；可复算）**
- 输入：85 kg 运动员，体脂 20%（FFM = 68 kg），目标增肌。
- 执行：
  (a) 每日 **+500 kcal**；
  (b) 蛋白 1.6–2.2 g/kg = **136–187 g/天**；
  (c) 可选一水肌酸；
  (d) 用目标体重式核对（目标体脂 15% → 68/(1−0.15) = **80 kg** 去脂体重占比口径）。
- 容差：蛋白区间照原文 g/kg；目标体重 ±0.5 kg。
- 原书未说明该合成输入的「实际结果」，此处为按原文档位复算。

## A2 — 未来触发 (Trigger)

**用户情境（3–5 条）**
1. 运动员想增重/增肌或减脂保肌，问热量与蛋白怎么调。
2. 问「增重每天多吃多少」「减脂每天少吃多少」。
3. 要按目标体脂反推目标体重。
4. 超重/肥胖者要设初始减重目标。
5. 问增重要不要补肌酸、减脂要不要换特殊饮食。

**语言信号（中英双写）**：增重 / 增肌 / 减脂 / 保肌 / 热量缺口 / 每日多吃 / body composition / weight gain / weight loss / energy deficit / 500 calories / 1.6-2.2 g/kg / 1.8-2.7 g/kg / target body weight / lean mass。

**与相邻能力的区分（初稿）**
- 与 **macronutrient-energy-needs**：能量需求估算与 g/kg 档位归那张卡，本卡给 ±500 kcal 干预。
- 与 **competition-nutrition-timeline**：赛时时机归那张卡。
- 与 **eating-disorder-rwl-referral**：危险减重属安全卡，本卡不含快速减重旁路。

## E — 执行 (Execution)

**输入契约（必需字段）**
- 性别/体重/身高/年龄；体成分（FFM 或体脂率）；训练负荷；目标（增肌/减脂/两者）；病史与用药；饮食史与偏好；目标体成分标准（队/项目/位置常模）。
- **缺失须先询问，不得静默猜值**：若 FFM/体脂未知 → 须体成分测量，不可默认；若目标方向未知 → 问增肌/减脂；若有进食障碍史或疑似 → 走转诊。
- 适用条件：健康运动员与超重/肥胖人群；肥胖者须先筛并存病。

**步骤（每步有完成标准）**
1. **估能量需求**——Cunningham（`RMR = 500 + 22×FFM`）× PAL，或 3 天饮食记录法。完成标准：输出 TDEE（kcal/天）。
2. **选方向并调能量**——增重 `+500 kcal/天`；减脂 `−500 kcal/天`。完成标准：输出每日目标热量。
3. **定蛋白档**——增重 1.6–2.2 g/kg；减脂 1.8–2.7 g/kg（或 2.3–3.1 g/kg FFM）。完成标准：输出蛋白克数区间。
4. **核对目标体成分**——用 `目标体重 = FFM ÷ (1 − 期望体脂%)`；超重/肥胖者设「6 个月减 10%」初始目标。完成标准：输出目标体重/减重目标。
5. **可选补充**——增重可辅一水肌酸。完成标准：输出建议并说明证据。

**输出契约**
- 字段：`{TDEE, 目标热量, 蛋白(g/kg, g/天), 目标体重, 补充建议}`。
- 单位：kcal/天；g/kg/天；kg。
- 容差：热量取整到 50 kcal；蛋白区间照原文；目标体重 ±0.5 kg。
- **约定**：`p11-20` 目标体重式原文写作 FFM/[100−期望体脂%]，**百分号口径有歧义**——本卡按 `FFM ÷ 期望去脂体重占比` 处理并标注；期望体脂须依测量方式（ADP/DXA/皮褶）与专项常模，原文未给具体数值。
- **约束（原文只给方向未给数值，不得静默补值）**：原文明确「无理想饮食」，**未给剂量—反应关系**；`ce11-02` 记录法会改变真实进食（估算失真）；体脂下降上限等受营养/训练量影响。

## B — 边界 (Boundary)

- **不要**依赖连续饮食记录反推需求而不顾记录本身对进食的干扰（`ce11-02`）。
- **不要**相信「存在万能减脂饮食」——总热量与依从性才是关键。
- **不要**用单一身体成分指标评估健康/疾病风险。
- **不要**把本卡用于体重级别项目的**快速减重**——那是高风险旁路，走 eating-disorder-rwl-referral。
- **作者盲点（3.1/3.3）**：±500 kcal 等为经验惯例（共识）；「无理想饮食」意味着个体响应差异大。
- **专业边界（2.2-14）**：并存病与进食障碍须转诊。
- **相邻易混**：与 **macronutrient-energy-needs** 分工——本卡做干预，那张卡算需求。
