# NSCA 测试、评估与数据解释（完整流程）

## R — 原文 (Reading)

> "The scientific process of testing should begin with identifying clear questions that physical testing can answer, based on observations specific to the context of the athlete and his or her sport. Without establishing clear questions (the rationale) for physical testing, there is a risk of testing athletes for the sake of it, which is both inefficient and potentially unethical."

— Chapter 13 · Principles of Test Selection and Administration（`ch13.txt:354-357`）

## I — 自述 (Interpretation)

这是一条把"要不要测、测什么、怎么测、怎么读"串起来的完整决策链，而不是某一项测试的操作说明。它的整体逻辑是**问题先于工具、证据先于习惯、决策先于数值**：

1. **为什么测**——先明确要回答的清晰问题（rationale），否则就是为测而测（既低效、又可能不合伦理）。测试要服务于"需求分析→处方→反馈"闭环。
2. **测什么**——两道筛子：先过**效度/信度/客观性**门槛（稳 ≠ 准；信度是效度的必要非充分条件），再按**专项特异性**（供能系统 + 生物力学动作模式）+ 经验/训练状态/年龄/性别/环境，拼成覆盖式测试电池。
3. **怎么实施**——排序（后测不受前测疲劳污染）、休息、测试员分工与培训、运动员准备、记录与环境标准化；一次只让一个测试员负责一项。
4. **怎么算与怎么读**——描述统计与 z 分数做标准化、SWC/效应量判幅度意义、常模表做百分位比较、合成可决策的**运动员画像**；并把结果用于识别强弱项、指导编程。
5. **安全红线**——识别红旗症状并转诊，区分热病与低钠血症（后者**绝不补液**）。

贯穿全链的四条判据：**有效性、可比性、实践意义、专业边界**。

## A1 — 案例 / 演练 (Application)

**类型：worked-example（`c14-05` 体成分两步法）＋ sample-program（`c14-11` 运动员画像）。**

- **体成分两步法（原书流程 `c14-05`）**：① 按人群从表 14.35 选方程，用皮褶和 ΣSKF 算体密度 Db（g/cc）；② 把 Db 代入表 14.36 两分模型 %BF = (a/Db − b) × 100。**报告必须带 SEE 区间**（人群特异方程最小 ±3%–5%，如 24% → 21%–27%）。
- **运动员画像（原书样例 `c14-11`）**：摔跤选手电池含拉力量、推力量、局部肌耐力；示例测试俯卧撑 + 仰卧起坐，**两项间隔 ≥10 min**；六步为——选贴近专项的测试 → 选有效可靠测试并按序留足休息 → 尽量多人施测 → 定 SWC 并对照常模（建议自建）→ 重复测试并可视化 → 用结果识别强弱项并改进计划。
- 数值演练可复算示例：MAS = 16 km/h → VO2max = 3.5 × 16 = 56；纵跳 SD 10 cm → SWC = 2 cm；卧推 104.5→111.7 kg、SD 5.7 → ES = 1.26。

## E — 执行 (Execution)

**输入契约（必需字段）**：`目标/待回答的问题` + `专项与位置` + `运动员（年龄/性别/训练状态/经验/损伤史）` + `可用场地器材与人员` + （若解读）`测试成绩与施测条件`。**缺失关键字段（尤其"要回答什么"与受测者属性）须先询问，不得静默猜值**。

**整体流程（每步有可判断完成标准）**：

**A. 为什么测**
1. 写下测试要回答的**清晰问题（rationale）**，绑定需求分析与处方闭环。完成标准：输出 1–3 条可被测试回答的问题；写不出 → 停止，先厘清问题。

**B. 测什么（选择）**
2. **效度/信度/客观性门槛**：逐候选勾选——稳（信度）≠准（效度），先过信度门再过效度门；均达标取更简单经济者。完成标准：每个候选给出"采用/拒绝 + 理由"。
3. **专项特异性 + 适用性过滤**：按供能系统 + 动作模式（动作模式/肌群/供能系统/技能复杂度四维查覆盖）选电池；再按经验/训练状态/年龄/性别/环境过滤（如 1.5-mile 跑对青春期前不适用）。完成标准：输出覆盖无盲区的电池 + 排除项理由。

**C. 怎么实施**
4. **排序**：非疲劳 → 敏捷 → 最大功率/力量 → 冲刺 → 局部肌耐力 → 疲劳性无氧 → 有氧；疲劳/有氧尽量另日。完成标准：单日排序串 + 跨日拆分建议。
5. **休息**：试次间非极限 ≥2 min、接近最大 ≥3 min、电池内测试间 ≥5 min（磷酸原 3–5 min、糖酵解 ≥1 h 恢复）。完成标准：每个间隔给具体分钟数。
6. **测试员/准备/记录/环境**：同一测试尽量同一人施测、每人同时只负责一项、需判断的交最熟练者、新手先做一致性校验；提前公布日期与目的、T-3 天熟悉课、统一讲解与热身、固定同一时段并尽量室内；记录表须含全部成绩 + 环境（温湿度/海拔）+ 设备设置 + 备注。完成标准：产出分工表 + 准备清单 + 记录表字段集。

**D. 怎么算与怎么读**
7. **描述统计与标准化**：`x̄`、`SD = √(Σ(x−x̄)²/(n−1))`、`z = (x−x̄)/SD`；注意指标方向（时间类越小越好）。完成标准：输出组内分布与各人 z。
8. **幅度意义**：`SWC = 0.2 × between-subjects SD`；`ES = (x̄_post − x̄_pre) / SD_pre`；锚点 0.2/0.6/1.2/2.0。完成标准：给出"是否有实践意义"判断。
9. **常模比较**：按项目/年龄/性别选表，定位百分位并赋描述词（90 远高/70 高/50 平均/30 低/10 远低）；标注表性质（描述性 vs 规范）。完成标准：输出百分位 + 描述词 + 表性质与可比性提示。
10. **运动员画像**：六步合成可决策画像（选测→排序留足休息→多人施测→定 SWC 对照常模→重复测试可视化→用于编程）。完成标准：输出可视化画像 + 排序后的强弱项清单。
11. **单项换算子例**：MAS→VO2max = 3.5 × MAS；体成分两步法（皮褶→Db→%BF，带 SEE 区间）；Margaria P=(w×h)/t；RSI = 跳高 ÷ 触地时间；EUR = CMJ ÷ 蹲跳。完成标准：输出数值 + 单位 + 容差。

**E. 安全红线**
12. **红旗识别与转诊**：持续红旗（胸痛/意识模糊/眩晕/皮肤深红湿冷/脉搏不规则等）→ 转诊；单次严重（如丧失意识）→ 立即就医；低钠血症（极清亮尿 + 皮肤胀 + 意识改变、**体温不升**）→ **绝不补液**、立即交医师。完成标准：输出明确处置动作 + 与热病的关键鉴别点。

**输出契约**：`{测试问题, 电池（含效度信度门槛与适用性）, 实施安排（排序/休息/分工/准备）, 数据解读（描述统计/z/SWC/ES/常模/画像）, 安全提示}`。

**容差与约定**：MAS→VO2max 容差 ±1 mL·kg⁻¹·min⁻¹；ES/SWC 判定容差 ±0.01；Margaria 功率容差 ±1%。原文未规定的实现约定（如取最佳 vs 平均、RSI 单位）须**显式标为约定**。

**分支/判停**：缺"要回答什么"或受测者属性 → 先问再做；出现红旗 → 立即转诊并停测（安全优先于数据）；1.5-mile 跑得的 VO2max → **只能查表（14.22–14.25），不得自拟合**。

## B — 边界 (Boundary)

- **常模时效性与人群依赖性（BOOK_OVERVIEW 3.1）**：第 14 章常模/描述性表来自特定年代、队伍与协议，跨年代/地区套用会失真，用前须核对样本、协议与设备。
- **"描述性"≠"规范性"**：部分表明确标注 descriptive, not normative，不得当标准常模。
- **共识 ≠ 实证（3.3-5）**：不少参数（进阶幅度、SWC 其他算法、RSI 阈值）以惯例出现，未必有直接证据，勿当定律。
- **单次数据意义有限（3.3-2）**："低于常模"不等于"需要干预"；须结合趋势、专项需求与个体响应。
- **测量不能替代训练判断**：测试是决策输入而非决策本身；教练经验与个体响应须参与解读。
- **迁移不保证（3.3-1）**：体能测试改善不自动等于专项表现提升，须专项验证。
- **变量耦合（3.3-3）**：测试/训练变量强耦合，不可把单一参数孤立套用。
- **专业边界（2.2-14）**：出现红旗症状、营养/心理/医疗问题一律**转诊**，越界处置是失职。
- **法域与场馆语境（3.2）**：管理/政策类内容属北美体系，跨法域须重新校验。
- **1.5-mile 无沟通径约束**：1.5 英里跑推算 VO2max 原文只给查表、无回归式，**不得自行拟合**；单位换算常数原文两处不一致（相对力量 4.44/9.81 vs Margaria 4.45/9.807），本卡统一取 kg × 9.81、lb × 4.448。
- **相邻易混**：本入口管全流程编排；具体单项协议与单项换算为可在本链内调用的子步骤，不必另立入口。
