# 跳跃与下肢爆发力测试协议族

## R — 原文 (Reading)

> "jump height values from jump-and-reach tests should not be compared directly to, or used interchangeably with, jump height values recorded with such technologies or, indeed, with different jump techniques, such as when keeping arms akimbo."

— Chapter 14 · Vertical Jump（`ch14.txt:714-717`）

## I — 自述 (Interpretation)

一组测下肢爆发力/拉长-缩短循环的跳跃测试，共享"取三次最佳 + 固定计分精度"结构：

| 测试 | 关键参数 | 计分/指标 |
|---|---|---|
| 纵跳（CMJ，含反向动作） | 力台标定归零；墙+粉笔两次标记高度差；Vertec 站立触高与跳后触叶高度差；手固定于髋 | 取三次最佳，精确到 0.5 in / 1 cm |
| 深蹲跳（静力跳） | 去掉反向动作，蹲至膝角约 **110°** 保持 **2–3 s** 后跳，手固定于髋 | 取三次最佳；EUR = CMJ 高 / 蹲跳高 |
| 落地跳（drop jump） | 从 8/12/16 in 箱齐高**迈出自由下落**（非跳下/走下），落地后尽快再跳，追求短触地时间与高跳 | 跳高、触地时间、RSI = 跳高 / 触地时间 |
| 连续反弹跳 | 先一次最大 CMJ，再若干次反弹跳（如 10-5 测试 = 10 次） | RSI；10-5 取最佳 5 次 RSI 平均 |
| 立定跳远 | 起点线后反向动作向前跳；**双脚落地**方计分，否则重跳；后脚跟最后缘放标记 | 三次取最佳，精确到 0.5 in / 1 cm |

**可比性约束（关键）**：摸高式（jump-and-reach）与力台/接触垫测得的跳高**不可直接比较或互换**（前者"手触墙瞬间 ≠ 重心最高时刻"、肩活动度受限）；不同起跳技术（如手叉腰）之间也不可直接比较。每跳须记录是否含摆臂（Abalakov）。

## E — 执行 (Execution)

**输入契约**：测试名（纵跳/深蹲跳/落地跳/反弹跳/立定跳远）+ 设备（力台/墙+粉笔/Vertec）+ 试次数据。缺"设备"须先问（因可比性依赖设备）。

**步骤与完成标准**：
1. **选测法与设备**并说明测量参考点。完成标准：写明"相对起跳高度"还是"相对站立高度"。
2. **纵跳**：标定归零（或准备墙/Vertec）→ 反向动作尽力跳（手固定于髋或记录摆臂）→ 取三次最佳，0.5 in/1 cm。完成标准：给出跳高 + 是否摆臂。
3. **深蹲跳**：去反向动作，蹲至膝角约 110°、保持 2–3 s 后跳，手固定髋 → 三次最佳；算 EUR。完成标准：给出蹲跳高与 EUR。
4. **落地跳**：从箱齐高迈出自由下落，落地尽快再跳，≥2–3 组 → 记录跳高、触地时间、RSI。完成标准：给出三指标。
5. **反弹跳（10-5）**：取最佳 5 次 RSI 平均。完成标准：给出平均值。
6. **立定跳远**：双脚落地才计分，后脚跟最后缘标记 → 三次最佳，0.5 in/1 cm。完成标准：给出距离。
7. **可比性声明**：报告时说明测量方式，不跨设备/技术互换比较。完成标准：声明写入输出。
8. **输出**。

**输出契约**：`{测试名, 设备/测法, 试次原始值, 结果(跳高/EUR/RSI/距离), 计分精度, 可比性声明}`。

**判停点/分支**：
- 跨设备/跨技术的跳高被要求比较 → 判"不可直接比较"，要求同法重测。
- 立定跳远未双脚落地 → 该次无效、重跳。
- 深蹲跳检出反向动作（肉眼 + 力-时曲线）→ 该次无效。

**约定**：原文未给三种纵跳测法之间的换算关系，也未给落地跳/反弹跳的组数上限与休息（仅"至少 2–3 组"）（`f14-07` gap）。本卡不虚构换算。

## B — 边界 (Boundary)

- **不要**跨设备/跨技术直接比较跳高（摸高 vs 力台 vs 叉腰）——`ce14-03`。
- **不要**用接触垫估算的跳高去推断力输出（开关/接触垫只能估高度，不能测力）。
- **作者盲点（3.3-1）**：跳高改善不自动迁移到专项；碰撞类项目可能"绝对功率提升"更重要（`ch14.txt:101-105`）。
- **体重操纵（原文强调）**：增重后同样跳高意味着功率提升，解读时须联动体重。
- **常模时效（3.1）**：跳跃常模表有年代/人群依赖，跨项目/年代套用须审慎。
- **相邻易混**：与 `rsi-eur-calculation`（只算数值）不同——本卡管施测与计分。
