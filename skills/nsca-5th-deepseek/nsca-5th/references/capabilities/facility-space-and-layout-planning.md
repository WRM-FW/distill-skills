# 场地空间估算与设备布置（Table 25.1 / 25.2 计算与设施规格）

## R — 原文 (Reading)

> "If using a 6 ft long weight bench and a 7 ft Olympic bar for the bench press exercise: DEPTH: (6 ft [bench] + 3 ft [safety cushion]) × WIDTH: (7 ft [bar] + 6 ft [double-wide safety cushion]) = 117 ft2."

— Chapter 25 · Arranging Equipment / Table 25.2（`ch25.txt` 第 896–899 行）

## I — 自述 (Interpretation)

把"空间够不够"变成**可核算的公式**。先记一条总基线：**每人最低 100 ft²（9.3 m²）**（含运动员、教练及在场其他人员）。

**Table 25.2 各动作类型空间公式（DEPTH × WIDTH；landmine 用圆面积÷4）**：
- **俯卧/仰卧杠铃动作**（卧推、仰卧三头、臀推）：`DEPTH = 凳长(6–8 ft) + 3 ft 缓冲`；`WIDTH = 杠长(4–7 ft) + 6 ft 双侧缓冲`。无凳的卧地杠铃动作用**运动员身高**作 DEPTH。
- **站姿动作**（弯举、直立划船）：`DEPTH = 2 ft 用户空间 + 3 ft 缓冲`；`WIDTH = 杠长(4–7 ft) + 6 ft 双侧缓冲`。（哑铃/壶铃无杠时 WIDTH 用 2 ft。）
- **架内站姿动作**（后蹲、肩推）：`DEPTH = 用户空间 8–10 ft`；`WIDTH = 杠长(5–7 ft) + 6 ft 双侧缓冲`。
- **举重动作**（高翻、抓举）：内嵌橡胶地面 `DEPTH = 用户空间 8–10 ft`；抬升木台 `DEPTH = 台长(约 8 ft) + 3 ft 缓冲`；WIDTH = 杠长(6–7 ft 或台宽约 8 ft) + 6 ft 双侧缓冲。
- **地雷管**：`(π × [杠长 + 用户空间 2 ft + 缓冲 3 ft]²) ÷ 4`（π 取 3.14；因需 90° 活动=1/4 圆）。
- **悬吊训练**：`DEPTH = 足位距锚点距离 + 运动员身高 + 3 ft 缓冲`；`WIDTH = 用户空间 2 ft + 6 ft 双侧缓冲`。

**布置与设施规格要点**：设备成组分区（热身/敏捷/自由重量/有氧/器械）；器械间**至少 3 ft（0.9 m）**；主通道**5–7 ft（1.5–2.1 m）**；器械站间**≥30 in，36 in 更佳**；层高 **12–14 ft（3.7–4.3 m）**；照明一般区 **20–30 fc**、抗阻/团操区至 **50 fc**；温度 **68–74 °F（20–23 °C）推荐**；相对湿度 **≤60%**；换气 **8–10 次/h，最优 12–15 次/h、每 1,200 ft² 2–4 风扇**；镜面离地 **≥20 in**；悬吊锚点 **7–9 ft、承重件 5,000 lb（22 kN）**；坡道 **1:12**；楼层承重 **≥100 ft-lb/ft²（4.8 kN/m²）**。有氧单机面积见 **Table 25.1**（如直立自行车 30 ft²、跑步机 53 ft²）。

## A1 — 案例 / 演练 (Application)

**数值演练（合成，按 Table 25.2 公式复算）**：
1. 5 ft 弯举杠站姿弯举：`(2+3)×(5+6) = 5×11 = 55 ft²`。
2. 6 ft 杠、8 ft 用户空间的架上深蹲：`8×(6+6) = 96 ft²`。
3. 5 ft 杠地雷管：`(3.14×[5+2+3]²)/4 = 3.14×100/4 = 78.5 ft²`。
4. 同场 24 人最低面积：`24×100 = 2,400 ft²`。

**原书素材（worked-example · c25-1，`ch25.txt` 第 888–1004 行）**：卧推 6 ft 凳 + 7 ft 杠 = **117 ft²**；7 ft 杠地雷管 **≈113 ft²**；悬吊（6 ft 高、足离锚 3 ft）**= 96 ft²**；并给出公制近似（如卧推 9 m²、地雷管 ≈12.5 m²）。**原书案例为演算样例，未涉及真实场馆建设结果。**

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 要规划/核算举重房、训练场**面积够不够**。
2. 问"某个动作需要多大空间、安全缓冲多少"。
3. 问"多少人需要多大场地、器械间距/通道多宽"。
4. 要布置器械、定分区与动线。
5. 想知道层高/照明/温湿度/镜面/锚点等**设施规格**。

**语言信号（中英双写）**：场地面积 / 空间够不够 / 需要多大 / 器械间距 / 通道宽度 / 每人多少平方 / 安全缓冲 / 层高 / 布置 / 动线 / 分区 / facility space / square footage / safety cushion / walkway width / equipment layout / ceiling height / per person 100 sq ft。

**与相邻能力的区分（初稿）**：本卡管"**空间估算与布置（可核算部分）**"。**设施设计流程/需求评估/运维**属 reference（U13，未出卡）；**政策手册**属 reference（U14）；**风险管理/过失** → `cap.nsca.risk-management-and-negligence`；**应急预案** → `cap.nsca.emergency-action-plan`。**与"测试与评估"不同**：那是测量能力，本卡是空间核算；**与"周期化"不同**：那是计划编排。

## E — 执行 (Execution)

**输入契约（必需）**：**动作类型**（决定用哪条公式）；**器材尺寸**（凳长、杠长、台尺寸，ft/m）；**人数**（峰值同时使用数 + 总人数）；单位（英制/公制须统一）。**可选**：运动员身高（悬吊/卧地动作用）、建筑结构（柱/梁位置）。
- **缺失处理**：缺器材尺寸 → 用原文范围值并**标注为范围**；缺人数 → 无法算总量，先问。**不得**静默假设。

**计算步骤与完成标准**：
1. **选公式**：按动作类型从 Table 25.2 取对应式。完成标准：写明所用公式。
2. **代入尺寸**（DEPTH × WIDTH；landmine 用 `(π·r²)/4`，π=3.14）。完成标准：给出单动作面积（ft² 或 m²）。
3. **算设施总量**：总最低面积 = **人数 × 100 ft²**；有氧区另按 Table 25.1 单机面积 × 台数。完成标准：给出总需求面积。
4. **核对规格**：器械间距 ≥3 ft、通道 5–7 ft、站间 ≥30/36 in、层高 12–14 ft、照明/温湿度/换气等。完成标准：逐项核对并标"符合/不符"。
5. **布置与动线**：成组分区、留主通道、确保随时可达出口。完成标准：给出分区与动线草图要点。
6. **输出方案**。

**输出契约**：`{动作类型→公式→单动作面积, 总需求面积, 规格核对表, 分区/动线要点, 单位与范围标注}`。
**舍入/容差**：landmine 取 π=3.14，容差 **±0.5 ft²**；英制↔公制按原文近似（如 100 ft²=9.3 m²），**换算为近似值**。

**判停点/分支**：
- 单位不统一 → 先统一再算。
- 面积不足 → 优先保障安全间距与出口，**不得**牺牲 safety spacing（原文：安全间距绝不因空间受限而妥协）。
- 需改造既有建筑/涉及建筑规范 → 超出本卡，属设施设计流程（reference）+ 建筑/法务。

**语境依赖（逐条标注，跨法域须重新校验）**：
- **全部为美国标准与英制口径**：**ADA**（坡道 1:12、轮椅可达、电话/开关/AED 可达）、**OSHA**（悬吊连接件 ≥5,000 lb/22 kN；美国外参照 CE 等第三方评级）、**ANSI/ASHRAE 62.1**（健康俱乐部/举重房换气）、消防/城市规范（最大容纳人数）。
- **跨法域使用需重新校验**：坡道比例、承重、换气、电气（GFCI）、照明、无障碍标准在不同国家/地区**不同**，不可直接照搬。

## B — 边界 (Boundary)

- **不要**牺牲安全间距/通道/出口来迁就面积不足。
- **不要**把美国规范数值当普适律——**ADA/OSHA/ANSI-ASHRAE 与英制**均为美国语境。
- **原文自认/结构性局限（B 段主依据）**：所有规格为**美国法规与场馆语境**（BOOK_OVERVIEW 3.2 西方/北美语境）；**跨法域须重新校验**（不是缺陷，但须如实呈现）。
- **图未展开**：Figure 25.2（改造步骤）与部分布置仅在图、正文未展开，本卡不臆补。
- **变量耦合**：面积、间距、动线、监督视线、出口可达互相牵制，单独优化某一项会损害别项。
- **迁移**：非场馆/居家/户外场景的规格不同（原文另有户外训练空间的专门注意事项）。
- **相邻易混**：设施设计流程（reference）、`cap.nsca.risk-management-and-negligence`（责任）、`cap.nsca.emergency-action-plan`（出口/通道与 EAP 相关）。
