# 最大力量测试协议族（1RM / IMTP / 北欧腘绳肌）

## R — 原文 (Reading)

> "To express the same from an isometric test, maximal force exerted in newtons is divided by bodyweight converted into newtons (lb × 4.44, or kg × 9.81). ... A quiet standing period of 1 s with >50 N change in force; Pre-tension (<50 N) while maintaining a rigid torso before initiating force application; A countermovement prior to the onset of force application; Peak force at the end of the pull"

— Chapter 14 · Maximum Muscular Strength / IMTP（`ch14.txt:64-66, 546-549`）

## I — 自述 (Interpretation)

最大力量测试分**动力（低速度力量）**与**等长**两条线，各有一套可复制的协议：

- **1RM（动力）**：先学正确技术 → 5–10 次轻到中等专项热身 → 至少 2 组较重热身（每组 2–5 次）→ 首次试举约取**估计 1RM 的 50%** → 按恢复感与上次轻松度逐次加重，间隔 1–5 min → 熟练者在热身后 **3–5 次试举内**把 1RM 定到真值数个百分点内。角色：卧推 1 名保护者 + 1 名记录员；深蹲 2 名保护者 + 1 名记录员。
- **相对力量（比值标准化）**：动力 = 举重 ÷ 体重（同单位）；等长 = 最大力(N) ÷ 体重换算成 N（lb×4.44 或 kg×9.81）。简单比值假设"力量与体重成正比"，未必成立 → 体型差异大时另做幂函数标度。
- **IMTP（等长中大腿拉）**：架高到模拟举重"second pull"位（杠在大腿上部、紧邻骨盆下）；躯干直立、约髋宽、clean 握法 + 拉力带；≥3 次最大用力试次，间隔 1–2 min；测峰值力每试次 3–5 s，测 RFD 则 ≤1 s；峰值力波动 >15% 补测。**四类试次须剔除**：静站 1 s 内力变化 >50 N；发力前有 <50 N 预张力；发力前有反向动作；峰值力出现在拉的末端。指标：峰值力、时点力(50/100/150/200/250 ms 或 0–50…0–250 ms)、RFD(20 ms 窗)、冲量。
- **北欧腘绳肌（离心）**：跪位、踝置于钩下，仅踝后侧接触钩、勿脚尖借力；控制下前倾（膝伸展、膝到肩成一线）；无仪器时以 **break point angle** 作离心力量中等代理。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 要测 1RM，问热身、首次负荷、加重幅度、试举次数。
2. 用等长设备（力台/IMTP）测最大力，问协议与哪些试次该剔除。
3. 要算相对力量，问体重归一化口径。
4. 用北欧腘绳肌测离心力量，问摆位与指标。

**语言信号（中英双写）**：1RM / 最大力量 / 卧推 / 深蹲 / 高翻 / 等长 / IMTP / 力台 / 相对力量 / 体重归一化 / max strength / relative strength / isometric / peak force / 剔除试次 / 预张力 / Nordic hamstring / break point angle。

**与相邻能力的区分**：本卡管"直接测最大力量"；用负荷-速度剖面估 1RM 属 `load-velocity-profile`（且被禁用）；跳跃/爆发力属 `jump-power-test-protocols`；统计解读属 `descriptive-stats-athletic-profile`。

## E — 执行 (Execution)

**输入契约**：动作（卧推/深蹲/高翻/IMTP/北欧）、估计 1RM 或设备读数、体重、试次数据。缺"动作"与"体重/单位"须先问。

**步骤与完成标准**：
1. **选口径**：动力用 1RM 协议，等长用 IMTP 协议。完成标准：明确选用哪族。
2. **1RM 路径**：按"轻热身 → ≥2 组较重热身 → 首试 ≈50% 估计 1RM → 逐次加重 → 3–5 次内定位"。完成标准：写出每次负荷与休息（1–5 min），最终给 1RM。
3. **IMTP 路径**：设位 → ≥3 次最大用力试次（间隔 1–2 min；峰值力 3–5 s / RFD ≤1 s）→ 逐试次筛查四类剔除信号。完成标准：给出有效试次集合与报告指标。
4. **一致性校验**：各试次峰值力极差 (max−min)/max ≤15%。完成标准：≤15% 判合格；>15% → 加测。
5. **相对力量换算**：等长相对力 = 力(N) / (体重换算为 N)。**单位口径（原文不一致，本卡采用）**：`kg × 9.81`、`lb × 4.448`。完成标准：给出相对力数值（N/kg 或无量纲）。
6. **输出**。

**输出契约**：`{动作, 1RM 或峰值力, 有效试次数, 剔除试次与原因, 相对力量, 单位换算口径}`。

**判停点/分支**：
- 某试次命中四类剔除信号之一 → 丢弃并补做。
- 有效但峰值力波动 >15% → 加测。
- 1RM 尝试超过 5 次仍未定位 → 停止（疲劳会拉低结果）。

**单位口径（必须显式）**：原文两处重力常数不一致——`p14-02`（相对力量）用 `lb×4.44 / kg×9.81`，`p14-09`（Margaria 功率）用 `lb×4.45 / kg×9.807`。**本簇统一采用 SI 标准 g=9.80665 → kg×9.81、lb×4.448**，差异 <0.2%。此为实现约定。

**其他约定**：原文只定性写"somewhat"（递增幅度无精确表）、幂函数标度指数"仍存争议"（无数值）、北欧组间休息未给。本卡不虚构这些数值。

## B — 边界 (Boundary)

- **不要**用负荷-速度剖面估算 1RM（会系统性高估，`ce14-01`）；最大力量须直接测。
- **不要**忽略 IMTP 试次筛查，含预张力/预反冲的试次不代表真实最大等长力（`ce14-07`）。
- **不要**把简单比值标准化当"消除体重影响"的普适解；体型差异大时用幂函数标度，且指数仍有争议（`p14-03`）。
- **作者盲点（3.3-5）**：递增百分比、幂指数等含"惯例"成分，共识 ≠ 实证。
- **迁移不保证（3.3-1）**：gym 里 1RM 提高不自动转化为专项表现。
- **专业边界（2.2-14）**：北欧腘绳肌、IMTP 数据解读不等于医疗康复处方。
- **单位冲突**：务必按本卡口径换算，勿混用两处常数。
