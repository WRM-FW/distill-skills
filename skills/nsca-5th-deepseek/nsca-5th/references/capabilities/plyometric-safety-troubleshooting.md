# Plyometric 安全与常见错误排障：技术/落地/ACL + 深跳高度/体重 + 场地器材

## R — 原文 (Reading)

> "Inward movement of the knees—also termed dynamic valgus—is a significant risk factor for knee injuries of all types, including patellofemoral pain and tears or ruptures of the anterior cruciate ligament (ACL). ... The recommended height for depth jumps ranges from 16 to 42 inches (41-107 cm), with 30 to 32 inches (76-81cm) being the norm. ... The depth jump box height for athletes who weigh over 220 pounds (100 kg) should be 18 inches (46 cm) or less."

— Chapter 19 · Safety Considerations / Technique / Depth Jumping（`ch19.txt` 第 920–924、1133–1137 行）

## I — 自述 (Interpretation)

Plyometric 本身不危险，伤害多发生在"流程被破坏"时。原文把成因链归为可校正的六项：**基础力量不足、热身不足、引导钻进阶不当、当期量或强度不当、鞋或地面差、技能不足**。排障的思路是：**症状 → 归因到这六项 → 施加对应校正 → 复测**。

四条必须记牢的硬约束：
1. **技术（最重要）**：落地时肩在膝上、膝在趾上；**膝内扣 = 动态外翻（dynamic valgus）**，是各类膝伤（含髌股痛与 **ACL 撕裂/断裂**）的显著危险因素。落地用主动平足，踝背屈、落地前跖屈"攻击地面"，脚跟保持离地（**信用卡规则**：能塞进一张信用卡）。
2. **深跳箱高**：有上限——**48 in（122 cm）** 虽过载大但多数人无法保持技术，会拉长过渡相、使练习失效且易伤；推荐 **16–42 in（41–107 cm）**，常规 **30–32 in（76–81 cm）**。
3. **体重**：>100 kg（220 lb）者受伤风险升高（关节压缩力大），**深跳箱高应 ≤18 in（46 cm）**，并谨慎对待高量/高强度。
4. **场地与器材**：草地/悬浮地板/橡胶垫为佳，**混凝土/瓷砖/硬木不推荐**；**过厚垫（≥6 in / 15 cm）与迷你蹦床会拉长过渡相**，健康运动员用它们会失去牵张反射效益；箱高 6–42 in、落地面 ≥18×24 in、防滑；鞋需良好踝足支撑与横向稳定性。

## A1 — 案例 / 演练 (Application)

**书中反例**（类型：counter-example；出处：`ch19.txt` 第 1125–1137、920–924 行；候选 `ce19-02`、`ce19-03`）：
- **深跳箱过高**：追求超过技术可控的箱高 → 损伤概率上升，且缓冲期被拉长使练习失效（`ce19-02`）。
- **落地膝内扣**：肩未过膝、膝未过趾，重心偏离支撑面 → 髌股痛与 ACL 撕裂/断裂风险显著上升（`ce19-03`）。
**原书未说明**具体伤例的个体随时间结果。

**合成演练**（明确标记）：
- (a) 体重 **105 kg** 的运动员被安排 **24 in（61 cm）** 箱深跳 → 超 >100 kg 的 **≤18 in（46 cm）** 上限 → 降至 ≤18 in 或改其他 plyo 动作。
- (b) 另一名运动员落地**膝内扣** → 判为 dynamic valgus → 校正为"肩过膝、膝过趾"对位 + 主动平足落地 + 踝背屈，并用信用卡规则自查脚跟离地。
**原书未说明**两例结果。

## A2 — 未来触发 (Trigger)

**情境**：
1. 用户描述跳跃/落地时膝内扣、脚跟砸地、或练后膝痛，问怎么改。
2. 用户问深跳箱该多高、体重大的人能不能做。
3. 用户问场地/垫子/鞋/箱体是否合规，或落地动作哪里出错。

**语言信号（中英）**：落地膝内扣 / knee valgus / ACL 风险 / landing technique / 深跳箱多高 / depth jump box height / 体重太大能不能跳 / plyometric injury / 地面/垫子/鞋要求 / credit card rule。

**与相邻能力的区分（初稿）**：本卡处理 plyometric 的**安全排障**；**能不能开始**（力量/平衡/技术门槛）转 U5；**年龄/关节退变的禁忌**转 U6；**杠铃训练技术安全与护具**属"抗阻计划设计/Skill 技术规范"；**冲刺/变向的技术错误**（overstriding 等）属"速度敏捷"Skill。

## E — 执行 (Execution)

**输入契约**：
- 必需：症状或不良表现（如膝内扣、疼痛、练后表现下降）；运动员体重（kg/lb）；拟用或现用箱高；场地表面与鞋；训练史与热身/进阶记录。
- 可选：技术视频；既往伤史。
- 缺失体重或箱高应先询问。

**步骤**：
1. **收集症状与情境**：记录表现/疼痛、发生动作、训练量强度、场地器材。完成标准 = 六成因（力量/热身/进阶/量强度/鞋地面/技能）各有一条"有/无"证据。
2. **逐项排查六成因**，定位最可能的缺口。完成标准 = 排出 1–2 个最可能成因。
3. **技术优先校正**（若涉及落地）：核对肩过膝、膝过趾、主动平足、无膝内扣、脚跟离地（信用卡规则）。**判停点**：出现膝内扣/明显对位错误 → 先降强度纠正技术再谈加量。
4. **箱高与体重核对**：箱高须在 **16–42 in**（常规 30–32 in）；**>100 kg → ≤18 in**；48 in 为否定性上限。完成标准 = 箱高落在安全区间或给出替代动作。
5. **场地/器材核对**：表面有缓冲（草地/悬浮地板/橡胶垫；混凝土/瓷砖/硬木不用）；垫厚 <6 in；臂/箱合规。完成标准 = 场地器材逐项合规。
6. **施加校正并复测**：对应补力量/补热身/改进阶/调量强度/换鞋地面/强化技术。完成标准 = 复现时症状消失或减轻。

**约定与容差**：原文**未给成因优先级排序**、地面/鞋为**推荐非量化标准**；<100 kg 者无精确箱高上界（仅总区间与常规值）。本卡按原文阈值，不自行加严或放宽。

**输出契约**：`{症状, 最可能成因, 技术校正项, 安全箱高, 体重风险标记, 场地/器材合规项, 复测标准}`。完成标准 = 给出一条"症状→成因→处置"链，且数值与原文一致。

## B — 边界 (Boundary)

**（本单元为安全单元，B 段写足）**

- **什么情况不要用/不要做**：
  - 落地**动态外翻（膝内扣）**未纠正前，**不得升强度或加箱高**——它是髌股痛与 **ACL 撕裂/断裂**的显著危险因素（`ce19-03`）。
  - **深跳箱高超过运动员技术可控范围**（尤其逼近 48 in）**禁止**：不仅伤险上升，还会拉长过渡相、使练习**目的失效**（`ce19-02`）。
  - **>100 kg 者**不得用 >18 in（46 cm）箱深跳，也不得直接做高量/高强度（`ce19-06`）。
  - **混凝土/瓷砖/硬木**等无缓冲地面**禁用**做下肢 plyo（`ce19-04`）。
  - **≥6 in 厚垫或迷你蹦床**不得用于健康运动员的 plyo 训练（拉长过渡相、失去牵拉反射效益；仅合康复入门）（`ce19-05`）。
  - **力量/速度/平衡基础不足**时不得提高强度（`ce19-07`）。
- **作者警告的失败模式**：伤害多来自"流程被破坏"而非动作本身——基础力量不足、热身不足、引导钻进阶不当、量强度不当、鞋地面差、技能不足。逐动作的常见错误（落地屈髋屈膝加大触地时间破坏踝主导性、飞行期未背屈导致脚尖着地、起跳未三重伸展、未协调摆臂）会改变动作性质使训练失效并增伤险（`ce19-11`）。
- **作者盲点（BOOK_OVERVIEW 步骤 3）**：原文列出风险因素但**未给成因优先级排序**（无"先查哪项"的判据）；地面/鞋/热身剂量为**推荐而非量化标准**；阈值（100 kg、18 in、6 in）为实践惯例（共识 ≠ 实证），个案应结合专业判断。
- **专业边界**：疼痛、关节退变、术后、脊柱功能障碍等的诊断与处置属医疗范畴，**应转诊**，教练不得自行续排高强度。
- **相邻易混**：把"准入评估（够不够格）"当成"安全排障（哪里出错）"；把本卡的箱高/体重规则误用于抗阻杠铃高度或速度敏捷栏架高度。
