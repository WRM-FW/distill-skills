# 常模数据的查找与解读口径（表 14.1–14.37）

## R — 原文 (Reading)

> "Descriptors for percentile rankings: 90 = well above average; 70 = above average; 50 = average; 30 = below average; 10 = well below average. ... The values listed are means ± standard deviation. The data should be regarded as only descriptive, not normative."

— Chapter 14 · Normative data（Table 14.1–14.37）（`ch14.txt:2537, 2424`）

## I — 自述 (Interpretation)

第 14 章末有 37 张表把测试成绩翻译成"在参照人群中处于什么位置"。这一步不是算公式，而是**用统一口径读表**。

- **统一读表语言（跨表通用）**：第 90 百分位 = 远高于平均；70 = 高于平均；50 = 平均；30 = 低于平均；10 = 远低于平均。
- **表的分层键**：多按**运动项目 / 位置 / 年龄组 / 性别 / 训练级别**分层；用表前必须选对同一人群的那一列。
- **表性质分级**：有些表是**规范（normative）**常模，有些**明确标注"descriptive, not normative"**（仅描述性、非规范性），后者不得当标准常模使用。
- **解读落点**：原始成绩 → 定位所在百分位 → 赋予描述词；必要时与 z 分数、SWC 联用。
- **使用前提**：核对样本年代、测试协议与设备是否与当前一致（BOOK_OVERVIEW 3.1）。

即：把"分数"放进参照分布，并**标注这张表能承担多少解读责任**。

## A1 — 案例 / 演练 (Application)

**类型：tabular-example（原书表例 `c14-13`，Table 14.1）。**

- 运动员 1RM 卧推 100 kg，人群 = NCAA D-I 女子篮球 → 定位到表 14.1 对应人群列 → 找到 100 kg 落入的百分位 → 赋予描述词（90 远高 / 70 高 / 50 平均 / 30 低 / 10 远低）。
- 若所查表标注 "descriptive, not normative"（如表 14.4/14.5/14.10）→ **必须加注**"此表仅描述性、不得当规范常模"（对应 `ce14-08`）。
- 表内数值为均值 ± SD（具体数值见原表）；本卡只给"表号–口径–锚点"索引。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 测完一项，问"我这个成绩在人群里算好还是差"。
2. 手上有原始分数，要找/选对应的常模表并按百分位给描述词。
3. 同一项在不同年龄段/性别/项目的表怎么选、能不能混用。
4. 想知道某张表是"规范常模"还是"仅描述性"。
5. 想核对常模的年代、样本人群与协议是否还适用。

**语言信号（中英双写）**：常模 / norms / normative data / 百分位 / percentile / 描述词 / well above average / 表 14.x / Table 14.1 / 高于平均 / descriptive not normative / 参照人群 / 年龄段 / 常模表。

**与相邻能力的区分**：本卡管"选表 + 读表口径 + 表性质标注"；把分数标准化为 z / 组内比较归 `descriptive-stats-athletic-profile`；变化的实践意义归 `swc-effect-size`；个体最优化的 MAS→VO2max 等换算归各自计算卡。

## E — 执行 (Execution)

**输入契约（必需字段）**：`原始成绩`（数值 + 单位）+ `运动项目` + `年龄组` + `性别` + `测试协议/设备`。**缺任一分层键须先问，不得静默套用"通用"列**。

**步骤与完成标准**：
1. **选表**：按测试项→项目/位置→年龄/性别/级别定位唯一目标表号。完成标准：输出 `Table 14.x` 编号与列选择理由。
2. **核表性质**：查表注是否含 "descriptive, not normative"。完成标准：给表性质标签（normative / descriptive-only）。
3. **定位百分位**：把成绩落入对应列区间。完成标准：输出百分位数值（与方向：时间类越小越好须注意）。
4. **赋描述词**：90 远高 / 70 高 / 50 平均 / 30 低 / 10 远低。完成标准：输出描述词 + 所用口径。
5. **核对可比性**：样本年代、协议、设备是否与当前一致。完成标准：输出"可直接用 / 须标注存疑 / 不建议用"。
6. **输出**：`{表号, 百分位, 描述词, 表性质, 可比性提示}`。

**计算顺序**：选表 → 核性质 → 定位百分位 → 赋词 → 核可比性（不可跳过第 5 步）。

**容差与舍入**：按表内区间读取，不做外推；边界值取相邻档并标注"临界"。

**分支/判停**：
- 若表为 **descriptive-only** → **禁止**当规范常模，强制加注"仅描述性"。
- 若样本年代/协议不明 → 标注"可比性存疑"，不得直接下结论。
- 若找不到匹配人群列 → 说明"无适用常模"，建议自建常模（可参考画像卡），不得借用错人群列。

## B — 边界 (Boundary)

- **重要约束（作者盲点 3.1）**：常模/描述性数据表来自**特定年代、特定队伍、特定测试协议与设备**，**跨年代、跨地区套用会失真**；使用前必须核对样本人群、协议与设备是否与当前一致。
- **"描述性"≠"规范性"**：表 14.4/14.5/14.10 等明确标注仅描述性，不得当标准常模（`ce14-08`）。
- **"低于常模"≠"需要干预"（3.3-2）**：常模不是因果处方；是否干预须结合专项需求与趋势。
- **共识 ≠ 实证（3.3-5）**：常模阈值以"惯例"形态出现，不等于对个体的最优判据。
- **单位/方向陷阱**：百分位高不等于成绩好（时间类反向）；先确认指标方向。
- **法域/人群语境**：样本多为北美竞技人群，迁移到其他人群须重新校验（3.2）。
- **相邻易混**：本卡是"查表与读表口径"；由原始数据算指标与 z 分数归 `descriptive-stats-athletic-profile`。
