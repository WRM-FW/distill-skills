# 营养评估口径、膳食换算与转诊边界

## R — 原文 (Reading)

> "athletes with complex nutrition issues should be referred to the appropriate resource, either a team physician or sports dietitian. The team physician is responsible for overseeing the athlete's medical care while the sports dietitian is responsible for providing individualized dietary advice."

— Chapter 10 · Basic Nutritional Factors Affecting Health（`ch10.txt:55-59`）

## I — 自述 (Interpretation)

把体能教练的营养角色限定为「运动营养教练」，并划清转诊边界与评估口径：

- **角色与转诊**：可自行处理**基本营养教育**（如「有什么健康零食」）；**复杂营养问题**→ 转诊队医或运动营养师（RD，最好 CSSD）。分工：**队医**管医疗照护，**运动营养师**给个体化膳食建议；涉及以食物/营养**治疗或管理疾病**（含营养素缺乏）→ 属医学营养治疗，归运动营养师（+ 队医）。个体化营养评估与咨询通常**只允许执业营养师**进行（须核实州 licensure 法规）。
- **评估口径**：DRIs 适用于「**惯常摄入**」而非单日——须采集**数日**求日均；蛋白质日间波动小、所需天数少。
- **阈值口径**：蛋白 AMDR 成人 10%–35%；纤维女 21–25、男 30–38 g/天；饱和脂肪 <10%、添加糖 ≤10% 总热量；LDL/总/HDL 胆固醇分类（Table 10.12，检测须 9–12 h 空腹）；铁：heme 15%–35%、nonheme 2%–20% 吸收率；「公共卫生关注营养素」＝纤维、维生素 D、钙、钾（女运动员铁缺乏是男运动员的 5–7 倍）。
- **处方权限**：**铁剂补充仅医生/注册营养师可推荐**；**钙剂补充**在膳食无法满足时由医生/营养师建议。

## A1 — 案例 / 演练 (Application)

**原书未给单一运动员的转诊算例**；以下为**明确标记的合成演练**，按原文规则复算。

**合成演练（标记：合成）**
- 输入：一名自述「想补铁提高耐力」的女运动员，教练非临床人员。
- 执行与预期输出：
  (a) 一般性问题由教练给**基本教育**；
  (b) 铁补充属**仅医生/注册营养师可推荐**（`p10-25`）→ **转诊**；
  (c) 若问题超出基本范畴（贫血/疾病）→ medical nutrition therapy 归运动营养师；
  (d) 记录并发起转诊，**不自行开方**。
- 原书未说明该合成输入的「实际结果」，此处为按规则复算。

## A2 — 未来触发 (Trigger)

**用户情境（3–5 条）**
1. 运动员问营养问题，不确定教练该自己答还是转诊。
2. 要评估膳食摄入是否达标（蛋白/纤维/脂肪/铁/钙）。
3. 要把食物份量换算成营养素克数。
4. 运动员想补铁/补钙，问教练能不能开。
5. 拿到血脂/胆固醇结果要判读分档。

**语言信号（中英双写）**：营养转诊 / 膳食评估 / 运动营养师 / 队医 / 铁剂 / 补铁 / 补钙 / 纤维 / 胆固醇 / 血脂 / nutrition referral / sports dietitian / team physician / assessment / food composition / iron supplement / blood lipids / DRI。

**与相邻能力的区分（初稿）**
- 与 **macronutrient-energy-needs**：能量与 g/kg 估算归那张卡；本卡给评估口径与转诊边界。
- 与 **energy-availability-red-s / eating-disorder-rwl-referral**：LEA/进食障碍的转诊归安全卡。
- 与 **test-*（医学红旗/健康安全）**：测试中的医学转诊另卡承载。

## E — 执行 (Execution)

**输入契约（必需字段）**
- 问题层级（一般 / 复杂 / 需医学营养治疗）；是否需要医学诊断；可用团队成员；膳食记录（天数）；食物份量与种类；所在法域 licensure 要求。
- **缺失须先询问，不得静默猜值**：若问题可能涉及疾病/缺乏 → 默认升级转诊；若不知本地执照法规 → 不承诺个体化咨询。
- 适用条件：健康人群的一般营养；医学/复杂问题须转诊。

**步骤（每步有完成标准）**
1. **判层级**——一般 / 复杂 / 需 medical nutrition therapy。完成标准：输出层级。
2. **按层级路由**——一般 → 教练基本教育；复杂 → 队医或运动营养师；疾病/缺乏 → 运动营养师（队医协同）。完成标准：输出处理归属。
3. **评估口径**——用**数日**膳食记录求日均（蛋白天数可少），对照阈值（蛋白 AMDR、纤维、饱和脂肪、添加糖）。完成标准：输出各项是否达标。
4. **换算**——按 Table 10.8（蛋白）/10.11（脂肪）查每份含量并线性累加。完成标准：输出克数。
5. **处方权限核对**——铁/钙补充等须由医生/营养师；核实法域 licensure。完成标准：输出转诊动作，教练不越界开方。

**输出契约**
- 字段：`{问题层级, 处理归属(教练/队医/营养师), 评估结果(达标/未达), 换算值, 转诊动作}`。
- 单位：g/天；%；g/kg；mg/dl（血脂）。
- **约束（原文只给方向未给数值，不得静默补值）**：原文食物成分表为**节选**（缺整表）；**未给「复杂 vs 一般」的清晰分界标准**；文本按美国（AND/CSSD、州 licensure、HIPAA）语境描述，**跨法域不可直接照搬**。

## B — 边界 (Boundary)

- **不要**越界做个体化营养咨询或开铁/钙补充——只医生/注册营养师可推荐（`p10-25`）。
- **不要**用单日膳食记录下结论——DRIs 适用于惯常摄入，须多日平均。
- **不要**把节选食物成分表当全表用——数据不完整。
- **不要**跨法域直接照搬美国 licensure 语境——须核验本地法规。
- **作者盲点（3.2/3.3）**：默认读者处于有队医/营养师的组织环境；资源匮乏场景的替代路径原文未给；「复杂 vs 一般」无清晰分界。
- **专业边界（2.2-14）**：以食物治疗/管理疾病属医学营养治疗，归营养师/医生。
- **相邻易混**：与 **macronutrient-energy-needs** 分工——本卡给口径与转诊，那张卡算需求。
