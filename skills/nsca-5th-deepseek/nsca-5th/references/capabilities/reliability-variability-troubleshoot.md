# 测试信度受损来源排查（前后测一致性）

## R — 原文 (Reading)

> "The difference between two sets of scores can arise from a number of different factors: Intrasubject (within subjects) variability; Lack of interrater (between raters) reliability or agreement; Intrarater (within raters) variability; Failure of the test itself to provide consistent results."

— Chapter 13 · Reliability（`ch13.txt:302-306`）

## I — 自述 (Interpretation)

当同一位运动员的两组成绩出现差异，别急着下"进步/退步"的结论——先沿**四个来源**逐层排查，再对症处理：

1. **Intrasubject（受试者内变异）**：本人表现不稳（与训练、状态、努力度有关）。
2. **Interrater（评分者间一致性不足）**：不同测试员之间不一致。对策：明确评分系统 + 受训评分者；前后测固定同一人；不同亚组由宽严不同的评分者测会虚高/压低。
3. **Intrarater（评分者内变异）**：同一人前后不一致。常见是"急于看到进步"而在后测无意识放水；也包括培训不足、注意力不集中、未遵循校准/准备/施测/评分的标准化程序。
4. **测试本身无法给出一致结果**：技巧性越强的测试变异越大，需更多赛前练习。

关键落地规则：**同一组运动员的前测与后测应由同一评分者执行**，否则评分者宽严差异可使前后比较失效。

## A1 — 案例 / 演练 (Application)

**原书案例（in-book-athlete-scenario，`ch13.txt:336-340`；`c13-01`）**：同一运动员做背蹲测试，若前测评分者**宽松**（允许蹲深不足）、后测评分者**严格**，运动员即使力量显著提高，也可能在后测拿到**更低**的分数——"假性退步"。

**合成演练（明确标记）**：某运动员深蹲 1RM 前测 120 kg、后测 115 kg，但教练确信力量增长。
- 依四来源排查 → 命中"intrarater（后测更严）/ interrater（换人施测）"。
- 修正：固定同一评分者 + 明确下蹲深度判据（标准化）。
- 结论：本次前后测**不可直接比较**，不是"力量退步"。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 同一个人前后测成绩对不上，问"是练退步了还是测错了"。
2. 大群体测试换了评分者，担心结果不可比。
3. 某项测试成绩波动特别大，要找原因。
4. 想设计控制信度的手段（评分系统、固定评分者、赛前练习）。

**语言信号（中英双写）**：前后测不一致 / 分数波动 / 是不是测错了 / 信度 / 评分者 / reliability / variability / interrater / intrarater / 假性退步 / not comparable / measurement error / 同一评分者。

**与相邻能力的区分**：本卡是"测得飘了"的**归因排查**（事后）；单测试是否合格用 `test-selection-validity`（事前准入）；人员培训/分工用 `tester-selection-duties`。

## E — 执行 (Execution)

**输入契约**：同一运动员/同一测试的两次（或多次）成绩 + 施测信息（是否换人、评分标准、是否标准化）。缺"是否换人施测"须先问。

**步骤与完成标准**：
1. **确认存在差异**：量化差值（差值 = 后测 − 前测）。完成标准：给出差值与方向。
2. **查受试者内变异**：该运动员近期训练/状态/努力度是否变化。完成标准：是/否判断 + 证据。
3. **查评分者间**：前后测是否由不同人/不同宽严完成（尤其分组施测）。完成标准：命中/未命中。
4. **查评分者内**：同一人是否在后测更宽或更严；是否遵循标准化（校准/准备/施测/评分）。完成标准：命中/未命中。
5. **查测试本身**：该测试是否技巧主导、变异大、需更多练习。完成标准：命中/未命中。
6. **对症纠正**：统一评分系统、训练评分者、**固定同一评分者做前后测**、增加赛前练习。完成标准：给出可执行纠偏动作。
7. **结论**：本次前后测是否可直接比较。完成标准：明确"可比/不可比 + 理由"。

**输出契约**：`{两组成绩与差值, 四来源命中表, 纠正动作, 可比性结论}`。

**判停点/分支**：
- 命中评分者相关问题 → 结论一律标"前后测不可直接比较"，重测需固定同一人。
- 若四来源均未命中且测试本身高度技巧主导 → 建议增加赛前练习或改测法。

**约定**：原文未给"变异多大算不可接受"的阈值，也未给 ICC/典型误差(TE) 的解析式与可接受阈值（`p13-07` gap）。本卡**不虚构公式与阈值**，只做四来源归因与纠正。

## B — 边界 (Boundary)

- **不要**在没有排除测量误差前，把差值解释为训练效果。
- **不要**用本卡做"测试选得对不对"的判断——那是效度问题。
- **作者盲点（3.3-4）**：部分输入来自自评/量表，信度依赖受试者经验与诚实度；本卡不覆盖该路径。
- **量化缺口**：ICC/TE 原文仅定性，勿自造公式或阈值。
- **共识 ≠ 实证**："同一评分者"是控制信度的做法，不等于消除全部误差。
- **相邻易混**：与 `tester-selection-duties`（事前配人）不同——本卡是"事后排查"。
