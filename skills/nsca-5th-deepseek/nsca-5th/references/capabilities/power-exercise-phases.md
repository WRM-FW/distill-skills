# 爆发力动作阶段结构（高翻/抓举、推举/借力推、中大腿拉）

## R — 原文 (Reading)

> "Although the lift consists of four phases (i.e., first pull, transition, second pull, and catch) the upward movement of the bar occurs in one continuous motion without interruption. ... In the push press, the hip and knee extension thrust is only forceful enough to drive the bar one-half to two-thirds the distance overhead. From this height, the bar is pressed out to the overhead position, with the hips and knees remaining fully extended after the thrust. ... it is not uncommon for athletes to be able to perform the mid-thigh pulls with as much as 140% of the 1RM."

— Chapter 16 · Power Exercises（`ch16.txt` 第 2265–2322、2411–2528、2638–2707 行）

## I — 自述 (Interpretation)

爆发动作（power exercises）是把杠**快速、连续**地从某起点送到某终点，**阶段划分只是教学/观察用**——真实动作是**一个不间断的整体**。三类动作的阶段骨架：

1. **高翻（power clean）/ 抓举（power snatch）**：四阶段 **first pull → transition → second pull → catch**，但"向上移动是连续、无中断的"。
   - **First pull**：伸髋伸膝把杠抬离地面，躯干—地面夹角恒定（**髋不先于肩抬起**），肘全伸、杠尽量贴小腿；**结束于膝最大伸展、小腿近乎垂直**。
   - **Transition**：杠过膝后伸髋、膝前移至杠下，进入 **power position**，杠贴大腿（该段类似 RDL）。
   - **Second pull**：**快速伸髋、膝、踝**，以**耸肩**收尾；脚跟尽量久留地面以最大化力的传递；下体关节达全伸后迅速耸肩（肘仍伸直），肩到最高时**开始屈肘**"把身体拉进杠下"。
   - **Catch**：髋膝全伸后把身体拉到杠下，双臂绕到杠下，**屈髋屈膝成四分之一蹲**，肘上抬使上臂与地面平行，**杠架于锁骨与前三角肌上**，近直立躯干承接，再站直。
   - 常见错误：first pull 杠偏离身体；second pull 掉髋；**三关节伸展完成前就屈肘**。
2. **推举（push press）**：起杠于肩前 → **dip（屈髋屈膝，下蹲不超过四分之一蹲）→ drive（快速伸髋膝踝把杠驱动到头顶方向）→ catch（用臂把杠推到肘全伸过顶）**。关键：推力只够把杠**驱动到头顶距离的 1/2–2/3**，其余靠臂推；drive 后髋膝仍保持全伸。
3. **借力推（push jerk）**：与推举相似的 dip–drive，但**更用力**，把杠**真正驱动向上**，以**肘伸展、髋膝略屈**的姿态在头顶"接住"。
4. **中大腿拉（clean/snatch grip mid-thigh pull）**：从 **power position（即第二拉位，**膝角约 125–145°、髋角约 140–150°）**起始，动作**镜像高翻的第二拉**——快速伸膝、髋、踝 + 耸肩；可承受**大于高翻/抓举的负荷，常达 1RM 的 140%**；每次重复都要重新建立起始位，不得借块反弹。

## A1 — 案例 / 演练 (Application)

**合成演练（标记：合成；非书中案例）**：运动员做高翻（power clean），杠在地面起始。
- 连续完成 first pull → transition → second pull → catch 四阶段（无停顿）。
- 末端绕肘接杠于锁骨/前三角肌、屈髋膝成四分之一蹲。
- 属爆发动作 → **不保护、教失杠并清空平台**（转 `spotting-rules`）。
- **原书未说明**该合成输入的实测结果；原文以检查清单形式给分阶段技术要求。

**书中数值（出处 `ch16.txt` 第 2643–2644、2704–2707 行）**：中大腿拉的 power position 定义为**膝角约 125–145°、髋角约 140–150°**；负荷可达**1RM 的 140%**（clean grip 或 snatch grip 变式均同）。

## A2 — 未来触发 (Trigger)

**用户会在什么情境下遇到这类问题**：
1. 用户问高翻/抓举/挺举"分几个阶段、每阶段怎么做"。
2. 用户问"三关节伸展（triple extension）什么时候发生""为什么我老先屈肘"。
3. 用户问推举和借力推有什么不同、dip 要蹲多深。
4. 用户问中大腿拉怎么起、能用多重。
5. 用户问爆发动作要不要保护、失手怎么办。

**情境的语言信号（中英双写关键 trigger 词）**：高翻 / 抓举 / 挺举 / power clean / power snatch / push press / push jerk / 借力推 / 三关节伸展 / triple extension / first pull / second pull / 二拉 / transition / catch / power position / 中大腿拉 / mid-thigh pull / 耸肩 / shrug / 髋先于肩。

## E — 执行 (Execution)

**输入契约**
- 必需：**动作名称**（clean/snatch/jerk/push press/mid-thigh pull 等）、**起杠位置**（地面 / hang / power position / 架或块）。
- 可选：运动员技术短板、目标负荷。
- **缺失"起杠位置"应先询问**（决定是否含 first pull 与 transition）。

**步骤（每步可判断完成标准）**
1. **识别阶段序列**：按动作给出阶段列表。
   - 高翻/抓举：`first pull → transition → second pull → catch`（**连续、无中断**）。
   - 推举/借力推：`dip → drive → catch`。
   - 中大腿拉：从 `power position` 直接做"第二拉 + 耸肩"。
   - 完成标准：阶段名与原文一致；强调"phase 划分是教学用，真实为一连续动作"。
2. **逐个阶段给关键技术点**（每阶段 1–3 条可检查项）。
   - first pull：躯干—地面角恒定、**髋不先于肩抬**、肘全伸、杠贴小腿；**结束于膝最大伸展**。
   - transition：伸髋、膝前移入 power position、杠贴大腿。
   - second pull：快速伸髋膝踝至全伸 + 耸肩；脚跟尽量久留地面；**下体全伸后才屈肘**。
   - catch：屈髋膝成四分之一蹲（高翻/抓举）、杠架于锁骨/前三角、近直立躯干。
   - 推举：dip 不超过四分之一蹲；drive 只驱动 1/2–2/3 头顶距离，其余靠臂推，髋膝全伸。
   - 完成标准：每条技术点可被现场观察判"做到/未做到"。
3. **标出常见错误（作为观察项）**：first pull 杠漂离身体；second pull 掉髋；**三关节伸展前屈肘**。
   - 完成标准：列出对应错误项，供质检。
4. **安全分支**：属爆发动作 → **不保护** → 教失杠（前失手推开/放手；头后失手松手前跳）+ 清空平台。
   - 完成标准：安全动作与 `spotting-rules` 一致。
5. **交付**：见输出契约。

**输出契约**
- 字段：`{ exercise, start_position, phases[{phase, key_points[], common_errors[]}], safety(不保护+失杠), load_note }`。
- 完成标准：阶段序列完整、连续；catch 位置描述准确。
- **数值口径**：中大腿拉 power position 的**膝角 ~125–145°、髋角 ~140–150°**；负荷可达 **1RM 的 140%**；推举驱动距离为**头顶距离的 1/2–2/3**。
- **约定与已知缺口（原文未给）**：除 power position 的角度定义外，原文**未给** first/second pull、transition 的**时间或角度阈值**（仅定性："膝完全伸展时结束""power position"）。本卡据动作描述做阶段判定，**不臆造角度/时间阈值**；若需量化，标为"原文未给"。

## B — 边界 (Boundary)

- **不要**把阶段当作"分离的停顿动作"——原文强调"one continuous motion without interruption"；阶段只用于教学观察。
- **不要**对爆发动作安排保护者（本卡与 `spotting-rules` 一致，`ce16-05`）：应教失杠并清场。
- **不要**臆造阶段阈值：除中大腿拉 power position 的**膝 125–145°、髋 140–150°** 外，原文对多数阶段**只给定性描述**（此为已登记的边界），不得补造角度/时间数字。
- **不要**忽略"先失技术、后加负荷"：三关节伸展前屈肘等错误多源于负荷超过当前技术承受度；应在技术稳定后再进阶。
- **共识 ≠ 实证 / 迁移不保证**：阶段技术多为教练共识与举重传统；"gym 里技术改善"不自动等于"专项表现提升"（BOOK_OVERVIEW 3.3-1）。
- **相邻易混**：把"某个非爆发动作的纠错"或"变阻负荷计算"混入本卡。
