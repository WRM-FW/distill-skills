# 应急预案（EAP）构成与分情境应急响应

## R — 原文 (Reading)

> "Within the emergency team, four principal roles exist. The first is to provide immediate care of the athletes, because time is the most critical factor in emergency situations. The second involves emergency equipment retrieval; users of the facility should be made aware of the types and locations of emergency equipment before participation. Next is the activation of the emergency medical system (EMS). Again, establish a method for a direct line of communication… Finally, the individual making the call should have been familiarized with the facility location during the orientation meeting."

— Chapter 26 · Roles Within the Emergency Team（`ch26.txt` 第 1237–1249 行）

## I — 自述 (Interpretation)

应急预案（EAP）是一份**书面文件**，把所有人在"出事那一刻"该做什么固定下来。含两块：

**① 必备构成要素**（`ch26.txt` 第 1180–1195 行）：EMS 启动程序；**主/次/三级联系人**姓名电话；设施的**具体地址**（给 EMS 指路）；**电话位置**；**最近出口**位置；有资质照护人员（运动医学人员）；**救护车通道**；急救箱/**AED** 位置；**火灾、龙卷风、危及生命伤害、犯罪、恐怖主义**等情境的行动方案。须张贴于醒目处；所有人员必须熟悉；**至少每季度演练**。

**② 应急团队四角色**：① **即时照护**运动员（时间最关键）；② **取应急设备**；③ **启动 EMS**（建立直连通信方式）；④ **向导**（因已在迎新会熟悉设施位置，便于引 EMS 到场）。

**③ 分情境分步规程（Figure 26.7）**：
- **火灾**：①启动火警 ②疏散建筑。
- **危及生命**：①**呼叫 911** ②勿移动伤者 ③清醒则先征得同意再施救 ④必要时 CPR/AED ⑤陪伴至救援到达 ⑥启动应急通信通知相关方 ⑦填写伤情报告。
- **环境情境**：①启动相应警报并把人导向预定安全点 ②必要时呼 911 ③清点人数并通知救援 ④启动应急通信 ⑤记录。
- **非危及生命**：①先急救 ②必要时呼 911 ③启动应急通信 ④记录。

一句话：**先保生命（缩短响应时间）→ 取设备/呼 EMS → 通知 → 记录；且必须演练。**

## A1 — 案例 / 演练 (Application)

**合成演练（明确标记，按 Figure 26.7 危及生命序列）**：举重房内运动员倒地、意识不清（危及生命情境）。
- ①呼叫 911；②勿移动伤者；③本例不清醒 → **跳过**"征求同意"直接进入；④必要时 CPR/AED；⑤陪伴至救援到达；⑥启动应急通信通知相关方；⑦填写伤情报告。
- 同时对应四角色分配：即时照护 / 取设备 / 启动 EMS / 向导。

**原书素材（sample-program · c26-2 / Figure 26.7，`ch26.txt` 第 1251–1286 行）**：给出火灾/危及生命/环境/非危及生命四类情境的分步样例；**原书为样例协议，未涉及真实事件结果**。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 要**制定/完善应急预案**（EAP）。
2. 问"出事了谁做什么、怎么分工"。
3. 问"EAP 要包含哪些内容、怎么演练"。
4. 问"危及生命/火灾/环境事件具体步骤"。
5. 想检查和更新现有 EAP（如联系人、地址、AED 位置）。

**语言信号（中英双写）**：应急预案 / 应急流程 / 出事怎么办 / 谁负责 / 分工 / 演练 / 呼叫 911 / 急救箱 / AED / 疏散 / emergency action plan / EAP / EMS activation / emergency roles / drill / evacuation / emergency contacts。

**与相邻能力的区分（初稿）**：本卡管"**EAP 的构成、角色与分情境步骤**"。**现场识别与急症处置**（热射病/横纹肌溶解等）→ `cap.nsca.exercise-medical-emergency-response`；**法律责任** → `cap.nsca.risk-management-and-negligence`；**出口/通道/空间** → `cap.nsca.facility-space-and-layout-planning`。**与"测试与评估""周期化"不同**：本卡属安全/运营流程。

## E — 执行 (Execution)

**输入契约（必需）**：设施**具体地址**与最近出口；**联系人层级**（主/次/三级）姓名电话；应急设备位置（急救箱/AED）；有资质照护人员；救护车通道；**当地应急号码**。**可选**：设施平面图、演练记录。
- **缺失处理**：缺地址/出口/设备位置 → 无法完成 EAP，先补；**跨法域须将 911 替换为当地应急号码**（原文注 "or a comparable local emergency response provider"）。

**步骤与完成标准**：
1. **写必备要素**：EMS 启动、三级联系人、具体地址、电话位置、最近出口、资质照护人员、救护车通道、急救箱/AED 位置、火灾/龙卷风/危及生命/犯罪等情境方案。完成标准：九项齐全。
2. **定四角色**：即时照护 / 取设备 / 启动 EMS / 向导。完成标准：每个角色有指定（可兼任但须明确）。
3. **写分情境分步规程**（火灾/危及生命/环境/非危及生命）。完成标准：每类情境有编号步骤。
4. **张贴与培训**：张贴在醒目位置；全员熟悉。完成标准：位置确定、人员知悉。
5. **认证与演练**：保持急救/CPR/AED 认证；**至少每季度演练**。完成标准：写出演练频率与下次日期。
6. **输出 EAP 文档**。

**输出契约**：`{九项必备要素, 四角色分工, 四类情境分步规程, 张贴位置, 演练频率与记录, 当地应急号码}`。

**判停点/分支**：
- 危及生命 → 呼 911 + 勿移动 + CPR/AED + 陪伴 + 通知 + 记录（不因缺某项而延迟呼叫）。
- 缺当地应急号码/地址 → 先补，再实施。
- 演练/认证超期 → 列入整改。

**语境依赖（跨法域须重新校验）**：以**美国 911/EMS** 体系为背景；原文已注明可替换为"comparable local emergency response provider"，且部分电话系统需替代拨号方式。**跨法域须替换为当地应急号码与流程**。

## B — 边界 (Boundary)

- **不要**把 EAP 写成"有就行"——须**张贴、熟悉、至少每季度演练**（`ce26-09`）。
- **不要**在危及生命情境下因流程细节迟疑而延迟呼叫 EMS。
- **不要**直接照搬美国 911/EMS 流程到其他法域（**B 段主依据**：跨法域须重新校验）。
- **非医疗处置**：EAP 涉及施救须由受训人员执行；体能教练不越界做医疗判断（`cap.nsca.rehab-scope-and-referral`）。
- **组织前提（作者盲点 2.2-14/3.2）**：原文默认有运动医学人员可及；资源匮乏时须优先建立通信与外部 EMS 联系，且**不得**由未受训者补位。
- **不替代急救训练**：EAP 是流程文件，不能替代 CPR/AED/急救认证与实操演练。
- **相邻易混**：`cap.nsca.exercise-medical-emergency-response`（现场处置）、`cap.nsca.risk-management-and-negligence`（责任）。
