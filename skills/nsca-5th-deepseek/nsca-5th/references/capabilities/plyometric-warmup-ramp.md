# Plyometric 专项热身（RAMP：激活—动员—增强）

## R — 原文 (Reading)

> "a plyometric exercise session should begin with a specific warm-up that incorporates activation, mobilization, and potentiation of the neuromuscular and musculoskeletal system. The specific warm-up for plyometric training should consist of low-intensity, dynamic movements that increase in intensity as the warm-up progresses. TABLE 19.7 Examples of Plyometric Warm-Up Drills: Marching; Ground contact (Rapid pogo jump... Straight-leg skip or bound...); Footwork; Neuromuscular acceleration and deceleration."

— Chapter 19 · Warm-Up / Table 19.7（`ch19.txt` 第 668–674、718–746 行）

## I — 自述 (Interpretation)

每节 plyometric 课都应先做一个**专项热身**，其性质是**激活（activation）+ 动员（mobilization）+ 增强（potentiation）**神经肌肉与肌骨系统。特点：**低强度动态动作起步，随进程递增强度**，最后进入主训练。

原文用 Table 19.7 给出四类热身钻，可编入 RAMP 各相：
1. **Marching**：模仿跑动、强调姿势与技术、强化正确下肢跑姿。
2. **Ground contact**：为落地与高冲击动作做准备——如 rapid pogo jump（脚跟不触地，强调踝背屈 + 主动前足触地）；straight-leg skip/bound（强调"负脚速"，即脚向后加速触地，最小化膝屈、最大化髋伸）。
3. **Footwork**：多平面加减速机制、为变向做准备（shuttle / shuffle / pattern / stride）。
4. **Neuromuscular acceleration and deceleration**：多关节爆发式变向、全幅度动作（前/侧/后弓步；由高举深蹲到蹲跳再到站立落地）。

关键点：**不要"直接上高强度跳"**；热身本身是一条**强度递增链**，覆盖"触地准备 → 变向准备 → 神经激活"。

## A1 — 案例 / 演练 (Application)

**书中清单**（类型：book-example；出处：`ch19.txt` Table 19.7，第 718–746 行）：原文以表格形式列出四类热身钻及其说明，可作为热身序列的素材库，但**未给出具体课例**。**原书未说明**某次热身课的实测效果。

**合成演练**（明确标记）：当日主训练含 depth jump（高强度）的一次 plyo 课，按 Table 19.7 形成递增强度序列——
① Marching（跑姿模仿，强调整位）→ ② Ground contact（rapid pogo jump 不使脚跟触地；straight-leg skip/bound 强调负脚速）→ ③ Footwork（变向加减速）→ ④ Neuromuscular acceleration & deceleration（多关节爆发变向、全幅度弓步/蹲）；全程**低强度起步、随进程升强度**，完成后进入主训练。**原书未说明**该序列的实测结果。

## E — 执行 (Execution)

**输入契约**：
- 必需：当日主训练动作与强度档（决定热身终点强度）；可用空间/器械。
- 可选：运动员技术短板（决定各相权重）。
- 缺失"当日主训练强度"应先询问，以免热身不足或过度。

**步骤**：
1. **激活与动员**：做低强度动态动作建立关节活动度与神经募集。完成标准 = 完成 marching 类动作并达到正确跑姿对位。
2. **触地准备（Ground contact）**：加入 rapid pogo jump（脚跟不触地）、straight-leg skip/bound（强调负脚速）。完成标准 = 完成触地类钻，动作中激活踝背屈与主动前足触地。
3. **变向准备（Footwork）**：shuttle/shuffle/pattern/stride。完成标准 = 完成多平面加减速钻。分支：当日主训练含变向 → 此相加量；不含变向 → 可略。
4. **神经激活（Neuromuscular accel/decel）**：多关节爆发变向、全幅度动作。完成标准 = 强度升至接近主训练。
5. **过渡**：完成四相后进入主训练。完成标准 = 热身序列整体**由低到高单调递增**，无跳步直上高强度。

**约定与容差**：原文**未给热身的时长/组次定量**（转 Ch15 的 RAMP 框架），本卡按"四相递增"结构执行，具体重复数为本卡实现约定。

**输出契约**：`{热身序列(四相), 各相动作, 强度递进说明}`。完成标准 = 序列覆盖激活/动员/增强三性质，且强度单调递增后进入主训练。

## B — 边界 (Boundary)

- **不要用本卡替代完整 RAMP 框架**：原文指向 Ch15；本卡只给 plyo 专项示例，**未给时长/组次**，不可当通用热身模板。
- **不要做静态拉伸替代动态热身**：动态、递增强度是核心，冷启动直接高强跳是常见致伤成因（转 U8 成因链）。
- **作者盲点**：热身"降低损伤"多为机制/经验推断，本处未给量化剂量（共识 ≠ 实证）。
- **人群/器材依赖**：场地硬度与鞋影响触地钻效果（转 U8）；儿童/老人热身强度须按 U6 裁剪。
- **相邻易混**：把训练后的恢复放松、或专项技术训练，当成 plyo 课前热身。
