# 确定主要训练目标（单目标聚焦 + emphasis/de-emphasis + 赛季优先级）

## R — 原文 (Reading)

> "The athlete's testing results, the movement and physiological analysis of the sport, and the priorities of the athlete's sport season determine the primary goal or outcome for the resistance training program. ... an effort should be made to concentrate on only one training outcome per training block. This can be accomplished using an emphasis/de-emphasis approach"

— Chapter 18 · Primary Resistance Training Goal + Table 18.2（`ch18.txt` 403–411）

## I — 自述 (Interpretation)

这一步决定"这一训练块到底练什么"。输入三路证据：**测试结果**、**运动的动作/生理分析**、**赛季优先级**。核心规则有三条：

1. **每个训练块只聚焦一个 dominant 目标**（strength / power / hypertrophy / muscular endurance）——即便存在同时改善两方面的愿望，也应只主攻一个，其余用 emphasis/de-emphasis 分期偏重。
2. **维持其余素质**——聚焦某素质时，仍要给其他素质足够维持刺激，尤其下个训练块要强调的那些。
3. **赛季映射（Table 18.2）**：off-season 专项练习低/抗阻高，目标先 hypertrophy+muscular endurance、后转 strength+power；preseason 专项中/抗阻中，目标专项与动作特异；in-season 专项高/抗阻低，目标维持赛前目标（长赛季可 strength↔power 交替）；postseason（主动休息）两者可变、目标非特异。
4. **团队项目 multitargeted**：需多素质时可并行，但只组合**兼容**素质（strength–power 与 speed），回避**不兼容**者（speed 与 cardiovascular endurance）；高容量 strength-endurance/hypertrophy 在赛季中可致过度疲劳与损伤风险升高。

## A1 — 案例 / 演练 (Application)

**原书案例（tabular-example，c18-3 / Table 18.2）**：需求分析应用表据三路证据给出各情境主目标——A（篮球中锋，in-season）Strength/power；B（橄榄球锋线，off-season）Hypertrophy；C（高中越野跑者，preseason）Muscular endurance。原文并说明：团队项目（篮球、足球、冰球）需多素质时可用 multitargeted 并行发展。

**合成演练（标记：合成；演示兼容性规则，非书中案例）**
- 输入：团队项目（篮球），运动员处 in-season，拟同时维持 strength–power 与 speed。
- 执行：应用三条规则——(a) 本块唯一 dominant 目标取 **power**（speed–strength）；(b) strength 用 de-emphasis 维持；(c) 兼容性检查：speed 与 strength–power 兼容，可并行；speed 与 cardiovascular endurance 不兼容，不与大容量有氧耐力同期。
- 预期输出：本块主目标＝power，strength de-emphasized 维持，speed 可并行。原书未说明该合成输入的"实际结果"。

## A2 — 未来触发 (Trigger)

**用户会遇到这类问题的情境（3–5 条）**
- 用户列出了多个想练的素质，问"到底该以哪个为主"。
- 用户想在同一训练块里同时练力量、爆发、耐力，问怎么排。
- 用户问赛季中该维持还是提升、该练什么。
- 用户是团队项目，需要同时发展多素质，问能否并行。
- 用户问"上块强调的力量，这块换练爆发行不行/其他素质会不会掉"。

**语言信号（中英双写关键 trigger 词）**
- "这块主要练什么" / "primary training goal"、"main goal"、"dominant goal"、"训练块只练一个目标"、"emphasis/de-emphasis"、"别同时练两个"、"赛季该维持还是提升"、"in-season 维持"、"off-season 练什么"、"concurrent training"、"速度和有氧能一起练吗"、"multitargeted"。
- 英文常见："what should the primary goal be"、"can I train strength and endurance at once"。

**与相邻能力的区分（初稿）**
- 与 **needs-analysis**：本卡消费需求分析三路证据，产出"单一收敛目标"；整体两阶段流程由前者承载。
- 与 **load-reps-assignment**：目标一旦定下即自动隐含负荷×次数区间；取值由后者承载（本卡不查负荷表）。
- 与 B-periodization 簇：赛季轮的年度/中周期编排由周期化承载；本卡只定"本块单目标 + 维持策略 + 兼容性"。
- 与 **training-frequency**：赛季也影响频率，但那是频率维度的查表，另卡承载。

## E — 执行 (Execution)

**输入契约**
- 必需：运动员测试结果、运动的动作/生理分析、当前赛季阶段（off/pre/in/post-season）、项目是个人还是团队、需同时发展的素质数量。
- **先询问（缺失不得静默猜值）**：若无**赛季阶段** → 先问"现在处于哪个赛季阶段"，否则无法查 Table 18.2；若无测试结果与运动分析 → 回 needs-analysis 补齐，不得凭空指定主目标。
- 适用条件：任何抗阻训练计划块。

**步骤（每步有完成标准）**
1. **汇总三路证据**——完成标准：测试结果、运动动作/生理分析、赛季阶段三项均已列明。
2. **锁定唯一 dominant 目标**——完成标准：本块目标四选一；判停点：若用户坚持两个以上不兼容目标，依规则拒绝并行并给出 emphasis/de-emphasis 分期方案。
3. **为其余素质设计维持刺激**——完成标准：列出被 de-emphasize 的素质及其维持手段，尤其下块要强调者。
4. **兼容性检查（团队项目多目标时）**——完成标准：仅组合兼容素质（strength–power + speed），显式排除不兼容组合（speed × cardiovascular endurance）。
5. **赛季轮换设定**——完成标准：按 Table 18.2 给出本块与相邻块的轮换（off→hypertrophy/endurance 先行、后 strength/power；in-season 维持，长赛季 strength↔power 交替）。

**输出契约**
- 字段：`{ dominant_goal, de-emphasized_qualities[], season_mapping, compatible_pairs[], rotation_plan }`。
- dominant_goal 只能取 `strength | power | hypertrophy | muscular_endurance`。
- 约定：原文未给"兼容素质"的定量判据，兼容性来自原文示例（strength–power/speed 兼容；speed/cardiovascular endurance 不兼容）；更细的期化规则参见 Ch22（由 B 簇承载）。

## B — 边界 (Boundary)

- **不要**在一个训练块内同时主攻两个以上互不兼容的素质——这是作者警告的失败模式（ce18-03），刺激相互干扰，任一目标都难充分实现。
- **不要**在同期并行互不兼容素质（如最大速度 + 大容量有氧耐力）——concurrent training 干扰（ce18-06）。
- 高容量 strength-endurance/hypertrophy 在赛季中可致过度疲劳并升高损伤风险，作者提醒 in-season 通常不采用高量。
- **共识 ≠ 实证、变量耦合**（BOOK_OVERVIEW 3.3）：赛事优先级表是"通常做法"，实际目标随具体项目而异（表注已声明），且目标一改会牵动负荷/量/休息。
- 易混淆：与 **load-reps-assignment**（目标的执行）、**training-frequency**（赛季对频率的影响）不同——本卡只产出"目标决策"本身。
