# 敏捷 drill 可操纵因素与知觉—认知进阶（含过渡移动）

## R — 原文 (Reading)

> "Temporal or time constraints can be administered (i.e., athlete has 5 s to achieve the objective) to maintain quality and intensity." ... "Backpedaling for 20 yards (18 m) along a marked line on the football field to establish correct technique ... Backpedaling while tracking an opponent who is initially running forward and then changing direction to sprint once the opponent initiates a COD or sprint."

— Chapter 20 · Table 20.6（`ch20.txt` 第 1855–1860 行）；"Transitional Movements"（第 1456–1467 行）

## I — 自述 (Interpretation)

设计敏捷练习时，把可调因素分成两类旋钮，按需增减难度与比赛代表性。**机械类**：场地间距与维度、进入/退出速度与动量、变向动作类型与角度、起始姿势（静态或过渡动作）。**知觉—认知类**：攻防者的位置与数量、时间约束（如"5 s 内完成"）、规则与条件、环境与场地表面、从通用刺激（口令/闪光灯/箭头）到专项刺激（真实对手、专项器械）、任务复杂性与认知负荷。进阶路线是从低认知负荷的闭合 drill，逐步加入通用刺激、再过渡到专项刺激与小场对抗，并可协同技能教练同步发展技术与战术。过渡移动（后撤跑、侧滑步、交叉跑）是敏捷的前置技术，其进阶为四步：标记线上建立正确技术 → 音频口令变速 → 口令/标记触发变向 → 追踪移动对手、在其启动变向或冲刺瞬间反应。目标是培养多样的"运动解决方案"。

## A1 — 案例 / 演练 (Application)

原书未提供单个运动员案例，但给出因素表（Table 20.6）与后撤跑四步进阶。以下为**合成演练**（明确标记，规则来自 Table 20.6 与第 1456–1467 行）：

- 输入：一名篮球运动员已熟练闭技能 Z-drill，拟提高认知负荷并更贴近比赛。
- 执行：按 Table 20.6 逐步加因素——先给 Z-drill 加通用刺激（口令/箭头）；再加时间约束（如 5 s 内完成）；再加 defending/attacking 人数与专项刺激（真实对手 / 小场对抗）；同步用后撤跑四步进阶。
- 预期输出：一份"机械旋钮 + 知觉—认知旋钮"的组合序列与 drill 设计参数，明确可执行。

## A2 — 未来触发 (Trigger)

**用户会在什么情境下遇到这类问题**
1. 已有闭技能变向 drill，想让它更像比赛、更有反应成分。
2. 需要给敏捷 drill 加时间压力、加防守者、换场地或改规则。
3. 想循序渐进地教后撤跑/侧滑步等过渡动作。
4. 面对高级运动员，要设计认知负荷更高的混沌型 drill。

**语言信号（中英双写关键 trigger）**
- 中文：「这个 drill 怎么加难度」「加时间限制/加防守者」「后撤跑怎么一步步教」「从闭技能过渡到反应性敏捷」「small-sided game 设计」
- English: "manipulate agility drill constraints", "temporal constraint 5 s", "generic to sport-specific stimulus", "backpedal progression", "from closed-skill to reactive agility"

**与相邻能力的区分（初稿，阶段 3 回填）**
- 与 `agility-needs-analysis-to-program`：本卡调**单个 drill**，后者排 block 与时间分配。
- 与 `speed-cod-agility-attribution`：本卡假定已知要练敏捷，只调设计参数。
- 与 `agility-multifactorial-plan`：本卡给 drill 旋钮，后者给三线（力量/技术/知觉认知）总体框架。

## E — 执行 (Execution)

**输入契约**
- 必需：① 目标运动与敏捷情境；② 目标难度/认知负荷（低/中/高）；③ 待改造的 drill（若有）。
- 缺失②时：默认从低认知负荷起步并逐级加，不得一次拉到最高。

**步骤与完成标准**
1. 选机械旋钮：间距/场地维度、进入/退出速度与动量、变向动作与角度、起始姿势（静态/过渡动作）。
2. 选知觉—认知旋钮：攻防人数与位置、时间约束、规则与条件、环境地面、通用→专项刺激、任务复杂度。
3. 设渐进顺序（分支），完成标准 = 每步只加少量负荷：
   - 低：闭技能 COD（无刺激）→
   - 中：加通用刺激（口令/箭头/闪光灯）→
   - 高：加时间约束 → 加专项刺激（真实对手、专项器械）→ 小场对抗/混沌。
4. 过渡移动四步进阶（分支，用于后撤跑/侧滑/交叉跑）：① 标记线上建立正确技术；② 音频口令变速；③ 口令或到标记触发变向（前/后/侧）；④ 追踪移动对手、在其启动变向/冲刺时反应。
5. 判停点：若运动员在任一步无法保持技术质量或时间约束下无法完成 → 退回上一级。

**输出契约**
- `{机械旋钮取值, 知觉—认知旋钮取值, 渐进序列, 每步完成标准}` 的 drill 设计参数 + 进阶路径。

**原文口径（供复算，回查 ch20.txt 1813–1905、1456–1558 行）**
- Table 20.6 六大知觉—认知因素：攻防人数/位置、时间约束、规则条件、环境地面、通用→专项刺激、任务复杂度。
- 后撤跑距离示例 20 yd (18 m)；技术要点：每次触地 toe-to-heel（不得脚跟先着地）、保持髋低。

## B — 边界 (Boundary)

- **不要用**：当目标只是提升预先计划的变向速度、不需要认知成分时（保持闭技能 COD 即可）。
- **作者警告的失败模式**：只加机械难度不加知觉—认知 → 仍是 COD 而非敏捷（ce20-04）；认知负荷一步拉满 → 技术质量崩溃。
- **盲点（BOOK_OVERVIEW 步骤 3）**：各因素**无固定档位**，须按项目与运动员水平调整；变量耦合，加时间约束会同时改变机械负荷；drill 设计的"比赛代表性"收益多为理论/共识推广，迁移证据有限。
- **相邻易混**：`agility-multifactorial-plan`、`agility-needs-analysis-to-program`。
