# 确定与估算 1RM / xRM（Step 5 之测试与估算）

## R — 原文 (Reading)

> "the strength and conditioning professional has the option of determining the athlete's actual 1RM (directly tested), estimated 1RM from an xRM test (e.g., a 10RM), or xRM based on the number of repetitions planned for that exercise (the 'goal' repetitions; e.g., 5 repetitions per set)."

— Chapter 18 · Step 5: 1RM and xRM Testing Options（`ch18.txt` 1333–1337）

## I — 自述 (Interpretation)

要给负荷赋值，先得知道"基准重量"。三条路径：

- **A 直接测 1RM**——适合 intermediate/advanced 且有技术经验者（多数核心动作）；未训练/无经验/伤后/医疗监护者不宜。用 Figure 18.8 的九步增减档迭代；理想 3–5 组内测出。
- **B 由 xRM 估 1RM**——测某个多重 RM（如 10RM），再用 Table 18.9 换算表反查 1RM；适用几乎所有人（技术合格即可）。次数越少越准，高次数倾向高估；长期以低 xRM 训练者估算更准。原文未给预测方程系数。
- **C 按目标次数直接做 xRM**——省去换算（如计划 6 次就测 6RM），常用于辅助动作。

常见组合：核心动作测 1RM、辅助动作用 xRM。约束：辅助动作的测试/赋值**不重于 8RM**（降低对关节与结缔组织的孤立应力，即使核心用 2RM）；**power 动作不宜做 >5 次 xRM**（技术会快速退化）。低 1RM 者（如深蹲 1RM 100 lb）应改用**相对百分比增量**，避免 20–30 lb 绝对增量过大。

## A1 — 案例 / 演练 (Application)

**原书案例（worked-example，c18-8）**：查 Table 18.9，在 "RM = 10（%1RM = 75）" 行找到所测 10RM 负荷，横读至 "RM = 1（%1RM = 100）" 行即得估计 1RM。示例：10RM = 300 pounds → estimated 1RM = **400 pounds**。

**原书案例（worked-example，c18-7）**：3RM hang power clean = 115 lb → estimated 1RM = **124 lb**（源表估算，原文取整）。

**原书案例（worked-example，c18-16）**：深蹲 1RM 约 100 lb 时，20–30 lb 的绝对测试增量过大、不够精确；应改用 Figure 18.8 的相对百分比（上肢 5%–10%、下肢 10%–20%）替代固定磅数增量。

**合成演练（标记：合成；非书中案例）**
- 输入 A：3RM 悬垂高翻＝115 lb。执行：1RM ≈ 115 ÷ 0.93 ≈ 123.7 → **124 lb**（容差 ±1）。输入 B：10RM 深蹲＝225 lb。执行：1RM ≈ 225 ÷ 0.75 = **300 lb**（容差 ±2）。

## A2 — 未来触发 (Trigger)

**用户会遇到这类问题的情境（3–5 条）**
- 用户想知道某动作的 1RM，但只有某次多重 RM 数据（如 5RM、10RM）。
- 用户问"能不能不测 1RM、用几次的量估出来"。
- 用户问辅助/爆发动作该测几 RM、为什么不能太重。
- 用户问"这个运动员该直接测 1RM 还是估"。
- 用户按 %1RM 赋值前需要先确立基准 1RM。

**语言信号（中英双写关键 trigger 词）**
- "由 10RM 估算 1RM" / "estimate 1RM"、"1RM test"、"xRM"、"3RM 是 115 磅，1RM 多少"、"深蹲 10RM 225"、"辅助动作测几 RM"、"能不能不测 1RM"、"要不要直接测最大"、"帮我算 1RM"。
- 英文常见："estimate 1RM from a 5RM"、"how much is his 1RM"。

**与相邻能力的区分（初稿）**
- 与 **load-reps-assignment**：本卡只产出"1RM/xRM 基准"，把它乘目标 %1RM 得训练负荷是后者的活。
- 与 **rpe-rir-srb-load**：当无法频繁测 RM 时用 RPE/RIR/SRB 替代，另卡承载。
- 与 C-testing 簇（测试质量/实施/常模比较）：本卡不展开测试效度信度与常模，聚焦 1RM/xRM 的确定与换算。
- 与 **power-load-assignment**：power 动作的 %1RM 特例由后者承载，本卡只管基准数值。

## E — 执行 (Execution)

**输入契约**
- 必需：训练状态、技术经验、动作类型（core/power/assistance）、能承受的测试负荷（或已有 xRM 实测值与次数）。
- **先询问（缺失不得静默猜值）**：若无任何 RM/1RM 数据且无法测试 → 不得凭空臆造；先询问能否测试或提供某次最大表现。若无训练状态 → 先判定（决定能否测 1RM）。若为低 1RM 者（如深蹲 1RM ≈100 lb）→ 记录并切换相对增量口径。
- 适用条件：1RM 直接测试限 intermediate/advanced + 技术经验者；其余走估算法。

**步骤（每步有完成标准）**
1. **选路径**——完成标准：三选一（A 直接测 1RM / B 由 xRM 估 / C 按目标次数做 xRM）。判停点：若 untrained/injured/medical 或技术不足 → **不走 A**，改 B 或 C；power 动作 xRM 次数 ≤5；辅助动作 xRM ≥8RM。
2. **（路径 B）用 Table 18.9 换算**——完成标准：`1RM ≈ xRM 负荷 ÷ (%1RM_该次数 / 100)`；示例 10RM=300 → 400 lb。舍入：取整到最近 5 lb（与原书应用表一致）。
3. **（路径 A）按 Figure 18.8 迭代**——完成标准：轻负荷热身 5–10 次→休息 1 min→加负荷做 3–5 次（上肢 +10–20 lb/5–10%，下肢 +30–40 lb/10–20%）→休息 2 min→近最大 2–3 次→休息 2–4 min→试 1RM；成功 +同增幅回加负荷步，失败 −（上肢 5–10 lb/2.5–5%，下肢 15–20 lb/5–10%）再试；3–5 组内测出。判停点：低 1RM 者一律用相对百分比代替绝对增量。
4. **交付基准**——完成标准：输出该动作的 1RM（实测或估算）并标注路径与精度提示。

**输出契约**
- 字段：`{ exercise, path(A|B|C), 实测/估计 1RM, 单位(lb|kg), 精度说明 }`。
- 容差：估算结果取整到最近 5 lb；合成演练示例 v 给出 ±1–2 lb 容差用于反查核对。
- 已知原文缺口（本卡不补造）：原文未列任何 1RM 预测方程（Epley/Brzycki 等）的公式与系数，仅指向文献；本卡以 Table 18.9 查表化为准。

## B — 边界 (Boundary)

- **不要**对 untrained、无经验、伤后或医疗监护者直接做 1RM 测试——应改用 3RM/5RM 估算。
- **不要**给辅助动作赋重于 8RM 的负荷；**不要**给 power 动作做 >5 次 xRM。
- **不要**对高次数 xRM 的估算过度自信——次数越多越不准且倾向高估 1RM。
- **常模/时效**：Table 18.9 是过渡性指南，直到运动员具备安全做 1RM–5RM 的神经肌肉条件。
- 数据冲突登记：Ch18 应用表 Scenario B 文本写"Assign 70% of the tested 1RM"，但所列负荷实按 ~75% 计算（650×0.75≈488 等），**属原书内部不一致**；引用该 worked example 时应按 Table 18.11 的区间自行核算。
- 易混淆：与 **load-reps-assignment**（用 %1RM×1RM 定负荷）、**rpe-rir-srb-load**（免测 RM 的替代法）不同——本卡只产出基准 1RM。
