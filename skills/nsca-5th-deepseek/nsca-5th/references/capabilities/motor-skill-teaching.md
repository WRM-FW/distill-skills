# 动作技能教学与实践安排（分解 / 练习次序 / 指导 / 反馈）

## R — 原文 (Reading)

> "tasks that are challenging but have low interrelatedness of the subcomponents are learned better with part practice ... whole practice would tend to be favored for a task with subcomponents that are highly interrelated ... in instances in which the skill may be dangerous or costly to learn as a whole, part practice is the favored choice."

— Chapter 9 · Psychological Foundations of Performance（`ch09.txt:1732-1745`）

## I — 自述 (Interpretation)

运动技能教学的决策树贯穿「分解—练习—指导—反馈」四层：

- **分解决策**：子成分关联度**低**（且挑战性高）→ **part practice**（分解）；子成分**高度关联** → **whole practice**（整体）；**危险/代价高** → 一律 part。
- **拆分方式**：segmentation（沿清晰断点分段，如抓举的 first pull / transition / second pull / catch）；fractionalization（拆同时发生的子成分）；simplification（降难度：改速度或器械，如先用 PVC 管）。
- **重组方式**：pure-part（各部件独立练后再整体）；progressive-part（逐步合并）；repetitive part（每加一部分从头连做）。
- **练习次序**：blocked（同一技能连续多次）vs random（随机顺序练多技能）；可**混合**（每个技能先做少数重复再切换）。random 初期单项表现下降但促进学习。
- **变化练习**：variable（一次课内改变同一技能规格）会削弱当堂表现，但增强对「新变式」的表现与陌生情境适应。
- **观察学习**：身体练习 + 观察练习（结对：一人做、一人在休息期看）增强学习。
- **指导风格**：explicit（给规则与细节）/ guided discovery（给目标与关键提示）/ discovery（只给目标）；发现式拖慢学习，显性指令在高压环境可能损害表现。
- **反馈**：同步反馈提升表现但损害学习（宜比赛）；延迟反馈促进学习；**降低频率**比每次都给更促进学习（技能复杂时例外）；初始阶段密、随水平提高逐步稀疏。
- **提示语**：用最少的话产生最大影响；否则「过度指导」（verbal overshadowing）会破坏流畅动作、阻碍自我纠错；早期偏**外部**提示，精修可转内部。

## A2 — 未来触发 (Trigger)

**用户情境（3–5 条）**
1. 要教一个新动作，问该整体教还是拆开教。
2. 问练习怎么排（组块还是随机、固定还是变化）。
3. 问给多少反馈、什么时候给、什么风格。
4. 提示语怎么写才有效。
5. 动作危险/复杂，担心新手学习过载或受伤。

## E — 执行 (Execution)

**输入契约（必需字段）**
- 技能子成分的关联度；危险/代价高低；运动员学习阶段与经验；任务目标；可用反馈类型（内在/增补、KR/KP）。
- **缺失须先询问**：若不知子成分关联度 → 需拆解动作结构判断；若不知学习阶段 → 问新手/老手。
- 适用条件：动作技能教学；危险动作优先分解。

**步骤（每步有完成标准）**
1. **选 whole/part**——关联度低 → part；关联度高 → whole；危险/代价高 → **一律 part**。完成标准：输出分解策略。
2. **选拆分与重组**——segmentation/fractionalization/simplification；pure-/progressive-/repetitive-part。完成标准：输出拆分与重组方式。
3. **排练习次序**——blocked/random/混合；需要泛化时加 variable practice。完成标准：输出次序。
4. **选指导风格**——新手/低压用 guided discovery 或 discovery；需快速规范用 explicit（但高压情境可能受损）。完成标准：输出风格与理由。
5. **设反馈与提示语**——按学习阶段调频率（初期密→逐步稀疏）；提示语简短、优先外部。完成标准：输出反馈与提示语安排。

**输出契约**
- 字段：`{whole/part, 拆分/重组方式, 练习次序, 指导风格, 反馈时机与频率, 提示语}`。
- 容差：无计算（定性方案）。
- **约束（原文只给方向未给数值，不得静默补值）**：原文**未给统一的「何时切换学习阶段」的硬阈值**；反馈频率与技能复杂度的交互只作定性说明；未给 variable/random 的具体剂量。

## B — 边界 (Boundary)

- **不要**对高度关联的动作强行分解——会妨碍子成分重组（如弓步不宜拆前腿/领先腿）。
- **不要**以当堂表现判断学习——random/variable 会削弱当堂表现但促进学习。
- **不要**对专家级自动化动作植入具体指导性提示——干扰自动化（`ce09-02`）。
- **不要**过度指导（verbal overshadowing）——会引入认知加工破坏流畅性、阻碍自我纠错。
- **作者盲点（3.3）**：分解决策依赖对「关联度」的主观判断；「共识 ≠ 实证」，切换阈值未量化。
- **专业边界（2.2-14）**：危险动作的安全监督与保护规则按簇 F 卡执行。
- **相邻易混**：与 **arousal-psych-skills** 分工——本卡管学习安排，那张卡管唤醒调控。
