# 有效测试的证据本位选择框架（效度/信度双门槛）

## R — 原文 (Reading)

> "Test results are valuable only when two key criteria are met: validity and reliability. ... A test must be reliable to be valid, because highly variable results have little meaning. However, even a reliable test may not be valid, because the test may not measure what it is supposed to measure."

— Chapter 13 · Evaluation of Test Quality（`ch13.txt:166-167, 283-285`）

## I — 自述 (Interpretation)

判断一个测试/指标能不能用，只过两道门，缺一不可：

1. **信度（reliability）** —— 同一对象在能力未变时重复测，结果是否一致。信度是效度的**必要条件**：结果高度飘忽就毫无意义。
2. **效度（validity）** —— 测的是不是它声称要测的那个属性。

两门之间是**单向关系**：稳 ≠ 准。60 m 冲刺和 1.5 英里跑都很稳，但只有 1.5 英里跑能代表有氧能力（60 m 冲刺测的是速度）。所以"稳而不准"的测试照样要拒。

效度本身分层：**构造效度**（construct，总纲）下辖 face（表面）、content（内容）、criterion（效标，含 concurrent 同期、predictive 预测）；构造效度内再分 convergent（与"金标准"高正相关）与 discriminant（与异质构念低相关）。选择逻辑：先证信度，再证效度，两者都达标才采用；若两个测试都有效，取更简单、更经济者。

## A1 — 案例 / 演练 (Application)

**原书未提供单一完整案例**，但给出两个直接判据（`ch13.txt:213-225, 286-288`；`p13-06`）：
- **收敛效度**：1RM 背蹲与等长蹲（需力台）高度相关 → 二者测同一构念（下肢力量）。
- **区分效度**：1RM 背蹲与 V̇O2max 不相关 → 蹲测的是力量、不是耐力。
- **信度≠效度**：60 m 冲刺与 1.5 英里跑都可靠，但对"有氧适能"只有后者有效。

**合成演练（明确标记）**：候选测试 A = "六边形跳（单腿跳 25 m）"用于**新手长跑运动员**；候选测试 B = "60 m 冲刺"用来代表有氧能力。
- 逐条勾选效度九条件（测专项重要能力 / 可重复 / 一次测一人 / 有意义 / 难度合适 / 可区分水平 / 可准确计分 / 足够试次 / 可统计评估）：
- A（单腿跳）：技巧主导（`p13-13`），对新手效度不成立 → **拒绝**；改选与新手技巧匹配的爆发力测试。
- B（60 m 冲刺）：信度成立，但测的是速度、不是有氧 → 效度不成立 → **拒绝**；改选 1.5 英里跑测有氧。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 拿到一套"看起来很流行"的测试清单，要判断该不该用/该不该换。
2. 新买了一个体脂仪/纵跳 App/测力设备，想知道它能不能替代既有方法。
3. 想用某个测试成绩做训练决策，但不确定它测的是不是自己以为的那个能力。
4. 要为一个测试电池做准入审查，逐条说明"为什么留、为什么删"。

**语言信号（中英双写）**：效度 / 信度 / 这个测试准不准 / 能不能用这个测试 / 值不值得测 / validity / reliability / is this test valid / can I trust this test / test quality / 金标准 / gold standard / 替代测试 / concurrent validity / discriminate。

**与相邻能力的区分**：本卡只做"准入判定"（单测试/单指标是否合格）；把合格测试拼成覆盖专项的电池属于 `sport-specific-test-battery`；已用过的测试出现前后不一致的归因属于 `reliability-variability-troubleshoot`。

## E — 执行 (Execution)

**输入契约**：候选测试名 + 目标属性（要测什么能力）+ 已知证据（相关系数/ICC/来源）。缺失"要测什么"必须先问，不得默认为"体能"。

**步骤与完成标准**：
1. **声明构念**：写出该测试声称测量的属性（如"下肢向心爆发力"）。完成标准：一句话属性名，可被证伪。
2. **过信度门**：查是否有重测证据（test–retest、ICC、例如同类研究）。完成标准：给出"有/无可靠证据"的二分判断；无证据 → 标"信度未证，暂缓采用"。
3. **过效度门**：逐条勾选九条件（`p13-02`）：① 测专项重要能力 ② 结果可重复 ③ 一次测一名运动员（协议另有规定除外）④ 看似有意义 ⑤ 难度合适 ⑥ 能区分不同水平 ⑦ 可准确计分 ⑧ 试次足够 ⑨ 可经受统计评估。任一硬条件不满足 → 判"不采用"。
4. **判方向**（若涉及替代/新设备）：convergent = 与金标准高正相关；discriminant = 与异质构念低相关。两者需同时成立。
5. **择优**：若两个候选均有效，选**简单、经济**者（`p13-02`）。
6. **输出结论**。

**输出契约**：每候选一行 `{测试名, 声称构念, 信度判断(是/否/未证), 效度判断(九条命中数), 采用/拒绝, 理由, 替代建议}`。

**判停点/分支**：
- 信度未过 → 直接停，不必评效度（因效度无从谈起）。
- 效度九条件中"测专项重要能力""一次测一人""可准确计分"任一失败 → 停，拒绝。
- 数据不足（既无信度又无效度证据）→ 输出"需先做一致性/效度验证"，不得凭流行度放行。

**约定**：原文未给"可接受标准"的数值阈值（未规定相关系数/ICC 下限），本卡不虚构阈值；只要求"有/无证据 + 九条勾选"。此为实现约定，不改变原意。

## B — 边界 (Boundary)

- **不要**把它当"排序浏览器"：本卡判定的是单测试准入，不负责跨专项配比。
- **不要**用"相关性高"直接等同"因果有效"：concurrent 高相关只是关联证据（`p13-05`）。
- **作者盲点（BOOK_OVERVIEW 3.3-5）**：参数常以"惯例/共识"形式出现，共识 ≠ 实证；"可接受标准"原文未量化，勿把它当权威阈值。
- **常模时效性（3.1）**：测试即使有效，其常模表也来自特定年代/人群/协议，跨年代套用会失真。
- **迁移不保证（3.3-1）**：测试效度成立 ≠ 该测试成绩改善会迁移到专项表现。
- **相邻易混**：与 `sport-specific-test-battery`（电池覆盖）不同；与 `reliability-variability-troubleshoot`（测得飘了怎么排查）不同。
