# 冲刺技术错误排障（症状 → 原因 → 纠正）

## R — 原文 (Reading)

> "Table 20.1 highlights many common sprinting errors as well as possible causes and coaching corrections. Quite often, these errors are the result of the misapplication of forces due to improper coaching cues, insufficient mobility, or disruption to an athlete's normal gait caused by external interference." ... "Instruct the athlete to drive the foot down and back into the track, not paw."

— Chapter 20 · "Technical Errors and Coaching"（`ch20.txt` 第 548–552 行）；Table 20.1（第 721–840 行，含 pawing 条 811–812 行）

## I — 自述 (Interpretation)

冲刺技术问题按"表象 → 可能成因 → 教练纠正"三步排查（Table 20.1），分 START AND ACCELERATION 与 MAXIMUM VELOCITY 两段。常见症状包括：蹲踞起跑臀部过高、驱动期侧向迈步、摆臂过短过紧、颈背过度紧张/后仰、第一步跨过支撑腿膝、过早直立、最高速阶段前侧膝高不足、overstriding、慢性腘绳肌伤/痛、循环式划腿（膝间张开）、额状面错误摆臂。成因多为力传导致错、教练口令误导、柔韧性/活动度不足或步态被外部干扰。纠正的核心不是改表象，而是把力正确传入地面、恢复自然步态、修正口令——例如足部看似水平运动时不要给"扒地"口令（那会破坏垂直力）；overstriding 常源于"加大步幅提速"的错误引导，应让运动员在本道内保持自然步态。输出是"症状→成因→纠正"的诊断+处方，并显式关联腘绳肌损伤边界。

## A1 — 案例 / 演练 (Application)

原书未提供独立运动员案例，Table 20.1 为错误—成因—纠正清单。以下为**合成演练**（明确标记，规则来自 Table 20.1）：

- 输入：运动员 40 m 冲刺全程 overstriding、触地时间偏长；其教练曾用"沿线逐步拉长步点"的 drill 提速。
- 执行：沿排障路径——症状 = overstriding → 原因 = 误解发力（试图用更大触地时间提速、抑制 SSC、降低步频）+ 错误引导 → 纠正。
- 预期输出：命中原书 Table 20.1 第 9 条——"cause = Misunderstanding of force application"、"correction = run in their lane and maintain their natural gait cycle"（第 790–798 行）；同时交叉提示腘绳肌损伤风险（ce20-05，第 800–809 行）。

## A2 — 未来触发 (Trigger)

**用户会在什么情境下遇到这类问题**
1. 看到视频里冲刺技术别扭（摆臂乱、跨步过大、抬膝不足），但不知原因。
2. 运动员反复腘绳肌不适/疼痛，怀疑与冲刺技术有关。
3. 教练给了某个口令（如"扒地""迈大步"）后技术反而变差。
4. 想建立一份按症状查纠正的冲刺技术排障清单。

**语言信号（中英双写关键 trigger）**
- 中文：「冲刺技术不对怎么改」「他总 overstriding」「摆臂穿过身体中线」「腘绳肌老伤和跑姿有关吗」「别再让他扒地了」
- English: "sprint technique errors", "overstriding cause and fix", "arms crossing midline", "pawing cue is wrong", "hamstring injury from sprint mechanics"

**与相邻能力的区分（初稿，阶段 3 回填）**
- 与 `cod-technique-diagnosis`：本卡管**直线冲刺**技术错误，后者管**变向/敏捷**技术四维度。
- 与 `speed-force-metrics-calculation`：本卡做技术归因，不算力学量。
- 与 `speed-method-selection-progression`：本卡修技术，后者选手段/负荷。

## E — 执行 (Execution)

**输入契约**
- 必需：① 具体技术症状（文字/视频观察）；② 发生阶段（起跑/加速/最高速）。
- 可选：既往口令、损伤史（尤其腘绳肌）。
- 缺 ① 时应先观察或索取视频，不得凭空诊断。

**步骤与完成标准**
1. 识别技术症状（对照 Table 20.1 两段清单）。
2. 归因到四类成因：发力错误 / 口令误导 / 柔韧与活动度不足 / 步态被外部干扰。
3. 给出纠正方案（原书"coaching recommendations"）。
4. **判停/分支（症状 → 原因 → 纠正）**：
   - 起跑臀部过高 ← 误解起跑设置 → 双脚间距 1.5–2 脚长，后腿小腿下压至与地面平行。
   - 驱动期侧向迈步 ← 力分配不当 → 向地面蹬/用力推进。
   - 摆臂过短过紧 ← 误解自然摆臂 → 肘向下向后驱动或"拉绳"，手破腰带、于中线回收。
   - 颈背后仰 ← 误解动作 → 头与脊柱成直线，躯干与头同速抬起。
   - 第一步跨过支撑腿膝 ← 蹬伸角过高/上推力过陡 → 摆动腿脚踝交叉切过支撑腿小腿，脚贴近地面。
   - 过早直立 ← 蹬地力不足/头部姿态不当 → 持续向地下蹬，保持自然躯干前倾。
   - 前侧膝高不足 ← 竖腿时仍强撑加速相 → 随小腿/髋到垂直，躯干与头同步直立，感受髋抬升。
   - overstriding ← 误解发力 → 本道内保持自然步态，靠垂直力而非加步幅提速。
   - 慢性腘绳肌伤/痛 ← 活动度不足/骨盆位置差 → 用合适冲刺 drill 发展前/后侧力学，减少骨盆前倾。
   - 循环式划腿（膝间张开）← 施力错误 → "drive the foot down and back into the track, not paw"，配 sprint drill。
   - 额状面错误摆臂 ← 误解动作模式 → 手臂向下向后驱动、躯干直立、于中线附近回收（不越身体中线）。
5. 复核步态是否恢复正常（完成标准：症状消失或改用正确口令后机制改善）。

**输出契约**
- `{症状, 阶段, 成因类别, 纠正口令/动作, 复核结论}`；若涉腘绳肌风险，附损伤边界提示。

## B — 边界 (Boundary)

- **不要用**：当问题是变向/敏捷技术时（用 `cod-technique-diagnosis`）；当需要的是速度负荷而非技术时（用 `speed-method-selection-progression`）。
- **作者警告的失败模式（原书反例）**：ce20-01 用"加大步幅"引导追速度 → overstriding、速度反降、腘绳肌风险↑；ce20-02 摆臂越中线/误把速度受限归因于代谢疲劳；ce20-03 "扒地"错误口令破坏垂直力、过度负荷 SSC；ce20-05 骨盆前倾 + overstriding → 慢性腘绳肌损伤。
- **盲点（BOOK_OVERVIEW 步骤 3）**：技术清单源自特定技术模型（Mann 2011 等），跨人群/项目需重校验；教练专业边界——腘绳肌损伤的诊治属医疗范围，教练应转诊而非自行处理。
- **相邻易混**：`cod-technique-diagnosis`、`speed-force-metrics-calculation`。
