# 训练频率（Step 3：状态×赛季双查表 + 恢复日间距 + split 时机）

## R — 原文 (Reading)

> "When determining training frequency, the strength and conditioning professional should consider the athlete's training status, sport season, projected exercise loads, types of exercises, and other concurrent training or activities."

— Chapter 18 · Step 3: Training Frequency（`ch18.txt` 798–799）

## I — 自述 (Interpretation)

第 3 步定"每周练几次"。输入五个：训练状态、赛季、预期负荷、动作类型、其他并行训练。**频率是"分配方式"而非"总量"**——当周 volume-load 相等时，肥大与力量适应不因频率而异。

核心是**双查表取交集**：
- 按训练状态查 Table 18.4：Beginner 2–3；Intermediate 3–4；Advanced 4–7 次/周（*可一天多次）。
- 按运动季节查 Table 18.7（针对已训练运动员）：Off-season 4–6；Preseason 3–4；In-season 1–3；Postseason 0–3 次/周。
- 两表结果取交集，再结合负荷/动作类型与其他训练负荷下调。

两条硬约束/建议：
- **同肌群恢复日间距**：同一肌群两次压力之间安排**至少 1 天、但不超过 3 天**的休息日（强度高时另论）。低频（如每周 2 次全身）应均匀铺开（周一/周四 或 周二/周五）；排成周一/周三会留出长时间无刺激、可能使训练状态下降（良好训练者短期每周 1 次在合适负荷下可维持力量）。
- **split routine 时机**：中/高级训练者可用分化 routine，在 off-season（强调肥大/高量）适合；preseason/in-season（强调爆发、降量降疲劳）不宜。当 volume 相等时，split 与 total-body 的肥大/力量适应无差异，split 的价值在于同等时间塞进更多动作。

## A1 — 案例 / 演练 (Application)

**原书案例（tabular-example，c18-5）**：三情境频率应用表——A（Advanced，in-season）：状态表 4–7 ∩ 赛季表 1–3 → 指派 **3×/week**（周一/三/五全身，含 push/pull/mix 强调）；B（Advanced，off-season）：4–7 ∩ 4–6 → 指派 **4×/week（split routine）**（周一/四下肢、周二/五上肢）；C（Beginner，preseason）：2–3 ∩ 3–4 → 指派 **2×/week**（周三/周六，重/轻强调），因训练状态与有氧耐力需求而定。

**合成演练（标记：合成；非书中案例）**
- 输入：Advanced 运动员、in-season、其他专项训练重。
- 执行：状态表 4–7 ∩ 赛季表 1–3 → 取交集 **3 次/周**，全身，排周一/三/五，检查同肌群间隔落 1–3 天。
- 预期输出：3 次/周。原书未说明该合成输入的"实际结果"。

## A2 — 未来触发 (Trigger)

**用户会遇到这类问题的情境（3–5 条）**
- 用户问"这个运动员每周该练几次"。
- 用户已定好训练状态或赛季，问频率该取多少。
- 用户问训练日怎么排（隔天？均匀铺开？）。
- 用户问"要不要用分化训练（split routine）"。
- 用户说还有其他专项训练/体力工作，问频率要不要降。

**语言信号（中英双写关键 trigger 词）**
- "每周几次" / "training frequency"、"sessions per week"、"一周练几练"、"训练日怎么排"、"隔几天练一次"、"split routine"、"分化训练"、"全身还是分化"、"还有其他训练怎么排频率"、"赛季节奏"、"恢复日"、"同一个肌群隔多久"。
- 英文常见："how many days per week"、"split or total body"。

**与相邻能力的区分（初稿）**
- 与 **training-status-classification**：本卡消费状态档位（Table 18.4 的键），判档另卡承载。
- 与 **primary-training-goal**：赛季同影响目标与频率，但目标由前者定。
- 与 **exercise-order**：频率定"哪几天练"，顺序定"单次课内怎么排"，分工不同。
- 与 B-periodization 簇：跨周/中周期的减量与 microdosing 编排由周期化承载。

## E — 执行 (Execution)

**输入契约**
- 必需：训练状态（beginner/intermediate/advanced）、运动季节（off/pre/in/post-season）、预期负荷与动作类型、并行训练/体力工作负荷。
- **先询问（缺失不得静默猜值）**：若无训练状态 → 先调用 training-status-classification 判定；若无赛季阶段 → 先问；若有并行专项/有氧训练但未知量 → 询问后再定；不得默认某档。
- 适用条件：已训练运动员查 Table 18.7；非"已训练"者以 Table 18.4 为主并注明。

**步骤（每步有完成标准）**
1. **按状态查上限**（Table 18.4）——完成标准：记下状态档的频率区间（Beginner 2–3｜Intermediate 3–4｜Advanced 4–7）。
2. **按赛季查区间**（Table 18.7）——完成标准：记下赛季档区间（Off 4–6｜Pre 3–4｜In 1–3｜Post 0–3）。
3. **取交集并下调**——完成标准：结合预期负荷/动作类型与其他训练负荷，取两表交集并可能下修。
4. **排布训练日（恢复日间距）**——完成标准：同一肌群两次压力间留 **1–3 天**休息；低频时训练日均匀铺开（周一/周四 或 周二/周五）。
5. **判定 split 时机**——判停点：仅当中/高级训练者 **且** 处 off-season（或时间受限需分散量）→ 用 split；preseason/in-season → 不用 split。
6. **交付**——完成标准：输出每周次数 + 具体训练日排布（含是否 split）。

**输出契约**
- 字段：`{ sessions_per_week, weekday_layout[], split(bool), 依据(两表交集), 同肌群间隔 }`。
- 数值：次数为正整数（Advanced 可含一天多次）；间隔以天计。
- 约定：两表冲突时原文靠场景示例取交集，无形式化裁决规则，本卡采用"取交集 + 按并行负荷下调"；跨周（如周三→下周一）间隔是否接受原文仅以"下降风险"提示，无硬阈值，本卡约定按同肌群 ≤3 天优先。

## B — 边界 (Boundary)

- **不要**用单一表直接定频率——必须"状态 × 赛季"双查表取交集，再用并行训练负荷调整。
- **不要**让同一肌群连续超 3 天无刺激或连续天天压（除分化安排下的相近肌群有 2–3 天恢复）。
- **常模/时效**（BOOK_OVERVIEW 3.1）：频率表来源为特定年代数据，跨语境需校验。
- **变量耦合**（3.3）：频率改一个会牵动量与恢复日安排，不可孤立最优。
- **共识 ≠ 实证**（3.3）：split 与 total-body 等价仅"volume 相等时"成立，实际训练量常不匹配。
- 易混淆：与 **exercise-order**（单次课排序）、**training-volume**（组数次数）不同——本卡只产出"每周几次、哪几天"。
