# 增补剂 / 激素滥用迹象识别与转诊

## R — 原文 (Reading)

> "TABLE 12.2 Signs and Symptoms of Ergogenic Aid Abuse ... Cardiovascular: Lipid profile changes, Elevated blood pressure, Decreased myocardial function ... Endocrine: Gynecomastia, Decreased sperm count, Testicular atrophy ... Musculoskeletal: Premature epiphyseal plate closure, Increased risk of tendon tears ... Psychological: Mania, Depression, Aggression, Hostility, Mood swings"

— Chapter 12 · Table 12.2（`ch12.txt:699-737`）

## I — 自述 (Interpretation)

把「按系统的体征/症状」当作异常线索，反推可能的增补剂或激素使用。这是**参考表 + 提示**，不是诊断工具——教练据此**提高警觉并转介**，而非自行判定。

- **逐系统体征（Table 12.2）**：心血管（血脂谱改变、血压升高、心肌功能下降）；内分泌（男性乳房发育、精子减少、睾丸萎缩、阳痿与暂时不育）；泌尿生殖（男：精子/睾丸体积减少；女：月经紊乱、阴蒂肥大、声音变低、男性化；两性：乳房发育、性欲改变）；皮肤（痤疮、男性型脱发）；肝（肝肿瘤/肝损伤风险升高）；肌骨（**骨骺板过早闭合**、肌腱撕裂风险升高、肌内脓肿）；心理（躁狂、抑郁、攻击性、敌意、情绪波动）。
- **行为线索**：快速体成分变化、情绪/攻击性变化、注射痕迹、秘密使用。
- **用药模式（辅助识别）**：stacking（同时用数种）、cycling（用数周至数月后停）、pyramid（周期内剂量递增、末尾递减）；典型方案平均 **3.1 种药、周期 5–10 周、剂量为替代剂量的 5–29 倍**。
- **其他特征物**：HGH 滥用的肢端肥大相关改变；EPO 滥用的血液黏度风险。
- **边界**：原文**未给「体征 → 具体物质」的确定性映射**，同一表现可由多因造成；该表为参考清单，判读需专业医疗人员介入（低确定性排障）。

## A1 — 案例 / 演练 (Application)

**原书未给「疑似滥用」的处置算例**；`ce12-02`（勿假定运动员剂量 HGH 无害）、`ce12-03`（EPO 心血管风险）为失败边界。以下为**明确标记的合成演练**，按原文清单复算。

**合成演练（标记：合成）**
- 输入：一名男运动员近期出现痤疮加重、情绪攻击性、睾酮抑制样表现与注射痕迹。
- 执行与预期输出：
  (a) 逐系统对照 Table 12.2 收集体征（皮肤/心理/内分泌/肌骨…）；
  (b) 结合行为线索（情绪波动、注射痕迹、秘密性）；
  (c) 得「疑似使用」**警觉清单**；
  (d) 依机构政策与医疗团队沟通/转诊，**不自行诊断**。
- 原书未说明该合成输入的「实际结果」，此处为按清单复算。

## A2 — 未来触发 (Trigger)

**用户情境（3–5 条）**
1. 运动员出现痤疮、情绪波动、男性乳房发育、注射痕迹等，怀疑用类固醇/HGH/EPO。
2. 要一份「按系统核对的可疑体征清单」用于警觉与沟通。
3. 运动员体成分异常快速变化、行为保密，教练不确定怎么处理。
4. 需要明确「什么情况下该转诊、交给谁」。
5. 反兴奋剂教育中要讲滥用的体征。

**语言信号（中英双写）**：滥用体征 / 类固醇 / 增能剂滥用 / 注射痕迹 / 男性乳房发育 / 睾丸萎缩 / 情绪攻击 / ergogenic aid abuse / anabolic steroids / signs and symptoms / gynecomastia / injection marks / 转诊 / Table 12.2。

**与相邻能力的区分（初稿）**
- 与 **supplement-evidence-evaluation**：本卡管滥用体征识别与转诊；「用不用」的四维判定归那张卡。
- 与 **ergogenic-dosing-evidence**：各物质剂量与证据分级归那张卡。
- 与 **banned-substance-reference**（reference）：禁用物质名称对照归 glossary/overview。
- 与 **mental-health-referral**：一般心理困扰的三步转诊另卡承载；本卡识别的是可能与物质滥用相关的心理/躯体体征。

## E — 执行 (Execution)

**输入契约（必需字段）**
- 可观察/可自报的体征（按 Table 12.2 系统分类）；运动员行为线索（体成分变化、情绪、注射痕迹、秘密性）；机构政策与可转诊医疗资源。
- **缺失须先询问/观察，不得静默猜值**：体征需逐系统采集；不得由单一表现推定具体物质。
- 适用条件：所有运动员；识别目的，非诊断。

**步骤（每步有完成标准）**
1. **逐系统收集体征**——对照 Table 12.2（心血管/内分泌/泌尿生殖/皮肤/肝/肌骨/心理）。完成标准：输出命中的各系统体征。
2. **结合行为线索**——体成分快速变化、情绪波动、注射痕迹、秘密性。完成标准：输出行为线索清单。
3. **注意特征物**——HGH（肢端肥大相关）、EPO（血液黏度风险）特征性体征。完成标准：输出相应警觉项。
4. **转诊触发（判停）**——将体征作为「提高警觉并转介」的依据，**不自行诊断**；按机构政策与医疗团队沟通。完成标准：输出转诊/沟通动作。

**输出契约**
- 字段：`{各系统可疑体征, 行为线索, 转诊触发, 沟通动作}`。
- 容差：无计算（定性清单）。
- **约束（原文只给方向未给数值，不得静默补值）**：原文**未给「体征 → 具体物质」的确定性映射**；同一致表现可由多因造成；部分 SARM/肽的副作用证据缺乏；该表为参考清单，属低确定性排障，判读须专业医疗人员介入。

## B — 边界 (Boundary)

- **不要**把体征当确诊依据——同一表现可由训练、疾病、其他药物造成；须专业医疗判读。
- **不要**自行处置或对运动员定性——教练只提高警觉、按政策沟通并转介。
- **不要**假定运动员剂量的 HGH「无害」——远超替代剂量（`ce12-02`）。
- **不要**忽视 EPO 的心血管风险——血黏度升高、血栓、脑/肺栓塞（`ce12-03`）。
- **作者盲点（3.1/3.3）**：体征映射不唯一；剂量统计多为自述数据；「共识 ≠ 实证」。
- **专业边界（2.2-14）**：诊断与处置归医疗专业人员；教练职责是识别与升级。
- **相邻易混**：与 **supplement-evidence-evaluation** 分工——本卡识别体征，那张卡判「用不用」。
