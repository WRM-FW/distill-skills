# 描述统计、数据标准化与运动员画像

## R — 原文 (Reading)

> "The z-score can be used to express the distance of any individual score in standard deviation (SD) units from the mean. ... Graphs can be a useful way of representing z-scores visually. This can provide the strength and conditioning professional with a comparison of different physical capacities and provide assistance with making decisions on which weaknesses to target with a training program."

— Chapter 14 · Statistics / Athletic Profile（`ch14.txt:1629-1633`）

## I — 自述 (Interpretation)

这一步把一摞原始测试分数变成**可比较、可决策**的标准化画像。

- **描述统计**：集中趋势（均值 / 中位数 / 众数）与离散度（极差 / 标准差）。样本 SD = √(Σ(x − x̄)² / (n − 1))；分数近似正态时 SD 最有用。
- **标准化**：z 分数 z = (x − x̄) / SD，表示个体分数距均值多少个 SD。**方向要治理**——时间类指标越小越好，所以 40 码冲刺的负 z 反而是"好"。
- **百分位秩**：得分低于该个体的受测者百分比（需先从小到大排序）。
- **四种分析路径**：① 纵向（差值分 / 百分比变化）② 横向历史 ③ 组内（z / 百分位）④ 外部常模。
- **运动员画像六步**：选贴近专项的测试 → 选有效可靠测试并排序留足休息（如两项间 ≥10 min）→ 尽量多人施测 → 定 SWC 并对照常模（建议自建常模）→ 重复测试并可视化 → **用结果识别强弱项、指导编程**。

核心用途：把不同量纲的体能测试用 z 分数柱状图并列，定位应优先补强的弱项。

## A1 — 案例 / 演练 (Application)

**类型：worked-example（原书算例 `c14-01`）＋ sample-program（`c14-11`）。**

- **z 分数（原书算例 `c14-01`）**：40 码冲刺 4.6 s，组均 5.00 s、SD 0.33 s → z = (4.6 − 5.00) / 0.33 = **−1.2**，即比组均**快** 1.2 个 SD（时间类，负 z = 好）。
- **SD 合成演练（明确标记）**：组内成绩 [10,12,14,16,18]（40 码，单位 s）→ 均值 14、偏差 −4/−2/0/2/4、平方和 40 → SD = √(40/4) = **3.16 s**。原书未给此组具体数值，属合成。
- **运动员画像（原书样例 `c14-11`）**：摔跤选手电池含拉力量、推力量、局部肌耐力；示例测试 = 定时最大重复俯卧撑 + 仰卧起坐，**两项间隔 ≥10 min** 休息以保证成绩准确（原书未给具体得分）。可视化判弱项见 `c14-12`（z 柱状图 → 决定补耐力/柔韧/体成分）。

## E — 执行 (Execution)

**输入契约（必需字段）**：用于 z 分数需 `x`（个体分数）+ `x̄`（组均值）+ `SD`（组标准差），三者**单位必须一致**；用于 SD 需全组各分数 `x_i` 与 `n`；用于画像需 `专项/位置` + `候选测试清单`。**缺"指标方向（越大越好 or 越小越好）"须先问，不得静默假定**。

**步骤与完成标准**：
1. **算描述统计**：`x̄ = Σx / n`；`SD = √( Σ(x − x̄)² / (n − 1) )`（样本口径，n−1）。完成标准：输出 x̄ 与 SD，单位同原始分。
2. **算 z 分数**：`z = (x − x̄) / SD`。完成标准：输出 z（无量纲），保留 1–2 位小数。
3. **治理方向**：时间/用时类（冲刺、敏捷、折返）标记为"越小越好"；负 z 表示优于均值。完成标准：给出"好/弱"的**方向校正后**标签。
4. **（可选）百分位秩**：先排序，百分位 = 低于该分数者占比。完成标准：输出百分位与描述词（读表口径见 `norms-lookup-interpretation`）。
5. **（可选）画像六步**：选测→选有效可靠测试+排序（两项间 ≥10 min）→多人施测→定 SWC+对照常模→重复测试可视化→产出强弱项清单。完成标准：输出可视化画像（z 柱状图）与**排序后的弱项清单**。

**输出契约**：`{x̄, SD, z, (可选)百分位, (可选)弱项清单/画像}`。

**容差与舍入**：SD 与 z 保留 2 位小数（原文 z 报 −1.2）；判定容差 ±0.01（对应原文 −1.21 四舍五入为 −1.2）。

**分支/判停**：
- 若少数极端分把均值拉偏 → 建议改用中位数（原文：中位数在均值不能代表多数人时更优）。
- 若各指标单位/方向不同 → 必须先标准化（z）再合并，**禁止**直接对原始分求和。

## B — 边界 (Boundary)

- **方向陷阱**：不同测试"越好数值越大/越小"不同，跨能力比较前必须校正方向，否则会把"冲刺快"误判为弱项。
- **SD 前提**：标准差在近似正态分布时最有用；偏态分布应改中位数 + 极差。
- **作者盲点（3.1）**：常模/描述性数据表来自特定年代与人群，跨年代套用会失真。
- **共识 ≠ 实证（3.3-5）**：画像中各指标如何配比/加权，原文未给规则（gap），勿把等权求和当定论。
- **单次数据意义有限（3.3-2）**：单次 z 分数不等于"需要干预"；须结合趋势与专项。
- **迁移不保证（3.3-1）**：组内 z 高低是相对位置，不直接代表专项表现。
- **相邻易混**：本卡算 z 与组内分布；"变化是否达到实践意义"归 `swc-effect-size`。
