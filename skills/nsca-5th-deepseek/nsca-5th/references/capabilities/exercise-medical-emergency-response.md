# 环境与医疗急症现场识别与处置（热病 / 横纹肌溶解 / 镰状细胞特质 / 低温症）

## R — 原文 (Reading)

> "core body temperatures in excess of 109.4 °F (43 °C) have been associated with death. Immediate total body cooling measures must be implemented such as total body immersion in ice." / "If rhabdomyolysis is suspected, immediately discontinue activity, lie the client down, implement proper hydration protocols, and closely monitor to ensure stability while awaiting further medical assistance."

— Chapter 23 · Medical Conditions（`ch23.txt` 第 1224–1230、1097–1101 行）

## I — 自述 (Interpretation)

这是"**识别信号 → 现场处置 → 升级/转诊**"的现场排障卡，覆盖四类可能致命的状况：

1. **热病连续谱**（热调节失衡，逐级进展，前一档未控即升级）：
   - **热痉挛**：大肌群痉挛/不自主持续收缩；可无核心体温升高。→ 停训、移至阴凉、补水、冷却、被动轻柔拉伸/按摩。
   - **热晕厥**：晕眩/头晕、昏倒。→ 仰卧位并抬腿高于心脏；清醒后口服补水；低血压/频繁晕厥 → 就医。
   - **热衰竭**：无法继续运动、苍白、虚弱、头痛、恶心、核心温可**升至 104.9 °F（40.5 °C）**。→ 移离热环境、口服补水（呕吐则考虑静脉）、**强制风/喷温水等积极降温**；无效则**全身冰浴**。
   - **热射病（医疗急症）**：心率快、低血压、出汗（可能已蒸发）、意识改变、抽搐、昏迷；**核心温 >109.4 °F（43 °C）与死亡相关**。→ **立即全身冰浴降温** + **监测核心体温** + **呼叫 EMS**（无随队医疗时）。
2. **横纹肌溶解**：骨骼肌崩解、肌红蛋白入血，可致肾损伤/衰竭。信号：**严重肌痛与无力、深色（可乐色）尿（myoglobinuria）、肿胀、压痛**，伴疲劳、恶心、呕吐、意识模糊；重度可脱水、电解质紊乱、急性肾损伤。→ **立即停训、平躺、实施补水、密切监测，等待医疗援助**；**须迅速转诊**。预防 = 合理处方，避免过量/不习惯的强度、量、时长。
3. **镰状细胞特质（SCT）**：一个异常+一个正常血红蛋白基因；在**极端运动/低氧**下红细胞镰变、聚集、血管阻塞。信号：疲劳、疼痛、手足肿胀、视力问题；可致血管损伤、贫血、卒中，与极端运动猝死相关。→ **立即停训、移离极端温度环境、立即补水**；有急性症状 → **立即转诊**。预防：识别诱因、教育、气候适应、**强度≤无氧阈**、积极整理活动促乳酸清除。
4. **低温症**：体温 <95 °F（35 °C）→ 生理功能降低乃至关闭。早期：**寒战、皮肤苍白干燥、肌张力增高**；可伴心率/血压/呼吸升高。→ 立即用环境与衣物保暖；**监测体温**；**核心温 <89.6 °F（32 °C）可致心血管衰竭**。注意：**人体对冷环境几无适应**。

## A1 — 案例 / 演练 (Application)

**合成演练（明确标记，按原文分级处置复算）**：八月，某橄榄球运动员训练中出现**意识改变、核心体温 41 °C、皮肤灼热**。
- 判为**热射病（医疗急症）** → 立即**全身冰浴降温** + 持续监测核心体温 + 呼叫 EMS（无随队医疗时）。
- **不**采用仅"强制风/喷温水"的较轻措施（那是热衰竭档的处置）。
- 依热病连续谱前置识别：热衰竭未控即进展为热射病——因此现场须能识别前驱档。

**原书素材**：原文以各状况的**症状—处置表**呈现（`ch23.txt` 第 1072–1263 行），**未给完整病例**。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 高温/高湿训练中出现**痉挛、头晕、昏倒、恶心、意识改变**，问怎么办。
2. 剧烈运动后**深色尿、严重肌痛无力**，怀疑横纹肌溶解。
3. 已知**镰状细胞特质**者在极端运动/低氧环境下出现问题。
4. 冷环境中出现寒战、皮肤苍白、意识变化。
5. 问"什么时候该教 EMS、什么时候只需现场处理"。

**语言信号（中英双写）**：中暑 / 热射病 / 热衰竭 / 热痉挛 / 热晕厥 / 横纹肌溶解 / 可乐色尿 / 深色尿 / 镰状细胞 / 低温症 / 失温 / 呼叫 911 / heat stroke / heat exhaustion / rhabdomyolysis / myoglobinuria / sickle cell trait / hypothermia / EMS / emergency。

**与相邻能力的区分（初稿）**：本卡管"**现场识别与立即处置**"。**应急预案的构成与角色分工/演练** → `cap.nsca.emergency-action-plan`；**法律后果/过失** → `cap.nsca.risk-management-and-negligence`；**能否训练/放行** → `cap.nsca.rehab-scope-and-referral`。**与"测试与评估"不同**：那是测量；**与"周期化"不同**：那是编排；本卡是**急症现场处置**。

## E — 执行 (Execution)

**输入契约（必需）**：现场**症状**（按上表逐项核对）；**环境**（温/湿/冷/海拔）；已知病史（SCT、哮喘等）；**是否有随队医疗/EMS 可达性**。**可选**：核心体温（若可测）。
- **缺失处理**：体温计不可用 → 依症状分级处置，**不因测不到体温而延迟降温/呼叫**。

**步骤（识别 → 处置 → 升级/转诊分支）与完成标准**：
1. **识别归类**：把观测量对照四类状况的**信号清单**归类。完成标准：给出"疑似类别 + 命中信号"。
2. **立即现场处置**（按类）：
   - 热病：移离热环境 → 补液/冷却 → 热射病立即**全身冰浴 + 监测核心温**。完成标准：降温措施已启动，热射病已冰浴。
   - 横纹肌溶解：停训、平躺、补水、密切监测。完成标准：措施落实。
   - SCT：停训、移离极端温度、补水。完成标准：措施落实。
   - 低温症：保暖、监测体温。完成标准：保暖措施启动。
3. **升级/转诊判据**：满足任一 → **呼叫 EMS/转诊**：热射病（**无条件**）；横纹肌溶解**疑即转**；SCT **有急性症状即转**；低温**重度/核心 <32 °C**；热晕厥伴低血压或反复。
4. **持续监测**：热射病测核心温、横纹肌溶解监测稳定性、低温症测体温。完成标准：有监测记录。
5. **移交与记录**：交 `cap.nsca.emergency-action-plan` 的步骤（通知、记录）。完成标准：事件已记录。
6. **输出处置结论**。

**输出契约**：`{疑似类别, 命中信号, 现场处置, 是否升级/转诊, 监测记录, 后续去向}`。

**原文缺口（如实标注）**：**补液量、降温目标温度、复温速率、发病环境温湿度阈值原文未给**；分级间**无连续温度切点**（仅有热衰竭上限 40.5 °C 与中暑致死相关 43 °C，低温 <35 °C、<32 °C 可致心血管衰竭）。本卡**不虚构这些数值**，一律以"症状分级 + 立即降温 + 疑即转诊"为执行准则。

**判停点/分支**：
- 热射病 → 冰浴 + EMS，**不**用较轻措施替代。
- 横纹肌溶解/SCT 急性症状 → 转诊，不"观察看看"。
- 症状不及急症阈值 → 现场处理 + 监测，恶化即升级。
- 涉及医疗判断/给药 → 转医疗人员（`cap.nsca.rehab-scope-and-referral`）。

## B — 边界 (Boundary)

- **不要**用较轻措施处理热射病（如仅强制风）；热射病必须全身冰浴 + EMS。
- **不要**因"测不到体温"或"看起来还行"而延迟降温/呼叫。
- **不要**把横纹肌溶解/SCT 急性症状当作普通酸痛观察——**疑即转诊**。
- **原文自认的缺口（B 段主依据）**：补液量、降温目标、复温速率、温湿度阈值**均未给**，分级间无连续温度切点（`_verified` 缺口 U10）——本卡**不补造**。
- **法域/应急语境**：原文以美国 EMS/911 体系为背景，明注 "or a comparable local emergency response provider"；**跨法域须替换为当地应急号码与流程**。
- **作者盲点（3.2 西方/北美语境 + 2.2-14）**：本卡默认有医疗/EMS 可及；资源匮乏场景下须优先建立应急联系，且**不得**由体能教练补位做医疗处置。
- **不替代专业急救训练**：本卡是识别与现场动作的提示，不能替代 CPR/AED/急救认证与演练。
- **相邻易混**：`cap.nsca.emergency-action-plan`（EAP 构成）、`cap.nsca.risk-management-and-negligence`（法律责任）。
