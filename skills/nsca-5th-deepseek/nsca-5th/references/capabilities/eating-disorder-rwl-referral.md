# 进食障碍与快速减重识别与转诊（安全相关）

## R — 原文 (Reading)

> "Potentially dangerous weight loss techniques may include fasting, fad diets, voluntary dehydration (diuretics, sauna, water and salt manipulation, wearing multiple layers of clothing), excessive spitting, self-induced vomiting, laxative abuse ... It is not the responsibility of the strength and conditioning professional to treat or diagnose an eating disorder."

— Chapter 11 · Nutrition Strategies for Maximizing Performance（`ch11.txt:1464-1468, 1701-1702`）

## I — 自述 (Interpretation)

这是高死亡风险问题上的**识别—记录—转诊**路径，核心是明确教练的**专业边界**。

- **识别失调进食信号**：限制性进食、禁食、跳餐、服减肥药/泻药/利尿剂（未达进食障碍完整诊断标准）。高危人群：有体重级别的项目（摔跤）、强调瘦的项目（越野跑）、审美类项目（体操）。
- **识别进食障碍亚型**：神经性厌食（极端限制、过度运动、怕胖、体像扭曲、否认严重性——**所有精神障碍中死亡率最高**）；神经性贪食（反复暴食后催吐/过度运动/泻药利尿剂，每周至少一次持续 3 个月，常为正常体重）；暴食障碍（每周至少一次持续 3 周、失控暴食伴 ≥3 项特征）；ARFID、异食癖、反刍障碍各有判据。
- **识别危险减重（RWL）手段**：禁食、流行饮食、**主动脱水**（利尿剂、桑拿、水盐操控、多层衣物）、过度吐口水、自我诱导呕吐、滥用泻药、不当/过度用产热剂。后果：脱水、热病、肌痉挛、激素失衡、电解质紊乱、肾衰、昏厥，极端情况**死亡**。
- **角色边界（关键）**：**不诊断、不治疗**进食障碍；伦理职责是帮助运动员获得合格医生的诊断与合格团队的治疗。须预先建立**转诊网络**（心理 + 医疗 + 营养专家）。异常进食模式与闭经**单独出现**不等于进食障碍，须由有经验的专业人员评估。
- **处置动作**：识别并记录 → 通知教练组 → 转介多学科团队 → 与医生/营养师共同设定安全体重目标 → 若无法安全达标，考虑改换体重级别。

## A2 — 未来触发 (Trigger)

**用户情境（3–5 条）**
1. 体重级别/瘦身导向项目的运动员快速减重，出现脱水/跳餐/用利尿剂等行为。
2. 怀疑运动员有进食障碍（厌食/贪食/暴食），问该不该管、怎么管。
3. 运动员体重骤降、闭经、反复骨应力伤，且进食异常。
4. 教练被要求「帮运动员达标体重」但怀疑手段危险。
5. 需要建立或确认转诊网络。

**语言信号（中英双写）**：进食障碍 / 厌食 / 贪食 / 暴食 / 快速减重 / 减重 / 脱水 / 桑拿 / 利尿剂 / 泻药 / 催吐 / 跳餐 / eating disorder / anorexia / bulimia / binge eating / rapid weight loss / weight cutting / dehydration / diuretics / laxative / referral / 2-3 weeks。

## E — 执行 (Execution)

**输入契约（必需字段）**
- 红旗信号（月经失调/闭经、反复骨应力伤、体重骤降、暴食-清除行为）；危险减重手段使用迹象；EA/FFM（如可用）；既往病史；进食行为描述。
- **缺失须先询问**：若怀疑进食障碍但证据不足 → 继续观察并记录，不擅自结论；若不知转诊资源 → 先确认本地网络。
- 适用条件：所有运动员；**出现红旗即刻进入本流程**。

**步骤（每步有完成标准）**
1. **识别**——对照红旗清单（失调进食信号、各亚型特征、RWL 手段）。完成标准：列出命中的具体信号。
2. **记录并通知**——记录已采取的步骤、通知教练组关切。完成标准：留下书面记录。
3. **不诊断不治疗**——完成标准：明确声明教练不越界；不自行开方案。
4. **转介多学科团队**——转介队医/注册营养师/心理专业人员。完成标准：输出转诊对象与沟通动作。
5. **共同设定安全体重目标**——与医生/营养师在体成分、饮食、医疗与进食障碍史评估后共同设定；**若无法在安全/不损表现下达标 → 考虑改换体重级别**。完成标准：输出体重目标或级别变更建议。
6. **转诊判停**——凡出现主动脱水/催吐/滥用泻药/体重骤降 → **停止训练相关自行处置**，立即转诊。

**输出契约**
- 字段：`{命中红旗, 记录, 转诊对象, 安全体重目标/级别变更建议, 是否停止处置}`。
- 容差：无计算（定性清单）。
- **约束（原文只给方向未给数值，不得静默补值）**：原文**未给**「复杂 vs 一般」的清晰分界标准、未给各症状的量化识别阈值；异常进食 + 闭经单独存在不构成诊断。教练资质边界须与本地多学科团队配合。

## B — 边界 (Boundary)

- **不要**把 RED-S/进食障碍当体能或纪律问题自行干预——须识别并转诊（`ce11-04`）。
- **不要**自行诊断或治疗进食障碍——这是伦理与能力双重边界；教练只做识别、记录、通知、转介。
- **不要**仅凭「异常进食 + 闭经」就下诊断——原文明确二者单独出现不指示进食障碍。
- **不要**在无安全体重目标的情况下让运动员继续减重到比赛——必要时改换体重级别。
- **作者盲点（3.1/3.3）**：进食障碍为多因素疾病，需多学科团队；筛查工具与阈值原文未给。
- **专业边界（2.2-14）**：教练的专业边界是**识别 + 升级转诊**；诊断与治疗归合格医疗/心理/营养团队。
- **相邻易混**：与 **energy-availability-red-s** 分工——本卡管进食障碍/RWL，那张卡量化 LEA。
