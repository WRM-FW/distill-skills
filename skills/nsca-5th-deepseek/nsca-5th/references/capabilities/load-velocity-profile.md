# 负荷-速度剖面（VBT）建立与 1RM 预测禁用

## R — 原文 (Reading)

> "when the 1RM back squat is estimated from the load–velocity profile, it is highly variable and consistently results in an overestimation of the athlete's 1RM and should not be used for 1RM prediction. ... As such, it is generally recommended that the 1RM should be directly tested"

— Chapter 14 · Velocity-Based Testing（`ch14.txt:136-143`）

## I — 自述 (Interpretation)

基于"杠速随负荷增加而线性下降"的逆向关系，用速度类设备建立**个体化负荷-速度剖面**：

- **构建**：以 1RM 的 **20%/40%/60%/80%/90%** 逐级加负荷做若干组，记录各负荷对应的杠速（m/s），拟合负荷-速度线性关系。
- **用途**：评价与处方抗阻训练**强度**；用杠速而非单纯的 %1RM 来度量强度。

**硬性禁用规则**：**不得**用剖面反推 1RM。由 L-V 剖面估算背蹲 1RM **高度可变且系统性高估**，会导致训练负荷误编程，甚至开出超过运动员能力的负荷。要确定最大力量，**直接测 1RM**。

## A1 — 案例 / 演练 (Application)

**原书未提供完整数值案例**，只给构建口径与禁用规则（`f14-06`、`p14-06`、`ce14-01`）。

**合成演练（明确标记）**：某运动员在 back squat 上取 5 个负荷点（20–90% 1RM）的平均杠速。
- 拟合出个体化 L-V 关系 → 用于强度评价与处方。
- **明确拒绝**用它反推 1RM；改直接测 1RM。
- 结论：输出个体化剖面 + "不得估 1RM"的边界（原文未给该运动员的具体剖面数值）。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 用 VBT 设备做测试，问怎么建负荷-速度剖面、怎么用。
2. 有人想用杠速数据"算出 1RM"，问可不可行。
3. 要个体化地评价/处方训练强度。
4. 手头有各负荷点的杠速数据，要判断怎么用。

**语言信号（中英双写）**：负荷-速度 / VBT / 杠速 / 速度剖面 / 用速度估 1RM / load-velocity profile / bar velocity / velocity-based training / m/s / 强度处方 / estimate 1RM from velocity。

**与相邻能力的区分**：本卡管"VBT 剖面的构建与使用边界"；直接测最大力量归 `max-strength-test-protocols`（本卡**禁用** L-V 估 1RM）；跳跃/爆发力的速度指标归 `jump-power-test-protocols` 与 `rsi-eur-calculation`。

## E — 执行 (Execution)

**输入契约**：VBT 设备类型 + 动作（如 back squat）+ 各负荷点的 %1RM 与对应杠速(m/s)。缺"动作"与"负荷点"须先问。

**步骤与完成标准**：
1. **布置设备**：按采集类型布线（线性位移传感器置于杠下连杠；IMU 固定于杠）。完成标准：设备就位且能导出数据。
2. **取点**：以 20/40/60/80/90% 1RM 逐级做组，记录每组杠速。完成标准：≥4 个负荷点的速度数据。
3. **拟合**：拟合负荷-速度线性关系（负荷为自变量、速度为因变量）。完成标准：给出斜率/截距或关系式，说明拟合优度。
4. **使用（评价/处方强度）**：用该关系把目标速度映射到强度。完成标准：给出"目标速度 → 推荐强度"的对照。
5. **禁止项校验**：确认**未**用剖面反推 1RM。完成标准：若用户要求估 1RM → 拒绝并改直接测 1RM。
6. **输出**。

**输出契约**：`{动作, 负荷点-速度数据, 拟合关系, 强度处方对照, 明确声明"不用于预测 1RM"}`。

**判停点/分支**：
- 用户要求"用 VBT 估算 1RM" → 直接判停，提示直接测 1RM。
- 负荷点 <4 个 → 标"剖面可靠性不足"。

**约定**：原文未给每组重复次数、组间休息、拟合方法（`f14-06` gap），也未量化"highly variable"的误差幅度。本卡要求写明所用方法，标为约定，不虚构数值。

## B — 边界 (Boundary)

- **不要**用剖面/速度阈值估算 1RM——系统性高估、可致负荷超过运动员能力（`ce14-01`）。
- **不要**把群体速度带当个体剖面：个体 L-V 关系可能不同。
- **作者盲点（3.3-5）**：速度阈值/剖面方法含惯例成分，共识 ≠ 实证。
- **迁移不保证（3.3-1）**：剖面用于强度评价 ≠ 改善会转化为专项表现。
- **工具时效（3.1）**：VBT 设备快速迭代，具体设备可靠性须逐台验证。
- **相邻易混**：与 `max-strength-test-protocols`（直接测 1RM）是互补但**边界相反**的关系：VBT 不估 1RM，1RM 不靠 VBT。
