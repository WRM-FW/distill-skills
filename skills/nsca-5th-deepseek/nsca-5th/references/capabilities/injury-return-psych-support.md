# 伤后重返训练的心理支持

## R — 原文 (Reading)

> "strength and conditioning professionals should maintain regular communication with all athletic trainers, position coaches, parents (if appropriate), and head coaches ... every effort should be made to customize the training program to accommodate the athlete's current abilities and limitations."

— Chapter 9 · Psychological Foundations of Performance（`ch09.txt:1642-1662`）

## I — 自述 (Interpretation)

把「身体过关就上场」改为**兼顾心理准备**的支持流程。背景是**压力—损伤模型**（人格因素 / 应激源史 / 应对资源三类因素共同影响受伤风险）与**认知评估模型**（个人 / 情境 / 行为 / 情绪四维评估伤后反应）。教练可执行的**六项行动**：

1. **定期沟通**——与运动防护师、位置教练、家长（若适当）、主教练保持定期沟通，衔接康复各阶段，确保介入循序且同步、避免过快推进导致再伤；全程保护隐私与保密。
2. **定制训练**——按伤病严重度定制动作、节奏、器械、安排（可更小更私密），**尽最大努力适配运动员当前能力与限制**。
3. **目标设定与里程碑**——目标对准**可控因素**（「我来了吗？做了 10 次吗？」）且具弹性，肯定训练里程碑。
4. **渐进整合**——从一对一私人康复逐步过渡到团队活动，满足「关联性」这一内在动机需求。
5. **提升自我效能与动机**——营造心理安全、支持自主的环境，防止恐惧/焦虑成为障碍，聚焦过程目标。
6. **警惕心理—身体不同步**——心理与身体准备往往**不同速**；警惕「忍痛上场被误当英雄」的文化。

## A1 — 案例 / 演练 (Application)

**原书未给单一运动员的伤后支持算例**；`ce09-03`（心理与身体恢复不同步）为失败边界。以下为**明确标记的合成演练**。

**合成演练（标记：合成）**
- 输入：一名 ACL 术后 3 个月、身体已放行但明显怕再伤的足球运动员。
- 执行：
  (a) 与运动医学队/教练/家长定期沟通，掌握康复各阶段；
  (b) 按当前能力订制动作/节奏/器械；
  (c) 设可控目标（「今天来了吗 / 做了 10 次吗」）并肯定里程碑；
  (d) 从一对一渐进到团队活动；
  (e) 营造心理安全、支持自主环境，降低恐惧。
- 原书未说明该合成输入的「实际结果」，此处为按六项行动复算。

## A2 — 未来触发 (Trigger)

**用户情境（3–5 条）**
1. 运动员伤后身体已放行，但明显怕再伤、不敢全力。
2. 要设计伤后从个体康复到团队回归的支持流程。
3. 要跟医疗队/教练/家长协调康复各阶段的训练。
4. 运动员康复中出现挫折、无聊、哀伤、冒险行为。
5. 想避免「忍痛上场被当英雄」的文化。

**语言信号（中英双写）**：伤后 / 重返赛场 / 康复 / 怕再伤 / 心理支持 / 再伤恐惧 / return to play / rehabilitation / fear of reinjury / return-to-sport / psychological readiness / 沟通 / 里程碑 / 自我效能。

**与相邻能力的区分（初稿）**
- 与 **mental-health-referral**：本卡管伤后重返支持；临床/心理健康困扰的识别与转诊归那张卡。
- 与 **arousal-psych-skills / motor-skill-teaching**：唤醒调控与技能教学另卡承载。
- 与 **rehabilitation-***（若簇 H/其他）：康复负荷进阶的医学进阶归医疗团队与相关卡。

## E — 执行 (Execution)

**输入契约（必需字段）**
- 损伤性质（急性/慢性、既往史）；运动身份认同；人格/疼痛耐受/应对技能；情境因素（项目、竞技层级、社会支持、医疗团队、康复环境、教练态度）；行为与情绪反应（依从性、冒险、恐惧、挫折、悲伤）。
- **缺失须先询问**：若不知康复阶段 → 与医疗团队沟通确认；若出现临床心理困扰 → 转 mental-health-referral。
- 适用条件：伤后重返训练者；涉及临床问题须转诊。

**步骤（每步有完成标准）**
1. **定期沟通**——与运动防护师/位置教练/家长/主教练沟通，掌握各阶段。完成标准：输出沟通计划与对象。
2. **定制训练**——按当前能力与限制定制动作/节奏/器械/安排。完成标准：输出个体化方案。
3. **设可控目标**——过程目标 + 肯定里程碑。完成标准：输出目标清单。
4. **渐进整合**——从一对一过渡到团队活动。完成标准：输出过渡路径。
5. **提自我效能**——营造心理安全、支持自主环境，降低恐惧。完成标准：输出支持措施。
6. **警惕不同步**——识别心理未就绪信号，必要时升级转诊。

**输出契约**
- 字段：`{沟通计划, 定制方案, 目标与里程碑, 团队过渡路径, 心理安全措施, 是否升级}`。
- 容差：无计算（定性流程）。
- **约束（原文只给方向未给数值，不得静默补值）**：原文以认知评估模型为背景，**未给量化评估工具**；教练心理服务边界须与心理专业人员配合；各阶段过渡的具体时间窗未给。

## B — 边界 (Boundary)

- **不要**以身体康复进度为唯一判据——心理与身体恢复往往不同步（`ce09-03`）。
- **不要**在心理未就绪时推运动员全力/上场——可致再伤或表现受损。
- **不要**强化「忍痛上场被当英雄」的文化。
- **不要**越界做临床心理处理——持续/严重信号转 mental-health-referral。
- **作者盲点（3.1/3.3）**：评估工具多未量化；运动员自评依赖诚实度；「共识 ≠ 实证」。
- **专业边界（2.2-14）**：隐私保密、与医疗团队协作；临床问题转专业。
- **相邻易混**：与 **mental-health-referral** 分工——本卡管伤后支持，那张卡识别临床红旗。
