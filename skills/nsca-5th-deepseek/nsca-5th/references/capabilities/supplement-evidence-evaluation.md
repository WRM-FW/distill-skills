# 增补剂证据评估框架（合法性 × 安全性 × 有效性 × 必要性）

## R — 原文 (Reading)

> "it is imperative that the athlete become informed about the legality of these substances, understand the potential risks associated with consumption, and know whether scientific research supports the claims (i.e., the efficacy of the product)." / "An athlete's first priority should be to apply sound principles of training, including adequate nutrition, before using any nutritional supplement or ergogenic aid."

— Chapter 12 · Performance-Enhancing Substances and Methods（`ch12.txt:45-47, 75-77`）

## I — 自述 (Interpretation)

任何增补剂决策都可套用**四维评估**，且顺序隐含优先级：

1. **必要性（优先级最高）**：先把周期化训练与合理营养做扎实，再考虑补充剂——补剂是「锦上添花」而非地基。若训练/营养未到位，先优化它们。
2. **合法性**：对照所属联盟禁用清单（WADA/NCAA 等）；注意**清单不完备**、**化学相关物亦禁**、历史更新。
3. **安全性**：核查已知风险/不良反应与监管地位（药物 vs 膳食补充剂在 FDA 审批上不同）；注意**未申报成分污染**导致误服禁药。
4. **有效性**：看是否有科学研究支持厂商宣称（运动人群中证据常不足）。

- **核心提醒**：**没有一份完整的禁用物质清单**；**不要凭标签成分或「不在清单上」判定安全**——补充剂可能被未标注违禁物污染（非故意兴奋剂违规）。
- **结论形态**：合法、安全、有效、必要时才考虑；否则**拒绝**或转介营养专家。

## A1 — 案例 / 演练 (Application)

**原书未给「某产品是否可用」的完整判定算例**；`ce12-01`（勿凭标签/清单判安全）、`ce12-05`（勿先上补剂）给出失败边界。以下为**明确标记的合成演练**，按原文四维复算。

**合成演练（标记：合成）**
- 输入：运动员询问「某网售 SARMs 产品能否用于增肌」。
- 执行（四步判定）：
  (1) 必要性：训练/营养是否已到位？
  (2) 合法性：SARMs 属 WADA 赛内赛外全禁、无 FDA 批准 → **不合法**；
  (3) 安全性：掺假率高（44 产品中仅 52% 实含 SARM、39% 含完全不同的未批准药物）、心血管/肝风险；
  (4) 有效性：非批准药、运动人群证据不足 → **不推荐**。
- 结论：四维均给出明确「否」→ **拒绝 + 先优化训练与营养 + 必要时转介营养专家**。
- 原书未说明该合成输入的「实际结果」，此处为按框架复算。

## A2 — 未来触发 (Trigger)

**用户情境（3–5 条）**
1. 运动员/家长问某补充剂（增肌/减脂/训练前）能不能用。
2. 拿到一个网售产品的成分表，问是否安全/合法/有效。
3. 想知道某物质是否属于禁药、会不会误服。
4. 想用补剂替代训练或营养上的不足。
5. 需要给「要不要吃某补剂」一个可复用的判定口径。

**语言信号（中英双写）**：增补剂 / 补充剂 / 合法吗 / 禁药 / 能不能用 / 有没有用 / 会不会阳性 / supplement / ergogenic aid / legality / banned substance / safety / efficacy / WADA / contamination / SARMs / 必要性。

**与相邻能力的区分（初稿）**
- 与 **ergogenic-dosing-evidence**：本卡做「用不用」的四维判定；具体成分剂量与证据分级归那张卡。
- 与 **ergogenic-abuse-identification**：滥用/激素的体征识别与转诊归那张卡。
- 与 **banned-substance-reference**（reference）：禁用物质名称对照归 glossary/overview。
- 与 **nutrition-assessment-referral**：营养转诊边界另卡承载。

## E — 执行 (Execution)

**输入契约（必需字段）**
- 产品宣称与成分；运动员所属联盟禁用清单；已知风险/不良反应；现有科学证据；训练与营养是否到位；是否需转介营养专家。
- **缺失须先询问，不得静默猜值**：若不知所属联盟清单 → 先确认；若无有效性证据 → 不默认有效。
- 适用条件：任何补充剂/增能剂决策。

**步骤（每步有完成标准）**
1. **必要性检查**——训练原理与营养是否已到位；未到位 → 先优化，不做补充剂决策。完成标准：输出必要性结论。
2. **合法性**——对照相应联盟禁用清单，警惕未申报污染；**不凭标签/清单判安全**。完成标准：输出合法性结论。
3. **安全性**——核查已知风险/不良反应与 FDA 监管地位。完成标准：输出安全性结论。
4. **有效性**——核对是否有研究支持宣称（区分药物与膳食补充剂监管）。完成标准：输出有效性结论。
5. **结论与行动**——四维全过才考虑；否则拒绝或转介营养专家。完成标准：输出最终建议。

**输出契约**
- 字段：`{必要性, 合法性, 安全性, 有效性, 最终建议(用/不用/转介)}`。
- 容差：无计算（定性四维）。
- **约束（原文只给方向未给数值，不得静默补值）**：禁用清单**每年更新且不完备**、化学相关物亦禁，须查最新来源；运动人群中「有效性」证据常不足；污染风险使安全性判断困难——原文未给各物质的量化风险阈值。

## B — 边界 (Boundary)

- **不要**凭「标签没列禁用成分」或「不在禁药清单上」判定安全——清单不完备、污染常见（`ce12-01`）。
- **不要**在训练与营养未落实前先用补剂——补剂是锦上添花（`ce12-05`）。
- **不要**把厂商宣称当证据——有效需有科学研究支持。
- **作者盲点（3.1/3.3）**：禁用清单时效性强、必须持续更新；运动人群证据常不足；「共识 ≠ 实证」。
- **专业边界（2.2-14）**：涉及用药/诊断的决策归合格专业人员；教练给信息、做转介。
- **相邻易混**：与 **ergogenic-dosing-evidence** 分工——本卡判「用不用」，那张卡给「吃多少、多有效」。
