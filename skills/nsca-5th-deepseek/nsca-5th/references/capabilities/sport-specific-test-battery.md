# 专项特异性与测试电池构建（含年龄/性别/训练状态边界）

## R — 原文 (Reading)

> "The 1.5-mile (2.4 km) run may be a valid and reliable field test of aerobic power for college-aged men and women but may not be appropriate for preadolescents because of their probable lack of experience and interest in sustained running."

— Chapter 13 · Age and Sex（`ch13.txt:642-645`）

## I — 自述 (Interpretation)

选测试不能只看"好不好测"，要同时过两把筛子：

- **专项筛**：测试须复现该专项的**代谢供能系统**与**生物力学动作模式**（如篮球本质是无氧跑步项目，选跑步测试要了解比赛中冲刺的距离与方向）。
- **个体筛**：运动员的**经验、训练状态、年龄、性别、环境**决定"同一测试对谁有效"。

再把候选动作按**四个特异性维度**分类，确保电池不出现覆盖盲区：
1. **主要动作模式**：推 / 拉 / 蹲 / 髋铰链 / 旋转 / 稳定；
2. **目标肌群**：识别潜在失衡与薄弱；
3. **主要供能系统**：磷酸原 / 糖酵解 / 氧化；
4. **技能水平与复杂度**：基础复合动作 vs 高阶专项动作。

**内容效度加权规则**：先列出该运动所需的能力成分，确保全部被覆盖；某成分对总分的贡献应与其对整体表现的重要性成正比（如足球电池至少含冲刺速度、敏捷、有氧耐力、踢球功率）。

## A1 — 案例 / 演练 (Application)

**原书案例（sample-program，`ch13.txt:245-247`）**：潜在足球运动员的电池至少含**冲刺速度、敏捷、有氧耐力、踢球功率**——用内容效度法覆盖全部成分。

**原书判据（`ch13.txt:609-652`）**：垂直纵跳非常贴合篮球/排球、但不太贴合不涉及纵跳的冰球；美式橄榄球锋线需推的力量与 5–15 码冲刺、外接手更依赖 30–100 码冲刺；单腿跳 25 m 对资深跳远运动员有效，对新手无效；1.5 英里跑对大学生有效，对青春期前儿童不适用；引体向上最大次数对男性摔跤手有效、对女性效度不足（可改脚支撑改良引体）。

**合成演练（明确标记）**：目标 = 高中女子足球队，需求 = 冲刺、敏捷、有氧耐力、踢球功率，可测者 = 15 岁新手。
- 输出电池：`[10–40 yd 冲刺, T-test / 5-10-5, 1.5-mile 跑（先核实长跑经验）, 专项踢球功率]`。
- 排除项：高技巧单腿跳类因"新手技巧负担"剔除；踢球功率须专项化（不能用力台纵跳代替）。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 要给某个项目/某个位置设计一整套测试，问"该测哪几项"。
2. 担心现有电池有覆盖盲区（动作模式或供能系统漏项）。
3. 面对青少年、女性或新手，拿不准某测试对其是否适用。
4. 想把通用体能测试直接搬到专项队使用，需要适用性判断。

**语言信号（中英双写）**：测试电池 / 该测什么 / 专项测试 / 内容效度 / 覆盖 / test battery / sport-specific test / which tests / content validity / 这个测试适合青少年吗 / is this test appropriate for / 训练状态 / training status / age and sex。

**与相邻能力的区分**：本卡产出"电池配比与适用边界"；单测试是否合格用 `test-selection-validity`；电池排定顺序与休息用 `test-sequencing-rest`；环境（温湿海拔）适用性用 `test-environment-adjustment`。

## E — 执行 (Execution)

**输入契约**：目标专项（含位置，若适用）+ 运动员属性（经验、训练状态、年龄、性别）+ 可用测试清单/器材。缺"目标专项"必须先问。

**步骤与完成标准**：
1. **列能力成分**：写出该专项/位置的关键能力成分（至少覆盖力量-功率、速度-敏捷、耐力、专项动作）。完成标准：成分清单 ≥3 条，每条可测。
2. **过专项筛**：标注每成分对应的供能系统与动作模式，与专项需求对齐。完成标准：每个成分都能说清"为什么这个专项需要它"。
3. **过个体筛**：对每名/每类运动员勾选经验、训练状态、年龄、性别是否满足该测试的适用条件（例：1.5 英里跑对青春期前不适用；技术密集测试对新手不适用；只练腿举者不宜用平行蹲测力量）。完成标准：给出"适用/不适用 + 理由"。
4. **四维分类校验**：把选定测试按动作模式、目标肌群、供能系统、技能复杂度归类，找盲区。完成标准：四维中任一维若关键类别缺失，须补测或写明"有意省略及其理由"。
5. **加权**：按成分对整体表现的重要性分配贡献比例（内容效度加权）。完成标准：给出百分比或高/中/低权重。
6. **输出电池**。

**输出契约**：`{专项/位置, 能力成分表, 成分→测试映射, 四维覆盖检查, 年龄/性别/训练状态适用性表, 排除项及理由, 权重}`。可配合 `resources/test-battery-checklist.md` 逐项核对。

**判停点/分支**：
- 某关键成分无合适测试 → 输出"缺口 + 替代/自建测试方向"，不得静默省略。
- 运动员为新手/青少年 → 强制剔除技巧主导测试（除非先做熟悉课并验证）。
- 目标为女性且测试效度不足（如引体向上）→ 换效度更佳的替代（脚支撑改良引体）。

**约定**：原文**未给四维权重与成分配比的量化规则**（`f13-02` gap）。本卡要求"显式给出权重并说明理由"，不虚构具体数值。

## B — 边界 (Boundary)

- **不要**用本卡替代单测试准入：先过 `test-selection-validity`，再来配电池。
- **不要**把"通用体能测试"当"专项测试"用（`p13-11`：有效测试必须复现专项能量需求与关键动作）。
- **作者盲点（3.3-1 迁移不保证，3.3-3 变量耦合）**：电池覆盖了某个成分，不代表该成分改善会转化为专项表现；改一个测试会牵动整体疲劳与顺序。
- **常模/人群依赖（3.1）**：跨年龄、性别、训练状态套用常模前必须校验样本与协议。
- **专业边界（2.2-14）**：青少年、女性、特殊人群的处方层差异分别属 Ch7/Ch8，本卡只做测试适用性判断，不做训练处方。
- **相邻易混**：与 `test-selection-validity`（准入）和 `test-sequencing-rest`（排序）不同。
