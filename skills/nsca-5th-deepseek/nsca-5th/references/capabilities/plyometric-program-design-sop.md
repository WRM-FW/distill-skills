# Plyometric 计划设计总纲：需求分析 + 五步 SOP + 六变量框架

## R — 原文 (Reading)

> "To properly design a plyometric training program, the strength and conditioning professional must analyze the needs of the athlete by evaluating his or her sport, sport position, anthropometry, and training status. ... Effective plyometric programs include the same variables that are essential to any training program design: mode, intensity, frequency, recovery, volume, and progression."

— Chapter 19 · Needs Analysis / Program Design（`ch19.txt` 第 275–278、652–655 行）

## I — 自述 (Interpretation)

设计任何一份 plyometric（快速伸缩复合）计划，都从一个固定的起点和一个固定的骨架出发。起点是**需求分析**：先弄清专项与场上位置的动作/伤病需求、运动员的体重与相对力量、以及训练状态（做过 plyo 没有、是否伤后）。骨架是**六个可调变量**——mode（上肢/下肢/躯干）、intensity、frequency、recovery、volume、progression；再加一节热身。

落地的顺序由原文显式给出的**五步 SOP** 规定：1) 评估运动员（含专项与训练史）→ 2) 建立专项/位置/个体目标 → 3) **先教正确的跳、落、抛技术** → 4) 分配强度/频率/恢复/量 → 5) 正确进阶。关键次序是第 3 步：**技术教学排在变量分配之前**，因为动作质量既是安全前提也是效果前提。

本卡只负责给出"该做哪几步、每步该调哪个变量"的骨架与入口；每个变量的具体取值分别由同簇的强度与量卡、频率与恢复卡、进阶卡、评估卡、热身卡、安全卡提供。原文明说 plyometric 最佳变量的研究极少，多数取值靠可得研究 + 实践经验 + 动作捕捉/测力台技术共同决定。

## A1 — 案例 / 演练 (Application)

**原书未提供一条覆盖全部五步的完整案例**；原文以"五步清单 + 各变量分节"的形式给出骨架。下面是一条**明确标记的合成演练**（非书中人物、非实证结果），用于演示骨架如何被填满，可按原书规则复算：

- 输入：网球运动员，无 plyo 经验，体重 78 kg，in-season，需提升侧向弹跳功率。
- ①需求画像：专项=多平面侧向 + 旋转（`ch19.txt` 306–313）；位置需求=侧向/旋转功率；人体测量=体重中等，重力辅助类负荷可控；训练状态=beginner。
- ②目标：提升侧向弹跳功率（专项/位置/个体三者对齐）。
- ③技术教学：主动平足落地、肩过膝、膝过趾、避免膝内扣。
- ④变量取值入口：mode=下肢为主；intensity 查 **U2/强度与量卡**；volume 查 **U2**（beginner 档）；frequency/recovery 查 **U3**；progression 查 **U4**；先做 **U7/RAMP 热身**；准入核对见 **U5**。
- ⑤进阶路径：由简到繁换动作、强度升则量降（U4）。
- 结果：得到一份"需求画像 + 目标 + 技术项 + 六变量入口"的完整计划骨架；各变量的具体数值由对应卡片给出——**原书未说明该例的实际训练结果**。

## A2 — 未来触发 (Trigger)

**情境**：
1. 用户要从零开始给一名运动员/自己排一份跳跃、落地类训练计划。
2. 用户手里已有零散参数（动作、组次），问"还缺什么、按什么顺序补齐"。
3. 用户问 plyometric 计划应包含哪些变量、先做什么后做什么。

**语言信号（中英）**：设计 plyometric 计划 / jump training program / plyometric program design / 快速伸缩复合计划怎么排 / how to design a plyometric program / 先教技术还是先定量 / program design variables for jumps。

**与相邻能力的区分（初稿，阶段 3 回填）**：本卡是"总纲骨架"，只给五步与六变量入口；具体数值请分别路由到强度与量、频率与恢复、进阶、准入评估、热身、安全、整合各卡。若问的是**冲刺/变向/敏捷**（sprint, change of direction, agility），属"速度敏捷"Skill；若问的是**杠铃/哑铃负荷与 RM 处方**（1RM, sets/reps, %1RM），属"抗阻计划设计"Skill。

## E — 执行 (Execution)

**输入契约**（缺失应先询问，不得静默猜值）：
- 必需：专项 + 场上位置（str）；体重（kg）与相对力量（可选但强烈建议）；plyo 经验水平（beginner/intermediate/advanced）；赛季阶段（off/in-season）。
- 可选：既往伤史；可用器械/场地；每周可训练天数。

**步骤**：
1. **需求分析**：评估专项、位置、人体测量（体重/相对力量）、训练状态四项；完成标准 = 写出"专项需求 + 位置需求 + 风险等级 + 训练状态档"四行画像。分支：若体重 >100 kg 或有既往伤史 → 立即转 **U5/U8** 先做准入与安全核对。
2. **设目标**：建立专项/位置/个体特异目标；完成标准 = 至少一条可测量的功率/弹跳目标。
3. **技术教学（先于变量分配）**：教跳、落、抛的正确技术；完成标准 = 落地能维持"肩过膝、膝过趾"、主动平足落地、无动态外翻。**判停点**：技术不达标 → 停止上强度，只做低强度技术练习并回第 1 步复评。
4. **分配变量**：依次定 mode → intensity（U2）→ frequency/recovery（U3）→ volume（U2）→ progression（U4）；完成标准 = 六变量各有一个确定取值或明确指向的卡片入口。
5. **配热身与进阶路径**：配 **U7** 递增强度热身；写 **U4** 进阶路径；完成标准 = 结束时可交出一份含六变量 + 热身 + 进阶路径的计划骨架。

**输出契约**：结构化计划骨架（需求画像 4 行 + 目标 + 技术项 + 六变量取值/入口 + 热身 + 进阶路径）。原书未规定字段格式的属本卡实现约定。**完成标准**：每一步都有可检查的书面产物，且技术项先于变量数值落定。

## B — 边界 (Boundary)

- **不要当"参数表"用**：本卡只给骨架与入口，不含具体强度/量数值；要数字请转 U2/U3/U4。
- **作者盲点（BOOK_OVERVIEW 步骤 3）**：原文自承 plyometric 最佳变量研究极少，六变量取值多为**专家共识/实践惯例**，不是实证定论（共识 ≠ 实证）；变量强耦合（改一个牵动另一个），五步虽线性呈现，实际需回环调整——不可把第 4 步当"一次性填表"。
- **迁移不保证**：gym 里的弹跳/功率改善不自动等于专项表现提升。
- **T14 映射之外**：年龄裁剪（U6）、安全排障（U8）、与抗阻/有氧整合（U9）不在本卡步骤内，需另行调用。
- **相邻易混**：把"排 plyo 计划"当成"排冲刺/变向计划"（应走速度敏捷），或当成"配杠铃负荷"（应走抗阻计划设计）。
- **专业边界**：任何疼痛、关节退变、伤后处置超出教练权限，应转诊，不自行续排高强度。
