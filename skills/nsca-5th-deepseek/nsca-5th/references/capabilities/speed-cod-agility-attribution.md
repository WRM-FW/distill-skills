# 速度 / 变向 / 敏捷三分定义与能力判定

## R — 原文 (Reading)

> "Speed. The skills and abilities needed to achieve high movement velocities. Change of direction. The skills and abilities needed to explosively change movement direction, velocities, or modes. Agility. The skills and abilities needed to change direction, velocity, or mode in response to a stimulus." ... "tests without a reactive aspect should be considered COD tests, and a test that includes a reactive stimulus is now by definition a test of agility for most sports."

— Chapter 20 · 开篇三分定义（`ch20.txt` 第 32–37 行）；"Factors Affecting Change of Direction and Perceptual-Cognitive Ability"（第 1201–1205 行）

## I — 自述 (Interpretation)

作者把常被笼统称作"速度"的表现拆成三种能力：**Speed**（直线达到高位移速度）、**Change of direction / COD**（预先计划地爆发式改变方向、速度或移动模式）、**Agility**（对外部刺激作出反应而改变方向/速度/模式）。区分三者的唯一硬判据是**有无"反应性刺激"**：变向是预先计划的（跑位、既定路线、口令前已知），敏捷必须包含外部刺激（对手、球）。因此敏捷 = COD 能力（action capacity）+ 知觉—认知能力，而 COD 只是敏捷的物理子集。训练上三者有重叠（都含加速、都依赖 SSC），重点却不同：速度练加速与最高速，COD 练制动/偏心与再加速，敏捷还要加视觉搜索、预判、决策时间与反应时。同一逻辑可迁移到测试端：不含反应成分的测试是 COD 测试，含反应刺激的才按定义算敏捷测试；名称里写着"agility"不等于真的测敏捷。

## A1 — 案例 / 演练 (Application)

原书在此处未提供独立运动员案例，仅给出定义与测试分类表（Table 20.3）。以下为**合成演练**（明确标记，非书中案例）：

- 输入：篮球后卫，在预定路线的反跑中能快速摆脱（预先计划变向）；但防守面对对手运球变向时慢半拍、预判差。
- 执行：沿四步——① 直线高速还是多方向？→ 多方向；② 变向是否预先计划？→ 反跑部分预先计划，防守部分否；③ 是否含反应性刺激？→ 反跑无、防守有（对手）；④ 归因。
- 预期输出：反跑部分 = COD；防守迟疑 = 反应性敏捷不足（缺知觉—认知）。训练各配一项：COD 用闭技能变向 drill，敏捷部分加反应性刺激（对手/视频）；测试应选含 reaction stimulus 的敏捷测试，而非仅标 COD speed 的 5-0-5。
- 分类依据（原书 Table 20.3，`ch20.txt` 第 1245–1289 行）：5-0-5 = COD speed；T-test = COD speed + maneuverability；Illinois / L-run = maneuverability；Y-shaped（specific stimulus）= COD speed + perceptual-cognitive。

## A2 — 未来触发 (Trigger)

**用户会在什么情境下遇到这类问题**
1. 教练说"这孩子速度不行"，但说不清该练直线冲刺、变向还是反应。
2. 要给篮球/足球/橄榄球运动员挑"敏捷测试"，纠结 5-0-5、T-test 够不够。
3. 运动员在既定跑位里很快，防守/接球反应时却慢半拍。
4. 想把"变向练习"当敏捷练，不确定是否真的练到反应能力。

**语言信号（中英双写关键 trigger）**
- 中文：「他速度不够快怎么办」「该练敏捷还是变向」「5-0-5 能测敏捷吗」「预判差/反应慢」「怎么区分 change of direction 和 agility」
- English: "is 5-0-5 an agility test", "change of direction vs agility", "reactive agility", "he's not fast enough", "decision-making / anticipation deficit"

**与相邻能力的区分（初稿，阶段 3 回填）**
- 与 `speed-force-metrics-calculation`：本卡只做**定性归因**，不算 RFD/impulse/COD deficit 数值。
- 与 `agility-needs-analysis-to-program`：本卡回答"这是哪种能力"，后者回答"据此怎么排计划"。
- 与 `cod-angle-training-orientation`：本卡判能力类别，后者按角度/入速定训练取向。

## E — 执行 (Execution)

**输入契约**
- 必需：① 运动情境/表现描述（文字）；② 该动作是否预先计划（是/否）；③ 是否含外部反应刺激（对手/球/灯光，是/否）。
- 选测试时还需：④ 候选测试的结构（有无刺激、时长）。
- 缺 ②③ 时应先询问，**不得默认**为 COD 或敏捷。

**步骤与完成标准**
1. 判断是直线高速还是多方向移动 → 得"直线"或"多向"。
2. 若多向，判断变向是否预先计划 → 是则 COD 候选。
3. 判断是否对外部刺激作出反应 → 是则升级为 Agility。
4. 按判定表归因：
   - 直线高位移速度 → **Speed**
   - 多方向 + 预先计划 + 无反应刺激 → **COD**
   - 多方向 + 对刺激反应 → **Agility**（= COD + perceptual-cognitive）
5. 选测试分支（按原书判据）：
   - 无反应刺激 → 归为 COD 测试；T-test / L-run / Illinois 因含弯曲保速或测试较长，偏 **maneuverability**。
   - 含反应刺激 → 敏捷测试（reactive agility；Y-shaped drill 用 **specific** stimulus 才含知觉—认知）。
   - **判停点**：测试时长偏长（如 Illinois、T-test <12 s）会引入代谢需求，成绩改善可能来自供能而非变向能力 → 标为 maneuverability，不当作敏捷指标。

**输出契约**
- 归因结论 `{Speed | COD | Agility}` + 判据（是否预先计划、是否含反应刺激）+ 每项能力对应训练成分；若选测试，附测试分类与理由。

## B — 边界 (Boundary)

- **不要用**：当诉求只是提升直线冲刺成绩时（属速度侧 `speed-short-to-long-periodization`）；当只需算力学指标时（属 `speed-force-metrics-calculation`）。
- **作者警告的失败模式**：用封闭变向 drill 冒充敏捷训练（ce20-04）——只有有限选项、固定信号的练习 "do not develop agility per se"（`ch20.txt` 第 1782 行附近）；专项迁移有限。
- **盲点（BOOK_OVERVIEW 步骤 3）**：三分边界在实践中是连续的，"预先计划 vs 反应"常是程度问题；测试分类取决于测试**设计**而非名称（大量名为 agilty 的测试实为 COD 或 maneuverability）；分类结论跨人群/场地需重校验。
- **相邻易混**：`speed-force-metrics-calculation`（算指标）、`agility-needs-analysis-to-program`（出计划）、`cod-angle-training-orientation`（定取向）。
