# 运动员测试准备、记录与测试日标准化

## R — 原文 (Reading)

> "It is important that test sessions be conducted at the same time of day to avoid fluctuations in physiological responses due to differences in circadian rhythm. It is also recommended that tests be conducted indoors, which will allow for climate and testing surfaces to remain more consistent."

— Chapter 13 · Sequence of Tests（`ch13.txt:900-904`）

## I — 自述 (Interpretation)

要让测试"可跨测次比较"，须把**运动员准备、记录、测日条件**三件事标准化：

- **提前动员**：提前公布测试日期、时间与目的，让运动员身心有准备（readiness）。
- **熟悉课**：对首次/久未测者，测前 1–3 天安排一次监督下、低于全力的熟悉/练习课；或把熟悉融入既有训练（哪怕作为动态热身一部分）。
- **讲解七要素**：目的、如何执行、建议热身量、允许的练习次数、试次数、评分方式、无效准则、最大化表现建议；讲解须清晰简明。
- **示范与激励**：尽量由测试员示范、允许前后提问；对所有运动员同等激励；每次试次后即时告知成绩。
- **热身**：一般热身 + 专项热身（含与测试相似的动作），可含 2–3 次专项热身试次；成绩取后续试次的最佳或平均。
- **测后整理**：剧烈升心率的测试后做监督下整理（如 300-yd 折返后勿坐卧）。
- **记录表**：测前即备好，须为全部结果 + 备注 + **环境条件** + **设备设置细节**（如 1RM 深蹲的插销高度）留位。
- **测日条件**：固定每日同一时段（规避昼夜节律），尽量室内。

## A1 — 案例 / 演练 (Application)

**原书未提供完整准备案例**（`ch13.txt:808-959`；`p13-19`、`p13-25`）。

**合成演练（明确标记）**：首次测试的 12 名高中运动员，明早 8:00 测 1RM 深蹲。
- 输出：提前通知（目的/时间/着装）；T-3 天熟悉课；热身试次安排；讲解脚本清单；记录表字段（结果 + 备注 + 环境温湿度 + 插销高度）；测后整理；要求改日重测的触发条件。
- 结论：可打印的准备清单 + 记录表字段集，动作明确。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 要组织一次测试日，问"测前该做哪些准备、怎么讲解"。
2. 要设计测试记录表，问"该记哪些字段"。
3. 发现跨测次成绩不可比，怀疑是环境/设备设置没记录。
4. 要给首次受测的运动员做熟悉与动员。

**语言信号（中英双写）**：测试准备 / 测前 / 熟悉课 / 讲解 / 记录表 / 测试日标准化 / prepare athletes / familiarization / test instructions / recording form / standardization / 同一时段 / same time of day / 环境记录 / environmental conditions。

**与相邻能力的区分**：本卡管"测前准备 + 记录 + 时间/场地一致性"；测试顺序与休息归 `test-sequencing-rest`；人员分工归 `tester-selection-duties`；温湿海拔的实质调整归 `test-environment-adjustment`。

## E — 执行 (Execution)

**输入契约**：测试清单 + 被测运动员（是否首测/久未测）+ 场地与时段。缺测试清单无法备料。

**步骤与完成标准**：
1. **提前通知**：公布日期、时间、目的、着装与准备要求。完成标准：含这四项的通知文本。
2. **熟悉课**：首测/久未测者安排测前 1–3 天、低于全力的练习课（或嵌入热身）。完成标准：写明时间与形式。
3. **讲解脚本**：覆盖七要素（目的/执行/热身量/练习次数/试次数/评分/无效准则/表现建议）。完成标准：逐条可读出。
4. **示范与激励**：安排示范 + 提问窗口 + 同等激励 + 试次后即时报成绩。完成标准：勾选完成。
5. **热身**：一般 + 专项热身 + 2–3 次热身试次。完成标准：写明热身结构。
6. **记录表**：字段 = 全部结果 + 备注 + 环境（温度/湿度等）+ 设备设置（如插销高度）。完成标准：字段清单可打印。
7. **测后整理 + 测日约定**：剧烈测试后监督整理；固定同一时段、尽量室内。完成标准：写入流程。
8. **输出**。

**输出契约**：`{通知文本, 熟悉课安排, 讲解脚本, 记录表字段集, 热身结构, 环境/设备记录项, 测后整理与时段约定}`。可直接套用 `resources/test-battery-checklist.md`。

**判停点/分支**：
- 运动员为首次受测且时间不足 → 至少把熟悉嵌入测试前的动态热身，不得直接施测。
- 环境/设备无法记录 → 标注"跨测次可比性受限"。

**约定**：原文未量化"低于全力"的具体强度与熟悉课次数上限（`f13-09` gap）；本卡要求写明所用强度，标为约定。

## B — 边界 (Boundary)

- **不要**把本卡当成"温湿度/海拔要不要调常模"的实质判断——那是 `test-environment-adjustment`。
- **不要**省略环境与设备设置记录；漏记会导致跨测次不可比（`p13-19`）。
- **作者盲点（3.3-4）**：讲解与激励的效果受运动员动机影响，同等激励是原则而非保证。
- **常模/时段依赖（3.1）**：生理节律与训练时段会影响成绩，跨时段比较需谨慎。
- **相邻易混**：与 `test-sequencing-rest`（排顺序/休息）和 `tester-selection-duties`（分工）不同。
