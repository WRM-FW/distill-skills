# 按愈合期调整抗阻训练（DAPRE / DeLorme / Oxford + SAID + 神经肌肉控制）

## R — 原文 (Reading)

> "The first set requires 10 repetitions of 50% of the estimated 6RM, and the second set requires 6 repetitions of 75% of the estimated 6RM. The third set in the DAPRE requires the maximum number of repetitions of 100% of the estimated 6RM; the number of repetitions performed during the third set determines the adjustment made in resistance for the fourth set (table 23.2)."

— Chapter 23 · Resistance Training（`ch23.txt` 第 836–842 行）

## I — 自述 (Interpretation)

康复抗阻不是"凭感觉加片"，而是**三条可查表的规则 + 一条迁移原则**：

1. **DAPRE（每日可调渐进抗阻，Knight）**：4 组，次数从 10 递减、末组可能仅 1 次。
   - 第 1 组：**10 次 @ 50% 估算 6RM**
   - 第 2 组：**6 次 @ 75% 估算 6RM**
   - 第 3 组：**100% 估算 6RM 做到最大次数**
   - **第 3 组实际次数 → 决定第 4 组阻力与下次课阻力**（Table 23.2，见下）。
2. **DeLorme（轻→重金字塔）**：3 组 ×10，50%→75%→100% 的 10RM。
3. **Oxford（重→轻，DeLorme 的反向）**：3 组 ×10，100%→75%→50% 的 10RM；因开头即重阻，建议加一组**非力竭热身**。
4. **SAID 迁移**：目标决定设计——耐力专项动作多重复、力量/爆发专项少重复高强度；**按愈合期 × 专项定制**（Table 23.3）。
5. **神经肌肉控制**：通过改变**面稳定（稳定面/不稳定面）、视觉（睁眼/闭眼）、速度（慢/快）**三变量渐进。
6. **运动速度也是设计变量**：急性伤更慢更可控，后期更接近专项速度。

**Table 23.2（DAPRE 第 3 组次数 → 阻力调整）**：
| 第 3 组次数 | 第 4 组阻力调整 | 下次课阻力 |
|---|---|---|
| 0–2 | 减 5–10 lb（2.3–4.5 kg）并重做该组 | — |
| 3–4 | 同重或减 5 lb（2.3 kg） | 同重 |
| 5–7 | 同重 | 加 5–10 lb（2.3–4.5 kg） |
| 8–12 | 加 5–10 lb（2.3–4.5 kg） | 加 5–15 lb（2.3–6.8 kg） |
| 13+ | 加 10–15 lb（4.5–6.8 kg） | 加 10–20 lb（4.5–9.1 kg） |

## A1 — 案例 / 演练 (Application)

**数值演练（合成，按 Table 23.2 规则复算）**：DAPRE 估算 6RM = 110 lb，第 3 组实际完成 **9 次**。
- 第 3 组 9 次落入 Table 23.2 的 **8–12** 行 → **第 4 组加 5–10 lb（115–120 lb）**；**下次课加 5–15 lb（115–125 lb）**。
- 复算校验：9 ∈ [8,12] ✓；调整量与原文一致（容差按 5 lb 档）。

**原书素材（c23-2 · Table 23.3，`ch23.txt` 第 908–964 行；c23-1 · Figure 23.4，第 703–726 行）**：
- **髌股关节损伤（c23-2）**，修复期 → 马拉松跑者 **2–3 组 × 15–20 次 @ ≤50% 1RM**；举重者 **3–4 组 × 8–10 次 @ ≤50% 1RM**（末期跑者 50%–75% 1RM、举重者 >75% 1RM）。同一损伤，按专项需求给出不同组×次。
- **篮球后卫踝扭伤（c23-1）**：进阶由一般单关节 → 专项，由慢（平衡/力量）→ 快（Plyometric/冲刺）；**原书未给具体时间线**。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 伤员要"开始抗阻康复/加重量"，问**加多少、下次加多少**。
2. 已知愈合期，问"该用几组几次、多大强度"。
3. 问 DAPRE/DeLorme/Oxford 怎么执行、第 4 组怎么调。
4. 同一损伤不同项目的运动员，处方为什么不同。
5. 康复里怎么加神经肌肉控制/专项速度。

**语言信号（中英双写）**：康复抗阻 / 加多少重量 / 下次加多少 / 几组几次 / DAPRE / DeLorme / Oxford / 6RM / 愈合期处方 / 神经肌肉控制 / 开闭链 / rehab resistance / how much to add / sets and reps / progress load / neuromuscular control。

**与相邻能力的区分（初稿）**：本卡管"**按愈合期落数值处方**"。**分期与允许动作** → `cap.nsca.tissue-healing-phase-classification`；**专业边界/转诊** → `cap.nsca.rehab-scope-and-referral`；**重返判据** → `cap.nsca.reinjury-risk-and-return-to-play`。**与健康人抗阻计划设计（`cap.nsca.nsca-resistance-program-design`）不同**：那是未伤运动员的七步设计，本卡是**伤员按愈合期的处方**，须叠加禁忌；**与"周期化"不同**：那是长期编排。

## E — 执行 (Execution)

**输入契约（必需）**：**估算 6RM**（或 1RM/10RM 用于 DeLorme/Oxford）；**愈合期**（炎症/修复/重塑）；医疗**允许/禁止**清单；专项需求；第 3 组实际完成次数（DAPRE）；单位须一致（lb/kg）。
- **缺失处理**：无 6RM → 先测/估，**不得猜重**；无愈合期 → 回 U7 先分期；无禁忌清单 → 先向医疗团队索取（见 U9）。

**计算类步骤与完成标准（DAPRE）**：
1. 第 1 组 = 10 次 @ `0.50×6RM`；第 2 组 = 6 次 @ `0.75×6RM`；第 3 组 = `1.00×6RM` 做到最大次数。
2. 记录第 3 组实际次数 n → 查 Table 23.2 得第 4 组调整与下次课调整。完成标准：写出 n、第 4 组阻力量、下次课阻力量区间。
3. 依据愈合期选规则（Table 23.3）：

| 期 | 示例（髌股损伤） | 组×次 | 强度 |
|---|---|---|---|
| 炎症期 | 受伤区不练；维持相邻部位/心肺 | — | — |
| 修复期（跑者/举重者） | 无痛等长→等张 | 2–3×15–20 / 3–4×8–10 | ≤50% 1RM |
| 重塑期（跑者） | 专项化、跑量渐进 | 2–3×15–20 | 50%–75% 1RM |
| 重塑期（举重者） | 更高强度、更少次数 | 4–5×3–8 | >75% 1RM |

4. **神经肌肉控制**：按面/视觉/速度三变量渐进。完成标准：写出变量调整。
5. **输出处方**。

**输出契约**：`{规则(DAPRE/DeLorme/Oxford), 6RM, 各组负荷与次数, 第3组n, 第4组调整, 下次课调整, 组×次×强度(按期×专项), 神经肌肉控制变量, 禁忌核对}`。
**舍入/容差**：DAPRE 调整按原文 **5 lb（及 kg 近似 2.3–4.5/2.3–6.8/4.5–9.1）** 档；本卡采用原文 lb 档，kg 用原文近似值（**原文此处为近似换算，非精确**），换算按原文标为近似。

**判停点/分支**：
- 第 3 组 n = 0–2 → 减阻重做该组，本期不进阶。
- 无 6RM → 停，先测。
- 涉及受伤区且无医疗许可 → 不处方，转诊。
- 处于炎症期 → 受伤区不主动抗阻。

## B — 边界 (Boundary)

- **不要**对受伤区未经医疗许可就上抗阻（`ce23-04`）——本卡在医疗允许清单内执行。
- **不要**凭感觉加片：用 Table 23.2 查档；**不要**给不同专项套同一组×次。
- **原文自认的适用边界（B 段主依据）**：DAPRE/DeLorme/Oxford"may be too strict to allow individualization for athletes in different sports"（`ch23.txt` 第 846–849 行）——它们是**通用起步协议**，须按专项裁剪。
- **单位换算**：Table 23.2 的 kg 为原文 lb 的**近似**；跨单位使用时须统一并注明近似。
- **证据**：DAPRE 源自 Knight 1979 单一来源协议；<10% 等判据另有局限（见 U11）。
- **专业边界**：康复处方的诊断/禁忌与放行由医疗团队负责；体能教练不越界（U9）。
- **相邻易混**：U7（分期）、U9（边界）、U11（重返）、`cap.nsca.nsca-resistance-program-design`（健康人设计）。
