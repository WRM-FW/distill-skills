# 替代/自调负荷法（RPE / RIR / SRB）

## R — 原文 (Reading)

> "RPE and RIR may be best used if combined with an objective method (e.g., percentage of 1RM) so that the desired loads for a given exercise can be determined before using RPE/RIR to adjust the load for autoregulation purposes... consider limiting load autonomy until the athletes can display proficiency with the RPE and RIR methods."

— Chapter 18 · Step 5: RPE and Repetitions in Reserve（`ch18.txt` 1628–1636）

## I — 自述 (Interpretation)

除 %1RM 外，还有三类"主观/自调"负荷法，用于无法频繁测 RM 的场景：

- **RPE（rating of perceived exertion）**：主观用力度，常用 CR10 0–10（原 6–20 为有氧版）。
- **RIR（repetitions in reserve）**：剩余可完成次数。RIR 越接近力竭越准，故 RIR 需在相对高强度下才有用；远离力竭时失准。
- **SRB（set-repetition best）**：以"某组次组合的实际表现"估该组次的最大负荷，用 **5% 相对区间**处方，每周可调，无需频繁 RM 测试。

使用要点：
- **以区间开处方**（如 RPE 7–8 / RIR 2–3）。
- **最佳用法：先用客观法（%1RM）定基础负荷，再用 RPE/RIR 做 autoregulation 微调**。
- **新手限制自主权**：经验不足者无法准确判断接近/最大用力，掌握前应限制其自主调负荷。
- **SRB 递进**：3×5 或 3×10 第 1 周取各自估计最大负荷的 85%–90%，次周升到 90%–95%；3×5 的负荷约比 3×2 低 15%；同周重日负荷比轻日重约 10%–15%。
- 证据有限（RPE 8 周 / RIR 12 周），原文承认需更多人群研究。

## A2 — 未来触发 (Trigger)

**用户会遇到这类问题的情境（3–5 条）**
- 用户无法频繁测 RM，问"能不能用 RPE/RIR 来定负荷"。
- 用户问"RPE 8 大概是多少 %1RM""RIR 2 是什么意思"。
- 用户想按主观感受让运动员自调当日负荷。
- 用户问"新手能不能自己调负荷"。
- 用户问 SRB 是什么、每周怎么递进。

**语言信号（中英双写关键 trigger 词）**
- "RPE 怎么用" / "RPE"、"RIR"、"repetitions in reserve"、"set-repetition best"、"SRB"、"自调负荷"、"autoregulation"、"主观用力"、"留几次余力"、"RPE 8 是多少 1RM"、"不想老测 1RM 怎么办"、"新手能不能自己加"。
- 英文常见："can I use RPE instead of 1RM"、"what is RIR 2"。

**与相邻能力的区分（初稿）**
- 与 **load-reps-assignment**：本卡是"客观 %1RM"的替代/补充，不是其替代品——推荐两者结合。
- 与 **load-progression**：SRB 每周递进与 2-for-2 的"何时加"相关，但本卡聚焦用相对区间处方，进阶判据由后者承载。
- 与 **one-rm-xrm-determination**：本卡免去频繁 RM 测试；基准测定仍由前者承载。

## E — 执行 (Execution)

**输入契约**
- 必需：客观基础负荷（%1RM 或 xRM）、运动员经验与主观用力判断能力、当周/当日状态。
- **先询问（缺失不得静默猜值）**：若无客观基础负荷 → 先用 %1RM/xRM 定基础，不得只靠 RPE 起量；若不知道运动员经验 → 先判定（决定是否允许自主调负荷）。
- 适用条件：运动员能准确表达接近/最大用力感受者；新手受限。

**步骤（每步有完成标准）**
1. **先客观定基础**——完成标准：用 %1RM（或 xRM）给出该动作基础负荷。
2. **用 RPE/RIR 区间自调**——完成标准：按区间处方（如 RPE 7–8 / RIR 2–3）；判停点：若为新手或未掌握 → **限制自主调负荷**，按基础负荷执行。RIR 需相对高强度才有效，远离力竭时不用它定负荷。
3. **或改用 SRB**——完成标准：以某组次的实测表现估该组次最大负荷；按 5% 区间，第 1 周 85%–90%、次周 90%–95%；3×5 比 3×2 低约 15%；同周重日比轻日重 10%–15%。
4. **交付**——完成标准：输出 `{ 客观基础, 目标强度区间(RPE/RIR 或 SRB %), 是否允许自主调 }`。

**输出契约**
- 字段：`{ base_load, target_intensity(RPE 区间 | RIR 区间 | SRB %), autonomy(bool) }`。
- 数值：RPE 0–10；RIR 次；SRB 相对百分比（步长 5%）。
- 约定：原文承认 RPE/RIR 信度依赖受试者经验与诚实度、证据有限；表中部分 RPE/RIR 无对应百分比（空白格），本卡不补造。

## B — 边界 (Boundary)

- **不要**只用 RPE/RIR 起量而不设客观基础——原文推荐"先 %1RM 定基础，再 RPE/RIR 自调"。
- **不要**让新手自主调负荷——经验不足者无法准确判断接近/最大用力。
- **不要**在远离力竭时依赖 RIR——越远离力竭，RIR 越不准。
- **量表可靠性假设**（BOOK_OVERVIEW 3.3-4）：RPE/问卷被广泛推荐，但其信度依赖受试者经验与诚实度，失效条件书中讨论不足。
- **共识 ≠ 实证**（3.3-5）：RPE(8 周)/RIR(12 周) 证据有限，SRB 需查专门文献。
- 易混淆：与 **load-reps-assignment**（客观 %1RM 法）、**load-progression**（2-for-2 何时加）不同——本卡只处理"用主观/自调口径处方与微调"。
