# 唤醒调控与心理技能（理论 + 降唤醒技术 + 目标设定 + 自我效能）

## R — 原文 (Reading)

> "An athlete should employ arousal reduction techniques when performing a new skill or one that is complex or when performing in high-pressure situations. Athletes should employ arousal enhancement techniques when executing simple skills, ones that are well learned, or in situations of minimal pressure."

— Chapter 9 · Psychological Foundations of Performance（`ch09.txt:816-819`）

## I — 自述 (Interpretation)

把「紧张怎么办」变成可选的**降/升唤醒技术菜单 + 目标设定模板**。骨架：

- **理论依据**：倒 U 理论（唤醒过高/过低都失分）、IZOF（最优唤醒是一个**区间**而非单点，且因人而异）、灾难理论（认知焦虑叠加生理唤醒 → 表现骤降而非渐变）、逆转理论（唤醒的**解释**可被主动逆转——把「可怕」重估为「兴奋」）。
- **方向决定**：**降唤醒**用于新技能/复杂技能/高压情境；**升唤醒**用于简单技能/已熟练技能/低压情境。技能水平越低，最优唤醒点越低，且应**削减决策负担**、聚焦简单任务；需要意识决策的技能（守门员、捕手）须「优化」唤醒以维持更宽注意焦点。
- **降唤醒技术**：横膈膜（腹式）呼吸（站姿起步、手放腹部反馈）；**PMR**（每肌群最大紧张 **10–15 s** 后完全放松，逐组推进；赛前**数日**练习而非比赛当天首用）；自生训练（以「温暖与沉重」替代强张力周期，适合伤后/年长者）；系统脱敏（构建恐惧层级 + 放松反应，反条件化）。
- **意象**：由简到繁、由静态到动态，内/外视角取更自然者。
- **自我效能六来源**：既往成败、替代经验（观察）、言语说服、想象经验、生理状态、情绪状态。
- **目标设定**：长期与短期互相依赖；**过程目标**（可控）优先级高于结果目标；具体可量化；**正强化优先于惩罚**。

## A1 — 案例 / 演练 (Application)

**原书案例（`c09-01`，in-book-athlete-scenario）**：举重教练 Gayle Hatch 用提示语「When the elbows bend, the power ends」教高翻初始提拉的直臂+斜方肌收紧（原书**未说明教学效果**）。以下另给**明确标记的合成演练**。

**合成演练（标记：合成）**
- 输入：一名技术熟练但比赛发挥不稳的飞镖运动员，赛前自觉「手抖、焦虑」。
- 执行：
  (a) 判定技能＝已熟练、任务需精细稳定 → 用**降唤醒**技术；
  (b) 选 PMR（10–15 s 紧张/放松循环）与腹式呼吸；
  (c) 赛前**数日**练习、非比赛当天首用；
  (d) 用系统脱敏 + 意象预演高压情境；
  (e) 设**过程目标**（如「每次出手都做完呼吸节律」）而非结果目标。
- 原书未说明该合成输入的「实际结果」，此处为按原文判据复算。

## A2 — 未来触发 (Trigger)

**用户情境（3–5 条）**
1. 运动员赛前紧张/手抖/焦虑，问怎么调整。
2. 要选降唤醒还是升唤醒技术，以及具体做法。
3. 要做意象、自我对话、目标设定等心理技能方案。
4. 运动员「关键时刻失常」（choking），要解释与干预。
5. 要提升自信（自我效能）或做赛前心理准备。

**语言信号（中英双写）**：唤醒调控 / 紧张 / 焦虑 / 呼吸 / 放松 / 意象 / 自我对话 / 目标设定 / 自信 / 关键时刻失常 / arousal / arousal reduction / enhancement / PMR / breathing / imagery / self-talk / goal setting / self-efficacy / choking / IZOF。

**与相邻能力的区分（初稿）**
- 与 **mental-health-referral**：本卡管表现相关的唤醒调控与心理技能；临床/心理健康困扰的识别与转诊归那张卡。
- 与 **motor-skill-teaching**：动作技能的学习/练习安排归那张卡。
- 与 **injury-return-psych-support**：伤后心理支持归那张卡。

## E — 执行 (Execution)

**输入契约（必需字段）**
- 技能属性（新/复杂 vs 简单/熟练）；情境压力高低；运动员当前唤醒水平（自评/心率/肌电）；个人最佳唤醒区（若已知）；是否需意识决策。
- **缺失须先询问，不得静默猜值**：若不知技能熟练度 → 问；若不知压力情境 → 问；若不适用（临床心理困扰）→ 转 mental-health-referral。
- 适用条件：表现相关心理调控；临床问题须转诊。

**步骤（每步有完成标准）**
1. **判方向**——新/复杂/高压 → 降唤醒；简单/熟练/低压 → 升唤醒。完成标准：输出调节方向。
2. **选技术**——降唤醒菜单（腹式呼吸 / PMR / 自生训练 / 系统脱敏 / 意象）；PMR 用 10–15 s 紧张—放松循环。完成标准：输出所选技术。
3. **定时序**——赛前**数日**练习技术（非比赛当天首用）。完成标准：输出练习安排。
4. **设目标**——过程目标优先（可控）、具体可量化。完成标准：输出目标清单。
5. **提自信（如需）**——按自我效能六来源逐条核对。完成标准：输出干预入口。

**输出契约**
- 字段：`{调节方向(降/升), 技术组合, 练习时序, 目标设定, 自我效能来源}`。
- 单位：s（PMR 10–15）；天（赛前数日）。
- 容差：无计算（定性方案）。
- **约束（原文只给方向未给数值，不得静默补值）**：原文**未给升唤醒技术的具体操作清单**（多讲降唤醒）；个人最佳区间的测定方法与量化工具未给全；「数日练习」未量化天数。

## B — 边界 (Boundary)

- **不要**对已高度自动化的专家级动作植入具体指导性自我对话——会干扰自动化（`ce09-02`）。
- **不要**把惩罚当主要手段——会把注意力引向「做错了什么」（`ce09-01`）。
- **不要**对新技能/高压情境用升唤醒——方向与判据相反。
- **不要**用本卡处理临床心理困扰——那是 mental-health-referral 的转诊范畴。
- **作者盲点（3.1/3.3）**：IZOF 等理论框架个体差异大；「共识 ≠ 实证」，工具与阈值多未量化。
- **专业边界（2.2-14）**：心理困扰越界时转诊专业人员。
- **相邻易混**：与 **mental-health-referral** 分工——本卡管表现调控，那张卡识别临床红旗。
