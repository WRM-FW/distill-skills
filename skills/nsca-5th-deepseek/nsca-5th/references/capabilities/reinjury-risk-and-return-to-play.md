# 降低初伤/再伤风险与重返运动判据

## R — 原文 (Reading)

> "Previous injury is one of the most substantial risk factors for future injury in active individuals (30, 75, 86, 91). … Side-to-side differences of less than 10% in strength and functional performance may be considered acceptable (60)."

— Chapter 23 · Reducing Risk of Injury and Reinjury（`ch23.txt` 第 1011–1012、1060–1062 行）

## I — 自述 (Interpretation)

把"感觉好了就上"换成**可核算的对称性判据 + 结构化预防**：

1. **核心事实**：**既往伤史是未来伤的极大风险因素**——所以"防再伤"和"防初伤"同等重要。
2. **风险因素**（举例）：上肢——肩关节活动度下降、肩胛运动障碍（scapular dyskinesis）、肩部力量下降；过头项目中肩内旋受限增肩伤风险，外旋/屈曲受限关联肘伤。下肢——平衡下降、落地时神经肌肉控制下降、下肢力量下降。
3. **结构化预防项目**：上肢用活动度练习 + **Throwers Ten**、强化肩外旋、牵伸改善内旋；下肢用 **Sportsmetrics**、**PEP**、正确的跳跃/落地技术、单腿蹲，以及**离心训练**大幅降低腘绳肌伤风险。
4. **重返判据**：复工后个体仍可能残留**力量、生物力学、功能表现**缺陷；缺陷可与**对侧**或**常模**比较；**力量与功能表现的对侧差异 <10% 可视为可接受**。
5. **关键危险期**：从**受监督康复**过渡到**无限制活动**之间，是需团队持续沟通、管理缺陷的窗口。

一句话：**再伤风险靠"对称性 <10% + 结构化预防"管理，不靠主观感觉。**

## A1 — 案例 / 演练 (Application)

**合成演练（明确标记，按原文 <10% 判据复算）**：某运动员 ACLR 术后 9 个月，等速股四头肌峰力矩较健侧差 **14%**，单腿跳差 **12%**。
- 判据：双侧差异 **>10%** → **不可接受** → **不判为可无限制重返**。
- 处置：继续康复与神经肌肉控制训练，待达标（<10%）再评估；复工后仍需管理残余缺陷（`ce23-05`）。

**原书案例（in-book · c23-4，`ch23.txt` 第 713–721 行）**：短跑运动员腘绳肌拉伤的进阶（柔韧→离心力量→向心力量→动态拉伸→快速等张）体现了"按专项速度需求排序"的再训练思路；**原书未给具体时间线或对称性数据**。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 伤员问"能重返了吗 / 复工了吗？"
2. 问"双侧差多少算可以上场"。
3. 有既往伤史，想降低**再伤**风险。
4. 想设计**预防**初伤/再伤的结构化项目。
5. 团队讨论"从康复过渡到无限制活动的标准"。

**语言信号（中英双写）**：重返运动 / 能不能复工 / 什么时候能上场 / 双侧差异 / 对称性 / 10% / 再伤风险 / 预防损伤 / return to play / return to sport / side-to-side difference / <10% / reinjury risk / injury prevention program / Sportsmetrics / PEP / Throwers Ten。

**与相邻能力的区分（初稿）**：本卡管"**再伤风险与重返判据**"。**分期与允许动作** → `cap.nsca.tissue-healing-phase-classification`；**康复期抗阻处方** → `cap.nsca.rehab-resistance-progression`；**谁放行/转诊** → `cap.nsca.rehab-scope-and-referral`。**与"测试与评估"不同**：那是"怎么把肌力/跳跃测准"，本卡是"用这些测量在对侧比较中做什么复工决策"；**与"周期化"不同**：那是计划编排。注意：**最终重返决定常由队医做出**，本卡为判据与沟通依据。

## E — 执行 (Execution)

**输入契约（必需）**：患侧 vs **对侧**（或常模）的力量与功能测量值；测试协议与设备（须可比）；损伤类型与运动专项；是否已达结构愈合与医疗许可。**可选**：生物力学评估（落地/变向）。
- **缺失处理**：无双侧可比测量 → **不得**仅凭主观"感觉好了"判重返；先测。无医疗许可 → 交 U9 转诊。

**步骤与完成标准**：
1. **测双侧（或对常模）力量与功能**：如等速肌力、单腿跳、专项功能测试。完成标准：得到患侧/对侧比值。
2. **算对侧差异**：`差异% = |患侧 − 对侧| / 对侧 × 100%`。完成标准：给出各测试的差异%。
3. **对照 <10% 判据**：差异 **<10%** → 可视为可接受；**≥10%** → 不合格，继续康复。完成标准：逐项给出"达标/未达标"。
4. **查风险因素并设计预防**：上肢查活动度/肩胛/肩力，下肢查平衡/落地控制/力量；据专项选结构化项目（Sportsmetrics、PEP、Throwers Ten、离心腘绳肌）。完成标准：风险因素清单 + 预防动作。
5. **管理过渡期**：从受监督康复到无限制活动期间持续沟通与复查。完成标准：写出复查节点与团队沟通安排。
6. **输出重返判据结论**。

**输出契约**：`{各测试对侧差异%, 达标判定(<10%), 风险因素清单, 预防项目, 过渡期复查安排, 待补/转诊项}`。
**约定与缺口（如实标注）**：**<10% 判据来自单一引用（`ch23.txt` 引 60）**，原文用 "may be considered"，属**建议性**；样本人群与测试协议未明。本卡据此作"可接受"参考值，并**标注其证据强度弱**，不将其绝对化。

**判停点/分支**：
- ≥10% → 不判可无限制重返。
- 无对侧测量 → 停，先测。
- 无医疗许可 → 转诊（U9）。
- 复工后出现新缺陷/再伤征兆 → 复评并回到康复。

## B — 边界 (Boundary)

- **不要**用"感觉好了/不疼了"代替双侧测量（`ce23-02`）。
- **不要**把 <10% 当铁律——原文 "may be considered"，**单一引用、样本与协议未明**（B 段主依据之一）。
- **不要**在复工后停止评估与管理残余缺陷——缺陷可持续存在、再伤风险高（`ce23-05`）。
- **专业边界**：最终重返决定**常由队医做出**；体能教练提供判据与执行，不自行放行（U9）。
- **证据局限**：<10% 判据证据弱；结构化项目（Sportsmetrics/PEP 等）证据以特定人群为主，迁移到其他专项/人群**不保证**同等效果（BOOK_OVERVIEW 3.3-1 迁移不保证）。
- **变量耦合**：力量、生物力学、功能三方面缺陷可能不同步，单项达标不等于整体达标。
- **相邻易混**：U7/U8（康复分期与处方）、U9（放行与转诊）。
