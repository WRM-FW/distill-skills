# 组织愈合分期与各期目标（炎症期 → 修复期 → 重塑期）

## R — 原文 (Reading)

> "Following injury, all damaged tissues go through the same general phases of healing: inflammation, repair, and remodeling. … the phases of healing progress along a continuum with no definitive timelines." / "This phase typically lasts 72 hours following an acute injury but may last longer with a compromised blood supply and more severe structural damage."

— Chapter 23 · Tissue Healing（`ch23.txt` 第 412–420、369–371 行）

## I — 自述 (Interpretation)

康复不是"疼不疼"的经验判断，而是"**组织现在处于哪一期 → 允许施加何种负荷**"的状态判断。所有受损组织都走**同一套通用分期**（Table 23.1），沿连续谱推进、**无确定时间线**：

1. **炎症反应期（Inflammatory）**：疼痛、肿胀、发红；胶原合成下降；炎症细胞增多。通常急性伤后 **72 小时**，但血供受损/结构损伤更重时可更长。目标 = **防止新组织被破坏 + 避免炎症迁延**；措施 = 相对休息 + 被动因子（冰/加压/抬高/电刺激），**受伤区不做主动练习**；维持未伤部位与心肺功能。循 **POLICE**（保护—最佳负荷—加压—冰—抬高，已取代 PRICE）。冰疗以 **15 分钟**为足；冷水浸泡 **<15 °C（<59 °F）**。
2. **纤维修复期（Fibroblastic repair / proliferative）**：胶原纤维生成、但排列差；炎症细胞减少。**72 小时后开始，可持续至约两个月**（原文另处亦称"可达 8 周"）。目标 = **防止过多肌萎缩与关节退变**；在"不破坏新生胶原"与"渐进低负荷促合成"之间平衡；可用**次最大等长**（无痛）、等速、等张、平衡/本体感觉训练。
3. **成熟—重塑期（Maturation–remodeling）**：胶原排列趋于正常、组织强度上升。可早在伤后数周开始，**可持续数月至数年**。目标 = **优化组织功能、过渡到重返**；渐进加载、转向专项特异性（关节角特异、速度特异、开/闭链、神经肌肉控制）。警惕"**过早过多**"——疼痛减轻早于组织完全愈合（Figure 23.3）。

一句话：**先判期，再定"可施加的负荷"；越早的期越保护，越晚的期越专项。**

## A1 — 案例 / 演练 (Application)

**合成演练（明确标记，按 Table 23.1 特征复算）**：某运动员踝关节 II 度扭伤后第 6 天，仍有肿胀、发红、压痛。
- 依 Table 23.1 特征（疼痛/肿胀/发红、胶原合成下降、炎症细胞增多）判为**炎症反应期**。
- 目标：防止新组织被破坏、避免炎症迁延。措施：相对休息 + 被动因子（冰/加压/抬高/电刺激）；**受伤区不做主动练习**；维持未伤部位与心肺功能；可循 POLICE（早期无痛活动）并以冰疗 15 min 辅助。
- 反面：若此期给受伤区做强抗阻/侧向跳（如 MCL 伤早期做 frontplane 动作）→ 违反"愈合组织不得被过度负荷"。

**原书相关案例（in-book · c23-1，`ch23.txt` 第 703–726 行）**：篮球后卫踝扭伤，康复练习由一般单关节 → 更专项的"平衡/力量（慢而可控）→ 快速伸缩复合/冲刺（快）"进阶——属**重塑期**的一般→专项、慢→快路径；**原书未给具体恢复时间**。

## A2 — 未来触发 (Trigger)

**用户情境**：
1. 受伤后问"现在能练什么、不能练什么？"
2. 问"现在是哪一期、该按什么原则处理？"
3. 急性伤后要不要冰、冰多久、要不要早早活动？
4. 想知道"为什么疼好了还不能上强度/重返"。

**语言信号（中英双写）**：组织愈合 / 炎症期 / 修复期 / 重塑期 / 现在什么阶段 / 能练什么 / 冰敷多久 / POLICE / PRICE / 要不要动 / tissue healing / inflammatory phase / repair / remodeling / how long ice / POLICE。

**与相邻能力的区分（初稿）**：本卡管"**分期与各期目标/允许动作**"。**按愈合期给具体抗阻处方（组×次×强度、DAPRE 调整）** → `cap.nsca.rehab-resistance-progression`；**谁能放行、专业边界/转诊** → `cap.nsca.rehab-scope-and-referral`；**重返判据/对侧差异** → `cap.nsca.reinjury-risk-and-return-to-play`。**与"测试与评估"不同**：那是测量能力，本卡是判断组织状态；**与"周期化"不同**：那是训练计划编排，本卡是伤后分期。

## E — 执行 (Execution)

**输入契约（必需）**：损伤部位与类型（扭伤/拉伤/骨折等）与分级；伤后**天数**；**现症**（疼痛/肿胀/发红/压痛、ROM、力量）；医疗诊断/禁忌（indications/contraindications）。**可选**：血供/合并症。
- **缺失处理**：无医疗诊断/禁忌清单 → **不得**自定"可练内容"，先向医疗团队索取（见 U9）；缺"伤后天数"→ 无法分期，先问。

**步骤与完成标准**：
1. **对照 Table 23.1 特征定位当期**（炎症/修复/重塑）。完成标准：给出期别 + 对应特征证据。
2. **写当期目标**（防破坏/防萎缩/优化功能）。完成标准：目标与期别一致。
3. **定"允许/禁止"动作**：炎症期受伤区不主动练、维持未伤部位与心肺；修复期次最大等长等无痛负荷；重塑期渐进、专项化。完成标准：明确的 allow/avoid 清单。
4. **急性期处置**（仅炎症期）：相对休息 + 被动因子；循 POLICE；冰 15 min、冷水浸泡 <15 °C。完成标准：写明措施与剂量。
5. **标"过渡判据"**：进入下一期需满足的目标（ROM/力量/活动），由医疗团队设定。完成标准：写出判据项。
6. **输出分期结论**。

**输出契约**：`{期别, 判定特征, 当期目标, allow/avoid 清单, 急性处置剂量, 过渡判据, 缺口标注}`。

**原文缺口（如实写明，不补造）**：
- **重塑期时长"数月至数年"跨度过大**，且原文**未给个体推算方法**。
- **重返判据的量化数值原文未给**（重返数值判据仅由 U11 的 **<10% 对侧差异** 部分覆盖，且那条来自**单一引用**）。
- 因此本卡在步骤 5 只要求"写出判据项"，**不虚构阈值**；需要数值判据时转 U11 或由医疗团队裁定。

**判停点/分支**：
- 处于炎症期且未获医疗许可 → 受伤区仅被动处理，主动练习一律暂缓。
- 疼痛已退但组织未愈（Figure 23.3）→ **不**据此判"可全量"，仍按分期渐进（`ce23-02`）。
- 分期不明/症状异常（红肿热痛加重、发热）→ 转诊，不自行分型。

## B — 边界 (Boundary)

- **不要**用"疼不疼"作为唯一分期依据——疼痛先于组织愈合消退（`ce23-02`/`ce23-03`）。
- **不要**对愈合组织施加过大应力；同一动作在不同分期意义不同（`ce23-01`）。
- **不要**忽略运动平面（如 MCL 伤早期避免内外翻应力）。
- **原文自认的缺口（B 段主依据）**：分期"无确定时间线"（`ch23.txt` 第 320 行）、重塑期"数月至数年"过宽、**重复判定与重返的数值判据缺失**（`_verified` 缺口 p23-05）——本卡**不补造**。
- **专业边界**：本章明言"not intended to provide rehabilitation protocols for specific injuries"；分期与过渡判据应由**医疗团队**设定，体能教练不越界诊断（`ce23-04`）。
- **法域/证据**：冰疗、POLICE 的证据为混合（原文亦称 ice 使用存在争议）；<10% 判据来自单一引用。
- **相邻易混**：U8（按愈合期抗阻处方）、U9（专业边界/转诊）、U11（重返判据）。
