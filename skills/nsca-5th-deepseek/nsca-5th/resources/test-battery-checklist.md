# 测试电池与测试日准备（核对清单）

- 来源：src-nsca-essentials-5e · Chapter 13 "Principles of Test Selection and Administration"（`ch13.txt`）
- 用途：为 `cap.nsca.sport-specific-test-battery`（电池配比与四维覆盖）与 `cap.nsca.test-prep-standardization`（测前准备、记录、测日标准化）提供可逐项勾选的核对清单。
- 说明：条目取自原文测选与施测章的原则陈述与各测试协议框；未给数值处只列"须核对"不虚构阈值。

---

## 一、测试电池构建核对（配合 `cap.nsca.sport-specific-test-battery`）

按专项特异性筛选测试，逐项确认：

- [ ] **声明专项需求**：写出目标专项/位置的关键能力成分（如冲刺、敏捷、有氧耐力、专项功率）。
- [ ] **供能系统覆盖**：电池是否覆盖专项主要供能系统（磷酸原 / 糖酵解 / 有氧），无系统级盲区。
- [ ] **动作模式覆盖**：是否覆盖专项关键动作模式（推/拉/蹲/髋铰链/旋转、单侧 vs 双侧）。
- [ ] **肌群覆盖**：主要发力肌群是否都有对应测试。
- [ ] **技能复杂度匹配**：高技巧测试（如单腿跳类）是否与受测者经验水平匹配。
- [ ] **四维覆盖检查表**：动作模式 / 肌群 / 供能系统 / 技能复杂度四维逐一打勾，标记空档。
- [ ] **成分→测试映射**：每个能力成分至少有一个有效（效度/信度达标）测试对应。
- [ ] **权重标注**：各成分测试占比是否与其对专项的重要性成比例（内容效度加权规则）。
- [ ] **适用性过滤**：核验年龄、性别、训练状态、经验是否落在测试的效度/信度适用范围内（如 1.5-mile 跑对青春期前不适用）。
- [ ] **排除项与理由**：被剔除的测试写明理由（效度不成立 / 技巧负担过高 / 不适用人群）。

## 二、测试日准备与标准化核对（配合 `cap.nsca.test-prep-standardization`）

### 测前（通知与熟悉）

- [ ] 提前公布**日期、时间、目的**与着装/准备要求。
- [ ] 测前 1–3 天安排**熟悉课**（或把熟悉练习融入动态热身）。
- [ ] 讲解覆盖：目的 / 执行方法 / 热身量 / 练习次数 / 试次数 / 评分方式 / 无效准则 / 表现建议。
- [ ] 演示 + 提问 + 同等激励 + 即时反馈。
- [ ] 统一热身结构：一般热身 + 专项热身 + 2–3 次热身试次。
- [ ] 首次受测者完成当场"重测留痕"检查（必要时改日重测）。

### 记录表字段

- [ ] 预留**全部试次结果**（不只最佳成绩）。
- [ ] **备注**栏（异常、中断、天气等）。
- [ ] **环境记录**：温度、湿度（必要时气压 / 海拔）。
- [ ] **设备设置**：如深蹲插销高度、器材品牌/型号、平台/仪器设置。
- [ ] 受测者标识、日期、时段、测试员姓名。

### 测日一致性与场地

- [ ] 测试固定在**同一时段**进行（避免昼夜节律造成的波动）。
- [ ] 尽量在**室内**进行，使气候与测试表面更一致。
- [ ] 器材前后一致，不中途更换（如坐位体前屈不许尺/箱混用）。
- [ ] 测试顺序按非疲劳→敏捷→最大力量/爆发→冲刺→局部肌耐力→无氧→有氧（配合 `cap.nsca.test-sequencing-rest`）。
- [ ] 测后**监督整理**：收表、归档、复核异常值。

## 三、环境与安全即时核对（配合 `cap.nsca.test-environment-adjustment` / `cap.nsca.test-health-safety-referral`）

- [ ] 记录海拔：>579 m 时核验常模是否需按海拔修正；到高海拔后是否已适应 ≥10 天。
- [ ] 极端热湿日：是否留足安全裕度、改室内/清晨，或推迟。
- [ ] 测前 24 h 是否补水；>1 h 是否补电解质；热习服是否 ≥1 周。
- [ ] 现场备医疗覆盖与转诊路径（红旗症状 → 转诊；低钠血症 → 绝不补液、交医师）。
