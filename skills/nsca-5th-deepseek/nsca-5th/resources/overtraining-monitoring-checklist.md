## 一、表现类变量敏感度与出现顺序（Table 24.1）

| 变量 | 敏感度 | 出现顺序 / 起始 |
|---|---|---|
| **力量 STRENGTH** | | |
| 1RM（动态恒外阻 DCER） | Low | 最后发生 |
| 等长力 | Poor | 未知 |
| 等速力 | High | 1 周内 |
| 离心力量 | Unknown | 未知 |
| 刺激力（stimulated force） | High | 1 周内 |
| 单关节 | Poor | 等速则 1 周；DCER 未知 |
| 多关节 | Moderate | 最后发生 |
| **力发展速率 RFD** | | |
| 单关节 | Low | 未知 |
| 多关节 | Unknown | 未知 |
| **功率 POWER** | | |
| 抗阻动作功率 | High | 1+ 周内 |
| 纵跳高度 | Low | 很少发生 |
| 纵跳动力学（力/反应强度） | High | 1 周内 |
| 纵跳运动学（姿势/策略） | High | 1 周内 |
| **速度 VELOCITY** | | |
| 冲刺 | **High（最敏感，最先下降）** | 1+ 周内 |
| 抗阻动作（DCER） | High | 1+ 周内 |
| 变向与敏捷 | Moderate | 1+ 周内 |
| EMG-to-force 比值（电活动效率） | High | 数天内 |
| **其他 OTHER** | | |
| 自我效能（自信） | High | 1 周内 |
| **恢复感知** | **Very high** | **数天内** |
| 训练意愿 | High | 1 周内 |
| 训练容量（承受高量高频的能力） | Moderate | 较慢发生 |

**要点**：速度（冲刺）最敏感、最先下降 → 其次功率 → **最大力量最后下降**。故**首发预警不应只盯 1RM**。

## 二、监控指标清单（Figure 24.15）

- 被监控的训练负荷（内部 + 外部）
- 静息心率 / 恢复心率
- 肌肉 O₂ 饱和度
- 心率变异性（HRV）
- 无氧阈 / VO₂max / RPE / 乳酸
- 重复完成 GXT 的能力、完成一次训练课的能力
- 纵跳：高度 / 动力学（力、功率）/ 运动学（姿势、策略）/ 僵度 / 离心使用比
- 抗阻表现：最大力量 / 速度—负荷曲线 / 功率—负荷曲线 / 同绝对负荷的杠速 / 等长中段拉 / 肌耐力测试 / 力发展速率
- 冲刺：加速 / 第一步速度 / 减速 / 最大速度
- 变向与敏捷、反应与移动时间、认知加工测试
- 饮食记录、睡眠记录、训练问卷、比赛数据、教练主观评估

## 三、问卷清单（Table 24.3）

**过度训练相关**：RPE（Borg 1982）、CR10 RPE、POMS / 37-item POMS、DALDA（运动员日常生活需求分析）、EmRecQ（情绪恢复问卷）、MTDS（多成分训练困扰量表）、REST-Q in Sport、ARSS / SRSS（急性/短版恢复-压力量表）、Recovery-Cue Inventory、TQR（总体质量恢复问卷）、Perceived Recovery Status、Rating of Fatigue Scale、Resistance Exercise Overtraining Questionnaire、Hooper Index、TDS（训练困扰量表）、PFAI。

**心理氛围相关**：TEOSQ、PMCSQ、CCS（关怀氛围量表）。

**睡眠相关**：PSQI（匹兹堡睡眠质量指数）、ASSQ（运动员睡眠筛查问卷）。

**教练心理健康**：Multiday coach survey。

**选问卷 6 条考量**（`ch24.txt` 第 829–836 行）：
1. 问卷多长、多少题？
2. 是否经验证（validated）？
3. 措辞对目标人群是否易懂？
4. 数据能否快速处理、快速回传？
5. 能否在无胁迫下作答？
6. 是否对过度训练刺激敏感？

## 四、施测纪律（四问质量闸 + 施测要求）

**测试四项质量**：specific/valid · reliable · sensitive · easy to incorporate。
**施测要求**：施测者严格遵守协议；确保受试者尽**最大努力**；否则数据无意义。
**数据回路**：高效数据管理系统，**快速回传**以支持及时调整。

---

## 五、分级检测升级路径

- **Category I**：每日、易施测、便宜、结果快速回传、方便教练与运动员。
- **Category II**：每隔几天、更复杂、更长问卷、稍不便、仍需快速回传。
- **Category III**：偶尔（如每月一次）、更繁琐且具侵入性、更贵、回传更慢。

**升级规则**：先做 I → 若"提示可能有过训练顾虑" → 升 II → 若 II 提示"过度训练问题" → 可做 III。
**判停**：I 正常则不升；II 未见问题则不上 III。**原文未给升级的具体阈值**（仅定性表述），阈值须结合队内基线自建（约定）。

---

## 六、合规与边界提示

- **阈值缺失**：Table 24.1 多项为 Unknown / 无百分比切点；本表**不编造**报警阈值。
- **医学检测越界**：体能教练 "does not typically order medical or laboratory tests"；抽血/实验室类须由医疗人员执行与解读。
- **专业边界**：疑似疾病/心理问题（RED-S、抑郁等）→ 转诊，不自行处置。
- **主观量表局限**：可靠性依赖受试者经验与诚实度，原文对其失效条件讨论不足。
