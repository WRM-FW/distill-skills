# 速度与敏捷训练设计（晋级伞形卡）

## R — 原文 (Reading)

> "Speed. The skills and abilities needed to achieve high movement velocities. Change of direction. The skills and abilities needed to explosively change movement direction, velocities, or modes. Agility. The skills and abilities needed to change direction, velocity, or mode in response to a stimulus." ... "agility requires the use of perceptual-cognitive ability in combination with change-of-direction ability."

— Chapter 20 · 开篇三分定义（`ch20.txt` 第 32–37 行）；"Agility Performance and Change-of-Direction Ability"（第 61–63 行）

## I — 自述 (Interpretation)

这是一张把 Ch20 全部设计环节串起来的自包含主卡，端到端回答"给一名运动员怎样设计速度与敏捷训练"。骨架为七环：**① 能力判定**——先把模糊的"速度问题"归到 Speed / COD / Agility 三类（判据是有无反应性刺激；敏捷 = COD + 知觉—认知）。**② 需求分析**——测试→标准化比较→定主/次需求→分配时间→编排过渡，五步成链。**③ 速度侧处方**——用 short-to-long 的 4-block（加速→长加速→引入最高速→强化最高速）排速度课。**④ 敏捷侧处方**——用 3-block（线性减速→横向减速→减速接再加速+反应）排敏捷课，每课 10–15 min、每周 1–3 次。**⑤ 手段选择与进阶**——速度手段分三级（primary/secondary/tertiary），负荷有经验档；任何练习都可用退阶/进阶/变式调难度。**⑥ 监控**——用触地时间、COD deficit、exit/entry velocity 等交叉解读进步来源。**⑦ 技术纠错**——冲刺用"症状→原因→纠正"，变向用四维度诊断。整条链都受同一底层约束支配：短时爆发性动作由力、RFD 与 impulse 决定，而非最大力量或抽象功率。

## E — 执行 (Execution)

**输入契约**
- 必需：① 项目（sport）与专项需求；② 运动员训练状态（新手/中级/高级）；③ 可用时间窗（周数与 block 划分）；④ 测试成绩（速度/COD/敏捷）+ 表现标准或队均值；⑤ 每周可用课次与单课时长。
- 缺 ④ 时：Step2 可用 performance standards 替代队均值；两者都缺先询问。不得静默猜值。

**完整设计流程（七步，每步有完成标准）**
1. **能力判定**：先归因到 Speed / COD / Agility（判据：是否预先计划、是否含反应性刺激）。完成标准：给出能力类别与训练成分。
2. **需求分析 5 步**：① 项目需求分析 + 匹配测试（Table 20.9）；② 成绩标准化后与标准值/队均值比较（图 20.13）定强弱项；③ 定主需求 + 次需求；④ 按需求分配时间；⑤ 给跨 block 百分比过渡计划并定监控检验（用 COD deficit）。完成标准：三层需求 + 主/次需求 + 时间分配表。
3. **速度分块处方（Table 20.7）**：排 4 个 block——加速发展（斜坡冲刺、阻力加速 bounds）→ 长加速（平地/牵引、acceleration holds）→ 引入最高速（block starts、fly-ins、速度耐力置于高疲劳位）→ 强化最高速（长 fly-in、race modeling、技术课）。每课含技术 drill 热身，格式为 组×距离×(组间休息)。完成标准：4 block × 每周课次的微周期。
4. **敏捷分块处方（Table 20.11）**：排 3 个 block（各 4 周）——Block1 线性减速（Decelerations 5 yd 1×6(30 s)、侧滑/后撤 1×4×11 yd(30 s)）→ Block2 横向减速与过渡（Decelerations 11 yd 1×6、Z-drill 2×4(30 s;2 min)、Y-drill 3×4）→ Block3 减速接再加速 + 反应（Modified 5-0-5 2×4(30 s;2 min)、T-test 1×4、Reactive agility(Y) 1×4）。每课 10–15 min，每周 1–3 次；减速速度半速→四分之三速渐进。完成标准：3 block × week1 处方。
5. **手段选择与进阶**：速度手段三级——Primary（max-velocity sprint）、Secondary（抗阻/助力冲刺）、Tertiary（举重动作、跳跃）；负荷档：超速增幅 ≤10%、田径短跑抗阻使跑速下降 ≤10%–12%、场地项目抗阻 20%–30% 体重；任一练习用**退阶/进阶/变式**调难度（退阶先保技术）。完成标准：每条练习标注手段级别与负荷档。
6. **监控**：速度侧用 Table 20.8（GCT、步长/步幅长、腾空时间、步幅角、速度、加速度、技术）；敏捷/COD 侧用 Table 20.12（完成时间、COD deficit、GCT、exit/entry velocity、决策时间、分相）。交叉解读：GCT↓+完赛↓ = RFD 提升；COD deficit 不变而完赛变化 = 直线速度影响；exit velocity↑ 且 GCT 同/更短 = COD 相关 RFD 提升。**判停点**：无常模时只报"变化方向"，不判达标。完成标准：输出指标归因与调整依据。
7. **技术纠错**：直线冲刺用"症状→原因→纠正"（Table 20.1，分起跑加速段与最高速段；口令如"向下向后蹬地，别扒地"）；变向用四维度诊断（视觉聚焦/躯干姿态/腿部 co-triple flexion/摆臂）。完成标准：输出症状—成因—纠正清单。
- **失败处理/分支**：若某环缺关键输入（如无测试成绩、无时间窗），暂停并询问；若加速机制不稳，**不进入最高速 block**；若运动员无法在认知负荷下保持技术质量，退回上一难度级。

**输出契约**
- 完整交付物：`{能力判定, 需求分析与主/次需求, 速度 4-block 微周期, 敏捷 3-block 处方, 手段与负荷档, 监控指标与归因规则, 技术纠错清单}`；每条处方含 组×距离×(休息)。

## B — 边界 (Boundary)

- **不要用**：当问题只是快速伸缩复合（落地/RSC/量进阶）时用 **`nsca-plyometric-design`**；当问题是有氧耐力与强度分区时用 **`nsca-aerobic-endurance-design`**；当只做单项判定或单个计算时下钻到 U1–U14 对应卡。
- **作者警告的失败模式**：把最高速训练过早前置；用封闭变向 drill 冒充敏捷（ce20-04）；用"加大步幅"提速（ce20-01）；只看完成时间下结论。
- **盲点（BOOK_OVERVIEW 步骤 3）**：所有表格值有**人群/年代依赖**（Table 20.4/20.7/20.10/20.11 多为示例或特定来源）；共识 ≠ 实证（负荷与阈值多为经验/区间值）；体能改善**迁移不保证**，需专项验证；变量耦合，不可孤立套单一参数；教练专业边界（损伤诊治转诊）。
- **相邻易混**：`nsca-plyometric-design`（Ch19 快速伸缩复合）、`nsca-aerobic-endurance-design`（Ch21 有氧耐力）。
