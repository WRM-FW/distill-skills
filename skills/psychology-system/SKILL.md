# psychology-system

基于用户 Google Drive 云盘中 28 部心理学、精神分析、心理治疗、社会心理学、亲密关系、沟通科学、脑科学与行为经济学典籍，按仓颉 `cangjie-skill` (RIA-TV++ 流水线) 蒸馏而成的全书系可执行心理学主路由技能。

## When to Use

当用户提出以下请求时调用本技能：

- **深层潜意识、人格类型与存在困境剖析**：解析心理防御机制、强迫性重复、弗洛伊德/荣格解梦、荣格八维认知功能(`Te/Ti/Fe/Fi/Se/Si/Ne/Ni`)与阴影/阿尼玛投射、阿德勒目的论与课题分离、亚隆四大终极关怀(死亡、自由与决断瘫痪、存在孤独、无意义感)及弗洛姆“逃避自由/爱的艺术”。
- **情绪内耗、自我状态切换与临床心理初筛**：识别《蛤蟆先生去看心理医生》中的 `PAC (父母-成人-儿童)` 自我状态、四种人生坐标与 `PLOM/NIGYSOB` 心理游戏，梳理丧失哀伤(“欢迎来到荷兰”)，或按《变态心理学》`4D 准则`与贝克 CBT 10 项认知扭曲进行症状机制拆解、行为激活与暴露预防(ERP)规划。
- **社会说服防卫与群体盲从脱嵌**：运用西奥迪尼《影响力》六大武器(互惠/留面子法、承诺一致/登门槛/抛低球、社会认同/旁观者效应求救、喜好、权威、稀缺)设计合规说服方案或反诈骗/反逼单防卫，拆解认知失调中的自我合理化策略，或运用勒庞《乌合之众》与迈尔斯群体动力学防范网络风暴、群体极化与团队群体思维(Groupthink)。
- **亲密关系诊断与高难度人际沟通**：运用斯滕伯格《爱情心理学》爱情三元论(亲密、激情、承诺 8 种爱情类型)与米勒《亲密关系》成人依恋四象限及相互依赖公式(`Outcome, CL, CL_alt`)诊断婚恋症结；运用卢森堡《非暴力沟通》四要素闭环、都希格《超级沟通者》三类对话匹配原则与“理解循环(Looping for Understanding)”拟定高情商沟通话术。
- **认知升级、技能精进与行为决策架构**：运用周岭《认知觉醒》三重大脑与元认知消除模糊、艾利克森《刻意练习》心理表征与 `3F 原则`突破高原期、克利尔《原子习惯》四步回路与“两分钟规则”重塑习惯，或运用塞勒《助推》`NUDGES` 选择架构、心理账户与查理·芒格《25种人类误判心理学》(`Lollapalooza` 效应)进行决策排雷。

不适用于：

- 替代精神科执业医师开具处方药、调整精神科药物剂量或出具具有法律效力的正式精神医学诊断书。
- 实施欺诈、精神控制(PUA)、恶意诱导消费或隐蔽剥夺用户选择权的暗黑模式(Dark Patterns)。

## Core Principles

1. **临床安全与 4D 分诊优先原则 (Clinical Triage First)**：在调用任何哲学或认知激励框架前，先用 `06` 的 `4D 准则`(偏离度、主观痛苦、社会功能受损、自伤/伤人危险)扫描安全红线。面对急性创伤、重度抑郁或高危危机，优先启用临床共情抱持(`05/06`)与专业医疗转介，严禁机械套用阿德勒“你的不幸是自己选的”造成二次伤害。
2. **因果还原与目的前瞻双轨互补 (Etiology + Teleology Dual-Track)**：用弗洛伊德(`01`)、荣格(`02`)与沟通分析(`05`)看清潜意识防御、童年脚本与阴影投射的“来龙去脉”；一旦完成觉察，立即切换至阿德勒(`03`)与存在主义(`04`)的“此时此刻目的论”，通过课题分离与责任所有权改写(`把“我不得不”改为“我选择”`)夺回当下行动权。
3. **频道匹配先于话术技巧 (Channel Matching Before Phrasing)**：在一切人际与亲密关系沟通(`09/10`)中，先按《超级沟通者》判断当前处于**务实对话(What)**、**情感对话(How we feel)**还是**身份对话(Who we are)**；未完成频道对齐与“理解循环”前，绝不盲目抛出理性建议或机械背诵 NVC 句式。
4. **顺应三重大脑与环境摩擦设计 (Design for Humans, Not Econs)**：承认本能脑与情绪脑(`11,000,000 次/秒`)远强于理智脑(`40 次/秒`)，放弃靠意志力硬扛；通过消除模糊、两分钟规则降低启动摩擦力(`11`)，并利用默认选项与防呆架构(`12 NUDGES`)让正确行为成为最省力的路径。
5. **多重偏误熔断机制 (Lollapalooza Circuit-Breaker)**：面对外部说服(`07`)、群体狂热(`08`)或重大财务/人生决策(`12`)，一旦检出 `>=3 种` 心理触发器或认知偏差(如互惠 + 稀缺 + 社会认同 + 权威 + 损失厌恶/沉没成本)同向叠加，立即触发强制冷却与逆向证伪审计。

## Steps

### Step 1: 临床安全初筛与需求层级定性 (Triage & Layer Identification)

在响应任何心理、关系或行为请求前，快速完成三项定性判断：

1. **安全与临床红线检查 (`06`)**：是否存在自伤/自杀风险、精神病性幻觉妄想或严重社会功能瓦解？若有，立即优先执行危机干预与医疗就医引导。
2. **内部动力 vs 外部交互定性**：问题核心是个体内部的**情绪/意义/习惯卡点**(`01-06, 11-12`)，还是双人/群体的**沟通/关系/博弈冲突**(`03, 05, 07-10`)？
3. **觉察溯源 vs 行动破局阶段**：用户当前是需要先被共情倾听、看清潜意识症结(`01, 02, 05, 10`)，还是已经清楚原因、亟需斩断内耗并拿到具体行动/话术方案(`03, 04, 07-12`)？

### Step 2: 路由加载对应能力卡并执行结构化诊断 (Capability Card Execution)

根据上方路由表读取 1-2 张最核心的 `references/capabilities/*.md` 能力卡(复合问题可按 `composes-with` 组合调用)：

- **个体内耗与成长线**：按 `PAC自我状态/防御扫描 (01/05) -> 目的论与课题分离切割 (03) -> 终极关怀与责任所有权转换 (04) -> 三重大脑消模糊 + 原子习惯两分钟启动 (11)` 推进。
- **亲密关系与沟通线**：按 `爱情三元论与依恋追逃诊断 (09) + 课题分离边界核查 (03) -> 三类对话频道匹配 (10) -> 理解循环 + NVC 四要素逐字话术生成 (10)` 推进。
- **社会防卫与理性决策线**：按 `六大说服触发器扫描 (07) + 群体传染/极化脱嵌 (08) -> 心理账户与沉没成本清零测试 (12) -> 芒格 25 项误判与 Lollapalooza 熔断核查 (12)` 推进。

### Step 3: 对照核心定量与决策速查表校验输出 (Quantitative & Structural Audit)

在生成最终方案或话术前，使用以下跨书核心标尺核验输出质量：

| 审计维度 | 核心检验公式 / 黄金判准 | 来源典籍锚点 |
| :--- | :--- | :--- |
| **边界归属判准** | `这件事情最终的直接后果由谁承担？` (谁承担就是谁的课题，绝不越界替对方背负) | 《被讨厌的勇气》第三夜 |
| **沟通句式检验** | `观察(无“总是/从不”评论) + 感受(无“我觉得你...”想法) + 内在需要 + 可执行请求(非命令)` | 《非暴力沟通》第3-6章 |
| **对话匹配检验** | 对方在谈情绪时，是否先完成了 `深层提问 -> 自己语言概括重述 -> 请求确认(理解循环)`？ | 《超级沟通者》第3-5章 |

| **决策偏差校准** | 损失厌恶赋予失去 `2.0-2.5 倍` 权重；是否通过“清零重置为等额现金测试”排除了沉没成本与禀赋效应？ | 《助推》+《“错误”的行为》 |

### Step 4: 执行学派适用边界与反例自检 (Boundary & Failure Mode Check)

确保输出不触碰各学派的典型翻车陷阱(详见各能力卡 `B - Boundary` 章节)：

1. **严禁野蛮贴标签**：不用精神分析术语或 MBTI/依恋类型给当事人或伴侣下死刑判决，也不用 PAC 术语居高临下指责伴侣。
2. **严禁伪非暴力沟通**：检查生成的 NVC 话术是否自然真诚，避免说成机械冷漠的“翻译腔”或把强人所难的命令包装成请求。
3. **严禁意志力说教**：在给出行为改变或习惯养成方案时，绝不只喊“你要自律/要坚持”，必须给出具体的物理环境改造(移除坏提示、增加好提示)与 2 分钟最小启动动作。

## Gotchas

- **把“课题分离”当成冷酷断联**：阿德勒的课题分离是“不强按马头喝水，但随时准备好在对方求助时提供横向支援”，切勿将其歪曲为对伴侣或家人的冷暴力漠视。
- **混淆“情感(Feeling)”与“情绪(Emotion/Affect)”**：在荣格八维(`02`)中，情感(F)是与思维(T)并列的严密**理性价值判断功能**，而非失控的情绪宣泄；在卢森堡 NVC(`10`)中，“我觉得你不在乎我”是想法/评判，而非真实感受(真实感受是“我感到孤单/不安”)。
- **在对方处于“适应型儿童”崩溃期时强推理性方案**：当一个人正陷入悲伤或愤怒(`05/10`)，其本能脑与情绪脑已接管控制权；此时必须先用“理解循环”与全身心倾听帮其卸载情绪，待其恢复“成人状态”与理智脑带宽后，再进入务实方案设计。
- **用“低水平勤奋打卡”替代刻意练习**：没有跨出舒适区边缘、没有即时纠错反馈(`Feedback & Fix it`)的机械重复(`11`)，无论堆满多少个小时都属于“天真的练习”，无法构建高阶心理表征。
