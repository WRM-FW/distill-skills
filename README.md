# distill-skills

**个人 Agent Skill 统一管理仓库** —— 汇聚由经典书籍、专业课程、实用工具及人物语料中深度蒸馏的 Agent Skills。通过结构化与能力化沉淀，打造开箱即用的个人外脑知识资产。

* **核心代表作**：`psychology-system`（心理学体系化技能）、`nsca-5th`（体能与力量训练科学）
* **技能总数**：10 个（位于 [skills/](skills/) 目录）
* **许可协议**：PolyForm Noncommercial 1.0.0（详见各 Skill 目录下的 `LICENSE` 文件）

## 按场景选 Skill：分领域详细说明

### 1. 心理学与亲密关系

如果只是日常心理分析、行为改变或沟通问题，优先用 **`psychology-system`** 作为统一入口；如果需要教材级严谨定义或特定细分场景，再调用下面对应的专著 Skill。

* **`psychology-system`**
  * **干啥的**：全书系可执行心理学主路由，整合了精神分析（弗洛伊德、荣格、阿德勒）、存在主义、CBT、社会影响（西奥迪尼、勒庞）、亲密关系、非暴力沟通、习惯工程（《掌控习惯》）与行为经济学（《助推》、芒格）。
  * **什么时候用**：分析潜意识防御或梦境、识别 CBT 认知扭曲、反制说服套路、起草非暴力沟通对话、制定刻意练习或微习惯计划。
* **`zimbardo-psych-8th`**
  * **干啥的**：基于《津巴多普通心理学（第 8 版）》14 章内容蒸馏的基础心理学执行框架。
  * **什么时候用**：需要实验设计批判性思维、经典/操作性条件反射矫正行为、记忆“七宗罪”优化学习、大五人格与津巴多时间观（ZTPI）剖析、DSM-5 心理障碍初步筛查。
* **`social-psychology`**
  * **干啥的**：基于大卫·迈尔斯《社会心理学（第 11 版）》的诊断与干预系统。
  * **什么时候用**：纠正事后聪明偏差与基本归因错误（FAE）、设计 ELM 说服与态度免疫方案、防范群体极化与社会懈怠、用 GRIT 策略化解群体或人际冲突。
* **`intimate-relationships-8th`**
  * **干啥的**：基于罗兰·米勒《亲密关系（第 8 版）》的循证关系科学系统。
  * **什么时候用**：恋爱/婚姻诊断、ECR-S 依恋风格评估、用 XYZ 句式化解非暴力沟通僵局、运用戈特曼冲突管理与 Rusbult 投资模型评估关系走向。

### 2. 体能与力量训练科学

* **`nsca-5th`**
  * **干啥的**：基于 NSCA《Essentials of Strength Training and Conditioning（第 5 版）》的前沿运动表现与体能训练系统。
  * **什么时候用**：设计抗阻、爆发力（增强式训练）、速度与变向敏捷（COD）周期计划；计算 `%1RM` / `RIR` / 链条与弹力带可变阻力负荷；解读测力台与 VBT 速度数据；制定青少年/孕妇/老年等特殊人群训练方案；评估运动营养与相对能量不足（RED-S）。
* **`nsca-3rd`**
  * **干啥的**：基于 NSCA 第 3 版经典教材的体能训练系统。
  * **什么时候用**：常规力量与体能课表编排、基础运动测试排序、动作技术与保护（Spotting）规范检查、DAPRE 伤后功能康复与体能房设施规划。

### 3. 逻辑、决策与个人知识库

* **`logic-system`**
  * **干啥的**：整合陈波、波普尔、叔本华、芭芭拉·明托、罗翔、迪克西特等 20 本著作的全能逻辑操作系统。
  * **什么时候用**：检验三段论与文氏图、画真值表或卡诺图、用穆勒五法做因果归因、用图尔敏模型拆解诡辩与谬误、用 MECE 金字塔整理汇报结构、求解博弈均衡与法律因果关系。
* **`personal-library-wisdom`**
  * **干啥的**：个人书库（246 个文件、228 个蒸馏单元、16 个主题簇）的总入口。
  * **什么时候用**：判断某个论断或研究是否可信（证据分级）、做成本收益与激励机制设计、用长时段视角复盘战略或社会舆论、排查技术路线、查证经典原文与训练中文写作。

### 4. 人物思维模型

* **`persona-luoxiang`**
  * **干啥的**：基于 19 期读评论、22 篇经典讲读与 14 场访谈提炼的罗翔思维操作系统（6 个核心心智模型 + 10 条决策启发式）。
  * **什么时候用**：当你希望用“承认人的有限性、坚守良知与法治边界”的视角来审视一个现实处境、复盘自己的判断是否带有傲慢或双标时触发（例如说“用罗翔的视角看看这件事”）。

### 5. 实用工程工具

* **`book-translator`**
  * **干啥的**：工业级长文本与书籍双引擎翻译系统（支持 PDF、DOCX、EPUB、Markdown、XHTML）。
  * **什么时候用**：需要高质量翻译整本书或长篇文稿、建立全书一致性术语表、彻底清除“欧化中文翻译腔”，并输出适配 Apple Books / Kindle / 深色模式的出版级 EPUB 3、PDF 或 DOCX。

## 快速开始

### 1. 仓库结构

```text
distill-skills/
├── README.md
└── skills/
    ├── book-translator/              # 出版级整书翻译流水线
    ├── intimate-relationships-8th/   # 《亲密关系 第8版》关系诊断与修复
    ├── logic-system/                 # 全书系逻辑推理主路由
    ├── nsca-3rd/                     # NSCA 第3版体能与力量训练
    ├── nsca-5th/                     # NSCA 第5版体能与力量训练（旗舰）
    ├── persona-luoxiang/             # 罗翔思维操作系统
    ├── personal-library-wisdom/      # 个人书库 228 单元思想武器库
    ├── psychology-system/            # 全书系心理学主路由（核心代表作）
    ├── social-psychology/            # 《社会心理学 第11版》干预系统
    └── zimbardo-psych-8th/           # 《津巴多普通心理学 第8版》全书蒸馏
```

### 2. 使用方式

```bash
git clone --depth 1 https://github.com/WRM-FW/distill-skills.git
cp -r distill-skills/skills/<skill-name> <你的 Agent Skill 目录>/
```

把 `skills/` 下所需的 Skill 文件夹复制到你的 AI Agent 技能目录中即可加载使用（每个 Skill 目录均包含完整的 `SKILL.md` 定义，部分技能附带 `references/` 知识卡片或 `scripts/` 工程脚本）。只拷 `SKILL.md` 会丢失能力卡，整个目录一起拷。

* **懒人用法**：直接装入 `psychology-system`、`nsca-5th`、`logic-system` 与 `personal-library-wisdom` 四个主干技能，即可覆盖日常 80% 以上的思考、决策、心理与训练需求。
* **按需扩展**：遇到整书翻译需求加载 `book-translator`；需要特定教材的细粒度查证或特定视角对话时，再挂载对应的单书或人物 Skill。

## 维护规范

**目录约定**：一个 Skill 一个目录，目录名与 `SKILL.md` 的 `name` 一致；每个目录含 `SKILL.md`、`README.md`、`CHANGELOG.md`、`LICENSE` 四件套，能力卡与脚本放在 `references/`、`scripts/`。

**上游口径**：九个 Skill 由 [cangjie-skill](https://github.com/kangarooking/cangjie-skill)（MIT）蒸馏生成；
`persona-luoxiang` 由 [Distilly](https://github.com/titanwings/distilly) 与 [nuwa-skill](https://github.com/alchaincyf/nuwa-skill)（均 MIT）生成；
`book-translator` 为原创手写，无上游。上游只写作法来源，不影响本仓库的许可。

**版本与发布**：每个 Skill 独立发版，标签为 `<skill-name>-v<semver>`，版本差异记在各目录 `CHANGELOG.md`。

```bash
git add skills/<skill-name> && git commit -m "<skill-name>: <变更>" && git push
git tag -a <skill-name>-v<X.Y.Z> -m "<skill-name> vX.Y.Z" && git push origin <skill-name>-v<X.Y.Z>
gh release create <skill-name>-v<X.Y.Z> --title "<skill-name> vX.Y.Z" --notes "<能力变化 / 来源 / 许可>"
```
